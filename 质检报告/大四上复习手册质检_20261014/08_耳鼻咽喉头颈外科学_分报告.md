## 第 3 节　事实核验记录（每模块 ≥3 条，带证据）

### M1 总论
1. **额镜工作距离约 25 cm**（手册 L2319）——属检查法基础，与教材一致；题干库 Q3 即考此距离。✅
2. **急症首步＝先处理气道/生命、再查因**（手册 L17、L407 图3）——手册在"急症危险信号"callout 反复强调，与教材"先救命后诊断"一致。✅
3. **鼻内镜/耳内镜/纤维喉镜适应证链**（手册 L290-298）——影像分工（CT/MRI 看骨、超声看颈部软组织、PET-CT 找转移）表述准确。✅

### M2 耳
1. **外耳道峡＝骨部距鼓膜约 0.5 cm**（手册 L2436 主动回忆）——教材原文一致。✅
2. **小儿咽鼓管短、宽、接近水平 → 上感易经此入中耳**（手册 L2370）——教材一致，系儿童中耳炎好发的解剖基础。✅
3. **迷路瘘管好发于外半规管凸后上方**（手册 L496）——与教材"面神经管凸上方为外半规管凸"一致。✅
4. **鼓膜/听骨链传音、骨导反映内耳功能**（手册 L2376）——音叉三试验互证逻辑正确。✅

### M3 鼻
1. **鼻出血部位分流**（手册 L1136）：儿童青少年＝鼻中隔前下易出血区（Little/克氏丛）；中老年＝下鼻道后部吴氏鼻-鼻咽静脉丛；鼻中隔后部动脉 90% 来自蝶腭动脉。**教材 L9710-9711 逐字一致**（"儿童、青少年…多数发生在该部位。中、老年患者的鼻出血多发生在…吴氏鼻-鼻咽静脉丛；亦可为鼻中隔后部动脉（90%来自蝶腭动脉）"）。✅
2. **鼻窦引流/OMC**（手册 L1171、L1257）：前组鼻窦开口中鼻道、后组筛窦开口上鼻道、蝶窦开口蝶筛隐窝；OMC 以筛漏斗为中心。**教材 L6930"前组鼻窦的开口均位于中鼻道"、L6959"后组筛窦开口于上鼻道"、L6954-6955 OMC 定义**——一致。✅
3. **慢性鼻窦炎病程 >12 周、主要症状必具其一**（手册 L1051）——与教材 CRS 定义一致。✅
4. **鼻疖→危险三角→海绵窦血栓性静脉炎、严禁挤压**（手册 L1172）——题库 Q16/17 高频点，手册表述准确。✅

### M4 咽
1. **OSAHS 双轴分度**（手册 L1623-1630）：成人 AHI 5~15 / >15~30 / >30 对应最低 SaO₂ 85~90 / 80~<85 / <80；报告示例"AHI 25、最低 SaO₂ 88% → 中度 OSA 合并轻度低氧血症"。**教材 L12322-12331 逐字一致**。✅
2. **扁桃体术后继发性出血＝术后 5~6 天（白膜脱落期）**（手册 L1446、L1449"当天看止血、一周看白膜"）。**教材 L11455"继发性出血常发生于术后 5～6 天，此时白[膜开始脱落]"**——一致。✅
3. **鼻咽癌早期颈深上淋巴结转移、易误诊为淋巴结结核/淋巴瘤**（手册 L1566、L1580 约 60% 首发）。**教材 L12021"…复视或颈深上淋巴结肿大"、L12037"鼻咽癌早期可出现颈淋巴结转移，因而常易误诊为淋巴结结核、颈部淋巴瘤"**——方向一致（60% 为通行统计值，教材未给精确百分比，标"待核"但不冲突）。⚠️→✅
4. **咽后脓肿仰卧低头位、禁坐位压舌板、先穿刺再切开**（手册 L1515）——与教材 L11660"将患者转身俯卧…吐出脓液；必要时须行气管切开"一致。✅

### M5 喉
1. **喉返神经走行**（手册 L1886、L2260）：左侧绕主动脉弓、右侧绕锁骨下动脉，左侧行程更长故左侧麻痹更多。**教材 L12556"左侧喉返神经绕主动脉弓，右侧绕锁骨下动脉"、L13498"由于左侧迷走神经与喉返神经行程较长，故左侧发病率[更高]"**——逐字一致。✅
2. **喉癌三型预后**（手册 L2061-2063）：声门约 60%、早期声嘶、淋巴少转移迟、预后最好（5 年 80~85%）；声门上约 30%、淋巴丰富转移早；声门下最少。**教材 L13770"声门上癌约占 30%"、L13800"声门区…淋巴引流不丰富，故声门癌较少出现淋巴转移"**——一致。✅
3. **环甲膜切开插管 ≤48 h、之后改行常规气管切开**（手册 L2161、L2266）——教材 P344 一致（环甲膜紧邻环状软骨，久置致喉狭窄）。✅
4. **气管切开于第 3~4 气管环、勿切第 1 环**（手册 L2133）——教材 P341-344 一致。✅
