## R2选项长度平衡 — 绝后患方案（batch014血泪教训）

### 核心原则
**永远扩充短选项，绝不截断长选项。** 任何 `text[:n]` 暴力截断都会产生语义残片，污染下游。

### 标准修复流程
1. 对每道题计算选项字符长度
2. 若 max/min > 2.0：将最短选项扩充至 ≥ max/2
3. 扩充方式：添加领域限定词（如"铁锈色痰"→"铁锈色痰液"），而非无意义后缀
4. 扩充后重新检查，直到 max/min ≤ 2.0
5. **禁止**对长选项做任何截断操作

### 选项长度平衡的最佳实践
- 出题时预平衡：同一题的5个选项控制在4-12字，比值≤1.5x
- 自然短术语（药名/受体名/疾病名2-7字）豁免，但同一题内其他选项也应保持相似长度
- 如需扩充：加具体特征词（如"胸痛"→"胸部疼痛"），不用"（相关表现）"等无意义后缀
- 数值类选项（如"100ml""200ml"等）保持格式一致，按升序排列

### 已验证的扩充策略
| 原文本(短) | 扩充方式 | 结果 | 原则 |
|-----------|---------|------|------|
| 吸烟(2) | 加"长期" | 长期吸烟(4) | 加时间限定 |
| 胸痛(2) | 拆双字词 | 胸部疼痛(4) | 无需加后缀 |
| 咯血(2) | 拆双字词 | 咯血症状(4) | 症状类 |
| 茶碱(2) | 加"类药物" | 茶碱类药物(5) | 药物类 |

### 禁止做法（已造成实际损害）
- ❌ `text[:target]` → 产生"LVEF大于等于"残片 → R8截断告警
- ❌ 使用"（相关表现）""（相关类型）"等无意义后缀凑长度
- ❌ 在选项末尾加句号"。"强制等长

## 选项长度治理宪法（2026-06-24 · HC-14 结构模板重构）

### 根因命名
**Prompt 阻抗不匹配（Defect B）**：自然语言的字数约束（"8-15字""R2≤1.5"）被 LLM 过度执行或不足执行，导致选项长度在 3.9字 ↔ 18.9字 之间反复振荡（batch007 v1→v2→v3 + batch009→batch010）。

### 治理三原则
1. **长度统一靠结构模板（生成时），不靠字数范围。**
   LLM 理解"所有选项都是 [部位]+[疾病名]"远强于理解"4-10字"。
2. **修复只做语义操作（LLM压缩/扩充），不做字符操作（text[:n]截断）。**
   让 LLM 做它擅长的事（理解→提取→重述），不做它不擅长的事（精确计数+机械截断）。
3. **检测区分真违规（跨类别混用）和假违规（同类别自然变异）。**
   "延髓(2字) vs Wallenberg综合征(7字)"都是解剖实体名 → 结构性豁免。
   "阿司匹林(3字) vs 抑制COX减少TXA2生成(13字)"药物vs机制 → 真违规。

### 设计原则（永不违背）
- ❌ 绝不告诉 LLM "选项 8-15 字" → 它会矫枉过正
- ❌ 绝不对选项做 `text[:n]` 截断 → 必然产生语义残片
- ✅ 告诉 LLM "5个选项共享同一语法结构" → 它能理解并执行
- ✅ 用 LLM 语义压缩替代机械截断 → 信息保留，长度缩短
