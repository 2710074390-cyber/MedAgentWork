# 知识库素材索引规则 v1.0

> 本文档定义 MedAgentWork 工作流中的知识库嵌入、索引与重排序策略。
> 所有 4 个 Agent 共享此规则文件，索引操作由 Agent 1 (MedMaster) 协调。

---

## 一、嵌入配置

| 参数 | 值 | 说明 |
|------|-----|------|
| **嵌入模型** | `BAAI/bge-m3` | 中英双语，1024 维，硅基流动 API |
| **重排序模型** | `BAAI/bge-reranker-v2-m3` | 交叉编码器，硅基流动 API |
| **API 端点** | `https://api.siliconflow.cn/v1/embeddings` | 嵌入 |
| **API 端点** | `https://api.siliconflow.cn/v1/rerank` | 重排序 |
| **API Key** | 环境变量 `SILICONFLOW_API_KEY` | — |
| **嵌入批次大小** | 32 | 每次 API 调用发送的文本数 |
| **最大重试次数** | 3 | 指数退避（1s/2s/4s） |
| **请求间隔** | 200ms | 避免速率限制 |

---

## 二、分块策略

### 医学教材专用配置

| 参数 | 值 | 理由 |
|------|-----|------|
| **chunk_size** | 800 字符 | 中文医学文本密度高，800 字符 ≈ 1200 tokens，粒度适中 |
| **chunk_overlap** | 150 字符 | 约 18% 重叠，防止诊断标准/数值在边界截断 |
| **min_chunk_size** | 100 字符 | 丢弃过短片段（如单独图注） |
| **分隔符优先级** | `\n\n` → `\n` → `。` → `；` → `、` | 优先在段落/句子边界切分 |

### 特殊处理规则

1. **表格区域**：检测到表格标记（`表\d`、`Table`）时，表格内容作为独立 chunk，附加前后各一句话作为上下文
2. **数值密集段落**：含 ≥3 个数值的段落不切分，保持完整性（避免诊断标准/药物剂量被打散）
3. **章节标题**：检测 `第[XX]章`、`第[X]节` 模式，标记为章节边界

## 三、元数据规范

每个 chunk 必须携带以下元数据：

```json
{
  "chunk_id": "internal-med_ch03_s3.5_p223_c0001",
  "subject": "内科学",
  "subject_code": "internal-med",
  "chapter": "第三章 心律失常",
  "chapter_num": 3,
  "section": "第六节 心脏传导阻滞",
  "page_number": 223,
  "has_table": false,
  "has_numeric_data": true,
  "textbook": "内科学（第10版）",
  "indexed_at": "2026-06-16T12:00:00+08:00"
}
```

### chunk_id 格式
`{subject_code}_ch{chapter_num}_s{section_id}_p{page}_c{chunk_index:04d}`

## 四、检索配置

| 参数 | 值 | 说明 |
|------|-----|------|
| **初始检索 top_k** | 20 | 从向量库召回 |
| **重排序后 top_n** | 5 | 最终返回给 Agent |
| **最小得分阈值** | ≥ 0.80 | 直接采用 |
| **复核区间** | 0.70 - 0.80 | 需人工/Agent 复核 |
| **拒绝阈值** | < 0.70 | 需重构查询词 |

### 查询增强规则

- 医学术语标准化：查询前将口语化术语映射到 MeSH/ICD-10 标准术语
- 同义词扩展：每个查询自动追加 1-2 个同义表述（如"房颤" → "心房颤动"）
- 章节锚定：如已知目标章节，在查询中添加章节号作为过滤条件

## 五、索引优先级矩阵

| 优先级 | 触发条件 | 科目 |
|:----:|------|------|
| **P0** | 当前批次正在使用的科目 | 由 workflow_state.json 决定 |
| **P1** | 下一候选批次科目 | 外科学、神经病学 |
| **P2** | 用户明确要求 | — |
| **P3** | 其余未索引科目 | 精神病学、皮肤性病学、中医学、医患沟通 |

## 六、索引刷新策略

### 自动触发

| 触发条件 | 操作 |
|------|------|
| 新 PDF 放入 `知识库素材/` | 自动检测并加入索引队列（P2 优先级） |
| 用户启动新批次（科目未索引） | 提升该科目至 P0，立即索引 |
| 教材版本更新 | 旧版索引标记为 `deprecated`，重新索引新版 |

### 质量触发

| 触发条件 | 操作 |
|------|------|
| 单次检索 ≥30% 结果得分 < 0.70 | 对该科目重新索引（调整分块参数） |
| 连续 5 次查询均无 ≥0.80 结果 | 告警用户，检查嵌入模型/API 状态 |

### 定期维护

- **每 30 天**：扫描 `知识库素材/` 目录变化，更新索引清单
- **每 90 天**：检查嵌入模型版本，如有新版本评估迁移

## 八、与工作流对接

### Agent 1 (MedMaster) 职责
- 新批次启动时检查目标科目是否已索引
- 如未索引，触发索引流程后再生成 Agent 2 调用指令
- 在 Agent 2 调用指令中附带检索到的教材原文

### Agent 2 (出题) 职责
- 接收教材原文 + 检索增强片段
- 以检索片段为事实依据，不凭空编造数值

### Agent 3 (质检) 职责
- 对检索增强产生的题目，验证数值与检索片段的原文一致（D15 维度）

### 检索日志格式
每次检索须记录：查询时间、查询词、召回数、重排序后得分、最终采用片段数。
