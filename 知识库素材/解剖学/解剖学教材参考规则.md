## 四、生图硬规则（解剖学相关）

### 规则1：教材查阅强制流程
生成任何解剖结构类图片前，**必须**执行：
1. 根据主题在上方速查表中定位教材页码
2. 用 Python 3.12 + PyMuPDF 读取对应页面文本（`fitz.open()` → `doc[页码-1].get_text()`）
3. 提取关键结构清单（名称/数量/位置/连接关系/层次）
4. 将结构清单写入生图 prompt 的主体描述部分
5. 生成后对照教材逐项核验结构关系

### 规则2：通道选择优先级（解剖学专用）
```
解剖结构类图片 → 优先查《人体解剖学彩色图谱》images/
  ├─ 图谱有覆盖且画面核验通过 → 通道①图谱复用（最准确）
  ├─ 图谱有覆盖但需多视图拼接/叠加 → compose_atlas.py
  └─ 图谱无覆盖 → 通道①扁平卡通示意（图注必须带「（示意）」）
       └─ 生图前必须查阅系统/局部解剖学对应章节
```

### 规则3：结构准确性核验清单（每张解剖图必查）
- [ ] **数量正确**：如颈椎7块/胸椎12块/腰椎5块，听小骨3块，腕骨8块，跗骨7块
- [ ] **左右对称**：成对结构左右数量一致（如肺：左2叶右3叶是例外，需特别注意）
- [ ] **连接关系正确**：如胆总管+胰管→肝胰壶腹→十二指肠大乳头
- [ ] **层次顺序正确**：如头皮5层（皮肤→浅筋膜→帽状腱膜→腱膜下疏松结缔组织→颅骨外膜）
- [ ] **毗邻关系正确**：如肾蒂排列（前→后V-A-肾盂，上→下A-V-肾盂）
- [ ] **神经支配正确**：如面肌→面神经，咀嚼肌→三叉神经，膈肌→膈神经（C3-C5）
- [ ] **血供来源正确**：如胃的5条动脉来源，阑尾动脉→回结肠动脉
- [ ] **特殊结构无遗漏**：如颈动脉窦/颈动脉小球，黄斑/视神经盘，齿状线

### 规则4：常见易错结构特别提示
| 易错点 | 正确内容 | 常见错误 |
|---|---|---|
| 肺叶数 | 左肺2叶（上/下），右肺3叶（上/中/下） | 画成左右都是3叶 |
| 主支气管 | 左细长水平，右粗短陡直（异物易入右） | 左右画成一样 |
| 心传导系 | 窦房结→房室结→房室束→左右束支→Purkinje纤维 | 顺序颠倒或遗漏 |
| 内囊 | 前肢/膝/后肢，膝部有皮质核束，后肢有皮质脊髓束 | 分不清楚或结构错位 |
| 腕骨排列 | 近侧列（桡→尺）：手舟骨/月骨/三角骨/豌豆骨；远侧列：大多角骨/小多角骨/头状骨/钩骨 | 顺序混乱 |
| 跗骨排列 | 距骨/跟骨/足舟骨/内侧楔骨/中间楔骨/外侧楔骨/骰骨（7块） | 数量或名称错 |
| 脑神经连脑 | III/IV中脑，V-VIII脑桥，IX-XII延髓 | 连脑部位错 |
| 交感vs副交感 | 交感T1-L3，副交感脑干+S2-S4 | 中枢部位混淆 |
| 肝蒂排列 | 前→后：胆总管/肝固有动脉/肝门静脉；右前/左前/后 | 排列顺序错 |
| 子宫位置 | 前倾前屈位（前倾：子宫长轴与阴道长轴间向前开放角；前屈：子宫体与颈间向前开放角） | 画成后倾或直位 |
| 输尿管狭窄 | 3处：肾盂输尿管移行处/跨髂血管处/穿膀胱壁处 | 数量或位置错 |
| 食管狭窄 | 3处：起始处/左主支气管交叉处/穿膈处 | 与输尿管混淆 |
| 男性尿道 | 3部（前列腺/膜/海绵体），3狭窄，3膨大，2弯曲 | 遗漏弯曲或膨大 |
| 腹膜陷凹 | 男性：直肠膀胱陷凹；女性：膀胱子宫陷凹+直肠子宫陷凹（最低） | 男女混淆 |
| 膈裂孔 | T12主动脉（+胸导管）/T10食管（+迷走神经）/T8腔静脉 | 椎体水平或内容错 |
| 房水循环 | 睫状突→后房→瞳孔→前房→虹膜角膜角→巩膜静脉窦 | 路径或方向错 |
| 脑脊液循环 | 侧脑室→室间孔→第三脑室→中脑水管→第四脑室→正中孔+外侧孔→蛛网膜下隙→蛛网膜粒→上矢状窦 | 路径遗漏或方向错 |
| 三叉神经分支 | V1眼神经（眶上裂）/V2上颌神经（圆孔）/V3下颌神经（卵圆孔） | 出颅部位混淆 |
| 臂丛束与分支 | 外侧束→肌皮神经+正中神经外侧根；内侧束→尺神经+正中神经内侧根；后束→桡神经+腋神经 | 束与分支对应错 |
