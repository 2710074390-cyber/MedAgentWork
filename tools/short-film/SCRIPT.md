# 三支科普短片 · 文案与分镜（2026-10-19）

统一规格：深蓝深海画布、等宽小标签、发丝分割线、无 emoji；暖色（`--warn`）**只用于「避坑 / 撤回」这类警示**。
每片四幕：钩子（一个具体场景）→ 事实（逐条入场）→ 卡点（做了什么、以前踩过什么）→ 收束（一句结论 + 数字）。

**文案原则（第二版，去 AI 味）**
- 不写反问句式（「靠谱吗？」），改写成陈述一个具体现象
- 不用「DECISION 01」「避坑」这类模板标签，标签就用事实词（契约 / 状态 / 回退 / 反查 / 真题 / 放行 / 缓存 / 降级 / 红线）
- 警示行不用「避坑」，用「以前」「那次」「取舍」「红线」
- 句子短、少形容词、不排比、不喊口号；数字和名词直接摆出来
- 事实全部来自项目真实记录，不编造：`操作流程.txt`、`docs/TODO.md`、`docs/交接文档_新Agent接手_v1.0.md`、`docs/产物格式规范.md`、`scripts/validate/rules_*.py`、`scripts/fact_check.py`

## 片一 · 五阶段管线（40s，键 `pipeline`）

**幕一 · 钩子（0–7s）**
- eyebrow：幕后管线
- 主标：一批题，五个角色 / 各写一段。
- 副标：出题只管出题，质检只管质检。中间不留一句「你看着办」。

**幕二 · 谁做什么（7–17s）** — 五行逐条入场
| 角色 | 做什么 |
|---|---|
| 编排 MedMaster | 先把科目、题数、模块说清楚，你点头才开跑 |
| MedGen 出题 | 写完落盘到 `中间产物/{批次}/`，文件名带批次号 |
| MedQC 质检 | 出报告：哪一条规则没过，写清楚 |
| MedFix 修复 | 只改报告里点名的题，不顺手改别的 |
| MedReview 成册 | 排版、插图、章节结构，最后才出复习资料 |

脚注：每一步都能单独重跑，不用整批重来。

**幕三 · 卡住的时候怎么办（17–29s）** — 三张卡
| 标签 | 做法 | 以前 |
|---|---|---|
| 契约 | 输入输出写死成 schema，产物摄入即用 jsonschema 校验 | 字段对不上，只能整批返工 |
| 状态 | 状态存一个文件、原子写，连着血缘；门禁不过就 HALT | 并发写互相覆盖，出过丢更新 |
| 回退 | BLOCKED 就地退回那个角色，修完重跑门禁 | 手工往下推，就是半成品上线 |

**幕四 · 收束（29–40s）**
- 数字：`5 角色` `4 门禁` `1 状态机` `40 秒`
- 结句：慢，但每一步都算数。

## 片二 · 质量门禁（42s，键 `gate`）

**幕一 · 钩子（0–7s）**
- eyebrow：质量门禁
- 主标：「看起来没问题」/ 不算通过。
- 副标：选题库里最危险的就是这句：讲得顺，答案错。判定得写死在代码里。

**幕二 · 先写死的规则（7–20s）**
| 规则 | 说明 |
|---|---|
| R9 数值缺单位 | 0.5 还是 0.5 mg，只能有一个对；缺单位直接判 FAIL |
| R2 正确选项最长 | 正确项总是最长的，这是选择题里最常见的破绽 |
| R6 数值太挨 | 四个选项数值接近，区分度就没了 |
| R10 / R11 线索 | 按 NBME 的出题习惯，反着排除 |

脚注：这类规则不需要模型参与，跑一遍就有结果。

**幕三 · 事实也要核（20–33s）**
| 标签 | 做法 | 以前 |
|---|---|---|

## 片三 · 个性化学科 RAG（38s，键 `rag`）

**幕一 · 钩子（0–7s）**
- eyebrow：个性化学科 RAG
- 主标：23 个学科，/ 一套配置不管用。
- 副标：方剂组成、影像分期、参考值区间，切法和检索词都不一样。

**幕二 · 分块跟着学科走（7–20s）**
| 做法 | 说明 |
|---|---|
| 方剂组成不切碎 | 一味药一段，别和功效混在一起 |
| 向量 + 关键词 | 向量找意思，关键词找药名和数值 |
| rerank 再收一次 | 两路召回合并之后重排 |
| 23 科各自调 | 分块大小、召回条数、阈值都不同 |

脚注：统一配置省事，但会把某个学科的信息切坏。

**幕三 · 别让检索拖死管线（20–30s）**
| 标签 | 做法 | 备注 |
|---|---|---|
| 缓存 | 查询和向量都落盘，同一条查询第二次不花钱 | 那次 batch027 余额见底，整条管线停过 |
| 降级 | 余额不够就跳付费 rerank，成本约减半 | 取舍：检索质量可以降，批次不能停 |
| 红线 | calibrated_p 只用于组卷配平 | 先验不是实测，标成实测等于骗自己 |

**幕四 · 收束（30–38s）**
- 数字：`23 学科` `26 索引` `双路检索` `命中缓存 0 调用`
- 结句：检索先对，后面才对。

## 音轨（第二版）

- **每幕换调、换织体**，不做一条弦乐铺到底：
  幕一干净低频 → 幕二加中音（低通开到 760Hz）→ 幕三压低收窄（500Hz）→ 幕四回主音（700Hz）
- **去掉锯齿波**，只用正弦 + 极轻八度泛音；**去掉噪声 riser**，幕切换只给一记轻铃
- 第二幕随五条列表逐条入场给五记轻点（440 / 523 / 587 / 659 / 784 Hz）
- 低音加 2.2–3.1Hz 的极慢起伏，避免一条死线；实测四段 RMS 0.037 → 0.045 → 0.063 → 0.044

## 与主介绍片的关系

- 主片回答「这是什么、为什么可信」；三支短片回答「具体怎么做的、踩过什么坑」。
