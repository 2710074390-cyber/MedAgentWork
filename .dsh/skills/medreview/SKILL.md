# MedReview（主复习资料生成器）

## 必读文件

1. `CONTEXT.md` / `SOUL.md` / `USER.md` — 共享规则。
2. `Prompt版本/Agent5_MedReview_Prompt.md` — 完整生成提示词。
3. `docs/复习资料详细度标准.md` — 自适应详细度、来源、安全及过渡标准。
4. 有教师重点时读取 `docs/教师重点蓝图版_生成规则_v1.0.md`。**配图相关规则（`复习资料/_配图需求/`、`medillustration`）随 HC-19 于 2026-11-02 下线，不再读取、不再产出配图与清单。**

## 执行规则

- 读取实际输入；课程安排按周/讲组织。教师重点是范围契约，逐条建覆盖矩阵，按输入锚定清单编号设置 `📌 重点原文（第X条）：` 独立落点，逐字保留关键句及全部数值、时间窗、界值、并列和禁止结构。无教师重点标记覆盖检查 SKIPPED。
- 教师仅提供主题时原样照录，另设「教材补写」或「其他来源补充」，标注可核实来源和真实页码；不将补写并入教师原文。来源不明或冲突时标明待核实和不同口径，不虚构医学事实或页码，考试口径不覆盖医学安全。
- 按输入、掌握层级和知识类型选择详细度。疾病按适用性解释识别、检查、鉴别、处置和安全边界；机制解释因果；解剖操作解释结构、步骤与风险；分类标准解释依据、界值及适用条件。案例、表格、机制链、回忆题等按需要选用，不强制固定槽位、字数或区块数量。
- 每个知识点确定一处主讲位置并讲透，其他位置仅必要提示并引用可定位的主讲位置；逐条原文锚点及必要安全提示可保留，不得重复堆字。自测答案可检索。
- 主资料可分片生成但须合并为单一 MD，附录一至五随文保留，覆盖矩阵和其他过程产物不写入正文。主文件位置按 `Prompt版本/Agent5_MedReview_Prompt.md` 执行。
- 保持导出兼容：强调用配对 `<b>`/`<i>`，禁用 `**`/`*` 强调及 `<details>`/`<summary>`；需展开时使用 `#### 🔬 展开：…`。**不写插图占位符、不出配图清单**（HC-19 已下线，主资料为纯文本）。

- 教材检索入口为 `知识库素材/search_kb.py --subject {code} --hybrid`，先查 `知识库素材/学科个性化RAG方案.md`；附录保留真实页码索引与术语同义异名，PG-11 页码要求无法满足时如实报告而非虚构。
- 教师重点版分片合并命令：`python scripts/merge_review_shards.py --shards 中间产物/{batchID}/bpa_v6 --appendix 中间产物/{batchID}/bpa/appendix.md --out "复习资料/{科目}教师重点版/{科目}教师重点版_主复习资料.md"`；合并失败真实记录，附录一至五不得遗漏。
- V14 检查加粗标签配对及禁用语法；V16 人工 PDF 导出后抽检真粗体及彩色标识，打印 CSS 参考 `scripts/obsidian-snippets/medagentwork-print.css`。

## 检查及过渡

对合并文件运行 `python scripts/check_keypoint_coverage.py --keypoints <清单> --md <主资料>`（有教师重点时）和 `python scripts/check_review_detail.py --md <主资料> --mode auto --profile <release_teacher_keypoint或release_teaching_plan>`（课程安排版使用 `--mode course_schedule`），并检查来源、安全、答案、引用及导出兼容。覆盖缺失须修复；真实报告、profile 和 PASS/FAIL 均须保留。

详细度门禁默认仍要求固定槽位、字数和区块，可能误报自适应内容；`--detail-standard adaptive` 仅供人工审核预检，不替代正式发布门禁。人工区分实质缺漏与旧规则误报，不为凑格式增加无关内容，不将 FAIL 或 advisory 当 PASS；现行发布流程仍 enforce 时 FAIL 仍阻断，等待同步或由有权负责人按现行流程处理，不自行绕过。覆盖与导出门禁不放宽。子模块 `medagentwork-skill` 的分发规则尚未同步，使用时须注意冲突。

完成后报告文件路径、覆盖检查、来源和待核实项、导出检查、详细度门禁真实结果与人工复核。旧产物不回改。
