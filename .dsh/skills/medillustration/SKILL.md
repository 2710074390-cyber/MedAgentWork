# MedIllustration — 医学插图工作流（卡通 + 图谱双形态）

## 分工契约（硬约束）

- **文字内容**（复习资料 MD、题库、解析）由 DSH / Trae Work / 其他内容 Agent 生成，本 skill 不负责。
- **图片内容**（卡通底图、确定性图谱、标注、压缩、嵌入）由 Doubao（图片 Agent）负责，调用本 skill；DSH 不调用 image_gen。
- 两者通过文件系统交接：内容 Agent 在 MD 中写 `![图注](images_webp/xxx.webp)` 占位，图片 Agent 按占位生成对应文件。

## 输入输出契约（与 MedReview v5.3 / MedMaster 衔接）

- **输入**：MedMaster 打包给豆包的交接任务包 = ①`{科目}_配图清单.md`（每条含 **通道：①复用 / ①教材 / ①示意 / ②卡通 / ③flow·compare·grid / 跨科复用** + AI Prompt 四要素或图谱 YAML 要点）②本 skill 全文 ③图谱索引（`知识库素材/图谱图片索引/image_index.md`）④可复用图路径 ⑤科目目录规范。
- **执行者**：豆包（Doubao 图片 Agent）。DSH 侧只做 GATE-A6 机械校验（`scripts/check_inline_images.py`）与人工质检复核。
- **输出**：回传 `复习资料/{科目}教学计划版/images_webp/*.webp`（1600px、q=82）供 MD 渲染；raw/、diagram_configs/、annotate_configs/、annotated/ 同目录保留中间产物。
- **验收**：MD 中每个 `![图N：…](images_webp/…)` 占位符必须有对应文件；三种通道来源可溯源到清单行。
- **基线**：大四上 5 科配图需求见 `复习资料/_配图需求/大四上复习资料_配图需求清单.md`（59 张建议；内科学 22 图试点已完成；卡通+图谱改造试点见 `复习资料/_试点插图/`）。

## 形态总原则：三通道路由（决策树）

> 废弃「教材写实」路线（实证：AI 写实解剖 >99% 含虚构结构）。改为 AI 擅长的两种形态：**扁平卡通示意** + **确定性图谱**。

```
知识点需要插图？
├─ ① 解剖结构类（骨骼/肌肉/器官/神经/眼球等）
│   ├─ ①a 图谱有覆盖 → 《人体解剖学彩色图谱》复用 + 程序标注（准确第一，首选）
│   │   路径：知识库素材/《人体解剖学》彩色图谱（第2版）(1).pdf-*/images/（148 张）
│   │   索引：知识库素材/图谱图片索引/image_index.json + image_index.md
│   ├─ ①b 图谱无覆盖、教材有覆盖 → 教材出版级插图提取（`①教材`，2026-09-11 新增，次选）
│   │   来源：知识库素材/解剖学/系统解剖学（第10版）·局部解剖学（第10版）→ MinerU 解析产物
│   │   ★ 图注**不加**「（示意）」——出版级来源，承担精确解剖表达
│   └─ ①c 图谱与教材均无覆盖 → AI 扁平卡通「示意」无字底图 + 程序标注
│                   ★ 图注必须带「（示意）」，不承担精确解剖定位
├─ ② 机制/病理/进展/形态类（如门脉侧支循环、ARDS、胎儿循环、突触机制）
│   └─ AI 扁平卡通无字底图（风格锁定）+ 程序标注
└─ ③ 流程/决策/对比/时序/分型类（步骤、鉴别、分期、分类）
    └─ 确定性图谱：内容 YAML → scripts/render_diagram.py → PNG/WebP
        ★ 不调用文生图；文字与结构 100% 来自教材，零幻觉、零乱码
```

**判定口诀：「长什么样」走卡通（①缺口/②），「什么关系、什么顺序」走图谱（③）。** 拿不准时优先③（确定性渲染不会出错），其次②。

**专业形态序列强制归③（2026-09-30 教训）**：一幅图需同时表现 ≥5 个「形态各异专业对象 + 固定顺序」时（实证：嵌体/贴面/全冠/桩核冠/固定桥/可摘局部义齿/全口义齿，AI 连续两版把桩核冠画成种植体、顺序混乱）→ **不调文生图，直接 grid/compare 确定性渲染**；「长什么样」仅适用于单结构/单对比形态。

## 通道①②：AI 扁平卡通无字底图

### 模型（硬约束）

- 统一使用 **seedream_5.0_pro**：`image_gen` / `image_edit` 的 `model_version="seedream_5.0_pro"`，不用默认 4.5。

### 固定风格前缀 STYLE_PROMPT（每张必带，只替换主体部分）

> 扁平矢量风格医学科普卡通插画（flat vector medical illustration），柔和平涂色块，统一粗细的深色描边，造型极简概括，纯白色背景，居中单一主视图，构图简洁、四周留白充足；无渐变、无阴影、无照片质感、无纹理；画面中不出现任何文字、字母、数字、箭头、指示线、编号、图例、局部放大图或辅助小图。主体：{主体/视角/结构清单/状态配色}。

负面约束：写实、照片、3D 渲染、复杂纹理、光影质感、文字乱码、水印、多余结构、解剖变形。

### 风格锁定（系列一致性，必做）

1. 每个大类先出 **1 张金样**，人工确认风格后作为全系列参考；试点金样：
   - 解剖示意：`复习资料/_试点插图/raw/金样_眼球结构_扁平卡通_raw.png`
   - 机制示意：`复习资料/_试点插图/raw/金样_突触机制_扁平卡通_raw.png`
2. 同科/同批后续底图用 **image_edit 以金样为参考图**生成（`image_reference_url_list` 传金样），prompt 只写主体差异，保证全系列风格统一。
3. 分辨率 ≥2048px（1:1 或 4:3）；仍然是**无字底图**，中文一律程序标注。

### 扁平色板（AI prompt 与 render_diagram.py 共用同一语义）

动脉/异常用柔和红、静脉/通路用蓝、神经用黄、正常/代偿用绿、病变/进展用橙、缺血/特殊用紫、中性结构用灰；**一图主色不超过 4 种**。渲染器色板键：blue / teal / green / orange / yellow / red / purple / gray。

## 通道③：确定性图谱渲染 scripts/render_diagram.py

- **适用**：流程/时序（`flow`）、对比鉴别（`compare`）、分型网格（`grid`）。
- **做法**：内容取自教材写成 YAML（`title/subtitle/note` + `steps` 或 `items`，每项 `title/color/lines`）；渲染器负责版式、自动折行、箭头、配色，输出 2048px PNG，并可用 `webp:` 字段同时产出 1600px q82 部署版。
- 配置放 `diagram_configs/`，路径解析与 annotate_image.py 一致（配置位于子目录时相对科目目录）。
- 用法：`python scripts/render_diagram.py diagram_configs/xxx.yaml`（支持多文件）。
- 试点样例：`复习资料/_试点插图/diagram_configs/`（示例1 休克微循环三期 flow、示例2 前置胎盘vs胎盘早剥 compare、示例3 骨折分型 grid）。
- **不需要底图、不需要再标注**（文字已在图内且 100% 正确）；质检只需核对 YAML 内容与教材一致。

## 通道①图谱复用：多面板拼接 scripts/compose_atlas.py

- **适用**：一张复习图需要图谱中 2-3 个相邻视图拼合（如「鼓室外侧壁+内侧壁+听小骨」），或要在出版图上程序叠加虚线轮廓/中文图例（如梅尼埃病内淋巴积水扩张边界）。单张图谱直接复用、无需拼接时不走本脚本。
- **做法**：YAML 定义 `rows → panels`（`image/caption/marks`），自动裁白边、等比排版、中文小标题带（窄栏字号自适应保单行）；`marks` 支持千分比虚线 `ellipse/rect` 与白底 `note` 图例框；输出 2048 PNG，`webp:` 字段同时出 1600 q82 部署版。
- 配置放 `compose_configs/`，路径相对科目目录；用法：`python scripts/compose_atlas.py compose_configs/xxx.yaml`（支持多文件）。
- 源图按**画面真实内容**命名复制到 `raw/`（不沿用可能错位的索引图号）；渲染后必须 Read 回读，逐面板核对内容、图注与虚线位置。

## 通道①教材：教材出版级插图提取（2026-09-11 新增）

- **适用**：解剖形态类，且《人体解剖学彩色图谱》无覆盖、但《系统解剖学（第10版）》或《局部解剖学（第10版）》有对应插图者。**优先于 AI 卡通**（形态准确性证据：高真实度 d=0.76）。
- **前置**：两本教材先经 MinerU 解析入知识库，产出 `知识库素材/解剖学/{书名}_mineru/`（排版 Markdown + 插图 + 版面框 + 图注）。
- **取图纪律**：按「**页号 + 图注**」定位，**逐张目视核验**（与图谱复用同理——严禁只按索引/文件名取图）；优先取**彩色图**（局部解剖学约 68% 为彩色），黑白线条图仅在无彩色版本时使用。
- **生产流程**：① 在 MinerU 产物中定位目标图 → ② 页面渲染 200–300 DPI + 版面框裁切至单图边界 → ③ 分辨率不足时**按原分辨率交付、不做放大插值**（教材内嵌图常见 600–1100px 宽）；关键结构过小则改「整图 + 局部放大插图」两段式 → ④ 教材原图自带中文者**原则上沿用原标注**（权威名词，不再叠加），需补充/遮盖时用 `annotate_image.py`（`label` 模式）→ ⑤ 命名 `{两位序号}_{知识点简称}.png`，导出 1600px q82 `.webp` 入 `images_webp/`。
- **图注**：**不加**「（示意）」；图注须与教材原图注一致，术语遵循《人体解剖学名词》（第2版）。
- **回退**：教材无对应插图、或裁切质量不达标（模糊/缺边/标注被裁）→ 该图回落 `①示意`（AI 卡通 + 「（示意）」），并在配图清单与科目明细中更新通道。
- **版权**：仅用于个人复习资料，不外发、不商用；交付物注明来源教材与版次。

## 质检（硬需求，不可跳过）

- **通道①教材**：教材版本与图号来源可溯源；裁切完整、无邻图残边；图注与教材原图注一致；**图注不得含「（示意）」**。
- **通道①a 图谱复用**：图号对应正确知识点、标注术语与教材一致（解剖准确性出版级保证）。**⚠ 图谱索引 `image_index.json` 的 fig_num 与实际画面存在系统性错位（实证：meta220 实为横切面、meta333 实为膜迷路、运动系统 6 张全部错位为脑血管影像），必须逐张 Read 目视核验画面（画面内印有真实图号），严禁只按索引 fig_num 提图；确认图谱无覆盖时改判①示意并在清单登记。**
- **通道①②AI 卡通**：标准从「照片级解剖精确」调整为——
  1. **结构关系无原则错误**：结构数量、左右、连接、层次正确（卡通允许形态简化）；错误→重生成（在主体描述里强化结构清单与相对位置）。
  2. **风格达标**：扁平色块、白底、无渐变/阴影/照片质感；不达标→以金样为参考重做。
  3. **无杂项**：无文字乱码、无辅助小图、无指示线、无多余结构。
  4. **标注后无重叠遮挡**。
  5. **标注成品逐张 Read 核验（2026-09-30 强制）**：每张 AI 卡通标注后必须 `Read` 成品，核对文字框 OCR 位置与每条引线端点确实落在对应结构上（引线末端不得指向无关结构，如侧脸图腮腺不得指向鼻）；多模态描述 + OCR 交叉确认；不达标即修正 YAML 坐标重标、重导出、重渲染。
- **通道③确定性图谱**：只核对 YAML 内容与教材一致、无错别字；版式由脚本保证。

## 标注工具：scripts/annotate_image.py（仅通道①②需要）

YAML 驱动，box 用千分比相对坐标（0-1000，左上原点），与分辨率无关。

| 模式 | 适用场景 | 效果 |
|------|---------|------|
| `label`（**默认推荐**） | 干净卡通底图、图谱图 | 无背景块，深色文字 + 白色描边直接写在图上，不遮挡图片 |
| `overlay` | 仅用于盖住 AI 图内偶发乱码后重写中文 | 白底圆角覆盖块 + 文字 |

```bash
python scripts/annotate_image.py annotate_configs/xxx.yaml
```
YAML 字段与 label 额外参数（stroke_width / stroke_fill / anchor 引导线）见脚本 docstring。

**标注纪律（2026-09-30 教训，不可回退）：**
1. **禁止目测估算坐标**：写 YAML 前先用脚本量化结构坐标（`scripts/_analyze_annot_pos.py`：按语义颜色掩膜做网格热区/角度端点/xband 质心），把实测坐标写入 box/anchor；估算坐标必然错位（实证：面神经五支、腮腺、溃疡、修复体全部偏）。
2. **`anchor` 引线强制**：label 文字一律带 `anchor:[x,y]`，从文字框边缘画线+圆点精确指向结构；文字框放空白区（图缘/顶部），不压结构。
3. **`output` 字段必填且写正确名**：成品名 = YAML 的 `output` 字段（非配置文件名）；须写 `annotated/xxx.png` 与 MD 占位名一致，禁止出现 `xxx.yaml.png`。
4. **侧脸/朝向先判器官相对位**：标注前先确认画面朝向（鼻/耳/腮腺/眼相对位置），神经主干根部=腮腺前缘（耳前），神经扇形最远端≠腮腺（实证：图2 曾把鼻当腮腺）；无法判定先 Read 底图看清五官再落坐标。
5. **标注目标随底图内容走**：底图缺考点结构（如白斑图无白斑）先重生成底图再标注，不得硬标不存在的结构。

## 压缩与嵌入

1. **压缩**：PNG → WebP，1600px 宽，quality=82，method=6（通道③可由 `webp:` 字段直接产出，免二次压缩）。
2. **嵌入**：MD 中用 `![图N：图注](images_webp/xxx.webp)`；`知识库素材/render_review.py` 已支持 `![]()` 图片语法（含 `--embed-images` base64 自包含模式）。
3. **嵌入 MD 不破坏格式（硬规则）**：
   - 图片语法独占一行，路径用正斜杠相对路径 `images_webp/xxx.webp`，不用绝对路径或反斜杠。
   - **优先同名替换**：新图文件名与 MD 既有引用完全一致时只换文件、零改动 MD；确需新增图片行时，插在对应考点段落之后，图片行前后各留一个空行（保证 CommonMark 块级渲染，不与上下文字段粘连）。
   - 图号 `图N` 与图注沿用 MD 既有编号与措辞，不新增、不重排、不改写其他任何行；一次嵌入只动图片相关行。
   - 嵌入后必须做引用解析校验：MD 中每个 `![]()` 引用都能在该科目 `images_webp/` 找到同名文件；缺文件视为未完成（可保留占位但需在交接说明列出待回填清单）。
   - 旧产物清理：废弃图片移入归档目录而非直接删除；`raw/`、`annotate_configs/` 为中间产物，清理不影响 MD；`images_webp/` 删除前必须确认 MD 引用已有同名新图或已登记待回填。

## 图注规范

- 通道①c「图谱与教材均无覆盖的 AI 卡通解剖示意」**图注必须含「（示意）」**，如 `图3：女性盆腔矢状结构（示意）`。
- **通道①教材（教材出版级插图）与通道①a（图谱复用）图注不加「（示意）」**——二者承担精确解剖表达。
- 通道②机制卡通建议加「（示意）」；通道③确定性图谱不加。

## 已知硬伤与规避

- **AI 写实解剖不可靠**（>99% 同行评审图含虚构结构）→ 已废弃写实路线：解剖优先图谱复用，缺口用扁平卡通示意并在图注标注「（示意）」；流程/对比/时序类不再让 AI 画，走 render_diagram.py 确定性渲染。
- **AI 中文标注乱码** → AI 只出无字底图，中文一律 annotate_image.py 程序叠加；通道③文字由渲染器输出，零乱码。
- **系列风格不统一** → 固定 STYLE_PROMPT 前缀 + seedream_5.0_pro + 金样参考图（image_edit）锁定。
- **overlay 白底块遮挡** → 默认 label 模式，overlay 仅用于修复偶发乱码。
- **标注坐标错位（2026-09-30 实证）** → 估算坐标必错位（面神经/腮腺/溃疡/修复体全偏）：写 YAML 前先跑 `scripts/_analyze_annot_pos.py` 量化坐标，label 一律 anchor 引线，标后逐张 Read 成品核验；修复体种类谱等专业形态序列 AI 两版失败 → 改判通道③ grid 确定性渲染。
- **AI 侧脸朝向混淆（2026-09-30 实证）** → 侧脸图神经最远端≠腮腺（曾把鼻当腮腺）：先 Read 底图确认五官朝向，腮腺=耳前神经主干根部。
