# Layer 2 — 临床推理层

## 目标
50道临床案例深度推理题，测试AI是否具备「专家级」出题能力。

## 数据来源

### CMB-Clin
- 来源：FreedomIntelligence/CMB (Apache-2.0)
- 规模：74例复杂临床推理病例
- 格式：现病史 + 体格检查 + 辅助检查 + 多轮问答
- 用途：检验AI出题的临床路径推理能力

### 自定义病例（可选）
- 从实习病历简化的短病例 Q&A
- 要求：含鉴别诊断链、辅助检查判读、治疗方案选择

## 评估维度
1. 答案一致性：AI给的答案是否与golden answer匹配
2. 干扰项质量：错误选项是否基于真实临床混淆点
3. 解析可追溯性：explanation是否落到教材页码/指南条文
