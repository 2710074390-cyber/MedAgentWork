## 附录三：必背记忆口诀汇总

> [!TIP] 全科口诀速查（v5.1 增强版，23条口诀）

### 概念辨析
- **「精神是学科，卫生是保健，医学是广义」** → 精神病学/精神卫生/精神医学
- **「幻无错有」** → 幻觉无客观刺激物，错觉有客观刺激但歪曲
- **「真外假内」** → 真性幻觉在客观空间，假性在主观空间

### 症状学（M2）
- **「奔躁迟抑贫阴性，散裂分裂不连谵」** → 思维形式障碍与疾病对应
- **「定时地人」** → 定向力丧失顺序：时间→地点→人物
- **「原发突来不可解，继发有因可溯源」** → 原发vs继发妄想
- **「被害关系最常见，夸大躁狂罪恶郁，钟情嫉妒物理控，洞悉原发分裂症」** → 妄想9类速记

### 精神分裂症（M5）
- **「中脑边缘多阳性，前额低下阴性来；一代直断D2关，二代双向开5-HT」** → DA假说+药物机制
- **「偏妄青破紧交替，单纯阴性预最差」** → 四亚型核心特征+预后
- **「首发1-2年，复发5到终身」** → 维持治疗时长

### 抑郁障碍（M6）
- **「三低三自晨重暮轻，核心二附加二周定」** → 诊断公式
- **「急性8-12，巩固4-9月，维持半年起」** → 三阶段治疗
- **「五朵金花加一兰，双通道看文度」** → SSRI+SNRI药物速记

### 双相障碍（M7）
- **「三高一夸大，睡眠减需随境转」** → 躁狂核心+伴随症状
- **「I型躁狂定，II型轻躁加抑郁」** → 分型关键
- **「锂0.6到1.2，中毒超过1.4」** → 锂盐治疗窗
- **「抑郁相禁单用，稳定剂上再抗郁」** → 用药禁忌

### 物质依赖（M4）
- **「酒戒6-12-24-48，震颤谵妄2-3天达」** → 戒断时间窗
- **「眼共意」** → Wernicke三联征：眼肌麻痹+共济失调+意识障碍

### 神经认知障碍（M3）
- **「AD隐袭无局灶、海马萎缩评分低；VD阶梯有局灶、梗死灶多评分高」**
- **「谵妄急波注，痴呆慢持智」** → 谵妄vs痴呆核心区别

### 躯体治疗（M12）
- **「D2→EPS+泌乳，M1→口干便秘记忆差，α1→低血压，H1→镇静发胖」**
- **「NMS高热肌强CPK高，5-HT意识不稳神肌乱」**
