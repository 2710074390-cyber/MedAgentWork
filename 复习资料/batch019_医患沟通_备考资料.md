## 二、结构化知识笔记

### 按临床沟通思维链条重组

#### 链条1：诊疗全程沟通路径

```
患者进入医疗系统
  │
  ├─[门诊沟通]──→ 简短/高效/建立信任
  │   │  重点：开放提问+倾听+共情（Ch3/Ch6）
  │   │  难点：时间短、患者多、信息不对等
  │   └─→ 病史采集（早期-中期-后期三段式，Ch3）
  │
  ├─[检查沟通]──→ 解释检查目的/风险/费用
  │   │  知情同意开始介入（Ch10）
  │   └─→ 危急值报告（核心制度）
  │
  ├─[诊断沟通]──→ SPIKES模型（如为坏消息）
  │   │  功能沟通三方面：事实+论证+趋势（Ch1）
  │   └─→ 确认理解+情绪支持
  │
  ├─[治疗沟通]──→ 方案选择→知情同意→依从性动员
  │   │  手术环节三阶段沟通（术前/术中/术后，Ch6）
  │   └─→ 共同决策（shared decision-making）
  │
  └─[随访沟通]──→ 康复指导/生活方式/复诊提醒
      └─→ 健康管理三目标人群（Ch9）
```

#### 链条2：医患冲突化解路径

```
冲突发生
  │
  ├─ Step1: 情绪降温
  │   原则：平等尊重/换位思考（Ch8原则2.1/2.3）
  │   技巧：适度体态语言、选择合适的沟通距离（Ch8原则2.4）
  │
  ├─ Step2: 事实澄清
  │   方法：倾听→共情→开放提问→确认（Ch3）
  │   原则：诚实守信（Ch8原则2.2）
  │
  ├─ Step3: 责任认定
  │   原则：公正合理/以客观事实为根据（Ch8原则2.5）
  │
  ├─ Step4: 解决方案
  │   协商→解释→道歉（Ch8冲突中语言沟通主要方式）
  │
  └─ Step5: 未解决→第三方介入
       ├─ 人民调解：申请后30个工作日完成
       └─ 行政调解：申请后5个工作日决定是否受理
```

#### 链条3：知情同意沟通流程

```
研究/治疗前
  │
  ├─ 告知内容：目的/方法/风险/获益/替代方案/退出权利
  │   常用方式：书面/口头/电子/见证人签署（Ch10）
  │
  ├─ 确认理解：通俗化语言+图示辅助+反问确认（Ch10）
  │   常见问题：理解不足/自愿性受损/信息过载/文化障碍
  │
  ├─ 自愿签署
  │   特别保护人群：儿童/孕妇/精神障碍者/囚犯
  │
  └─ 持续沟通
       研究过程中依从性维护→影响数据质量和结论可靠性
```

## 三、易混淆对比表

### 对比1：调解制度对比

| 对比维度 | 人民调解 | 行政调解 |
|----------|----------|----------|
| 受理机构 | 人民调解委员会 | 卫生行政部门 |
| 性质 | 群众性自治 | 行政性调解 |
| 申请→完成/受理时限 | **30个工作日**完成调解 | **5个工作日**决定是否受理 |
| 法律效力 | 调解协议具有民事合同性质 | 调解协议具有行政效力 |
| 费用 | 不收费 | 不收费 |

### 对比2：患方权利 vs 患方义务

| 维度 | 权利 | 义务 |
|------|------|------|
| 知情方面 | 知情权（了解病情/方案/风险） | 如实告知（病史/症状/过敏史） |
| 决策方面 | 选择权（选择治疗方案/医师/医院） | 配合诊疗（遵从医嘱/配合检查） |
| 隐私方面 | 隐私权（个人信息/病情保密） | 支付费用（按规定支付医疗费用） |
| 自主方面 | 同意权（知情同意/拒绝治疗） | 遵守规章（医院规章制度） |

### 对比3：医疗团队类型对比

| 对比维度 | 多学科团队(MDT) | 问题解决型团队 | 虚拟医疗团队 | 自我管理型团队 |

### 对比5：共情(empathy) vs 同情(sympathy)

| 维度 | 共情(Empathy) | 同情(Sympathy) |

```

  │   ├─ 老年患者 → 语速慢/重复确认/家属参与
  │   ├─ 儿科患者 → 与家长沟通（交换对象）
  │   └─ 急诊患者 → 快速/简明/情绪安抚
  │
  ├─ 沟通执行
  │   ├─ 开放提问→倾听→共情→澄清（Ch3基本技能）

  │
  └─ 沟通效果评估
      ├─ 患者满意度
      ├─ 信息理解度
      └─ 依从性预判

### 路径2：医患冲突场景分析决策（A3/A4型题素材）

```

  │   ├─ 利益型冲突（费用/赔偿争议）
  │   └─ 价值型冲突（文化/信仰差异）
  │
  ├─ [评估冲突阶段]
  │   ├─ 潜伏期 → 预防为主（知情同意/充分沟通）

  │   └─ 恢复期 → 关系重建/制度改进
  │
  ├─ [选择沟通策略]
