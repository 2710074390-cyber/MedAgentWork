## 模块1：总论与专科检查

> [!INFO] 模块信息
> <b>权重</b>：8%｜<b>预计题型</b>：判断 / A1 / A2 / 多选｜<b>卡片</b>：8 张
> <b>谱系位置</b>：耳鼻咽喉的"地基层"——解剖分区、传音通路、神经支配、检查方法。后续六个模块的全部推理都从这里出发。
> <b>三个题眼</b>：① 传导性 vs 感音神经性聋的分界；② 面神经五分支与周围性面瘫；③ 前庭三个终末器各管什么。
> <b>阅读</b>：约 18 分钟

### 🧩 前置知识检查

- 耳分为哪三部分？鼓膜是哪两部分的界膜？
- 声音从外耳到听觉中枢，中间经过哪几块听小骨？
- 面神经是第几对脑神经？它在腮腺内分成哪五支？
- 前庭里哪两个结构感受直线加速度？哪个结构感受角加速度？
- 咽鼓管连通哪两个腔？儿童咽鼓管有什么解剖特点？

> [!TIP] 复习入口
> 本模块只回答三件事：<b>结构在哪、声音怎么走、神经怎么支配</b>。这三件事记住了，耳科学（M02）的传导性聋、面瘫、眩晕才有落脚点。

### 🎯 30 秒摘要

1. 外耳集音、中耳传音、内耳感音；鼓膜是外耳与中耳的界膜。
2. 空气传导是正常听觉主途径，骨传导不依赖外耳和中耳。
3. 基底膜高频在基底部、低频在蜗顶；毛细胞把机械振动变成电信号。
4. 面神经是混合神经，出茎乳孔后分颞、颧、颊、下颌缘、颈五支。
5. 椭圆囊斑、球囊斑感受直线加速度；半规管壶腹嵴感受角加速度。

### 📋 考点卡

#### 🔴 K-M01-001｜耳的三部分与内耳结构（教师重点第1、111条｜P16）

📌 重点原文（第1条）：内耳（Inner ear） 是听觉和平衡觉的感受器所在部位，主要包括以下结构：耳蜗（Cochlea）负责感受声音刺激，是听觉感受器所在；前庭（Vestibule）和半规管（Semicircular canals）负责维持身体平衡。外耳：耳廓 + 外耳道 + 鼓膜；中耳：鼓室 + 听小骨（锤骨、砧骨、镫骨）+ 咽鼓管；内耳：耳蜗 + 前庭 + 半规管（P16）

📌 重点原文（第111条）：听骨链依次为锤骨、砧骨、镫骨；耵聍腺主要位于外耳道软骨部；前庭终末器包括椭圆囊斑、球囊斑和半规管壶腹嵴。

<b>🎯 一句话题眼</b>：看到"听觉和平衡觉的感受器"→ 直接定位内耳；听到"听骨链"→ 按锤、砧、镫的顺序背。

<b>🧬 为什么</b>：外耳与中耳只负责"把声音送进去"，真正的换能器在内耳。所以外耳、中耳病变只造成传导性下降（骨导仍正常），耳蜗或听神经病变才会把气导和骨导一起拉低。外耳道全长约 2.5～3.5cm，呈 S 形，外侧约 1/3 为软骨部（耵聍腺所在），内侧约 2/3 为骨部；检查成人外耳道通常向后上方牵拉耳廓。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 外耳 | 中耳 | 内耳 |
|---|---|---|---|
| 组成 | 耳廓、外耳道、鼓膜 | 鼓室、听骨链、咽鼓管、乳突气房 | 耳蜗、前庭、半规管 |
| 主要功能 | 集音、保护 | 传音、增压 | 感音、平衡 |
| 病变听力类型 | 传导性 | 传导性 | 感音神经性 |

<b>🚨 红线</b>：把鼓膜算作中耳结构是最常见的错误——鼓膜是外耳与中耳之间的界膜，属外耳侧。

<b>🩺 下一步</b>：① 先按"外—中—内"三 compartment 记结构；② 再用"传导 vs 感音"把结构映射到听力类型；③ 最后记听骨链顺序与前庭终末器。

#### 🔴 K-M01-002｜空气传导与骨传导（教师重点第2条｜P37）

📌 重点原文（第2条）：声音传导至内耳主要有两种途径：空气传导（air conduction） 和 骨传导（bone conduction）。两者都能使内耳产生听觉反应，但在生理机制和临床意义上有所不同。

<b>🎯 一句话题眼</b>：气导走"外耳道→鼓膜→听骨→卵圆窗"，骨导走"颅骨→外淋巴"；气导是主途径。

<b>🧬 为什么</b>：气导需要外耳和中耳结构完整，所以中耳有病变时气导先掉；骨导绕过外耳和中耳，直接振动颅骨与内耳淋巴，因此骨导正常、气导下降就是传导性聋的签名。

<b>🔗 机制链</b>：

```text
声波
├─ 空气传导：外耳道 → 鼓膜振动 → 听小骨（锤、砧、镫） → 卵圆窗
│                              → 外淋巴波动 → 耳蜗毛细胞
└─ 骨传导：颅骨振动 → 内耳外淋巴及基底膜振动 → 毛细胞
                         ↓
                  听神经 → 大脑听觉中枢
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 空气传导 | 骨传导 |
|---|---|---|
| 起点 | 外耳道 | 颅骨 |
| 依赖结构 | 外耳 + 中耳 + 内耳 | 内耳为主 |
| 听阈 | 通常优于骨导 | 略差 |
| 临床用途 | 判断整体听力 | 判断是否为传导性聋 |

<b>🚨 红线</b>：气导听阈优于骨导是正常现象，不要把它当"异常"；只有当骨导大于气导（Rinne 阴性）时才提示传导性聋。

<b>🩺 下一步</b>：先用音叉试验区分气导与骨导谁更强，再用纯音测听量化气骨导差。

<b>🔄 自测</b>：空气传导的完整路径是什么？为什么骨导正常而气导下降提示传导性聋？（答案见附录五）

#### 🔴 K-M01-003｜耳蜗、基底膜与毛细胞的换能（教师重点第3、6条｜P40、P41）

📌 重点原文（第3条）：耳蜗主要功能是感受声波产生神经电信号（P40）

📌 重点原文（第6条）：基底膜（Basilar membrane）位于耳蜗内部的蜗管（cochlear duct）中，是柯蒂氏器（Organ of Corti）的重要组成部分；不同频率的声波在基底膜上引起不同部位的共振：高频 → 基底部（靠近卵圆窗），低频 → 顶端（靠近蜗顶）；毛细胞顶部的感受毛（stereocilia）弯曲，打开机械性离子通道，引发去极化。

<b>🎯 一句话题眼</b>：高频在基底、低频在蜗顶；毛细胞纤毛一弯，机械能变电信号。

<b>🧬 为什么</b>：基底膜不同部位的劲度和质量不同，所以对不同频率共振。高频区靠近卵圆窗、最先受声波冲击，因此噪声性聋和老年性聋往往先丢高频。

<b>⚖️ 鉴别</b>：

| 部位 | 负责 | 受损后的听力曲线 |
|---|---|---|
| 基底膜基底部 | 高频 | 高频下降（噪声性、老年性） |
| 基底膜蜗顶部 | 低频 | 低频下降（梅尼埃早期） |
| 内毛细胞 | 主要感受器 | 感音神经性聋 |
| 外毛细胞 | 放大、提高敏感性 | 重振、言语识别下降 |

<b>🚨 红线</b>：耳蜗病变造成的是感音神经性聋，不是传导性聋；不要把"耳蜗"和"传音"混为一谈。

<b>🩺 下一步</b>：纯音测听看曲线形态（高频型 / 低频型 / 平坦型）→ 声导抗排除中耳因素 → 必要时 OAE、ABR。

<b>🔄 自测</b>：高频声波主要使基底膜哪一端振动？毛细胞如何把机械振动转成电信号？（答案见附录五）

#### 🟡 K-M01-004｜面神经的纤维成分与五个终末支（教师重点第4、5条｜P34）

📌 重点原文（第4条）：面神经（Facial nerve, 第Ⅶ对脑神经）是一条混合性神经，同时具有运动、感觉和副交感纤维。它的主要作用是支配面部表情肌肉的运动，并参与味觉和腺体分泌功能。（P34）

📌 重点原文（第5条）：面神经在出颅后于腮腺内分为五个主要终末分支，支配面部表情肌：颞支（额支）–支配额肌、眼轮匝肌上部；颧支–支配眼轮匝肌下部；颊支–支配口轮匝肌、颧大肌等；下颌缘支（颏支）–支配下唇肌群；颈支–支配颈阔肌。

<b>🎯 一句话题眼</b>：面神经 = 运动 + 味觉（舌前2/3）+ 副交感；五支按"颞、颧、颊、下颌缘、颈"自上而下排。

<b>🧬 为什么</b>：面神经在颞骨内走行于面神经管，与中耳结构紧邻。慢性化脓性中耳炎、胆脂瘤破坏面神经管时可出现周围性面瘫；因此"中耳炎 + 面瘫"是并发症信号，不是两个独立病。

<b>⚖️ 鉴别</b>：

| 分支 | 支配 | 损伤表现 |
|---|---|---|
| 颞支 | 额肌、眼轮匝肌上部 | 额纹消失、不能皱眉 |
| 颧支 | 眼轮匝肌下部 | 闭眼不全 |
| 颊支 | 口轮匝肌、颧大肌 | 鼓腮漏气、口角歪斜 |
| 下颌缘支 | 下唇肌群 | 下唇下垂 |
| 颈支 | 颈阔肌 | 颈部皮肤皱襞消失 |

<b>🚨 红线</b>：下颌下腺及颌下淋巴结手术要注意保护下颌缘支；损伤后下唇下垂是不可逆的功能损失。

<b>🩺 下一步</b>：先定位（周围性 vs 中枢性）→ 再查耳部（中耳炎、胆脂瘤、外伤）→ 必要时面神经电图与颞骨 CT。

<b>🔄 自测</b>：面神经有哪三类纤维？五个终末支自上而下如何排列？（答案见附录五）

#### 🔴 K-M01-005｜周围性面瘫与中枢性面瘫（教师重点第113条）

📌 重点原文（第113条）：面神经出茎乳孔后进入腮腺并分为颞支、颧支、颊支、下颌缘支和颈支；周围性面瘫常见同侧额纹消失、闭眼不全和口角歪斜。

<b>🎯 一句话题眼</b>：额纹也消失 → 周围性（同侧）；额纹保留 → 中枢性（对侧下半面）。

<b>🧬 为什么</b>：额肌受双侧皮质支配，所以中枢病变时额纹常保留；面神经核或神经本身受损时，同侧全部表情肌一起瘫。临床上不能只凭额纹判断，需结合完整神经系统检查。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 周围性面瘫 | 中枢性面瘫 |
|---|---|---|
| 病变部位 | 面神经核/神经 | 皮质延髓束 |
| 额纹 | 同侧消失 | 多保留 |
| 闭眼 | 不全 | 多正常 |
| 口角 | 同侧歪斜 | 对侧歪斜 |
| 常见病因 | 贝尔面瘫、中耳炎、胆脂瘤、外伤 | 脑血管病 |

<b>🚨 红线</b>：慢性胆脂瘤型中耳炎伴周围性面瘫，提示面神经管受侵或破坏，属需尽快评估处理的并发症。

<b>🩺 下一步</b>：① 神经系统查体定位；② 耳镜检查 + 颞骨 CT；③ 中枢性者查头颅影像。

#### 🔴 K-M01-006｜前庭系统与三个终末器（教师重点第7条｜P43）

📌 重点原文（第7条）：前庭系统的主要功能：感受头部的运动和空间位置变化，维持身体的平衡与姿势稳定（P43）

<b>🎯 一句话题眼</b>：椭圆囊斑、球囊斑管"直线"，半规管壶腹嵴管"旋转"。

<b>🧬 为什么</b>：三个半规管互相垂直，分别对应三个平面的角加速度；耳石器官感受重力与直线加速度。前庭信息与视觉、本体感觉三方整合，任何一方出错都会眩晕。

<b>⚖️ 鉴别</b>：

| 终末器 | 感受 | 受损表现 |
|---|---|---|
| 椭圆囊斑 | 水平直线加速度、头部位置 | 平衡不稳 |
| 球囊斑 | 垂直直线加速度、重力 | 站立不稳、倾倒感 |
| 半规管壶腹嵴 | 角加速度（旋转） | 旋转性眩晕、眼震 |

<b>🚨 红线</b>：眩晕伴复视、构音障碍、共济失调或垂直性眼震，先排中枢（后循环卒中），不能只按"前庭周围病"处理。

<b>🩺 下一步</b>：① 问时间轴（秒/小时/天）；② 位置试验；③ 前庭功能检查；④ 有中枢体征时急诊影像。

<b>🔄 自测</b>：椭圆囊斑、球囊斑、壶腹嵴各感受什么？（答案见附录五）

#### 🟡 K-M01-007｜耳部解剖生理的综合串联（教师重点第107条｜P16）

📌 重点原文（第107条）：耳部的解剖与生理功能。鼓膜明确分为上方的松弛部与下方占比较大的紧张部，后者是主要功能区。鼓室以鼓膜为界分为上、中、下三部，容纳听骨链。儿童因咽鼓管具有短、宽、平直的解剖特点，故易患中耳炎。在内耳，三个互相垂直的半规管（尤其是水平位的外半规管）负责感知旋转运动。听觉方面，内毛细胞是听觉信号的主要感受器，而外毛细胞起"放大"作用以增强敏感性；声音通过空气传导的完整途径实现。骨迷路与膜迷路之间为外淋巴，膜迷路内为内淋巴，两者循环独立；前庭阶与鼓阶的外淋巴通过蜗孔相通。耳郭静脉回流并非单一途径，除颞浅静脉外，还经耳后静脉汇入颈外静脉，且存在与颅内相通的导血管，这是耳部感染可能引发颅内并发症的解剖基础。（P16）

<b>🎯 一句话题眼</b>：鼓膜分松弛部/紧张部；鼓室分上/中/下；儿童咽鼓管"短宽平直"→ 易中耳炎。

<b>🧬 为什么</b>：鼓室三部以鼓膜为界，上鼓室与乳突窦相通，所以上鼓室病变容易向乳突蔓延；儿童咽鼓管短宽平直，鼻咽部感染更容易逆行进入中耳。

<b>⚖️ 鉴别</b>：

| 概念 | 关键点 |
|---|---|
| 鼓膜松弛部 | 上方，紧张部是主要功能区 |
| 鼓室三部 | 上鼓室、中鼓室、下鼓室 |
| 外淋巴 vs 内淋巴 | 骨迷路与膜迷路之间 / 膜迷路内，循环独立 |
| 蜗孔 | 连通前庭阶与鼓阶的外淋巴 |

<b>🚨 红线</b>：耳郭静脉经导血管与颅内相通，是耳部感染引起颅内并发症的解剖基础，不能把耳廓感染当"皮肤小病"。

<b>🩺 下一步</b>：把本卡当作"总图"，遇到具体疾病时回到这张图定位（外耳/中耳/内耳/颅内外并发症）。

#### 🟢 K-M01-008｜专科检查方法学（教材背景，不单列条号）

<b>🎯 一句话题眼</b>：额镜照明、压舌板暴露口咽；硬镜看细节、软镜看深部；纯音测听是主观检查，声导抗/OAE/ABR 是客观检查。

<b>⚖️ 检查对照</b>：

| 检查 | 看什么 | 不能替代什么 |
|---|---|---|
| 耳内镜 | 外耳道、鼓膜 | 不能判定听力损失类型 |
| 鼻内镜 | 鼻腔、鼻咽、鼻窦开口 | 不能替代病理确诊 |
| 电子鼻咽喉镜 | 鼻咽、喉、部分下咽 | 不能替代影像分期 |
| 纯音测听 | 气导/骨导阈值 | 主观检查，需配合 |
| 声导抗 | 鼓膜与中耳传音 | 不能定位感音部位 |
| 颞骨 CT | 骨质破坏、解剖 | 不能定性肿瘤 |
| 增强 MRI | 软组织、颅底、神经 | 不能替代病理 |

<b>🚨 红线</b>：设备不能相互替代——耳内镜不能判定听力类型，正常胸片不能排除气道异物，EB 病毒检测不能代替鼻咽癌病理确诊。

<b>🩺 下一步</b>：先无创（镜检 + 听力学），再有创（活检/穿刺）；先排除危险（气道、血管、颅内），再追求确诊。

### 🔗 因果链：从声波到听觉中枢

```text
声波（空气传导）
        ↓
外耳道集音 → 鼓膜振动
        ↓
听骨链（锤骨→砧骨→镫骨）增压
        ↓
卵圆窗 → 外淋巴波动
        ↓
基底膜行波（高频基底、低频蜗顶）
        ↓
毛细胞纤毛弯曲 → 机械门控离子通道开放
        ↓
去极化 → 听神经（第Ⅷ对脑神经）
        ↓
脑干 → 听觉中枢
```

> [!INFO] 读图
> 这条链上任何一个"↓"断掉，都会表现为听力下降；断在外耳/中耳是传导性，断在毛细胞/听神经是感音神经性。

### 🌳 决策树：听力下降的定位

```text
听力下降
├─ 外耳道被耵聍/异物/炎症堵住
│    → 传导性（取出或消炎后恢复）
├─ 鼓膜穿孔、中耳积液、听骨链固定
│    → 传导性（声导抗 + 鼓膜检查）
├─ 气导骨导同降、无气骨导差
│    → 感音神经性（耳蜗/听神经）
│    ├─ 突发、单侧 → 突发性聋（急症）
│    ├─ 波动性低频 → 梅尼埃病
│    └─ 进行性单侧 → 查桥小脑角（MRI）
└─ 气骨导均下降且有气骨导差
     → 混合性聋（中耳 + 内耳同时受累）
```

#### 🟡 K-M02-001｜耳郭假性囊肿（教师重点第8条｜P77）

📌 重点原文（第8条）：耳郭假性囊肿的发病原因可能与耳郭外伤有关，如耳郭的挤压、撞击等，导致局部血液循环障碍，组织间液积聚形成囊肿。（P77）

<b>🎯 一句话题眼</b>：耳廓前面无痛性隆起 + 波动感 + 有挤压/撞击史 → 假性囊肿（不是真性囊肿，无上皮衬里）。

<b>🧬 为什么</b>：耳廓软骨血供差，轻微挤压造成软骨间积液，液体被困在软骨内或软骨间隙，形成"假性"囊肿。因为不是真性肿瘤，抽吸后容易复发。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 耳郭假性囊肿 | 耳郭化脓性软骨膜炎 |
|---|---|---|
| 疼痛 | 多不明显 | 明显红、肿、热、痛 |
| 内容物 | 浆液性 | 脓性 |
| 全身症状 | 无 | 可有发热 |

<b>🚨 红线</b>：不要自行反复挤压"抽液"，易继发感染并导致耳廓畸形。

<b>🩺 下一步</b>：专科评估后选择抽吸+加压固定或手术处理，目标是防止复发与畸形。

#### 🔴 K-M02-002｜耳郭化脓性软骨膜炎（教师重点第9条｜P78）

📌 重点原文（第9条）：耳郭化脓性软骨膜炎的病因及致病菌及临床表现（P78）——① 病因：耳廓外伤、穿孔、手术或感染；② 常见致病菌：铜绿假单胞菌、金黄色葡萄球菌；③ 表现：耳廓红、肿、热、痛，严重时形成脓肿并破坏软骨，耳垂因不含软骨可相对不受累；延误治疗可致耳廓畸形。

<b>🎯 一句话题眼</b>：耳廓红肿热痛 + 耳垂幸免 → 化脓性软骨膜炎；铜绿假单胞菌是高频答案。

<b>🧬 为什么</b>：耳廓软骨本身无血供，靠软骨膜渗透营养；一旦感染形成脓肿，软骨缺血坏死，修复后纤维化收缩，形成菜花耳畸形。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 化脓性软骨膜炎 | 耳郭假性囊肿 | 外耳道疖 |
|---|---|---|---|
| 部位 | 耳廓软骨 | 耳廓软骨间 | 外耳道软骨部 |
| 疼痛 | 剧烈 | 轻 | 牵拉耳廓剧痛 |
| 耳垂 | 相对不受累 | 可累及 | 正常 |

<b>🚨 红线</b>：形成脓肿必须及时引流，延误可致耳廓畸形；抗感染要覆盖铜绿假单胞菌。

<b>🩺 下一步</b>：① 取分泌物培养；② 足量抗感染；③ 脓肿切开引流、必要时清除坏死软骨。

<b>🔄 自测</b>：耳郭化脓性软骨膜炎最常见的致病菌是什么？为什么耳垂常不受累？（答案见附录五）

#### 🟢 K-M02-003｜外耳湿疹（教师重点第10条｜P78）

📌 重点原文（第10条）：外耳湿疹的主要病因及治疗原则（P78）——① 病因：过敏、接触刺激、皮肤屏障受损或反复搔抓；② 表现：瘙痒、红斑、脱屑、渗出及结痂，瘙痒往往最突出；③ 治疗原则：去除刺激或过敏因素、保持局部清洁干燥、避免搔抓，由医师选择适当局部抗炎药物，合并感染时相应处理。

<b>🎯 一句话题眼</b>：耳廓/耳道"痒"大于"痛"，有渗出结痂 → 外耳湿疹；治疗先"去因+干燥"。

<b>🚨 红线</b>：鼓膜穿孔或不能确认鼓膜完整时，避免使用有耳毒性风险的滴耳制剂。

<b>🩺 下一步</b>：去因 → 清洁干燥 → 局部抗炎 → 合并感染时抗感染。

#### 🔴 K-M02-004｜耵聍栓塞与外耳道胆脂瘤（教师重点第11、14、104条｜P79、P82、P37）

📌 重点原文（第11条）：外耳道耵聍栓塞的主要原因及外耳道耵聍栓塞的治疗方法，外耳道耵聍栓塞与外耳道胆脂瘤的主要鉴别点（P79）——原因：耵聍分泌过多、外耳道狭窄或弯曲、耳毛较多、频繁挖耳将耵聍推向深部；治疗：耵聍软化、器械取出或冲洗，怀疑鼓膜穿孔、既往耳部手术、外耳道感染时不宜盲目冲洗；鉴别：耵聍栓塞无进行性骨质破坏，外耳道胆脂瘤可伴外耳道骨质侵蚀、耳痛、流脓或恶臭分泌物。

📌 重点原文（第14条）：外耳道胆脂瘤的诊断主要依赖于组织病理学检查，通过显微镜观察角化物质的典型表现来确诊（P82）——临床诊断需结合耳镜或耳内镜观察，必要时行颞骨 CT 评估骨质破坏，病理检查用于鉴别，不能将诊断简单归结为仅依赖组织病理。

📌 重点原文（第104条）：耵聍堵塞导致的传导性耳聋及鼓膜内陷、纯音测听和声导抗检查的作用、外耳道在空气传导中的重要性以及耵聍取出和鼓膜、咽鼓管处理的基本原则：硬耵聍团块堵塞外耳道是传导性听力下降的核心病因，表现为气导下降而骨导正常；长期堵塞可导致鼓膜内陷，形成鼓室负压，间接影响声音传导。听骨链固定多需慢性中耳炎或外伤史，而耳蜗功能减退则表现为感音神经性耳聋。声音空气传导的起始环节是外耳道，耵聍完全堵塞直接阻碍声音进入，鼓膜内陷进一步降低振动幅度。诊断上，耳内镜可观察鼓膜及耵聍情况，纯音测听复查可判断取出耵聍后听力恢复，声导抗测试评估鼓室压力，颞骨CT可排除中耳结构异常，前庭功能检查在无眩晕、平衡障碍时可省略。治疗核心是先软化硬耵聍再用专业器械取出，辅以鼓膜按摩改善内陷或咽鼓管吹张恢复鼓室压力。患者无外耳道红肿、流脓等感染迹象时无需口服抗生素。（P37）

<b>🎯 一句话题眼</b>：耵聍=堵住的声音，取出就好；胆脂瘤=会吃骨头的"假瘤"，要看 CT 与病理。

<b>🧬 为什么</b>：耵聍只占位不侵蚀，所以气导降、骨导正常，取出后恢复；外耳道胆脂瘤由角化上皮不断堆积并释放酶类，造成外耳道骨质侵蚀，因此会有耳痛、流脓、恶臭，甚至外耳道狭窄。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 耵聍栓塞 | 外耳道胆脂瘤 |
|---|---|---|
| 本质 | 耵聍堆积 | 角化上皮及角化碎屑堆积 |
| 骨质破坏 | 无 | 有，进行性 |
| 症状 | 耳闷、听力下降、耳鸣 | 耳痛、流脓、恶臭 |
| 关键检查 | 耳内镜 | 耳内镜 + 颞骨 CT，必要时病理 |

<b>🚨 红线</b>：怀疑鼓膜穿孔、既往耳部手术、外耳道感染时，不宜盲目冲洗；无感染迹象不需口服抗生素。

<b>🩺 下一步</b>：① 耳内镜确认；② 先软化再专业器械取出；③ 疑胆脂瘤加颞骨 CT；④ 取出后复查纯音测听与声导抗。

📌 重点原文（第15条）：大疱性鼓膜炎的病因大多为病毒感染，以流感病毒、脊髓灰质炎病毒等为主，（P83）

📌 重点原文（第16条）：大疱性鼓膜炎与一般急性鼓膜炎、急性化脓性中耳炎早期、特发性血鼓室及蓝鼓膜症状及查体所见的鼓膜表现相似，联系密切，在临床上常相互鉴别，避免误诊，P83）

<b>🧬 为什么</b>：病毒侵犯鼓膜上皮层，局部渗出形成疱；因为病变在鼓膜表层，所以疼痛剧烈但听力多无明显下降，穿孔后可自愈。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 大疱性鼓膜炎 | 急性化脓性中耳炎 | 特发性血鼓室 |

| 耳痛 | 剧烈 | 剧烈，穿孔后减轻 | 轻 |
| 听力 | 多正常或轻降 | 传导性下降 | 传导性下降 |
| 病程 | 短，多自限 | 需抗感染 | 迁延 |

<b>🚨 红线</b>：大疱不要随意穿刺；需与急性化脓性中耳炎早期鉴别，避免误用抗生素或延误引流。

<b>🩺 下一步</b>：耳内镜确认鼓膜形态 → 听力学评估 → 对症止痛、保持干燥，合并细菌感染时抗感染。

#### 🔴 K-M02-009｜分泌性中耳炎（教师重点第17、106条｜P85、P83）

📌 重点原文（第17条）：分泌性中耳炎的临床表现，分泌性中耳炎鼓膜置管术适应证（P85）——表现：耳闷、听力下降、耳内堵塞感，儿童可表现为听力反应下降、注意力下降或言语发育受影响；鼓膜可呈琥珀色、内陷、活动度下降或见液平面、气泡，声导抗可呈 B 型平坦曲线；置管适应证：持续约 3 个月或更久的中耳积液且伴明确听力困难，或存在言语、学习、平衡、生活质量等相关问题。

📌 重点原文（第106条）：分泌性中耳炎的典型临床表现、咽鼓管功能障碍及过敏性鼻炎的病因、鼓室负压与积液对传导性听力的影响、诊断检查方法及治疗原则：感冒后出现耳闷和传导性听力下降，鼓膜内陷，声导抗呈B型曲线，符合分泌性中耳炎诊断，其主要病因是咽鼓管功能障碍，常由过敏性鼻炎导致咽鼓管咽口黏膜肿胀所诱发，而急性化脓性中耳炎则多伴耳痛、发热、鼓膜充血膨隆及穿孔流脓。发病机制为咽鼓管功能障碍导致鼓室通气不足，形成鼓室负压或积液，直接阻碍声音传导，同时鼓膜内陷降低振动幅度，加重传导性听力下降；听骨链正常，无慢性中耳炎病史，耳蜗功能正常（骨导正常）。诊断可结合鼻内镜观察咽口阻塞、鼓室穿刺确认积液、咽鼓管功能测试量化通气能力，过敏原检测可指导预防，颞骨MRI主要用于排查内耳或听神经病变，对分泌性中耳炎诊断非必需。治疗以恢复咽鼓管通气和促进积液排出为主：鼻腔糖皮质激素减轻黏膜肿胀，黏液促排剂帮助排出积液，鼓膜穿刺可快速改善听力，咽鼓管吹张促进通气和积液吸收，患者无感染迹象时无需口服抗生素。（P83）

<b>🎯 一句话题眼</b>：感冒后耳闷 + 鼓膜内陷 + 声导抗 B 型 → 分泌性中耳炎；成人单侧要查鼻咽。

<b>🧬 为什么</b>：咽鼓管是鼓室唯一的通气通道。它一堵，鼓室空气被吸收形成负压，黏膜渗出积液，鼓膜内陷、振动受限，于是出现传导性听力下降。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 分泌性中耳炎 | 急性化脓性中耳炎 |
|---|---|---|
| 耳痛 | 轻或无 | 明显 |
| 发热 | 多无 | 常有 |
| 鼓膜 | 内陷、琥珀色、液平面 | 充血膨隆、穿孔流脓 |
| 声导抗 | B 型平坦 | 早期 C 型，穿孔后无法测 |
| 听力 | 传导性下降 | 传导性下降 |

<b>🚨 红线</b>：成人单侧、原因不明的分泌性中耳炎，必须查鼻咽部排除鼻咽癌；不能把所有积液都直接置管。

<b>🩺 下一步</b>：① 耳内镜 + 声导抗；② 鼻内镜看咽鼓管咽口；③ 鼻腔糖皮质激素 + 黏液促排剂；④ 持续约 3 个月且有听力/言语问题才考虑置管。

#### 🔴 K-M02-011｜急性化脓性中耳炎（教师重点第19条｜P88）

📌 重点原文（第19条）：急性化脓性中耳炎病程超过6～8周，可称为慢性化脓性中耳炎（P88）急性化脓性中耳炎治疗原则，鼓膜穿孔后，禁止使用粉剂，以免与脓液结块影响引流。急性化脓性中耳炎检查情况。

<b>🎯 一句话题眼</b>：耳痛 + 发热 + 鼓膜膨隆 → 穿孔后流脓、疼痛减轻；超过 6～8 周转慢性。

<b>🧬 为什么</b>：鼓室积脓压力升高，压迫鼓膜致缺血坏死穿孔；穿孔后脓液引流，压力下降，疼痛随之缓解。因此"穿孔后疼痛减轻"是病程转折点。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 急性化脓性中耳炎 | 大疱性鼓膜炎 |
|---|---|---|
| 鼓膜 | 充血膨隆、穿孔 | 表面血性大疱 |
| 耳流脓 | 穿孔后出现 | 无 |
| 发热 | 常有 | 多无 |

<b>🚨 红线</b>：鼓膜穿孔后禁止使用粉剂，以免与脓液结块影响引流；忌用耳毒性滴耳液。

<b>🩺 下一步</b>：① 耳镜 + 听力学；② 止痛、抗感染；③ 穿孔后保持引流通畅；④ 超过 6～8 周按慢性化脓性中耳炎管理。

#### 🔴 K-M02-012｜慢性化脓性中耳炎（教师重点第20条｜P88）

📌 重点原文（第20条）：慢性化脓性中耳炎致病菌，临床表现，体征及治疗，流脓停止耳内干燥后，鼓膜小的穿孔可自愈，穿孔不愈合应及时早行鼓室成形术。局部用药时忌用氨基糖苷类抗生素等耳毒性药物滴耳，以免引起听力下降。忌用粉剂，因其可能堵塞穿孔妨碍引流。尽量不用有色药物，以防影响局部观察。中耳腔内忌用含酚类、砷类腐蚀剂。慢性化脓性中耳炎的治疗原则之一是改善听力，因此当患耳是唯一听力耳时，应谨慎手术。（P88）

<b>🎯 一句话题眼</b>：鼓膜穿孔 + 反复流脓 + 传导性聋 → 慢性化脓性中耳炎；用药"三忌"：忌耳毒性、忌粉剂、忌腐蚀剂。

<b>🧬 为什么</b>：穿孔后中耳与外耳相通，滴耳液可直接经圆窗进入内耳，所以氨基糖苷类耳毒性药物会"越治越聋"；粉剂结块堵塞穿孔，脓液引流不畅反而加重感染。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 单纯型 | 骨疡型 | 胆脂瘤型 |
|---|---|---|---|
| 分泌物 | 黏液性、无臭 | 脓性、可臭 | 恶臭豆渣样 |
| 穿孔 | 紧张部中央性 | 边缘性 | 松弛部/边缘性 |
| 骨质破坏 | 无 | 有 | 明显 |
| 危险度 | 低 | 中 | 高（颅内并发症） |

<b>🚨 红线</b>：唯一听力耳手术要极谨慎；出现头痛、发热、面瘫、眩晕提示颅内/迷路并发症。

<b>🩺 下一步</b>：① 耳内镜 + 纯音测听 + 颞骨 CT；② 保持干燥、局部非耳毒性药物；③ 干耳后小穿孔可自愈，不愈者择期鼓室成形术。

#### 🔴 K-M02-013｜中耳胆脂瘤（教师重点第21条｜P91）

📌 重点原文（第21条）：中耳胆脂瘤病因及临床表现及治疗，诊断中耳胆脂瘤最有价值的检查是颞骨CT扫描可发现上鼓室、鼓窦和乳突区有骨质破坏，边缘浓密整齐。可评价乳突气化程度、病变范围、听小骨破坏程度、面神经管状况、有无迷路瘘孔、颈静脉球高度等，为手术提供参考。（P91）

<b>🎯 一句话题眼</b>：松弛部穿孔 + 恶臭豆渣样脓 + CT 骨质破坏伴硬化边缘 → 胆脂瘤。

<b>🧬 为什么</b>：角化上皮在鼓室/乳突内不断堆积，分泌溶骨酶并产生压力，造成听骨链、面神经管、迷路骨质破坏；因此它不是肿瘤却比很多肿瘤更"吃骨头"。

<b>🔗 机制链</b>：

```text
咽鼓管功能障碍 / 鼓膜内陷袋
        ↓
角化上皮在鼓室堆积
        ↓
溶骨酶 + 机械压迫
        ↓
听骨链破坏 → 传导性聋
        ↓
面神经管 / 迷路 / 乙状窦破坏
        ↓
面瘫、眩晕、颅内感染
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 胆脂瘤 | 慢性化脓性中耳炎（单纯型） | 胆固醇肉芽肿 |
|---|---|---|---|
| 分泌物 | 恶臭豆渣样 | 黏液性、无臭 | 褐色 |
| 穿孔 | 松弛部/边缘性 | 紧张部中央性 | 鼓膜完整或蓝鼓膜 |
| CT | 骨质破坏、硬化边缘 | 无破坏 | 软组织影，少破坏 |
| 治疗 | 手术为主 | 保守为主 | 手术 |

<b>🚨 红线</b>：胆脂瘤是"必须手术"的病变；出现面瘫、眩晕、头痛提示并发症，需尽快处理。

<b>🩺 下一步</b>：① 耳内镜；② 颞骨高分辨率 CT（最有价值）；③ 手术清除 + 听骨链重建；④ 术后随访防复发。

#### 🟡 K-M02-014｜中耳胆固醇肉芽肿（教师重点第22条｜P93）

📌 重点原文（第22条）：中耳胆固醇肉芽肿的发病原因不明，病理改变是中耳腔出现胆固醇结晶和继发的反应性肉芽组织。主要临床症状是较分泌性中耳炎略重的传导性耳聋。体征是蓝鼓膜或深褐色鼓膜，鼓膜被肉芽组织累及出现穿孔，可有褐色分泌物流出。追问病史多有自幼或常年中耳炎病史。胆固醇肉芽肿可局限于乳突或中耳的某些气房，也可侵犯整个中耳。颞骨CT扫描可见鼓室及乳突内软组织影，少数有骨质破坏。（P93）

<b>🎯 一句话题眼</b>：蓝鼓膜 + 褐色分泌物 + 长期中耳炎史 → 胆固醇肉芽肿。

<b>🧬 为什么</b>：中耳通气障碍 → 出血 → 红细胞分解出胆固醇 → 胆固醇结晶刺激产生反应性肉芽组织，故呈蓝黑色。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 胆固醇肉芽肿 | 胆脂瘤 | 分泌性中耳炎 |
|---|---|---|---|
| 鼓膜 | 蓝/深褐色 | 松弛部穿孔 | 内陷、琥珀色 |
| 分泌物 | 褐色 | 恶臭豆渣样 | 无 |
| CT | 软组织影，少破坏 | 骨质破坏 | 积液 |
| 听力 | 传导性，略重 | 传导性 | 传导性 |

<b>🚨 红线</b>：蓝鼓膜不等于"血鼓室"，要追问长期中耳炎史并做影像鉴别。

<b>🩺 下一步</b>：耳内镜 + 颞骨 CT（必要时 MRI 鉴别）→ 手术清除病灶 + 重建通气。

#### 🔴 K-M02-015｜音叉试验与三型听力损失（教师重点第112条）

📌 重点原文（第112条）：气导大于骨导为林纳试验阳性；林纳试验阴性典型提示传导性聋；韦伯试验中传导性聋偏患耳、单侧感音神经性聋偏健耳。

<b>🎯 一句话题眼</b>：Rinne 阴性 → 传导性；Weber 偏患耳 → 传导性，偏健耳 → 感音神经性。

<b>🧬 为什么</b>：传导性聋时外耳/中耳隔音，环境噪声进不来，骨导反而"显得更响"，所以骨导大于气导（Rinne 阴性）；Weber 试验中，传导性侧声音更"封闭"因而偏患耳，感音神经性侧因患耳感知差而偏健耳。

<b>⚖️ 鉴别</b>：

| 试验 | 传导性聋 | 感音神经性聋 | 正常 |
|---|---|---|---|
| Rinne | 阴性（骨>气） | 阳性（气>骨） | 阳性 |
| Weber | 偏患耳 | 偏健耳 | 居中 |

<b>🚨 红线</b>：重度单侧聋可能出现假阴性 Rinne；音叉试验只能初筛，不能代替纯音测听。

<b>🩺 下一步</b>：音叉初筛 → 纯音测听 + 声导抗定性定量。

#### 🔴 K-M02-016｜眩晕的诊断框架（教师重点第23、24、25条｜P111、P112、P110）

📌 重点原文（第23条）：眩晕的诊断应做到定位、定性、定因。病史的采集与分析是首要任务。（P111）

📌 重点原文（第24条）：周围性眩晕与中枢性眩晕的一般特征（P112）——周围性：旋转性眩晕明显，伴恶心、呕吐、面色苍白、出冷汗等自主神经症状，眼震多为水平或水平旋转性，可伴耳鸣、耳闷、听力下降；中枢性：眩晕可不典型，常伴复视、构音障碍、肢体无力、感觉异常、严重共济失调，眼震可为垂直性或方向改变性。

📌 重点原文（第25条）：前庭周围性眩晕分为：（1）耳蜗前庭疾患，包括：①迷路内，如梅尼埃病等；②迷路内外，如氨基苷类耳中毒。（2）前庭疾患，包括：①迷路内，如良性阵发性位置性眩晕；②迷路外，如前庭神经炎。（P110）

<b>🎯 一句话题眼</b>：先分"周围 vs 中枢"，再分"耳蜗前庭 vs 纯前庭"，最后定具体病。

<b>🧬 为什么</b>：前庭通路从迷路到前庭核再到脑干、小脑，越靠中枢，越容易同时累及邻近的脑干结构（复视、构音、共济），所以"伴随神经体征"是中枢的指纹。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 周围性眩晕 | 中枢性眩晕 |
|---|---|---|
| 眩晕性质 | 旋转性，剧烈 | 可不典型，较轻 |
| 自主神经症状 | 明显 | 可轻 |
| 眼震 | 水平/水平旋转，固视抑制 | 垂直/方向改变，固视不抑制 |
| 神经体征 | 无 | 复视、构音障碍、共济失调 |
| 听力 | 可伴耳鸣耳闷 | 多正常 |

<b>🚨 红线</b>：任何"眩晕 + 神经体征"都先按后循环卒中处理，不能直接诊断梅尼埃或 BPPV。

<b>🩺 下一步</b>：① 病史（时间轴、诱因、伴随）；② 眼震与神经查体；③ 位置试验；④ 有中枢体征急诊头颅影像。

#### 🔴 K-M02-017｜梅尼埃病的病理与机制（教师重点第26、28、31条｜P112、P114）

📌 重点原文（第26条）：梅尼埃病的病因、梅尼埃病的主要病理改变、及临床表现、诊断标准，眩晕的特点，诊断主要依靠翔实的病史、全面的检查和仔细的鉴别诊断，甘油试验阳性有助于对本病的诊断。（P114）

📌 重点原文（第28条）：梅尼埃病发生机制主要是内淋巴产生和吸收失衡，具体机制不明。主要学说有：内淋巴管机械阻塞与内淋巴吸收障碍、免疫反应学说、内耳缺血学说和其他学说，如内淋巴囊功能紊乱学说、病毒感染学说、遗传学说等。（P112）

📌 重点原文（第31条）：梅尼埃病的基本病理表现为膜迷路积水膨大，膜蜗管和球囊较椭圆囊和壶腹明显。膜半规管与内淋巴囊不膨大（P112）。

<b>🎯 一句话题眼</b>：膜迷路积水 = 梅尼埃的病理签名；病因是"内淋巴产生与吸收失衡"。

<b>🧬 为什么</b>：内淋巴在封闭的膜迷路内循环，产生多于吸收时压力升高，膜蜗管与球囊最先膨大，压迫毛细胞与神经纤维，于是出现波动性听力下降与眩晕。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 梅尼埃病 | BPPV | 前庭神经炎 |
|---|---|---|---|
| 病理 | 膜迷路积水 | 耳石碎屑进入半规管 | 前庭神经炎性损害 |
| 听力 | 波动性感音神经性 | 正常 | 多正常 |
| 眩晕时长 | 20 分钟–12 小时 | 不超过 1 分钟 | 数天 |

<b>🚨 红线</b>：首次发作、伴神经体征或进行性听力下降，先排中枢/桥小脑角病变。

<b>🩺 下一步</b>：① 纯音测听（波动性低-中频）；② 甘油试验辅助；③ 前庭功能与影像排除其他病因。

#### 🔴 K-M02-018｜梅尼埃病的临床表现（教师重点第29、30、119条｜P112）

📌 重点原文（第29条）：梅尼埃病的典型症状表现包括发作性眩晕，波动性、渐进性听力下降，耳鸣以及耳胀满感。患者神志清醒，眩晕持续短暂，多20分钟至数小时，通常2∼3小时转入缓解期，眩晕持续超过24小时者较少见。（P112）

📌 重点原文（第30条）：梅尼埃病的眩晕多呈突发旋转性，患者感到自身或周围物体沿一定的方向与平面旋转，或感摇晃、升降或漂浮。眩晕均伴有恶心、呕吐、面色苍白、出冷汗、脉搏迟缓、血压下降等自主神经反射症状。上述症状在睁眼转头时加剧，闭目静卧时减轻。患者神志清醒，眩晕持续短暂，多20分钟至数小时，通常2∼3小时转入缓解期，眩晕持续超过24小时者较少见。在缓解期可有不平衡或不稳感，可持续数天。眩晕常反复发作，复发次数越多，持续越长，间歇越短。（P112）

📌 重点原文（第119条）：椭圆囊斑和球囊斑感受直线加速度，半规管壶腹嵴感受角加速度；梅尼埃病眩晕通常持续20分钟至12小时并伴波动性听力改变；BPPV由头位改变诱发，通常不超过1分钟。

<b>🎯 一句话题眼</b>：20 分钟到数小时 + 波动性听力下降 + 耳鸣耳闷 = 梅尼埃四联征。

<b>🧬 为什么</b>：膜迷路积水使内淋巴压力波动，压力高时眩晕发作、听力下降；压力回落时听力回升，所以听力曲线呈"波动性"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 梅尼埃病 | 前庭神经炎 | 迷路炎 |
|---|---|---|---|
| 诱因 | 自发、反复 | 常有上感史 | 中耳炎/感染 |
| 听力 | 波动性下降 | 正常 | 可下降 |
| 时长 | 20 分钟–12 小时 | 数天 | 数天 |
| 复发 | 反复发作 | 多单次 | 依病因而定 |

<b>🚨 红线</b>：眩晕持续超过 24 小时或伴神经体征，不要按梅尼埃处理。

<b>🩺 下一步</b>：急性期前庭抑制剂 + 止吐；间歇期限盐、生活方式调整、必要时药物或手术；长期随访听力。

#### 🔴 K-M02-019｜良性阵发性位置性眩晕（教师重点第27、32、33、34条｜P116）

📌 重点原文（第27条）：良性阵发性位置性眩晕的病因、典型症状、检查、诊断依据，。为头位变化时突然出现短暂的（通常不超过1分钟）眩晕发作伴眼球震颤。眩晕多为旋转性，可伴恶心、呕吐等自主神经症状，但无耳鸣、耳闷和听力下降。

📌 重点原文（第32条）：手术中发现及颞骨组织病理学研究证实，BPPV患者半规管中或其壶腹嵴上存在游离的碳酸钙结晶或嗜碱性染色的沉着物（耳石碎屑）。但类似组织学改变在包括儿童在内的普通颞骨标本中也有发现，后半规管及外半规管的检出率高于前半规管。按受累的半规管不同，分为4种亚型：后半规管BPPV、外半规管BPPV、前半规管BPPV和混合型BPPV。后半规管BPPV最常见，约占90%，外半规管BPPV次之，前半规管BPPV极少。（P116）

📌 重点原文（第33条）：BPPV的诊断标准：（1）相对于重力方向改变头位后出现反复发作的、短暂的眩晕或头晕（通常持续不超过1分钟）。（2）位置试验中出现眩晕及特征性位置性眼震。（3）排除其他疾病，如前庭性偏头痛、前庭阵发症、中枢性位置性眩晕、梅尼埃病、前庭神经炎、迷路炎、前半规管裂综合征、后循环缺血、直立性低血压、心理精神源性眩晕等。（P116）

📌 重点原文（第34条）：约半数患者病因不明，属特发性BPPV。多见于老年人及女性，可能与年龄增长所致的耳石退化加速、吸收能力下降及耳石的稳定性降低等有关，激素水平改变、钙代谢紊乱及骨质疏松等也可能是易患因素。继发性BPPV继发于其他耳科或全身系统疾病。最常见的原因是头部外伤和前庭神经炎，其他有：梅尼埃病，突发性聋，中耳或内耳的感染和手术，长期卧床等。（P116）

<b>🎯 一句话题眼</b>：翻身/抬头诱发 + 不到 1 分钟 + 无听力下降 = BPPV；后半规管占 90%。

<b>🧬 为什么</b>：耳石从椭圆囊脱落，进入半规管成为游离碎屑；头位改变时碎屑移动带动内淋巴，壶腹嵴被"骗"出旋转信号，于是出现短暂眩晕与位置性眼震。

<b>🔗 机制链</b>：

```text
耳石脱落（退化/外伤/炎症）
        ↓
碎屑进入半规管
        ↓
头位改变 → 碎屑移动 → 内淋巴流动
        ↓
壶腹嵴受刺激 → 旋转性眩晕（<1 分钟）
        ↓
特征性位置性眼震
        ↓
复位后碎屑回椭圆囊 → 症状消失
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | BPPV | 梅尼埃病 | 中枢性位置性眩晕 |
|---|---|---|---|
| 诱因 | 头位改变 | 自发 | 头位改变 |
| 时长 | 不超过 1 分钟 | 20 分钟–12 小时 | 持续，可无潜伏期 |
| 听力 | 正常 | 波动性下降 | 多正常 |
| 眼震 | 短暂、疲劳性 | 自发眼震 | 垂直、方向改变、不疲劳 |
| 处理 | 手法复位 | 前庭抑制剂 | 查中枢病因 |

<b>🚨 红线</b>：出现垂直眼震、方向改变性眼震、伴神经体征，考虑中枢性位置性眩晕，不能复位了事。

<b>🩺 下一步</b>：① Dix-Hallpike（后半规管）/ 滚转试验（外半规管）；② 手法复位（Epley 等）；③ 复位无效或非典型时查影像。

<b>🔄 自测</b>：BPPV 的诊断标准三条是什么？后半规管 BPPV 用哪个试验？首选处理是什么？（答案见附录五）

#### 🔴 K-M02-020｜突发性聋（教师重点第125条）

📌 重点原文（第125条）：突发性聋应尽早进行听力学检查和专科评估，可在发病2周内考虑糖皮质激素初始治疗；初始治疗后恢复不完全者，可在发病2～6周评估鼓室内糖皮质激素挽救治疗。改善微循环药物并非所有患者的必需核心一线治疗。

<b>🎯 一句话题眼</b>：72 小时内单侧听力骤降 → 2 周内激素初始，2～6 周挽救。

<b>🧬 为什么</b>：内耳供血依赖终末动脉，栓塞或痉挛导致毛细胞缺氧。毛细胞不可再生，越早恢复灌注，挽救概率越高；超过窗口，损伤不可逆。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 突发性聋 | 梅尼埃病 | 听神经瘤 |
|---|---|---|---|
| 起病 | 数分钟–数小时达峰 | 反复发作 | 进行性 |
| 听力 | 单侧感音神经性 | 波动性低-中频 | 单侧进行性 |
| 伴随 | 耳鸣，可伴眩晕 | 耳闷、低频耳鸣、眩晕 | 耳鸣、不平衡感 |
| 关键检查 | 纯音测听、声导抗 | 甘油试验、听力学 | 增强 MRI |

<b>🚨 红线</b>：伴眩晕或神经体征 → 先排后循环卒中；双侧或进行性下降 → 查桥小脑角。

<b>🩺 下一步</b>：① 纯音测听 + 声导抗；② 2 周内糖皮质激素初始治疗；③ 恢复不完全者 2～6 周评估鼓室内挽救；④ 必要时 MRI。

<b>🔄 自测</b>：突发性聋激素初始治疗与挽救治疗的时间窗分别是多少？为什么越早越好？（答案见附录五）

#### 🟢 K-M02-021｜外耳道炎与外耳道疖（教材背景，不单列条号）

<b>🎯 一句话题眼</b>：牵拉耳廓/按压耳屏剧痛 → 外耳道炎/疖；疖多在外耳道软骨部。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 外耳道炎 | 外耳道疖 | 中耳炎 |
|---|---|---|---|
| 疼痛触发 | 牵拉耳廓加重 | 牵拉耳廓剧痛 | 不随牵拉明显变化 |
| 部位 | 外耳道弥漫 | 外耳道软骨部局限 | 鼓室 |
| 听力 | 多正常 | 多正常 | 传导性下降 |

<b>🚨 红线</b>：鼓膜穿孔或无法确认鼓膜完整时，避免耳毒性滴耳制剂。

<b>🩺 下一步</b>：保持干燥、清理分泌物、局部抗感染；疖成熟后切开引流。

## 模块3：鼻科学

> [!INFO] 模块信息
> <b>权重</b>：24%｜<b>预计题型</b>：判断 / A1 / A2 / A3/A4 / 多选 / 案例｜<b>卡片</b>：21 张
> <b>谱系位置</b>：鼻腔解剖 → 鼻腔炎症 → 鼻窦炎症 → 鼻息肉/肿瘤 → 鼻出血与眶颅并发症。
> <b>三个题眼</b>：① 利特尔区与鼻出血；② 鼻窦开口与 OMC；③ 变应性鼻炎 vs 血管运动性鼻炎 vs 萎缩性鼻炎。
> <b>阅读</b>：约 32 分钟

### 🧩 前置知识检查

- 鼻腔外侧壁有哪三个鼻甲、三个鼻道？
- 鼻窦分前组、后组，各自开口在哪里？

- 鼻腔的动脉血供来自哪两个系统？

> [!TIP] 复习入口
> 鼻科学的所有题目都能归到两句话：<b>"通不通"看鼻甲与鼻窦开口，"出不出血"看利特尔区与血管</b>。

### 🎯 30 秒摘要

1. 鼻阈是鼻前庭内界与最狭窄处；梨状孔是骨性入口；后鼻孔由四块骨围成。
2. 鼻甲自上而下缩小约 1/3、前端后移约 1/3；中鼻甲属筛骨。
3. 利特尔区是鼻出血最常见部位；鼻疖严禁挤压。
4. 前组鼻窦开口于中鼻道，后组筛窦开口于上鼻道，蝶窦开口于蝶筛隐窝。
5. 慢性鼻窦炎病程超过 12 周，鼻用糖皮质激素是一线首选，疗程不少于 12 周。

### 📋 考点卡

#### 🔴 K-M03-001｜鼻腔的三个"门"：鼻阈、梨状孔、后鼻孔（教师重点第38、46、47条｜P152、P159）

📌 重点原文（第38条）：在鼻前庭的皮肤和固有鼻腔黏膜交界处的外侧部分，相当于外侧鼻软骨外侧脚上缘有一弧形隆起，称为鼻阈。与鼻阈相对应的内侧鼻中隔和外下方的鼻腔底部也呈皱襞样隆起，共同构成鼻内孔，该区域为鼻前庭的内界和最狭窄处，对鼻的呼吸功能有重要影响。（P152）

📌 重点原文（第46条）：鼻骨下缘与上颌骨额突内侧缘及腭骨突起共同形成梨状孔。（P159）

📌 重点原文（第47条）：后鼻孔主要由蝶骨体（上）、蝶骨翼突内侧板（外）、腭骨水平部后缘（底）、犁骨的后缘（内）共同围成。（P159）

📌 重点原文（第108条）：鼻腔的核心解剖结构与生理功能。鼻腔主要分为覆有皮肤的鼻前庭（含毛囊、皮脂腺）和覆有黏膜的固有鼻腔。鼻中隔在成人中大多存在不同程度的偏曲，完全居中者少见。鼻窦根据其开口位置分为前组（开口于中鼻道）和后组（开口于上鼻道及蝶筛隐窝）。嗅区黏膜分布局限，位于上鼻甲内侧面及对应鼻中隔区域，是嗅觉产生的关键。鼻泪管开口于下鼻道，这一结构使得鼻腔炎症可能逆行引发泪囊炎。在生理功能方面，鼻周期是指两侧鼻腔阻力呈交替性变化，具有促进睡眠时翻身的生理意义。鼻腔的血液供应来源丰富，主要来自颈内动脉系统（眼动脉分支）和颈外动脉系统（上颌动脉分支）。鼻腔的加温、加湿和过滤功能主要由鼻腔黏膜（而非咽喉）完成，其中纤毛朝向鼻咽部的统一运动是实现鼻腔自洁和保护的重要机制。（P150）

<b>🎯 一句话题眼</b>：鼻阈 = 最窄处（鼻前庭内界）；梨状孔 = 骨性入口；后鼻孔 = 四骨围成。

<b>🧬 为什么</b>：鼻阈是鼻腔阻力最大的部位，也是鼻前庭与固有鼻腔的分界；后鼻孔是鼻腔与鼻咽的唯一通道，其骨性边界是鼻窦手术与鼻咽部操作的安全标志。

<b>⚖️ 鉴别</b>：

| 结构 | 构成 | 意义 |
|---|---|---|
| 鼻阈/鼻内孔 | 外侧鼻软骨外侧脚上缘 + 鼻中隔 + 鼻腔底 | 鼻前庭内界、最狭窄处 |
| 梨状孔 | 鼻骨下缘 + 上颌骨额突内侧缘 + 腭骨突起 | 鼻腔骨性入口 |
| 后鼻孔 | 蝶骨体、蝶骨翼突内侧板、腭骨水平部后缘、犁骨后缘 | 鼻腔通鼻咽 |

<b>🚨 红线</b>：后鼻孔的四个边界是高频填空，记错一个就整题失分；不要把"蝶骨翼突外侧板"写进去。

<b>🩺 下一步</b>：按"前—骨—后"三段记鼻腔入口，遇到鼻塞先判断阻塞层面（鼻阈/鼻甲/后鼻孔）。此外，鼻前庭含毛囊与皮脂腺，是鼻疖的好发处；鼻中隔在成人中大多存在不同程度偏曲，完全居中者少见。

#### 🔴 K-M03-002｜鼻甲、鼻道与中鼻甲（教师重点第36、43条｜P158、P160）

📌 重点原文（第36条）：鼻腔外侧壁从下向上有三个呈阶梯状排列的长条骨片，分别称为下、中、上鼻甲，其大小依次缩小约1/3，其前端的位置则依次后移约1/3。每一个鼻甲的下方与鼻腔外侧壁均形成一个裂隙状空间，分别称为下、中、上鼻道。（P158）

📌 重点原文（第43条）：中鼻甲属于筛骨结构，前段垂直向下，后段的游离缘逐渐外卷，几乎与鼻腔底平行。手术操作中应严格保持在中鼻甲外侧进行，可防止损伤筛板。（P160）

<b>🎯 一句话题眼</b>：三个鼻甲"越小越靠后"；中鼻甲是筛骨，手术走它外侧。

<b>🧬 为什么</b>：中鼻甲内侧附着于筛板（嗅裂顶），筛板上有嗅丝穿过；器械一旦越过中鼻甲内侧，就可能撕破筛板造成脑脊液鼻漏。

<b>⚖️ 鉴别</b>：

| 鼻道 | 开口结构 |
|---|---|
| 下鼻道 | 鼻泪管 |
| 中鼻道 | 额窦、上颌窦、前组筛窦 |
| 上鼻道 | 后组筛窦 |
| 蝶筛隐窝 | 蝶窦 |

<b>🚨 红线</b>：鼻内镜手术必须保持在中鼻甲外侧，防止损伤筛板。

<b>🩺 下一步</b>：先用"鼻甲—鼻道—开口"三层记解剖，再记手术安全边界。

#### 🔴 K-M03-003｜鼻中隔、利特尔区与鼻出血（教师重点第42、80、114条｜P156、P222）

📌 重点原文（第42条）：鼻腭动脉、筛前动脉、筛后动脉、上唇动脉和腭大动脉，在鼻中隔前下部的黏膜下交互吻合，形成动脉丛，称之为利特尔动脉丛，此区称为利特尔区（Little’s area），是临床上鼻出血最常见的部位。（P156）

📌 重点原文（第114条）：鼻中隔主要由鼻中隔软骨、筛骨垂直板和犁骨构成；鼻出血常见部位为利特尔区；鼻疖常见致病菌为金黄色葡萄球菌，严禁挤压。

📌 重点原文（第80条）：营养素或维生素C、K、P或Ca缺乏，均可能导致鼻出血；DSA或CTA、前鼻镜检查、鼻内镜检查、血常规等可以进行鼻出血评估的检查；长期、反复、少量出血的情况，应积极寻找病因；大量出血者，应先止血，再找病因；鼻腔后部的出血多源于动脉、出血较大，难以控制；情绪紧张者，可予以安慰、镇静；条件允许，可采用鼻内镜检查并止血；对于鼻出血的局部治疗，烧灼法、填塞法、血管结扎法及血管栓塞法均可能控制鼻出血；前鼻孔填塞是较常用的有效止血方法；适用于出血量大、出血位置不明确的患者；填塞时多采用口袋状进行填塞纱条；前鼻孔填塞后，可酌情使用抗生素；前鼻孔填塞纱条，一般不超过3～5天取出；后鼻孔填塞治疗，一般先行后鼻孔填塞，再联合前鼻孔填塞；多用于鼻腔后段、出血量较多的患者；后鼻孔填塞后，可酌情使用抗生素；老年患者行后鼻孔填塞，应评估心肺功能；后鼻孔填塞，最多5～6天取出。（P222）

<b>🎯 一句话题眼</b>：前鼻出血找利特尔区，后鼻出血想到蝶腭动脉；先止血，再找病因。

<b>🧬 为什么</b>：利特尔区是五条动脉的吻合丛，位置表浅、黏膜薄，受干燥空气与挖鼻刺激最易破裂；后鼻出血多来自蝶腭动脉分支，位置深、压力高，所以难止。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 前鼻出血 | 后鼻出血 |
|---|---|---|
| 来源 | 利特尔区 | 蝶腭动脉等分支 |
| 表现 | 血从前鼻孔流出 | 血流向咽部、可呕血 |
| 止血 | 指压、烧灼、前鼻孔填塞 | 后鼻孔填塞、血管结扎/栓塞 |
| 填塞取出 | 一般不超过 3～5 天 | 最多 5～6 天 |

<b>🚨 红线</b>：大量出血先止血再找病因；老年患者后鼻孔填塞要评估心肺功能；填塞后酌情用抗生素。

<b>🩺 下一步</b>：① 前鼻镜/鼻内镜定位；② 指压或烧灼；③ 前/后鼻孔填塞；④ 顽固者 DSA 栓塞或血管结扎；⑤ 查血常规、凝血、维生素。

#### 🔴 K-M03-004｜鼻腔黏膜、黏液纤毛系统与鼻周期（教师重点第35、48、115条｜P161、P162）

📌 重点原文（第35条）：正常人的鼻阻力呈昼夜及左右规律和交替变化，这种变化主要受双侧下鼻甲充血状态影响间隔2~7小时出现一个周期，称之为生理性的鼻周期。由于鼻周期的作用，一侧鼻腔病变引起持续性阻塞时，患者会主诉双侧间歇性鼻塞症状，且卧位时此种症状加重；故鼻病患者大多于夜间睡眠时鼻塞程度更加明显（P161）。37.鼻腔鼻窦黏膜大部分为假复层纤毛柱状上皮，表面约有250～300根纤毛，长度为5～10µm，直径0.3µm，每根纤毛朝鼻咽部摆动的频率是1000次/分。（P162）

📌 重点原文（第48条）：鼻前庭的鼻毛对空气中较大的粉尘颗粒及细菌有阻挡和过滤的作用。喷嚏反射可清除侵入鼻腔的粉尘和微小异物，鼻腔的清洁作用主要由鼻腔黏膜表面的黏液纤毛系统完成的。（P161）

📌 重点原文（第115条）：下鼻甲参与加温、加湿及调节鼻腔阻力；鼻腔黏液纤毛系统向鼻咽方向清除分泌物；鼻周期是两侧鼻腔通气程度的生理性周期变化。

<b>🎯 一句话题眼</b>：纤毛朝鼻咽方向摆、1000 次/分；鼻周期 2~7 小时一轮，所以夜间鼻塞更明显。

<b>🧬 为什么</b>：纤毛定向摆动把黏液毯推向鼻咽，形成"黏液纤毛清除"；鼻周期由下鼻甲充血交替驱动，卧位时静脉回流改变使充血加重，故夜间鼻塞明显。

<b>⚖️ 三道防线</b>：

| 防线 | 结构 | 作用 |
|---|---|---|
| 第一道 | 鼻前庭鼻毛 | 阻挡较大粉尘与细菌 |
| 第二道 | 喷嚏反射 | 清除粉尘与微小异物 |
| 第三道 | 黏液纤毛系统 | 黏附并定向清除颗粒与微生物 |

<b>🚨 红线</b>：纤毛摆动方向是"朝鼻咽部"，不是朝前鼻孔；方向写反即错。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 生理性鼻周期 | 慢性鼻炎鼻塞 |
|---|---|---|
| 诱因 | 生理性，交替出现 | 炎症、结构异常 |
| 持续时间 | 2~7 小时一周期 | 持续或间歇反复 |
| 伴随 | 无分泌物增多 | 鼻涕、鼻甲肥大 |
| 处理 | 无需治疗 | 针对病因治疗 |

<b>🩺 下一步</b>：遇到"夜间鼻塞加重"先想到鼻周期，不要直接诊断慢性鼻炎。

#### 🟡 K-M03-005｜嗅区黏膜（教师重点第49、51、52条｜P162、P163）

📌 重点原文（第49条）：嗅区黏膜主要感受嗅觉功能，嗅觉上皮主要由嗅细胞、支持细胞和基底细胞组成。（P162）

📌 重点原文（第51条）：嗅区黏膜分布在鼻腔顶中部、向下至鼻中隔上部及鼻腔外侧壁上部的嗅裂区域。（P163）

<b>🎯 一句话题眼</b>：嗅区在"顶中部 + 鼻中隔上部 + 外侧壁上部"；上皮是"无纤毛"的假复层柱状。

<b>🧬 为什么</b>：嗅区位置高、在鼻道气流的主路之外，所以气流要"到达嗅裂"才能闻到气味；鼻息肉、鼻甲肥大阻塞嗅裂是嗅觉下降的常见原因。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 嗅区黏膜 | 呼吸区黏膜 |

| 上皮 | 假复层无纤毛柱状 | 假复层纤毛柱状 |
| 位置 | 鼻腔顶、鼻中隔上部、外侧壁上部 | 鼻腔大部分 |
| 功能 | 嗅觉 | 加温、加湿、过滤 |

<b>🚨 红线</b>：不要把嗅区写成"有纤毛"；也不要把它写成只在上鼻甲。

<b>🩺 下一步</b>：嗅觉下降先查嗅裂是否被息肉/水肿阻塞，再考虑嗅神经病变。

#### 🟡 K-M03-006｜鼻腔血供、静脉与感染扩散（教师重点第39、54条｜P151、P157）

📌 重点原文（第39条）：鼻腔前部、后部和下部的静脉，最后汇入颈内、外静脉。鼻腔上部静脉经眼静脉汇入海绵窦，也可经筛静脉汇入颅内的静脉和硬脑膜窦。（P151）

📌 重点原文（第54条）：外鼻的静脉可经内眦静脉和面静脉汇入颈内静脉。内眦静脉可经眼上、眼下静脉而与海绵窦相通，静脉管内无瓣膜使血液可双向流动，故当鼻、面部感染和疖肿时，若治疗不当或用力挤压可能引发海绵窦栓塞或其他颅内并发症。（P157）

📌 重点原文（第37条）：鼻腔后2/3的淋巴汇入咽后淋巴结及颈深淋巴结上群。鼻部恶性肿瘤可循上述途径发生淋巴结转移。（P157）

<b>🎯 一句话题眼</b>：面部静脉无瓣膜 + 通海绵窦 → 鼻疖/面部感染严禁挤压。

<b>🧬 为什么</b>：内眦静脉与眼上、眼下静脉相通，眼静脉又汇入海绵窦；无瓣膜意味着血液可双向流，挤压把感染"推"进海绵窦。

<b>⚖️ 鉴别</b>：

| 区域 | 回流去向 | 风险 |
|---|---|---|
| 鼻腔前/后/下部 | 颈内、外静脉 | 一般 |
| 鼻腔上部 | 眼静脉 → 海绵窦 | 颅内并发症 |
| 外鼻 | 内眦静脉、面静脉 → 颈内静脉 | 挤压可致海绵窦栓塞 |
| 鼻腔后2/3 淋巴 | 咽后淋巴结、颈深淋巴结上群 | 鼻部恶性肿瘤淋巴转移途径 |

<b>🚨 红线</b>：鼻疖严禁挤压；出现眼睑肿胀、眼球运动异常、剧烈头痛，警惕海绵窦血栓性静脉炎。

<b>🩺 下一步</b>：鼻疖以局部治疗为主，出现眶内/颅内症状立即升级抗感染并影像评估。

#### 🟡 K-M03-007｜鼻腔的神经支配（教师重点第40、41、44条｜P158）

📌 重点原文（第40条）：交感神经来自颈内动脉交感神经丛组成的岩深神经，副交感神经来自面神经分出的岩浅大神经，两者在翼管组成翼管神经。分布于鼻腔，支配腺体分泌和血管舒缩。（P158）

📌 重点原文（第41条）：鼻腔的感觉神经来自三叉神经第一支 (眼神经)和三叉神经第二支(上颌神经)的分支。（P158）

📌 重点原文（第44条）：筛前神经和筛后神经是由三叉神经第一支眼神经的分支鼻睫神经发出的，与同名动脉伴行，筛前神经进入鼻腔后分为内侧支和外侧支，内侧支分布于鼻中隔上部，外侧支分布于鼻腔外侧壁上部及鼻外皮肤，筛后神经分布于鼻中隔和嗅区。（P158）

<b>🎯 一句话题眼</b>：感觉 = 三叉神经 V1 + V2；交感 = 岩深神经，副交感 = 岩浅大神经，二者合成翼管神经。

<b>🧬 为什么</b>：交感兴奋使血管收缩、腺体分泌减少；副交感兴奋使血管扩张、腺体分泌增多。变应性鼻炎的流涕、鼻塞正是副交感优势的表现。

<b>⚖️ 鉴别</b>：

| 神经 | 来源 | 功能 |
|---|---|---|
| 岩深神经（交感） | 颈内动脉交感丛 | 血管收缩、分泌减少 |
| 岩浅大神经（副交感） | 面神经 | 血管扩张、分泌增多 |
| 翼管神经 | 上述二者合成 | 支配鼻腔腺体与血管 |
| 筛前/筛后神经 | 三叉神经 V1 的鼻睫神经 | 鼻中隔上部、外侧壁上部、嗅区感觉 |

<b>🚨 红线</b>：翼管神经由交感与副交感"合成"，不是单一神经；感觉神经不要漏掉 V2。

<b>🩺 下一步</b>：过敏性鼻炎药物选择可回指此解剖（抗组胺、鼻用激素、减充血剂的靶点）。

#### 🔴 K-M03-008｜鼻窦开口与 OMC（教师重点第116条）

📌 重点原文（第116条）：OMC涉及上颌窦、前组筛窦及额窦的相关引流通道，不包括蝶窦自然开口；后组筛窦开口于上鼻道，蝶窦开口于蝶筛隐窝。

| 鼻窦 | 开口位置 |
|---|---|
| 上颌窦 | 中鼻道（筛漏斗） |
| 前组筛窦 | 中鼻道 |
| 额窦 | 中鼻道（额隐窝） |
| 后组筛窦 | 上鼻道 |
| 蝶窦 | 蝶筛隐窝 |

<b>🚨 红线</b>：OMC 不包括蝶窦自然开口——这是最容易设的干扰项。

#### 🟡 K-M03-009｜鼻窦与眼眶的解剖关系（教师重点第45、50条｜P159、P157）

📌 重点原文（第45条）：眼眶有上下内外四壁，除外壁其余三壁均为鼻窦环绕，后组筛窦的炎症可波及眼眶，引起眶内炎性并发症，严重可出现眶尖并发症。眶下壁前内缘近鼻泪管处有一浅凹，为下斜肌的起始部位，切忌损伤；7岁后鼻窦与眼眶关系基本发育成熟；眶内壁前方有泪囊窝，其前后界分别为泪前嵴及泪后嵴。（P159）

<b>🧬 为什么</b>：纸样板极薄，筛窦炎症最容易突破进入眶内；眶尖与视神经孔邻近后组筛窦、蝶窦，所以后组鼻窦炎可引起视力下降。

<b>⚖️ 鉴别</b>：

| 眶壁 | 相邻鼻窦 | 重要结构 |
|---|---|---|
| 上壁 | 额窦、前颅底 | 视神经孔、眶上裂 |

| 下壁 | 上颌窦 | 下斜肌起点、鼻泪管 |
| 外壁 | 无（不与鼻窦相邻） | — |

<b>🚨 红线</b>：眶内并发症出现视力下降、眼球活动受限，属危险信号，需急诊处理。

<b>🩺 下一步</b>：鼻窦炎伴眼睑红肿、眼球突出 → 增强 CT/MRI 评估眶内并发症。

#### 🟢 K-M03-010｜鼻肺反射（教师重点第53条｜P164）

📌 重点原文（第53条）：鼻肺反射是以鼻腔黏膜三叉神经末梢为传出支，以三叉神经及迷走神经核为其中枢核团，形成的反射弧。鼻部受到各种非特异性刺激后反射性地引起同侧支气管收缩，进而减少肺通气量。鼻肺反射是鼻腔局部刺激和病变引起支气管病变的原因之一。（P164）

<b>🧬 为什么</b>：鼻黏膜三叉神经末梢受刺激，经三叉神经核与迷走神经核整合，传出至支气管平滑肌，引起收缩。因此变应性鼻炎与哮喘常共存。

<b>🚨 红线</b>：不要把鼻肺反射的传入写成"迷走神经"；传入是鼻腔黏膜三叉神经末梢。

<b>🩺 下一步</b>：治疗鼻炎有助于控制合并的哮喘，需上下气道整体管理。

#### 🟡 K-M03-011｜鼻窦的解剖特点（教师重点第61条｜P191）

📌 重点原文（第55条）：鼻腔鼻窦的炎症，一般先发生在鼻腔，炎症扩散可伴发鼻窦炎症；可一侧发生，也可双侧；其中上颌窦炎症最为常见；鼻窦炎也可以单独孤立存在。（P189）

📌 重点原文（第61条）：鼻窦的特点有：窦口小，鼻道狭窄，易于阻塞；鼻腔黏膜炎症容易影响鼻窦黏膜；各鼻窦会互相累及；各鼻窦有自身引流特点；儿童亦可患有鼻窦炎。（P191）

<b>🎯 一句话题眼</b>：窦口小 + 鼻道窄 → 一肿就堵，一堵就炎，所以鼻窦炎常"成群"出现。

<b>🧬 为什么</b>：窦口是鼻窦唯一的通气引流通道，口径只有数毫米；黏膜轻微肿胀即可闭塞，形成负压与积液，进而继发感染。炎症一般先发生在鼻腔，扩散后伴发鼻窦炎；各窦之中上颌窦炎最常见，但鼻窦炎也可单独孤立存在。

<b>🚨 红线</b>：儿童也会患鼻窦炎，不要因为"年龄小"而排除。

<b>🩺 下一步</b>：治疗核心是"消肿 + 引流"，而不是单纯抗菌。

#### 🔴 K-M03-012｜急性鼻炎（教师重点第56、58、59、60条｜P189）

📌 重点原文（第56条）：病毒感染是急性鼻炎发生的首要因素，可继发细菌感染；急性鼻炎多通过呼吸道吸入病毒引起，全身性因素及局部因素等均可诱发。（P189）

📌 重点原文（第58条）：急性鼻炎向邻近组织扩散，可伴发急性鼻窦炎、急性中耳炎、急性咽炎、喉炎、急性气管、支气管炎等。（P189）

📌 重点原文（第59条）：需要和急性鼻炎相鉴别的疾病有流感、变应性鼻炎、血管运动性鼻炎、急性传染病等。（P189）

📌 重点原文（第60条）：对于急性鼻炎，对症支持治疗为主，预防并发症；可使用鼻用减充血剂、鼻用糖皮质激素；合并细菌感染时，可应用抗生素治疗。急性鼻炎亦可采用中医中药辅助治疗。（P189）

<b>🎯 一句话题眼</b>：病毒感染为主 → 对症支持；脓涕+发热才考虑继发细菌感染。

<b>🧬 为什么</b>：鼻黏膜病毒感染后纤毛功能下降、分泌物增多，若引流不畅，细菌在鼻窦内繁殖，于是"感冒"迁延成鼻窦炎。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 急性鼻炎 | 变应性鼻炎 | 流感 |
|---|---|---|---|
| 诱因 | 病毒感染 | 变应原 | 流感病毒 |
| 鼻涕 | 清水→黏脓 | 大量清水样 | 清涕，全身症状重 |
| 喷嚏 | 有，不剧烈 | 阵发性连续 | 有 |
| 发热 | 低热或无 | 无 | 高热、肌痛 |

<b>🚨 红线</b>：急性鼻炎以对症为主，不要一律上抗生素；出现耳痛、脓涕加重、高热提示并发症。

<b>🩺 下一步</b>：对症 + 鼻用减充血剂/鼻用激素；合并细菌感染时抗菌；警惕鼻窦炎、中耳炎。

#### 🔴 K-M03-013｜急性鼻窦炎（教师重点第57、62、63、64、65、66、68条｜P189、P191）

📌 重点原文（第57条）：急性鼻窦炎初期表现为鼻部症状，可伴有耳部症状，症状严重者可出现全身症状；检查可提示鼻黏膜充血肿胀，鼻腔可见分泌物，初期为水样，逐渐可变为黏性、黏脓性或脓性。（P189）

📌 重点原文（第62条）：急性鼻窦炎可能的局部因素是鼻腔疾病、邻近器官的感染、鼻窦外伤或异物、医源性感染以及气压改变。（P191）

📌 重点原文（第63条）：急性鼻窦炎多见于化脓性球菌、杆菌、厌氧菌等。（P191）

📌 重点原文（第64条）：急性鼻窦炎的临床表现可表现为局部症状，如鼻塞、脓性分泌物、头痛或局部疼痛、嗅觉减退；也可以表现为全身症状，如畏寒发热、恶心呕吐及消化道症状。（P191）

📌 重点原文（第65条）：急性后组筛窦炎的位置，与急性蝶窦炎相似，可表现为颅底或眼球深部钝痛。（P191）

📌 重点原文（第66条）：急性额窦炎，晨起后鼻腔分泌物流出，堵塞鼻额管，额窦腔内产生负压甚至真空，发生真空性头痛；中午以后，额窦内分泌物排空，疼痛逐渐缓解。（P191）

📌 重点原文（第68条）：急性鼻窦炎治疗原则：根除病因；解除鼻腔鼻窦引流和通气障碍；控制感染和预防并发症。（P191）

<b>🎯 一句话题眼</b>：额窦炎"晨起加重、午后缓解"；后组筛窦炎"颅底/眼球深部钝痛"。

<b>🧬 为什么</b>：额窦开口（鼻额管）细长，夜间平卧分泌物蓄积、窦内形成负压，故晨起剧痛；白天直立引流改善，午后缓解。这是位置决定症状的典型。

<b>⚖️ 鉴别</b>：

| 鼻窦 | 疼痛定位 | 时间规律 |
|---|---|---|
| 额窦 | 前额、眶上 | 晨起加重、午后缓解 |
| 上颌窦 | 面颊、上颌牙 | 低头加重 |
| 前组筛窦 | 鼻根、内眦 | 无明显规律 |
| 后组筛窦/蝶窦 | 颅底、眼球深部 | 钝痛，位置深 |

<b>🚨 红线</b>：急性鼻窦炎出现眼睑红肿、眼球突出、视力下降或剧烈头痛，提示眶内/颅内并发症。

<b>🩺 下一步</b>：① 鼻内镜 + 必要时 CT；② 鼻用激素 + 减充血剂 + 黏液促排；③ 细菌感染时抗菌；④ 有并发症影像评估并升级治疗。

#### 🔴 K-M03-015｜变应性鼻炎与色甘酸钠（教师重点第69、70、71条｜P196）

📌 重点原文（第69条）：变应性鼻炎属IgE介导的Ⅰ型变态反应。（P196）

📌 重点原文（第70条）：变应性鼻炎早发相症状发生于与变应原接触的数分钟内，主要由肥大细胞/嗜碱粒细胞脱颗粒释放的炎性介质引起。季节性变应原主要指木本类、禾本和草本类的风媒花粉。变应性鼻炎以鼻痒、阵发性连续喷嚏、大量水样鼻涕和鼻塞为临床主要特征，由于鼻黏膜水肿明显，部分患者尚有嗅觉减退。变应性鼻炎诊断主要依靠病史、典型的临床症状和体征以及特异性变应原检查。病史对于诊断非常重要，通过详尽地病史调查，如发病季节、时间、诱因、程度，生活和工作环境，家族及个人过敏史，有否哮喘、皮炎等，就可大致判定鼻炎症状是否为变应性。最后确诊病史须与特异性变应原检测结果相符。预防和治疗花粉症最有效的治疗方法是避免接触变应原（P196）

📌 重点原文（第71条）：色甘酸钠是色酮类药物，有稳定肥大细胞膜的作用，可阻止该细胞脱颗粒和释放介质，但起效时间多在1周以后，故仅适用于轻症变应性鼻炎患者或预防用药。（P196）

<b>🎯 一句话题眼</b>：鼻痒 + 连续喷嚏 + 大量清水涕 + 鼻塞 = 四联征；IgE 介导 I 型，早发相在数分钟内。

<b>🧬 为什么</b>：变应原交联肥大细胞表面 IgE，脱颗粒释放组胺等介质，数分钟内出现喷嚏、流涕；反复发作后黏膜水肿，出现鼻塞与嗅觉减退。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 变应性鼻炎 | 血管运动性鼻炎 | 急性鼻炎 |
|---|---|---|---|
| 机制 | IgE 介导 I 型 | 自主神经功能紊乱 | 病毒感染 |
| 鼻涕 | 大量清水样 | 清水样，遇冷加重 | 清水→黏脓 |
| 喷嚏 | 阵发性连续 | 有，不典型 | 有 |
| 变应原检测 | 阳性 | 阴性 | 阴性 |
| 发热 | 无 | 无 | 可有 |

<b>🚨 红线</b>：色甘酸钠起效多在 1 周以后，只适用于轻症或预防，不能当"急救药"。

<b>🩺 下一步</b>：① 病史 + 特异性变应原检测；② 避免接触变应原（最有效）；③ 鼻用激素/抗组胺；④ 轻症或预防可用色甘酸钠。

#### 🟡 K-M03-016｜血管运动性鼻炎（教师重点第72条｜P196）

📌 重点原文（第72条）：血管运动性鼻炎病因不明，精神紧张、焦虑，环境温度突然变化，内分泌功能紊乱，均可引起副交感神经递质释放过多，或者引起组胺的非特异性释放，血管扩张，腺体分泌增多，导致相应临床症状。长期使用血管收缩剂可引起药物性鼻炎。（P196）

<b>🎯 一句话题眼</b>：遇冷、情绪波动就流涕鼻塞，变应原检测阴性 → 血管运动性鼻炎。

<b>🧬 为什么</b>：不是 IgE 介导，而是副交感优势导致血管扩张、腺体分泌增多；长期用减充血剂会造成反跳性充血，形成药物性鼻炎。

<b>🚨 红线</b>：长期使用血管收缩剂可引起药物性鼻炎——这是高频陷阱。

<b>🩺 下一步</b>：避免诱因、鼻用激素；停用长期减充血剂。

#### 🔴 K-M03-017｜萎缩性鼻炎（教师重点第73、74条｜P199）

📌 重点原文（第73条）：萎缩性鼻炎的医源性原因是鼻腔组织特别是下鼻甲切除过多，导致鼻腔过分宽大，通气过度，下鼻甲黏膜下低温等离子射频消融术不会引起萎缩性鼻炎。萎缩性鼻炎的临床表现有①鼻及鼻咽部干燥感：鼻黏膜腺体萎缩，分泌减少，鼻内常有结痂，有时带血，甚至鼻出血。②鼻塞和嗅觉减退或失嗅：因鼻腔痂皮阻塞或因鼻黏膜萎缩，神经感觉迟钝，不能察觉气流通过，嗅区黏膜萎缩或被痂皮堵塞导致嗅觉减退甚至消失。③头痛、头昏：头痛多位于前额、颞侧或后枕部。④恶臭：多见于病情严重和晚期患者。呼气有特殊臭味，但由于嗅觉减退或丧失，患者自己不能闻到。⑤耳鸣、听力下降：病变波及咽鼓管引起咽鼓管功能障碍，出现分泌性中耳炎症状。⑥咽干、声嘶以及刺激性干咳，病变累及咽喉所致。〔源①原标号75〕

📌 重点原文（第74条）：萎缩性鼻炎鼻腔局部治疗可选择：生理盐水鼻腔冲洗；复方薄荷滴鼻剂、1%～3%链霉素液滴鼻、50%葡萄糖滴鼻等滴鼻，可润滑黏膜，软化干痂、抑制细菌生长和促进黏膜腺体分泌等作用。麻黄碱属血管收缩剂，萎缩性鼻炎应禁用。（P199）

<b>🎯 一句话题眼</b>：鼻腔宽大 + 干痂 + 恶臭 + 嗅觉减退 → 萎缩性鼻炎；麻黄碱禁用。

<b>🧬 为什么</b>：黏膜与腺体萎缩 → 分泌减少 → 干痂堆积 → 细菌分解产生臭味；同时鼻腔过宽、气流感觉迟钝，所以"通而不觉"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 萎缩性鼻炎 | 慢性肥厚性鼻炎 | 变应性鼻炎 |
|---|---|---|---|
| 鼻腔 | 宽大、干痂 | 鼻甲肥厚 | 黏膜水肿 |
| 鼻涕 | 干痂、可带血 | 黏脓 | 大量清水样 |
| 嗅觉 | 减退或失嗅 | 多正常 | 可减退 |
| 减充血剂 | 禁用 | 可短期用 | 可短期用 |

<b>🚨 红线</b>：麻黄碱属血管收缩剂，萎缩性鼻炎应禁用；下鼻甲切除过多是医源性原因。

<b>🩺 下一步</b>：生理盐水冲洗 + 润滑/软化干痂 + 抑制细菌；避免血管收缩剂。

#### 🔴 K-M03-018｜慢性鼻窦炎（教师重点第75、79、117条｜P201、P204）

📌 重点原文（第75条）：根据《中国慢性鼻窦炎诊断和治疗指南（2018）》，慢性鼻窦炎的定义是鼻窦黏膜的慢性炎性疾病，病程超过12周；根据《中国慢性鼻窦炎诊断和治疗指南（2018）》，推荐鼻用糖皮质激素作为慢性鼻窦炎的一线首选治疗药物，疗程不少于12周。鼻内镜手术已被临床实践证明为治疗鼻窦炎的有效方法；儿童慢性鼻窦炎患者的手术指征需严格把握，12岁以下原则不宜手术。（P201）

📌 重点原文（第79条）：鼻塞，黏性或黏脓性鼻涕为慢性鼻窦炎的主要症状；头面部胀痛，嗅觉减退或丧失为慢性鼻窦炎的次要症状；鼻痒，喷嚏，水样涕为过敏性鼻炎的典型症状，慢性鼻窦炎患者可同时伴有过敏性鼻炎；慢性鼻窦炎的诊断主要依据症状、查体和/或鼻窦CT进行。（P204）

📌 重点原文（第117条）：急性细菌性鼻窦炎应根据持续时间及病程变化判断；慢性鼻窦炎通常需症状至少12周并有客观证据；真菌球CT可见不规则高密度及钙化影。

<b>🎯 一句话题眼</b>：超过 12 周 + 鼻塞脓涕（主要）+ 头面胀痛/嗅觉减退（次要）→ 慢性鼻窦炎；鼻用激素疗程不少于 12 周。

<b>🧬 为什么</b>：窦口长期阻塞 → 缺氧、黏液滞留 → 黏膜慢性炎症与重塑；激素从源头抑制黏膜炎症与水肿，所以需要"长疗程"而非"见好就停"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 慢性鼻窦炎 | 变应性鼻炎 | 真菌球 |
|---|---|---|---|
| 主症状 | 鼻塞 + 黏脓涕 | 鼻痒 + 喷嚏 + 水样涕 | 单侧脓涕、可带血 |
| 病程 | 超过 12 周 | 季节性/常年 | 慢性、单侧 |
| CT | 窦腔浑浊、黏膜增厚 | 多正常 | 高密度影 + 钙化 |
| 治疗 | 鼻用激素 ≥12 周，必要时手术 | 避免变应原 + 鼻用激素 | 手术清除 |

<b>🚨 红线</b>：12 岁以下儿童原则上不宜手术；手术前必须有规范药物治疗失败的证据。

<b>🩺 下一步</b>：① 症状 + 鼻内镜 + 鼻窦 CT；② 鼻用糖皮质激素不少于 12 周；③ 必要时鼻腔冲洗、黏液促排；④ 药物失败考虑 FESS。

#### 🟡 K-M03-019｜鼻息肉与生物制剂（教师重点第76、78条｜P201、P204）

📌 重点原文（第76条）：以嗜酸性粒细胞浸润为主的鼻息肉由2型炎症反应介导，哮喘合并率高。 （P201）

📌 重点原文（第78条）：已有多个全球多中心随机对照临床研究证实使用针对IgE、IL-5和IL-4受体的单克隆抗体肌内注射可以显著缩小鼻息肉体积，缓解鼻塞、流涕等症状，改善嗅觉，提高生活质量。目前部分生物制剂已在欧美获得治疗难治性重度CRSwNP的适应证，使这部分患者免于承受反复手术或长期使用口服糖皮质激素的风险。（P204）

<b>🎯 一句话题眼</b>：嗜酸粒细胞浸润 + 2 型炎症 + 哮喘共病 → 难治性鼻息肉；生物制剂靶点 IgE、IL-5、IL-4 受体。

<b>🧬 为什么</b>：2 型炎症（IL-4/IL-5/IL-13）驱动嗜酸粒细胞浸润与黏膜水肿，所以激素与生物制剂有效，而单纯抗菌无效。

<b>🚨 红线</b>：生物制剂适用于"难治性重度 CRSwNP"，不是所有鼻息肉的一线。

<b>🩺 下一步</b>：鼻用激素为基础；反复手术/激素依赖者评估生物制剂；同时管理哮喘。

#### 🟡 K-M03-020｜功能性鼻内镜鼻窦手术（FESS）（教师重点第77条｜P204）

📌 重点原文（第77条）：功能性鼻内镜鼻窦手术（functional endoscopic sinus surgery，FESS），在鼻内镜和电视监视下，切除鼻息肉，开放鼻窦，纠正鼻中隔偏曲和泡状中鼻甲等鼻腔解剖学异常，尽可能保留鼻窦黏膜，重建鼻腔鼻窦通气引流，为鼻腔鼻窦黏膜炎症的良性转归创造条件。（P204）

<b>🎯 一句话题眼</b>：FESS 的关键词是"功能"——保留黏膜、重建引流，而不是"切干净"。

<b>🧬 为什么</b>：鼻窦黏膜有纤毛清除功能，切除过多黏膜等于永久破坏自洁能力；因此手术目标是恢复通气引流，让黏膜自己恢复。

<b>🚨 红线</b>：FESS 并发症包括眶周淤血、内直肌损伤、鼻泪管损伤、脑脊液鼻漏、视神经损伤及颈内动脉损伤。

<b>🩺 下一步</b>：规范药物失败 → 鼻窦 CT 评估 → FESS → 术后鼻腔冲洗与随访。

<b>🔄 自测</b>：FESS 的核心目标是什么？常见并发症有哪些？（答案见附录五）

#### 🟡 K-M03-021｜鼻疖（教师重点第114条，与 K-M03-003 互补）

📌 重点原文（第114条）：鼻中隔主要由鼻中隔软骨、筛骨垂直板和犁骨构成；鼻出血常见部位为利特尔区；鼻疖常见致病菌为金黄色葡萄球菌，严禁挤压。

<b>🎯 一句话题眼</b>：鼻前庭红肿热痛 + 金黄色葡萄球菌 → 鼻疖；一条铁律：严禁挤压。

<b>🚨 红线</b>：挤压可致海绵窦血栓性静脉炎；出现眼睑肿胀、眼球运动异常、剧烈头痛立即升级处理。

<b>🩺 下一步</b>：局部热敷/抗感染；成熟脓肿切开引流；警惕眶内与颅内并发症。

### 📋 考点卡

#### 🔴 K-M04-001｜咽的分部、喉咽与梨状窝（教师重点第81、109条｜P248）

📌 重点原文（第81条）：咽的底部约平第6颈椎；喉咽（laryngopharynx）的位置，喉咽又称下咽（hypopharynx），位于喉的后方。上界：舌骨上缘（约第3颈椎水平）。下界：环状软骨下缘、食管入口（约第6颈椎水平）。因此，其后壁平对第3～6颈椎；咽的肌层按其功能的不同分为3组,包括3对横行的咽缩肌、3对纵行的咽提肌和5组腭帆肌；梨状窝（piriform recess）是喉咽部的重要结构，位于喉咽的两侧。它是由喉入口（喉口）外侧的杓会厌襞和甲状软骨内面之间形成的一个浅窝。（P248）

📌 重点原文（第109条）：咽部的解剖与生理功能。咽部是呼吸与消化的共同通道，以软腭游离缘和会厌上缘为界，明确分为鼻咽、口咽和喉咽三部分。其结构特点与功能紧密相关：咽鼓管咽口位于鼻咽侧壁，平下鼻甲后端，通过吞咽、打哈欠时开放以平衡中耳压力；腭扁桃体位于口咽的扁桃体窝，表面隐窝易藏病菌导致发炎；它与腺样体（咽扁桃体）等共同构成咽淋巴环，形成上呼吸道的重要免疫防线。咽部的肌肉均为横纹肌，包括缩小咽腔的咽缩肌和上提喉体的咽提肌，它们在吞咽时与软腭、会厌协同运动，确保食物顺利进入食管而防止误入气管或反流鼻腔。在临床方面，儿童腺样体增生是引起鼻塞、打鼾和分泌性中耳炎的常见原因；而喉咽部的梨状隐窝则是异物易滞留和肿瘤的好发部位。咽部的血液供应主要来自颈外动脉分支，静脉则回流至颈内静脉。（P248）

<b>🎯 一句话题眼</b>：软腭游离缘分鼻咽/口咽，会厌上缘分口咽/喉咽；梨状窝是异物与肿瘤的"死角"。

<b>🧬 为什么</b>：梨状窝是喉入口两侧的浅窝，位置低、口径小，鱼刺等异物容易嵌顿；其黏膜下有喉上神经内支通过，异物损伤可引起感觉异常，肿瘤也常在此起病。

<b>⚖️ 鉴别</b>：

| 分部 | 上界 | 下界 | 关键结构 |
|---|---|---|---|
| 鼻咽 | 颅底 | 软腭游离缘 | 咽鼓管咽口、咽隐窝、咽扁桃体 |
| 口咽 | 软腭游离缘 | 会厌上缘 | 腭扁桃体、舌根 |
| 喉咽 | 会厌上缘 | 环状软骨下缘（约第6颈椎） | 梨状窝、环后区 |

<b>🚨 红线</b>：喉咽后壁平对第 3～6 颈椎，不是"第 6 颈椎以上都算喉咽"；上界在舌骨上缘（约第 3 颈椎）。

<b>🩺 下一步</b>：遇到异物或肿瘤定位，先判断在鼻咽、口咽还是喉咽，再选检查（鼻内镜/电子喉镜）。

<b>🔄 自测</b>：咽的三部分以什么为界？喉咽的上、下界分别在哪里？梨状窝位于何处？（答案见附录五）

#### 🟡 K-M04-002｜咽肌与吞咽（教师重点第81、109条）

📌 重点原文（第81条）：咽的肌层按其功能的不同分为3组,包括3对横行的咽缩肌、3对纵行的咽提肌和5组腭帆肌（P248）

<b>🎯 一句话题眼</b>：咽缩肌 3 对"往下压"，咽提肌 3 对"往上提"，腭帆肌 5 组"关鼻咽"。

<b>🧬 为什么</b>：吞咽是一串精确的时序动作：软腭上提封闭鼻咽 → 咽缩肌依次收缩 → 喉上提、会厌下翻封闭喉口 → 食物进入食管。任何一环失调都会出现鼻反流或误吸。

<b>⚖️ 鉴别</b>：

| 肌群 | 数量 | 功能 |
|---|---|---|
| 咽缩肌 | 3 对（上、中、下） | 缩小咽腔，推进食团 |
| 咽提肌 | 3 对（茎突咽肌、腭咽肌、咽鼓管咽肌） | 上提喉体与咽 |
| 腭帆肌 | 5 组 | 腭咽闭合，防鼻反流 |

<b>🚨 红线</b>：吞咽时软腭必须向后上方抬起完成腭咽闭合，否则食物反流至鼻咽。

<b>🩺 下一步</b>：出现鼻反流、误吸，评估软腭功能与咽肌协调（神经系统查体 + 吞咽评估）。

#### 🔴 K-M04-003｜咽旁间隙的四大神经（教师重点第82条｜P251）

📌 重点原文（第82条）：咽旁间隙四大神经"口诀: "舌舌副迷走"即：舌咽神经、舌下神经、副神经、迷走神经。 临床提示：咽旁脓肿或肿瘤压迫该间隙，可能出现吞咽困难、发音障碍、舌偏斜、肩耸力减弱等神经症状。（P251）

<b>🎯 一句话题眼</b>："舌舌副迷走"——舌咽、舌下、副、迷走；舌偏斜 = 舌下神经，肩耸无力 = 副神经。

<b>🧬 为什么</b>：四对脑神经在咽旁间隙内密集走行，占位病变压迫时按"受累神经"就能反推病变位置，这是典型的定位诊断题。

<b>⚖️ 鉴别</b>：

| 神经 | 受累表现 |
|---|---|
| 舌咽神经 | 吞咽困难、咽反射减弱 |
| 舌下神经 | 伸舌偏向患侧 |
| 副神经 | 肩耸力减弱、转颈无力 |
| 迷走神经 | 发音障碍、声带麻痹 |

<b>🚨 红线</b>：咽旁间隙感染可向下蔓延至纵隔，出现呼吸困难、颈部肿胀需紧急处理。

<b>🩺 下一步</b>：① 神经查体定位；② 增强 CT/MRI 评估咽旁间隙；③ 脓肿需引流。

#### 🔴 K-M04-004｜咽淋巴环（教师重点第83条｜P251）

📌 重点原文（第83条）：咽淋巴环是上呼吸道免疫防线，参与病原体识别与免疫应答;"上咽鼓，两侧腭，下舌旁"（上：咽扁桃体；咽鼓管旁：咽鼓管扁桃体；两侧：腭扁桃体；下：舌扁桃体；旁：咽侧索）（P251）

<b>🎯 一句话题眼</b>："上咽鼓，两侧腭，下舌旁"——五组淋巴组织围成一环。

<b>🧬 为什么</b>：咽是呼吸与消化的共同入口，淋巴组织环形分布可在病原体进入的第一站完成识别与免疫应答；儿童期淋巴组织增生旺盛，故腺样体、扁桃体肥大常见。

<b>⚖️ 组成</b>：

| 位置 | 淋巴组织 |
|---|---|
| 上 | 咽扁桃体（腺样体） |
| 咽鼓管旁 | 咽鼓管扁桃体 |
| 两侧 | 腭扁桃体 |
| 下 | 舌扁桃体 |
| 旁 | 咽侧索 |

<b>🚨 红线</b>：咽淋巴环是"内环"，不包括颈部淋巴结（外环）；答题时不要混。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 内环（咽淋巴环） | 外环（颈部淋巴结） |
|---|---|---|
| 位置 | 咽黏膜下 | 颈部筋膜间隙 |
| 组成 | 咽扁桃体、咽鼓管扁桃体、腭扁桃体、舌扁桃体、咽侧索 | 颈深上/下、颈后三角等淋巴结群 |
| 引流 | 汇入外环 | 汇入胸导管/右淋巴导管 |
| 临床 | 儿童增生致鼻塞、打鼾 | 转移癌、淋巴瘤 |

<b>🩺 下一步</b>：反复咽痛/扁桃体炎评估咽淋巴环增生程度与手术指征。

#### 🔴 K-M04-006｜急性扁桃体炎（教师重点第85条｜P260）

📌 重点原文（第85条）：乙型溶血性链球菌为急性扁桃体炎的主要致病菌，非溶血性链球菌、葡萄球菌、肺炎链球菌、流感嗜血杆菌或腺病毒、鼻病毒、单纯性疱疹病毒等也可引起本病；抗生素应用为急性扁桃体炎主要治疗方法，首选青霉素。（P260）

<b>🧬 为什么</b>：乙型溶血性链球菌的 M 蛋白抗吞噬，易引起化脓性炎症；青霉素抑制细胞壁合成，对链球菌敏感，故为首选。

| 张口 | 正常 | 受限 | 正常 |
| 扁桃体 | 充血肿大 | 单侧膨隆、悬雍垂偏健侧 | 有假膜 |
| 用药 | 青霉素 | 抗感染 + 引流 | 对症 |

<b>🚨 红线</b>：出现张口受限、言语含糊"口含汤圆音"、单侧膨隆，提示扁桃体周围脓肿，需引流。

<b>🩺 下一步</b>：① 咽部检查 + 血常规；② 青霉素为首选；③ 反复发作评估手术指征。

#### 🟡 K-M04-007｜慢性扁桃体炎（教师重点第86条｜P262）

📌 重点原文（第86条）：慢性扁桃体炎多由急性扁桃体炎反复发作或因扁桃体隐窝引流不畅，窝内细菌、病毒滋生感染而演变为慢性炎症。链球菌和葡萄球菌为本病的主要致病菌；扁桃体切除术后并发症包括出血、伤口感染和肺部并发症。（P262）

<b>🩺 下一步</b>：反复发作（每年多次）、影响生活或并发风湿热/肾炎者评估扁桃体切除。

#### 🔴 K-M04-008｜腺样体肥大（教师重点第87条｜P266）

📌 重点原文（第87条）：腺样体位于鼻咽部的后壁和顶部，为咽淋巴环的内环组成部分。出生时即存在，2～6岁是增生旺盛时期，为腺样体的生理性肥大期，10岁以后逐渐萎缩，成人则大部分消失。腺样体肥大导致长期张口呼吸，可影响面容颌骨发育，形成"腺样体面容"；腺样体出生时即存在，2～6岁是增生旺盛时期，为腺样体的生理性肥大期，10岁以后逐渐萎缩;腺样体肥大常并发鼻炎、鼻窦炎，有鼻塞及流鼻涕等症状。说话时呈闭塞性鼻音，睡眠时发出鼾声、张口呼吸。严重者可引起阻塞性睡眠呼吸暂停低通气综合征;分为四度：Ⅰ度：腺样体阻塞鼻后孔≤25%；Ⅱ度：腺样体阻塞鼻后孔26%～50%；Ⅲ度：腺样体阻塞鼻后孔51%～75%；Ⅳ度：腺样体阻塞鼻后孔>75%；若保守治疗无效，应尽早经口或鼻内镜行腺样体切除术。手术前应仔细检查，排除禁忌证。手术常同扁桃体切除术一并施行，若扁桃体无明确的手术适应证，可单独切除腺样体。（P266）

| 分度 | 阻塞鼻后孔 |
|---|---|
| Ⅰ度 | ≤25% |
| Ⅱ度 | 26%～50% |
| Ⅲ度 | 51%～75% |
| Ⅳ度 | >75% |

<b>🚨 红线</b>：严重者可致阻塞性睡眠呼吸暂停低通气综合征；手术前须排除禁忌证。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 腺样体肥大 | 鼻咽纤维血管瘤 | 后鼻孔闭锁 |

| 人群 | 儿童 2～6 岁 | 青少年男性 | 新生儿/婴幼儿 |

| 鼻塞特点 | 双侧、渐进 | 单侧或双侧、进行性 | 单侧或双侧、持续性 |

#### 🔴 K-M04-010｜鼻咽纤维血管瘤（教师重点第89条｜P277）

📌 重点原文（第89条）：鼻咽纤维血管瘤是一种血管丰富、纤维成分多的良性肿瘤，但生长迅速，局部有侵袭性。典型人群：青少年男性（10～25岁）主要症状：鼻出血、鼻塞;治疗：手术切除，必要时术前血管栓塞;生长特点：良性但局部侵袭性，易累及蝶骨、鼻腔和颅底。主要血供来自颈外动脉系统，尤其是上颌动脉（maxillary artery）及其分支。 肿瘤生长迅速，周围还可能有来自面动脉、蝶腭动脉、腭大动脉、枕动脉等的辅助血供，但上颌动脉是最主要来源。（P277）

<b>🎯 一句话题眼</b>：青少年男性 + 反复鼻出血 + 鼻塞 → 鼻咽纤维血管瘤；血供主要来自上颌动脉。

<b>🧬 为什么</b>：肿瘤血管丰富且缺乏收缩能力，所以出血量大、反复；虽为良性却沿自然间隙侵袭蝶骨、鼻腔与颅底，故术前常需栓塞减少出血。

|---|---|---|---|
| 人群 | 青少年男性 | 中老年 | 儿童 |
| 表现 | 反复鼻出血、鼻塞 | 回吸性血涕、颈部肿块 | 鼻塞、打鼾 |
| 质地 | 血管性、易出血 | 溃疡性肿物 | 淋巴组织 |
| 禁忌 | 活检易大出血 | 需活检确诊 | 无需活检 |

<b>🚨 红线</b>：怀疑鼻咽纤维血管瘤时不要盲目活检，以免大出血；必须先做影像评估。

<b>🩺 下一步</b>：① 鼻内镜 + 增强 CT/MRI；② 血管造影评估血供；③ 术前栓塞 + 手术切除。

#### 🟡 K-M04-012｜喉咽恶性肿瘤（教师重点第91条｜P282）

📌 重点原文（第91条）：喉咽恶性肿瘤（hypopharyngeal carcinoma）是喉咽部的恶性肿瘤，约占咽喉恶性肿瘤的5%-10%。病理类型：以鳞状细胞癌为主。部位分类：梨状窝型（piriform recess type）；环状软骨后区型（postcricoid type）；喉咽后壁型（posterior wall type） 早期症状特点：喉咽肿瘤早期常无明显症状，容易被忽视，导致就诊时多为中晚期。常见晚期症状：吞咽困难（单侧或双侧），颈部淋巴结肿大，声音嘶哑（部分病例），咽痛较轻或不明显。（P282）

#### 🔴 K-M04-013｜鼻咽癌（教师重点第118条）

📌 重点原文（第118条）：鼻咽癌好发于咽隐窝，与EB病毒密切相关，确诊依靠组织病理；单侧分泌性中耳炎需关注鼻咽部病变。

## 模块5：喉科学

> [!INFO] 模块信息
> <b>权重</b>：14%｜<b>预计题型</b>：判断 / A1 / A2 / A3/A4 / 多选｜<b>卡片</b>：15 张
> <b>谱系位置</b>：喉软骨支架 → 喉腔分部 → 喉内肌与神经 → 炎症 → 声带良性病变 → 喉阻塞 → 喉癌。
> <b>三个题眼</b>：① 环状软骨是唯一完整环形软骨；② 喉阻塞四度与气管切开时机；③ 声带小结在前中 1/3 交界处。
> <b>阅读</b>：约 26 分钟

### 🧩 前置知识检查

- 喉的软骨支架由哪些软骨构成？哪一块是完整环形？
- 喉腔分哪三部分？最狭窄处在哪里？
- 哪块肌肉负责声带外展？哪块负责内收？
- 喉上神经内支、外支与喉返神经各支配什么？
- 喉的淋巴以什么为界分区？

> [!TIP] 复习入口
> 喉科学有两条主线：<b>"发音"看声带与喉内肌，"呼吸"看喉阻塞分度与气道处理</b>。把这两条分开记，不会互相干扰。

### 🎯 30 秒摘要

1. 环状软骨是喉气管中唯一完整的环形软骨，损伤易致喉气管狭窄。
2. 声门区是喉腔最狭窄处；环杓后肌外展，环杓侧肌与杓肌内收。
3. 喉淋巴以声门区为界分两组，声门上区淋巴最丰富。
4. 喉阻塞分四度：Ⅰ度活动后、Ⅱ度安静时、Ⅲ度缺氧体征、Ⅳ度衰竭。
5. 喉癌最常见声门型（约占 60%），病理以鳞状细胞癌为主。

### 📋 考点卡

#### 🔴 K-M05-001｜喉的软骨支架（教师重点第92、120条｜P290）

📌 重点原文（第92条）：环状软骨是喉气管中唯一完整的环形软骨，对保持喉气管的通畅至关重要。如果外伤或疾病引起环状软骨损伤，常可引起喉及气管狭窄，两侧声带之间的区域称为声门区，为喉腔中最狭窄的部位。（P290）

📌 重点原文（第120条）：声带小结常位于声带前、中1/3交界处；环状软骨是喉部唯一完整环形软骨；喉返神经支配除环甲肌外的大多数喉内肌。

<b>🎯 一句话题眼</b>：唯一完整环形 = 环状软骨；唯一"例外" = 环甲肌由喉上神经外支支配。

<b>🧬 为什么</b>：环状软骨是喉与气管的"地基"，一旦骨折塌陷，整个气道支架失去支撑，愈合后易形成瘢痕狭窄。

<b>⚖️ 鉴别</b>：

| 软骨 | 形态 | 关键点 |
|---|---|---|
| 甲状软骨 | 最大，前方成喉结 | 不成环 |
| 环状软骨 | 唯一完整环形 | 损伤易致狭窄 |
| 会厌软骨 | 叶片状 | 吞咽时封闭喉口 |
| 杓状软骨 | 成对 | 声带突连声带，肌突附喉内肌 |

<b>🚨 红线</b>：环状软骨损伤常引起喉及气管狭窄，处理不当可终身带管。

<b>🩺 下一步</b>：外伤后评估气道通畅度，必要时气管切开；后期狭窄需重建。

<b>🔄 自测</b>：为什么环状软骨损伤容易导致喉气管狭窄？喉返神经支配哪些喉内肌？哪块例外？（答案见附录五）

#### 🔴 K-M05-002｜喉腔分部与声门区（教师重点第92、109条｜P290）

📌 重点原文（第109条）：喉部解剖与生理的解析内容。喉部是呼吸、发音和保护气道的核心器官。其软骨支架中，环状软骨是唯一完整的环形软骨，对维持喉腔通畅至关重要。喉腔分为声门上区、声门区和声门下区三部分，其中声门裂是喉腔最狭窄的部位。声带是发音的核心结构，由声韧带、声带肌和黏膜构成。其运动由喉内肌群精细调控（负责声带张弛、开合），而喉外肌群则负责喉体的整体运动。喉的呼吸保护功能通过声门的开放（呼吸时）与闭合（发音、吞咽时）来实现。在神经支配上，喉上神经内支司声门上区感觉，该区域感觉敏锐；喉返神经司声门下区感觉及喉内肌运动。血液供应主要来自甲状腺上动脉的喉上动脉和甲状腺下动脉的喉下动脉（喉返动脉）。最后，音调的高低主要由声带长度决定（男性长、声调低；女性短、声调高），并通过声带的张力与振动频率进行调节。（P290）

<b>🎯 一句话题眼</b>：声门上区、声门区、声门下区；声门裂最窄，也是异物与肿瘤的"关口"。

<b>🧬 为什么</b>：声门裂是气道最窄处，成人约 8–10 mm；喉阻塞时气流在此形成涡流产生喉鸣，也是气管插管最需通过的部位。

<b>⚖️ 鉴别</b>：

| 分区 | 范围 | 特点 |
|---|---|---|
| 声门上区 | 喉入口至室带 | 淋巴丰富，肿瘤易淋巴结转移 |
| 声门区 | 声带与声门裂 | 最狭窄，肿瘤易早期声嘶 |
| 声门下区 | 声带下缘至环状软骨下缘 | 淋巴少，早期症状隐蔽 |

<b>🚨 红线</b>：声门裂是喉腔最狭窄处，不是"声门下区"。

<b>🩺 下一步</b>：声嘶超过 2 周 → 喉镜检查；吸气性呼吸困难 → 按喉阻塞分度处理。

<b>🔄 自测</b>：喉腔分哪三部分？最狭窄的部位是哪里？（答案见附录五）

#### 🔴 K-M05-003｜喉内肌的功能分组（教师重点第93条｜P290）

📌 重点原文（第93条）：环杓后肌是声带外展肌，环杓侧肌和杓肌是声带内收肌，环甲肌和甲杓肌是声带张力肌，杓会厌肌使会厌活动；会厌可分为舌面和喉面，舌面组织疏松，感染时容易出现肿胀。（P290）

<b>🎯 一句话题眼</b>：外展只有一块（环杓后肌），内收有两块，张力有两块。

<b>🧬 为什么</b>：外展肌只有一块，所以双侧喉返神经损伤时外展功能先丧失、声带居中间位，出现严重呼吸困难；这是"为什么双侧麻痹更危险"的解剖基础。

<b>⚖️ 功能表</b>：

| 肌 | 功能 |
|---|---|
| 环杓后肌 | 声带外展（唯一） |
| 环杓侧肌、杓肌 | 声带内收 |
| 环甲肌、甲杓肌 | 调节声带张力 |
| 杓会厌肌 | 使会厌活动 |

<b>🚨 红线</b>：外展肌只有环杓后肌一块，双侧损伤可致窒息。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 外展肌 | 内收肌 | 张力肌 |
|---|---|---|---|
| 代表肌 | 环杓后肌 | 环杓侧肌、杓肌 | 环甲肌、甲杓肌 |
| 作用 | 开大声门 | 闭合声门 | 调节音调 |
| 损伤后果 | 呼吸困难（最危险） | 声门闭合不全、气息声 | 音域变窄、高音困难 |

<b>🩺 下一步</b>：声带麻痹先定位（喉返神经/喉上神经外支/中枢），再评估气道。

<b>🔄 自测</b>：哪块肌肉是唯一的声带外展肌？双侧喉返神经损伤为什么危险？（答案见附录五）

#### 🟡 K-M05-004｜会厌的解剖与临床（教师重点第93条）

📌 重点原文（第93条）：会厌可分为舌面和喉面，舌面组织疏松，感染时容易出现肿胀。（P290）

<b>🎯 一句话题眼</b>：会厌舌面组织疏松 → 感染时肿胀快 → 急性会厌炎可迅速窒息。

<b>🧬 为什么</b>：疏松结缔组织含水量大、间隙宽，炎症渗出后体积迅速增大；会厌又位于喉入口，肿胀直接封闭气道。

<b>🚨 红线</b>：急性会厌炎是耳鼻喉科最凶险的急症之一，必须优先评估气道。

<b>🩺 下一步</b>：怀疑急性会厌炎 → 立即备好气道（气管插管/切开）→ 再行喉镜检查。

#### 🟡 K-M05-005｜喉的淋巴分区（教师重点第94条｜P295）

📌 重点原文（第94条）：喉的淋巴以声门区为界，分为声门上区组和声门下区组，声门上区的淋巴管最为丰富。（P295）

<b>🎯 一句话题眼</b>：以声门区为界分两组；声门上区淋巴最丰富 → 声门上癌易淋巴结转移。

<b>🧬 为什么</b>：声门上区淋巴管密集并引流至颈深上淋巴结，所以声门上癌早期就可能出现颈部肿块；声门区淋巴少，声门型癌早期以声嘶为主、转移晚。

<b>⚖️ 鉴别</b>：

| 分区 | 淋巴丰富度 | 转移特点 |
|---|---|---|
| 声门上区 | 最丰富 | 早期即可颈淋巴结转移 |
| 声门区 | 少 | 转移晚 |
| 声门下区 | 少 | 可有气管前/喉前淋巴结转移 |

<b>🚨 红线</b>：声门上癌早期症状不典型，不能因"没有声嘶"而排除喉癌。

<b>🩺 下一步</b>：声门上占位要同时评估颈部淋巴结（触诊 + 超声/CT）。

#### 🟡 K-M05-006｜喉的神经与血供（教师重点第109条｜P290）

📌 重点原文（第109条）：在神经支配上，喉上神经内支司声门上区感觉，该区域感觉敏锐；喉返神经司声门下区感觉及喉内肌运动。血液供应主要来自甲状腺上动脉的喉上动脉和甲状腺下动脉的喉下动脉（喉返动脉）。（P290）

<b>🎯 一句话题眼</b>：喉上神经内支管"声门上感觉"，外支管环甲肌，喉返神经管其余喉内肌 + 声门下感觉。

<b>🧬 为什么</b>：喉上神经内支穿甲状舌骨膜入喉，位置表浅，是喉部手术与外伤最易损伤的感觉支；损伤后声门上感觉丧失，易误吸。

<b>⚖️ 鉴别</b>：

| 神经 | 支配 | 损伤表现 |
|---|---|---|
| 喉上神经内支 | 声门上区感觉 | 误吸、呛咳 |
| 喉上神经外支 | 环甲肌 | 高音困难、声音耐力下降 |
| 喉返神经 | 除环甲肌外喉内肌 + 声门下感觉 | 声嘶，双侧可致呼吸困难 |

<b>🚨 红线</b>：甲状腺手术需保护喉返神经与喉上神经外支；双侧喉返神经损伤可致窒息。

<b>🩺 下一步</b>：术后声嘶评估声带运动；误吸评估声门上感觉。

#### 🔴 K-M05-007｜喉阻塞的分度（教师重点第95、110条｜P339、P340）

📌 重点原文（第95条）：喉阻塞根据患儿呼吸困难程度不同分为四度。（P339）——Ⅰ度：安静时无症状，活动后出现吸气性呼吸困难，以病因治疗为主；Ⅱ度：安静时即有吸气性呼吸困难及喉鸣，需严密观察并积极病因治疗；Ⅲ度：安静时明显呼吸困难，伴烦躁、发绀及三凹征，病因无法迅速解除时需立即行气管切开术；Ⅳ度：极度呼吸困难、严重发绀、意识障碍或濒死状态，必须紧急开放气道。

📌 重点原文（第110条）：喉阻塞与气管切开术。喉阻塞的常见病因包括急性喉炎、喉异物、喉肿瘤及喉外伤等，其中儿童因喉腔狭小、黏膜下组织疏松，急性喉炎时更易发生喉阻塞。其典型表现为吸气性呼吸困难（吸气时间延长、费力，呼气正常），严重时出现"三凹征"（胸骨上窝、锁骨上窝、肋间隙凹陷），若进展为"四凹征"则提示病情危重（Ⅳ度）。喉阻塞的临床分度是指导治疗的关键：Ⅰ度于安静时无症状，仅活动后出现，以病因治疗为主；Ⅱ度在安静时即有症状，需严密观察并积极病因治疗；Ⅲ度则表现为安静时明显呼吸困难，伴烦躁、发绀，若病因无法迅速解除，需立即行气管切开术；而Ⅳ度患者已出现呼吸衰竭征象，必须紧急开放气道（如        异物。气管切开术的常规部位位于第3-4气管软骨环之间，其适应证涵盖Ⅱ-Ⅳ度喉阻塞、下呼吸道分泌物潴留、某些头颈手术的术前准备以及需长期机械通气的患者。术后需加强护理，包括定期吸痰、保持套管通畅等。术后并发症如皮下气肿通常可自行吸收，但需警惕气胸、纵隔气肿及大出血（如损伤无名动脉）等严重并发症。拔管前需遵循规范流程，通常需更换为带气囊的套管并逐步试行堵管，确认呼吸平稳后方可拔管。（P340）

<b>🎯 一句话题眼</b>：Ⅰ度活动后、Ⅱ度安静时、Ⅲ度缺氧体征（三凹征）、Ⅳ度衰竭——Ⅲ度切开、Ⅳ度紧急开放气道。

<b>🧬 为什么</b>：喉阻塞是"吸气性"梗阻，吸气时胸内负压增大，把胸骨上窝、锁骨上窝、肋间隙"吸"进去形成三凹征；梗阻越重，负压越大，凹陷越明显，直至呼吸衰竭。

<b>⚖️ 分度表</b>：

| 分度 | 安静时 | 活动后 | 缺氧体征 | 处理 |
|---|---|---|---|---|
| Ⅰ度 | 无症状 | 吸气性呼吸困难 | 无 | 病因治疗 |
| Ⅱ度 | 有呼吸困难、喉鸣 | 加重 | 轻度 | 严密观察 + 病因治疗 |
| Ⅲ度 | 明显呼吸困难 | 明显 | 烦躁、发绀、三凹征 | 立即气管切开 |
| Ⅳ度 | 极度呼吸困难 | — | 意识障碍、濒死 | 紧急开放气道 |

<b>🚨 红线</b>：Ⅲ～Ⅳ度不能仅药物保守观察；严重气流减少时喉鸣反而可能减弱，不能以"喉鸣大小"判断轻重。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 喉源性呼吸困难 | 肺源性呼吸困难 | 喉痉挛 |
|---|---|---|---|
| 呼吸相 | 吸气性，吸气延长 | 呼气性或混合性 | 吸气性，突发 |
| 三凹征 | 明显 | 不明显 | 可明显 |
| 喉鸣 | 吸气性喉鸣 | 多无 | 有，音调高 |
| 诱因 | 炎症、异物、肿瘤 | 哮喘、COPD | 低钙、刺激 |
| 处理 | 按分度开放气道 | 解痉、氧疗 | 解痉、镇静、补钙 |

<b>🩺 下一步</b>：① 判断分度；② Ⅲ度备气管切开，Ⅳ度紧急开放气道（环甲膜切开/气管插管）；③ 同时病因治疗。

#### 🔴 K-M05-008｜气管切开术（教师重点第110、121条｜P340）

📌 重点原文（第121条）：重症急性会厌炎和III～IV度喉阻塞必须优先评估和保障气道；气管切开常在第2～4气管软骨环附近；气管切开术后需重视气道湿化和套管通畅。

📌 重点原文（第110条）：气管切开术的常规部位位于第3-4气管软骨环之间，其适应证涵盖Ⅱ-Ⅳ度喉阻塞、下呼吸道分泌物潴留、某些头颈手术的术前准备以及需长期机械通气的患者。术后需加强护理，包括定期吸痰、保持套管通畅等。术后并发症如皮下气肿通常可自行吸收，但需警惕气胸、纵隔气肿及大出血（如损伤无名动脉）等严重并发症。拔管前需遵循规范流程，通常需更换为带气囊的套管并逐步试行堵管，确认呼吸平稳后方可拔管。（P340）

<b>🎯 一句话题眼</b>：常规在第 3-4 气管软骨环（也可记第 2～4 附近）；适应证 = 喉阻塞 Ⅱ–Ⅳ 度 + 分泌物潴留 + 头颈手术 + 长期通气。

<b>🧬 为什么</b>：气管切开绕过上气道梗阻，但吸入空气失去鼻腔加温加湿，分泌物易干结成痂堵管，所以术后"湿化 + 吸痰 + 套管通畅"是三条生命线。

<b>⚖️ 并发症</b>：

| 类型 | 表现 | 处理 |
|---|---|---|
| 皮下气肿 | 颈部捻发感 | 多可自行吸收 |
| 气胸/纵隔气肿 | 呼吸困难加重 | 影像确认，必要时引流 |
| 大出血 | 损伤无名动脉 | 紧急压迫/手术 |
| 堵管/脱管 | 突发呼吸困难 | 立即处理套管 |

<b>🚨 红线</b>：拔管前必须逐步堵管确认呼吸平稳；大出血（无名动脉损伤）可致命。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 常规气管切开 | 环甲膜切开 | 气管插管 |
|---|---|---|---|
| 适用 | Ⅱ–Ⅳ度喉阻塞、长期通气 | 濒临窒息、无法插管 | 多数急症首选 |
| 部位 | 第 3-4 气管软骨环 | 环甲膜 | 声门 |
| 速度 | 较慢 | 最快 | 快 |
| 局限 | 需手术条件 | 临时措施，后期改切开 | 上气道梗阻时可能失败 |

<b>🩺 下一步</b>：术后湿化、吸痰、固定套管、观察呼吸；拔管按"换带气囊套管→逐步堵管→确认→拔管"流程。

#### 🔴 K-M05-009｜急性会厌炎（教师重点第96条｜P309）

📌 重点原文（第96条）：急性会厌炎主要表现为剧烈咽痛，吞咽困难等，多不伴声嘶症状；咽部剧痛为急性会厌炎的最典型表现；急性会厌炎分急性卡他型、急性水肿型、急性溃疡型三种类型；急性会厌炎的最常见症状为剧烈咽痛，但是最严重的情况是由于会厌肿胀导致气道梗阻引起的吸气性呼吸困难，可能危及生命。（P309）

<b>🎯 一句话题眼</b>：剧烈咽痛 + 吞咽困难 + 不伴声嘶 → 急性会厌炎；最危险的是气道梗阻。

<b>🧬 为什么</b>：会厌舌面组织疏松，感染后迅速肿胀成球状，直接堵住喉入口；因为病变在声门上，声带未受累，所以"疼得厉害但不哑"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 急性会厌炎 | 急性喉炎 | 扁桃体周围脓肿 |
|---|---|---|---|
| 咽痛 | 剧烈 | 轻中度 | 单侧剧烈 |
| 声嘶 | 多无 | 明显 | 无 |
| 吞咽困难 | 明显、流涎 | 轻 | 明显 |
| 气道风险 | 高（可窒息） | 中（儿童高） | 低 |
| 关键处理 | 优先保障气道 | 激素 + 雾化 | 抗感染 + 引流 |

<b>🚨 红线</b>：疑似重症会厌炎，禁止在无气道保障条件下强行刺激咽喉（压舌可诱发窒息）。

<b>🩺 下一步</b>：① 优先评估气道，备插管/切开；② 糖皮质激素 + 抗感染；③ 雾化肾上腺素；④ 监测血氧。

#### 🔴 K-M05-010｜小儿急性喉炎（教师重点第97、98条｜P311）

📌 重点原文（第97条）：儿童期易发生上呼吸道感染；小儿急性喉炎易引起喉阻塞原因：喉腔狭小〔第98条续：炎性时容易发生肿胀、喉黏膜下组织疏松、咳嗽力量不够下呼吸道分泌物不易咳出〕

📌 重点原文（第98条）：炎性时容易发生肿胀；喉黏膜下组织疏松；咳嗽力量不够，下呼吸道分泌物不易咳出；声嘶、犬吠样咳及吸气性呼吸困难是小儿急性喉炎的典型表现；：急性喉炎通常先有病毒感染，之后可继发细菌感染。常见的致病病毒有流感病毒、副流感病毒、鼻病毒等，常见的致病细菌有溶血性链球菌、流感嗜血杆菌等。（P311）

<b>🎯 一句话题眼</b>：小儿"空空"犬吠样咳 + 声嘶 + 吸气性呼吸困难 → 急性喉炎；五大原因：腔小、易肿、膜松、咳弱、易感染。

<b>🧬 为什么</b>：儿童喉腔绝对径小，黏膜下组织疏松，炎症水肿后气道截面积急剧下降（半径减小一半，阻力增大约 16 倍），所以同样的炎症在成人只是声嘶，在小儿可以窒息。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 小儿急性喉炎 | 急性会厌炎 | 喉异物 |
|---|---|---|---|
| 起病 | 渐进，先有感冒 | 急骤 | 突发呛咳 |
| 咳嗽 | 犬吠样 | 无 | 阵发性 |
| 声嘶 | 明显 | 多无 | 可有 |
| 吞咽困难 | 轻 | 明显、流涎 | 可有 |
| 关键处理 | 激素 + 雾化 + 观察 | 优先气道 | 取出异物 |

<b>🚨 红线</b>：出现三凹征、发绀、烦躁，按喉阻塞 Ⅲ 度处理，不能只在家观察。

<b>🩺 下一步</b>：① 保持安静、避免哭闹；② 糖皮质激素；③ 中重度雾化肾上腺素；④ 必要时气管插管/切开。

#### 🟡 K-M05-011｜慢性喉炎（教师重点第99条｜P314）

📌 重点原文（第99条）：慢性喉炎的症状包括：①声音嘶哑：是慢性喉炎最主要症状，程度可轻重不等，可呈持续性或间歇性；②喉部干燥感、异物感、喉痛；③喉部分泌物增多，讲话费力，咳出后可缓解；慢性喉炎治疗包括：①去除病因：避免长时间用声过度、戒除烟酒、改善工作环境；在粉尘环境中作业者应加强防护；积极治疗鼻腔、鼻窦的慢性炎症，解除鼻塞、流涕，控制咽部及下呼吸道的感染，治疗反流性食管炎等疾病；②雾化吸入；③中成药治疗。（P314）

<b>🎯 一句话题眼</b>：声嘶是最主要症状；治疗第一位永远是"去除病因"。

<b>🧬 为什么</b>：长期用声过度、烟酒、粉尘、鼻后滴流与反流共同刺激声带黏膜，形成慢性充血与水肿；不去因，雾化只能暂时缓解。

<b>🚨 红线</b>：声嘶超过 2 周不缓解，必须喉镜检查排除喉癌，不能一直按"慢性喉炎"治疗。

<b>🩺 下一步</b>：去因 + 雾化 + 中成药；持续声嘶查喉镜。

#### 🔴 K-M05-012｜声带小结（教师重点第100、120条｜P315）

📌 重点原文（第100条）：声带小结：喉镜检查见双侧声带前、中1/3交界处有对称性结节状隆起。病程短的早期小结是粉红色息肉状；病程长者，则呈白色结节状小的隆起，表面光滑。发声时两侧的小结互相靠在一起使声门不能完全闭合；声带小结按发展过程可分为三个阶段。早期基质水肿，可有血管增生及扩张为正常的鳞状上皮，外观似小息肉，其病理改变和息肉相似；中期基质有纤维化及透明变性，表面仍为正常鳞状上皮，此时小结的外观较坚实；晚期小结基质和中期相似，但表面上皮有增厚及角化，也可有棘细胞层增厚和角化不全，故外观色苍白。（P315）

<b>🎯 一句话题眼</b>：双侧、对称、前中 1/3 交界处 → 声带小结；早期粉红，晚期苍白。

<b>🧬 为什么</b>：声带振动时前中 1/3 交界处振幅最大、碰撞最剧烈，长期用声不当在此形成"对冲伤"，先是水肿，继而纤维化、上皮角化。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 声带小结 | 声带息肉 | 喉癌 |
|---|---|---|---|
| 位置 | 双侧前中 1/3 交界 | 多单侧，任一段 | 多单侧，可固定 |
| 对称性 | 对称 | 不对称 | 不对称 |
| 外观 | 早期粉红、晚期苍白 | 表面光滑的息肉样 | 菜花样、溃疡 |
| 治疗 | 发声训练为主 | 手术为主 | 手术/放化疗 |

<b>🚨 红线</b>：单侧、不对称、进行性增大的声带病变，必须排除喉癌。

<b>🩺 下一步</b>：① 频闪喉镜评估振动与黏膜波；② 发声卫生与嗓音训练；③ 保守无效考虑手术。

#### 🟡 K-M05-014｜环杓关节炎与环甲关节炎（教师重点第102条｜P317）

📌 重点原文（第102条）：环杓关节炎喉镜下可见患侧的杓区黏膜肿胀、充血。间接喉镜下喉钳行杓区触诊时，患侧杓区会有明显触痛。患侧声带运动可受限，严重者因环杓关节固定可导致患侧声带固定。环甲关节炎喉镜下可见患侧声带肌松弛。如为一侧病变可出现声门偏斜，双侧环甲关节炎可引起关节活动障碍，则双侧声带肌松弛，声门闭合时有梭形裂隙。杓间区溃疡病变可见于喉结核；因风湿或类风湿引起的喉关节炎，可用糖皮质激素治疗；合并细菌感染应用抗生素治疗；喉痛者可用水杨酸制剂，或解热镇痛类药物。环杓关节固定者可在喉镜下行杓状软骨拨动术，环甲关节炎可行环甲关节推拿治疗。（P317）

<b>🎯 一句话题眼</b>：杓区肿胀 + 触痛 + 声带运动受限 → 环杓关节炎；声带松弛 + 声门偏斜 → 环甲关节炎。

<b>🧬 为什么</b>：环杓关节控制声带开合，环甲关节调节声带张力；关节炎症使活动受限，于是出现声带固定或张力下降。杓间区溃疡要想到喉结核。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 环杓关节炎 | 环甲关节炎 | 喉返神经麻痹 |
|---|---|---|---|
| 喉镜 | 杓区肿胀、触痛 | 声带松弛、声门偏斜 | 声带固定于旁中位 |
| 诱因 | 风湿、感染、插管 | 风湿、感染 | 甲状腺手术、肿瘤 |
| 治疗 | 激素/抗感染/拨动 | 激素/推拿 | 病因治疗、声带手术 |

<b>🚨 红线</b>：杓间区溃疡要排除喉结核；声带固定要区分关节性与神经性。

<b>🩺 下一步</b>：喉镜 + 触诊；风湿/类风湿用糖皮质激素，感染用抗生素；固定者行杓状软骨拨动术。

#### 🔴 K-M05-015｜喉癌（教师重点第103条｜P325）

📌 重点原文（第103条）：喉癌最常见的类型是声门型，约占60%；声门上癌早期症状不明显，或仅表现为咽异物感、吞咽不适、口臭、咽痛、咯血或呛咳等非特异症状；喉癌治疗的主要措施包括手术、放疗、化疗、靶向、免疫以及中医药治疗；早期喉癌可选择单一的治疗方案，而中晚期喉癌则需采取综合治疗；垂直喉部分切除术适用于肿瘤主要位于半侧喉的声门癌；或声门上癌累及喉室、声带，但不累及会厌和会厌前间隙、声门旁间隙为佳；若累及杓会厌壁，至少声带不完全固定，声门下累及不超过5mm;声门型喉癌，肿瘤局限在喉内，伴有声带固定为T3期。（P325）

<b>🎯 一句话题眼</b>：声门型约占 60%；持续声嘶 + 吸烟史 → 查喉镜；声门上癌早期"不声嘶"。

<b>🧬 为什么</b>：声门区淋巴少，声门型癌早期即因声带振动异常出现声嘶，所以发现早、转移晚；声门上区淋巴丰富且空间大，早期无症状，发现时多有淋巴结转移。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 声门型 | 声门上型 | 声门下型 |
|---|---|---|---|
| 占比 | 约 60% | 次之 | 少 |
| 早期症状 | 声嘶 | 咽异物感、呛咳，可不声嘶 | 多无症状 |
| 淋巴转移 | 晚 | 早 | 中 |
| 预后 | 较好 | 较差 | 差 |

<b>🚨 红线</b>：声嘶超过 2 周、吸烟中老年男性，必须喉镜检查；声门上癌不能因"不哑"而漏诊。

## 模块6：气道与食管异物

> [!INFO] 模块信息
> <b>权重</b>：5%｜<b>预计题型</b>：判断 / A1 / 多选｜<b>卡片</b>：3 张
> <b>谱系位置</b>：喉（M05）→ 气管支气管 → 食管；从"气道梗阻"到"消化道穿孔"，共同点是"急"。
> <b>三个题眼</b>：① 右侧主支气管为什么更易进异物；② 单向活瓣 → 局限性肺气肿；③ 食管三处生理性狭窄的距离。
> <b>阅读</b>：约 10 分钟

### 🧩 前置知识检查

- 气管在哪一分叉？左右主支气管有什么区别？
- 食管有哪三处生理性狭窄？各距中切牙多远？
- 不完全性阻塞与完全性阻塞的后果有什么不同？
- 为什么"胸片正常"不能排除气道异物？

> [!TIP] 复习入口
> 本模块只记三句话：<b>右主支气管短粗直、单向活瓣成肺气肿、食管三狭窄 15/25/40</b>。

### 🎯 30 秒摘要

1. 气道异物好发于 3 岁以下，典型为进食时突发呛咳、憋气、发绀。
2. 右侧主支气管短、粗、走向垂直，异物更易进入右侧。
3. 不完全性阻塞形成单向活瓣 → 局限性肺气肿；完全阻塞 → 肺不张。
4. 食管三狭窄距中切牙约 15～16 cm、25 cm、40 cm。
5. 食管异物严禁吞咽饭团、馒头或饮醋强推。

### 📋 考点卡

#### 🔴 K-M06-001｜气管支气管异物（教师重点第122条）

📌 重点原文（第122条）：右侧主支气管相对较短、较粗、走向较垂直；气道异物不完全性阻塞可形成单向活瓣，导致局限性肺气肿；儿童疑似气道异物不能因胸片正常而排除。

<b>🎯 一句话题眼</b>：右主支气管"短粗直"→ 异物偏右；单向活瓣 → 肺气肿；胸片正常 ≠ 排除。

<b>🧬 为什么</b>：右主支气管与气管夹角小、管径粗，异物顺着气流更容易落入右侧。不完全阻塞时吸气时气道扩张、气体能进；呼气时气道收缩、气体出不来，形成"只进不出"的单向活瓣，远端肺过度充气。

<b>🔗 机制链</b>：

```text
异物吸入
        ↓
├─ 不完全阻塞 → 单向活瓣 → 气体只进不出
│                        → 局限性肺气肿、患侧透亮度增高
├─ 完全阻塞 → 远端气体吸收 → 肺不张
└─ 尖锐异物 → 黏膜损伤 → 出血、感染
        ↓
突发呛咳、喘息、单侧呼吸音减弱
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 气道异物 | 支气管哮喘 | 喉炎 |
|---|---|---|---|
| 起病 | 突发呛咳 | 渐进、反复 | 渐进、发热 |
| 呼吸音 | 单侧减弱 | 双肺哮鸣音 | 喉鸣 |
| 影像 | 肺气肿/肺不张/纵隔摆动 | 过度充气 | 多正常 |
| 关键处理 | 支气管镜取出 | 解痉 | 激素 + 雾化 |

<b>🚨 红线</b>：儿童疑似气道异物，胸片正常不能排除；有机异物（花生、瓜子）常不显影。

<b>🩺 下一步</b>：① 详细询问呛咳史；② 双肺听诊；③ 颈胸影像（必要时透视看纵隔摆动）；④ 硬性支气管镜确诊并取出。

<b>🔄 自测</b>：为什么异物更容易进入右侧主支气管？单向活瓣会导致什么后果？（答案见附录五）

#### 🔴 K-M06-002｜食管异物与三处生理性狭窄（教师重点第123条）

📌 重点原文（第123条）：食管三处生理性狭窄距成人中切牙约15～16cm、25cm、40cm；食管穿孔可能导致纵隔感染和皮下气肿，严禁吞咽饭团、馒头或饮醋强行处理异物。

<b>🎯 一句话题眼</b>：15～16、25、40 cm 三个狭窄；尖锐异物 → 穿孔 → 纵隔感染。

<b>🧬 为什么</b>：三处狭窄分别是食管入口（环咽肌）、主动脉弓与左主支气管压迹、膈食管裂孔；异物在此嵌顿，尖锐物易刺穿管壁，食管周围为纵隔疏松结缔组织，感染迅速扩散。

<b>⚖️ 鉴别：气道 vs 食管异物</b>：

| 鉴别轴 | 气道异物 | 食管异物 |
|---|---|---|
| 主症 | 呛咳、喘息、憋气 | 吞咽困难、吞咽痛、流涎 |
| 呼吸音 | 单侧减弱 | 多正常 |
| 疼痛 | 胸骨后不明显 | 颈部/胸骨后疼痛 |
| 检查 | 支气管镜 | 食管镜/胃镜 |
| 危险 | 窒息 | 穿孔、纵隔感染 |

<b>🚨 红线</b>：严禁吞咽饭团、馒头或饮醋强行处理异物；出现进行性胸骨后疼痛、发热、皮下气肿，高度怀疑穿孔。

<b>🩺 下一步</b>：① 立即禁食；② 颈胸部影像（CT 更敏感）；③ 专科内镜取出；④ 穿孔者禁食、抗感染、必要时手术修补。

<b>🔄 自测</b>：食管三处生理性狭窄距中切牙分别约多少厘米？为什么不能吞饭团强推？（答案见附录五）

#### 🟡 K-M06-003｜异物急症的通用处理原则（教材背景，不单列条号）

<b>🎯 一句话题眼</b>：先看气道（ABC），再定位置，最后选器械；能看见的取、看不见的查。

<b>🧬 为什么</b>：异物最致命的不是"异物本身"，而是窒息与穿孔两大并发症；所以顺序永远是"气道—位置—取出"。

<b>⚖️ 处理对照</b>：

| 情形 | 处理 |
|---|---|
| 完全性气道梗阻、不能咳嗽 | 立即解除梗阻（海姆立克/取异物） |
| 不完全梗阻、能咳嗽 | 密切监护，避免盲目抠挖 |
| 儿童气道异物 | 硬性支气管镜，全麻下取出 |
| 食管尖锐异物 | 禁食 + 影像 + 内镜，警惕穿孔 |
| 电池等腐蚀性异物 | 紧急取出 |

<b>🚨 红线</b>：不要对能咳嗽的不完全梗阻患者盲目拍背或抠挖，可能把异物推得更深。

<b>🩺 下一步</b>：按"气道—位置—取出—并发症"四步处理，全程备好急救设备。

### 📊 对比速查：气道异物 vs 食管异物

| 鉴别轴 | 气道异物 | 食管异物 |
|---|---|---|
| 好发人群 | 3 岁以下儿童 | 老人、儿童、假牙使用者 |
| 典型病史 | 进食/玩耍时突发呛咳 | 误吞鱼刺、枣核、假牙 |
| 主症 | 呛咳、喘息、单侧呼吸音减弱 | 吞咽困难、吞咽痛、流涎 |
| 影像 | 肺气肿、肺不张、纵隔摆动 | 异物影、纵隔气体（穿孔） |
| 处理 | 硬性支气管镜 | 内镜取出，禁食 |

### 🔗 因果链：异物 → 阻塞 → 两类后果

```text
异物进入气道
        ↓
├─ 不完全阻塞 → 单向活瓣 → 局限性肺气肿
├─ 完全阻塞 → 远端气体吸收 → 肺不张
└─ 停留时间长 → 黏膜炎症、肉芽、肺脓肿
        ↓
呛咳、喘息、单侧呼吸音减弱、反复肺部感染
```

### 🌳 决策树：突发呛咳/吞咽痛的定位

```text
突发呛咳 / 吞咽痛
├─ 呛咳、喘息、单侧呼吸音减弱
│    → 气道异物（支气管镜）
├─ 吞咽困难、流涎、胸骨后痛
│    → 食管异物（禁食 + 内镜）
├─ 进行性胸痛、发热、皮下气肿
│    → 食管穿孔（禁食 + 抗感染 + 外科评估）
└─ 完全不能发声、双手抓喉
     → 完全性气道梗阻（立即解除）
```

#### 🔴 K-M07-001｜颈部肿块的诊断路径与鼻咽癌颈部转移（教师重点第105、124条）

📌 重点原文（第124条）：甲状舌管囊肿常随伸舌移动；第二鳃裂瘘管多位于胸锁乳突肌前缘附近；颈动脉体瘤位于颈总动脉分叉处并可呈高脚杯征；成人持续性硬质颈部肿块应排查恶性肿瘤。

📌 重点原文（第105条）：鼻咽癌典型症状与鉴别诊断、病理活检为金标准、MRI及EB病毒检测作用、Ki-67与预后关系、远处转移筛查及随访监测方法、放疗为首选治疗原则：患者如有吸烟史、耳部症状（耳鸣、听力下降）、颈部淋巴结无痛、质硬、活动差，合并回吸性涕血和鼻咽溃疡型肿物，符合鼻咽癌伴颈淋巴结转移的典型临床表现，但需与颈部淋巴瘤（多部位淋巴结肿大、可伴发热）、甲状腺癌（颈侧区淋巴结转移）、急性化脓性淋巴结炎（伴红肿热痛）、鼻咽纤维血管瘤（青年男性、鼻塞、反复鼻出血、无淋巴结转移）、鼻窦癌侵犯鼻咽及鼻咽结核鉴别，慢性鼻咽炎多为黏膜充血，无溃疡及易出血肿物。鼻咽癌诊断金标准为病理活检，应先行鼻咽镜+活检，颈部淋巴结细针穿刺可确认转移，MRI用于评估肿瘤范围及颅底侵犯，EB病毒检测（如EBV-VCA IgA、EBV-EA IgA及EB病毒DNA载量）为重要辅助诊断，其DNA水平可反映病情活动度；Ki-67指数高提示肿瘤增殖快、预后差，CEA通常不升高。影像学检查包括鼻窦CT排除鼻窦来源病变，胸部CT用于筛查远处转移（胸片分辨率低且患者无远处转移征象，可非重点项目）。鼻咽癌颈淋巴结转移多先至颈深上Ⅱ区，特点为无痛、质硬、边界不清、活动度差，可融合，而红肿、疼痛提示炎症。治疗上，首选根治性放疗，中晚期需同步放化疗，靶向治疗可联合放疗增强疗效，手术仅用于放疗后复发或残留，单纯化疗疗效差。随访核心为监测复发及转移：鼻咽镜检查局部，影像学评估复发及转移，EB病毒DNA监测病情，肝肾功能及血常规定期（如3~6个月）监测即可，无需每月复查。

<b>🎯 一句话题眼</b>：成人"无痛、质硬、活动差"的颈部淋巴结 → 先找原发灶（鼻咽、口咽、下咽、喉、甲状腺）；FNA 定性，活检定源。

<b>🧬 为什么</b>：头颈部淋巴引流按解剖分区有序进行，鼻咽癌引流至颈深上Ⅱ区，喉癌至Ⅲ/Ⅳ区，甲状腺癌至Ⅵ区。因此"哪一区肿大"能反推原发部位，这是颈部肿块诊断的核心逻辑。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 转移性淋巴结 | 淋巴瘤 | 化脓性淋巴结炎 |
|---|---|---|---|
| 疼痛 | 无痛 | 无痛 | 红肿热痛 |
| 质地 | 质硬、边界不清 | 韧、可多发 | 软、有波动 |
| 活动度 | 差、可融合 | 中等 | 受限 |
| 全身症状 | 多无 | 可发热、盗汗 | 发热 |
| 确诊 | FNA/活检 | 切除活检 | 穿刺/抗感染试验 |

<b>🚨 红线</b>：怀疑颈动脉体瘤时忌盲目穿刺（血供丰富，可致严重出血）；成人硬质颈部肿块不能长期按"淋巴结炎"观察。

<b>🩺 下一步</b>：① 颈部超声 + 增强 CT/MRI；② FNAB；③ 鼻内镜/喉镜找原发灶；④ 鼻咽癌以根治性放疗为主，中晚期同步放化疗。

<b>🔄 自测</b>：成人持续性硬质颈部肿块为什么先排恶性？鼻咽癌颈淋巴结转移的第一站是哪个区？FNAB 的作用是什么？（答案见附录五）

#### 🟡 K-M07-002｜颈部淋巴结分区与转移规律（教材背景，不列条号）

<b>🎯 一句话题眼</b>：I 颏下/下颌下，II 颈内静脉上，III 中，IV 下，V 颈后三角，VI 颈前中央区。

<b>🧬 为什么</b>：分区把"解剖位置"翻译成"原发灶概率"。II 区 → 鼻咽/口咽；III/IV 区 → 喉/下咽/甲状腺；V 区 → 鼻咽/皮肤；VI 区 → 甲状腺。

<b>⚖️ 分区表</b>：

| 分区 | 范围 | 常见原发 |
|---|---|---|
| I | 颏下、下颌下 | 口腔、唇 |
| II | 颈内静脉上组 | 鼻咽、口咽 |
| III | 颈内静脉中组 | 喉、下咽、甲状腺 |
| IV | 颈内静脉下组 | 喉、下咽、甲状腺 |
| V | 颈后三角 | 鼻咽、皮肤 |
| VI | 颈前中央区（喉前、气管前、气道旁） | 甲状腺 |

<b>🚨 红线</b>：咽后淋巴结不属于 VI 区；Virchow 淋巴结指左侧锁骨上淋巴结，提示胸腹腔肿瘤。

<b>🩺 下一步</b>：按分区选择影像与活检路径，指导手术清扫范围与放疗靶区。

<b>🔄 自测</b>：II 区与 VI 区分别指什么？各常见于哪些原发肿瘤的转移？（答案见附录五）

#### 🟢 K-M07-003｜颈深筋膜三层（教材背景，不列条号）

<b>🎯 一句话题眼</b>：封套筋膜包肌肉，内脏筋膜包脏器，椎前筋膜盖深层。

<b>🧬 为什么</b>：筋膜层决定感染与肿瘤的扩散路径：内脏筋膜间隙向下通纵隔，所以颈深部感染可致纵隔炎。

<b>⚖️ 三层表</b>：

| 筋膜 | 包绕 |
|---|---|
| 封套筋膜 | 胸锁乳突肌、斜方肌 |
| 内脏筋膜 | 气管、食管、甲状腺 |
| 椎前筋膜 | 颈椎前方肌群与深层结构 |

<b>🚨 红线</b>：颈部感染向下蔓延至纵隔是致命并发症，需尽早影像与引流。

<b>🩺 下一步</b>：深部感染评估筋膜间隙，必要时切开引流。

#### 🟡 K-M07-004｜先天性颈部肿块三病（教师重点第124条）

📌 重点原文（第124条）：甲状舌管囊肿常随伸舌移动；第二鳃裂瘘管多位于胸锁乳突肌前缘附近；颈动脉体瘤位于颈总动脉分叉处并可呈高脚杯征；成人持续性硬质颈部肿块应排查恶性肿瘤。

<b>🎯 一句话题眼</b>：随伸舌动 = 甲状舌管囊肿；胸锁乳突肌前缘 = 第二鳃裂；颈动脉分叉 + 高脚杯征 = 颈动脉体瘤。

<b>🧬 为什么</b>：甲状舌管囊肿与舌骨相连，伸舌时舌骨上提牵动囊肿；第二鳃裂瘘管沿胸锁乳突肌前缘走行；颈动脉体瘤位于分叉处，血管造影见颈内、外动脉被推开呈"高脚杯"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 甲状舌管囊肿 | 第二鳃裂囊肿/瘘管 | 颈动脉体瘤 |
|---|---|---|---|
| 位置 | 颈前正中 | 胸锁乳突肌前缘 | 颈总动脉分叉处 |
| 特征动作 | 随伸舌/吞咽移动 | 可有瘘口流黏液 | 横向活动、上下受限 |
| 影像 | 超声/CT | 超声/瘘管造影 | 增强 CT/MRI、血管造影（高脚杯征） |
| 处理 | Sistrunk 术 | 手术切除 | 手术，术前评估血管 |

<b>🚨 红线</b>：颈动脉体瘤血供丰富，忌盲目穿刺；怀疑时先做影像与血管评估。

<b>🩺 下一步</b>：超声初筛 → 增强 CT/MRI → 必要时血管造影 → 手术。

<b>🔄 自测</b>：甲状舌管囊肿为什么随伸舌移动？颈动脉体瘤的典型影像征象是什么？（答案见附录五）

### 📊 对比速查：颈部肿块"时间—性质"规律

| 病程 | 常见性质 | 举例 |
|---|---|---|
| 7 天 | 炎症性 | 急性淋巴结炎、脓肿 |
| 7 月 | 肿瘤性（先天/良性） | 鳃裂囊肿、甲状舌管囊肿、良性肿瘤 |
| 7 年 | 先天性 | 甲状舌管囊肿、鳃裂囊肿 |

> [!WARNING] 易错陷阱
> "7 天/7 月/7 年"是帮助记忆的经验规律，不是诊断标准；最终仍要靠影像与病理。

### 🔗 因果链：颈部淋巴结肿大 → 原发灶定位

```text
颈部淋巴结肿大
        ↓
超声评估（大小、边界、血流、囊实性）
        ↓
按分区推断原发灶
├─ II 区 → 鼻咽、口咽（查鼻内镜）
├─ III/IV 区 → 喉、下咽、甲状腺（查喉镜、甲状腺超声）
├─ V 区 → 鼻咽、皮肤
└─ VI 区 → 甲状腺
        ↓
FNAB 定性 → 找原发灶活检（金标准）
        ↓
分期 → 手术/放疗/综合治疗
```

### 🌳 决策树：颈部肿块的鉴别

```text
颈部肿块
├─ 颈前正中、随伸舌移动
│    → 甲状舌管囊肿（Sistrunk 术）
├─ 胸锁乳突肌前缘、可有瘘口
│    → 第二鳃裂囊肿/瘘管（手术切除）
├─ 颈动脉分叉处、可闻血管杂音、高脚杯征
│    → 颈动脉体瘤（忌穿刺，先影像）
├─ 红肿热痛、病程短
│    → 急性淋巴结炎（抗感染）
└─ 无痛、质硬、活动差、成人、吸烟饮酒
     → 转移性淋巴结（FNAB + 找原发灶）
```
