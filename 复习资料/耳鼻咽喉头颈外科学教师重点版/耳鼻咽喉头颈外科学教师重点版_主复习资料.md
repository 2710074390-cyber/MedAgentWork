## 科目导航：耳鼻咽喉头颈外科学怎么学？

<b>一句话核心逻辑链</b>：本科目可概括为「<b>三个管道 + 一组腔隙 + 一组神经</b>」被堵塞、破坏或侵犯——<b>管道</b>（鼻气道、咽鼓管、喉腔气道、咽-食管通路）以「阻塞」为症状核心（鼻塞、耳闷、吸气性呼吸困难、吞咽困难）；<b>腔隙</b>（中耳、鼻窦、咽旁/咽后间隙、颈部间隙）以「积脓/积液 → 压迫 → 破坏」为核心；<b>神经</b>（面神经、听/前庭神经、喉返神经、颈部重要神经）以「功能丧失」为核心（面瘫、耳聋、声嘶）。抓住「<b>堵—积—失</b>」三字，即可串起全科骨干。

<b>命题规律</b>：耳科学约占 1/3，其次鼻、喉、咽；颈科学（头颈）与气管食管异物为独立板块。三大必考高地：①各类中耳炎分型与胆脂瘤（重灾区）；②鼻出血/鼻窦炎/变应性鼻炎/鼻窦开口（背数值 + 处置流程）；③喉阻塞分度与急性会厌炎（气道急救）。

<b>复习路径</b>：M1 总论与检查 → M2 耳科学 → M3 鼻科学 → M4 咽部疾病与 OSAHS → M5 喉部疾病及危重气道 → M6 气管支气管与食管异物 → M7 头颈外科学与颈部肿块。

> [!TIP] 本科目高分密码
> 每学一个病都问三句：<b>堵在哪（部位）？怎么发现（首选检查）？怎么解堵（首选治疗）？</b> 急症（急性会厌炎、III–IV 度喉阻塞、气道/食管异物穿孔）思路永远先「气道与生命」，后「病因」。

## 📐 疾病谱系总览（D3：从良到危）

```
【耳】外耳炎/耵聍栓塞（自限，最轻）
  ↓ 感染突破鼓膜 → 急性/分泌性中耳炎（可药物）
  ↓ 胆脂瘤/肉芽破坏骨壁 → 中耳胆脂瘤（必须手术）
  ↓ 内耳/听神经损伤不可逆 → 突发性聋/感音神经性聋、面瘫（功能丧失）
【鼻】急性鼻炎（自限）→ 急/慢性鼻窦炎（药物多数可愈）
  ↓ 息肉/黏膜增生 → CRSwNP → FESS；窦源性眶内并发症
  ↓ 大出血/肿瘤 → 鼻出血（后部危险）、鼻腔鼻窦肿瘤
【咽】咽炎（自限）→ 急性扁桃体炎（青霉素可愈）
  ↓ 脓液波及咽旁/咽后 → 咽部脓肿（气道与纵隔风险）
  ↓ 长期气道阻塞/恶性增殖 → OSAHS、鼻咽癌（放疗敏感）
【喉】声带小结/息肉（良性可逆）→ 急性会厌炎/小儿急性喉炎（数小时可至 III–IV 度）
  ↓ 气道横截面积缩减 → 喉阻塞（III/IV 度立即建立气道）→ 喉癌
【气管食管】异物（单向活瓣→肺气肿 / 完全阻塞→肺不张；食管穿孔→纵隔感染）
【颈部】先天囊肿/瘘管 → 炎性肿大 → 转移性淋巴结/原发肿瘤（成人质硬固定肿块优先排查恶性）
```

### D1 第一性原理

🔴 【掌握级】学科定位与范畴：耳鼻咽喉头颈外科学研究耳、鼻、咽、喉、气管、食管及头颈部相关疾病，涉及听觉、平衡、嗅觉、呼吸、吞咽和发声等重要功能的维护与修复（教材P2、P3）。

🧬 第一性原理：
这些器官在胚胎期由管状/囊状结构发育而来，彼此借孔道相连（咽鼓管通中耳、后鼻孔通鼻咽、喉口通气管），是一组<b>有入口、有孔径、相互沟通</b>的腔道器官群，且深藏于颅面腔洞之中，周围紧邻重要血管、神经及颅底、眼眶。如果它们各自孤立、浅表可及，就不会出现「一处病变、多处受累」的连锁；正因为<b>腔洞深在、器官毗邻、局部病变可向邻近蔓延</b>（向上→颅内，向前→眶内，向下→颈部），部分疾病甚至可迅速引起气道梗阻、颅内感染、眶内并发症或大出血，才必须把「除眼、口腔、颅内结构以外」的这一整片区域当作一个整体来研究。
<b>本质上就是：一片深藏、互通、毗邻危险的腔道器官群，因解剖与功能的整体性而自成二级学科。</b>

学科特点：解剖结构复杂、腔洞深在、器官彼此毗邻；耳鼻咽喉疾病与全身状况密切相关（如变应性鼻炎常与支气管哮喘共存）；部分颅底病变与颅内侵犯需与神经外科、眼科、口腔颌面外科、肿瘤科多学科协作（教材P3）。

> [!NOTE] 学科边界
> 解题先排除「<b>眼、口腔、颅内结构</b>」三处，再对齐「耳鼻咽喉＋气管食管＋头颈颅底」这一范围与「听觉、平衡、嗅觉、呼吸、吞咽、发声」等功能。边界清楚，题目就不会错。

---

🔴 【掌握级】常用检查器械与额镜的使用：基础器械包括额镜、耳窥镜、鼻镜、压舌板等；额镜是传统照明器械，利用反射光源照亮检查部位（教材P11）。

🧬 第一性原理：
器官藏在颅颌深处，眼球够不着、手探不进去，于是本学科的第一性矛盾是「<b>看不见、摸不到</b>」——必须靠一束光把靶区照亮。额镜是一面圆形聚光凹面镜：把外来平行光反射并聚焦成一个明亮光斑投到检查部位。要看清这个光斑，检查者的眼睛必须正好落在这条光路上。如果眼偏离光路（弯腰、扭颈找光源、闭起一只眼），焦点就进不了视野、图像就「看不清」；而<b>另一眼不闭</b>是为了保持双眼协调、避免单眼调节疲劳与深度判断失误。
<b>本质上就是：让「眼睛—光路—病灶」三点共线，单眼对准窥视孔又保持双眼协调。</b>

机制要点：使用时瞳孔—窥视孔—反光焦点—检查部位成一条直线；姿势端正、不弯腰扭颈；单目经窥视孔观察、另一眼不闭；额镜与检查部位保持约 25 cm；光源置于受检者耳后上方约 15 cm（教材P11-12）。压舌板用于暴露口咽部，便于观察扁桃体、咽后壁及咽侧壁（教材P12）。

> [!TIP] 额镜铁律
> 记住「<b>四点一线、单目视、另一眼不闭、约 25 cm</b>」。注意区分：镜与检查部位距离约 <b>25 cm</b>，而受检者与检查者相对而坐时头与检查者间距约 <b>25~40 cm</b>，两者常被混淆设问。

---

🔴 【掌握级】内镜体系：硬性内镜 vs 软性内镜，以及各镜的观察部位（教材P13、P12）。

🧬 第一性原理：
腔道有「<b>直</b>」与「<b>弯</b>」两类几何形态。鼻腔、鼻窦、外耳道相对直、口径窄——硬性内镜可稳定地把光与像送到位，图像清晰、适合精细观察；而鼻咽、喉、部分下咽拐弯多、口径小——硬镜「直」就进不去，必须靠可弯曲的软性纤维内镜/电子内镜绕过角度、贴着腔壁看。若用错器械（如拿耳内镜去看喉、拿硬镜硬闯鼻咽），要么进不去、要么看不全。
<b>本质上就是：按腔道「直/弯」匹配「硬镜/软镜」，器械选错则靶区必漏。</b>

- 硬性内镜：一般<b>不能弯曲</b>，图像清晰、适合精细观察，常用于鼻腔、鼻窦及耳部检查（教材P13）。
- 软性纤维内镜/电子内镜：<b>可弯曲</b>，便于观察鼻腔深部、鼻咽、喉及部分下咽，适用于部分儿童或张口受限患者（教材P13）。
- 耳内镜：观察外耳道和鼓膜；电子鼻咽喉镜：观察鼻咽、喉及部分下咽；间接喉镜：观察部分喉部及下咽；频闪喉镜：评价声带振动、黏膜波、振幅和振动对称性，对声带细微病变及嗓音疾病有价值（教材P12-13）。

> [!NOTE] 器械→门户配对
> 记住一句话即可——<b>鼻用鼻镜/鼻内镜，耳用耳镜/耳内镜，口咽用压舌板，喉/下咽用间接喉镜/电子鼻咽喉镜；声带振动看频闪喉镜。</b>

---

🔴 【掌握级】听力学检查：主观 vs 客观（教材P13）。

🧬 第一性原理：
听觉通路分「<b>传导</b>（外耳、中耳）」与「<b>感受</b>（耳蜗、听神经至脑干）」两段。要判断耳聋的性质，需要两类证据：一类是受检者<b>主动回答</b>听到的最小声音（主观），测得的是「响亮感」；另一类是仪器记录的<b>生理反应</b>（客观），测得的是「通路是否正常运转」。如果受检者不能配合（婴幼儿、伪聋、意识障碍），主观测不了，就必须靠客观记录；反之，客观正常也不能代替受检者真实听阈。二者互证、不可替代。
<b>本质上就是：主观测「感知」，客观测「通路」。</b>

- <b>主观检查</b>：纯音测听、音叉试验、言语测听、表试验（均需受检者主观应答）（教材P13）。
- <b>客观检查</b>：声导抗、耳声发射（OAE）、听性脑干反应（ABR）、镫骨肌反射（不需受检者配合）（教材P13）。

> [!SUCCESS] 主客观二分速记
> 「<b>纯音、音叉、言语、表——主观</b>；<b>声导抗、OAE、ABR——客观</b>」。看到「需患者配合应答」即主观，看到「生理反应/反射/诱发」即客观。

---

🔴 【掌握级】影像检查与「设备不可替代」原则（教材P13-14、P366、P277）。

🧬 第一性原理：
不同设备回答的是<b>不同的问题</b>：内镜回答「长什么样」，CT 回答「骨头与病变范围」，MRI/增强 CT 回答「软组织、血管神经毗邻关系」，超声回答「浅表肿块的形态与血流」。因此单台设备只能回答一个问题，必须组合互证；把「看得见形态」误当成「能定性」，就会漏诊。
<b>本质上就是：一器一问，互证不可替代。</b>

- <b>鼻窦 CT</b>：评估鼻窦解剖、慢性炎症、真菌球、骨质改变及手术相关解剖（教材P13）。
- <b>颈部彩色多普勒超声</b>：评估肿块大小、边界、囊实性及血流（教材P14）。
- <b>增强 CT 或 MRI</b>：进一步评估病变与周围组织、血管神经的关系（教材P13）。
- <b>不可替代四例</b>：耳内镜不能判定听力损失类型；正常胸片不能排除气管支气管异物；EB 病毒检测不能代替鼻咽癌组织病理确诊；颈部超声不能独立确诊所有性质不明的肿块（教材P13-14、P366、P277）。

> [!WARNING] 高频陷阱·设备局限
> 四例「不能替代」是本模块必考陷阱：<b>耳内镜只见外耳道/鼓膜 → 不能定聋的性质与程度</b>；<b>透光异物可致胸片正常 → 不能排除气道异物（须结合异物吸入史+支气管镜）</b>；<b>EB 抗体只是感染提示 → 不能代替病理确诊鼻咽癌</b>；<b>超声只给形态/血流 → 不能独立定性颈部肿块（需增强 CT/MRI±活检）</b>。凡把单一检查当「一锤定音」的选项，基本可排除。

---

🟡 【熟悉级】危险信号与急症处置原则：本学科部分疾病可迅速引起气道梗阻、颅内感染、眶内并发症或大出血（教材P5-7、P13-14）。

机制：急症意识永远「先气道与生命，后病因」——急性进行性咽喉痛伴呼吸困难（警惕急性会厌炎）、突发大量鼻出血伴休克、外伤后清亮液体经鼻/耳流出（警惕脑脊液漏），均应先处理急症再全面查因。｜💡 病例题若出现在「先做什么」的选择，先问一句「有没有生命危险」。

🟢 【了解级】学科亚专业划分：按功能分为听觉、平衡、嗅觉、呼吸、吞咽、发声、言语；亚专业含耳科及侧颅底、听力与眩晕、鼻科及鼻颅底、咽喉、嗓音、头颈外科、小儿学等（教材P3）。

### D2 因果链：专科检查的「主诉→送光→定位→救急」链

```text
主诉(症状)：鼻塞/鼻出血、听力下降/耳鸣/眩晕、咽痛/声嘶、颈部肿块
        │
        ▼
判断病灶所在腔道：鼻腔鼻窦 / 耳与前庭 / 咽 / 喉 / 气管食管 / 颈部
        │
        ▼
★ 腔洞深在 + 毗邻复杂 → 光与手够不到 → 必须「送光进去、送镜进去」
        │
        ▼
选择手段：器械照明(额镜) → 内镜(硬/软) → 功能检查(听力学:主观+客观) → 影像(CT/MRI/超声)
        │
        ▼
定位定性：炎症 / 异物 / 肿瘤 / 畸形 / 全身病 + 是否累及毗邻(颅底、眼眶、血管神经)
        │
        ▼
★ 红旗征筛查：气道梗阻？颅内/眶内并发症？大出血？
        │        │
        │        └─► 有 → 先救急(开放气道/止血/防感染)，再查因
        ▼
单设备只回答一个问题 → 组合检查「互证不可替代」
```

> [!INFO] 读图要点
> 两个「★」是本模块的思维拐点：①<b>腔洞深窄 → 必须先解决「怎么看得见」，再谈看到什么</b>；②<b>有红旗征 → 救急优先于全面检查</b>。答题卡壳时，先答「病灶在哪个腔道、用什么送光」，再答「有没有生命危险」。

### D3 谱系/分层：专科症状的危险度梯度

```text
【低危·常见炎症性主诉】鼻塞、耳闷、轻度咽痛、短暂声嘶
   ↓ ← 转折点1：单侧 / 进行性 / 常规治疗无效
【中危·需排除肿瘤】单侧鼻塞血涕、单侧耳闷（警惕鼻咽癌）、持续声嘶
   ↓ ← 转折点2：出现毗邻受累（眼球突出、面瘫、颈部肿块固定）
【高危·区域蔓延】窦源性眶内并发症、耳源性颅内感染（脑膜炎/脑脓肿）、颈部大血管受累
   ↓ ← 转折点3：气道梗阻 / 大出血 / 意识改变
【危急·救命】急性喉阻塞、后部鼻出血、脑脊液漏 → 先救气道/止血/防感染
```

关键转折点识别：
- 转折点1（可治→需排查肿瘤）：症状由「双侧、间歇、对症有效」变为「单侧、进行性、对症无效」——肿瘤常酷似炎症。
- 转折点2（局部→区域）：病变突破骨壁/间隔进入眶、颅、颈深部——治疗由单纯药物转为「药物+手术」。
- 转折点3（→危及生命）：气道横截面积锐减、大出血、感染入颅——进入抢救流程。

> [!WARNING] 红旗征清单
> ①<b>急性进行性咽喉痛＋呼吸困难/流涎</b>：警惕急性会厌炎与喉阻塞，先开放气道；②<b>突发大量鼻出血伴面色苍白/脉速</b>：警惕后部出血致失血性休克，先抗休克后止血；③<b>外伤后清亮液体经鼻/耳流出</b>：警惕脑脊液漏，头高位、防颅内感染。任何一条出现，先救急，莫陷入「慢慢查」。

### D4 决策树：主诉 → 首选检查 → 怀疑疾病

```text
「该做什么检查？」
├─ 病灶在鼻腔/鼻窦？
│    └─ 前鼻镜 + 鼻内镜；骨性/炎症/手术解剖评估 → 鼻窦CT
├─ 病灶在耳（听力下降/耳鸣）？
│    ├─ 定性 → 音叉试验
│    ├─ 定量 → 纯音测听（主观）
│    └─ 定位中耳 → 声导抗（客观）
├─ 病灶在前庭（眩晕）？
│    └─ 耳内镜 + 前庭功能 + 影像（先排除中枢性）
├─ 病灶在咽/喉（咽痛/声嘶）？
│    └─ 压舌板 / 间接喉镜 / 电子鼻咽喉镜（软镜）
└─ 病灶在颈部（肿块）？
     └─ 彩色多普勒超声（大小/边界/囊实性/血流）
        → 增强CT或MRI（与血管神经关系）
           → 组织活检（最终定性，超声/EB抗体均不能替代）
```

每一步的判断依据：
- 第一分支：<b>按主诉锁定腔道门户</b>（鼻/耳/前庭/咽喉/颈部）。
- 第二分支：<b>按腔道几何形态选器械</b>（直→硬镜、弯→软镜）。
- 第三分支：<b>按「一器一问」拼组合</b>——形态靠内镜、骨与范围靠 CT、毗邻靠增强 CT/MRI、浅表血流靠超声，最终定性靠病理。

> [!TIP] 首选检查一句话
> 「<b>鼻用镜、耳用听（音叉+纯音+声导抗）、眩用前庭、咽喉用镜、颈部先超声后增强影像再活检</b>」。

#### 🔬 展开：主客观听力学检查的分工与判读要点

- <b>纯音测听（主观）</b>：同时测气导与骨导阈值，画成听力图；传导性聋示气骨导差，感音神经性聋曲线下降、无气骨导差，混合性二者兼有（细节在 M2）。
- <b>声导抗（客观）</b>：改变外耳道压力测鼓膜—听骨链「劲度」，间接读出鼓室压力与积液；B 型平坦曲线提示鼓室积液。
- <b>耳声发射（客观）</b>：反映耳蜗外毛细胞功能，是新生儿听力筛查利器。
- <b>听性脑干反应（客观）</b>：记录听神经至脑干通路的诱发反应，可用于客观听阈估计与伪聋鉴别。
- 判读总原则：<b>客观测「通路有没有坏」，主观测「受检者听到没有」；受检者不配合时，只有客观能测。</b>

#### 🔬 展开：内镜与影像各自「回答什么问题」——设备局限四例

- <b>耳内镜</b>只见外耳道与鼓膜形态，回答不了「听力损失的类型与程度」——判型必须靠音叉+纯音+声导抗。
- <b>胸部 X 线</b>对透光异物或位置特殊者可正常，回答不了「有没有气道异物」——须结合明确异物吸入史与支气管镜（教材P366）。
- <b>EB 病毒抗体</b>阳性只是感染提示，回答不了「鼻咽新生物是不是癌」——确诊靠鼻咽部活组织病理检查（教材P277）。
- <b>颈部彩色多普勒超声</b>给出形态与血流，回答不了「肿块的性质」——对质硬、进行性增大的肿块须进一步行增强 CT/MRI 并考虑活检（教材P14）。
- 记忆句：<b>「形态靠镜、骨与范围靠 CT、毗邻靠增强、定性靠病理」</b>。

### 🔄 主动回忆区

- 耳鼻咽喉头颈外科学研究除《眼》《口腔》《颅内结构》以外，耳、鼻、咽、喉、气管、食管及头颈部的相关疾病，涉及《听觉、平衡、嗅觉、呼吸、吞咽、发声》等功能。（教材P2）
- 额镜的主要作用是《将光源反射并聚焦于检查部位》；使用时瞳孔—窥视孔—反光焦点—检查部位成《一条直线》，单目经窥视孔观察、另一眼《不闭》，与检查部位距离约《25cm》。（教材P11-12）
- 硬性内镜《不能弯曲、图像清晰、适合精细观察》；软性内镜《可弯曲、便于观察深在腔隙、适用于部分儿童或张口受限者》。（教材P13）
- 听力学主观检查有《纯音测听、音叉试验、言语测听、表试验》；客观检查有《声导抗、耳声发射(OAE)、听性脑干反应(ABR)》。（教材P13）
- 设备不可替代：耳内镜不能《判定听力损失的类型与程度》；正常胸片不能《排除气管支气管异物》；EB 病毒检测不能《代替鼻咽癌组织病理确诊》；颈部超声不能《独立确诊所有性质不明的肿块》。（教材P13-14）
- 判断依据：看到「需受检者主观应答」属《主观》，看到「生理反应/反射/诱发」属《客观》。（教材P13）

### ⚠️ 易错陷阱

> [!WARNING] 易错一：把「看得见」当成「能定性」
> 耳内镜见鼓膜完整、外耳道通畅，<b>不能</b>据此排除中耳或内耳病变，更不能判定听力损失类型与程度——必须补做听力学检查。

> [!WARNING] 易错二：错配器械与腔道
> 用硬性内镜去观察鼻咽/喉（拐弯处进不去）、或用耳内镜去查喉，都是「器械—腔道」错配；弯腔道要用软镜。

> [!WARNING] 易错三：数值混淆
> 额镜直径约 8 cm、焦距约 25 cm、窥视孔直径约 1.4 cm；额镜与检查部位约 <b>25 cm</b>，受检者与检查者间距约 <b>25~40 cm</b>；光源在耳后上方约 <b>15 cm</b>。三组数值勿混。

> [!WARNING] 易错四：忽略急症与全身
> 急性进行性咽喉痛、大量鼻出血、脑脊液漏等红旗征要先救急；同时别忘了耳鼻咽喉疾病常与全身状况相关（如变应性鼻炎与哮喘共存）。

### D1 第一性原理

🔴 【掌握级】耳的应用解剖与传声链（外耳·中耳·内耳）（教材P19-31、P39）。

🧬 第一性原理：
耳是一条把「<b>空气振动</b>」转成「<b>内耳液体神经冲动</b>」的传导链：外耳道与鼓膜负责集音，听骨链（锤骨—砧骨—镫骨）把低阻抗的空气声匹配进高阻抗的内耳淋巴，前庭窗之后的耳蜗基底膜负责「按频率分区」感受，再由毛细胞把机械振动转为神经冲动传向听神经（第Ⅷ脑神经耳蜗部）。如果这条链完整，就不存在气骨导差；恰恰因为病变卡在某一环（堵在管道、断在听骨、坏在毛细胞/听神经），才出现传导性、感音神经性或混合性聋。
<b>本质上就是：一条「集音—阻抗匹配—频率定位—换能」的传声链，哪里断，就在哪里丢音。</b>

- 外耳：耳廓 + 外耳道。外耳道全长约 <b>2.5~3.5 cm</b>，呈 <b>S</b> 形，外侧约 <b>1/3 为软骨部</b>（耵聍腺主要分布于此）、内侧约 <b>2/3 为骨部</b>；检查成人外耳道深部或鼓膜时须将耳廓向<b>后上方</b>牵拉使外耳道成一直线（教材P19）。
- 鼓膜：重要标志含松弛部、紧张部、锤骨柄、锤骨短突、鼓膜脐及<b>光锥</b>；光锥通常位于<b>前下部</b>，鼓膜内陷时可变形或消失（教材P21）。
- 中耳：包括鼓室、听骨链、咽鼓管及乳突气房；听骨链自外向内依次为<b>锤骨—砧骨—镫骨</b>，镫骨足板封闭<b>前庭窗</b>；鼓室顶壁即鼓室盖，分隔鼓室与<b>颅中窝</b>，其岩鳞裂在婴幼儿常未闭合，可成中耳感染入颅的途径（教材P22）。
- 咽鼓管：连接鼓室与鼻咽，具有调节鼓室压力、引流分泌物及防止逆流功能；儿童咽鼓管<b>短、宽、近水平，约为成人一半</b>，故小儿上感易经此侵入中耳（教材P24）。
- 声压放大：鼓膜有效振动面积约 <b>55 mm²</b>（约为解剖面积的 2/3），是镫骨足板面积（<b>3.2 mm²</b>）的 <b>17 倍</b>（教材P39）。
- 内耳：位于颞骨岩部，包括耳蜗、前庭和半规管。<b>耳蜗负责听觉</b>；<b>椭圆囊斑、球囊斑</b>（耳石器官）感受<b>直线加速度及重力相关的位置变化</b>；<b>三个半规管壶腹嵴</b>感受<b>角加速度</b>（教材P28、P43）。
- 基底膜频率定位：<b>蜗底（靠前庭窗）感受高频</b>，<b>蜗顶感受低频</b>（教材P31）。

> [!NOTE] 结构速记
> 外耳道「<b>外 1/3 软骨＋内 2/3 骨</b>」；听骨链「<b>锤—砧—镫</b>」；鼓室顶壁邻<b>颅中窝</b>；镫骨足板封<b>前庭窗</b>；耳蜗=听觉、耳石=直线、半规管=角；基底膜「<b>底高顶低</b>」。

> [!WARNING] 易错·感受器配对
> 半规管壶腹嵴感受<b>角加速度</b>（旋转）；椭圆囊斑/球囊斑感受<b>直线加速度与重力</b>（耳石器官）；<b>螺旋器</b>在基底膜上、为<b>听觉</b>感受器，切勿与壶腹嵴混淆。

---

🔴 【掌握级】面神经的走行与损伤定位（教材P36、P136-137）。

🧬 第一性原理：
面神经（第Ⅶ脑神经）像一根沿颞骨「七拐八弯」的电缆：出<b>茎乳孔</b>后进入腮腺，在腮腺内分为<b>颞支、颧支、颊支、下颌缘支、颈支</b>五组终末支，支配面部表情肌；而在<b>颞骨面神经管内</b>，它还发出三支带不同功能的分支——<b>岩浅大神经</b>（经翼腭神经节参与泪腺、鼻腔腺体分泌）、<b>镫骨肌支</b>（支配镫骨肌）、<b>鼓索神经</b>（司舌前 2/3 味觉，并携带副交感纤维参与下颌下腺、舌下腺分泌）。因此，损伤在「哪一段」就露出「哪一段所带分支」的功能缺失：泪液减少→膝状神经节及以上；听觉过敏→镫骨肌支；舌前 2/3 味觉异常→鼓索神经。
<b>本质上就是：面神经按「分段带分支」，哪一段断，该段分支的功能就丢——用分支症状反向定位损伤平面。</b>

- 五终末支：颞支（额肌、眼轮匝肌上部）、颧支、颊支（口轮匝肌等）、下颌缘支（下唇肌群）、颈支（颈阔肌）（教材P36）。
- 颞骨内分支：岩浅大神经、镫骨肌支、鼓索神经；鼓索司<b>舌前 2/3 味觉</b>；镫骨肌支受损→<b>听觉过敏</b>（张大强声保护丧失）（教材P36、P136）。
- 周围性面瘫：同侧<b>额纹消失</b>、闭眼不全、鼻唇沟变浅、口角歪斜；中枢性面瘫：多为<b>对侧下半面部</b>无力而额纹相对保留（教材P136-137）。

> [!WARNING] 周围性 vs 中枢性面瘫
> 关键区别在「<b>额纹</b>」：周围性面瘫<b>同侧额纹消失</b>（全侧面肌受累）；中枢性面瘫<b>对侧下半面弱、额纹相对保留</b>（额肌受双侧皮质支配）。但临床不能只凭额纹判断，需结合完整神经系统检查。

🔴 【掌握级】听力检查与耳聋分类（教材P50-52、P85、P121）。

🧬 第一性原理：
判断聋性看两条路径：<b>气导（AC，经外耳+中耳）</b>与<b>骨导（BC，未经中耳、直接经颅骨刺激内耳）</b>。病变在传导路径（外耳/中耳）→骨导保留、气导下降→出现<b>气骨导差</b>（传导性聋）；病变在感受路径（耳蜗/听神经）→气骨导一致下降、无气骨导差（感音神经性聋）；两者兼有→混合性聋。正因为骨导绕过了外耳与中耳，它才成为「内耳是否健康」的天然参照。
<b>本质上就是：气导测「整条链」，骨导测「后半段」；两者一比，就把病变切成「传导段」还是「感受段」。</b>

- 纯音测听属<b>主观</b>检查，可测气导及骨导阈值；传导性聋有气骨导差，感音神经性聋无气骨导差，混合性聋两者兼有（教材P50-52）。
- 林纳试验（Rinne）：气导大于骨导为<b>阳性</b>（正常/感音神经性聋）；骨导大于等于气导为<b>阴性</b>（典型传导性聋）。
- 韦伯试验（Weber）：单侧传导性聋偏向<b>患耳</b>，单侧感音神经性聋偏向<b>健耳</b>。
- 声导抗：分泌性中耳炎典型为<b>B 型平坦曲线</b>（教材P85）。
- 感音神经性聋常见病因：药物性（氨基糖苷类）、噪声性、遗传性、老年性等（教材P121）。

> [!SUCCESS] 音叉两条铁律
> 「<b>传导性聋偏患侧，感音神经性聋偏健侧</b>」（Weber）；「<b>Rinne 阴=传导性、阳=正常/感音神经性</b>」。音叉只能初步判断，不能代替听力学检查（重度单侧聋可现假阴性 Rinne）。

🔴 【掌握级】外耳疾病群：共同的解剖学原因（教材P77-82）。

🧬 第一性原理：
外耳的解剖共性是「<b>皮薄、骨/软骨近</b>」——外耳道皮下组织极少、皮肤与软骨膜/骨膜紧贴，耳廓软骨靠软骨膜供血。因此任何化脓性炎症都会令神经末梢受压→<b>剧痛</b>；而软骨一旦积脓隔断血供→<b>软骨坏死</b>→愈后耳廓畸形。顺着这一条，即可推出各病：耵聍腺在软骨部→耵聍栓塞（遇水膨胀加重）；角化上皮异常堆积→外耳道胆脂瘤（进行性骨蚀）；软骨膜下积脓→化脓性软骨膜炎（畸形）。
<b>本质上就是：外耳「薄皮近骨」，炎症=剧痛，破坏=畸形/骨蚀。</b>

- 耳廓假性囊肿：软骨内/软骨间隙的<b>局限性浆液性积液</b>，多位于耳廓前面，局部隆起、波动感，透光试验阳性、穿刺抽出<b>淡黄清亮液体</b>，无急性感染表现（教材P77）。
- 耳廓化脓性软骨膜炎：耳廓红肿热痛，严重时成脓破坏软骨；耳垂因不含软骨可相对不受累；常见病原为<b>铜绿假单胞菌</b>和金黄色葡萄球菌（教材P78）。
- 耵聍栓塞：耳闷、听力下降、耳鸣、耳内异物感，遇水膨胀加重；治疗可软化、器械取出或冲洗；<b>疑鼓膜穿孔/外耳道感染/既往耳部手术时不宜盲目冲洗</b>（教材P79）。
- 外耳道胆脂瘤：角化上皮及角化碎屑积聚，可伴外耳道局部<b>骨质侵蚀</b>、耳痛、流脓或恶臭分泌物——与耵聍栓塞的关键鉴别是「<b>进行性骨质破坏</b>」（教材P82）。
- 外耳道异物：充分照明、直视下取出；<b>电池等腐蚀性异物应紧急取出</b>；植物性异物遇水膨胀、鼓膜情况不明或取出困难时不宜随意冲洗（教材P79）。
- 外耳道炎/外耳道疖：耳痛、红肿、分泌物增加，牵拉耳廓或按压耳屏时疼痛明显；疖多位于软骨部含毛囊的外侧区，常由<b>金黄色葡萄球菌</b>引起（教材P80）。
- 外耳湿疹、外耳道真菌病：前者瘙痒、红斑、渗出，重点去刺激、避免搔抓；后者耳痒、耳闷、真菌样菌丝，治疗以直视下清理＋必要时局部抗真菌（教材P78、P81）。

> [!NOTE] 外耳病速记
> 「<b>假性囊肿 → 淡黄清亮、透光阳性</b>；<b>化脓性软骨膜炎 → 铜绿、易畸形</b>；<b>耵聍栓塞 → 遇水膨胀、忌盲冲</b>；<b>外耳道胆脂瘤 → 骨质破坏</b>；<b>疖 → 牵拉耳廓/压耳屏痛</b>」。

🔴 【掌握级】分泌性中耳炎：以传导性听力损失与鼓室积液为特征的中耳非化脓性炎性疾病，儿童高发（教材P83-85）。

🧬 第一性原理：
分泌性中耳炎的核心是「<b>咽鼓管功能障碍 → 中耳通气受阻</b>」。咽鼓管平时闭合、在吞咽/打哈欠时开放以平衡鼓室压；一旦机械阻塞（儿童腺样体肥大、鼻咽肿瘤）或软骨塌陷/肌肉无力，外界空气进不去，中耳内原有气体被黏膜吸收→<b>中耳负压</b>→黏膜静脉扩张、通透性增强→<b>鼓室积液</b>。若负压不解除，黏膜上皮化生、分泌亢进，形成「胶耳」。儿童咽鼓管短平宽、近水平，感染易扩散，故发病率高。
<b>本质上就是：通气被堵 → 中耳变负压 → 吸出积液。</b>

表现与检查：耳闷、听力下降、耳内堵塞感，儿童可表现为反应下降、注意力下降或言语发育受影响；鼓膜可呈琥珀色、内陷、活动度下降，可见液平面或气泡；声导抗呈 <b>B 型平坦曲线</b>（教材P84-85）。

> [!WARNING] 成人单侧必须排癌
> <b>成人单侧原因不明的分泌性中耳炎必须检查鼻咽部</b>（电子鼻咽镜/CT/MRI）以排除鼻咽癌——因分泌性中耳炎可能是鼻咽癌的首发症状。儿童反复中耳积液则应评估<b>腺样体肥大</b>。鼓膜置管并非所有积液都适用，需结合年龄、听力、病程与风险因素。

🔴 【掌握级】急性化脓性中耳炎：中耳黏膜的急性化脓性炎症，多经咽鼓管感染，儿童好发（教材P86-87）。

🧬 第一性原理：
病原经<b>咽鼓管</b>（上感、不当擤鼻、婴幼儿咽鼓管短平宽）进入中耳→黏膜充血水肿、咽鼓管咽口闭塞→鼓室内空气被吸收变负压→渗出转脓→积脓增多、鼓室压升高→<b>鼓膜膨胀、局部坏死溃破→穿孔流脓</b>。穿孔前鼓室压高、牵拉痛觉神经→<b>耳痛剧烈、呈搏动性跳痛</b>；<b>穿孔流脓后压力骤降→耳痛明显减轻</b>、全身症状缓解。
<b>本质上就是：脓把鼓膜「顶破」的过程，就是耳痛由剧痛转减轻的过程。</b>

治疗与用药：止痛、按年龄与严重程度判断是否用抗菌药物；鼓膜穿孔时应避免使用<b>耳毒性氨基糖苷类滴耳液、酒精或低 pH 刺激性制剂</b>，不宜用粉剂堵塞穿孔妨碍引流（教材P86-87）。

> [!NOTE] 穿孔前后对比
> <b>穿孔前</b>：耳痛剧烈（搏动性跳痛）、鼓膜充血膨隆；<b>穿孔后</b>：耳流脓、<b>耳痛明显减轻</b>、体温与全身症状缓解——「<b>脓出痛减</b>」。

---

🔴 【掌握级】慢性化脓性中耳炎与中耳胆脂瘤（教材P87-91）。

🧬 第一性原理：
慢性化脓性中耳炎多由急性期治疗不当迁延而来，表现为鼓膜穿孔背景下持续或反复流脓，伴不同程度传导性聋。传统分三型：<b>单纯型</b>（炎症限于黏膜）、<b>骨疡型（肉芽型）</b>（侵犯骨质、肉芽/息肉）、<b>胆脂瘤型</b>。中耳胆脂瘤<b>不是恶性肿瘤</b>，而是角化上皮及脱落角化物在中耳/乳突内异常积聚，具有<b>局部侵蚀骨质</b>的能力：角化产物持续堆积＋酶与压迫→破坏听骨链、面神经管、迷路骨壁，甚至鼓室盖/乙状窦骨板→传导性聋、面瘫、迷路瘘、眩晕，乃至颅内感染。
<b>本质上就是：胆脂瘤不是「长瘤」，而是「堆积＋溶骨」的破坏性生长，所以必须手术清除。</b>

- 慢性化脓性中耳炎：鼓膜穿孔背景下持续或反复耳流脓、传导性听力下降；教材常以持续流脓超过数周至 <b>6~8 周</b>作为临床描述之一，但不能仅凭单次急性病程时长机械判断（教材P87-88）。
- 中耳胆脂瘤：反复耳流脓、<b>恶臭分泌物</b>、听力下降；鼓膜<b>松弛部或边缘性穿孔</b>是重要线索（教材P90-91）。
- 术前评估：<b>颞骨高分辨率 CT</b>观察上鼓室、鼓窦和乳突区病变、骨质破坏、听骨链及面神经管（教材P91）。
- 局部用药禁忌：鼓膜穿孔者忌耳毒性药物、粉剂堵塞与酚类腐蚀性制剂，可用 <b>3% 过氧化氢溶液</b>清洗拭净脓液（教材P88-89）。

> [!WARNING] 胆脂瘤 + 面瘫 = 骨管受侵
> 慢性胆脂瘤型中耳炎伴<b>周围性面瘫</b>时，应警惕<b>面神经管受侵或破坏</b>，属需尽快评估处理的并发症；治疗以手术清除病灶为核心（术式按病变范围、听力状态、解剖条件个体化）。

🟡 【熟悉级】大疱性鼓膜炎：鼓膜表面出现含液性大疱，常伴明显耳痛，可与急性中耳炎重叠（教材P83）。

机制：鼓膜后上方见一个或多个淡黄/紫色大疱，位于鼓膜上皮层内，内含血液或血浆，破裂后流出少量血性渗出液，<b>无鼓膜穿孔</b>；现代认识不支持将脊髓灰质炎病毒视为其主要病原。｜💡 与急性化脓性中耳炎早期、鼓室积血、蓝鼓膜等鉴别，关键是结合病史、鼓膜形态、听力及中耳积液情况。

🟡 【熟悉级】粘连性中耳炎与中耳胆固醇肉芽肿（教材P91）。

- 粘连性中耳炎：与长期咽鼓管功能障碍、分泌性中耳炎迁延及鼓膜明显内陷有关；鼓膜可粘连于鼓岬或听骨链，造成持续性传导性聋，重者可继发胆脂瘤。
- 中耳胆固醇肉芽肿：与中耳通气引流障碍、出血及胆固醇结晶引起的反应性肉芽组织有关；鼓膜可呈<b>蓝色、深褐色或蓝黑色</b>（「蓝鼓膜」），累及并穿孔时可流出褐色分泌物；MRI 对鉴别价值较高。

🟡 【熟悉级】Hunt 综合征：表现为<b>耳痛、耳部疱疹及周围性面瘫</b>，由带状疱疹病毒感染、主要侵犯<b>膝状神经节</b>所致；耳疱疹是与其他周围性面瘫鉴别的关键（教材P139-140）。

🟢 【了解级】耳的症状学与耳漏性质（教材P67）。

耳科五大症状：耳痛、耳漏、听力损失、耳鸣、眩晕。耳漏性质→病灶：脂性=油性耵聍；浆液性=外耳道湿疹/变应性中耳炎；黏液性=慢性化脓性中耳炎早期/分泌性中耳炎置管后；<b>水样=脑脊液耳漏</b>（颞骨外伤/术后）；脓性=急慢性化脓性中耳炎/外耳道疖；血性=大疱性鼓膜炎/胆固醇肉芽肿/中耳癌等。

🟢 【了解级】耳廓假性囊肿（详见上「外耳疾病群」）、中耳胆固醇肉芽肿（详见上「粘连/胆固醇」）为本模块了解级条目，掌握其「透光阳性/蓝鼓膜」两句话即可。

### D2 因果链：咽鼓管 → 中耳疾病 → 并发症

```text
上呼吸道感染 / 腺样体肥大 / 鼻咽病变 / 呛水或挖耳
        │
        ▼
★ 咽鼓管功能障碍（机械阻塞 或 软骨塌陷）——中耳疾病的「总入口」
        │
        ├─► 中耳通气受阻 → 中耳负压 → 鼓室积液 → ★分泌性中耳炎（B型鼓室图）
        │
        └─► 鼻腔/咽部细菌经咽鼓管上行 → 中耳化脓 → ★急性化脓性中耳炎
                                            │
                                            ▼ 迁延 / 治疗不当
                                    慢性化脓性中耳炎（鼓膜穿孔＋间断流脓）
                                            │
                                            ▼ 角化鳞状上皮侵入
                                    ★中耳胆脂瘤（非肿瘤，破坏性生长）
                                            │
                       ┌────────────────────┼────────────────────┐
                       ▼                    ▼                    ▼
                  听骨链破坏            面神经管破坏          迷路骨壁破坏
                       ↓                    ↓                    ↓
                  传导性聋加重          周围性面瘫          迷路瘘/眩晕
                                            │
                                            ▼（骨壁扩展至鼓室盖/乙状窦）
                                    颅内并发症（脑膜炎/脑脓肿/乙状窦血栓）

外耳侧：皮薄骨近 → 外耳道炎/疖、化脓性软骨膜炎（→耳廓畸形）；耵聍栓塞/外耳道胆脂瘤（→骨蚀）
```

> [!INFO] 读图要点
> 两个「总闸门」：①<b>咽鼓管</b>——中耳一切炎症与积液的入口（所以儿童、鼻咽病变者高发）；②<b>骨质破坏</b>——并发症的开关（胆脂瘤破坏听骨/面神经管/迷路/鼓室盖，把「耳病」升级为「面瘫、眩晕、颅内感染」）。考题问「并发症从哪来」，答案几乎都指向这两条。

### D3 谱系/分层：耳疾病从轻到危的严重度梯度

```text
【轻度·自限/可治愈】外耳道炎、耵聍栓塞、外耳湿疹、耳廓假性囊肿
   ↓ ← 转折点1：感染突破鼓膜、中耳积脓
【中度·感染化脓】急性化脓性中耳炎、分泌性中耳炎（药物可治愈）
   ↓ ← 转折点2：角化上皮侵入、肉芽/骨质破坏
【中重·结构性破坏】慢性化脓性中耳炎（骨疡型）、中耳胆脂瘤 → 手术为主
   ↓ ← 转折点3：破坏面神经管/迷路骨壁/内耳
【重度·功能丧失】周围性面瘫、迷路瘘/眩晕、突发性聋（可控制难恢复）
   ↓ ← 转折点4：骨壁扩展至颅腔
【危急·颅内并发症】脑膜炎、脑脓肿、乙状窦血栓 → 危及生命
```

关键转折点识别：
- 转折点1（外→中耳）：鼓膜被突破或咽鼓管失守——治疗由「局部对症」转为「抗感染＋排脓引流」。
- 转折点2（黏膜→骨质）：炎症超越黏膜侵犯骨质/上皮堆积——治疗转为「以手术为主」。
- 转折点3（→神经/内耳）：面神经管、迷路骨壁破坏——出现面瘫、眩晕，功能损害多不可逆。
- 转折点4（→颅内）：破坏达鼓室盖/乙状窦骨板——进入致命并发症区。

> [!WARNING] 转折点即「报警点」
> 记住每次越级的分水岭指标：<b>穿孔流脓（转折1）→ 骨质破坏/恶臭分泌物（转折2）→ 面瘫/眩晕（转折3）→ 颅内症状（转折4）</b>。考病例题时，看到「恶臭分泌物＋骨破坏」就要想到胆脂瘤并锁定手术路径。

### D4 决策树：眩晕鉴别 + 听力下降鉴别

```text
【眩晕 / 头晕】
├─ 头位改变诱发 + 短暂（通常<1分钟）+ 无耳鸣/听力下降 → ★BPPV（耳石症）
│    └─ Dix-Hallpike / 滚转试验 + 耳石复位
├─ 反复旋转性眩晕 20分钟~12小时 + 波动性听力下降/耳鸣/耳胀满 → ★梅尼埃病（膜迷路积水）
├─ 急性持续性眩晕数天 + 向健侧自发性眼震 + 无听力下降 → ★前庭神经炎
├─ 突发感音神经性听力下降（常72h内）+ 耳鸣 → ★突发性聋（耳科急症，激素一线）
└─ 持续不稳 / 垂直性眼震 / 复视 / 构音障碍 / 肢体无力 → 中枢性（后循环/脑干）→ 头颅影像
```

```text
【听力下降】
├─ Rinne 阴（BC>AC）+ Weber 偏患耳 + 气骨导差 → 传导性聋
│    ├─ 外耳：耵聍栓塞 / 外耳道炎疖 / 异物 / 外耳道胆脂瘤
│    └─ 中耳：分泌性中耳炎(B型图) / 急性化脓性中耳炎 / 慢性化脓性中耳炎 / 胆脂瘤
├─ Rinne 阳（AC>BC）+ Weber 偏健耳 + 气骨导一致下降 → 感音神经性聋
│    ├─ 耳蜗：突发性聋 / 梅尼埃病 / 药物性(氨基糖苷) / 噪声性 / 老年性
│    └─ 听神经/中枢：听神经瘤等
└─ 有气骨导差 + 高频一致性下降 → 混合性聋
```

判断依据：
- 第一分支（眩晕）：<b>持续时间＋有无耳蜗症状</b>是核心——短暂变位性=BPPV、反复数十分钟至数小时伴耳蜗症状=梅尼埃病、持续数天无耳蜗症状=前庭神经炎。
- 第二分支（听力）：<b>气骨导关系</b>先分传导/感音神经，再用「外耳 vs 中耳」「耳蜗 vs 听神经」细分。

> [!TIP] 眩晕三病「一句话分流」
> 「<b>短——BPPV（秒~分钟、变位诱发）；中——梅尼埃（20分钟~12小时、伴耳蜗症状）；长——前庭神经炎（数天、无耳蜗症状）</b>；凡带脑干/小脑体征者先按中枢处理」。

#### 🔬 展开：三型耳聋的音叉与听力图判读

- <b>音叉试验三件套</b>：Rinne（气导 vs 骨导）、Weber（骨导偏向）、Schwabach（骨导对比）。传导性聋 Rinne 阴、Weber 偏患耳；感音神经性聋 Rinne 阳、Weber 偏健耳。
- <b>纯音听力图</b>：传导性聋骨导接近正常、气导提高且以低频为主，存在气骨导差（>10 dB）；感音神经性聋气、骨导一致下降、通常高频损失重，无气骨导差；混合性聋两者兼有。
- <b>判读提醒</b>：轻中度传导性或混合性聋，Rinne 可呈（±）；重度单侧聋可出现假阴性 Rinne——<b>音叉只能初步判断，不能代替听力学检查</b>。
- <b>声导抗定位</b>：B 型（平坦）=鼓室积液；C 型（负压）=咽鼓管功能不良；A 型=中耳功能正常。

#### 🔬 展开：面神经颞骨内走行与损伤定位

- 面神经在颞骨面神经管内发出三支：<b>岩浅大神经</b>（膝状神经节前方发出→经翼腭神经节参与泪腺与鼻腭腺体分泌，故不宜简化为「直接支配泪腺」）、<b>镫骨肌支</b>（支配镫骨肌）、<b>鼓索神经</b>（乳突段发出→舌前 2/3 味觉＋下颌下腺/舌下腺分泌）。
- 损伤定位：泪液分泌减少（Schirmer 试验异常）→<b>膝状神经节及以上</b>；听觉过敏→<b>镫骨肌支</b>；舌前 2/3 味觉异常→<b>鼓索神经</b>。
- 周围性面瘫：同侧额纹消失、闭眼不全、鼻唇沟变浅、口角歪斜；中枢性面瘫：对侧下半面弱、额纹相对保留。
- 慢性胆脂瘤型中耳炎伴周围性面瘫，提示<b>面神经管受侵/破坏</b>，需尽快评估处理。

#### 🔬 展开：外耳道异物/耵聍/胆脂瘤的处理与禁忌

- <b>耵聍栓塞</b>：可软化后取出或冲洗；<b>疑鼓膜穿孔、既往耳部手术、外耳道感染或其他冲洗禁忌时不宜盲目冲洗</b>；长期嵌塞可继发外耳道炎，并可刺激迷走神经耳支致反射性咳嗽。
- <b>外耳道异物</b>：充分照明、直视下取出，避免反复盲目夹取造成嵌顿或鼓膜损伤；<b>电池等腐蚀性异物应紧急取出</b>；植物性异物遇水膨胀、鼓膜情况不明或取出困难时不宜随意冲洗。
- <b>外耳道胆脂瘤</b>：角化上皮堆积，可致外耳道骨质侵蚀、耳痛、流脓或恶臭分泌物；诊断结合耳镜/耳内镜，必要时颞骨 CT 评估骨质破坏，不能简单归结为仅依赖组织病理。
- <b>局部用药禁忌</b>：鼓膜穿孔时不使用耳毒性氨基糖苷类滴耳液、酒精或低 pH 刺激性制剂，不用粉剂堵塞穿孔，避免酚类腐蚀性制剂；可用 3% 过氧化氢溶液清洗拭净脓液。

### 🔄 主动回忆区

- 外耳道全长约《2.5~3.5cm》、呈《S》形，外侧约《1/3》为软骨部（耵聍腺多分布于此）、内侧约《2/3》为骨部；检查成人时耳廓向《后上方》牵拉。（教材P19）
- 鼓膜光锥通常位于《前下部》；听骨链自外向内依次为《锤骨—砧骨—镫骨》，镫骨足板封闭《前庭窗》。（教材P21-22）
- 鼓室顶壁（鼓室盖）分隔鼓室与《颅中窝》；儿童咽鼓管《短、宽、近水平，约为成人一半》→易患中耳炎。（教材P22、P24）
- 鼓膜有效振动面积约为镫骨足板面积的《17 倍》。（教材P39）
- 《椭圆囊斑/球囊斑》感受直线加速度及重力位置变化；《半规管壶腹嵴》感受角加速度；《耳蜗》负责听觉。（教材P28、P43）
- 基底膜频率定位：《蜗底》感受高频、《蜗顶》感受低频。（教材P31）
- 面神经腮腺内五终末支为《颞支、颧支、颊支、下颌缘支、颈支》；鼓索神经司《舌前 2/3 味觉》；镫骨肌支受损→《听觉过敏》；泪液减少提示损害在《膝状神经节及以上》。（教材P36、P137）
- 分泌性中耳炎典型鼓室图《B 型（平坦型）》；成人单侧原因不明者必须排查《鼻咽癌》。（教材P84-85）
- 急性化脓性中耳炎多为《咽鼓管》途径感染；穿孔流脓后耳痛《明显减轻》。（教材P86-87）
- 中耳胆脂瘤常见鼓膜《松弛部或边缘性》穿孔，分泌物《恶臭》，术前评估首推《颞骨高分辨率 CT》。（教材P90-91）
- 梅尼埃病眩晕持续《20 分钟至 12 小时》，基本病理为《膜迷路积水》；BPPV 眩晕《头位改变诱发、通常不超过 1 分钟》、无《耳鸣及听力下降》，治疗《耳石复位》。（教材P113-116）
- 前庭神经炎：急性持续眩晕、向《健侧》自发性眼震、无《听力下降》。（教材P115）
- 突发性聋属《耳科急症》，一线药物为《糖皮质激素》。（教材P122-125）

> 能口述①外耳道分部与牵拉方向；②听骨链顺序；③儿童咽鼓管特点；④三个内耳感受器分工；⑤面神经分支与损伤定位；⑥三型聋＋鼓室图；⑦三种眩晕的持续时间与鉴别；⑧胆脂瘤为什么必须手术——八条齐全，本模块即过关。

### ⚠️ 易错陷阱

> [!WARNING] 易错一：感受器配对错
> 半规管壶腹嵴=角加速度；椭圆囊斑/球囊斑=直线加速度；螺旋器（基底膜上）=听觉。三者常被张冠李戴。

> [!WARNING] 易错二：把「耳痛减轻」当成好转方向错
> 急性化脓性中耳炎<b>穿孔流脓后耳痛减轻</b>是病情发展的表现（脓液引流减压），不代表治愈；鼓膜穿孔后仍须足量抗感染、通畅引流。

> [!WARNING] 易错三：鼓膜穿孔后乱用药
> 忌耳毒性氨基糖苷类滴耳液、酒精、酚类腐蚀性制剂与粉剂堵塞；可用 3% 过氧化氢溶液清洗。这条是高频用药陷阱。

> [!WARNING] 易错四：忽略「耳病 → 面瘫/颅内」的恶化
> 胆脂瘤伴恶臭分泌物、松弛部/边缘性穿孔、面瘫、眩晕，均提示骨质破坏升级，必须尽快评估手术，切勿按普通中耳炎长期观察。

> [!WARNING] 易错五：儿童 vs 成人咽鼓管
> 儿童咽鼓管是「短、宽、近水平」（易感染上行）；成人是「长、窄、较陡直」。方向别记反。

### ✅ 本模块小结

> [!INFO] 本模块小结
> - 传声链：外耳集音 → 鼓膜 → 听骨链（阻抗匹配 17 倍）→ 前庭窗 → 耳蜗（蜗底高、蜗顶低）；外耳/中耳病变致传导性聋，耳蜗/听神经病变致感音神经性聋。
> - 面神经沿颞骨分段带分支，用「泪液/听觉过敏/味觉」定位损伤平面；周围性与中枢性面瘫以「额纹」相区分。
> - 中耳疾病的总入口是<b>咽鼓管</b>，并发症的总开关是<b>骨质破坏</b>；分泌性中耳炎（B 型图）、急性化脓性中耳炎（脓出痛减）、慢性化脓性中耳炎、中耳胆脂瘤（必手术）依次递进。
> - 周围性眩晕三病按「持续时间＋耳蜗症状」分流；突发性聋按耳科急症用激素。
> <b>🧬 本模块核心洞察</b>：耳科的一切都可回到两条主线——「咽鼓管把病送进中耳，骨质破坏把病送出中耳」；面神经与迷路骨壁恰在中耳骨管内穿行，所以中耳的破坏性病变必然外溢为「面瘫、眩晕、颅内感染」。

## 模块3｜鼻科学

模块信息：🔴7 / 🟡4 / 🟢3 ｜ <b>定位</b>：鼻科疾病构成一条从「自限性急性鼻炎」→「急性鼻窦炎」→「慢性鼻窦炎/鼻息肉（引流障碍恶性循环）」→「侵袭性真菌性鼻窦炎/鼻及鼻窦恶性肿瘤」的连续严重度梯度；鼻是呼吸、嗅觉与上气道防御的第一道门户，其两大核心命题是「窦口引流障碍（OMC）」与「危险三角静脉直通海绵窦」。

---

### D1 第一性原理

#### 🔴 【掌握级】鼻腔解剖与生理的「三个地理坐标」（教材P152-161）

💡 为什么重要：鼻中隔构成、利特尔区（Little 区）、鼻窦开口（OMC）是每年必考的定位题底座，鼻出血、鼻窦炎、鼻疖的机制都从这里长出来。

🧬 第一性原理：鼻腔本质是一根「前方经鼻孔进气、后方经后鼻孔出气、侧壁挂三层鼻甲、顶部开嗅裂」的管腔。管腔内壁覆假复层纤毛柱状上皮，纤毛朝鼻咽方向摆动（黏液纤毛清除系统），把黏附的颗粒与微生物「扫」向鼻咽。鼻中隔是两侧鼻腔的分界线，由<b>鼻中隔软骨、筛骨垂直板、犁骨</b>三块骨与软骨拼成（教材P152）。<b>如果鼻中隔居中、纤毛摆动正常、鼻甲舒缩有度，鼻腔就能完成呼吸、过滤、加温、加湿、嗅觉五项功能；一旦某处结构或黏膜出错（偏曲、纤毛不动、黏膜水肿），通气与引流立刻出问题——本质上，鼻腔的一切疾病都是「这根管腔的通气、引流、屏障三者被破坏」的后果。</b>

<b>关键坐标速记</b>（教材P152-161）：
- <b>鼻中隔支架</b>＝鼻中隔软骨＋筛骨垂直板＋犁骨；前下部血管吻合丛＝<b>利特尔区（Little 区）</b>，是前鼻出血最常见部位。
- <b>骨性后鼻孔周界</b>＝蝶骨体＋蝶骨翼突内侧板＋腭骨水平部后缘＋犁骨后缘。
- <b>嗅区黏膜</b>主要分布于<b>鼻中隔上部、上鼻甲及其上方</b>（覆盖嗅细胞、支持细胞、基底细胞）。
- <b>鼻窦开口</b>：额窦、上颌窦、前组筛窦→<b>中鼻道（OMC）</b>；后组筛窦→<b>上鼻道</b>；蝶窦→<b>蝶筛隐窝</b>；鼻泪管开口于<b>下鼻道前部</b>。
- <b>鼻周期</b>＝两侧下鼻甲黏膜充血状态交替的生理性周期，约 <b>2～7 小时</b> 一个循环，受下丘脑调节。
- <b>感觉神经</b>＝三叉神经第一支（眼神经）与第二支（上颌神经）；筛前、筛后神经来自眼神经的鼻睫神经。自主神经：交感经深岩神经、副交感经面神经分出的岩浅大神经，二者在<b>翼管神经</b>汇合后经<b>翼腭神经节</b>分布于鼻腔腺体与血管。

> [!NOTE] OMC 是鼻窦炎的「总开关」
> 窦口鼻道复合体（OMC）＝中鼻道＋筛漏斗＋半月裂等结构，是<b>上颌窦、前组筛窦、额窦</b>引流的共同通道；<b>不包括蝶窦自然开口</b>（蝶窦开口于蝶筛隐窝）。黏液纤毛系统把鼻窦分泌物朝自然窦口「扫」，OMC 一旦黏膜水肿或解剖变异而阻塞，前组鼻窦的通气引流即全线受阻。

#### 🔴 【掌握级】鼻出血：前部 Little 区 vs 后部吴氏丛（教材P222-225）

💡 为什么重要：耳鼻喉最常见急症之一；考点不是「一味填塞」，而是「按部位＋病因分级处理」。

🧬 第一性原理：鼻出血的危险程度由<b>出血部位</b>与<b>病因</b>两个变量共同决定。前部利特尔区是动静脉吻合丛、血管浅表，可指压/烧灼/填塞轻易控制，多见于儿童青少年、量少；<b>后部出血多位于下鼻道后部的吴氏鼻-鼻咽静脉丛或鼻中隔后部动脉（约 90% 来自蝶腭动脉），位置深、血管粗、量大多且仰头易误吸，多见于中老年高血压/动脉硬化</b>。若出血源于全身疾病（高血压、血液病、肝病、抗凝药），单纯局部止血治标、会反复。<b>如果出血点浅、病因单一，局部压迫就够了；一旦出血点深或病因为全身性，就必须动用后鼻孔填塞/介入并同步治因——本质上，鼻出血治疗＝「按部位分级止血＋按病因分流治因」的双轨，休克者先抗休克。</b>

<b>处理要点</b>（教材P223-225）：坐位或半卧位、勿将血液咽下；休克者平卧头低位按低血容量性休克急救。前部：捏紧两侧鼻翼压迫 10～15 分钟＋冷敷，出血点明确者烧灼（<b>避免同时烧灼鼻中隔两侧对称部位，以免穿孔</b>）；出血较剧且部位不明者前鼻孔纱条填塞（一般 24～48 小时，需延长者辅以抗生素、一般不超 3～5 天），未奏效者鼻后孔填塞（一般不超过 3 天，最多不超过 5～6 天，老年者评估心肺）；顽固性出血行 DSA 血管栓塞。全身治疗同时纠正贫血、控制血压、处理血液病。

> [!WARNING] 先止血还是先查病因？
> <b>大量出血者先立即止血、再查病因；长期反复少量出血者则积极寻找病因。</b>紧急时先救命（抗休克、止血），稳定后病因挂帅。切莫仰头止血（血液后流易误吸/刺激胃肠）。

#### 🔴 【掌握级】鼻疖：危险三角与海绵窦血栓性静脉炎（教材P186-187）

💡 为什么重要：鼻疖本身是小病，但位于危险三角，处理不当可酿成致命的颅内并发症。

🧬 第一性原理：鼻尖鼻翼皮肤与软骨膜直接相连、皮下组织少，炎症张力高故疼痛剧烈；而外鼻静脉经内眦静脉、面静脉回流，<b>面部静脉无瓣膜、血可双向流动</b>，内眦静脉又经眼上、下静脉与海绵窦相通。<b>如果盲目挤压疖肿，脓栓被挤进无瓣膜的静脉、逆行入海绵窦，就引发海绵窦血栓性静脉炎（寒战高热、剧烈头痛、患侧眼睑结膜水肿、眼球突出固定、视盘水肿甚至失明）</b>。本质上，鼻疖的危险不在疖本身，而在「血管无瓣膜、直通海绵窦」的解剖条件被人为破坏——<b>致病菌以金黄色葡萄球菌为主，治疗核心是「严禁挤压」。</b>

> [!WARNING] 鼻疖的「忌」与「宜」
> <b>忌</b>挤压、过早切开、切至周围浸润；<b>宜</b>未成熟者抗生素软膏＋理疗，成熟者无菌挑破脓头/钳出脓栓，全身合理用抗生素。题眼「挤压鼻疖后寒战高热＋眶周水肿＋眼球突出」→立即答<b>海绵窦血栓性静脉炎</b>（教材P187）。

#### 🔴 【掌握级】变应性鼻炎：IgE 介导的Ⅰ型超敏（教材P196-198）

💡 为什么重要：最常见慢性鼻病，与支气管哮喘「一个气道、一种疾病」，四大症状与阶梯治疗必考。

🧬 第一性原理：变应性鼻炎是<b>抗原再次暴露</b>导致的超敏反应。第一阶段「致敏」：变应原初次进入，Th2 细胞因子使 B 细胞分化为浆细胞产生 <b>IgE</b>，IgE 结合于肥大/嗜碱性粒细胞膜受体，此时无症状。第二阶段「激发」：同种变应原再次进入，桥接两个 IgE 的 Fab 端，触发肥大细胞<b>脱颗粒释放组胺</b>，引起血管扩张、腺体分泌、神经敏感，于是爆发鼻痒、阵发喷嚏、清水涕、鼻塞。<b>如果机体不再暴露变应原（环境控制）或不产生特异性 IgE（免疫治疗提高耐受），就没有激发相——这就是「对因治疗」的逻辑。本质上，变应性鼻炎＝已致敏免疫系统对同一抗原的再次过度应答（Ⅰ型超敏）。</b>

<b>四大症状</b>＝鼻痒、阵发性喷嚏、大量清水样涕、鼻塞，可伴眼痒；鼻黏膜呈<b>苍白或水肿</b>。查找变应原首选<b>皮肤点刺试验（SPT）</b>或血清特异性 IgE。<b>治疗阶梯</b>：环境控制→鼻用糖皮质激素（一线核心）＋第二代抗组胺药→变应原特异性免疫治疗（<b>唯一对因</b>）→手术（选择性神经切断）。

> [!TIP] 鼻炎「对因 vs 对症」一句话
> 鼻用激素治症状（一线）、免疫治疗治病因（唯一对因）；减充血剂只辅助缓解鼻塞、<b>连续应用不超过 7 天</b>（否则药物性鼻炎）；抗胆碱药只减涕、对鼻痒喷嚏无效。

#### 🔴 【掌握级】急性鼻窦炎：窦口引流障碍是核心（教材P189-195）

💡 为什么重要：最常继发于急性鼻炎；「好发顺序（前组＞后组、上颌窦＞筛窦）＋病程判断＋通引流」是核心考点。

🧬 第一性原理：急性鼻窦炎＝鼻窦黏膜急性炎症＝<b>窦口引流障碍</b>的结果。无论病毒或细菌，第一步都是 OMC 被黏膜肿胀、分泌物堵塞，窦腔通气引流受阻；堵塞后分泌物淤积成为细菌培养基，黏膜由卡他转化脓，产生脓涕＋窦区炎性头痛＋嗅觉减退。<b>引流一旦恢复（收缩黏膜、纤毛排除、穿刺/手术开放），感染即可控制；若引流持续受阻，则急性迁延为慢性。</b>

<b>定位要点</b>：上颌窦＞筛窦，前组＞后组。头痛投影——上颌窦晨轻午后重（面颊/上颌磨牙）、额窦晨起重午后渐轻（前额周期性）、筛窦无节律（内眦/鼻根）、蝶窦晨轻午后重（头颅深部/枕部）。<b>急性细菌性鼻窦炎判断</b>：症状持续至少 10 天无改善，或先改善后再次明显加重；常见病原＝肺炎链球菌、流感嗜血杆菌、卡他莫拉菌（但并非所有急性鼻窦炎都由细菌引起）。<b>首选影像＝鼻窦CT</b>；鼻内镜直视中鼻道脓涕是有效诊断工具。

| 鼻窦 | 头痛部位 | 时间/节律 |
|---|---|---|
| 急性上颌窦炎 | 面颊部/上颌磨牙痛 | 晨轻、午后重 |
| 急性额窦炎 | 前额部（周期性真空性痛） | 晨起重、午后渐轻消失 |
| 急性筛窦炎 | 内眦/鼻根部，可放射头顶 | 无明显节律 |
| 急性蝶窦炎 | 头颅深部/眼球深处/枕部 | 晨轻、午后重 |

#### 🔴 【掌握级】慢性鼻窦炎与鼻息肉：引流障碍的恶性循环（教材P201-207）

💡 为什么重要：慢性鼻窦炎是鼻科最常见慢性病，CRSsNP/CRSwNP 分型决定治疗策略。

🧬 第一性原理：慢性鼻窦炎（CRS）＝病程<b>超过 12 周</b>的鼻窦黏膜慢性炎症，本质是「引流障碍」与「慢性炎症」互为因果、自我维持的恶性循环：局部炎症（细菌生物膜、病毒破坏上皮屏障、变应原致黏膜肿胀、解剖异常阻塞 OMC）→窦口引流受阻→分泌物淤积→细菌过度增殖→炎症加重、上皮破坏→组织重塑/息肉（CRSwNP）→息肉又机械性堵塞 OMC→引流更进一步受阻。<b>只要这个「堵→积→感→更堵」循环不被打破，炎症就不可能自愈，只能靠药物（激素抗炎、促排、冲洗通引流）或手术（FESS 开放窦口）打断。</b>

<b>分型</b>：不伴息肉（CRSsNP，主要症状＝鼻塞＋黏脓涕必具其一）与伴息肉（CRSwNP，双侧中鼻道灰白半透明息肉、嗅觉减退）。<b>诊断三要素</b>：主要症状（鼻塞、黏脓涕）必具其一＋病程＞12 周＋可加次要症状（头面胀痛、嗅觉减退）。<b>治疗</b>：鼻用糖皮质激素＋鼻腔冲洗至少 3 个月，疗效不佳再行功能性内镜鼻窦手术（FESS）。

> [!NOTE] CRSsNP 诊断的「灵魂」
> 主要症状（鼻塞、黏脓涕）<b>必具其一</b> ＋ 病程<b>＞12 周</b>。CT 可辅助但不作诊断必要条件。CRSwNP 则强调「双侧灰白半透明息肉＋双侧进行性鼻塞／嗅觉减退」，术后需长期鼻用激素防复发。

#### 🔴 【掌握级】鼻中隔偏曲与鼻外伤（鼻骨骨折/鼻中隔血肿）（教材P219-221、P181）

💡 为什么重要：鼻塞/鼻出血/反射性头痛的常见病因；「有无症状」决定是否手术，「鼻中隔血肿」是外伤后必须及时处理的关键点。

🧬 第一性原理：鼻中隔居中时分隔两侧鼻腔；偏曲时狭窄侧气流受阻→鼻塞，凸面/骨棘黏膜薄、受气流尘埃刺激易糜烂→鼻出血，凸出部压迫同侧鼻甲→反射性头痛。<b>但鼻中隔几乎无人完全居中，大多数人偏曲而无症状（生理性）；只有偏曲引起症状时才称病理性、才需矫正——本质上，鼻中隔偏曲是「形态异常」，要不要治取决于「是否因它产生了症状」。</b>

<b>鼻骨骨折</b>（P181）：鼻骨上端窄而厚、下端宽而薄，外伤易骨折并向下塌陷，表现为鼻部畸形、压痛、肿胀及鼻塞。<b>鼻中隔血肿</b>（P220）：外伤后鼻中隔出现<b>暗红色膨隆、触之有波动感</b>，双侧鼻塞、无全身感染表现，穿刺抽出血液；需及时由专科医师<b>引流</b>，以防软骨缺血坏死、感染及<b>鞍鼻畸形</b>。若继发感染则成鼻中隔脓肿（寒战发热、鼻梁鼻尖红肿热痛、穿刺抽出脓液），须立即切开引流。

> [!WARNING] 「隆起」莫混淆
> 鼻中隔血肿/脓肿的共同鉴别点是「隆起对血管收缩剂<b>无反应</b>」（与可收缩的下鼻甲黏膜肿胀不同）；血肿＝抽出血、无明显全身症状，脓肿＝抽出脓、伴寒战发热。<b>鼻中隔血肿未及时引流→软骨坏死→鞍鼻</b>（教材P220）。

#### 🟡 【熟悉级】慢性单纯性鼻炎 vs 慢性肥厚性鼻炎（教材P174）

💡 为什么重要：以「鼻塞是否交替＋减充血剂反应」做鉴别，是鼻炎类高频鉴别题。

<b>慢性单纯性鼻炎</b>：间歇性、交替性鼻塞，下鼻甲黏膜充血肿胀但<b>收缩能力较好</b>，用鼻用减充血剂后鼻甲明显缩小。<b>慢性肥厚性鼻炎</b>：持续性鼻塞，下鼻甲肥厚、表面可呈结节状或桑葚状，<b>用减充血剂后收缩较差</b>。治疗先病因控制与药物治疗，药物无效时按病情选择手术，<b>不应将下鼻甲大部分切除作为所有病例的首选</b>。

#### 🟡 【熟悉级】真菌球型鼻窦炎：单侧＋钙化是关键线索（教材P208-210）

💡 为什么重要：CT 高密度影＋点状钙化＝题眼；须与侵袭性真菌性鼻窦炎鉴别。

<b>真菌球型鼻窦炎</b>多单窦（上颌窦最多）、免疫正常，CT 见窦腔内<b>不规则高密度影、点状或斑片状钙化</b>，可伴窦壁硬化或骨质重塑；治疗以<b>手术清除真菌团块、恢复引流</b>为主。须与<b>侵袭性真菌性鼻窦炎</b>鉴别——后者（曲霉/毛霉）可侵犯血管与周围组织，在免疫功能低下者中进展快、可致命，须紧急清创＋抗真菌。

> [!WARNING] 「单侧＋钙化」提示真菌
> 普通慢性鼻窦炎常双侧、CT 弥散黏膜增厚；<b>真菌球多单侧、上颌窦、CT 见高密度钙化影、术中干酪灰黑团块、可有恶臭</b>。「反复发作＋单侧＋影像钙化」是提示真菌性鼻窦炎的重要线索，与恶性肿瘤（骨质破坏、进展快）鉴别，鉴别困难靠病理确诊。

#### 🟡 【熟悉级】鼻源性眶内并发症（教材P203）

💡 为什么重要：儿童急性鼻窦炎尤其需警惕；视力下降与眼球活动障碍是危险信号。

筛窦与眼眶内侧壁仅隔薄的<b>纸样板</b>，上颌窦位于眶底下方，额窦与眶顶及前颅底关系密切，蝶窦/后组筛窦与视神经、眶尖及颅底关系密切。鼻窦炎可扩散至眼眶，引起眶内炎性水肿、眶蜂窝织炎或眶骨膜下脓肿。<b>眼睑红肿、眼球突出、眼球活动受限、视力下降</b>提示可能存在眶内并发症，须结合临床与增强 CT/MRI 鉴别。

#### 🟡 【熟悉级】鼻腔及颌骨囊肿（教材P230）

💡 为什么重要：以「是否含未萌出牙冠」区分含牙囊肿与牙根囊肿。

<b>含牙囊肿</b>：上颌骨囊性病变若含有<b>未萌出牙齿的牙冠</b>；<b>牙根囊肿</b>：通常与无活力牙齿根尖部慢性炎症相关，须结合牙齿活力、病变与牙根的关系及影像学表现鉴别。

#### 🟢 【了解级】鼻前庭炎、鼻中隔穿孔与萎缩性鼻炎（教材P186、P221、P199-200）

- <b>鼻前庭炎</b>：鼻前庭皮肤弥漫性炎症，由鼻腔分泌物刺激、挖鼻/摩擦致损伤继发；急性期疼痛红肿触痛、重者糜烂结痂，慢性期发痒干燥、皮肤增厚；须与鼻前庭湿疹鉴别（湿疹为全身湿疹局部表现、瘙痒剧烈）。
- <b>鼻中隔穿孔</b>：各种原因致鼻中隔贯穿两侧鼻腔的永久性穿孔，病因有外伤（挖鼻、化学/粉尘刺激）、医源性（鼻中隔手术）、感染（白喉/结核/梅毒）等；<b>小穿孔位于鼻中隔前段时呼吸有吹哨声</b>；单纯穿孔可行穿孔修补术。
- <b>萎缩性鼻炎</b>：以鼻黏膜萎缩为特征，鼻黏膜干燥、鼻腔宽大、鼻甲缩小、大量黄绿脓痂、可有恶臭（「臭鼻症」），严重者鼻梁宽平呈<b>鞍鼻</b>；<b>无特效疗法</b>，以生理盐水冲洗去痂、复方薄荷油润滑、补充维生素等综合治疗为主。

> [!NOTE] 鼻科第一性原理一句话速记
> <b>窦口一堵，鼻窦必炎（OMC 是总开关）；静脉无瓣，鼻疖必险（危险三角直通海绵窦）；抗原一遇，鼻子必痒（IgE Ⅰ型超敏）；部位一深，出血必凶（Little 区易控、吴氏丛难止）。</b>鼻科全部考点，都围绕「通气—引流—屏障」三条主线展开。

<b>鼻窦炎/鼻息肉「引流障碍」恶性循环</b>（★＝关键转折点）

```text
鼻腔/鼻窦炎症（变应性、病毒、细菌、上皮屏障破坏）

(2) 窦腔通气+引流障碍 → 分泌物淤积
        │
        ▼
(3) 黏液潴留 → 细菌繁殖/生物膜形成（金葡菌超抗原）
        │
        ▼
(4) 炎症加重、上皮破坏 → 2型炎症/嗜酸性粒细胞浸润
        │
        ▼

        │
        ▼
★(6) 息肉/增生再次堵塞 OMC → 引流更恶化 → 回到(2)   （恶性循环）
        │
```

### D3 谱系/分层

<b>鼻科疾病严重度谱系：从自限到危重</b>（★＝转折点）

```text
急性鼻炎（病毒感染，自限 7~10 天）   ★自限轻症
        │  若继发细菌、沿窦口蔓延
        ▼
急性鼻窦炎（脓涕＋窦区头痛，首选 CT/内镜＋药物可愈）
        │  若引流持续受阻、病程 >12 周
        ▼
慢性鼻窦炎 / 鼻息肉（CRSsNP/CRSwNP，慢性炎症＋引流恶性循环）
        │  若免疫低下 + 侵袭性真菌 / 上皮恶变
        ▼
★终末危重：急性侵袭性真菌性鼻窦炎 / 鼻及鼻窦恶性肿瘤
```

> [!TIP] 谱系解读
> 鼻科疾病的升级都遵循「<b>炎症范围越广、引流越受阻、免疫越低下 → 越危重</b>」：急性鼻炎（黏膜表层）→急性鼻窦炎（窦腔）→慢性鼻窦炎/息肉（窦口与组织重塑）→侵袭性真菌/恶性肿瘤（骨质与邻近器官）。判定某病严重度的两个抓手＝<b>病程时长</b>与<b>是否侵犯骨质/眶颅</b>。

### D4 鉴别决策树

<b>决策树一：「鼻塞（±脓涕）」鉴别</b>（⭐＝诊断要点）

```text
首诉：鼻塞（±脓涕）
   ├─ 急性起病＋发热＋病程 7~10 天 → 急性鼻炎（病毒、自限，P189）
   ├─ 单侧持续鼻塞＋脓涕＋窦区面/额胀痛 → 急性鼻窦炎
   │     ⭐中鼻道/嗅裂脓涕；鼻内镜＋鼻窦CT；通引流（P191）
   │        ↘ 病程 >12 周、反复 → 慢性鼻窦炎（CRS）
   ├─ 双侧进行性鼻塞＋清涕/黏涕＋嗅觉减退，见双侧灰白半透明息肉 → 鼻息肉（CRSwNP，P204）
   ├─ 鼻痒＋阵发喷嚏＋清水涕（＋眼痒）＋无发热 → 变应性鼻炎（SPT/sIgE 阳性，P196）
   │        ↘ 变应原检测阴性、与温度/情绪/刺激气体相关 → 血管运动性鼻炎（P198）
   ├─ 单侧鼻塞、交替、偏曲侧重＋鼻出血＋反射性头痛 → 鼻中隔偏曲（P219，有症状才手术）
   ├─ 单侧鼻塞＋涕血＋恶臭，CT 见点状钙化 → 真菌球型鼻窦炎（P209）
   └─ 进行性加重＋涕血＋头痛 → 警惕鼻腔鼻窦恶性肿瘤（P235）
          ⭐凡鼻塞伴血染涕，应警惕恶性肿瘤
```

<b>决策树二：鼻出血处置</b>（⭐＝分级要点）

```text
鼻出血（epistaxis）
   ├─ 先评估：出血量？哪侧？部位？全身病因（高血压/血液病/抗凝药/肝病）？
   │     ↳ 大量出血/休克 → 平卧头低位、低血容量休克急救、补液抗休克
   ├─【前部】（儿童青少年、Little 区）
   │     → 捏鼻 10~15min/冷敷 → 烧灼（电凝/激光）→ 前鼻孔纱条填塞
   │     ⭐可局部止血；烧灼避免对侧对称部位（防穿孔）
   ├─【后部】（中老年高血压、吴氏静脉丛/蝶腭动脉 90%）
   │     → 前鼻孔填塞未奏效 → 鼻后孔填塞/气囊压迫（评估心肺、≤3~5~6 天、防误吸）
   │     ⭐量大动脉性难控 → 顽固性 → 血管栓塞（SSE）/血管结扎
   └─【全身病因】高血压→控压；血液病→输血小板/因子；肝病→凝血纠正；抗凝药→停/调
         ⭐反复少量者先找病因；大量者先止血再查病因（双轨）
```

> [!WARNING] 鉴别三条底线
> ①「鼻塞＋脓涕＞12 周」＝慢性鼻窦炎；「脓涕＋病程≥10 天无改善」＝急性细菌性鼻窦炎；②鼻疖/鼻前庭区红肿＋挤压史＋眶周水肿＝海绵窦血栓；③鼻塞伴<b>血染涕且进行性加重</b>，别只当炎症——先排除恶性肿瘤。

#### 🔬 展开：OMC 与各窦开口的「地理坐标」

窦口鼻道复合体（OMC）是<b>中鼻道</b>内上颌窦、前组筛窦、额窦的共同引流通道，涉及筛漏斗、半月裂等结构，<b>不包括蝶窦自然开口</b>。四组鼻窦开口归纳：额窦、上颌窦、前组筛窦→中鼻道（经 OMC）；后组筛窦→上鼻道；蝶窦→蝶筛隐窝；鼻泪管→下鼻道前部。因为 OMC 是「共用下水道」，任一前组鼻窦的黏膜水肿或解剖变异都会牵累其余前组鼻窦——这解释了为什么急性鼻窦炎常「前组多发、上颌窦最好发」。（教材P155-160）

#### 🔬 展开：鼻腔鼻窦手术的解剖风险

鼻腔鼻窦手术必须熟悉四组关键毗邻：<b>筛板（筛骨水平板）</b>菲薄，损伤可致脑脊液鼻漏；<b>眶纸样板</b>是筛窦与眼眶间最薄的骨壁，损伤可致眶内并发症；<b>鼻泪管</b>开口于下鼻道前部，损伤致泪溢；<b>蝶窦外侧壁</b>毗邻海绵窦、颈内动脉与视神经管，气化好者此壁菲薄，手术失误可致失明或致命性大出血。（教材P159-160）

#### 🔬 展开：鼻出血填塞时间与并发症

前鼻孔纱条填塞一般 24～48 小时，须延长者辅以抗生素、一般不超 3～5 天；鼻后孔填塞一般不超过 3 天、最多不超过 5～6 天，老年者填塞前评估心肺功能。鼻腔填塞可致血氧分压降低、二氧化碳分压升高，故老年患者应警惕心肺脑功能、必要时吸氧。切勿仰头止血，以免血液后流误吸或刺激胃肠。（教材P223-225）

> 4. 分隔筛窦与眼眶的菲薄骨壁是《纸样板》；嗅区黏膜主要分布于《鼻中隔上部、上鼻甲及其上方》。
> 5. 鼻疖最常见致病菌是《金黄色葡萄球菌》，严禁《挤压》，最严重的颅内并发症是《海绵窦血栓性静脉炎》。
> 6. 变应性鼻炎由《IgE》介导《Ⅰ型》超敏，四大症状＝《鼻痒、阵发喷嚏、清水涕、鼻塞》，唯一对因治疗是《变应原特异性免疫治疗》。
> 7. 急性细菌性鼻窦炎：症状持续至少《10 天》无改善，或好转后再次加重；常见病原＝《肺炎链球菌、流感嗜血杆菌、卡他莫拉菌》。
> 8. 慢性鼻窦炎病程《＞12 周》，主要症状《鼻塞＋黏脓涕》必具其一；首选影像＝《鼻窦CT》。
> 9. 上颌骨囊性病变含未萌出牙齿牙冠者→《含牙囊肿》；鼻部外伤后鼻中隔对称暗红隆起、波动感→《鼻中隔血肿》，须《引流》防《鞍鼻》。

### ⚠️ 易错陷阱

> [!WARNING] 陷阱一：OMC 「不包括」什么
> OMC 涉及上颌窦、前组筛窦、额窦的相关引流通道，<b>不包括蝶窦自然开口</b>（蝶窦开口于蝶筛隐窝）。这是「不属于 OMC」类选择题的标准答案，务必与「后组筛窦开口于上鼻道」一起记死。

> [!WARNING] 陷阱二：鼻疖「坚决不挤压」
> 面部静脉无瓣膜、内眦静脉直通海绵窦，挤压鼻疖＝人为把脓栓送进颅内。题眼「挤压后寒战高热＋眶周水肿＋眼球突出」＝海绵窦血栓性静脉炎。

> [!WARNING] 陷阱三：鼻出血「先止血还是先查病因」
> <b>大量出血者先抢救止血、再查病因；长期反复少量者先找病因。</b>仰头止血、只做局部处理而不评估全身病因都是考点陷阱。

### ✅ 本模块小结

> [!NOTE] 本模块小结
> - 鼻腔一切疾病围绕「<b>通气—引流—屏障</b>」三条主线：OMC 是前组鼻窦的「总开关」，堵则鼻窦必炎。

## 模块4｜咽部疾病与睡眠呼吸障碍

模块信息：🔴8 / 🟡4 / 🟢3 ｜ <b>定位</b>：咽是呼吸道与消化道共享的「十字路口」，疾病谱系由「表浅黏膜炎症」→「淋巴器官化脓」→「深部筋膜间隙脓肿」→「恶性肿瘤」→「慢性上气道梗阻（OSAHS）」严重度递增；本模块核心是「腔道被堵/被侵蚀」的定位思维，以及「感染越被膜」「睡眠时气道塌陷」两条关键机制链。

---

### D1 第一性原理

#### 🔴 【掌握级】咽的应用解剖与咽淋巴环（教材P248-253）

💡 为什么重要：咽隐窝、咽鼓管咽口、咽淋巴环、咽肌分群与三间隙是所有咽病的「地理坐标」，定位题必考。

🧬 第一性原理：咽上起颅底、下至环状软骨下缘（约平<b>第 6 颈椎</b>）移行为食管，以<b>软腭平面</b>分鼻咽/口咽、以<b>会厌上缘</b>分口咽/喉咽。鼻咽的<b>咽隐窝</b>（咽鼓管圆枕后上方与咽后壁之间的凹陷）隐蔽且黏膜上皮易受刺激增生，是鼻咽癌好发部位之一；鼻咽侧壁的<b>咽鼓管咽口</b>连通中耳、调节中耳气压。<b>如果咽隐窝与咽鼓管咽口不出问题，鼻咽病变与耳部症状（单侧耳闷、分泌性中耳炎）就不会纠缠在一起——本质上，咽部各病就是「腔道在哪里被堵或被侵蚀」的定位器。</b>

<b>三大关键结构</b>：
- <b>咽淋巴环（Waldeyer 环）内环</b>＝咽扁桃体（腺样体）＋咽鼓管扁桃体＋腭扁桃体＋舌扁桃体＋咽侧索＋咽后壁淋巴滤泡；腺样体<b>10 岁后逐渐退化萎缩</b>。
- <b>咽肌</b>：咽缩肌群（咽上/中/下缩肌）与<b>咽提肌群</b>（茎突咽肌、腭咽肌、咽鼓管咽肌）；吞咽时软腭向后上方抬起、与咽后壁贴合完成<b>腭咽闭合</b>，防止食物反流至鼻咽。
- <b>喉咽易嵌顿结构</b>＝梨状窝（异物易嵌顿，其黏膜下有喉上神经内支通过）、会厌谷、环后区；<b>腭扁桃体</b>位于腭舌弓与腭咽弓之间的扁桃体窝内。

> [!TIP] 咽峡与腭咽闭合
> 咽峡由上方悬雍垂与软腭游离缘、下方舌背、两侧腭舌弓与腭咽弓围成。吞咽时软腭上提、与咽后壁贴合关闭鼻咽峡，完成腭咽闭合——这是「食物不反流鼻腔、说话不带鼻音」的解剖基础。

#### 🔴 【掌握级】腺样体肥大：儿童鼻塞+张口呼吸+分泌性中耳炎的「上游病因」（教材P266-268）

💡 为什么重要：既是分泌性中耳炎的上游，又是儿童 OSA 的强指征；「腺样体面容」与阻塞分度常考。

🧬 第一性原理：腺样体（咽扁桃体）位于鼻咽顶后壁，2～6 岁增生旺盛。若因反复感染而病理性肥大，它会同时堵住两个「路口」：<b>向后堵鼻后孔→鼻塞、张口呼吸、打鼾、睡眠呼吸暂停、闭塞性鼻音；向侧方压咽鼓管咽口→中耳通气障碍→分泌性中耳炎</b>。长期张口呼吸还可能影响颌面发育，形成「腺样体面容」（上颌骨变长、硬腭高拱、牙列不齐、上切牙突出）。<b>如果腺样体不肥大，鼻后孔与咽鼓管咽口都通畅，鼻塞与中耳问题就不会同时出现——本质上，腺样体肥大是「一个病灶、两处堵塞」的典型。</b>

<b>检查</b>：鼻咽镜直接观察（可按阻塞鼻后孔程度分四度：Ⅰ度≤25%、Ⅱ度 26%~50%、Ⅲ度 51%~75%、Ⅳ度＞75%），部分患儿可用鼻咽侧位 X 线初步评估。<b>治疗</b>：根据症状、阻塞程度、有无睡眠呼吸障碍及耳部并发症选择观察、药物治疗或腺样体切除术。

#### 🔴 【掌握级】急性扁桃体炎：乙型溶血性链球菌与青霉素（教材P260-262）

💡 为什么重要：考点集中在「病原＝乙型溶血性链球菌、首选青霉素、链球菌后风湿热与肾小球肾炎」。

🧬 第一性原理：正常咽部与扁桃体隐窝本就潜伏病原体，受凉、劳累使抵抗力下降，病原体大量繁殖、毒素破坏隐窝上皮、细菌侵入实质，炎症即爆发。<b>乙型溶血性链球菌</b>既引起局部化脓（高热、咽痛剧烈、扁桃体充血肿大伴脓点/隐窝脓栓），又可诱发<b>Ⅲ型变态反应</b>攻击心脏、关节、肾脏。<b>如果链球菌只停留局部、不激起免疫交叉反应，就不会有风湿热与肾小球肾炎——这正是「既要足量杀菌、又要防后遗症」的根本原因。本质上，急性扁桃体炎是「局部感染＋全身免疫靶器官受累风险」的双重事件。</b>

<b>治疗</b>：隔离、卧床、流质多饮水；<b>抗生素首选青霉素</b>（过敏者改大环内酯类），疗程要足；局部含漱；反复发作或已有并发症者，<b>急性炎症消退后再行扁桃体切除术</b>。需与咽白喉等鉴别（咽白喉假膜坚韧、超出扁桃体范围、不易擦去）。

#### 🔴 【掌握级】慢性扁桃体炎：「反复急性发作史」才是诊断依据（教材P262-263）

💡 为什么重要：教学重点是「反复急性发作史是诊断要点、扁桃体大小不是标准」及病灶性扁桃体炎的手术决策。

🧬 第一性原理：每次急性发作都让隐窝上皮坏死、细菌与炎性渗出物积聚；若隐窝口因瘢痕粘连而引流不畅，脓栓/渗出物「出不去」，就成为长期潜伏的<b>病灶</b>。为自保，机体或让淋巴与结缔组织增生（增生型、肥大质软），或让淋巴组织萎缩被纤维取代（纤维型、小而硬，病灶感染多为此型）。<b>如果每次急性发作后隐窝都能彻底引流、不反复，就不会形成这个「病灶」；一旦形成，它可借变态反应持续向全身放电（风湿、肾炎）——本质上，慢性扁桃体炎不是「扁桃体大不大」的问题，而是「一个反复化脓、隐含全身风险的慢性病灶」。</b>

<b>手术指征</b>：反复急性发作或多次并发扁桃体周脓肿；过度肥大妨碍吞咽/呼吸/发声；已成为其他脏器病变的病灶；扁桃体角化症、白喉带菌者保守无效等。<b>扁桃体大小并不表明炎症程度，不能据此诊断。</b>

#### 🔴 【掌握级】扁桃体周脓肿：「感染越过被膜」的典型（教材P269-270）

💡 为什么重要：急性扁桃体炎最常见的局部并发症；「咽痛＋张口受限＋悬雍垂偏向健侧」是其考场面孔，确诊靠穿刺，治疗先穿刺后切开。

🧬 第一性原理：腭扁桃体仅内侧面朝向咽腔，其余被结缔组织<b>被膜</b>包裹，被膜与咽腱膜之间是疏松无屏障的<b>扁桃体周间隙</b>。急性扁桃体炎时，扁桃体上隐窝的炎症使窝口阻塞，细菌与炎性产物<b>穿透被膜</b>、进入此间隙迅速积脓。脓腔扩大后压迫周围软组织：刺激<b>翼内肌→张口困难</b>；使患侧扁桃体及腭舌弓、软腭红肿突出、悬雍垂水肿并<b>偏向健侧</b>；引起「口含汤圆音」般的言语含糊、吞咽痛向同侧耳部放射。<b>如果被膜不被穿透，感染本可被抗生素控制而不至于「顶起」软腭、锁住嘴巴——本质上，扁桃体周脓肿就是扁桃体的感染越过被膜后，在一个无阻力间隙里「把周围结构都顶开」的结果。</b>

<b>诊断</b>：超声助鉴别扁桃体周炎与脓肿，<b>穿刺抽出脓液即可确诊</b>。<b>治疗</b>：脓肿形成前按急性扁桃体炎处理（足量抗生素＋适量激素）；形成后<b>先穿刺抽脓、再切开排脓</b>，多次发作者在炎症消退 2 周后行扁桃体切除。

#### 🔴 【掌握级】咽后脓肿：婴幼儿的「贴着气道」危重急症（教材P270-271）

💡 为什么重要：好发于 3 岁以下婴幼儿；检查与治疗都强调「防止脓液误吸/窒息」——体位与操作都要为防误吸让路。

🧬 第一性原理：咽后隙在椎前筋膜与颊咽筋膜之间，每侧含淋巴结，<b>婴幼儿淋巴结多（3~8 个/侧）、成人极少</b>，故咽、口、鼻腔感染可使其化脓形成脓肿（急性型，多见于 3 岁以下）。脓肿位于咽后壁侧方、向前隆起，<b>从后方向前压迫喉腔与喉入口</b>，直接造成吞咽困难与吸气性呼吸困难。<b>如果脓肿局限且不破裂，或能先穿刺把脓液吸走再切开，气道就不会被脓液「淹没」；若强行坐位检查或未先穿刺就大口切开，脓液可瞬间灌入气管窒息——本质上，咽后脓肿是「贴着气道、边切边可能引爆」的危重急症，一切体位与操作都要为防误吸让路。</b>

<b>处理要点</b>：确诊后<b>及早切开排脓</b>，取<b>仰卧低头位</b>，<b>先以长粗穿刺针抽脓</b>，再于脓肿底部作纵切口、长血管钳撑开排脓。结核性者不可在咽部切开。

> [!WARNING] 咽后脓肿「三禁一备」
> <b>严禁坐位/强行压舌板检查</b>（易诱发脓液破入气道）；正确体位是<b>仰卧低头位</b>；<b>先穿刺吸脓、再切开排脓</b>；局麻切开时若脓液大量涌出，应<b>转身俯卧</b>吐出，必要时<b>气管切开</b>备用。别把「防误吸」落成「防感染」——这是本题的题眼。

#### 🔴 【掌握级】鼻咽癌：咽隐窝 + EB 病毒 + 放疗敏感（教材P279-281）

💡 为什么重要：「隐蔽部位＋EB 病毒＋放疗敏感」三位一体；症状四联与「单侧耳闷、颈深上无痛性肿物」是最强鉴别线索，确诊靠病理、治疗首选放疗。

🧬 第一性原理：鼻咽位置隐蔽，早期症状不典型。咽隐窝病灶有两处「近水楼台」：一是向上、向外<b>破坏颅底骨质，经破裂孔与颈动脉管侵犯岩骨尖</b>，引起第Ⅴ、Ⅵ（外展→复视）等脑神经损害；二是向侧方<b>压迫咽鼓管咽口</b>，阻塞引流→同侧耳鸣、耳闭塞感、听力下降、分泌性中耳炎；同时经淋巴向<b>颈深上淋巴结</b>转移（早期即可出现，始单侧继双侧）。<b>如果鼻咽癌只局限在黏膜而不向颅底、咽鼓管与颈淋巴结扩张，它就不会「伪装」成耳闷或「无名肿块」而逃过早期发现——本质上，鼻咽癌是一个「病灶小、破坏路径多、常借道中耳和颈部淋巴结来表达自己」的隐匿癌。</b>

<b>症状四联</b>：①鼻部——回吸涕中带血、鼻塞；②耳部——咽鼓管阻塞致耳鸣、耳闭塞感、听力下降、分泌性中耳炎；③颈部——早期即可出现<b>颈深上无痛性肿大淋巴结</b>；④脑神经——复视（Ⅵ）、头痛、面部麻木、Ⅸ~Ⅻ障碍。<b>检查与诊断</b>：鼻咽镜（含 NBI）＋鼻咽部活组织病理＝<b>确诊金标准</b>；EB 病毒血清学为<b>辅助信息，不能替代病理确诊</b>。<b>治疗</b>：<b>以放射治疗为主的综合治疗为首选</b>，局部晚期常同步放化疗。

> [!SUCCESS] 鼻咽癌「警惕链」
> <b>成人单侧分泌性中耳炎久治不愈／回吸涕血／颈深上无痛性肿物 = 务必查鼻咽、查 EB 病毒、必要时活检。</b>别把「反复耳闷」只当普通中耳炎，也别把「颈部无痛肿块」只当淋巴结结核/淋巴瘤。

#### 🔴 【掌握级】阻塞性睡眠呼吸暂停低通气综合征（OSAHS）：狭窄-塌陷-低氧链（教材P285-288）

💡 为什么重要：唯一以「睡眠时反复阻塞」为特征、且靠 AHI 数值分级的疾病；PSG 是诊断金标准，CPAP 是一线治疗。

🧬 第一性原理：清醒时咽肌有张力、气道保持开放；睡眠时咽肌（颏舌肌、咽侧壁肌、软腭肌）松弛，若同时存在上气道解剖狭窄，气道就在吸气负压下塌陷。塌陷导致呼吸暂停、血氧下降、CO₂ 潴留；呼吸中枢令「使劲吸」，但气道仍堵着，更强的吸气负压反而带来更重的塌陷。<b>如果上气道足够宽敞、或咽肌在睡眠时仍有足够张力，吸气负压就塌不下去、也不会形成呼吸暂停——本质上，OSAHS 是「解剖性腔道窄＋睡眠性张力低」两股力量叠加、在吸气负压下反复塌陷的恶性循环。</b>

<b>核心概念</b>：呼吸暂停＝口鼻气流较基线下降≥90%、成人≥10 秒（儿童≥两个呼吸长度）；低通气＝气流降低≥30% 伴 SaO₂ 下降≥4% 持续≥10 秒；<b>AHI＝（呼吸暂停次数＋低通气次数）/睡眠时间</b>；儿童用 OAHI。<b>诊断＝整夜多导睡眠监测（PSG），金标准</b>；报告须「病情程度（AHI）＋低氧血症程度（SaO₂）双轴」并写。成人分度：轻度 AHI 5～15（SaO₂ 85~90%）、中度＞15~30（80~＜85%）、重度＞30（＜80%）。<b>治疗</b>：一般治疗（减肥、侧卧、戒烟酒）；<b>CPAP＝成人一线</b>；口腔矫治器用于轻中度（尤其下颌后缩）；手术按阻塞平面选择（鼻腔/鼻咽：鼻中隔矫正、腺样体切除；口咽：悬雍垂腭咽成形术 UPPP；儿童以腺样体/腭扁桃体切除为主）。

| 成人程度 | AHI（次/h） | 最低 SaO₂（%） |
|---|---|---|
| 轻度 | 5～15 | 85～90 |
| 中度 | ＞15～30 | 80～＜85 |
| 重度 | ＞30 | ＜80 |

> [!WARNING] 呼吸暂停的「分型」
> 睡眠中口鼻气流消失但<b>胸腹呼吸运动仍存在</b>的是<b>阻塞性</b>；气流与胸腹运动同时消失的是<b>中枢性</b>；先中枢后阻塞的是<b>混合性</b>。OSAHS 以阻塞性为主，故 PSG 需同时记录口鼻气流与胸腹运动才能分型——仅看气流消失不能分型。

#### 🟡 【熟悉级】急性/慢性咽炎：多数不需要全身大剂量抗生素（教材P258-259）

💡 为什么重要：与急性扁桃体炎的鉴别，以及「慢性咽炎不滥用抗生素」的用药原则。

<b>急性咽炎</b>：咽黏膜与黏膜下急性炎症，病毒（柯萨奇、腺病毒）为主，细菌以 A 组乙型溶血性链球菌最重；表现咽干灼热→明显咽痛、吞咽加重、咽后壁淋巴滤泡隆起伴黄白点状渗出。治疗以对症为主，细菌性才用抗生素。<b>慢性咽炎</b>：咽干、咽痒、咽部异物感、频繁清嗓，检查可见<b>咽后壁慢性充血或淋巴滤泡增生</b>；常与吸烟、饮酒、粉尘、长期用声、鼻后滴流有关。<b>治疗重点是避免刺激因素、改善鼻部疾病、纠正不良发声习惯并进行局部对症处理；没有明确细菌感染证据时不应常规长期使用全身大剂量广谱抗生素。</b>

#### 🟡 【熟悉级】咽旁脓肿：颈侧深部的「定时炸弹」（教材P271-272）

💡 为什么重要：咽旁隙含颈内动脉、颈内静脉与颈深上淋巴结，脓肿可致致命性大出血或脓毒败血症。

<b>咽旁脓肿</b>为咽旁间隙化脓性炎症（早期蜂窝织炎继而脓肿），致病菌多为溶血性链球菌；<b>茎突前隙感染累及翼内肌→张口困难</b>；患侧下颌下区及下颌角后方肿胀、压痛，<b>患侧扁桃体及咽侧壁突向咽中线但扁桃体本身无明显病变</b>。<b>并发症</b>：可侵蚀颈内动脉致致命性大出血、或致颈内静脉血栓性静脉炎/脓毒败血症。治疗：脓肿形成前足量抗生素，形成后切开排脓（颈外径路或经口径路）。

#### 🟡 【熟悉级】鼻咽纤维血管瘤：良性却「禁忌盲目活检」（教材P277-278）

💡 为什么重要：以「反复大量鼻出血」为标志，是「禁忌盲目活检」的典型良性肿瘤。

好发于 10~25 岁青年男性；瘤体含大量<b>管壁薄且无收缩能力的血管</b>，故受损即大出血不止，可扩张性侵入鼻腔、鼻窦、眼眶、翼腭窝甚至颅内。<b>表现</b>：反复阵发性鼻出血（常为首诊主诉）、单侧或双侧鼻塞、鼻音；压迫咽鼓管咽口→耳鸣、听力下降。<b>检查</b>：鼻咽镜见红色、富血管肿瘤；<b>CT/MRI 评估范围，DSA 了解血供（多来自上颌动脉）并可栓塞减少术中出血</b>；触诊易大出血、尽量少用。<b>治疗</b>：手术切除为主（可鼻内镜下切除）。

#### 🟡 【熟悉级】扁桃体癌与下咽癌：单侧扁桃体肿大须排查（教材P281-282）

💡 为什么重要：成人单侧扁桃体明显肿大、溃烂、质硬固定、进行性增大→警惕恶性肿瘤，不能按慢性炎症处理。

<b>扁桃体癌</b>（口咽部常见恶性，与烟酒、HPV 相关）：早期咽部不适/异物感、一侧咽痛，晚期同侧耳痛、吞咽困难、张口受限；一侧扁桃体明显肿大、溃烂、结节状、触硬、易出血。<b>下咽癌</b>（梨状窝型多见，95% 为鳞癌）：常以颈部包块为首发，增大时吞咽哽噎、吞咽痛伴同侧耳痛、进行性吞咽困难、痰中带血。诊断均以病理为金标准，治疗依分期综合（放化疗、手术＋颈清扫）。

#### 🟢 【了解级】咽异物与咽灼伤、扁桃体切除术、咽部神经性疾病（教材P263-265、P273-276、P283-284）

- <b>咽异物与咽灼伤</b>：咽异物多见于扁桃体窝、舌根、会厌谷、梨状窝；咽灼伤分 3 度（1 度黏膜充血水肿无瘢痕、2 度累及黏膜肌层形成瘢痕、3 度深坏死致狭窄闭锁，重度呼吸困难需气管切开）。
- <b>扁桃体切除术</b>：术式有剥离法、挤切法、低温等离子切除法；<b>术后出血分原发性（术后 24 小时内）与继发性（术后 5~6 天白膜脱落期）</b>，须重点观察。
- <b>咽部神经性疾病与感觉异常</b>：舌咽神经痛（同侧扁桃体、舌根、咽部、耳深部间歇性针刺样剧痛，说话/吞咽/触摸诱发）、咽异感症（「梅核气」，须先排除器质性病变）。

> [!NOTE] 咽部第一性原理一句话速记
> <b>咽隐窝藏癌（鼻咽癌），咽鼓管堵耳（分泌性中耳炎），被膜一破必脓（扁桃体周脓肿），睡眠一松必堵（OSAHS）。</b>咽部疾病＝「腔道在哪里被堵或被侵蚀」——深部（间隙、颅底、气道）越险，恶性/慢性梗阻越易造成全身不可逆损害。

### D3 谱系/分层

<b>咽科疾病「位置-严重度」谱系</b>

```text
 位置(由浅到深)            严重度(自限→危重→慢性)
 ① 黏膜表浅炎症  ─────→ 急性/慢性咽炎          轻、自限
        │
 ② 淋巴器官化脓  ─────→ 急性/慢性扁桃体炎      中、局部+全身免疫反应
        │
 ③ 深部间隙脓肿  ─────→ 扁桃体周脓肿→咽后/咽旁脓肿  重、压迫气道/大血管
        │
 ④ 新生物(良/恶性) ───→ 纤维血管瘤→鼻咽癌/扁桃体癌/下咽癌  恶性、远处转移
        │
 ⑤ 慢性上气道梗阻 ────→ OSAHS                  慢性、多系统损害(心脑血管)
```

> [!NOTE] 谱系解读
> 从黏膜浅表炎症到深层间隙感染、再到恶性新生物与慢性梗阻，本质是<b>腔道受累的「深度」与「广度」同时升级</b>：越深（间隙、颅底、纵隔、气道）越易出现呼吸/吞咽/大血管危象；越恶性或越慢性梗阻，越易造成全身性、不可逆损害。

<b>咽部疾病跨模块联接</b>


<b>关键跨模块链路</b>：
- <b>咽→耳（M4→M2）</b>：腺样体肥大或鼻咽癌压迫咽鼓管咽口→中耳通气障碍→分泌性中耳炎（成人单侧分泌性中耳炎务必查鼻咽）。

- <b>咽→喉（M4→M5）</b>：咽痛＋张口受限的鉴别树末端指向急性会厌炎（喉阻塞），两模块共用「咽痛鉴别」主干。
- <b>咽→头颈（M4→头颈）</b>：鼻咽癌、扁桃体癌、下咽癌均以颈部淋巴结转移为重要线索，是头颈肿块鉴别的一部分。

#### 🔬 展开：扁桃体周脓肿的分型、部位与治疗细节

<b>位置分型</b>：前上型（多见，脓肿位于扁桃体上极与腭舌弓之间，患侧腭舌弓及软腭红肿突出、悬雍垂偏向对侧、扁桃体被推向下方）与后上型（少见，位于扁桃体与腭咽弓之间，腭咽弓红肿圆柱状、扁桃体被推向前下方）。<b>治疗三步</b>：①脓肿形成前——足量抗生素＋适量激素；②脓肿形成后——<b>先穿刺抽脓</b>（于最隆起处刺入，进针不可太深以免伤及咽旁隙大血管）→<b>切开排脓</b>（用长弯钳撑开排脓）→③必要时<b>扁桃体切除</b>（多次发作者应在炎症消退 2 周后切除）。（教材P269-270）

#### 🔬 展开：腺样体肥大 → 分泌性中耳炎 / 儿童 OSA 的「上游」

腺样体肥大是两类疾病的共同上游：①压迫咽鼓管咽口→中耳通气障碍→<b>分泌性中耳炎</b>（儿童反复分泌性中耳炎＋耳闷必须查鼻咽）；②阻塞鼻后孔→<b>儿童 OSA</b>。故临床上「腺样体肥大＋分泌性中耳炎」常作<b>鼓膜置管联合腺样体切除</b>，「腺样体肥大＋儿童 OSA」是腺样体切除的强指征。腺样体按阻塞鼻后孔程度分四度：Ⅰ度≤25%、Ⅱ度 26%~50%、Ⅲ度 51%~75%、Ⅳ度＞75%。（教材P266-268）

#### 🔬 展开：OSAHS 的「首选」清单与定位诊断

诊断金标准＝整夜多导睡眠监测（<b>PSG</b>）；成人一线治疗＝<b>CPAP</b>；口咽平面阻塞手术首选＝<b>悬雍垂腭咽成形术（UPPP）</b>；儿童以腺样体/腭扁桃体切除为主；轻中度尤伴下颌后缩＝口腔矫治器；阻塞定位首选＝电子鼻咽喉镜＋<b>Müller 试验</b>（食管测压 Pes 最准确）。PSG 需同时记录口鼻气流与胸腹运动才能区分阻塞性/中枢性/混合性，同时记录脑电、眼电、肌电算 AHI 并判定睡眠结构。（教材P285-288）

### ⚠️ 易错陷阱

> [!WARNING] 陷阱一：扁桃体大小 ≠ 炎症程度
> 「扁桃体大不大」不是慢性扁桃体炎的诊断标准——<b>反复急性发作史才是主要依据</b>。急性期扁桃体可明显肿大，也常被当作诊断依据，属常见干扰项。

> [!WARNING] 陷阱二：咽后脓肿「禁坐位」
> 咽后脓肿<b>严禁坐位/强行压舌板检查</b>，正确体位是<b>仰卧低头位</b>，操作要<b>先穿刺吸脓再切开排脓</b>。把「防误吸」错记成「防感染」是最典型的失分点。

> [!WARNING] 陷阱三：EB 病毒检测不能替代病理
> 鼻咽癌确诊金标准是<b>鼻咽部活组织病理检查</b>；EB 病毒血清学只是辅助信息。<b>首次活检阴性也不能排除</b>（原发灶可在黏膜外观正常时向颅内侵犯），疑似者应密切随访、必要时多次活检。

> [!WARNING] 陷阱四：呼吸暂停的分型看「胸腹运动」
> 口鼻气流消失但<b>胸腹呼吸运动仍存在</b>＝阻塞性；气流与胸腹运动同时消失＝中枢性。仅凭「气流消失」不能分型，须 PSG 同时记录两者。

## 模块5｜喉部疾病及危重气道处理

模块信息：🔴8/🟡5/🟢2 | 定位：全科目唯一的「救命」模块——以「喉的解剖—喉神经支配—喉阻塞分度—危重气道建立」为主线，喉阻塞、急性会厌炎、喉癌是三条命题主线。

---

### D1 第一性原理

🔴 【掌握级】喉的双重身份与喉阻塞的「吸气性」本质（教材P338–P339）
💡 为什么重要：喉阻塞的分度与处理是全科最经典的急症决策题，A2 病例必考。

🧬 第一性原理：
  喉位于颈前正中，上界为会厌上缘（约平第4～5颈椎）、下界为环状软骨下缘（约平第6颈椎）。它同时是「呼吸管道」和「发声器官」——正因为它是管道，一旦变窄，通气就在声门区这个最窄处受阻。
  正常呼吸时，喉的支撑软骨（尤其是唯一呈完整环形的环状软骨）保证气道在任何体位都不塌陷。但声门裂是整条气道最狭窄处：当喉腔因炎症水肿、异物、肿瘤或外伤变窄时，空气「进」比「出」更费劲——吸气时胸腔负压把软组织往内吸，狭窄更明显，因此呼吸困难表现为<b>吸气性</b>；同时牵引锁骨上窝、胸骨上窝、肋间隙内陷，即<b>三凹征</b>。如果声门区不变窄，就不会有喉鸣与三凹征；反过来，一旦出现三凹征，说明喉腔已窄到影响通气。
  关键转折：严重气流极度减少时，通过狭窄处的气流不足以产生湍流，<b>喉鸣反而减弱甚至消失</b>——这是濒死信号而非好转。

  一句话：喉阻塞的一切表现（吸气性呼吸困难、喉鸣、三凹征）本质都是「最窄处进气受阻」。

🔴 【掌握级】喉软骨与喉神经支配（教材P290–P295）
💡 为什么重要：配伍题与 X 型题高频，且是甲状腺手术并发症（声嘶/呼吸困难）的解剖基础。

🧬 第一性原理：
  喉软骨共 9 块：不成对的是甲状软骨（最大、形成喉结）、环状软骨（唯一完整环形，维持气道）、会厌软骨（吞咽时盖住喉入口防误吸）；成对的是杓状软骨、小角软骨、楔状软骨。
  运动与感觉「分工明确」是理解神经损伤表现的关键：<b>喉上神经内支</b>司声门上区黏膜感觉（进食呛咳的保护）；<b>喉上神经外支</b>支配环甲肌（拉紧声带、发高音）；<b>喉返神经</b>支配除环甲肌以外的所有喉内肌，并司声门下区感觉。若喉返神经不出问题，声带就能正常开合；一旦单侧损伤→声带运动异常→<b>声音嘶哑</b>；一旦双侧损伤→两声带均固定于旁正中位→<b>声门开放受限→严重吸气性呼吸困难</b>（危重）。喉上神经外支单独损伤则表现为高音发声困难、声音耐力下降。

  一句话：记住「内支管感觉、外支管环甲肌、喉返管其余全部」，声嘶看喉返、高音困难看外支。

> [!WARNING] 高频陷阱
> ① 双侧喉返神经损伤的危重表现是<b>严重吸气性呼吸困难</b>，而非声嘶（声嘶是单侧损伤）；② 喉鸣减弱不是好转，Ⅳ度喉阻塞气流极度减少时喉鸣反而减弱，伴发绀、意识障碍、脉搏细数，属濒死状态；③ 「高音发声困难」提示喉上神经外支损伤，不要与喉返神经混淆。

🔴 【掌握级】三度声门与喉腔分区（教材P294）
💡 为什么重要：分区是理解各型喉癌行为与喉阻塞定位的坐标系。

🧬 第一性原理：
  以声带为界，喉腔分为<b>声门上区、声门区、声门下区</b>。声门上区上通喉咽、含喉前庭与喉室；声门区是两侧声带之间的区域；声门下区位于声带以下、<b>下连气管</b>。分区之所以重要，是因为淋巴引流不同：声门区淋巴稀少（早期喉癌转移少），声门上区与声门下区淋巴丰富（易颈部转移）——这就是喉癌不同分型预后差异的解剖学根源。喉前庭属声门上区内的结构，喉咽则属咽腔、<b>不属于喉腔分区</b>。

> [!TIP] 记忆锚点：喉的「三唯一」與「三分区」
> 甲状软骨=<b>唯一最大</b>；环状软骨=<b>唯一完整环形</b>；声门下区=<b>唯一下连气管</b>的分区。

### D3 谱系与分层

### 📐 喉部疾病谱系：从良性到致命

```
慢性喉炎 / 声带小结 / 声带息肉（良性、多可保守）
  ↓ ← 转折点1: 急性炎症加重或小儿喉腔狭窄
小儿急性喉炎 / 成人急性喉炎（可迅速进展，犬吠样咳嗽）
  ↓ ← 转折点2: 会厌及声门上区急性水肿
急性会厌炎（流涎、吞咽困难、可迅速窒息——气道优先）
  ↓ ← 转折点3: 有效通气截面进行性缩小
喉阻塞 Ⅰ度 → Ⅱ度 → Ⅲ度
  ↓ ← 转折点4: 缺氧加重、意识障碍
喉阻塞 Ⅳ度（发绀、意识障碍、脉搏细数，濒死）
  ↓ ← 越过此点不可逆
窒息 → 死亡（须气管切开/环甲膜切开抢救）

另一条平行链（肿瘤）：
喉癌（鳞癌）→ 持续进行性声嘶 → 颈部淋巴结转移 → 气道梗阻 → 窒息
```

<b>关键转折点识别</b>：
- 转折点1（良性→急性）：用声过度/感染叠加，出现吸气性喉鸣。
- 转折点2（喉炎→会厌炎）：口咽部检查「无明显异常」而剧痛流涎——会厌水肿被舌根遮挡，是致命盲区。
- 转折点3（可代偿→失代偿）：出现三凹征与烦躁不安（Ⅲ度）。
- 转折点4（失代偿→濒死）：发绀、意识障碍、喉鸣减弱。
- 每次越过转折点，留给「建立气道」的窗口越短，不可逆风险越大。

> [!NOTE] 谱系用途
> 面对「声嘶/呼吸困难」病例，先用本谱系定位病情等级：良性层→保守；急性层→备好气道；阻塞Ⅲ～Ⅳ度→立即介入。谱系就是答题的「严重度坐标」。

```
   气管支气管异物           喉癌（鳞癌）        ┌──────┴──────┐
   (见模块6)                                   咽部红肿明显   咽部无明显异常
        │                                        │              │
   突发憋气+单侧呼吸音减弱                  急性扁桃体炎/    急性会厌炎★
                                          扁桃体周脓肿     (会厌充血肿胀呈球形)
                                                              │
                                                       气道保障优先
```

每一步的判断依据：
- 第一分支：<b>起病方式</b>——急骤（异物/会厌炎/小儿喉炎）vs 渐进（肿瘤/慢性）。
- 第二分支：<b>有无发热咽痛</b>——感染性（会厌炎、扁桃体炎）vs 非感染性（异物、肿瘤）。
- 第三分支（关键）：<b>口咽部检查是否「与症状不符」</b>——剧痛流涎而口咽无异常，会厌炎高度可能（会厌位于舌根后，口咽镜常看不到）。

> [!TIP] 决策树速记
> 「剧痛+流涎+口咽无异常 → 想会厌炎」；「呛咳史+单侧呼吸音减弱 → 想气道异物」；「长期吸烟+进行性声嘶 → 想喉癌」。三个病史锚点直接锁定三个诊断。

#### 🔬 展开：喉阻塞四度分度与危重气道建立

喉阻塞分度的核心是<b>结合整体通气和氧合状态判断，不能只依据喉鸣大小</b>。Ⅰ度仅活动时轻度吸气性呼吸困难；Ⅱ度安静时即出现吸气性呼吸困难与喉鸣，活动加重，但不影响睡眠进食、无烦躁不安；Ⅲ度出现明显三凹征与缺氧体征，患者烦躁不安、脉搏加快；Ⅳ度极度呼吸困难、严重发绀、意识障碍、脉搏细数，濒死状态，此时气流极度减少喉鸣可减弱。处理原则：<b>Ⅲ度或Ⅳ度必须迅速评估气道并由有经验的团队建立可靠通气，不能仅药物保守观察</b>。濒临窒息且不能及时建立常规气道的成人，可由具备技能者在急救规范下实施紧急环甲膜切开；常规气管切开选择第2～4气管软骨环附近（教材述第3～4气管环切开，具体结合解剖），避免切开第1气管环（损伤环状软骨致喉狭窄），切口不应低于第5气管环（防伤大血管与胸膜顶）（教材P339、教材P342）。

#### 🔬 展开：气管切开术后护理与喉癌警示

气管切开术后，呼吸道绕过鼻腔，吸入空气的<b>加温、加湿及过滤作用减弱</b>，分泌物易脱水、结痂并堵塞套管。护理重点：保持气道湿化、及时清除分泌物、维持套管通畅、观察呼吸与氧合、预防感染/出血/堵管/脱管（教材P340–P342）。喉癌方面：最常见病理类型为<b>鳞状细胞癌</b>；中老年长期重度吸烟者出现持续性、进行性声音嘶哑，伴痰中带血、吞咽不适或颈部肿块时须高度警惕；确诊依靠<b>喉镜检查+活组织病理</b>，治疗按部位、分期及患者状况选择手术、放疗或综合治疗（教材P326–P327）。

### 🔄 主动回忆区

基础级填空：
1. 成人喉的上界约平第《4～5》颈椎，下界约平第《6》颈椎。
2. 喉部最大的软骨是《甲状软骨》；喉气管中唯一完整环形的软骨是《环状软骨》。
3. 以声带为界，喉腔分为《声门上区》、《声门区》和《声门下区》，其中下连气管的是《声门下区》。
4. 司声门上区黏膜感觉的神经是《喉上神经内支》；支配环甲肌的是《喉上神经外支》；支配除环甲肌以外喉内肌的是《喉返神经》。

第一性原理问题：
5. 为什么喉阻塞表现为「吸气性」呼吸困难而不是呼气性？因为吸气时胸腔负压使《声门区这一最窄处进一步被软组织内吸而更显狭窄》，故进气受阻更明显。
6. 为什么喉鸣减弱反而提示病情危急？因为《Ⅳ度喉阻塞气流极度减少，不足以产生湍流，故喉鸣减弱甚至消失，是濒死信号》。

进阶级决策路径：
7. 成人剧痛、流涎、吞咽困难伴发热，而口咽部检查无明显异常 → 应首先考虑《急性会厌炎》，决策依据是《剧痛流涎而口咽检查「与症状不符」，会厌位于舌根后常被遮挡》。
8. 患儿极度呼吸困难、发绀、意识障碍、脉搏细数 → 应判定为《喉阻塞Ⅳ度》，首选处理是《立即气管切开/紧急时环甲膜切开》。

### ⚠️ 易错陷阱

> [!WARNING] 五大易错点
> ① 「内支/外支」颠倒——喉上神经<b>内支</b>管<b>感觉</b>、<b>外支</b>管<b>环甲肌</b>；② 双侧喉返神经损伤≠声嘶，而是严重吸气性呼吸困难；③ 喉鸣减弱≠好转（Ⅳ度濒死）；④ 气管切开避免第1气管环（损环状软骨致狭窄），不低于第5环；⑤ 声带小结为双侧对称结节，喉癌为单侧菜花样肿物伴进行性声嘶与颈部肿块。

> [!NOTE] 本模块小结
> - 喉阻塞三要素：<b>吸气性呼吸困难、吸气性喉鸣、三凹征</b>；分度决定处理，Ⅲ～Ⅳ度必须迅速建立气道。

## 模块6｜气管、支气管与食管异物

模块信息：🔴8/🟡5/🟢2 | 定位：儿童最常见的耳鼻喉急症模块——以「气道异物=单向活瓣/阻塞性肺气肿/肺不张」与「食管异物=三狭窄/穿孔」两条链为核心，鉴别是命题重点。

---

### D1 第一性原理

🔴 【掌握级】气管、支气管异物的「活瓣性」病理生理（教材P366–P367）
💡 为什么重要：活瓣性阻塞→肺气肿、全阻塞→肺不张，是影像征象分析题的机制核心。

🧬 第一性原理：
  异物在支气管内形成阻塞，其后果完全取决于「空气能否进出」这一阀门开合方式。
  ① <b>不完全性阻塞（只进不出，吸气性活瓣）</b>：吸气时胸腔负压使支气管腔扩大，异物与管壁间出现空隙，空气可进入；呼气时管腔回缩、异物被气流冲击而封闭管腔，气体排出受阻 → 远端肺组织气体「易进难出」→ <b>局限性肺气肿</b>，患侧肺透亮度增高、横膈下移、纵隔向健侧偏移。
  ② <b>完全性阻塞（既不能进也不能出）</b>：远端残余气体逐渐被血液吸收而不能再充入 → <b>阻塞性肺不张</b>，患肺密度增高、体积缩小、纵隔向患侧移位。
  如果阀门只出不进，则是肺不张方向；只有「只进不出」才形成肺气肿。因此同样一个异物，影像结论由阻塞类型决定，而阻塞类型又由「吸气扩张、呼气回缩」的力学决定。

  一句话：<b>异物的物理后果=活瓣方向——只进不出→肺气肿，进出自如皆不可→肺不张</b>。

> [!WARNING] 高频陷阱
> 患侧肺透亮度增高、横膈下移、纵隔向<b>健侧</b>移位=患侧肺气肿（只进不出活瓣）；患侧密度增高、体积缩小、纵隔向<b>患侧</b>移位=患侧肺不张（全阻塞）。纵隔偏移方向是区分二者的关键，千万不要凭「单侧」二字就选肺气肿。

🔴 【掌握级】气道异物为何好发于儿童、为何多入右侧（教材P353、P366）
💡 为什么重要：解剖学原因是「右主支气管」相关选择题的固定考点。

🧬 第一性原理：
  <b>好发年龄</b>：气管、支气管异物绝大多数发生于儿童，尤其 1～3 岁。此期儿童磨牙未萌出、咀嚼功能不完善、吞咽协调与喉保护反射不健全——在哭笑、惊恐深吸气时，声门张开，异物随气流被吸入气管。
  <b>好发侧</b>：右主支气管较粗短（约2.5 cm），与气管纵轴延长线成 20°～25°角、走向较垂直；左主支气管细而长（约5 cm），约成 45° 角。异物沿气流惯性更易进入「更直、更宽」的右侧，但并非绝对。

  一句话：儿童气道异物=「会厌保护不健全+磨牙未萌出的年龄窗」；入右侧=「右主支气管更粗短更垂直」。

🔴 【掌握级】食管异物与三处生理性狭窄（教材P354、P372）
💡 为什么重要：数值型高频考点，且第二狭窄邻近主动脉弓是致命部位。

🧬 第一性原理：
  食管本身是肌性管道，但在三处因邻近组织或结构而相对狭窄，成为异物「卡点」：距成人中切牙约 <b>15～16 cm（食管入口，环咽肌处）</b>、<b>25 cm（主动脉弓及左主支气管相关区域）</b>、<b>40 cm（膈食管裂孔处）</b>。异物一旦嵌顿在第二狭窄，因尖硬异物易刺破邻近主动脉弓/左主支气管，可致<b>致命性大出血或纵隔感染</b>。
  临床上食管入口由环咽肌收缩而致，是食管<b>最狭窄、异物最易嵌顿</b>之处，其次为第二狭窄处。

  一句话：记住「15～16 / 25 / 40 cm」三把尺子——入口最常见，中段（主动脉弓旁）最危险。

> [!TIP] 记忆锚点：异物「三条铁律」
> ① 右主支气管<b>粗、短、直</b>→异物易入右侧；② 食管入口（15～16 cm）<b>最易嵌顿</b>；③ 食管第二狭窄（25 cm）<b>最危险</b>（贴主动脉弓）。

<b>关键转折点识别</b>：
- 转折点1（进入期→再发期）：异物进入时剧烈呛咳，随后「假性缓解」——此期最易被误判为「好了」而延误。
- 转折点2（机械→感染）：体温升高、脓痰，提示继发感染。
- 转折点3（食管机械→穿透）：进行性胸骨后疼痛提示穿孔。
- 转折点4（局部→致命）：纵隔感染或大出血。
- 每次越过转折点，内镜处理的难度与风险都显著上升。

> [!NOTE] 谱系用途
> 见到「呛咳后一度缓解却反复喘息」的儿童，应定位在「再发期」——这正是气道异物最典型的伪装期，勿因一时缓解而漏诊。

### D4 鉴别决策树

### 🌳 气道异物 vs 食管异物鉴别决策树

```
              进食/玩耍后急性症状
                      │
        ┌─────────────┴─────────────┐
    呼吸相关症状                  吞咽相关症状
        │                             │
 突然剧烈呛咳、憋气、发绀       吞咽困难、吞咽痛、流涎
        │                             │
  阵发性咳嗽、喘息               异物位于中段→胸骨后痛
        │                        异物位于上段→颈根部痛
  单侧呼吸音减弱                        │
        │                        ┌────┴────┐
        ↓                       进行性胸骨后痛+发热
   气道异物★                    +皮下气肿/纵隔气体
        │                             │
 硬性支气管镜确诊并取出         食管穿孔并纵隔感染★
                                  (禁食+专科评估+内镜/手术)
```

每一步的判断依据：
- 第一分支：<b>主症状系统</b>——呼吸（气促、喘息、单侧呼吸音减弱）vs 吞咽（吞咽痛、流涎、胸骨后痛）。
- 第二分支：<b>疼痛部位</b>——食管上段痛在颈根部/胸骨上窝，中段痛在胸骨后。
- 第三分支（关键）：<b>有无穿孔征象</b>——皮下气肿、纵隔气体提示穿孔；禁止吞咽饭团/馒头/饮醋强行处理。

> [!TIP] 决策树速记
> 「呛咳、喘息、单侧呼吸音减弱 → 气道」；「吞咽痛、流涎、胸骨后痛 → 食管」；「皮下气肿、纵隔气体 → 穿孔」。两套检查和治疗方式<b>不能互相替代</b>。

#### 🔬 展开：气道异物的诊断陷阱与「三期内」规律

气道异物病程分三期：<b>异物进入期</b>（进食/玩耍时突发剧烈呛咳、憋气、发绀）→ <b>症状再发期</b>（缓解后反复阵发性咳嗽、喘息、单侧呼吸音减弱）→ <b>并发症期</b>（继发感染出现发热、脓痰）。诊断关键陷阱：许多有机异物（花生、瓜子）本身不显影，<b>胸片正常不能排除气道异物</b>；应结合胸部透视观察纵隔摆动、肺气肿、肺不张等间接征象。高度怀疑时应在适当麻醉与气道保障下，用<b>硬性支气管镜</b>既确诊又取出（教材P366–P368）。

#### 🔬 展开：食管穿孔与「严禁强行处理」

误吞尖锐异物（鱼刺、枣核、骨片、假牙等）后可嵌顿或穿透食管壁。穿孔后咽下的空气经穿孔外溢，可进入颈部皮下组织形成<b>皮下气肿</b>，或进入纵隔形成<b>纵隔气肿并继发纵隔感染</b>。典型线索：进行性胸骨后疼痛、发热、颈部皮下气肿或影像提示纵隔气体。处理原则：立即禁食、尽快专科评估、完善颈胸部影像，按异物位置/穿孔程度/感染情况选择内镜取出、手术修补或其他干预。<b>严禁通过吞咽饭团、馒头或饮醋等方式强行处理</b>，以免加重食管壁及邻近大血管损伤（教材P373）。

### 🔄 主动回忆区

基础级填空：
1. 气管隆嵴（隆突）位于气管分叉处，通常投影于第《4～5》胸椎水平，其位置可随《呼吸和体位》变化。
2. 气管、支气管异物绝大多数发生于儿童，尤其好发于《1～3》岁。
3. 右主支气管较粗短，与气管纵轴延长线成《20°～25°》角、走向较垂直，故异物更易进入《右侧》主支气管。
4. 成人食管三处生理性狭窄距中切牙约《15～16》cm、《25》cm 和《40》cm，其中最易嵌顿异物的是《食管入口（第一狭窄）》。

第一性原理问题：
5. 为什么支气管不完全性阻塞会导致肺气肿而非肺不张？因为吸气时管腔扩张、空气可进入，呼气时异物封闭管腔、气体排出受阻，即《只进不出的活瓣作用》，故气体在远端蓄积形成肺气肿。
6. 为什么胸片正常不能排除气道异物？因为《许多有机异物本身不显影》，须结合透视观察纵隔摆动、肺气肿、肺不张等间接征象。

进阶级决策路径：
7. 患儿进食花生后突发呛咳、憋气，缓解后反复喘息并右肺呼吸音减弱 → 应首先考虑《气管、支气管异物》，决策依据是《明确进食史+突发呛咳+单侧呼吸音减弱》。
8. 误吞枣核 3 天后进行性胸骨后痛、发热、颈部皮下气肿、CT 示纵隔气体 → 提示《食管穿孔并纵隔感染》，处理首要措施是《立即禁食并专科评估》。
9. 患侧肺透亮度增高、横膈下移、纵隔向健侧移位 → 判断为《只进不出的活瓣性阻塞》，对应《局限性肺气肿》。

### ⚠️ 易错陷阱

> [!WARNING] 五大易错点
> ① 纵隔偏移方向弄反——向<b>健侧</b>=肺气肿，向<b>患侧</b>=肺不张；② 误以为「胸片正常就能排除气道异物」——有机异物不显影；③ 把鱼刺、枣核误归为气道异物——它们主要见于<b>食管</b>异物；④ 口诀「右侧」并非绝对，左主支气管亦可发生；⑤ 严禁用吞咽饭团/馒头/饮醋处理食管异物（可致穿孔加重）。

## 模块7｜头颈外科学与颈部肿块

模块信息：🔴8/🟡5/🟢2 | 定位：全科目的「结构+肿瘤转移」模块——以「颈部筋膜与间隙—颈淋巴结分区与引流—颈部肿块性质鉴别」为主线，成人颈部肿块排查恶性是核心决策。

---

### D1 第一性原理

🔴 【掌握级】颈深筋膜三层与颈部间隙的「分隔–通连」逻辑（教材P384）
💡 为什么重要：筋膜分层决定了感染/肿瘤沿间隙扩散的路径，也是颈清扫层次的基础。

🧬 第一性原理：
  颈部若只是一团软组织，「肿瘤转移与感染扩散」将无规律可循；正因为颈部被筋膜分成若干<b>有边界的间隙</b>，扩散才有固定通道。颈深筋膜由浅至深分三层：<b>浅层（封套筋膜）</b>呈套状包绕胸锁乳突肌、斜方肌；<b>中层（内脏筋膜）</b>包绕气管、食管、甲状腺，并形成<b>颈动脉鞘</b>；<b>深层（椎前筋膜）</b>覆盖椎体及椎前肌群。
  关键点：<b>颈动脉鞘由内脏筋膜形成，鞘内三者（颈总动脉/颈内动脉、颈内静脉、迷走神经）同处一鞘</b>——因此手术分离该区时必须连同鞘膜一并保护，这就是「颈部手术为何要整鞘处理」的解剖学依据。如果颈部没有这层套状筋膜，感染就会弥漫而非沿固定间隙扩散。

  一句话：<b>筋膜=颈部扩散的「轨道」；颈动脉鞘=三主结构同乘一节车厢</b>。

🔴 【掌握级】颈淋巴结分区与引流规律（教材P386）
💡 为什么重要：Robbins 分区、角淋巴结、Virchow 淋巴结是头颈肿瘤分期与转移的必考点。

🧬 第一性原理：
  淋巴转移不是随机的，而是沿「引流路径」流动：颈深淋巴结位于胸锁乳突肌深面、主要沿<b>颈内静脉</b>排列，以肩胛舌骨肌与颈内静脉交叉处为界分为颈深上、颈深下两组。Robbins 分区把这条路标成坐标：Ⅰ区（颏下+下颌下）、Ⅱ区（颈内静脉上组）、Ⅲ区（中组）、Ⅳ区（下组）、Ⅴ区（颈后三角）、Ⅵ区（颈前中央区：喉前、气管前、气管旁；咽后淋巴结<b>不属Ⅵ区</b>）。
  由此推出两条「转移落点」规律：<b>角淋巴结（颈二腹肌淋巴结，二腹肌后腹附近）</b>——鼻咽癌、口咽部肿瘤常转移至此；<b>Virchow 淋巴结（左侧锁骨上淋巴结，胸导管汇入左静脉角附近）</b>——肿大提示胃肠道等胸腹部恶性肿瘤转移。若原发肿瘤部位决定引流路径，则「按分区找原发灶」即可反向推断隐匿癌。

  一句话：<b>淋巴沿颈内静脉排列、分区即坐标；上组接鼻咽、左锁骨上接胸腹</b>。

🔴 【掌握级】颈部肿块的性质评估原则（教材P404）
💡 为什么重要：成人颈部肿块的「先影像后穿刺、不盲目活检」是决策型高频题。

🧬 第一性原理：
  颈部肿块的处理核心矛盾是：既要「尽早定性（防漏恶性肿瘤）」，又要「避免因取材方式不当而带来出血/播散风险」。
  成人出现<b>持续性、质硬、固定或进行性增大</b>的颈部肿块，尤其伴吸烟饮酒史、体重下降时，应先按「高度怀疑恶性」处理：安排增强 CT/MRI + 上呼吸消化道内镜 + <b>细针穿刺抽吸活检（FNAB）</b>。FNAB 是重要的初步病理取材方式，<b>假阴性率约10%</b>，穿刺阴性不能据此排除恶性，也不宜常规直接行开放性切除活检。
  但遇到<b>怀疑颈动脉体瘤</b>这类血供极丰富的肿块时，逻辑反转：必须先做影像学评估（彩超、增强 CT/MRI，造影可见「高脚杯征」），<b>不盲目穿刺</b>，以免致命性大出血。

  一句话：<b>普通可疑肿块=先影像+细针穿刺；血管性肿块=先影像、禁穿刺。</b>

> [!WARNING] 高频陷阱
> ① 「质硬、固定、进行性增大」是颈部肿块<b>提示恶性</b>的三大关键词，伴吸烟饮酒史、体重下降更须警惕；② 怀疑颈动脉体瘤<b>禁止盲目穿刺</b>（血供丰富，可致大出血），必须先影像评估；③ FNAB 阴性≠排除恶性（假阴性率约10%）；④ 咽后淋巴结<b>不属于Ⅵ区</b>，是分区题的经典干扰项。

### D3 谱系与分层

### 📐 颈部肿块谱系：从良性先天到恶性转移

```
先天性（多为儿童/青年，边界清、生长慢、无痛）
  甲状舌管囊肿（颈前正中，随伸舌动）
  第二鳃裂囊肿/瘘管（胸锁乳突肌前缘中1/3）
    ↓ ← 转折点1: 继发感染
  囊肿感染（迅速增大、红肿疼痛，可形成瘘口流黏液）
    ↓ ← 转折点2: 血供丰富或神经受累（血管性/功能性肿块）
  颈动脉体瘤（颈总动脉分叉处，横动明显、上下受限、血管杂音、高脚杯征）★禁穿刺
    ↓ ← 转折点3（成人新发、质硬固定、进行性增大）
  恶性淋巴结转移 / 原发恶性肿瘤
    ↓ ← 转折点4: 伴吸烟饮酒史、体重下降、吞咽不适
  ★须按恶性排查（增强CT/MRI+内镜+FNAB）

另一类：Virchow 淋巴结肿大 → 提示胸腹部（胃肠道）恶性肿瘤转移
```

<b>关键转折点识别</b>：
- 转折点1（先天→感染）：囊肿迅速增大、红肿、压痛。
- 转折点2（普通肿块→血管性肿块）：横向活动明显、上下受限、闻及血管杂音——提示颈动脉体瘤，禁穿刺。
- 转折点3（良性→恶性可疑）：成人新发、质硬、固定、进行性增大。
- 转折点4（局部→系统）：左锁骨上淋巴结肿大提示胸腹部恶性肿瘤。
- 每次越过分界，处理策略从「切除/观察」转向「按恶性路径定性」。

> [!NOTE] 谱系用途
> 门诊见到颈部肿块，先按本谱系定位：儿童/青年+边界清+生长慢→偏先天；成人+质硬固定+进行性增大→偏恶性。定位后再决定影像、穿刺的顺序。

### 🌳 颈部肿块性质鉴别决策树

```
                       颈部肿块
                          │
        ┌─────────────────┼─────────────────┐
      儿童/青年            中年/老年          颈部大血管分叉处
      边界清生长慢          质硬固定进行性增大   横向活动明显/上下受限
        │                    │                 │
   ┌────┴────┐          ┌────┴────┐        血管杂音
```

每一步的判断依据：
- 第一分支：<b>年龄与生长特征</b>——儿童/青年+生长慢→先天；中老年+质硬固定进行性增大→恶性。

> 「正中随舌动=甲状舌管；侧颈前缘=鳃裂囊肿；分叉处+杂音=颈动脉体瘤（禁穿刺）；老年质硬固定=先查恶性」。

#### 🔬 展开：颈部淋巴结分区与转移规律

颈深淋巴结位于胸锁乳突肌深面，沿颈内静脉排列，以肩胛舌骨肌与颈内静脉交叉处为界分上、下两组，颈深下延伸至锁骨上区者即锁骨上淋巴结。Robbins 分区中Ⅰ～Ⅵ区的范围见上表；其中<b>Ⅵ区为颈前中央区（喉前、气管前、气管旁淋巴结），咽后淋巴结不属于Ⅵ区</b>。转移落点规律：<b>角淋巴结（颈二腹肌淋巴结，二腹肌后腹附近）</b>是鼻咽癌及口咽部肿瘤常转移处；<b>颈肩胛舌骨肌淋巴结（颈内静脉淋巴结）</b>是舌癌淋巴转移的重要相关区域；<b>Virchow 淋巴结（左侧锁骨上）</b>经典上提示胃肠道等胸腹部恶性肿瘤转移，但不能仅凭此认定唯一原发部位（教材P386）。颈部淋巴结分区对头颈部恶性肿瘤的分期、颈清扫范围及放疗靶区设计具有重要意义。

#### 🔬 展开：成人颈部肿块评估与面神经保护

成人出现持续性、质硬、固定或进行性增大的颈部肿块，尤其伴吸烟饮酒史、体重下降或其它可疑症状时，应优先排查恶性肿瘤，安排增强 CT/MRI、上呼吸消化道内镜检查及<b>细针穿刺抽吸活检（FNAB）</b>；FNAB 假阴性率约 10%，穿刺阴性不能据此排除恶性，也不宜常规直接行开放性切除活检；怀疑颈动脉体瘤等血管性肿块时，必须先行影像学评估、不应盲目穿刺（教材P404、教材P398）。手术安全方面：面神经出茎乳孔后进入腮腺，分颞支、颧支、颊支、<b>下颌缘支</b>及颈支；处理下颌下腺及颌下淋巴结区域时应重点保护<b>下颌缘支</b>，损伤可致口角下垂、下唇运动障碍（教材P36）。

### 🔄 主动回忆区

基础级填空：
1. 颈深筋膜由浅至深依次为《封套筋膜》、《内脏筋膜》和《椎前筋膜》；其中形成颈动脉鞘的是《内脏筋膜》。
2. 颈动脉鞘内包含《颈总动脉（分叉上为颈内动脉）》、《颈内静脉》和《迷走神经》三者。
3. 颈深淋巴结主要沿《颈内静脉》排列，以《肩胛舌骨肌》与颈内静脉交叉处为界分上、下两组。
4. 甲状舌管囊肿位于《颈前正中线》，可随《吞咽及伸舌》运动上下移动，经典术式为《Sistrunk 术》。

第一性原理问题：
5. 为什么颈部手术要「整鞘」保护颈动脉鞘区？因为《颈动脉鞘由内脏筋膜形成，颈总动脉、颈内静脉、迷走神经三者同处一鞘，分离时须连同鞘膜一并保护》。
6. 为什么怀疑颈动脉体瘤时禁止盲目穿刺？因为《颈动脉体瘤位于颈总动脉分叉处、血供极其丰富，穿刺可致严重出血》，须先影像评估。

进阶级决策路径：
7. 成人质硬、固定、进行性增大的左颈中部无痛性肿块，伴吸烟史与体重下降 → 应优先排查《恶性肿瘤》，首选处理路径为《先行增强CT/MRI等影像并行细针穿刺取材（FNAB）》，依据是《成人质硬固定进行性增大+吸烟史+体重下降提示恶性》并由《FNAB》。
8. 青年女性颈侧胸锁乳突肌前缘中1/3无痛性囊性肿块 → 应首先考虑《第二鳃裂囊肿》。
9. 左锁骨上淋巴结肿大 → 经典上提示《胸腹部（胃肠道等）恶性肿瘤转移》（Virchow 淋巴结）。

### ⚠️ 易错陷阱

> [!WARNING] 五大易错点
> ① 把咽后淋巴结归入Ⅵ区——<b>错误</b>，咽后淋巴结不属于Ⅵ区；② 颈动脉窦≠颈动脉体：前者=压力感受器、后者=化学感受器；③ 怀疑颈动脉体瘤仍去穿刺——<b>禁止</b>（可致命大出血）；④ 认为 FNAB 阴性就能排除恶性——假阴性率约10%；⑤ 下颌缘支损伤表现为口角下垂、下唇运动障碍，是颌下区手术的保护重点。

### 🎯 口诀

- 筋膜三层：「封套包肌、内脏包腺成鞘、椎前盖椎」。
- 鞘内三宝：「总动脉（或颈内动脉）+ 颈内静脉 + 迷走神经」。
- 分区：「一颏下、二上、三中、四下、五后三角、六前中央」。

### ✅ 本模块小结

> [!NOTE] 本模块小结
> - 颈深筋膜三层：封套（包肌）、内脏（包腺并成颈动脉鞘）、椎前（盖椎）；颈动脉鞘内含颈总/颈内动脉、颈内静脉、迷走神经。
> - 颈部淋巴沿颈内静脉排列；Robbins Ⅰ～Ⅵ 区中Ⅵ区为颈前中央区，咽后淋巴结不属Ⅵ区。
> - 转移落点：角淋巴结（鼻咽/口咽）、颈内静脉淋巴结（舌癌）、Virchow 淋巴结（胸腹肿瘤）。
> - 成人质硬、固定、进行性增大的颈部肿块须优先排查恶性：先影像+内镜+FNAB；怀疑颈动脉体瘤须先影像、禁穿刺。
> <b>🧬 本模块核心洞察</b>：颈部不是一团软组织，而是被筋膜切成的「有轨道的间隙系统」——淋巴沿颈内静脉流动、肿瘤沿分区落点，因此「按分区可反推原发灶、按筋膜可预判扩散路径」。
