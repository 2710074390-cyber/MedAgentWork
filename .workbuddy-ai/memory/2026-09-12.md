**推送后遇到的 git 环境坑（重要，下次直接照做）**：
`git push` 成功（`git ls-remote origin` 确认 `refs/heads/main` = `f0fa233`），但本地 `origin/main` 跟踪引用写不进去 —— `git fetch` 打印 `[new branch] main -> origin/main`、`git update-ref` 返回 exit 0，**但 `.git/refs/remotes/origin/main` 始终不存在**，`git status -sb` 显示 `[gone]`。加 `dangerouslyDisableSandbox` 也无效。
**根因**：本机对 `.git/refs/` 的 **lock+rename 写入协议被拦截**（rename 步骤静默失败），但**直接写文件可用**。
**解法**：`mkdir -p .git/refs/remotes/origin && printf '<sha>\n' > .git/refs/remotes/origin/main`，之后 `git rev-parse origin/main` / `git status -sb` 正常。
**判断推送是否真成功**：不要信本地引用，用 `git ls-remote origin refs/heads/main` 直接查远程。
