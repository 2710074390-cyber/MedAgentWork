## 怎么记：五个记忆主轴

1. <b>解剖地基</b>：外—中—内、鼻甲—鼻道—窦口、咽三腔、喉三区。
2. <b>鉴别对照</b>：传导 vs 感音、周围 vs 中枢、梅尼埃 vs BPPV、变应性 vs 血管运动性。
3. <b>急症优先</b>：喉阻塞、急性会厌炎、气道异物、鼻出血、突发性聋。
4. <b>五问定题眼</b>：核心病理 → 典型体征 → 首选检查 → 确诊金标准 → 首选治疗。
5. <b>跨科意识</b>：单侧分泌性中耳炎查鼻咽、鼻疖防颅内、眩晕先排卒中。

## 怎么错：十个高频陷阱

| # | 陷阱 | 正确口径 |
|---|---|---|
| 1 | 把鼓膜算作中耳 | 鼓膜是外耳与中耳界膜，属外耳侧 |
| 2 | 把"2 周内激素"写成"尽早" | 初始 2 周内，挽救 2～6 周 |
| 3 | 梅尼埃的"数小时"记成"数天" | 20 分钟–12 小时 |
| 4 | OMC 包含蝶窦 | OMC 不含蝶窦自然开口 |
| 5 | 萎缩性鼻炎用麻黄碱 | 麻黄碱禁用 |
| 6 | 鼻疖可以挤压 | 严禁挤压，可致海绵窦栓塞 |
| 7 | 胸片正常排除气道异物 | 不能排除，有机异物不显影 |
| 8 | 喉阻塞按喉鸣大小判断 | 严重时喉鸣可减弱，按分度 |
| 9 | 颈动脉体瘤可穿刺 | 忌盲目穿刺 |
| 10 | 单侧扁桃体肿大按炎症处理 | 成人单侧质硬需活检 |

## 疾病谱系总览：从"结构病"到"致命急症"

```text
耳：外耳（炎/耵聍/异物）→ 中耳（分泌性/化脓性/胆脂瘤）→ 内耳（突发性聋/梅尼埃）
                                                          → 前庭（BPPV/前庭神经炎）
鼻：鼻炎（急性/变应性/血管运动性/萎缩性）→ 鼻窦炎（急性/慢性/真菌球）
    → 鼻息肉 → 鼻出血 → 眶内/颅内并发症
咽：咽炎 → 扁桃体炎 → 扁桃体周围脓肿 → 腺样体肥大 → 鼻咽癌/喉咽癌
喉：喉炎（急性/慢性）→ 声带小结/息肉 → 喉阻塞 → 喉癌
气道/食管：异物 → 梗阻/穿孔 → 纵隔感染
头颈：先天性肿块 → 淋巴结转移 → 恶性肿瘤
```

> [!INFO] 读图
> 横向是"部位"，纵向是"从炎症到肿瘤、从慢性到急症"。复习时先定位横坐标，再判断纵坐标的严重度。
