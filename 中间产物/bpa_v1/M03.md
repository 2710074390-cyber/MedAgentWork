## 模块3：鼻科学

> [!INFO] 模块信息
> <b>权重</b>：24%｜<b>预计题型</b>：判断 / A1 / A2 / A3/A4 / 多选 / 案例｜<b>卡片</b>：21 张
> <b>谱系位置</b>：鼻腔解剖 → 鼻腔炎症 → 鼻窦炎症 → 鼻息肉/肿瘤 → 鼻出血与眶颅并发症。
> <b>三个题眼</b>：① 利特尔区与鼻出血；② 鼻窦开口与 OMC；③ 变应性鼻炎 vs 血管运动性鼻炎 vs 萎缩性鼻炎。
> <b>阅读</b>：约 32 分钟

### 🧩 前置知识检查

- 鼻腔外侧壁有哪三个鼻甲、三个鼻道？
- 鼻窦分前组、后组，各自开口在哪里？
- 鼻中隔由哪三块结构构成？利特尔区在哪？
- 鼻腔的动脉血供来自哪两个系统？
- 为什么鼻疖不能挤压？

> [!TIP] 复习入口
> 鼻科学的所有题目都能归到两句话：<b>"通不通"看鼻甲与鼻窦开口，"出不出血"看利特尔区与血管</b>。

### 🎯 30 秒摘要

1. 鼻阈是鼻前庭内界与最狭窄处；梨状孔是骨性入口；后鼻孔由四块骨围成。
2. 鼻甲自上而下缩小约 1/3、前端后移约 1/3；中鼻甲属筛骨。
3. 利特尔区是鼻出血最常见部位；鼻疖严禁挤压。
4. 前组鼻窦开口于中鼻道，后组筛窦开口于上鼻道，蝶窦开口于蝶筛隐窝。
5. 慢性鼻窦炎病程超过 12 周，鼻用糖皮质激素是一线首选，疗程不少于 12 周。

### 📋 考点卡

#### 🔴 K-M03-001｜鼻腔的三个"门"：鼻阈、梨状孔、后鼻孔（教师重点第38、46、47条｜P152、P159）

📌 重点原文（第38条）：在鼻前庭的皮肤和固有鼻腔黏膜交界处的外侧部分，相当于外侧鼻软骨外侧脚上缘有一弧形隆起，称为鼻阈。与鼻阈相对应的内侧鼻中隔和外下方的鼻腔底部也呈皱襞样隆起，共同构成鼻内孔，该区域为鼻前庭的内界和最狭窄处，对鼻的呼吸功能有重要影响。（P152）

📌 重点原文（第46条）：鼻骨下缘与上颌骨额突内侧缘及腭骨突起共同形成梨状孔。（P159）

📌 重点原文（第47条）：后鼻孔主要由蝶骨体（上）、蝶骨翼突内侧板（外）、腭骨水平部后缘（底）、犁骨的后缘（内）共同围成。（P159）

📌 重点原文（第108条）：鼻腔的核心解剖结构与生理功能。鼻腔主要分为覆有皮肤的鼻前庭（含毛囊、皮脂腺）和覆有黏膜的固有鼻腔。鼻中隔在成人中大多存在不同程度的偏曲，完全居中者少见。鼻窦根据其开口位置分为前组（开口于中鼻道）和后组（开口于上鼻道及蝶筛隐窝）。嗅区黏膜分布局限，位于上鼻甲内侧面及对应鼻中隔区域，是嗅觉产生的关键。鼻泪管开口于下鼻道，这一结构使得鼻腔炎症可能逆行引发泪囊炎。在生理功能方面，鼻周期是指两侧鼻腔阻力呈交替性变化，具有促进睡眠时翻身的生理意义。鼻腔的血液供应来源丰富，主要来自颈内动脉系统（眼动脉分支）和颈外动脉系统（上颌动脉分支）。鼻腔的加温、加湿和过滤功能主要由鼻腔黏膜（而非咽喉）完成，其中纤毛朝向鼻咽部的统一运动是实现鼻腔自洁和保护的重要机制。（P150）

<b>🎯 一句话题眼</b>：鼻阈 = 最窄处（鼻前庭内界）；梨状孔 = 骨性入口；后鼻孔 = 四骨围成。

<b>🧬 为什么</b>：鼻阈是鼻腔阻力最大的部位，也是鼻前庭与固有鼻腔的分界；后鼻孔是鼻腔与鼻咽的唯一通道，其骨性边界是鼻窦手术与鼻咽部操作的安全标志。

<b>⚖️ 鉴别</b>：

| 结构 | 构成 | 意义 |
|---|---|---|
| 鼻阈/鼻内孔 | 外侧鼻软骨外侧脚上缘 + 鼻中隔 + 鼻腔底 | 鼻前庭内界、最狭窄处 |
| 梨状孔 | 鼻骨下缘 + 上颌骨额突内侧缘 + 腭骨突起 | 鼻腔骨性入口 |
| 后鼻孔 | 蝶骨体、蝶骨翼突内侧板、腭骨水平部后缘、犁骨后缘 | 鼻腔通鼻咽 |

<b>🚨 红线</b>：后鼻孔的四个边界是高频填空，记错一个就整题失分；不要把"蝶骨翼突外侧板"写进去。

<b>🩺 下一步</b>：按"前—骨—后"三段记鼻腔入口，遇到鼻塞先判断阻塞层面（鼻阈/鼻甲/后鼻孔）。此外，鼻前庭含毛囊与皮脂腺，是鼻疖的好发处；鼻中隔在成人中大多存在不同程度偏曲，完全居中者少见。

#### 🔴 K-M03-002｜鼻甲、鼻道与中鼻甲（教师重点第36、43条｜P158、P160）

📌 重点原文（第36条）：鼻腔外侧壁从下向上有三个呈阶梯状排列的长条骨片，分别称为下、中、上鼻甲，其大小依次缩小约1/3，其前端的位置则依次后移约1/3。每一个鼻甲的下方与鼻腔外侧壁均形成一个裂隙状空间，分别称为下、中、上鼻道。（P158）

📌 重点原文（第43条）：中鼻甲属于筛骨结构，前段垂直向下，后段的游离缘逐渐外卷，几乎与鼻腔底平行。手术操作中应严格保持在中鼻甲外侧进行，可防止损伤筛板。（P160）

<b>🎯 一句话题眼</b>：三个鼻甲"越小越靠后"；中鼻甲是筛骨，手术走它外侧。

<b>🧬 为什么</b>：中鼻甲内侧附着于筛板（嗅裂顶），筛板上有嗅丝穿过；器械一旦越过中鼻甲内侧，就可能撕破筛板造成脑脊液鼻漏。

<b>⚖️ 鉴别</b>：

| 鼻道 | 开口结构 |
|---|---|
| 下鼻道 | 鼻泪管 |
| 中鼻道 | 额窦、上颌窦、前组筛窦 |
| 上鼻道 | 后组筛窦 |
| 蝶筛隐窝 | 蝶窦 |

<b>🚨 红线</b>：鼻内镜手术必须保持在中鼻甲外侧，防止损伤筛板。

<b>🩺 下一步</b>：先用"鼻甲—鼻道—开口"三层记解剖，再记手术安全边界。

#### 🔴 K-M03-003｜鼻中隔、利特尔区与鼻出血（教师重点第42、80、114条｜P156、P222）

📌 重点原文（第42条）：鼻腭动脉、筛前动脉、筛后动脉、上唇动脉和腭大动脉，在鼻中隔前下部的黏膜下交互吻合，形成动脉丛，称之为利特尔动脉丛，此区称为利特尔区（Little’s area），是临床上鼻出血最常见的部位。（P156）

📌 重点原文（第114条）：鼻中隔主要由鼻中隔软骨、筛骨垂直板和犁骨构成；鼻出血常见部位为利特尔区；鼻疖常见致病菌为金黄色葡萄球菌，严禁挤压。

📌 重点原文（第80条）：营养素或维生素C、K、P或Ca缺乏，均可能导致鼻出血；DSA或CTA、前鼻镜检查、鼻内镜检查、血常规等可以进行鼻出血评估的检查；长期、反复、少量出血的情况，应积极寻找病因；大量出血者，应先止血，再找病因；鼻腔后部的出血多源于动脉、出血较大，难以控制；情绪紧张者，可予以安慰、镇静；条件允许，可采用鼻内镜检查并止血；对于鼻出血的局部治疗，烧灼法、填塞法、血管结扎法及血管栓塞法均可能控制鼻出血；前鼻孔填塞是较常用的有效止血方法；适用于出血量大、出血位置不明确的患者；填塞时多采用口袋状进行填塞纱条；前鼻孔填塞后，可酌情使用抗生素；前鼻孔填塞纱条，一般不超过3～5天取出；后鼻孔填塞治疗，一般先行后鼻孔填塞，再联合前鼻孔填塞；多用于鼻腔后段、出血量较多的患者；后鼻孔填塞后，可酌情使用抗生素；老年患者行后鼻孔填塞，应评估心肺功能；后鼻孔填塞，最多5～6天取出。（P222）

<b>🎯 一句话题眼</b>：前鼻出血找利特尔区，后鼻出血想到蝶腭动脉；先止血，再找病因。

<b>🧬 为什么</b>：利特尔区是五条动脉的吻合丛，位置表浅、黏膜薄，受干燥空气与挖鼻刺激最易破裂；后鼻出血多来自蝶腭动脉分支，位置深、压力高，所以难止。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 前鼻出血 | 后鼻出血 |
|---|---|---|
| 来源 | 利特尔区 | 蝶腭动脉等分支 |
| 表现 | 血从前鼻孔流出 | 血流向咽部、可呕血 |
| 止血 | 指压、烧灼、前鼻孔填塞 | 后鼻孔填塞、血管结扎/栓塞 |
| 填塞取出 | 一般不超过 3～5 天 | 最多 5～6 天 |

<b>🚨 红线</b>：大量出血先止血再找病因；老年患者后鼻孔填塞要评估心肺功能；填塞后酌情用抗生素。

<b>🩺 下一步</b>：① 前鼻镜/鼻内镜定位；② 指压或烧灼；③ 前/后鼻孔填塞；④ 顽固者 DSA 栓塞或血管结扎；⑤ 查血常规、凝血、维生素。

#### 🔴 K-M03-004｜鼻腔黏膜、黏液纤毛系统与鼻周期（教师重点第35、48、115条｜P161、P162）

📌 重点原文（第35条）：正常人的鼻阻力呈昼夜及左右规律和交替变化，这种变化主要受双侧下鼻甲充血状态影响间隔2~7小时出现一个周期，称之为生理性的鼻周期。由于鼻周期的作用，一侧鼻腔病变引起持续性阻塞时，患者会主诉双侧间歇性鼻塞症状，且卧位时此种症状加重；故鼻病患者大多于夜间睡眠时鼻塞程度更加明显（P161）。37.鼻腔鼻窦黏膜大部分为假复层纤毛柱状上皮，表面约有250～300根纤毛，长度为5～10µm，直径0.3µm，每根纤毛朝鼻咽部摆动的频率是1000次/分。（P162）

📌 重点原文（第48条）：鼻前庭的鼻毛对空气中较大的粉尘颗粒及细菌有阻挡和过滤的作用。喷嚏反射可清除侵入鼻腔的粉尘和微小异物，鼻腔的清洁作用主要由鼻腔黏膜表面的黏液纤毛系统完成的。（P161）

📌 重点原文（第115条）：下鼻甲参与加温、加湿及调节鼻腔阻力；鼻腔黏液纤毛系统向鼻咽方向清除分泌物；鼻周期是两侧鼻腔通气程度的生理性周期变化。

<b>🎯 一句话题眼</b>：纤毛朝鼻咽方向摆、1000 次/分；鼻周期 2~7 小时一轮，所以夜间鼻塞更明显。

<b>🧬 为什么</b>：纤毛定向摆动把黏液毯推向鼻咽，形成"黏液纤毛清除"；鼻周期由下鼻甲充血交替驱动，卧位时静脉回流改变使充血加重，故夜间鼻塞明显。

<b>⚖️ 三道防线</b>：

| 防线 | 结构 | 作用 |
|---|---|---|
| 第一道 | 鼻前庭鼻毛 | 阻挡较大粉尘与细菌 |
| 第二道 | 喷嚏反射 | 清除粉尘与微小异物 |
| 第三道 | 黏液纤毛系统 | 黏附并定向清除颗粒与微生物 |

<b>🚨 红线</b>：纤毛摆动方向是"朝鼻咽部"，不是朝前鼻孔；方向写反即错。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 生理性鼻周期 | 慢性鼻炎鼻塞 |
|---|---|---|
| 诱因 | 生理性，交替出现 | 炎症、结构异常 |
| 持续时间 | 2~7 小时一周期 | 持续或间歇反复 |
| 伴随 | 无分泌物增多 | 鼻涕、鼻甲肥大 |
| 处理 | 无需治疗 | 针对病因治疗 |

<b>🩺 下一步</b>：遇到"夜间鼻塞加重"先想到鼻周期，不要直接诊断慢性鼻炎。

#### 🟡 K-M03-005｜嗅区黏膜（教师重点第49、51、52条｜P162、P163）

📌 重点原文（第49条）：嗅区黏膜主要感受嗅觉功能，嗅觉上皮主要由嗅细胞、支持细胞和基底细胞组成。（P162）

📌 重点原文（第51条）：嗅区黏膜分布在鼻腔顶中部、向下至鼻中隔上部及鼻腔外侧壁上部的嗅裂区域。（P163）

📌 重点原文（第52条）：嗅区黏膜为假复层无纤毛柱状上皮，由支持细胞，嗅细胞及嗅细胞组成。（P163）

<b>🎯 一句话题眼</b>：嗅区在"顶中部 + 鼻中隔上部 + 外侧壁上部"；上皮是"无纤毛"的假复层柱状。

<b>🧬 为什么</b>：嗅区位置高、在鼻道气流的主路之外，所以气流要"到达嗅裂"才能闻到气味；鼻息肉、鼻甲肥大阻塞嗅裂是嗅觉下降的常见原因。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 嗅区黏膜 | 呼吸区黏膜 |
|---|---|---|
| 上皮 | 假复层无纤毛柱状 | 假复层纤毛柱状 |
| 位置 | 鼻腔顶、鼻中隔上部、外侧壁上部 | 鼻腔大部分 |
| 功能 | 嗅觉 | 加温、加湿、过滤 |

<b>🚨 红线</b>：不要把嗅区写成"有纤毛"；也不要把它写成只在上鼻甲。

<b>🩺 下一步</b>：嗅觉下降先查嗅裂是否被息肉/水肿阻塞，再考虑嗅神经病变。

#### 🟡 K-M03-006｜鼻腔血供、静脉与感染扩散（教师重点第39、54条｜P151、P157）

📌 重点原文（第39条）：鼻腔前部、后部和下部的静脉，最后汇入颈内、外静脉。鼻腔上部静脉经眼静脉汇入海绵窦，也可经筛静脉汇入颅内的静脉和硬脑膜窦。（P151）

📌 重点原文（第54条）：外鼻的静脉可经内眦静脉和面静脉汇入颈内静脉。内眦静脉可经眼上、眼下静脉而与海绵窦相通，静脉管内无瓣膜使血液可双向流动，故当鼻、面部感染和疖肿时，若治疗不当或用力挤压可能引发海绵窦栓塞或其他颅内并发症。（P157）

📌 重点原文（第37条）：鼻腔后2/3的淋巴汇入咽后淋巴结及颈深淋巴结上群。鼻部恶性肿瘤可循上述途径发生淋巴结转移。（P157）

<b>🎯 一句话题眼</b>：面部静脉无瓣膜 + 通海绵窦 → 鼻疖/面部感染严禁挤压。

<b>🧬 为什么</b>：内眦静脉与眼上、眼下静脉相通，眼静脉又汇入海绵窦；无瓣膜意味着血液可双向流，挤压把感染"推"进海绵窦。

<b>⚖️ 鉴别</b>：

| 区域 | 回流去向 | 风险 |
|---|---|---|
| 鼻腔前/后/下部 | 颈内、外静脉 | 一般 |
| 鼻腔上部 | 眼静脉 → 海绵窦 | 颅内并发症 |
| 外鼻 | 内眦静脉、面静脉 → 颈内静脉 | 挤压可致海绵窦栓塞 |
| 鼻腔后2/3 淋巴 | 咽后淋巴结、颈深淋巴结上群 | 鼻部恶性肿瘤淋巴转移途径 |

<b>🚨 红线</b>：鼻疖严禁挤压；出现眼睑肿胀、眼球运动异常、剧烈头痛，警惕海绵窦血栓性静脉炎。

<b>🩺 下一步</b>：鼻疖以局部治疗为主，出现眶内/颅内症状立即升级抗感染并影像评估。

#### 🟡 K-M03-007｜鼻腔的神经支配（教师重点第40、41、44条｜P158）

📌 重点原文（第40条）：交感神经来自颈内动脉交感神经丛组成的岩深神经，副交感神经来自面神经分出的岩浅大神经，两者在翼管组成翼管神经。分布于鼻腔，支配腺体分泌和血管舒缩。（P158）

📌 重点原文（第41条）：鼻腔的感觉神经来自三叉神经第一支 (眼神经)和三叉神经第二支(上颌神经)的分支。（P158）

📌 重点原文（第44条）：筛前神经和筛后神经是由三叉神经第一支眼神经的分支鼻睫神经发出的，与同名动脉伴行，筛前神经进入鼻腔后分为内侧支和外侧支，内侧支分布于鼻中隔上部，外侧支分布于鼻腔外侧壁上部及鼻外皮肤，筛后神经分布于鼻中隔和嗅区。（P158）

<b>🎯 一句话题眼</b>：感觉 = 三叉神经 V1 + V2；交感 = 岩深神经，副交感 = 岩浅大神经，二者合成翼管神经。

<b>🧬 为什么</b>：交感兴奋使血管收缩、腺体分泌减少；副交感兴奋使血管扩张、腺体分泌增多。变应性鼻炎的流涕、鼻塞正是副交感优势的表现。

<b>⚖️ 鉴别</b>：

| 神经 | 来源 | 功能 |
|---|---|---|
| 岩深神经（交感） | 颈内动脉交感丛 | 血管收缩、分泌减少 |
| 岩浅大神经（副交感） | 面神经 | 血管扩张、分泌增多 |
| 翼管神经 | 上述二者合成 | 支配鼻腔腺体与血管 |
| 筛前/筛后神经 | 三叉神经 V1 的鼻睫神经 | 鼻中隔上部、外侧壁上部、嗅区感觉 |

<b>🚨 红线</b>：翼管神经由交感与副交感"合成"，不是单一神经；感觉神经不要漏掉 V2。

<b>🩺 下一步</b>：过敏性鼻炎药物选择可回指此解剖（抗组胺、鼻用激素、减充血剂的靶点）。

#### 🔴 K-M03-008｜鼻窦开口与 OMC（教师重点第116条）

📌 重点原文（第116条）：OMC涉及上颌窦、前组筛窦及额窦的相关引流通道，不包括蝶窦自然开口；后组筛窦开口于上鼻道，蝶窦开口于蝶筛隐窝。

<b>🎯 一句话题眼</b>：OMC = 上颌窦 + 前组筛窦 + 额窦，唯独不含蝶窦。

<b>🧬 为什么</b>：前组鼻窦的引流都汇入中鼻道周围的一个狭小通道群（筛漏斗、半月裂、中鼻道），这里黏膜一肿，三个窦一起堵，所以"前组鼻窦炎常同时发生"。

<b>⚖️ 鉴别</b>：

| 鼻窦 | 开口位置 |
|---|---|
| 上颌窦 | 中鼻道（筛漏斗） |
| 前组筛窦 | 中鼻道 |
| 额窦 | 中鼻道（额隐窝） |
| 后组筛窦 | 上鼻道 |
| 蝶窦 | 蝶筛隐窝 |

<b>🚨 红线</b>：OMC 不包括蝶窦自然开口——这是最容易设的干扰项。

<b>🩺 下一步</b>：FESS 的核心就是开放 OMC、重建前组鼻窦通气引流。

#### 🟡 K-M03-009｜鼻窦与眼眶的解剖关系（教师重点第45、50条｜P159、P157）

📌 重点原文（第45条）：眼眶有上下内外四壁，除外壁其余三壁均为鼻窦环绕，后组筛窦的炎症可波及眼眶，引起眶内炎性并发症，严重可出现眶尖并发症。眶下壁前内缘近鼻泪管处有一浅凹，为下斜肌的起始部位，切忌损伤；7岁后鼻窦与眼眶关系基本发育成熟；眶内壁前方有泪囊窝，其前后界分别为泪前嵴及泪后嵴。（P159）

📌 重点原文（第50条）：眶上壁深处为视神经孔所在处，该孔的内侧以薄骨板与后组筛窦及蝶窦相隔；外侧即眶上壁与外壁交界处为眶上裂，有动眼神经，滑车神经、展神经、三叉神经第一支及眼上静脉通过。（P157）

<b>🎯 一句话题眼</b>：眶内壁 = 纸样板（筛窦）；眶上裂过 III、IV、VI、V1 与眼上静脉。

<b>🧬 为什么</b>：纸样板极薄，筛窦炎症最容易突破进入眶内；眶尖与视神经孔邻近后组筛窦、蝶窦，所以后组鼻窦炎可引起视力下降。

<b>⚖️ 鉴别</b>：

| 眶壁 | 相邻鼻窦 | 重要结构 |
|---|---|---|
| 上壁 | 额窦、前颅底 | 视神经孔、眶上裂 |
| 内壁 | 筛窦（纸样板） | 泪囊窝 |
| 下壁 | 上颌窦 | 下斜肌起点、鼻泪管 |
| 外壁 | 无（不与鼻窦相邻） | — |

<b>🚨 红线</b>：眶内并发症出现视力下降、眼球活动受限，属危险信号，需急诊处理。

<b>🩺 下一步</b>：鼻窦炎伴眼睑红肿、眼球突出 → 增强 CT/MRI 评估眶内并发症。

#### 🟢 K-M03-010｜鼻肺反射（教师重点第53条｜P164）

📌 重点原文（第53条）：鼻肺反射是以鼻腔黏膜三叉神经末梢为传出支，以三叉神经及迷走神经核为其中枢核团，形成的反射弧。鼻部受到各种非特异性刺激后反射性地引起同侧支气管收缩，进而减少肺通气量。鼻肺反射是鼻腔局部刺激和病变引起支气管病变的原因之一。（P164）

<b>🎯 一句话题眼</b>：鼻受刺激 → 同侧支气管收缩 → 肺通气量下降；这就是"鼻病及肺"的解剖基础。

<b>🧬 为什么</b>：鼻黏膜三叉神经末梢受刺激，经三叉神经核与迷走神经核整合，传出至支气管平滑肌，引起收缩。因此变应性鼻炎与哮喘常共存。

<b>🚨 红线</b>：不要把鼻肺反射的传入写成"迷走神经"；传入是鼻腔黏膜三叉神经末梢。

<b>🩺 下一步</b>：治疗鼻炎有助于控制合并的哮喘，需上下气道整体管理。

#### 🟡 K-M03-011｜鼻窦的解剖特点（教师重点第61条｜P191）

📌 重点原文（第55条）：鼻腔鼻窦的炎症，一般先发生在鼻腔，炎症扩散可伴发鼻窦炎症；可一侧发生，也可双侧；其中上颌窦炎症最为常见；鼻窦炎也可以单独孤立存在。（P189）

📌 重点原文（第61条）：鼻窦的特点有：窦口小，鼻道狭窄，易于阻塞；鼻腔黏膜炎症容易影响鼻窦黏膜；各鼻窦会互相累及；各鼻窦有自身引流特点；儿童亦可患有鼻窦炎。（P191）

<b>🎯 一句话题眼</b>：窦口小 + 鼻道窄 → 一肿就堵，一堵就炎，所以鼻窦炎常"成群"出现。

<b>🧬 为什么</b>：窦口是鼻窦唯一的通气引流通道，口径只有数毫米；黏膜轻微肿胀即可闭塞，形成负压与积液，进而继发感染。炎症一般先发生在鼻腔，扩散后伴发鼻窦炎；各窦之中上颌窦炎最常见，但鼻窦炎也可单独孤立存在。

<b>🚨 红线</b>：儿童也会患鼻窦炎，不要因为"年龄小"而排除。

<b>🩺 下一步</b>：治疗核心是"消肿 + 引流"，而不是单纯抗菌。

#### 🔴 K-M03-012｜急性鼻炎（教师重点第56、58、59、60条｜P189）

📌 重点原文（第56条）：病毒感染是急性鼻炎发生的首要因素，可继发细菌感染；急性鼻炎多通过呼吸道吸入病毒引起，全身性因素及局部因素等均可诱发。（P189）

📌 重点原文（第58条）：急性鼻炎向邻近组织扩散，可伴发急性鼻窦炎、急性中耳炎、急性咽炎、喉炎、急性气管、支气管炎等。（P189）

📌 重点原文（第59条）：需要和急性鼻炎相鉴别的疾病有流感、变应性鼻炎、血管运动性鼻炎、急性传染病等。（P189）

📌 重点原文（第60条）：对于急性鼻炎，对症支持治疗为主，预防并发症；可使用鼻用减充血剂、鼻用糖皮质激素；合并细菌感染时，可应用抗生素治疗。急性鼻炎亦可采用中医中药辅助治疗。（P189）

<b>🎯 一句话题眼</b>：病毒感染为主 → 对症支持；脓涕+发热才考虑继发细菌感染。

<b>🧬 为什么</b>：鼻黏膜病毒感染后纤毛功能下降、分泌物增多，若引流不畅，细菌在鼻窦内繁殖，于是"感冒"迁延成鼻窦炎。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 急性鼻炎 | 变应性鼻炎 | 流感 |
|---|---|---|---|
| 诱因 | 病毒感染 | 变应原 | 流感病毒 |
| 鼻涕 | 清水→黏脓 | 大量清水样 | 清涕，全身症状重 |
| 喷嚏 | 有，不剧烈 | 阵发性连续 | 有 |
| 发热 | 低热或无 | 无 | 高热、肌痛 |

<b>🚨 红线</b>：急性鼻炎以对症为主，不要一律上抗生素；出现耳痛、脓涕加重、高热提示并发症。

<b>🩺 下一步</b>：对症 + 鼻用减充血剂/鼻用激素；合并细菌感染时抗菌；警惕鼻窦炎、中耳炎。

#### 🔴 K-M03-013｜急性鼻窦炎（教师重点第57、62、63、64、65、66、68条｜P189、P191）

📌 重点原文（第57条）：急性鼻窦炎初期表现为鼻部症状，可伴有耳部症状，症状严重者可出现全身症状；检查可提示鼻黏膜充血肿胀，鼻腔可见分泌物，初期为水样，逐渐可变为黏性、黏脓性或脓性。（P189）

📌 重点原文（第62条）：急性鼻窦炎可能的局部因素是鼻腔疾病、邻近器官的感染、鼻窦外伤或异物、医源性感染以及气压改变。（P191）

📌 重点原文（第63条）：急性鼻窦炎多见于化脓性球菌、杆菌、厌氧菌等。（P191）

📌 重点原文（第64条）：急性鼻窦炎的临床表现可表现为局部症状，如鼻塞、脓性分泌物、头痛或局部疼痛、嗅觉减退；也可以表现为全身症状，如畏寒发热、恶心呕吐及消化道症状。（P191）

📌 重点原文（第65条）：急性后组筛窦炎的位置，与急性蝶窦炎相似，可表现为颅底或眼球深部钝痛。（P191）

📌 重点原文（第66条）：急性额窦炎，晨起后鼻腔分泌物流出，堵塞鼻额管，额窦腔内产生负压甚至真空，发生真空性头痛；中午以后，额窦内分泌物排空，疼痛逐渐缓解。（P191）

📌 重点原文（第68条）：急性鼻窦炎治疗原则：根除病因；解除鼻腔鼻窦引流和通气障碍；控制感染和预防并发症。（P191）

<b>🎯 一句话题眼</b>：额窦炎"晨起加重、午后缓解"；后组筛窦炎"颅底/眼球深部钝痛"。

<b>🧬 为什么</b>：额窦开口（鼻额管）细长，夜间平卧分泌物蓄积、窦内形成负压，故晨起剧痛；白天直立引流改善，午后缓解。这是位置决定症状的典型。

<b>⚖️ 鉴别</b>：

| 鼻窦 | 疼痛定位 | 时间规律 |
|---|---|---|
| 额窦 | 前额、眶上 | 晨起加重、午后缓解 |
| 上颌窦 | 面颊、上颌牙 | 低头加重 |
| 前组筛窦 | 鼻根、内眦 | 无明显规律 |
| 后组筛窦/蝶窦 | 颅底、眼球深部 | 钝痛，位置深 |

<b>🚨 红线</b>：急性鼻窦炎出现眼睑红肿、眼球突出、视力下降或剧烈头痛，提示眶内/颅内并发症。

<b>🩺 下一步</b>：① 鼻内镜 + 必要时 CT；② 鼻用激素 + 减充血剂 + 黏液促排；③ 细菌感染时抗菌；④ 有并发症影像评估并升级治疗。

#### 🔴 K-M03-015｜变应性鼻炎与色甘酸钠（教师重点第69、70、71条｜P196）

📌 重点原文（第69条）：变应性鼻炎属IgE介导的Ⅰ型变态反应。（P196）

📌 重点原文（第70条）：变应性鼻炎早发相症状发生于与变应原接触的数分钟内，主要由肥大细胞/嗜碱粒细胞脱颗粒释放的炎性介质引起。季节性变应原主要指木本类、禾本和草本类的风媒花粉。变应性鼻炎以鼻痒、阵发性连续喷嚏、大量水样鼻涕和鼻塞为临床主要特征，由于鼻黏膜水肿明显，部分患者尚有嗅觉减退。变应性鼻炎诊断主要依靠病史、典型的临床症状和体征以及特异性变应原检查。病史对于诊断非常重要，通过详尽地病史调查，如发病季节、时间、诱因、程度，生活和工作环境，家族及个人过敏史，有否哮喘、皮炎等，就可大致判定鼻炎症状是否为变应性。最后确诊病史须与特异性变应原检测结果相符。预防和治疗花粉症最有效的治疗方法是避免接触变应原（P196）

📌 重点原文（第71条）：色甘酸钠是色酮类药物，有稳定肥大细胞膜的作用，可阻止该细胞脱颗粒和释放介质，但起效时间多在1周以后，故仅适用于轻症变应性鼻炎患者或预防用药。（P196）

<b>🎯 一句话题眼</b>：鼻痒 + 连续喷嚏 + 大量清水涕 + 鼻塞 = 四联征；IgE 介导 I 型，早发相在数分钟内。

<b>🧬 为什么</b>：变应原交联肥大细胞表面 IgE，脱颗粒释放组胺等介质，数分钟内出现喷嚏、流涕；反复发作后黏膜水肿，出现鼻塞与嗅觉减退。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 变应性鼻炎 | 血管运动性鼻炎 | 急性鼻炎 |
|---|---|---|---|
| 机制 | IgE 介导 I 型 | 自主神经功能紊乱 | 病毒感染 |
| 鼻涕 | 大量清水样 | 清水样，遇冷加重 | 清水→黏脓 |
| 喷嚏 | 阵发性连续 | 有，不典型 | 有 |
| 变应原检测 | 阳性 | 阴性 | 阴性 |
| 发热 | 无 | 无 | 可有 |

<b>🚨 红线</b>：色甘酸钠起效多在 1 周以后，只适用于轻症或预防，不能当"急救药"。

<b>🩺 下一步</b>：① 病史 + 特异性变应原检测；② 避免接触变应原（最有效）；③ 鼻用激素/抗组胺；④ 轻症或预防可用色甘酸钠。

#### 🟡 K-M03-016｜血管运动性鼻炎（教师重点第72条｜P196）

📌 重点原文（第72条）：血管运动性鼻炎病因不明，精神紧张、焦虑，环境温度突然变化，内分泌功能紊乱，均可引起副交感神经递质释放过多，或者引起组胺的非特异性释放，血管扩张，腺体分泌增多，导致相应临床症状。长期使用血管收缩剂可引起药物性鼻炎。（P196）

<b>🎯 一句话题眼</b>：遇冷、情绪波动就流涕鼻塞，变应原检测阴性 → 血管运动性鼻炎。

<b>🧬 为什么</b>：不是 IgE 介导，而是副交感优势导致血管扩张、腺体分泌增多；长期用减充血剂会造成反跳性充血，形成药物性鼻炎。

<b>🚨 红线</b>：长期使用血管收缩剂可引起药物性鼻炎——这是高频陷阱。

<b>🩺 下一步</b>：避免诱因、鼻用激素；停用长期减充血剂。

<b>🔄 自测</b>：血管运动性鼻炎的机制是什么？长期用血管收缩剂会有什么后果？（答案见附录五）

#### 🔴 K-M03-017｜萎缩性鼻炎（教师重点第73、74条｜P199）

📌 重点原文（第73条）：萎缩性鼻炎的医源性原因是鼻腔组织特别是下鼻甲切除过多，导致鼻腔过分宽大，通气过度，下鼻甲黏膜下低温等离子射频消融术不会引起萎缩性鼻炎。萎缩性鼻炎的临床表现有①鼻及鼻咽部干燥感：鼻黏膜腺体萎缩，分泌减少，鼻内常有结痂，有时带血，甚至鼻出血。②鼻塞和嗅觉减退或失嗅：因鼻腔痂皮阻塞或因鼻黏膜萎缩，神经感觉迟钝，不能察觉气流通过，嗅区黏膜萎缩或被痂皮堵塞导致嗅觉减退甚至消失。③头痛、头昏：头痛多位于前额、颞侧或后枕部。④恶臭：多见于病情严重和晚期患者。呼气有特殊臭味，但由于嗅觉减退或丧失，患者自己不能闻到。⑤耳鸣、听力下降：病变波及咽鼓管引起咽鼓管功能障碍，出现分泌性中耳炎症状。⑥咽干、声嘶以及刺激性干咳，病变累及咽喉所致。〔源①原标号75〕

📌 重点原文（第74条）：萎缩性鼻炎鼻腔局部治疗可选择：生理盐水鼻腔冲洗；复方薄荷滴鼻剂、1%～3%链霉素液滴鼻、50%葡萄糖滴鼻等滴鼻，可润滑黏膜，软化干痂、抑制细菌生长和促进黏膜腺体分泌等作用。麻黄碱属血管收缩剂，萎缩性鼻炎应禁用。（P199）

<b>🎯 一句话题眼</b>：鼻腔宽大 + 干痂 + 恶臭 + 嗅觉减退 → 萎缩性鼻炎；麻黄碱禁用。

<b>🧬 为什么</b>：黏膜与腺体萎缩 → 分泌减少 → 干痂堆积 → 细菌分解产生臭味；同时鼻腔过宽、气流感觉迟钝，所以"通而不觉"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 萎缩性鼻炎 | 慢性肥厚性鼻炎 | 变应性鼻炎 |
|---|---|---|---|
| 鼻腔 | 宽大、干痂 | 鼻甲肥厚 | 黏膜水肿 |
| 鼻涕 | 干痂、可带血 | 黏脓 | 大量清水样 |
| 嗅觉 | 减退或失嗅 | 多正常 | 可减退 |
| 减充血剂 | 禁用 | 可短期用 | 可短期用 |

<b>🚨 红线</b>：麻黄碱属血管收缩剂，萎缩性鼻炎应禁用；下鼻甲切除过多是医源性原因。

<b>🩺 下一步</b>：生理盐水冲洗 + 润滑/软化干痂 + 抑制细菌；避免血管收缩剂。

<b>🔄 自测</b>：萎缩性鼻炎的医源性原因是什么？为什么禁用麻黄碱？（答案见附录五）

#### 🔴 K-M03-018｜慢性鼻窦炎（教师重点第75、79、117条｜P201、P204）

📌 重点原文（第75条）：根据《中国慢性鼻窦炎诊断和治疗指南（2018）》，慢性鼻窦炎的定义是鼻窦黏膜的慢性炎性疾病，病程超过12周；根据《中国慢性鼻窦炎诊断和治疗指南（2018）》，推荐鼻用糖皮质激素作为慢性鼻窦炎的一线首选治疗药物，疗程不少于12周。鼻内镜手术已被临床实践证明为治疗鼻窦炎的有效方法；儿童慢性鼻窦炎患者的手术指征需严格把握，12岁以下原则不宜手术。（P201）

📌 重点原文（第79条）：鼻塞，黏性或黏脓性鼻涕为慢性鼻窦炎的主要症状；头面部胀痛，嗅觉减退或丧失为慢性鼻窦炎的次要症状；鼻痒，喷嚏，水样涕为过敏性鼻炎的典型症状，慢性鼻窦炎患者可同时伴有过敏性鼻炎；慢性鼻窦炎的诊断主要依据症状、查体和/或鼻窦CT进行。（P204）

📌 重点原文（第117条）：急性细菌性鼻窦炎应根据持续时间及病程变化判断；慢性鼻窦炎通常需症状至少12周并有客观证据；真菌球CT可见不规则高密度及钙化影。

<b>🎯 一句话题眼</b>：超过 12 周 + 鼻塞脓涕（主要）+ 头面胀痛/嗅觉减退（次要）→ 慢性鼻窦炎；鼻用激素疗程不少于 12 周。

<b>🧬 为什么</b>：窦口长期阻塞 → 缺氧、黏液滞留 → 黏膜慢性炎症与重塑；激素从源头抑制黏膜炎症与水肿，所以需要"长疗程"而非"见好就停"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 慢性鼻窦炎 | 变应性鼻炎 | 真菌球 |
|---|---|---|---|
| 主症状 | 鼻塞 + 黏脓涕 | 鼻痒 + 喷嚏 + 水样涕 | 单侧脓涕、可带血 |
| 病程 | 超过 12 周 | 季节性/常年 | 慢性、单侧 |
| CT | 窦腔浑浊、黏膜增厚 | 多正常 | 高密度影 + 钙化 |
| 治疗 | 鼻用激素 ≥12 周，必要时手术 | 避免变应原 + 鼻用激素 | 手术清除 |

<b>🚨 红线</b>：12 岁以下儿童原则上不宜手术；手术前必须有规范药物治疗失败的证据。

<b>🩺 下一步</b>：① 症状 + 鼻内镜 + 鼻窦 CT；② 鼻用糖皮质激素不少于 12 周；③ 必要时鼻腔冲洗、黏液促排；④ 药物失败考虑 FESS。

<b>🔄 自测</b>：慢性鼻窦炎的病程界值是多少？鼻用激素的疗程要求？儿童手术的年龄界值？（答案见附录五）

#### 🟡 K-M03-019｜鼻息肉与生物制剂（教师重点第76、78条｜P201、P204）

📌 重点原文（第76条）：以嗜酸性粒细胞浸润为主的鼻息肉由2型炎症反应介导，哮喘合并率高。 （P201）

📌 重点原文（第78条）：已有多个全球多中心随机对照临床研究证实使用针对IgE、IL-5和IL-4受体的单克隆抗体肌内注射可以显著缩小鼻息肉体积，缓解鼻塞、流涕等症状，改善嗅觉，提高生活质量。目前部分生物制剂已在欧美获得治疗难治性重度CRSwNP的适应证，使这部分患者免于承受反复手术或长期使用口服糖皮质激素的风险。（P204）

<b>🎯 一句话题眼</b>：嗜酸粒细胞浸润 + 2 型炎症 + 哮喘共病 → 难治性鼻息肉；生物制剂靶点 IgE、IL-5、IL-4 受体。

<b>🧬 为什么</b>：2 型炎症（IL-4/IL-5/IL-13）驱动嗜酸粒细胞浸润与黏膜水肿，所以激素与生物制剂有效，而单纯抗菌无效。

<b>🚨 红线</b>：生物制剂适用于"难治性重度 CRSwNP"，不是所有鼻息肉的一线。

<b>🩺 下一步</b>：鼻用激素为基础；反复手术/激素依赖者评估生物制剂；同时管理哮喘。

<b>🔄 自测</b>：嗜酸粒细胞性鼻息肉由哪型炎症介导？生物制剂的三个主要靶点是什么？（答案见附录五）

#### 🟡 K-M03-020｜功能性鼻内镜鼻窦手术（FESS）（教师重点第77条｜P204）

📌 重点原文（第77条）：功能性鼻内镜鼻窦手术（functional endoscopic sinus surgery，FESS），在鼻内镜和电视监视下，切除鼻息肉，开放鼻窦，纠正鼻中隔偏曲和泡状中鼻甲等鼻腔解剖学异常，尽可能保留鼻窦黏膜，重建鼻腔鼻窦通气引流，为鼻腔鼻窦黏膜炎症的良性转归创造条件。（P204）

<b>🎯 一句话题眼</b>：FESS 的关键词是"功能"——保留黏膜、重建引流，而不是"切干净"。

<b>🧬 为什么</b>：鼻窦黏膜有纤毛清除功能，切除过多黏膜等于永久破坏自洁能力；因此手术目标是恢复通气引流，让黏膜自己恢复。

<b>🚨 红线</b>：FESS 并发症包括眶周淤血、内直肌损伤、鼻泪管损伤、脑脊液鼻漏、视神经损伤及颈内动脉损伤。

<b>🩺 下一步</b>：规范药物失败 → 鼻窦 CT 评估 → FESS → 术后鼻腔冲洗与随访。

<b>🔄 自测</b>：FESS 的核心目标是什么？常见并发症有哪些？（答案见附录五）

#### 🟡 K-M03-021｜鼻疖（教师重点第114条，与 K-M03-003 互补）

📌 重点原文（第114条）：鼻中隔主要由鼻中隔软骨、筛骨垂直板和犁骨构成；鼻出血常见部位为利特尔区；鼻疖常见致病菌为金黄色葡萄球菌，严禁挤压。

<b>🎯 一句话题眼</b>：鼻前庭红肿热痛 + 金黄色葡萄球菌 → 鼻疖；一条铁律：严禁挤压。

<b>🚨 红线</b>：挤压可致海绵窦血栓性静脉炎；出现眼睑肿胀、眼球运动异常、剧烈头痛立即升级处理。

<b>🩺 下一步</b>：局部热敷/抗感染；成熟脓肿切开引流；警惕眶内与颅内并发症。

### 🔗 因果链：鼻窦炎的"堵塞—负压—感染"闭环

```text
病毒感染 / 过敏 / 解剖异常（鼻中隔偏曲、泡状中鼻甲）
                ↓
        OMC 黏膜肿胀 → 窦口阻塞
                ↓
        窦腔通气不足 → 负压 → 黏膜渗出
                ↓
        分泌物潴留 → 细菌繁殖
                ↓
        急性鼻窦炎（脓涕、头痛、嗅觉减退）
                ↓
   迁延超过 12 周 → 慢性鼻窦炎 → 鼻息肉 / 眶颅并发症
```

> [!INFO] 读图
> 这条链解释了为什么治疗核心是"消肿 + 引流"：只要窦口不通，抗菌只是暂时压制。

### 🌳 决策树：鼻塞的鉴别

```text
鼻塞
├─ 间歇性、交替性、夜间加重
│    → 慢性单纯性鼻炎 / 鼻周期（鼻用激素、减充血剂短期）
├─ 持续性、鼻甲肥厚、减充血剂收缩差
│    → 慢性肥厚性鼻炎（药物失败考虑手术）
├─ 伴鼻痒、连续喷嚏、大量清水涕
│    → 变应性鼻炎（变应原检测、鼻用激素）
├─ 伴黏脓涕、头面胀痛、嗅觉减退
│    → 慢性鼻窦炎（鼻内镜 + CT，鼻用激素 ≥12 周）
├─ 单侧、进行性、伴血涕或颈部肿块
│    → 查鼻咽/鼻腔肿瘤（鼻内镜 + 活检 + 影像）
└─ 儿童、张口呼吸、打鼾
     → 腺样体肥大（见 M04）
```
