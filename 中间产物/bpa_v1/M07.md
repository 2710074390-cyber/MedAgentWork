## 模块7：头颈外科与颈部肿块

> [!INFO] 模块信息
> <b>权重</b>：3%｜<b>预计题型</b>：A1 / 判断｜<b>卡片</b>：4 张
> <b>谱系位置</b>：颈部筋膜与分区 → 淋巴结转移规律 → 先天性肿块 → 颈部肿块的诊断路径。
> <b>三个题眼</b>：① 成人持续性硬质颈部肿块先排恶性；② 甲状舌管囊肿随伸舌移动；③ 颈动脉体瘤呈"高脚杯征"、忌盲目穿刺。
> <b>阅读</b>：约 10 分钟

### 🧩 前置知识检查

- 颈部淋巴结 Robbins 分区中，II 区指什么？
- 颈深筋膜分哪三层？
- 鼻咽癌、喉癌、甲状腺癌各容易转移到哪些颈淋巴结区？
- 成人颈部肿块"7 天/7 月/7 年"规律分别提示什么？

> [!TIP] 复习入口
> 颈部肿块先问三个问题：<b>在哪一区、长了多久、硬不硬</b>。位置定来源，时间定性质，质地定良恶。

### 🎯 30 秒摘要

1. 成人持续性、质硬、固定的颈部肿块，优先排查恶性肿瘤。
2. 性质不明、怀疑恶性的颈部肿块，FNAB 是重要的初步病理取材方式。
3. 甲状舌管囊肿随吞咽及伸舌移动，经典手术为 Sistrunk 术。
4. 第二鳃裂囊肿/瘘管多位于胸锁乳突肌前缘附近。
5. 颈动脉体瘤位于颈总动脉分叉处，可呈"高脚杯征"，忌盲目穿刺。

### 📋 考点卡

#### 🔴 K-M07-001｜颈部肿块的诊断路径与鼻咽癌颈部转移（教师重点第105、124条）

📌 重点原文（第124条）：甲状舌管囊肿常随伸舌移动；第二鳃裂瘘管多位于胸锁乳突肌前缘附近；颈动脉体瘤位于颈总动脉分叉处并可呈高脚杯征；成人持续性硬质颈部肿块应排查恶性肿瘤。

📌 重点原文（第105条）：鼻咽癌典型症状与鉴别诊断、病理活检为金标准、MRI及EB病毒检测作用、Ki-67与预后关系、远处转移筛查及随访监测方法、放疗为首选治疗原则：患者如有吸烟史、耳部症状（耳鸣、听力下降）、颈部淋巴结无痛、质硬、活动差，合并回吸性涕血和鼻咽溃疡型肿物，符合鼻咽癌伴颈淋巴结转移的典型临床表现，但需与颈部淋巴瘤（多部位淋巴结肿大、可伴发热）、甲状腺癌（颈侧区淋巴结转移）、急性化脓性淋巴结炎（伴红肿热痛）、鼻咽纤维血管瘤（青年男性、鼻塞、反复鼻出血、无淋巴结转移）、鼻窦癌侵犯鼻咽及鼻咽结核鉴别，慢性鼻咽炎多为黏膜充血，无溃疡及易出血肿物。鼻咽癌诊断金标准为病理活检，应先行鼻咽镜+活检，颈部淋巴结细针穿刺可确认转移，MRI用于评估肿瘤范围及颅底侵犯，EB病毒检测（如EBV-VCA IgA、EBV-EA IgA及EB病毒DNA载量）为重要辅助诊断，其DNA水平可反映病情活动度；Ki-67指数高提示肿瘤增殖快、预后差，CEA通常不升高。影像学检查包括鼻窦CT排除鼻窦来源病变，胸部CT用于筛查远处转移（胸片分辨率低且患者无远处转移征象，可非重点项目）。鼻咽癌颈淋巴结转移多先至颈深上Ⅱ区，特点为无痛、质硬、边界不清、活动度差，可融合，而红肿、疼痛提示炎症。治疗上，首选根治性放疗，中晚期需同步放化疗，靶向治疗可联合放疗增强疗效，手术仅用于放疗后复发或残留，单纯化疗疗效差。随访核心为监测复发及转移：鼻咽镜检查局部，影像学评估复发及转移，EB病毒DNA监测病情，肝肾功能及血常规定期（如3~6个月）监测即可，无需每月复查。

<b>🎯 一句话题眼</b>：成人"无痛、质硬、活动差"的颈部淋巴结 → 先找原发灶（鼻咽、口咽、下咽、喉、甲状腺）；FNA 定性，活检定源。

<b>🧬 为什么</b>：头颈部淋巴引流按解剖分区有序进行，鼻咽癌引流至颈深上Ⅱ区，喉癌至Ⅲ/Ⅳ区，甲状腺癌至Ⅵ区。因此"哪一区肿大"能反推原发部位，这是颈部肿块诊断的核心逻辑。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 转移性淋巴结 | 淋巴瘤 | 化脓性淋巴结炎 |
|---|---|---|---|
| 疼痛 | 无痛 | 无痛 | 红肿热痛 |
| 质地 | 质硬、边界不清 | 韧、可多发 | 软、有波动 |
| 活动度 | 差、可融合 | 中等 | 受限 |
| 全身症状 | 多无 | 可发热、盗汗 | 发热 |
| 确诊 | FNA/活检 | 切除活检 | 穿刺/抗感染试验 |

<b>🚨 红线</b>：怀疑颈动脉体瘤时忌盲目穿刺（血供丰富，可致严重出血）；成人硬质颈部肿块不能长期按"淋巴结炎"观察。

<b>🩺 下一步</b>：① 颈部超声 + 增强 CT/MRI；② FNAB；③ 鼻内镜/喉镜找原发灶；④ 鼻咽癌以根治性放疗为主，中晚期同步放化疗。

#### 🟡 K-M07-002｜颈部淋巴结分区与转移规律（教材背景，不列条号）

<b>🎯 一句话题眼</b>：I 颏下/下颌下，II 颈内静脉上，III 中，IV 下，V 颈后三角，VI 颈前中央区。

<b>🧬 为什么</b>：分区把"解剖位置"翻译成"原发灶概率"。II 区 → 鼻咽/口咽；III/IV 区 → 喉/下咽/甲状腺；V 区 → 鼻咽/皮肤；VI 区 → 甲状腺。

<b>⚖️ 分区表</b>：

| 分区 | 范围 | 常见原发 |
|---|---|---|
| I | 颏下、下颌下 | 口腔、唇 |
| II | 颈内静脉上组 | 鼻咽、口咽 |
| III | 颈内静脉中组 | 喉、下咽、甲状腺 |
| IV | 颈内静脉下组 | 喉、下咽、甲状腺 |
| V | 颈后三角 | 鼻咽、皮肤 |
| VI | 颈前中央区（喉前、气管前、气道旁） | 甲状腺 |

<b>🚨 红线</b>：咽后淋巴结不属于 VI 区；Virchow 淋巴结指左侧锁骨上淋巴结，提示胸腹腔肿瘤。

<b>🩺 下一步</b>：按分区选择影像与活检路径，指导手术清扫范围与放疗靶区。

<b>🔄 自测</b>：II 区与 VI 区分别指什么？各常见于哪些原发肿瘤的转移？（答案见附录五）

#### 🟢 K-M07-003｜颈深筋膜三层（教材背景，不列条号）

<b>🎯 一句话题眼</b>：封套筋膜包肌肉，内脏筋膜包脏器，椎前筋膜盖深层。

<b>🧬 为什么</b>：筋膜层决定感染与肿瘤的扩散路径：内脏筋膜间隙向下通纵隔，所以颈深部感染可致纵隔炎。

<b>⚖️ 三层表</b>：

| 筋膜 | 包绕 |
|---|---|
| 封套筋膜 | 胸锁乳突肌、斜方肌 |
| 内脏筋膜 | 气管、食管、甲状腺 |
| 椎前筋膜 | 颈椎前方肌群与深层结构 |

<b>🚨 红线</b>：颈部感染向下蔓延至纵隔是致命并发症，需尽早影像与引流。

<b>🩺 下一步</b>：深部感染评估筋膜间隙，必要时切开引流。

#### 🟡 K-M07-004｜先天性颈部肿块三病（教师重点第124条）

📌 重点原文（第124条）：甲状舌管囊肿常随伸舌移动；第二鳃裂瘘管多位于胸锁乳突肌前缘附近；颈动脉体瘤位于颈总动脉分叉处并可呈高脚杯征；成人持续性硬质颈部肿块应排查恶性肿瘤。

<b>🎯 一句话题眼</b>：随伸舌动 = 甲状舌管囊肿；胸锁乳突肌前缘 = 第二鳃裂；颈动脉分叉 + 高脚杯征 = 颈动脉体瘤。

<b>🧬 为什么</b>：甲状舌管囊肿与舌骨相连，伸舌时舌骨上提牵动囊肿；第二鳃裂瘘管沿胸锁乳突肌前缘走行；颈动脉体瘤位于分叉处，血管造影见颈内、外动脉被推开呈"高脚杯"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 甲状舌管囊肿 | 第二鳃裂囊肿/瘘管 | 颈动脉体瘤 |
|---|---|---|---|
| 位置 | 颈前正中 | 胸锁乳突肌前缘 | 颈总动脉分叉处 |
| 特征动作 | 随伸舌/吞咽移动 | 可有瘘口流黏液 | 横向活动、上下受限 |
| 影像 | 超声/CT | 超声/瘘管造影 | 增强 CT/MRI、血管造影（高脚杯征） |
| 处理 | Sistrunk 术 | 手术切除 | 手术，术前评估血管 |

<b>🚨 红线</b>：颈动脉体瘤血供丰富，忌盲目穿刺；怀疑时先做影像与血管评估。

<b>🩺 下一步</b>：超声初筛 → 增强 CT/MRI → 必要时血管造影 → 手术。

### 📊 对比速查：颈部肿块"时间—性质"规律

| 病程 | 常见性质 | 举例 |
|---|---|---|
| 7 天 | 炎症性 | 急性淋巴结炎、脓肿 |
| 7 月 | 肿瘤性（先天/良性） | 鳃裂囊肿、甲状舌管囊肿、良性肿瘤 |
| 7 年 | 先天性 | 甲状舌管囊肿、鳃裂囊肿 |

> [!WARNING] 易错陷阱
> "7 天/7 月/7 年"是帮助记忆的经验规律，不是诊断标准；最终仍要靠影像与病理。

### 🔗 因果链：颈部淋巴结肿大 → 原发灶定位

```text
颈部淋巴结肿大
        ↓
超声评估（大小、边界、血流、囊实性）
        ↓
按分区推断原发灶
├─ II 区 → 鼻咽、口咽（查鼻内镜）
├─ III/IV 区 → 喉、下咽、甲状腺（查喉镜、甲状腺超声）
├─ V 区 → 鼻咽、皮肤
└─ VI 区 → 甲状腺
        ↓
FNAB 定性 → 找原发灶活检（金标准）
        ↓
分期 → 手术/放疗/综合治疗
```

### 🌳 决策树：颈部肿块的鉴别

```text
颈部肿块
├─ 颈前正中、随伸舌移动
│    → 甲状舌管囊肿（Sistrunk 术）
├─ 胸锁乳突肌前缘、可有瘘口
│    → 第二鳃裂囊肿/瘘管（手术切除）
├─ 颈动脉分叉处、可闻血管杂音、高脚杯征
│    → 颈动脉体瘤（忌穿刺，先影像）
├─ 红肿热痛、病程短
│    → 急性淋巴结炎（抗感染）
└─ 无痛、质硬、活动差、成人、吸烟饮酒
     → 转移性淋巴结（FNAB + 找原发灶）
```
