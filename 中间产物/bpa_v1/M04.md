## 模块4：咽科学

> [!INFO] 模块信息
> <b>权重</b>：18%｜<b>预计题型</b>：判断 / A1 / A2 / A3/A4 / 多选 / 案例｜<b>卡片</b>：13 张
> <b>谱系位置</b>：咽的解剖（三部分 + 间隙）→ 咽的免疫（咽淋巴环）→ 炎症（扁桃体、腺样体）→ 肿瘤（鼻咽、口咽、喉咽）。
> <b>三个题眼</b>：① 咽旁间隙四大神经；② 腺样体肥大的分度与手术指征；③ 鼻咽癌的"回吸性血涕 + 颈部无痛肿块 + 病理确诊"。
> <b>阅读</b>：约 24 分钟

### 🧩 前置知识检查

- 咽分哪三部分？以什么为界？
- 咽鼓管咽口位于哪里？它有什么功能？
- 咽淋巴环由哪些淋巴组织构成？
- 扁桃体位于哪个窝？它的上皮是什么类型？
- 鼻咽癌最好发于哪个部位？

> [!TIP] 复习入口
> 咽科学可以按"腔—环—炎—瘤"四步记：先记三个腔的分界，再记咽淋巴环，然后记炎症与肿瘤。所有题目都能挂到这四步上。

### 🎯 30 秒摘要

1. 咽分鼻咽、口咽、喉咽；喉咽后壁平对第 3～6 颈椎。
2. 咽旁间隙四大神经："舌舌副迷走"——舌咽、舌下、副、迷走。
3. 咽淋巴环："上咽鼓，两侧腭，下舌旁"。
4. 急性扁桃体炎主要致病菌是乙型溶血性链球菌，首选青霉素。
5. 鼻咽癌好发于咽隐窝，确诊靠病理活检；单侧分泌性中耳炎要查鼻咽。

### 📋 考点卡

#### 🔴 K-M04-001｜咽的分部、喉咽与梨状窝（教师重点第81、109条｜P248）

📌 重点原文（第81条）：咽的底部约平第6颈椎；喉咽（laryngopharynx）的位置，喉咽又称下咽（hypopharynx），位于喉的后方。上界：舌骨上缘（约第3颈椎水平）。下界：环状软骨下缘、食管入口（约第6颈椎水平）。因此，其后壁平对第3～6颈椎；咽的肌层按其功能的不同分为3组,包括3对横行的咽缩肌、3对纵行的咽提肌和5组腭帆肌；梨状窝（piriform recess）是喉咽部的重要结构，位于喉咽的两侧。它是由喉入口（喉口）外侧的杓会厌襞和甲状软骨内面之间形成的一个浅窝。（P248）

📌 重点原文（第109条）：咽部的解剖与生理功能。咽部是呼吸与消化的共同通道，以软腭游离缘和会厌上缘为界，明确分为鼻咽、口咽和喉咽三部分。其结构特点与功能紧密相关：咽鼓管咽口位于鼻咽侧壁，平下鼻甲后端，通过吞咽、打哈欠时开放以平衡中耳压力；腭扁桃体位于口咽的扁桃体窝，表面隐窝易藏病菌导致发炎；它与腺样体（咽扁桃体）等共同构成咽淋巴环，形成上呼吸道的重要免疫防线。咽部的肌肉均为横纹肌，包括缩小咽腔的咽缩肌和上提喉体的咽提肌，它们在吞咽时与软腭、会厌协同运动，确保食物顺利进入食管而防止误入气管或反流鼻腔。在临床方面，儿童腺样体增生是引起鼻塞、打鼾和分泌性中耳炎的常见原因；而喉咽部的梨状隐窝则是异物易滞留和肿瘤的好发部位。咽部的血液供应主要来自颈外动脉分支，静脉则回流至颈内静脉。（P248）

<b>🎯 一句话题眼</b>：软腭游离缘分鼻咽/口咽，会厌上缘分口咽/喉咽；梨状窝是异物与肿瘤的"死角"。

<b>🧬 为什么</b>：梨状窝是喉入口两侧的浅窝，位置低、口径小，鱼刺等异物容易嵌顿；其黏膜下有喉上神经内支通过，异物损伤可引起感觉异常，肿瘤也常在此起病。

<b>⚖️ 鉴别</b>：

| 分部 | 上界 | 下界 | 关键结构 |
|---|---|---|---|
| 鼻咽 | 颅底 | 软腭游离缘 | 咽鼓管咽口、咽隐窝、咽扁桃体 |
| 口咽 | 软腭游离缘 | 会厌上缘 | 腭扁桃体、舌根 |
| 喉咽 | 会厌上缘 | 环状软骨下缘（约第6颈椎） | 梨状窝、环后区 |

<b>🚨 红线</b>：喉咽后壁平对第 3～6 颈椎，不是"第 6 颈椎以上都算喉咽"；上界在舌骨上缘（约第 3 颈椎）。

<b>🩺 下一步</b>：遇到异物或肿瘤定位，先判断在鼻咽、口咽还是喉咽，再选检查（鼻内镜/电子喉镜）。

#### 🟡 K-M04-002｜咽肌与吞咽（教师重点第81、109条）

📌 重点原文（第81条）：咽的肌层按其功能的不同分为3组,包括3对横行的咽缩肌、3对纵行的咽提肌和5组腭帆肌（P248）

<b>🎯 一句话题眼</b>：咽缩肌 3 对"往下压"，咽提肌 3 对"往上提"，腭帆肌 5 组"关鼻咽"。

<b>🧬 为什么</b>：吞咽是一串精确的时序动作：软腭上提封闭鼻咽 → 咽缩肌依次收缩 → 喉上提、会厌下翻封闭喉口 → 食物进入食管。任何一环失调都会出现鼻反流或误吸。

<b>⚖️ 鉴别</b>：

| 肌群 | 数量 | 功能 |
|---|---|---|
| 咽缩肌 | 3 对（上、中、下） | 缩小咽腔，推进食团 |
| 咽提肌 | 3 对（茎突咽肌、腭咽肌、咽鼓管咽肌） | 上提喉体与咽 |
| 腭帆肌 | 5 组 | 腭咽闭合，防鼻反流 |

<b>🚨 红线</b>：吞咽时软腭必须向后上方抬起完成腭咽闭合，否则食物反流至鼻咽。

<b>🩺 下一步</b>：出现鼻反流、误吸，评估软腭功能与咽肌协调（神经系统查体 + 吞咽评估）。

#### 🔴 K-M04-003｜咽旁间隙的四大神经（教师重点第82条｜P251）

📌 重点原文（第82条）：咽旁间隙四大神经"口诀: "舌舌副迷走"即：舌咽神经、舌下神经、副神经、迷走神经。 临床提示：咽旁脓肿或肿瘤压迫该间隙，可能出现吞咽困难、发音障碍、舌偏斜、肩耸力减弱等神经症状。（P251）

<b>🎯 一句话题眼</b>："舌舌副迷走"——舌咽、舌下、副、迷走；舌偏斜 = 舌下神经，肩耸无力 = 副神经。

<b>🧬 为什么</b>：四对脑神经在咽旁间隙内密集走行，占位病变压迫时按"受累神经"就能反推病变位置，这是典型的定位诊断题。

<b>⚖️ 鉴别</b>：

| 神经 | 受累表现 |
|---|---|
| 舌咽神经 | 吞咽困难、咽反射减弱 |
| 舌下神经 | 伸舌偏向患侧 |
| 副神经 | 肩耸力减弱、转颈无力 |
| 迷走神经 | 发音障碍、声带麻痹 |

<b>🚨 红线</b>：咽旁间隙感染可向下蔓延至纵隔，出现呼吸困难、颈部肿胀需紧急处理。

<b>🩺 下一步</b>：① 神经查体定位；② 增强 CT/MRI 评估咽旁间隙；③ 脓肿需引流。

#### 🔴 K-M04-004｜咽淋巴环（教师重点第83条｜P251）

📌 重点原文（第83条）：咽淋巴环是上呼吸道免疫防线，参与病原体识别与免疫应答;"上咽鼓，两侧腭，下舌旁"（上：咽扁桃体；咽鼓管旁：咽鼓管扁桃体；两侧：腭扁桃体；下：舌扁桃体；旁：咽侧索）（P251）

<b>🎯 一句话题眼</b>："上咽鼓，两侧腭，下舌旁"——五组淋巴组织围成一环。

<b>🧬 为什么</b>：咽是呼吸与消化的共同入口，淋巴组织环形分布可在病原体进入的第一站完成识别与免疫应答；儿童期淋巴组织增生旺盛，故腺样体、扁桃体肥大常见。

<b>⚖️ 组成</b>：

| 位置 | 淋巴组织 |
|---|---|
| 上 | 咽扁桃体（腺样体） |
| 咽鼓管旁 | 咽鼓管扁桃体 |
| 两侧 | 腭扁桃体 |
| 下 | 舌扁桃体 |
| 旁 | 咽侧索 |

<b>🚨 红线</b>：咽淋巴环是"内环"，不包括颈部淋巴结（外环）；答题时不要混。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 内环（咽淋巴环） | 外环（颈部淋巴结） |
|---|---|---|
| 位置 | 咽黏膜下 | 颈部筋膜间隙 |
| 组成 | 咽扁桃体、咽鼓管扁桃体、腭扁桃体、舌扁桃体、咽侧索 | 颈深上/下、颈后三角等淋巴结群 |
| 引流 | 汇入外环 | 汇入胸导管/右淋巴导管 |
| 临床 | 儿童增生致鼻塞、打鼾 | 转移癌、淋巴瘤 |

<b>🩺 下一步</b>：反复咽痛/扁桃体炎评估咽淋巴环增生程度与手术指征。

#### 🟡 K-M04-005｜咽的生理功能（教师重点第84条｜P253）

📌 重点原文（第84条）：咽为呼吸与消化的共同通道,具有下列生理功能：呼吸功能、言语形成、吞咽功能、防御保护功能、调节中耳气压功能、扁桃体的免疫功能。（P253）

<b>🎯 一句话题眼</b>：六项功能：呼吸、言语、吞咽、防御、调压、免疫。

<b>🧬 为什么</b>：咽既是气道又是食道，还要参与共鸣与免疫，所以咽部手术或病变会同时影响呼吸、吞咽与发音。

<b>🚨 红线</b>：不要把"调节中耳气压"漏掉——它直接关联分泌性中耳炎。

<b>🩺 下一步</b>：咽部病变评估要覆盖六项功能，而不只看"疼不疼"。

#### 🔴 K-M04-006｜急性扁桃体炎（教师重点第85条｜P260）

📌 重点原文（第85条）：乙型溶血性链球菌为急性扁桃体炎的主要致病菌，非溶血性链球菌、葡萄球菌、肺炎链球菌、流感嗜血杆菌或腺病毒、鼻病毒、单纯性疱疹病毒等也可引起本病；抗生素应用为急性扁桃体炎主要治疗方法，首选青霉素。（P260）

<b>🎯 一句话题眼</b>：咽痛 + 发热 + 扁桃体充血肿大 → 乙型溶血性链球菌；首选青霉素。

<b>🧬 为什么</b>：乙型溶血性链球菌的 M 蛋白抗吞噬，易引起化脓性炎症；青霉素抑制细胞壁合成，对链球菌敏感，故为首选。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 急性扁桃体炎 | 扁桃体周围脓肿 | 传染性单核细胞增多症 |
|---|---|---|---|
| 咽痛 | 双侧 | 单侧剧烈 | 双侧 |
| 张口 | 正常 | 受限 | 正常 |
| 扁桃体 | 充血肿大 | 单侧膨隆、悬雍垂偏健侧 | 有假膜 |
| 用药 | 青霉素 | 抗感染 + 引流 | 对症 |

<b>🚨 红线</b>：出现张口受限、言语含糊"口含汤圆音"、单侧膨隆，提示扁桃体周围脓肿，需引流。

<b>🩺 下一步</b>：① 咽部检查 + 血常规；② 青霉素为首选；③ 反复发作评估手术指征。

#### 🟡 K-M04-007｜慢性扁桃体炎（教师重点第86条｜P262）

📌 重点原文（第86条）：慢性扁桃体炎多由急性扁桃体炎反复发作或因扁桃体隐窝引流不畅，窝内细菌、病毒滋生感染而演变为慢性炎症。链球菌和葡萄球菌为本病的主要致病菌；扁桃体切除术后并发症包括出血、伤口感染和肺部并发症。（P262）

<b>🎯 一句话题眼</b>：反复急性发作 + 隐窝引流不畅 → 慢性扁桃体炎；术后三大并发症：出血、感染、肺部并发症。

<b>🧬 为什么</b>：隐窝深、开口小，细菌在窝内形成"病灶"，抗生素难以清除，于是反复发作；这也是手术切除的理论依据。

<b>🚨 红线</b>：术后出血是最危险的并发症，需观察吐出物颜色与生命体征。

<b>🩺 下一步</b>：反复发作（每年多次）、影响生活或并发风湿热/肾炎者评估扁桃体切除。

#### 🔴 K-M04-008｜腺样体肥大（教师重点第87条｜P266）

📌 重点原文（第87条）：腺样体位于鼻咽部的后壁和顶部，为咽淋巴环的内环组成部分。出生时即存在，2～6岁是增生旺盛时期，为腺样体的生理性肥大期，10岁以后逐渐萎缩，成人则大部分消失。腺样体肥大导致长期张口呼吸，可影响面容颌骨发育，形成"腺样体面容"；腺样体出生时即存在，2～6岁是增生旺盛时期，为腺样体的生理性肥大期，10岁以后逐渐萎缩;腺样体肥大常并发鼻炎、鼻窦炎，有鼻塞及流鼻涕等症状。说话时呈闭塞性鼻音，睡眠时发出鼾声、张口呼吸。严重者可引起阻塞性睡眠呼吸暂停低通气综合征;分为四度：Ⅰ度：腺样体阻塞鼻后孔≤25%；Ⅱ度：腺样体阻塞鼻后孔26%～50%；Ⅲ度：腺样体阻塞鼻后孔51%～75%；Ⅳ度：腺样体阻塞鼻后孔>75%；若保守治疗无效，应尽早经口或鼻内镜行腺样体切除术。手术前应仔细检查，排除禁忌证。手术常同扁桃体切除术一并施行，若扁桃体无明确的手术适应证，可单独切除腺样体。（P266）

<b>🎯 一句话题眼</b>：2～6 岁增生旺盛、10 岁后萎缩；鼻塞 + 打鼾 + 张口呼吸 + 腺样体面容 → 腺样体肥大。

<b>🧬 为什么</b>：腺样体位于鼻咽顶后壁，紧邻后鼻孔与咽鼓管咽口。肥大后同时阻塞鼻后孔（鼻塞、打鼾）与咽鼓管咽口（分泌性中耳炎），长期张口呼吸改变颌面发育。

<b>⚖️ 分度</b>：

| 分度 | 阻塞鼻后孔 |
|---|---|
| Ⅰ度 | ≤25% |
| Ⅱ度 | 26%～50% |
| Ⅲ度 | 51%～75% |
| Ⅳ度 | >75% |

<b>🚨 红线</b>：严重者可致阻塞性睡眠呼吸暂停低通气综合征；手术前须排除禁忌证。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 腺样体肥大 | 鼻咽纤维血管瘤 | 后鼻孔闭锁 |
|---|---|---|---|
| 人群 | 儿童 2～6 岁 | 青少年男性 | 新生儿/婴幼儿 |
| 出血 | 无 | 反复大量鼻出血 | 无 |
| 鼻塞特点 | 双侧、渐进 | 单侧或双侧、进行性 | 单侧或双侧、持续性 |
| 检查 | 鼻内镜见淋巴组织 | 影像见血管性肿物 | 影像见骨性/膜性闭锁 |

<b>🩺 下一步</b>：① 鼻内镜评估阻塞程度；② 保守治疗无效尽早手术；③ 常与扁桃体切除同期，扁桃体无指征可单独切除腺样体。

#### 🟢 K-M04-009｜急性腺样体炎（教师重点第88条｜P266）

📌 重点原文（第88条）：急性腺样体炎为儿童常见的疾病，以3～10岁为多见，男女无差别。成年人的腺样体多已退化、消失，极少患此病。（P266）

<b>🎯 一句话题眼</b>：3～10 岁儿童高热 + 鼻塞 + 咽痛 → 想到急性腺样体炎；成人极少见。

<b>🧬 为什么</b>：腺样体在儿童期增生旺盛，感染后肿胀明显；成年后腺样体萎缩，故极少发病。

<b>🚨 红线</b>：儿童高热伴鼻塞、耳痛，要同时评估中耳炎。

<b>🩺 下一步</b>：对症 + 抗感染；反复发作评估腺样体肥大。

#### 🔴 K-M04-010｜鼻咽纤维血管瘤（教师重点第89条｜P277）

📌 重点原文（第89条）：鼻咽纤维血管瘤是一种血管丰富、纤维成分多的良性肿瘤，但生长迅速，局部有侵袭性。典型人群：青少年男性（10～25岁）主要症状：鼻出血、鼻塞;治疗：手术切除，必要时术前血管栓塞;生长特点：良性但局部侵袭性，易累及蝶骨、鼻腔和颅底。主要血供来自颈外动脉系统，尤其是上颌动脉（maxillary artery）及其分支。 肿瘤生长迅速，周围还可能有来自面动脉、蝶腭动脉、腭大动脉、枕动脉等的辅助血供，但上颌动脉是最主要来源。（P277）

<b>🎯 一句话题眼</b>：青少年男性 + 反复鼻出血 + 鼻塞 → 鼻咽纤维血管瘤；血供主要来自上颌动脉。

<b>🧬 为什么</b>：肿瘤血管丰富且缺乏收缩能力，所以出血量大、反复；虽为良性却沿自然间隙侵袭蝶骨、鼻腔与颅底，故术前常需栓塞减少出血。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 鼻咽纤维血管瘤 | 鼻咽癌 | 腺样体肥大 |
|---|---|---|---|
| 人群 | 青少年男性 | 中老年 | 儿童 |
| 表现 | 反复鼻出血、鼻塞 | 回吸性血涕、颈部肿块 | 鼻塞、打鼾 |
| 质地 | 血管性、易出血 | 溃疡性肿物 | 淋巴组织 |
| 禁忌 | 活检易大出血 | 需活检确诊 | 无需活检 |

<b>🚨 红线</b>：怀疑鼻咽纤维血管瘤时不要盲目活检，以免大出血；必须先做影像评估。

<b>🩺 下一步</b>：① 鼻内镜 + 增强 CT/MRI；② 血管造影评估血供；③ 术前栓塞 + 手术切除。

<b>🔄 自测</b>：鼻咽纤维血管瘤的典型人群与主要症状是什么？为什么术前要栓塞？（答案见附录五）

#### 🟡 K-M04-011｜扁桃体恶性肿瘤（教师重点第90条｜P281）

📌 重点原文（第90条）：扁桃体位于口咽腭弓之间，属于淋巴组织丰富的口咽结构。口咽区的扁桃体上皮覆盖为复层鳞状上皮，因此容易发生鳞状上皮恶变.扁桃体恶性肿瘤首选手术或放化疗方案，鳞状细胞癌是最常见类型，因此在口咽肿瘤评估中应优先考虑。（P281）

<b>🎯 一句话题眼</b>：成人单侧扁桃体肿大、质硬、溃疡 → 先想鳞状细胞癌，不要按慢性炎症处理。

<b>🧬 为什么</b>：扁桃体表面是复层鳞状上皮，长期烟酒刺激下易发生鳞状上皮恶变；淋巴组织丰富也使区域淋巴结转移早。

<b>🚨 红线</b>：单侧、质硬、固定、进行性增大的扁桃体肿物，必须活检。

<b>🩺 下一步</b>：活检确诊 → 影像分期 → 手术或放化疗。

#### 🟡 K-M04-012｜喉咽恶性肿瘤（教师重点第91条｜P282）

📌 重点原文（第91条）：喉咽恶性肿瘤（hypopharyngeal carcinoma）是喉咽部的恶性肿瘤，约占咽喉恶性肿瘤的5%-10%。病理类型：以鳞状细胞癌为主。部位分类：梨状窝型（piriform recess type）；环状软骨后区型（postcricoid type）；喉咽后壁型（posterior wall type） 早期症状特点：喉咽肿瘤早期常无明显症状，容易被忽视，导致就诊时多为中晚期。常见晚期症状：吞咽困难（单侧或双侧），颈部淋巴结肿大，声音嘶哑（部分病例），咽痛较轻或不明显。（P282）

<b>🎯 一句话题眼</b>：吞咽困难 + 颈部淋巴结肿大 + 咽痛不明显 → 喉咽癌；早期无症状，发现多晚期。

<b>🧬 为什么</b>：喉咽腔隙大、黏膜松弛，早期肿瘤不阻塞、不疼痛；一旦出现吞咽困难，往往已侵及周围结构或已有淋巴结转移。

<b>⚖️ 分型</b>：

| 类型 | 部位 |
|---|---|
| 梨状窝型 | 梨状窝 |
| 环状软骨后区型 | 环后区 |
| 喉咽后壁型 | 喉咽后壁 |

<b>🚨 红线</b>：咽痛轻但吞咽困难进行性加重，伴颈部肿块，必须做喉咽检查，不能按"慢性咽炎"长期观察。

<b>🩺 下一步</b>：电子喉镜 + 活检 + 增强 CT/MRI 分期；治疗以手术/放化疗综合为主。

<b>🔄 自测</b>：喉咽癌的三个部位类型是什么？为什么早期难以发现？（答案见附录五）

#### 🔴 K-M04-013｜鼻咽癌（教师重点第118条）

📌 重点原文（第118条）：鼻咽癌好发于咽隐窝，与EB病毒密切相关，确诊依靠组织病理；单侧分泌性中耳炎需关注鼻咽部病变。

<b>🎯 一句话题眼</b>：回吸性血涕 + 单侧鼻塞/耳鸣耳闷 + 颈部无痛质硬淋巴结 → 鼻咽癌；确诊靠病理。

<b>🧬 为什么</b>：鼻咽癌好发于咽隐窝，紧邻咽鼓管咽口，肿瘤压迫导致单侧分泌性中耳炎；同时鼻咽淋巴引流丰富，早期即可出现颈深上淋巴结转移，所以"颈部肿块"常是首发表现。

<b>🔗 机制链</b>：

```text
EB 病毒 + 遗传/环境因素
        ↓
咽隐窝黏膜恶变
        ↓
├─ 阻塞后鼻孔 → 单侧鼻塞、回吸性血涕
├─ 压迫咽鼓管咽口 → 单侧分泌性中耳炎
└─ 颈深上淋巴结转移 → 无痛、质硬、活动差
        ↓
鼻咽镜 + 活检（金标准）
        ↓
放疗为主，中晚期同步放化疗
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 鼻咽癌 | 鼻咽纤维血管瘤 | 慢性鼻咽炎 |
|---|---|---|---|
| 人群 | 中老年 | 青少年男性 | 各年龄 |
| 出血 | 回吸性血涕 | 反复大量鼻出血 | 少量血丝 |
| 颈部肿块 | 常见，无痛质硬 | 无 | 无 |
| 确诊 | 病理活检 | 影像（忌盲目活检） | 临床 |

<b>🚨 红线</b>：成人单侧分泌性中耳炎必须查鼻咽；EB 病毒检测不能代替病理确诊。

<b>🩺 下一步</b>：① 鼻内镜 + 鼻咽活检（金标准）；② 增强 MRI 评估颅底与范围；③ 颈部淋巴结 FNA；④ 首选根治性放疗，中晚期同步放化疗。

<b>🔄 自测</b>：鼻咽癌最好发于哪个部位？确诊金标准是什么？为什么单侧分泌性中耳炎要查鼻咽？（答案见附录五）
