## 模块2：耳科学（含耳源性眩晕）

> [!INFO] 模块信息
> <b>权重</b>：28%｜<b>预计题型</b>：判断 / A1 / A2 / A3/A4 / 多选 / 案例｜<b>卡片</b>：21 张
> <b>谱系位置</b>：外耳 → 中耳 → 内耳 → 耳源性眩晕；从"传导障碍"到"感音/平衡障碍"，再到"颅内外并发症"。
> <b>三个题眼</b>：① 传导性 vs 感音神经性聋；② 胆脂瘤的骨质破坏与并发症；③ 眩晕三病的时间轴。
> <b>阅读</b>：约 30 分钟

### 🧩 前置知识检查

- 外耳道哪一段含耵聍腺？鼓膜的正常标志有哪些？
- 咽鼓管连通哪里？儿童咽鼓管为什么容易致病？
- 听骨链的顺序是什么？卵圆窗与镫骨底板是什么关系？
- 面神经在颞骨内走行于哪个骨管？受损会出现什么表现？
- 眩晕的"时间轴"为什么是最强的鉴别线索？

> [!TIP] 复习入口
> 本模块的主线是"位置决定病名，时间决定眩晕"。先按外耳/中耳/内耳把病名归位，再用"秒—小时—天"切眩晕。

### 🎯 30 秒摘要

1. 外耳病以"痛、痒、堵"为主，中耳病以"流脓、穿孔、听力下降"为主。
2. 传导性聋：气导降、骨导正常、有气骨导差；感音神经性：气骨导同降。
3. 胆脂瘤不是肿瘤，却能破坏骨质；颞骨 CT 是术前评估的关键。
4. 眩晕看时间：秒级 BPPV，20 分钟至 12 小时梅尼埃，数天前庭神经炎。
5. 突发性聋是耳科急症：2 周内激素初始，2～6 周挽救。

### 📋 考点卡

#### 🟡 K-M02-001｜耳郭假性囊肿（教师重点第8条｜P77）

📌 重点原文（第8条）：耳郭假性囊肿的发病原因可能与耳郭外伤有关，如耳郭的挤压、撞击等，导致局部血液循环障碍，组织间液积聚形成囊肿。（P77）

<b>🎯 一句话题眼</b>：耳廓前面无痛性隆起 + 波动感 + 有挤压/撞击史 → 假性囊肿（不是真性囊肿，无上皮衬里）。

<b>🧬 为什么</b>：耳廓软骨血供差，轻微挤压造成软骨间积液，液体被困在软骨内或软骨间隙，形成"假性"囊肿。因为不是真性肿瘤，抽吸后容易复发。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 耳郭假性囊肿 | 耳郭化脓性软骨膜炎 |
|---|---|---|
| 疼痛 | 多不明显 | 明显红、肿、热、痛 |
| 内容物 | 浆液性 | 脓性 |
| 全身症状 | 无 | 可有发热 |

<b>🚨 红线</b>：不要自行反复挤压"抽液"，易继发感染并导致耳廓畸形。

<b>🩺 下一步</b>：专科评估后选择抽吸+加压固定或手术处理，目标是防止复发与畸形。

#### 🔴 K-M02-002｜耳郭化脓性软骨膜炎（教师重点第9条｜P78）

📌 重点原文（第9条）：耳郭化脓性软骨膜炎的病因及致病菌及临床表现（P78）——① 病因：耳廓外伤、穿孔、手术或感染；② 常见致病菌：铜绿假单胞菌、金黄色葡萄球菌；③ 表现：耳廓红、肿、热、痛，严重时形成脓肿并破坏软骨，耳垂因不含软骨可相对不受累；延误治疗可致耳廓畸形。

<b>🎯 一句话题眼</b>：耳廓红肿热痛 + 耳垂幸免 → 化脓性软骨膜炎；铜绿假单胞菌是高频答案。

<b>🧬 为什么</b>：耳廓软骨本身无血供，靠软骨膜渗透营养；一旦感染形成脓肿，软骨缺血坏死，修复后纤维化收缩，形成菜花耳畸形。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 化脓性软骨膜炎 | 耳郭假性囊肿 | 外耳道疖 |
|---|---|---|---|
| 部位 | 耳廓软骨 | 耳廓软骨间 | 外耳道软骨部 |
| 疼痛 | 剧烈 | 轻 | 牵拉耳廓剧痛 |
| 耳垂 | 相对不受累 | 可累及 | 正常 |

<b>🚨 红线</b>：形成脓肿必须及时引流，延误可致耳廓畸形；抗感染要覆盖铜绿假单胞菌。

<b>🩺 下一步</b>：① 取分泌物培养；② 足量抗感染；③ 脓肿切开引流、必要时清除坏死软骨。

<b>🔄 自测</b>：耳郭化脓性软骨膜炎最常见的致病菌是什么？为什么耳垂常不受累？（答案见附录五）

#### 🟢 K-M02-003｜外耳湿疹（教师重点第10条｜P78）

📌 重点原文（第10条）：外耳湿疹的主要病因及治疗原则（P78）——① 病因：过敏、接触刺激、皮肤屏障受损或反复搔抓；② 表现：瘙痒、红斑、脱屑、渗出及结痂，瘙痒往往最突出；③ 治疗原则：去除刺激或过敏因素、保持局部清洁干燥、避免搔抓，由医师选择适当局部抗炎药物，合并感染时相应处理。

<b>🎯 一句话题眼</b>：耳廓/耳道"痒"大于"痛"，有渗出结痂 → 外耳湿疹；治疗先"去因+干燥"。

<b>🚨 红线</b>：鼓膜穿孔或不能确认鼓膜完整时，避免使用有耳毒性风险的滴耳制剂。

<b>🩺 下一步</b>：去因 → 清洁干燥 → 局部抗炎 → 合并感染时抗感染。

#### 🔴 K-M02-004｜耵聍栓塞与外耳道胆脂瘤（教师重点第11、14、104条｜P79、P82、P37）

📌 重点原文（第11条）：外耳道耵聍栓塞的主要原因及外耳道耵聍栓塞的治疗方法，外耳道耵聍栓塞与外耳道胆脂瘤的主要鉴别点（P79）——原因：耵聍分泌过多、外耳道狭窄或弯曲、耳毛较多、频繁挖耳将耵聍推向深部；治疗：耵聍软化、器械取出或冲洗，怀疑鼓膜穿孔、既往耳部手术、外耳道感染时不宜盲目冲洗；鉴别：耵聍栓塞无进行性骨质破坏，外耳道胆脂瘤可伴外耳道骨质侵蚀、耳痛、流脓或恶臭分泌物。

📌 重点原文（第14条）：外耳道胆脂瘤的诊断主要依赖于组织病理学检查，通过显微镜观察角化物质的典型表现来确诊（P82）——临床诊断需结合耳镜或耳内镜观察，必要时行颞骨 CT 评估骨质破坏，病理检查用于鉴别，不能将诊断简单归结为仅依赖组织病理。

📌 重点原文（第104条）：耵聍堵塞导致的传导性耳聋及鼓膜内陷、纯音测听和声导抗检查的作用、外耳道在空气传导中的重要性以及耵聍取出和鼓膜、咽鼓管处理的基本原则：硬耵聍团块堵塞外耳道是传导性听力下降的核心病因，表现为气导下降而骨导正常；长期堵塞可导致鼓膜内陷，形成鼓室负压，间接影响声音传导。听骨链固定多需慢性中耳炎或外伤史，而耳蜗功能减退则表现为感音神经性耳聋。声音空气传导的起始环节是外耳道，耵聍完全堵塞直接阻碍声音进入，鼓膜内陷进一步降低振动幅度。诊断上，耳内镜可观察鼓膜及耵聍情况，纯音测听复查可判断取出耵聍后听力恢复，声导抗测试评估鼓室压力，颞骨CT可排除中耳结构异常，前庭功能检查在无眩晕、平衡障碍时可省略。治疗核心是先软化硬耵聍再用专业器械取出，辅以鼓膜按摩改善内陷或咽鼓管吹张恢复鼓室压力。患者无外耳道红肿、流脓等感染迹象时无需口服抗生素。（P37）

<b>🎯 一句话题眼</b>：耵聍=堵住的声音，取出就好；胆脂瘤=会吃骨头的"假瘤"，要看 CT 与病理。

<b>🧬 为什么</b>：耵聍只占位不侵蚀，所以气导降、骨导正常，取出后恢复；外耳道胆脂瘤由角化上皮不断堆积并释放酶类，造成外耳道骨质侵蚀，因此会有耳痛、流脓、恶臭，甚至外耳道狭窄。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 耵聍栓塞 | 外耳道胆脂瘤 |
|---|---|---|
| 本质 | 耵聍堆积 | 角化上皮及角化碎屑堆积 |
| 骨质破坏 | 无 | 有，进行性 |
| 症状 | 耳闷、听力下降、耳鸣 | 耳痛、流脓、恶臭 |
| 关键检查 | 耳内镜 | 耳内镜 + 颞骨 CT，必要时病理 |

<b>🚨 红线</b>：怀疑鼓膜穿孔、既往耳部手术、外耳道感染时，不宜盲目冲洗；无感染迹象不需口服抗生素。

<b>🩺 下一步</b>：① 耳内镜确认；② 先软化再专业器械取出；③ 疑胆脂瘤加颞骨 CT；④ 取出后复查纯音测听与声导抗。

#### 🟡 K-M02-005｜外耳道异物（教师重点第12条｜P79）

📌 重点原文（第12条）：外耳道异物可能导致的主要症状及病因（P79）——症状：耳痛、耳闷、听力下降、外耳道损伤或继发感染；病因：儿童玩耍时塞入小物件、成人挖耳遗留棉签头、昆虫飞入等；处理：充分照明、直视下取出，电池等腐蚀性异物紧急取出。

<b>🎯 一句话题眼</b>：儿童单侧耳痛耳闷 + 掏耳史 → 先想到异物；电池是急症。

<b>🚨 红线</b>：遇水膨胀的植物性异物、鼓膜情况不明或取出困难时，不宜随意冲洗；避免反复盲目夹取造成嵌顿或鼓膜损伤。

<b>🩺 下一步</b>：照明 + 直视取出；困难或特殊异物转专科，必要时麻醉下处理。

#### 🟡 K-M02-006｜外耳道真菌病（教师重点第13条｜P81）

📌 重点原文（第13条）：外耳道真菌病的治疗及预防措施包括保持外耳道干燥、避免频繁挖耳、避免佩戴耳塞和提高免疫力。（P81）

<b>🎯 一句话题眼</b>：耳痒 + 耳内真菌样菌丝/碎屑 → 外耳道真菌病；治疗核心是"清理 + 干燥"。

<b>🧬 为什么</b>：真菌喜湿，长期佩戴耳塞、频繁挖耳、滥用抗菌滴耳液都会破坏外耳道微环境，导致菌群失衡。

<b>🚨 红线</b>：鼓膜穿孔时局部用药需特别谨慎；不要长期自行使用抗菌滴耳液。

<b>🩺 下一步</b>：直视下清理真菌碎屑 → 必要时局部抗真菌 → 保持干燥、停用不必要滴耳液。

#### 🟡 K-M02-007｜外耳道胆脂瘤的临床要点（教师重点第14条，原文锚点见 K-M02-004）

<b>🎯 一句话题眼</b>：外耳道"角化物质堆积 + 骨质侵蚀" → 胆脂瘤；病理可确诊，但不能只靠病理。

<b>🧬 为什么</b>：角化上皮不断脱落堆积，释放酶类并产生压力，造成外耳道骨质侵蚀与狭窄；因此它既有"肿物"表现，又会破坏骨性结构，单靠肉眼容易与耵聍混淆。

<b>🚨 红线</b>：不能把外耳道胆脂瘤的诊断简单归结为"仅依赖组织病理"；临床 + 影像 + 病理三者结合。

<b>🩺 下一步</b>：耳内镜 → 颞骨 CT 评估骨质破坏范围 → 清理/手术 + 病理。

#### 🔴 K-M02-008｜大疱性鼓膜炎及其鉴别（教师重点第15、16条｜P83）

📌 重点原文（第15条）：大疱性鼓膜炎的病因大多为病毒感染，以流感病毒、脊髓灰质炎病毒等为主，（P83）

📌 重点原文（第16条）：大疱性鼓膜炎与一般急性鼓膜炎、急性化脓性中耳炎早期、特发性血鼓室及蓝鼓膜症状及查体所见的鼓膜表现相似，联系密切，在临床上常相互鉴别，避免误诊，P83）

<b>🎯 一句话题眼</b>：鼓膜表面血性大疱 + 剧烈耳痛 + 近期上感 → 大疱性鼓膜炎。

<b>🧬 为什么</b>：病毒侵犯鼓膜上皮层，局部渗出形成疱；因为病变在鼓膜表层，所以疼痛剧烈但听力多无明显下降，穿孔后可自愈。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 大疱性鼓膜炎 | 急性化脓性中耳炎 | 特发性血鼓室 |
|---|---|---|---|
| 鼓膜 | 表面血性大疱 | 充血膨隆、穿孔流脓 | 完整、呈蓝黑色 |
| 耳痛 | 剧烈 | 剧烈，穿孔后减轻 | 轻 |
| 听力 | 多正常或轻降 | 传导性下降 | 传导性下降 |
| 病程 | 短，多自限 | 需抗感染 | 迁延 |

<b>🚨 红线</b>：大疱不要随意穿刺；需与急性化脓性中耳炎早期鉴别，避免误用抗生素或延误引流。

<b>🩺 下一步</b>：耳内镜确认鼓膜形态 → 听力学评估 → 对症止痛、保持干燥，合并细菌感染时抗感染。

#### 🔴 K-M02-009｜分泌性中耳炎（教师重点第17、106条｜P85、P83）

📌 重点原文（第17条）：分泌性中耳炎的临床表现，分泌性中耳炎鼓膜置管术适应证（P85）——表现：耳闷、听力下降、耳内堵塞感，儿童可表现为听力反应下降、注意力下降或言语发育受影响；鼓膜可呈琥珀色、内陷、活动度下降或见液平面、气泡，声导抗可呈 B 型平坦曲线；置管适应证：持续约 3 个月或更久的中耳积液且伴明确听力困难，或存在言语、学习、平衡、生活质量等相关问题。

📌 重点原文（第106条）：分泌性中耳炎的典型临床表现、咽鼓管功能障碍及过敏性鼻炎的病因、鼓室负压与积液对传导性听力的影响、诊断检查方法及治疗原则：感冒后出现耳闷和传导性听力下降，鼓膜内陷，声导抗呈B型曲线，符合分泌性中耳炎诊断，其主要病因是咽鼓管功能障碍，常由过敏性鼻炎导致咽鼓管咽口黏膜肿胀所诱发，而急性化脓性中耳炎则多伴耳痛、发热、鼓膜充血膨隆及穿孔流脓。发病机制为咽鼓管功能障碍导致鼓室通气不足，形成鼓室负压或积液，直接阻碍声音传导，同时鼓膜内陷降低振动幅度，加重传导性听力下降；听骨链正常，无慢性中耳炎病史，耳蜗功能正常（骨导正常）。诊断可结合鼻内镜观察咽口阻塞、鼓室穿刺确认积液、咽鼓管功能测试量化通气能力，过敏原检测可指导预防，颞骨MRI主要用于排查内耳或听神经病变，对分泌性中耳炎诊断非必需。治疗以恢复咽鼓管通气和促进积液排出为主：鼻腔糖皮质激素减轻黏膜肿胀，黏液促排剂帮助排出积液，鼓膜穿刺可快速改善听力，咽鼓管吹张促进通气和积液吸收，患者无感染迹象时无需口服抗生素。（P83）

<b>🎯 一句话题眼</b>：感冒后耳闷 + 鼓膜内陷 + 声导抗 B 型 → 分泌性中耳炎；成人单侧要查鼻咽。

<b>🧬 为什么</b>：咽鼓管是鼓室唯一的通气通道。它一堵，鼓室空气被吸收形成负压，黏膜渗出积液，鼓膜内陷、振动受限，于是出现传导性听力下降。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 分泌性中耳炎 | 急性化脓性中耳炎 |
|---|---|---|
| 耳痛 | 轻或无 | 明显 |
| 发热 | 多无 | 常有 |
| 鼓膜 | 内陷、琥珀色、液平面 | 充血膨隆、穿孔流脓 |
| 声导抗 | B 型平坦 | 早期 C 型，穿孔后无法测 |
| 听力 | 传导性下降 | 传导性下降 |

<b>🚨 红线</b>：成人单侧、原因不明的分泌性中耳炎，必须查鼻咽部排除鼻咽癌；不能把所有积液都直接置管。

<b>🩺 下一步</b>：① 耳内镜 + 声导抗；② 鼻内镜看咽鼓管咽口；③ 鼻腔糖皮质激素 + 黏液促排剂；④ 持续约 3 个月且有听力/言语问题才考虑置管。

#### 🟡 K-M02-010｜婴幼儿易患化脓性中耳炎的原因（教师重点第18条｜P86）

📌 重点原文（第18条）：婴幼儿容易发生化脓性中耳炎的主要原因（P86）——① 咽鼓管短、宽、平直，鼻咽部感染易逆行入中耳；② 免疫系统尚未成熟；③ 婴幼儿常仰卧喂奶，乳汁可经咽鼓管进入中耳；④ 腺样体肥大、上呼吸道感染反复。

#### 🔴 K-M02-011｜急性化脓性中耳炎（教师重点第19条｜P88）

📌 重点原文（第19条）：急性化脓性中耳炎病程超过6～8周，可称为慢性化脓性中耳炎（P88）急性化脓性中耳炎治疗原则，鼓膜穿孔后，禁止使用粉剂，以免与脓液结块影响引流。急性化脓性中耳炎检查情况。

<b>🎯 一句话题眼</b>：耳痛 + 发热 + 鼓膜膨隆 → 穿孔后流脓、疼痛减轻；超过 6～8 周转慢性。

<b>🧬 为什么</b>：鼓室积脓压力升高，压迫鼓膜致缺血坏死穿孔；穿孔后脓液引流，压力下降，疼痛随之缓解。因此"穿孔后疼痛减轻"是病程转折点。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 急性化脓性中耳炎 | 大疱性鼓膜炎 |
|---|---|---|
| 鼓膜 | 充血膨隆、穿孔 | 表面血性大疱 |
| 耳流脓 | 穿孔后出现 | 无 |
| 发热 | 常有 | 多无 |

<b>🚨 红线</b>：鼓膜穿孔后禁止使用粉剂，以免与脓液结块影响引流；忌用耳毒性滴耳液。

<b>🩺 下一步</b>：① 耳镜 + 听力学；② 止痛、抗感染；③ 穿孔后保持引流通畅；④ 超过 6～8 周按慢性化脓性中耳炎管理。

#### 🔴 K-M02-012｜慢性化脓性中耳炎（教师重点第20条｜P88）

📌 重点原文（第20条）：慢性化脓性中耳炎致病菌，临床表现，体征及治疗，流脓停止耳内干燥后，鼓膜小的穿孔可自愈，穿孔不愈合应及时早行鼓室成形术。局部用药时忌用氨基糖苷类抗生素等耳毒性药物滴耳，以免引起听力下降。忌用粉剂，因其可能堵塞穿孔妨碍引流。尽量不用有色药物，以防影响局部观察。中耳腔内忌用含酚类、砷类腐蚀剂。慢性化脓性中耳炎的治疗原则之一是改善听力，因此当患耳是唯一听力耳时，应谨慎手术。（P88）

<b>🎯 一句话题眼</b>：鼓膜穿孔 + 反复流脓 + 传导性聋 → 慢性化脓性中耳炎；用药"三忌"：忌耳毒性、忌粉剂、忌腐蚀剂。

<b>🧬 为什么</b>：穿孔后中耳与外耳相通，滴耳液可直接经圆窗进入内耳，所以氨基糖苷类耳毒性药物会"越治越聋"；粉剂结块堵塞穿孔，脓液引流不畅反而加重感染。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 单纯型 | 骨疡型 | 胆脂瘤型 |
|---|---|---|---|
| 分泌物 | 黏液性、无臭 | 脓性、可臭 | 恶臭豆渣样 |
| 穿孔 | 紧张部中央性 | 边缘性 | 松弛部/边缘性 |
| 骨质破坏 | 无 | 有 | 明显 |
| 危险度 | 低 | 中 | 高（颅内并发症） |

<b>🚨 红线</b>：唯一听力耳手术要极谨慎；出现头痛、发热、面瘫、眩晕提示颅内/迷路并发症。

<b>🩺 下一步</b>：① 耳内镜 + 纯音测听 + 颞骨 CT；② 保持干燥、局部非耳毒性药物；③ 干耳后小穿孔可自愈，不愈者择期鼓室成形术。

#### 🔴 K-M02-013｜中耳胆脂瘤（教师重点第21条｜P91）

📌 重点原文（第21条）：中耳胆脂瘤病因及临床表现及治疗，诊断中耳胆脂瘤最有价值的检查是颞骨CT扫描可发现上鼓室、鼓窦和乳突区有骨质破坏，边缘浓密整齐。可评价乳突气化程度、病变范围、听小骨破坏程度、面神经管状况、有无迷路瘘孔、颈静脉球高度等，为手术提供参考。（P91）

<b>🎯 一句话题眼</b>：松弛部穿孔 + 恶臭豆渣样脓 + CT 骨质破坏伴硬化边缘 → 胆脂瘤。

<b>🧬 为什么</b>：角化上皮在鼓室/乳突内不断堆积，分泌溶骨酶并产生压力，造成听骨链、面神经管、迷路骨质破坏；因此它不是肿瘤却比很多肿瘤更"吃骨头"。

<b>🔗 机制链</b>：

```text
咽鼓管功能障碍 / 鼓膜内陷袋
        ↓
角化上皮在鼓室堆积
        ↓
溶骨酶 + 机械压迫
        ↓
听骨链破坏 → 传导性聋
        ↓
面神经管 / 迷路 / 乙状窦破坏
        ↓
面瘫、眩晕、颅内感染
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 胆脂瘤 | 慢性化脓性中耳炎（单纯型） | 胆固醇肉芽肿 |
|---|---|---|---|
| 分泌物 | 恶臭豆渣样 | 黏液性、无臭 | 褐色 |
| 穿孔 | 松弛部/边缘性 | 紧张部中央性 | 鼓膜完整或蓝鼓膜 |
| CT | 骨质破坏、硬化边缘 | 无破坏 | 软组织影，少破坏 |
| 治疗 | 手术为主 | 保守为主 | 手术 |

<b>🚨 红线</b>：胆脂瘤是"必须手术"的病变；出现面瘫、眩晕、头痛提示并发症，需尽快处理。

<b>🩺 下一步</b>：① 耳内镜；② 颞骨高分辨率 CT（最有价值）；③ 手术清除 + 听骨链重建；④ 术后随访防复发。

#### 🟡 K-M02-014｜中耳胆固醇肉芽肿（教师重点第22条｜P93）

📌 重点原文（第22条）：中耳胆固醇肉芽肿的发病原因不明，病理改变是中耳腔出现胆固醇结晶和继发的反应性肉芽组织。主要临床症状是较分泌性中耳炎略重的传导性耳聋。体征是蓝鼓膜或深褐色鼓膜，鼓膜被肉芽组织累及出现穿孔，可有褐色分泌物流出。追问病史多有自幼或常年中耳炎病史。胆固醇肉芽肿可局限于乳突或中耳的某些气房，也可侵犯整个中耳。颞骨CT扫描可见鼓室及乳突内软组织影，少数有骨质破坏。（P93）

<b>🎯 一句话题眼</b>：蓝鼓膜 + 褐色分泌物 + 长期中耳炎史 → 胆固醇肉芽肿。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 胆固醇肉芽肿 | 胆脂瘤 | 分泌性中耳炎 |
|---|---|---|---|
| 鼓膜 | 蓝/深褐色 | 松弛部穿孔 | 内陷、琥珀色 |
| 分泌物 | 褐色 | 恶臭豆渣样 | 无 |
| CT | 软组织影，少破坏 | 骨质破坏 | 积液 |
| 听力 | 传导性，略重 | 传导性 | 传导性 |

<b>🚨 红线</b>：蓝鼓膜不等于"血鼓室"，要追问长期中耳炎史并做影像鉴别。

<b>🩺 下一步</b>：耳内镜 + 颞骨 CT（必要时 MRI 鉴别）→ 手术清除病灶 + 重建通气。

#### 🔴 K-M02-015｜音叉试验与三型听力损失（教师重点第112条）

📌 重点原文（第112条）：气导大于骨导为林纳试验阳性；林纳试验阴性典型提示传导性聋；韦伯试验中传导性聋偏患耳、单侧感音神经性聋偏健耳。

<b>🎯 一句话题眼</b>：Rinne 阴性 → 传导性；Weber 偏患耳 → 传导性，偏健耳 → 感音神经性。

<b>🧬 为什么</b>：传导性聋时外耳/中耳隔音，环境噪声进不来，骨导反而"显得更响"，所以骨导大于气导（Rinne 阴性）；Weber 试验中，传导性侧声音更"封闭"因而偏患耳，感音神经性侧因患耳感知差而偏健耳。

<b>⚖️ 鉴别</b>：

| 试验 | 传导性聋 | 感音神经性聋 | 正常 |
|---|---|---|---|
| Rinne | 阴性（骨>气） | 阳性（气>骨） | 阳性 |
| Weber | 偏患耳 | 偏健耳 | 居中 |

<b>🚨 红线</b>：重度单侧聋可能出现假阴性 Rinne；音叉试验只能初筛，不能代替纯音测听。

<b>🩺 下一步</b>：音叉初筛 → 纯音测听 + 声导抗定性定量。

#### 🔴 K-M02-016｜眩晕的诊断框架（教师重点第23、24、25条｜P111、P112、P110）

📌 重点原文（第23条）：眩晕的诊断应做到定位、定性、定因。病史的采集与分析是首要任务。（P111）

📌 重点原文（第24条）：周围性眩晕与中枢性眩晕的一般特征（P112）——周围性：旋转性眩晕明显，伴恶心、呕吐、面色苍白、出冷汗等自主神经症状，眼震多为水平或水平旋转性，可伴耳鸣、耳闷、听力下降；中枢性：眩晕可不典型，常伴复视、构音障碍、肢体无力、感觉异常、严重共济失调，眼震可为垂直性或方向改变性。

📌 重点原文（第25条）：前庭周围性眩晕分为：（1）耳蜗前庭疾患，包括：①迷路内，如梅尼埃病等；②迷路内外，如氨基苷类耳中毒。（2）前庭疾患，包括：①迷路内，如良性阵发性位置性眩晕；②迷路外，如前庭神经炎。（P110）

<b>🎯 一句话题眼</b>：先分"周围 vs 中枢"，再分"耳蜗前庭 vs 纯前庭"，最后定具体病。

<b>🧬 为什么</b>：前庭通路从迷路到前庭核再到脑干、小脑，越靠中枢，越容易同时累及邻近的脑干结构（复视、构音、共济），所以"伴随神经体征"是中枢的指纹。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 周围性眩晕 | 中枢性眩晕 |
|---|---|---|
| 眩晕性质 | 旋转性，剧烈 | 可不典型，较轻 |
| 自主神经症状 | 明显 | 可轻 |
| 眼震 | 水平/水平旋转，固视抑制 | 垂直/方向改变，固视不抑制 |
| 神经体征 | 无 | 复视、构音障碍、共济失调 |
| 听力 | 可伴耳鸣耳闷 | 多正常 |

<b>🚨 红线</b>：任何"眩晕 + 神经体征"都先按后循环卒中处理，不能直接诊断梅尼埃或 BPPV。

<b>🩺 下一步</b>：① 病史（时间轴、诱因、伴随）；② 眼震与神经查体；③ 位置试验；④ 有中枢体征急诊头颅影像。

#### 🔴 K-M02-017｜梅尼埃病的病理与机制（教师重点第26、28、31条｜P112、P114）

📌 重点原文（第26条）：梅尼埃病的病因、梅尼埃病的主要病理改变、及临床表现、诊断标准，眩晕的特点，诊断主要依靠翔实的病史、全面的检查和仔细的鉴别诊断，甘油试验阳性有助于对本病的诊断。（P114）

📌 重点原文（第28条）：梅尼埃病发生机制主要是内淋巴产生和吸收失衡，具体机制不明。主要学说有：内淋巴管机械阻塞与内淋巴吸收障碍、免疫反应学说、内耳缺血学说和其他学说，如内淋巴囊功能紊乱学说、病毒感染学说、遗传学说等。（P112）

📌 重点原文（第31条）：梅尼埃病的基本病理表现为膜迷路积水膨大，膜蜗管和球囊较椭圆囊和壶腹明显。膜半规管与内淋巴囊不膨大（P112）。

<b>🎯 一句话题眼</b>：膜迷路积水 = 梅尼埃的病理签名；病因是"内淋巴产生与吸收失衡"。

<b>🧬 为什么</b>：内淋巴在封闭的膜迷路内循环，产生多于吸收时压力升高，膜蜗管与球囊最先膨大，压迫毛细胞与神经纤维，于是出现波动性听力下降与眩晕。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 梅尼埃病 | BPPV | 前庭神经炎 |
|---|---|---|---|
| 病理 | 膜迷路积水 | 耳石碎屑进入半规管 | 前庭神经炎性损害 |
| 听力 | 波动性感音神经性 | 正常 | 多正常 |
| 眩晕时长 | 20 分钟–12 小时 | 不超过 1 分钟 | 数天 |

<b>🚨 红线</b>：首次发作、伴神经体征或进行性听力下降，先排中枢/桥小脑角病变。

<b>🩺 下一步</b>：① 纯音测听（波动性低-中频）；② 甘油试验辅助；③ 前庭功能与影像排除其他病因。

#### 🔴 K-M02-018｜梅尼埃病的临床表现（教师重点第29、30、119条｜P112）

📌 重点原文（第29条）：梅尼埃病的典型症状表现包括发作性眩晕，波动性、渐进性听力下降，耳鸣以及耳胀满感。患者神志清醒，眩晕持续短暂，多20分钟至数小时，通常2∼3小时转入缓解期，眩晕持续超过24小时者较少见。（P112）

📌 重点原文（第30条）：梅尼埃病的眩晕多呈突发旋转性，患者感到自身或周围物体沿一定的方向与平面旋转，或感摇晃、升降或漂浮。眩晕均伴有恶心、呕吐、面色苍白、出冷汗、脉搏迟缓、血压下降等自主神经反射症状。上述症状在睁眼转头时加剧，闭目静卧时减轻。患者神志清醒，眩晕持续短暂，多20分钟至数小时，通常2∼3小时转入缓解期，眩晕持续超过24小时者较少见。在缓解期可有不平衡或不稳感，可持续数天。眩晕常反复发作，复发次数越多，持续越长，间歇越短。（P112）

📌 重点原文（第119条）：椭圆囊斑和球囊斑感受直线加速度，半规管壶腹嵴感受角加速度；梅尼埃病眩晕通常持续20分钟至12小时并伴波动性听力改变；BPPV由头位改变诱发，通常不超过1分钟。

<b>🎯 一句话题眼</b>：20 分钟到数小时 + 波动性听力下降 + 耳鸣耳闷 = 梅尼埃四联征。

<b>🧬 为什么</b>：膜迷路积水使内淋巴压力波动，压力高时眩晕发作、听力下降；压力回落时听力回升，所以听力曲线呈"波动性"。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 梅尼埃病 | 前庭神经炎 | 迷路炎 |
|---|---|---|---|
| 诱因 | 自发、反复 | 常有上感史 | 中耳炎/感染 |
| 听力 | 波动性下降 | 正常 | 可下降 |
| 时长 | 20 分钟–12 小时 | 数天 | 数天 |
| 复发 | 反复发作 | 多单次 | 依病因而定 |

<b>🚨 红线</b>：眩晕持续超过 24 小时或伴神经体征，不要按梅尼埃处理。

<b>🩺 下一步</b>：急性期前庭抑制剂 + 止吐；间歇期限盐、生活方式调整、必要时药物或手术；长期随访听力。

#### 🔴 K-M02-019｜良性阵发性位置性眩晕（教师重点第27、32、33、34条｜P116）

📌 重点原文（第27条）：良性阵发性位置性眩晕的病因、典型症状、检查、诊断依据，。为头位变化时突然出现短暂的（通常不超过1分钟）眩晕发作伴眼球震颤。眩晕多为旋转性，可伴恶心、呕吐等自主神经症状，但无耳鸣、耳闷和听力下降。

📌 重点原文（第32条）：手术中发现及颞骨组织病理学研究证实，BPPV患者半规管中或其壶腹嵴上存在游离的碳酸钙结晶或嗜碱性染色的沉着物（耳石碎屑）。但类似组织学改变在包括儿童在内的普通颞骨标本中也有发现，后半规管及外半规管的检出率高于前半规管。按受累的半规管不同，分为4种亚型：后半规管BPPV、外半规管BPPV、前半规管BPPV和混合型BPPV。后半规管BPPV最常见，约占90%，外半规管BPPV次之，前半规管BPPV极少。（P116）

📌 重点原文（第33条）：BPPV的诊断标准：（1）相对于重力方向改变头位后出现反复发作的、短暂的眩晕或头晕（通常持续不超过1分钟）。（2）位置试验中出现眩晕及特征性位置性眼震。（3）排除其他疾病，如前庭性偏头痛、前庭阵发症、中枢性位置性眩晕、梅尼埃病、前庭神经炎、迷路炎、前半规管裂综合征、后循环缺血、直立性低血压、心理精神源性眩晕等。（P116）

📌 重点原文（第34条）：约半数患者病因不明，属特发性BPPV。多见于老年人及女性，可能与年龄增长所致的耳石退化加速、吸收能力下降及耳石的稳定性降低等有关，激素水平改变、钙代谢紊乱及骨质疏松等也可能是易患因素。继发性BPPV继发于其他耳科或全身系统疾病。最常见的原因是头部外伤和前庭神经炎，其他有：梅尼埃病，突发性聋，中耳或内耳的感染和手术，长期卧床等。（P116）

<b>🎯 一句话题眼</b>：翻身/抬头诱发 + 不到 1 分钟 + 无听力下降 = BPPV；后半规管占 90%。

<b>🧬 为什么</b>：耳石从椭圆囊脱落，进入半规管成为游离碎屑；头位改变时碎屑移动带动内淋巴，壶腹嵴被"骗"出旋转信号，于是出现短暂眩晕与位置性眼震。

<b>🔗 机制链</b>：

```text
耳石脱落（退化/外伤/炎症）
        ↓
碎屑进入半规管
        ↓
头位改变 → 碎屑移动 → 内淋巴流动
        ↓
壶腹嵴受刺激 → 旋转性眩晕（<1 分钟）
        ↓
特征性位置性眼震
        ↓
复位后碎屑回椭圆囊 → 症状消失
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | BPPV | 梅尼埃病 | 中枢性位置性眩晕 |
|---|---|---|---|
| 诱因 | 头位改变 | 自发 | 头位改变 |
| 时长 | 不超过 1 分钟 | 20 分钟–12 小时 | 持续，可无潜伏期 |
| 听力 | 正常 | 波动性下降 | 多正常 |
| 眼震 | 短暂、疲劳性 | 自发眼震 | 垂直、方向改变、不疲劳 |
| 处理 | 手法复位 | 前庭抑制剂 | 查中枢病因 |

<b>🚨 红线</b>：出现垂直眼震、方向改变性眼震、伴神经体征，考虑中枢性位置性眩晕，不能复位了事。

<b>🩺 下一步</b>：① Dix-Hallpike（后半规管）/ 滚转试验（外半规管）；② 手法复位（Epley 等）；③ 复位无效或非典型时查影像。

#### 🔴 K-M02-020｜突发性聋（教师重点第125条）

📌 重点原文（第125条）：突发性聋应尽早进行听力学检查和专科评估，可在发病2周内考虑糖皮质激素初始治疗；初始治疗后恢复不完全者，可在发病2～6周评估鼓室内糖皮质激素挽救治疗。改善微循环药物并非所有患者的必需核心一线治疗。

<b>🎯 一句话题眼</b>：72 小时内单侧听力骤降 → 2 周内激素初始，2～6 周挽救。

<b>🧬 为什么</b>：内耳供血依赖终末动脉，栓塞或痉挛导致毛细胞缺氧。毛细胞不可再生，越早恢复灌注，挽救概率越高；超过窗口，损伤不可逆。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 突发性聋 | 梅尼埃病 | 听神经瘤 |
|---|---|---|---|
| 起病 | 数分钟–数小时达峰 | 反复发作 | 进行性 |
| 听力 | 单侧感音神经性 | 波动性低-中频 | 单侧进行性 |
| 伴随 | 耳鸣，可伴眩晕 | 耳闷、低频耳鸣、眩晕 | 耳鸣、不平衡感 |
| 关键检查 | 纯音测听、声导抗 | 甘油试验、听力学 | 增强 MRI |

<b>🚨 红线</b>：伴眩晕或神经体征 → 先排后循环卒中；双侧或进行性下降 → 查桥小脑角。

<b>🩺 下一步</b>：① 纯音测听 + 声导抗；② 2 周内糖皮质激素初始治疗；③ 恢复不完全者 2～6 周评估鼓室内挽救；④ 必要时 MRI。

#### 🟢 K-M02-021｜外耳道炎与外耳道疖（教材背景，不单列条号）

<b>🎯 一句话题眼</b>：牵拉耳廓/按压耳屏剧痛 → 外耳道炎/疖；疖多在外耳道软骨部。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 外耳道炎 | 外耳道疖 | 中耳炎 |
|---|---|---|---|
| 疼痛触发 | 牵拉耳廓加重 | 牵拉耳廓剧痛 | 不随牵拉明显变化 |
| 部位 | 外耳道弥漫 | 外耳道软骨部局限 | 鼓室 |
| 听力 | 多正常 | 多正常 | 传导性下降 |

<b>🚨 红线</b>：鼓膜穿孔或无法确认鼓膜完整时，避免耳毒性滴耳制剂。

<b>🩺 下一步</b>：保持干燥、清理分泌物、局部抗感染；疖成熟后切开引流。

| 鉴别轴 | 外耳道炎 | 慢性化脓性中耳炎 | 胆脂瘤 | 胆固醇肉芽肿 |
|---|---|---|---|---|

### 🔗 因果链：咽鼓管功能障碍 → 分泌性中耳炎 → 粘连/胆脂瘤

```text
上呼吸道感染 / 过敏 / 腺样体肥大 / 鼻咽肿瘤
                ↓
        咽鼓管咽口阻塞
                ↓
        鼓室通气不足 → 负压
                ↓
        黏膜静脉扩张 → 渗出 → 鼓室积液
                ↓
        鼓膜内陷、振动受限 → 传导性聋
                ↓
   长期不愈 → 粘连性中耳炎 / 内陷袋 → 胆脂瘤
```

> 为什么成人单侧分泌性中耳炎要查鼻咽？因为咽鼓管咽口被肿瘤压迫是常见诱因，"单侧"就是题眼。

### 🌳 决策树：眩晕的时间轴

```text
眩晕
├─ 头位改变诱发、不超过 1 分钟、无听力下降
│    → BPPV（Dix-Hallpike / 滚转试验 → 手法复位）
├─ 反复发作、20 分钟–12 小时、波动性听力下降

     → 先排后循环卒中（急诊影像）
```
