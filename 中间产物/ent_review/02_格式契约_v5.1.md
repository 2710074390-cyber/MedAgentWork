# 格式契约（v5.1 五维深度体系 · 每个模块统一遵守）

> 依据：`Prompt版本/Agent5_MedReview_Prompt.md`（v5.1）。写作时**逐条对照**，交付前自检。

## 1. 输出元数据

- 文件：按各自任务路径输出（中间产物\ent_review\模块X_XXX.md）。
- 只写本模块内容；模块开头为 `## 模块N：{模块名}`（最高层级 h2，不要再写 `# 一级标题`，因为最终要合并进总文档）。
- 无「批次标记」「V1-V13 自检报告」等流程残留写入文件。
- **不生成任何题目**（选择题/简答题/病例题一律不要）；唯一允许的自测形式是「🔄 主动回忆区」的《》填空。

## 2. 语法子集（与站端渲染器兼容，缺一禁用）

- ✅ h2-h6 / 空行分段 / 标准 Markdown 表格 / ``` 代码块 / `---` 分隔线 / 行内 **粗** 或 `代码`
- ✅ Obsidian Callout：`> [!WARNING|TIP|INFO|SUCCESS|NOTE] 标题`（连续 `>` 行成卡）
- ✅ 折叠区：`<details open>` + `<summary>…</summary>`（**必须带 open**，严禁出现不带 open 的 `<details>`）
- ✅ 列表：`- ` / `1. `
- ❌ 禁用 Mermaid（一律用 ASCII 图，放在 ``` 代码块内）
- ❌ 禁用其它 HTML 标签、YAML front matter、任务列表 `- [ ]`

## 3. 每模块固定模板（9 区块，顺序不变）

```
## 模块N：{模块名}

> [!INFO] 模块信息
> **重点等级**：🔴掌握X个 / 🟡熟悉X个 / 🟢了解X个
> **教学范围**：{教学大纲条目}
> **关联模块**：与模块X（前导知识）、模块Y（后续应用）相关
> **谱系位置**：{本模块疾病在学科谱系中的严重度位置}
> **预计阅读**：约 X 分钟

### 🧩 前置知识检查（2-4 条，to-do 式反问 or 提示，说明“看不懂的回头补哪里”）

### 🎯 高收益摘要（3-6 条 bullet，先结论后细节）

### 📋 结构化笔记（核心，占最大篇幅）

各考点格式：
🔴 【掌握级】{考点名称}：{定义句}（教材P##）
💡 为什么重要：{≤1行}

🧬 第一性原理：
  {2-5行从正常→异常的因果推导；必须含至少 1 个“如果X不出问题，就不会有Y”式的逻辑转折；结尾一句话总结“本质上就是XX”}

{机制/原理要点 2-3 句}

<details open>
<summary>🔬 展开：{细分知识点}</summary>
{深入机制/数据/鉴别细节 4-8 行}
</details>

> [!WARNING] 易错陷阱
> {陷阱+为什么容易错}

---

🟡 【熟悉级】{考点}：{定义}（教材P##）｜{3-5行：机制+鉴别}｜💡 {≤1行}
---

🟢 【了解级】{考点}：{一句话}（教材P##）
```

## 4. 机械约束（v5.1 不可违反）

| 约束 | 要求 | 本模块最低值 |
|---|---|---|
| Callout | ≥4 种不同类型（WARNING/TIP/INFO/SUCCESS/NOTE 中选 4 种） | ≥8 个（建议 10-14 个） |
| 折叠区 | `<details open>`（默认展开） | ≥4 个（每个🔴考点至少 1 个） |
| D1 第一性原理 | 每个🔴考点必须有「🧬 第一性原理」段 | 🔴个数=段数 |
| D2 因果链 | ASCII 流程图，节点 ≤15，转折节点标 ★ | ≥1 张 |
| D3 谱系梯度 | 本模块疾病严重度梯度图（自限→危重），带转折点 | 1 张 |
| D4 鉴别决策树 | 高频鉴别点（如眩晕、声嘶、耳聋、鼻塞、咽痛、肿物） | ≥1 张（建议 2 张） |
| D5 概念地图 | 不在模块内写（由总文档统一） | — |
| 对比表格 | 诊断标准表/分级表/鉴别表/治疗选择表 ≥4 种类型；表格 3-5 列、每格≤20 字 | ≥5 张 |
| 视觉呼吸 | 无连续 10 行纯文本（每 3-5 行正文后有 callout/表格/折叠区/分隔线） | 全文 |
| 三色覆盖 | 🔴🟡🟢 出现在 ≥90% 考点名称前 | 全文 |
| 页码 | 每个考点（🔴/🟡/🟢）都标（教材P##）真实页码 | 100% |
| 篇幅 | 9000-13000 汉字正文（不含表格/代码块内 ASCII 图） | 本模块 |

## 5. 写法要点

- **L（Links）**：模块信息框 + 开头「先行组织者」1-2 句（这章解决什么问题、本质是什么）。
- **I（可理解性）**：核心句 ≤60 字；先结论→第一性原理→细节。
- **H（Highlighting）**：🔴=期末必考（需要背数值/标准），🟡=能复述，🟢=眼熟。
- **T（Targeting）**：对标期末考试（教学范围）+ 贺银成式考点权重（见 01 文件）。
- **原创性**：基于教材内容重组改写，禁止逐字复制教材或 01 文件；引号内教材原文最多 1 句且必须带页码。
- **D2 与表格互补**：D2 图展示机制链，表格展示数据对比，两者都保留，不得互相替代。
- 未明示的数字：教材没写的不得编造；写不出就概括表述。
