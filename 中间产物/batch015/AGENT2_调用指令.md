## M1 外科学总论与基础（补充 ~8题）

### 浅部组织化脓性感染 — 常见诱因（batch006缺）
- 诱因：皮肤破损（微小创伤/抓伤）、局部卫生不良、糖尿病、免疫功能低下（糖皮质激素/化疗）、营养不良
- 出题方向：A2 病例题 — 糖尿病患者+皮肤疖肿 → 诱因分析
- 来源：大纲/教材（RAG补充）

### 真菌感染 — 入侵途径（batch006只提了念珠菌表现）
- 入侵途径：①皮肤黏膜破损 → 局部念珠菌感染（鹅口疮/阴道炎）
  ②呼吸道吸入 → 肺部曲霉菌感染（免疫低下者）
  ③侵入性操作（深静脉导管/导尿管）→ 血源性播散
- 常见病原菌：念珠菌（最常见）、曲霉菌、隐球菌
- 出题方向：A1 真菌感染途径 / B1 病原菌-感染途径配对
- 来源：大纲/教材P49-50

### MODS — 诊断要点与诱因（batch006只提了SOFA/qSOFA）
- 诊断要点：①原发致病因素（感染/创伤/休克）②器官序贯衰竭（≥2个器官）
  ③改良 Marshall 评分 ≥2 分
- 诱因列表：严重感染（最常见）、严重创伤、大手术、重症胰腺炎、休克、大量输血
- 衰竭顺序：肺→肝→胃肠道→肾→凝血→心脏
- 出题方向：A1 MODS定义+诊断 / X型 MODS诱因多选
- 来源：RAG 外科学 P489 / 教材P36

## M2 休克（补充 ~5题）

### 创伤性休克 — 单独展开（batch006只在低血容量里带了一句）
- 病理特点：①严重创伤+失血双重因素 → 组织灌注不足
  ②脂肪栓塞综合征（长骨骨折后→脂肪滴入血→肺/脑栓塞）
  ③大量组织破坏→肌红蛋白入血→急性肾损伤
  ④激活凝血系统→DIC风险
- 处理原则：止血+镇痛+扩容（晶体:胶体=2:1）+ 手术干预
- 出题方向：A1 创伤性休克特点 / A2 骨折后呼吸困难+瘀点→脂肪栓塞
- 来源：大纲/教材P30-33

## M3 神经外科（补充 ~20题）⚠️ 最大缺失模块

### 小脑幕切迹区解剖（batch006完全缺失）
- 小脑幕切迹裂孔：中脑通过，其外侧面与颞叶钩回、海马回相邻
- 动眼神经：发自大脑脚内侧，越过小脑幕切迹，走行于海绵窦外侧壁 → 眶上裂
- 临床意义：颞叶钩回疝→压迫动眼神经→同侧瞳孔散大（早期体征）
- 出题方向：A1 解剖结构-位置配对 / B1 解剖-临床意义配对
- 来源：RAG 外科学 P186

### 海绵窦位置与临床（batch006完全缺失）
- 位置：蝶鞍两侧，硬脑膜两层之间的静脉间隙
- 穿行结构：动眼神经(III)、滑车神经(IV)、三叉神经眼支(V1)、上颌支(V2)、展神经(VI)、颈内动脉
- 临床：海绵窦综合征 → III/IV/V1/VI 受累
- 出题方向：A1 海绵窦内容物 / X型 海绵窦穿行结构多选
- 来源：大纲/教材

### 颅后窝病变定位（batch006完全缺失）
- 小脑半球病变：同侧肢体共济失调、肌张力↓、意向性震颤、眼球震颤
- 脑干病变：交叉性瘫痪（同侧脑神经麻痹+对侧肢体瘫痪）
- 小脑蚓部病变：躯干共济失调（行走不稳）
- 桥小脑角病变：听神经瘤→耳鸣/听力下降+面瘫
- 出题方向：A1 定位-表现配对 / B1 病变部位-体征配对
- 来源：大纲/教材

### 颅内肿瘤 — 最常见类型与鉴别（batch006完全缺失）
- 最常见类型：①胶质瘤（占40-50%，最常见）→ 胶质母细胞瘤预后最差
  ②脑膜瘤（占20%，良性居多，起源于蛛网膜帽细胞，好发矢状窦旁/大脑凸面）
  ③垂体腺瘤（占10-15%）④转移瘤（占10%，原发灶：肺癌>乳腺癌>黑色素瘤）
  ⑤颅咽管瘤（儿童鞍上区，钙化常见）
- 小脑半球肿瘤体征：同侧肢体共济失调、肌张力↓、眼球震颤
- 脑膜瘤鉴别要点：CT等密度/稍高密度+均匀强化+脑膜尾征；MRI T1等信号/T2等或高信号
- 出题方向：A1 最常见颅内肿瘤 / B1 肿瘤类型-特征配对 / A2 CT表现为脑膜尾征
- 来源：RAG 外科学 P202-207

### 中型颅脑损伤表现（batch006只提了重型GCS≤8）
- GCS：中型 9-12分（轻型13-15/重型3-8）
- 中型临床表现：意识障碍（嗜睡-昏睡而非昏迷）、可有神经系统阳性体征、
  生命体征轻-中度改变、无去大脑强直
- 出题方向：A1 GCS分级 / A2 GCS评分判断伤情
- 来源：RAG 外科学 P188

### 脑囊虫病（batch006完全缺失）
- 感染途径：食入猪带绦虫虫卵→六钩蚴穿入肠壁→血行播散至脑
- 临床表现：癫痫（最常见）、颅内压增高、脑膜脑炎、精神障碍
- 影像：CT示多发小囊状低密度灶+头节（点状高密度）
- 治疗：吡喹酮/阿苯达唑驱虫 + 抗癫痫 + 脱水降颅压
- 出题方向：A1 感染途径 / A2 癫痫+多发囊性病变
- 来源：大纲/教材

### 脑干损伤 — 内脏并发症与呼吸紊乱（batch006完全缺失）
- 内脏并发症：①应激性溃疡（Cushing溃疡）→上消化道出血
  ②神经源性肺水肿 ③心律失常/心肌损伤 ④高血糖
- 呼吸功能紊乱：①中枢性呼吸衰竭（呼吸节律异常—潮式/毕奥/长吸式）
  ②呼吸道分泌物堆积→通气障碍 ③周围性呼吸障碍（误吸/肺不张）
- 出题方向：A1 脑干损伤并发症 / X型 呼吸紊乱类型多选
- 来源：大纲/教材

### ICP增高典型表现 — 完整版（batch006只有三大主症+Cushing）
- 完整表现：①三大主症（头痛/呕吐/视神经乳头水肿）
  ②Cushing反应（血压↑/脉搏↓/呼吸↓/体温↑）
  ③意识障碍（嗜睡→昏睡→昏迷）
  ④生命体征改变
  ⑤外展神经麻痹（假定位征，因外展神经在颅底行程长）
  ⑥小儿：头围增大/前囟隆起/头皮静脉怒张
- 出题方向：A1 ICP典型表现 / X型 ICP临床表现多选
- 来源：RAG 外科学 P186

### 良性颅内压增高（batch006只提了一句）
- 定义：无颅内占位/脑积水/感染的ICP增高
- 好发：肥胖育龄女性
- 临床表现：头痛+视乳头水肿+视力障碍，无局灶神经体征
- 治疗：减轻体重+乙酰唑胺+反复腰穿放液
- 出题方向：A1 良性ICP特点 / A2 肥胖女性+头痛+视乳头水肿
- 来源：大纲/教材

## M4 麻醉学（补充 ~8题）

### 气管切开适应证（batch006完全缺失）
- 适应证：①上呼吸道机械性梗阻（肿瘤/异物/水肿）
  ②下呼吸道分泌物潴留（昏迷/呼吸肌无力→排痰困难）
  ③需长期机械通气（>7-14天）
  ④预防性气管切开（颌面/颈部大手术）
  ⑤双侧声带麻痹
- 出题方向：A1 气管切开适应证 / X型 适应证多选
- 来源：大纲/教材P135

### 上呼吸道梗阻最常见原因（batch006缺失）
- 最常见原因：舌后坠（全麻/昏迷时舌肌松弛→舌根后坠→堵塞咽部）
- 其他原因：喉痉挛、分泌物/异物堵塞、喉水肿
- 处理：仰头抬颏法/托下颌法 → 口咽通气管 → 气管插管 → 气管切开
- 出题方向：A1 最常见原因 / A2 全麻后呼吸困难+鼾声
- 来源：RAG 外科学 P135

### 药物相互作用（batch006缺失）
- 阿片类+吸入麻醉药：协同抑制心血管和呼吸→减少吸入药MAC
- 吸入麻醉药+其他药物：①氨基糖苷类→增强肌松作用
  ②β受体阻滞剂→加重心肌抑制 ③氨茶碱→增加心律失常风险
- 出题方向：A1 药物相互作用 / B1 药物组合-效应配对
- 来源：大纲/教材

### 高血压患者麻醉管理（batch006缺失）
- 术前评估：血压控制程度、靶器官损害（心/脑/肾）、降压药使用情况
- 麻醉诱导：避免血压剧烈波动→选用依托咪酯（心血管稳定）
- 术中管理：维持血压在术前水平的±20%，避免低血压（心肌缺血）和高血压（脑出血）
- 常用降压药：硝普钠/硝酸甘油/尼卡地平
- 出题方向：A1 高血压麻醉原则 / A2 高血压患者术中管理
- 来源：大纲/教材

## M5 甲状腺与乳腺（补充 ~5题）

### 单纯性甲状腺肿病因（batch006缺失）
- 病因：①碘缺乏（最常见，山区/内陆→地方性甲状腺肿）
  ②甲状腺素合成/分泌障碍（先天性酶缺陷）
  ③甲状腺素需求增多（青春期/妊娠期/绝经期）
  ④致甲状腺肿物质（硫氰酸盐/过氯酸盐→抑制碘摄取）
- 出题方向：A1 病因分类 / A2 山区少年+甲状腺弥漫肿大
- 来源：RAG 外科学 P233 + PDF笔记

### 甲状旁腺分泌调节（batch006只讲了损伤后低钙）
- PTH分泌调节：①血Ca²⁺↓→PTH↑（负反馈）；血Ca²⁺↑→PTH↓
  ②活性维生素D₃↓→PTH↑ ③血磷↑→PTH↑（间接）
- PTH靶器官与作用：骨（动员钙磷入血）、肾（排磷保钙+促1α羟化→活性VitD₃）、小肠（促钙吸收）
- 损伤后表现：低钙血症→手足抽搐（Chvostek征+/Trousseau征+）
- 出题方向：A1 PTH调节机制 / B1 激素-靶器官配对
- 来源：RAG 外科学 P241-242

## M6 烧伤与创伤（补充 ~5题）

### 检伤分类目的（batch006缺失）
- 目的：在批量伤员时，按伤情严重程度和治疗紧迫性对伤员分类
- 分类：①第一优先（红色）—立即治疗，危及生命但可救治
  ②第二优先（黄色）—延迟治疗，伤情重但暂不致命
  ③第三优先（绿色）—轻伤，可自行走动
  ④第四优先（黑色）—期待治疗，伤情极重/濒死
- 出题方向：A1 检伤分类颜色-意义配对 / B1 场景-分类判断
- 来源：大纲/教材P68

### 吸入性损伤临床分期（batch006完全缺失）
- 定义：吸入热空气/蒸汽/烟雾/有毒气体→呼吸道损伤
- 临床分期：①早期（0-6h）：呼吸道刺激症状+支气管痉挛
  ②水肿期（6-48h）：喉头及气管支气管黏膜水肿→进行性上呼吸道梗阻（最危险期）
  ③感染期（48h后）：坏死内膜脱落+细菌繁殖→肺部感染/ARDS
- 体征：面部烧伤+鼻毛烧焦+声音嘶哑+碳末痰+喘鸣
- 诊断：纤支镜检查（金标准）
- 出题方向：A1 吸入性损伤分期 / A2 面部烧伤+声音嘶哑→诊断
- 来源：RAG 外科学 P75

## M8 重症监护与急救（补充 ~4题）

### 肾性肾衰竭病因展开（batch006简略）
- 肾前性：低血容量（出血/脱水）、心衰、休克、肾动脉狭窄
- 肾性（肾实质）：①急性肾小管坏死（最常见，缺血/肾毒性药物）
  ②肾小球肾炎③急性间质性肾炎④肾血管病变
- 肾后性：尿路梗阻（结石/肿瘤/前列腺增生）
- 鉴别：肾前性vs ATN → 尿比重/尿钠/尿肌酐比值（见教材P169表格）
- 出题方向：A1 三类病因 / B1 指标-肾前/肾性配对
- 来源：RAG 外科学 P167-169

## M9 其他 — 心胸/血管/产科/新生儿（补充 ~25题）⚠️ 第二大缺失模块

### COPD急性加重表现与治疗（batch006只标了"大纲/待查"）
- 急性加重表现：呼吸困难加重+痰量增多+脓性痰
- 体征：桶状胸+双肺哮鸣音+湿啰音+呼气延长
- 治疗：①氧疗（低流量1-2L/min，防CO₂潴留）②支气管扩张剂（短效β₂激动剂+抗胆碱药）
  ③糖皮质激素（口服/静脉）④抗生素（有感染证据时）⑤无创通气（NIV）→ 有创通气
- 出题方向：A1 COPD急性加重治疗 / A2 慢阻肺病史+呼吸困难加重
- 来源：内科学 P25-29（跨科RAG检索）

### 呼吸衰竭主要临床表现（batch006缺失）
- 定义：PaO₂＜60mmHg（Ⅰ型）或伴 PaCO₂＞50mmHg（Ⅱ型）
- 临床表现：①呼吸困难（最早/最突出）②发绀（缺氧典型体征）
  ③精神神经症状（CO₂潴留→肺性脑病：先兴奋后抑制/嗜睡昏迷）
  ④循环表现（心动过速/血压↑→晚期血压↓）
- Ⅰ型vsⅡ型鉴别：Ⅰ型换气障碍（ARDS/肺炎），Ⅱ型通气障碍（COPD/呼吸肌麻痹）
- 出题方向：A1 呼衰诊断标准 / A2 血气分析+临床表现→分型判断
- 来源：内科学 P148-152（跨科RAG检索）

### 肺动脉高压原因（batch006只列了5大类名）
- 病因分类：①肺动脉高压（特发性/遗传性/药物）②左心疾病所致
  ③肺部疾病/低氧所致（COPD最常见）
  ④慢性血栓栓塞性肺动脉高压 ⑤多种机制不明
- 出题方向：A1 肺高压分类 / X型 病因多选
- 来源：内科学 P122

### 广谱抗心律失常药（batch006完全缺失）
- 胺碘酮（Ⅲ类）：广谱，用于房颤/室速/室颤，副作用→甲亢/甲减/肺纤维化/角膜沉积
- 利多卡因（Ⅰb类）：室性心律失常首选，AMI时预防室颤
- β受体阻滞剂（Ⅱ类）：窦速/房颤室率控制/心梗后
- 出题方向：A1 胺碘酮分类与副作用 / B1 药物-适应症配对
