## 二、结构化知识笔记

### 2.1 三步诊断法

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  定向诊断    │ → │  定位诊断    │ → │  定性诊断    │
│  是否为神经   │    │  病灶在哪里   │    │  什么病因     │
│  系统疾病？   │    │  解剖位置     │    │  病理性质     │
└─────────────┘    └─────────────┘    └─────────────┘
    病史+体检         神经解剖推理        辅助检查+病程
```

### 2.2 运动系统病损定位链

```
大脑皮质运动区 → 内囊(集中通过)→ 脑干(交叉)→ 脊髓前角/脑神经核 → 周围神经 → 神经肌肉接头 → 肌肉

UMN损伤（中枢性瘫）= 皮质至前角以上 → 痉挛性瘫+腱反射↑+病理征(+) 
LMN损伤（周围性瘫）= 前角及以下 → 弛缓性瘫+腱反射↓+病理征(-)
```

### 2.3 脑干病变核心规律：交叉性体征

> 脑干病变 = 同侧脑神经麻痹 + 对侧肢体运动/感觉障碍
> 中脑 → Weber（III+偏瘫）/ Benedikt（III+不自主运动）
> 脑桥 → Millard-Gubler（VII+VI+偏瘫）
> 延髓 → Wallenberg（IX/X+Horner+交叉性感觉障碍）

### 2.4 脑血管定位口诀

| 血管 | 核心症状 | 记忆线索 |
|------|---------|----------|
| 大脑中动脉(MCA) | 对侧三偏+失语 | 「中动脉偏中间」 |
| 大脑前动脉(ACA) | 对侧下肢重瘫+尿失禁 | 「前=下肢在前」 |
| 大脑后动脉(PCA) | 对侧偏盲+丘脑综合征 | 「后=视觉在后」 |
| 椎-基底动脉 | 眩晕+复视+交叉瘫 | 「椎基底=基础紊乱」 |
| 小脑后下动脉(PICA) | Wallenberg综合征 | 「PICA=5同1对」 |

## 四、临床思维路径

### 路径1：急性偏瘫定位诊断

```
患者急性偏瘫
├── 有无同侧脑神经麻痹？
│   ├── 有 → 脑干病变（交叉性）→ 定位脑神经核水平
│   └── 无 → 大脑/内囊 → 继续判断
│       ├── 下肢为主 → ACA供血区
│       ├── 上下肢均等+面下部 → MCA/内囊
│       ├── 偏盲突出 → PCA供血区
│       └── 纯运动/纯感觉 → 腔隙性梗死
└── CT+DWI → 鉴别缺血/出血 → 指导治疗
```

### 路径2：眩晕鉴别路径

```
眩晕/头晕
├── 真性眩晕（旋转感）？
│   ├── 持续时间？
│   │   ├── 数秒 → BPPV（耳石症）→ Dix-Hallpike
│   │   ├── 数分钟至小时 → 梅尼埃病（+耳鸣）→ 周围性
│   │   ├── 数天 → 前庭神经炎 → 周围性
│   │   └── 持续数天至月 → 脑干/小脑？→ 中枢性
│   └── 伴随脑干体征？
│       ├── 有 → 中枢性 → MRI(DWI)
│       └── 无 → 周围性
└── 非真性眩晕 → 心血管/代谢检查
```

### 路径3：癫痫发作急诊处理

```
癫痫发作
├── 持续状态(>5min)？ → 是 → 急救
│   ├── 气道+吸氧+生命体征
│   ├── 地西泮10mg iv（一线）
│   ├── 5-10min仍发 → 苯妥英钠/丙戊酸 iv（二线）
│   └── 30min仍发 → ICU+麻醉药（难治性SE）
└── 单次发作 → 侧卧+观察+EEG+MRI → 鉴别晕厥/PNES/TIA
```

### 路径4：肌无力鉴别路径（MG/GBS/周期性瘫）

```
四肢无力
├── 波动性（晨轻暮重）？ → MG（新斯的明+抗AChR抗体）
├── 发作性（数小时恢复）？ → 查血钾
│   ├── 血钾↓ → 低钾周期性瘫（补钾）
│   └── 血钾正常 → 正常钾/高钾性
├── 急性+前驱感染？ → GBS（CSF蛋白-细胞分离+NCV）
└── 亚急性近端+自主神经+腱反射↓ → LEMS（抗VGCC抗体）
```

### 路径5：脑疝识别与处理

```
颅内压增高征象（头痛+呕吐+视乳头水肿）
├── 意识障碍迅速恶化？
│   ├── 一侧瞳孔散大+对侧偏瘫+去脑强直 → 小脑幕裂孔疝（颞叶钩回疝）
│   │   └── 紧急降颅压(甘露醇)+过度通气+手术
│   └── 突发呼吸骤停+双侧瞳孔散大 → 枕骨大孔疝（小脑扁桃体疝）
│       └── 立即插管+紧急后颅窝减压
└── 慢性颅内压增高 → 影像学+病因治疗
```
