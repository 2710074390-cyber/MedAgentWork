**字段约束（任一不符 → FAIL）**：
- `id`：`batch031-{模块号}-{题型}-{3位序号}`，如 `batch031-M2-A1-001`；同模块同题型序号连续、不重复；B1 共用选项组内子题序号连续
- `module`：`M1`~`M11`（见 §4，一字不差用表内编号）
- `module_name`：§4 模块清单原文
- `topic`：本模块内一个具体考点（≤ 20 字）
- `type`：`A1`/`A2`/`A3`/`B1`/`X`（无 A4、无判断题）
- `polarity`：`positive`（选正确项）/ `negative`（选错误/不正确/除外项，题干须含「不/错误/除外/不包括」）/ `multi`（X 型）
- `bloom`：`记忆`/`理解`/`应用`/`分析`（中文四档）
- `stem`：题干文本；A2/A3 为「男性/女性，年龄，+主诉+体征/检查」病例摘要；B1 为共用选项下的独立小问

- `answer`：单选为单字母 A–E；X 型为多字母串（如 `"ABD"`，2–4 个字母）
- `explanation`：机制/鉴别要点 + 真实印刷页（如 `教材P162`）；X 型须逐项说明入选/排除理由
- `source_page`：`教材P{printed}` 单值
- `difficulty`：`基础`/`中等`/`较难`/`困难`
- `option_polarities`：`{"A":bool,...}`，仅正确项为 `true`（X 型多个 true）
- 真题题额外加 `kaoyan_origin` 字段（见 §6）

## 3. 题型定义与选项设计（NBME 八项 + HC-14 + R 系列门禁）

- **A1**：单句最佳单选题（定义/数值/标准/首选处理/特征）。
- **A2**：简短病例单点诊断/处理（急诊情境：分诊、首要处理、下一步检查）。
- **A3**：共用题干病例组（同组 2–3 问逐步推进：诊断→机制→检查→处理）。本批 A3 采用「一问一对象」：每个子题独立 JSON，stem 内含完整病例摘要 + 本问问题（参照 batch033 成品写法）。
- **B1**：共用 5 选项，2–3 个独立小问；共用选项须同一抽象层（同类药物/同类检查/同类表现），每个子题独立 JSON 且 options 重复列出；组内答案字母不重复占用同一位置。
- **X**：不定项多选，题干含「正确的有/包括/机制涉及」，`polarity:"multi"`，解析逐项说明。

**选项硬规则**：
1. 禁绝对词（所有/均/必然/从不/绝对）；允许「最常见/主要/典型」。
2. **结构模板（HC-14）**：同题 5 选项共享相同语法结构（如都是「[药物]+[作用靶点]」、都是「[数值]+[单位]」）。
3. 长度比 ≤ 1.5×；单选项 ≤ 20 字；自然短术语（药名/病名 3–7 字）豁免下限。
4. 数值选项升/降序排列，正确答案位置随机（禁恒 C）。
5. 词重复防护（R10）：题干关键词不得只出现在正确选项；收敛防护（R11）。
6. 禁无意义后缀（R12）：禁止「（相关表现）」「（相关类型）」凑长度。
7. 禁截断（R7/R8）：不以「的/和/与/于」结尾、无「..」、临床参数/剂量必须带单位（R9：CPR/补液/血气/电解质类数值缺单位 → FAIL）。
8. 数值干扰项与正确值差距 ≤ 5×（HC-6）。
9. 答案位置在 A–E 上均衡分布，避免连续 5 题同字母。
