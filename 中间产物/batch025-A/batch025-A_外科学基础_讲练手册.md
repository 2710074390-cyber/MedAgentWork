## 考点 1.1：外科感染与无菌原则 【Tier 1·⭐⭐⭐】

### 📖 三源讲解

**🧬 核心概念**

| 术语 | 定义 | 来源 |
|------|------|:---:|
| 外科感染 | 需要外科处理的感染，包括创伤/烧伤/手术相关感染 | 教材P49 |
| 非特异性感染（化脓性感染） | 疖、痈、丹毒、急性蜂窝织炎、急性乳腺炎、急性阑尾炎等 | 绿皮P266 |
| 特异性感染 | 破伤风、气性坏疽、结核、真菌感染等——每种病原体有独特病理改变 | 昭昭 |
| 疖 | 单个毛囊及其周围组织的急性化脓性感染 | 教材 |
| 痈 | 多个相邻毛囊及其周围组织的急性化脓性感染，可由多个疖融合而成 | 绿皮P266 |
| 丹毒 | 乙型溶血性链球菌引起的皮肤淋巴管网急性炎症 | 绿皮P266 |
| 灭菌法 | 杀灭一切微生物（含芽胞）的方法——高压蒸汽灭菌后**有效期14天** | 教师重点 |
| 消毒 | 杀灭病原微生物但不一定杀灭芽胞 | — |
| 无菌 | 无活微生物存在的状态 | — |

**🔍 机制理解**

- **破伤风**：破伤风梭菌（G⁺厌氧芽胞杆菌）→ 产生**痉挛毒素**（外毒素）→ 抑制抑制性神经递质（GABA/甘氨酸）释放 → 肌肉持续强直收缩。**最先受累：咀嚼肌**（张口困难/苦笑面容）→ 面肌→颈→背→腹→四肢→膈肌。病人**一般无发热**，神志始终清醒。
- **气性坏疽**：梭状芽胞杆菌（G⁺厌氧）→ 肌坏死+肌炎→产生气体（H₂S等）+ 恶臭 + **捻发感** + 大理石样斑纹 + 严重全身中毒症状。**预防关键：早期彻底清创、引流、切开减压。治疗：清创+大剂量青霉素（200万-1000万U/d）+ 高压氧。**
- **慢性感染时限**：病程超过**2个月**。

**💡 考试角度**

| 🟢 绿皮书 | 破伤风/气性坏疽临床表现+治疗原则；丹毒的致病菌（乙型溶链菌）；抗生素选择原则 |
| 🟡 贺银成 | 外科感染概述→浅表感染→破伤风和气性坏疽的临床表现及治疗 |
| 🔵 昭昭 | 题眼：破伤风/结核/真菌/气性坏疽 = **特异性感染**；金葡菌→**疖/痈**最常见致病菌 |

**⚠️ 易混淆**

| 对比维度 | 破伤风 | 气性坏疽 |
|----------|--------|----------|
| 致病菌 | 破伤风梭菌（G⁺厌氧） | 梭状芽胞杆菌（G⁺厌氧） |
| 毒素 | 痉挛毒素（外毒素） | α毒素等外毒素 |
| 核心病理 | 痉挛毒素抑制抑制性递质→持续强直收缩 | 肌坏死+肌炎+气体产生 |
| 最早表现 | 咬肌痉挛（张口困难/苦笑面容） | 伤口剧痛+肿胀 |
| 特征体征 | 角弓反张 / 无发热 / 神志清楚 | **捻发感** / 恶臭 / 大理石斑纹 |
| 关键治疗 | TAT中和毒素 + 镇静控制痉挛 + 青霉素 | **彻底清创** + 大剂量青霉素 + **高压氧** |
| 预防 | 清创+免疫（主动：类毒素；被动：TAT） | 早期彻底清创 |
| 神志 | **始终清醒** | 严重全身中毒→意识障碍 |

### 📝 例题印证

**【例1·绿皮书】**
> 破伤风病人一般无以下哪项表现？
> A. 角弓反张　B. 苦笑面容　C. 张口困难　D. **发热**✅　E. 肌肉强直

**解析**：破伤风病人一般**无发热**（D项为错误→即正确答案）。破伤风痉挛毒素作用→肌紧张+阵发性痉挛（A/B/C/E均正确）。**不选原因**：学生可能在A-E全对→找不到"无"的表现 → 需记住"无发热"是关键鉴别点。

**【例2·绿皮书】**
> 气性坏疽的临床特点不包括：
> A. 捻发感　B. 恶臭　C. 全身中毒症状重　D. **持续高热**✅　E. 伤口产气

**思路**：气性坏疽有产气=捻发感(A✓)、H₂S=恶臭(B✓)、全身中毒重(C✓)、气体(E✓)。D错。

## 考点 1.2：创伤与烧伤 【Tier 1·⭐⭐⭐】

### 📖 三源讲解

**🧬 核心概念**

| 知识点 | 核心内容 | 来源 |
|--------|----------|:---:|
| 创伤愈合过程 | **炎症期**（1-3天：止血+炎细胞浸润）→ **增生期**（3天-数周：肉芽组织+胶原沉积）→ **重塑期**（数周-数月：胶原重组/瘢痕收缩） | 教师重点 |
| 影响愈合因素 | **局部**：感染、异物、血肿、血运不良、制动不良；**全身**：营养不良、高龄、糖尿病、免疫抑制、吸烟 | 绿皮P298 |
| 创伤并发症 | 感染/休克/脂肪栓塞综合征/ARDS/ARF/DIC | 教师重点 |
| 多发伤救治 | **ABCDE原则**：Airway→Breathing→Circulation→Disability→Exposure；**损伤控制外科(DCS)**：止血+控制污染→ICU复苏→确定性手术 | 教师重点 |
| 烧伤面积·中国九分法 | 头颈9% / 双上肢18%(9×2) / 躯干27%(9×3) / 双下肢46%(9×5+1) | 贺讲义/绿皮P305 |
| 小儿体表面积 | **头颈=[9+(12-年龄)]%** / **双下肢=[46-(12-年龄)]%** | 绿皮P319 |

**🔍 烧伤深度·三度四分法**

| 分度 | 深度 | 创面特点 | 感觉 | 愈合 |
|:---:|------|----------|:---:|------|
| **Ⅰ°** | 表皮层(生发层健在) | 红斑、干燥、无水疱 | 烧灼感（过敏） | 3-7天脱屑，不留瘢痕 |
| **浅Ⅱ°** | 真皮乳头层 | **水疱大**、基底红润、渗出多 | 剧痛（过敏） | 1-2周，不留瘢痕 |
| **深Ⅱ°** | 真皮深层(网状层) | **水疱小**、基底**红白相间** | 迟钝 | 3-4周，留瘢痕 |
| **Ⅲ°** | 全层皮肤+皮下 | **焦痂**、蜡白/炭化/树枝状血管 | 消失 | 需植皮 |

**🔍 烧伤补液**

```
成人伤后第1个24h补液量 = 1.5ml × 体重(kg) × 烧伤面积(%TBSA) + 2000ml(5%GS)
  其中：胶体:电解质 = 0.5:1（即胶0.5ml/kg·%、晶1.0ml/kg·%）
  前8h输入总量的一半，后16h输入另一半
  
第2个24h = 第1个24h胶晶量的一半 + 2000ml(5%GS)
```

> ⚠️ **Parkland公式**（国际常用）= 4ml × kg × %TBSA（乳酸林格液）/ 前8h半量 / 不含胶体 / 不含5%GS

**监测指标**：成人尿量维持 **30-50ml/h**（绿皮P314）

**💡 考试角度**

| 🟢 绿皮书 | 烧伤面积计算+深度判断+补液公式计算；影响创伤愈合因素（多选常考）；火器伤一期缝合禁忌 |
| 🟡 贺银成 | 中国九分法记忆要点（3,3,3 / 5,6,7 / 13,13,会阴1 / 5,7,13,21） |
| 🔵 昭昭 | 烧伤深度题眼：水疱大+剧痛=浅Ⅱ°；红白相间+迟钝=深Ⅱ°；焦痂=Ⅲ° |

**⚠️ 易混淆**

| 对比维度 | 浅Ⅱ°烧伤 | 深Ⅱ°烧伤 |
|----------|----------|----------|
| 深度 | 真皮乳头层 | 真皮网状层 |
| 水疱 | **大**、饱满 | **小**、扁平 |
| 基底 | **红润**、渗出多 | **红白相间** |
| 感觉 | **剧痛/过敏** | 迟钝 |
| 愈合 | 1-2周，不留瘢痕 | 3-4周，留瘢痕 |
| 昭昭题眼 | "水疱大+剧痛" | "红白相间+迟钝" |

### 📝 例题印证

**【例1·绿皮书】**
> 成人头颈部占体表面积9%，小儿头颈部占体表面积为：
> A. 9%　B. 12%　C. **[9+(12-年龄)]%**✅　D. 9-(12-年龄)%　E. 12+(12-年龄)%

**解析**：关键公式记忆——儿童头大、下肢小。头颈=9+(12-年龄)%，双下肢=46-(12-年龄)%。

**【例2·绿皮书】**
> 烧伤休克期(成人)床旁掌握输液速度的简易指标是：
> A. **每小时尿量30-50ml**✅　B. 每小时尿量10-15ml　C. 脉率在120次以下　D. 脉率在140次以下　E. 安静

**解析**：烧伤补液最简易可靠的监测指标=**尿量**。成人维持30-50ml/h。尿量<30ml/h→补液不足。B项(10-15ml/h = 少尿)→提示休克未纠正。

## 考点 1.3：休克 【Tier 1·⭐⭐⭐】

### 📖 三源讲解

**🧬 核心概念**

> **休克定义**：多种病因→有效循环血容量减少→组织灌注不足→细胞代谢紊乱和功能受损的病理生理过程。（绿皮P91 / 贺讲义）

**休克分类**：低血容量性 / 感染性 / 心源性 / 神经性 / 过敏性。外科最常见→**低血容量性休克和感染性休克**。

| 核心概念 | 数值/内容 | 来源 |
|----------|-----------|:---:|
| **休克本质** | 组织灌注不足（微循环障碍） | 昭昭/贺讲义 |
| **休克指数** | **脉率÷收缩压** → >1.0提示休克，>1.5严重休克 | 教师重点 |
| 代偿期血压 | 可正常或略高，**脉压↓** | 教师重点 |
| 脉搏 | 脉快而弱 | 教师重点 |
| 早期易损器官 | **肾**（肾血流↓→GFR↓→少尿） | 教师重点 |
| 少尿机制 | 肾血流↓ + ADH↑ + 醛固酮↑ → 水钠重吸收↑ + GFR↓ | 教师重点 |

**🔍 微循环改变·三期**

| 分期 | 机制 | 微循环特点 | 临床 |
|:---:|------|-----------|------|
| **缺血期**（代偿期） | 交感神经兴奋→儿茶酚胺大量释放→外周血管收缩 | **"只出不进"**：毛细血管前括约肌收缩，后括约肌相对开放 | 血压可正常/脉压↓，皮肤苍白湿冷 |
| **淤血期**（失代偿期） | 酸性代谢产物堆积→前括约肌松弛/后括约肌仍痉挛 | **"只进不出"**：毛细血管淤血、静水压↑ | 血压↓，皮肤花斑 |
| **衰竭期**（不可逆期） | DIC形成、细胞坏死 | 微血栓形成、血液不凝 | MODS→死亡 |

**🔍 休克监测**

| 类别 | 指标 | 正常值/意义 |
|------|------|-----------|
| 一般 | 精神状态 | 反映脑灌注 |
| 一般 | 皮肤温度/色泽 | 反映体表灌注 |
| 一般 | 血压+脉率 | 休克指数=脉率/收缩压 |
| 一般 | **尿量** | >30ml/h→肾灌注良好 |
| 特殊 | **CVP**（中心静脉压） | **5-12cmH₂O**；<5→血容量不足；>15→心功能不全；>20→充血性心衰 |
| 特殊 | **PAWP**（肺动脉楔压） | 6-15mmHg，反映左心前负荷 |
| 特殊 | CO/CI | 心排血量/心脏指数 |
| 特殊 | **动脉血乳酸** | >2mmol/L→组织缺氧/无氧代谢 |
| 特殊 | SvO₂（混合静脉血氧饱和度） | 反映氧供-氧耗平衡 |

**🔍 感染性休克·血流动力学分型**

| 特征 | 🔥 暖休克（高排低阻） | ❄️ 冷休克（低排高阻） |
|------|----------------------|----------------------|
| 心排血量 | ↑（高排） | ↓（低排） |
| 外周血管阻力 | ↓（低阻） | ↑（高阻） |
| 皮肤 | 温暖干燥、潮红 | **湿冷苍白**、发绀 |
| 血压 | 可正常或偏低 | 明显降低 |
| 脉搏 | 有力 | 细弱 |
| 常见病原 | G⁺菌（早期） | G⁻菌（更常见） |

**💡 考试角度**

| 🟢 绿皮书 | 休克监测指标分类（一般+特殊常考多选）；低血容量性休克首要治疗=纠正低血容量；感染性休克病因治疗=抗感染 |
| 🟡 贺银成 | 微循环三期机制；CVP解读（<5→补液/ >15→强心/ >20→心衰）；暖休克vs冷休克表格 |
| 🔵 昭昭 | 题眼："各类型休克的根本变化=**组织灌注不足**"；"休克代偿期血压=正常或略高"；"暖休克皮肤=**温暖潮红**" |

**⚠️ 易混淆**

| 对比 | CVP低 (<5cmH₂O) | CVP高 (>15cmH₂O) |
|------|-----------------|-------------------|
| 意义 | 血容量不足 | 心功能不全/肺循环阻力增高 |
| 处理 | **补液试验**（250-500ml晶体快速输入） | 强心+利尿+血管扩张剂 |
| 血压 | 低 | 可低可正常 |

### 📝 例题印证

**【例1·绿皮书】**
> 腹痛、发热48小时，血压80/60mmHg，神志清楚，面色苍白，四肢湿冷，全腹肌紧张，肠鸣音消失，诊断为：
> A. 低血容量性休克　B. **感染性休克**✅　C. 神经源性休克　D. 心源性休克　E. 过敏性休克

**解析**：腹痛+发热+腹膜炎体征（全腹肌紧张、肠鸣音消失）→急腹症/腹腔感染→感染性休克。血流动力学：面色苍白+四肢湿冷 = **冷休克**（低排高阻型）。**不选A**：虽然存在低血容量，但感染是原发病因。

**【例2·绿皮书】**
> 当病人处于休克状态时，首要的治疗措施是：
> A. 使用血管活性药物　B. 使用强心药　C. 使用抗生素　D. 使用激素　E. **纠正低血容量**✅

**解析**：无论何种休克，**恢复组织灌注**是首要目标。补充血容量（补液+必要时输血）是最基本措施。**先补液，后用药**——血管活性药在血容量补足后才考虑。

## 考点 1.4：SIRS与MODS 【Tier 1·⭐⭐】

### 📖 三源讲解

**🧬 核心概念**

> **SIRS**（全身炎症反应综合征）：机体对感染/创伤/烧伤/胰腺炎等严重打击的失控性全身炎症反应。

**SIRS诊断标准**（≥2条即可诊断）：

| 指标 | 标准 |
|------|------|
| 体温 | **>38℃** 或 **<36℃** |
| 心率 | **>90次/分** |
| 呼吸 | **>20次/分** 或 PaCO₂**<32mmHg** |
| WBC | **>12×10⁹/L** 或 **<4×10⁹/L** 或 **幼稚粒细胞>10%** |

**🔍 MODS**（多器官功能障碍综合征）

| 要点 | 内容 |
|------|------|
| 定义 | 严重创伤/感染/休克后，**序贯**出现≥2个器官功能障碍 |
| 评估工具 | **SOFA评分**（序贯器官衰竭评分） |
| 诱发因素 | 感染（最常见）、创伤、休克、重症胰腺炎 |
| **核心学说** | 肠屏障破坏→细菌/内毒素移位→"**肠道是MODS的发动机**" |
| 临床分期 | 早期→SIRS / 进展→MODS / 终末→MOF（多器官衰竭） |

**💡 考试角度**

| 🟢 绿皮书 | SIRS/脓毒症/MODS概念区分；全身并发症归类 |
| 🟡 贺银成 | SIRS→MODS级联；重症胰腺炎早期的SIRS→MODS演变 |
| 🔵 昭昭 | —（SIRS/MODS在昭昭外科部分出现较少） |

---

### 📝 例题印证

**【例1·绿皮书型】**
> 关于SIRS（全身炎症反应综合征）的诊断标准，以下哪项是诊断所**必需**的？
> A. 必须同时满足4条标准　B. 满足≥1条即可诊断　C. **满足≥2条即可诊断**✅　D. 必须有明确的感染证据　E. 必须有器官功能障碍

**解析**：SIRS诊断标准4条（体温>38℃或<36℃、心率>90次/分、呼吸>20次/分或PaCO₂<32mmHg、WBC>12×10⁹/L或<4×10⁹/L或幼稚>10%）——满足≥2条即可诊断。SIRS≠感染（感染+SIRS=脓毒症）。无器官功能障碍也可诊断SIRS。

**【例2·教材改编型】**
> 关于MODS的发病机制，被认为起"发动机"作用的器官是：
> A. 肝脏　B. 肺脏　C. **肠道**✅　D. 肾脏　E. 心脏

**解析**：肠道屏障破坏→细菌/内毒素移位→启动全身炎症反应→序贯器官衰竭。故肠道被称为"MODS的发动机"。这是外科学教材中的重要概念，常以A1型题考查。

## 考点 1.5：水电解质与酸碱平衡 【Tier 1·⭐⭐⭐】

### 📖 三源讲解

**🧬 脱水类型对比**

| 类型 | 别名 | 失水 vs 失钠 | 血清Na⁺ | 主要病因 | 体液分布 |
|:---:|------|:----------:|:--------:|----------|----------|
| **等渗性脱水** | 急性脱水 | 水钠等比 | 135-145mmol/L（正常） | 消化液大量丢失（呕吐/腹泻/肠瘘） | **细胞外液↓**，细胞内液正常 |
| **高渗性脱水** | 原发性脱水 | 失水>失钠 | **>145mmol/L** | 进水不足/失水过多（高热/大汗/尿崩） | 细胞内液↓为主→**渴感明显** |
| **低渗性脱水** | 慢性脱水/继发性脱水 | 失钠>失水 | **<135mmol/L** | 消化道/皮肤/肾性失钠后补水未补钠 | 细胞外液↓明显→**休克倾向** |

**🔍 低渗性缺水原因**：
- 消化道：持续胃肠减压、反复呕吐、慢性肠梗阻
- 皮肤：大面积烧伤、大量出汗后只补水
- 肾性：使用排钠利尿剂、肾小管酸中毒
- **关键：补水未补钠 → 低渗**

**🔍 高钾血症**

| 病因 | 具体 |
|------|------|
| 摄入↑ | 大量输库存血/补钾过量 |
| 排出↓ | **肾衰竭**（最常见）/ 保钾利尿剂 / ACEI / 醛固酮↓ |
| 细胞内钾外移 | 酸中毒 / 组织破坏（挤压伤/溶血/烧伤） / 高钾性周期性麻痹 |

**补钾铁律（⚠️高频考点）**：

| 规则 | 标准 |
|------|------|
| **见尿补钾** | 尿量 **>40ml/h** 方可补钾 |
| 浓度 | ≤ **0.3%**（即≤40mmol/L） |
| 速度 | ≤ **20mmol/h**（即≤1.5g KCl/h） |
| 每日总量 | 3-6g KCl/d（严重可至8-12g） |

**🔍 脱水程度判断**

| 程度 | 失水占体重% | 临床表现 |
|:---:|:----------:|----------|
| 轻度 | 2-4% | 口渴 |
| 中度 | 4-6% | 明显口渴/皮肤干燥/尿少/乏力 |
| 重度 | >6% | 躁狂/谵妄/休克/无尿 |

> **少尿**：<400ml/24h 或 <17ml/h（教师重点）

**💡 考试角度**

| 🟢 绿皮书 | 等渗性脱水时细胞外液量迅速减少；低渗性缺水时ADH↓→多尿+醛固酮↑→保钠；急性肾衰竭多尿期机制 |
| 🟡 贺银成 | 补钾原则；高钾血症降钾治疗（血钾>5.5常规降钾/>6.5紧急血液净化） |
| 🔵 昭昭 | — |

---

### 📝 例题印证

**【例1·绿皮书】**
> 关于水钠代谢紊乱正确的是：
> A. 等渗性缺水可引起细胞外和细胞内都缺水　B. 平衡液的电解质含量和血浆内含量相仿，但渗透压则较血浆为高　C. **低渗性缺水时，尿比重往往低于1.010，尿Na⁺和Cl⁻常明显减少**✅　D. 高渗性缺水时应快速补充低渗液　E. 等渗性缺水应单用等渗盐水治疗

**解析**：低渗性缺水→ADH分泌↓→多尿→尿比重<1.010 + 肾保钠→尿Na⁺/Cl⁻减少(C✓)。A错：等渗性脱水仅细胞外液减少；B错：平衡液渗透压≈血浆；D错：高渗性脱水应缓慢纠正；E错：等渗性缺水用平衡盐优于单纯盐水。

**【例2·绿皮书】**
> 急性肾衰竭多尿期多尿的机制不包括：
> A. 肾血流量和肾小球滤过功能逐渐恢复　B. 新生肾小管上皮细胞功能尚不成熟　C. 肾间质水肿消退，肾小管堵塞解除　D. 少尿期中潴留在血中的代谢产物经肾小球大量滤出，产生渗透性利尿　E. **抗利尿激素分泌增多**✅

**思路**：多尿期ADH应↓（非↑），否则应持续少尿。E为错误→即为"不包括"的正确答案。

## 考点 1.6：输血 【Tier 1·⭐⭐】

### 📖 三源讲解

**🧬 核心概念**

> ⚠️ **输血指征必须精确，数值不可差！**

| 指征 | 标准 |
|------|------|
| 一般手术 | **Hb<70g/L** |
| 合并心肺疾病 | **Hb<100g/L** |
| 急性失血 | 失血**>20%血容量**（约>1000ml） |

**🔍 自体输血**

| 方式 | 内容 | 优点 |
|------|------|------|
| **预存式** | 术前3-4周分次采血储存，术中回输 | Hb>110g/L方可采血 |
| **稀释式** | 麻醉后采血+同时输胶晶液稀释，术毕回输 | 适用于无感染/无贫血患者 |
| **回收式** | 术中体腔积血回输 | 禁忌：血液被消化液/癌细胞污染 |

**自体输血优点**：无免疫反应 / 无传染病传播 / 节约血源（教师重点）

**🔍 血小板输注指征**

| 情况 | PLT阈值 |
|------|:------:|
| 预防性输注 | **<10×10⁹/L** |
| 手术前/有创操作前 | **<50×10⁹/L** |
| 神经外科/眼科手术 | **<100×10⁹/L** |

**🔍 大量输血后渗血原因（5因素）**

| 因素 | 机制 |
|------|------|
| ①稀释性血小板↓ | 库存血中血小板已失活 |
| ②凝血因子↓ | 库存血中凝血因子V/VIII降解 |
| ③低体温 | 抑制凝血酶活性 |
| ④DIC | 大量输血+休克诱发 |
| ⑤低钙血症 | 枸橼酸盐抗凝剂→结合Ca²⁺ |

**🔍 输血反应速查**

| 反应类型 | 发生时间 | 主要表现 | 处理 |
|----------|----------|----------|------|
| **发热反应**（最常见早期反应） | 输血开始后15min-2h | 寒战+发热 | 减慢/停止→退热药 |
| **过敏反应** | 任何时间 | 荨麻疹→血管神经性水肿→休克 | 停止→抗组胺药/肾上腺素/氢化可的松 |
| **溶血反应**（最严重） | 输血开始后数分钟 | 腰背痛/血红蛋白尿/休克/DIC | 立即停止→补液利尿→碱化尿液 |
| 细菌污染反应 | 输血开始后 | 寒战高热+休克 | 立即停止→抗感染+抗休克 |
| 循环超负荷 | 输血中/后 | 心衰/肺水肿 | 停止→利尿+强心 |

> 过敏反应·特殊处理：**IgA缺乏者→输注IgA缺乏者血液**

**💡 考试角度**

| 🟢 绿皮书 | 非溶血性发热反应机制（白细胞/血小板抗体）；过敏反应（IgE）；自体输血禁忌（消化液/癌细胞污染）；输血并发症全面分类 |
| 🟡 贺银成 | 输血并发症的诊断及处理；自体输血偶尔涉及 |
| 🔵 昭昭 | 失血量题眼：<750ml(<15%)=不输血 / 750-1000ml=酌情 / >1000ml=必须输血 |

---

### 📝 例题印证

**【例1·绿皮书】**
> 输血后的非溶血性发热反应主要为免疫反应，常见于：
> A. 经产妇或多次接受输血者✅　B. 初次输血者　C. 男性患者　D. 老年人　E. 儿童

**解析**：非溶血性发热反应=受血者体内已有**白细胞/血小板抗体**→与输入的白细胞/血小板发生抗原抗体反应→发热。经产妇（胎儿白细胞致敏）+多次输血者→抗体阳性率高→风险大。

**【例2·绿皮书】**
> 输血过敏反应的处理要点不包括：
> A. 停止输注　B. 使用抗组胺药或肾上腺素　C. **继续缓慢输注观察**✅　D. 血管神经性水肿时使用氢化可的松　E. 必要时插管/气管切开保持呼吸通畅

**思路**：过敏反应→**必须停止输注**（C错→正确答案）。轻度荨麻疹→可用抗组胺药；严重→肾上腺素/氢化可的松+气道管理。

## 考点 1.7：肿瘤 【Tier 1·⭐】

### 📖 三源讲解

**🧬 化疗敏感肿瘤**（教师重点）

| 高敏感（可治愈） | 中敏感 | 低敏感 |
|:---|:---|:---|
| 绒毛膜癌 | 急性白血病 | 消化道癌(胃癌/肝癌/胰腺癌) |
| **ALL**(急性淋巴细胞白血病) | 乳腺癌 | 非小细胞肺癌 |
| **淋巴瘤**(霍奇金+非霍奇金) | 小细胞肺癌 | 黑色素瘤 |
| **精原细胞瘤** | 卵巢癌 | 肾癌 |
| 睾丸肿瘤 | 骨肉瘤 | |

> 记忆口诀（昭昭风格）：**"绒毛精淋小ALL"**——绒癌、精原细胞瘤、淋巴瘤、小细胞肺癌、ALL → 化疗首选/化疗敏感

**🔍 常用肿瘤标志物**

| 肿瘤标志物 | 相关肿瘤 | 临床用途 |
|-----------|---------|---------|
| **AFP**（甲胎蛋白） | 原发性肝癌、卵黄囊瘤 | 肝癌筛查+疗效监测；>400μg/L持续升高→高度怀疑肝癌 |
| **CEA**（癌胚抗原） | 结直肠癌、胃癌、胰腺癌、肺癌 | 结直肠癌术后复发监测 |
| **CA19-9** | 胰腺癌、胆管癌 | 胰腺癌辅助诊断+疗效评估 |
| **CA125** | 卵巢癌 | 卵巢癌筛查+复发监测 |
| **CA15-3** | 乳腺癌 | 乳腺癌复发转移监测 |
| **PSA**（前列腺特异性抗原） | 前列腺癌 | 前列腺癌筛查；>10ng/mL→高度可疑 |
| **β-hCG** | 绒癌、睾丸癌 | 诊断+疗效监测 |

**🔍 TNM分期原则**（AJCC/UICC）

| 分类 | 含义 | 分级 |
|------|------|------|
| **T**（原发肿瘤） | 肿瘤大小/侵犯范围 | Tis(原位癌)→T1→T2→T3→T4 |
| **N**（区域淋巴结） | 淋巴结转移情况 | N0(无)→N1→N2→N3 |
| **M**（远处转移） | 有无远处转移 | M0(无) / M1(有) |

**🔍 外科手术原则**
- **根治性手术**：完整切除肿瘤+区域淋巴结清扫+足够安全切缘（R0切除=镜下无残留）
- **姑息性手术**：解除梗阻/出血/穿孔等并发症，改善生活质量但不延长生存
- **诊断性手术**：切取活检（incisional）/切除活检（excisional）
- **减瘤手术**：减少肿瘤负荷以提高放化疗效果（如卵巢癌肿瘤细胞减灭术）

**🔍 动脉瘤破裂后继发病变**：血栓形成、栓塞、假性动脉瘤、AVF（动静脉瘘）形成（教师重点）

**💡 考试角度**

| 🟢 绿皮书 | 肿瘤标志物对应肿瘤类型（常考B型题）；TNM分期基本原则；化疗敏感肿瘤列表 |
| 🟡 贺银成 | 肿瘤标志物的敏感性和特异性（AFP对肝癌/CEA对结直肠癌/PSA对前列腺癌） |
| 🔵 昭昭 | "绒毛精淋小ALL"口诀；肿瘤标志物对应肿瘤的快速记忆 |

**⚠️ 易混淆**

| 标志物 | 主要肿瘤 | 易混淆点 |
|--------|---------|---------|
| AFP | 原发性肝癌 | 活动性肝炎/肝硬化也可轻度↑（通常<400μg/L） |
| CEA | 结直肠癌 | 吸烟者CEA可轻度↑；非肿瘤特异性 |
| CA125 | 卵巢癌 | 子宫内膜异位症/盆腔炎也可↑ |
| PSA | 前列腺癌 | 前列腺增生/前列腺炎也可↑（4-10ng/mL为灰区） |

## T2-1：外科营养支持 【Tier 2·⭐⭐】

### 📖 三源讲解

**🧬 核心概念**

| 概念 | 内容 |
|------|------|
| **EN**（肠内营养） | 经胃肠道提供营养——首选途径（"If the gut works, use it"） |
| **TPN**（全肠外营养） | 经静脉提供全部营养——胃肠道无功能时使用 |
| **再喂养综合征** | 长期营养不良者重新喂养→胰岛素↑→**低磷/低钾/低镁**→心律失常/心衰/呼衰 |

**EN vs TPN**

| 对比 | EN | TPN |
|------|:--:|:--:|
| 适应证 | 胃肠道有吸收功能但不能经口摄食 | 胃肠道完全无功能（肠梗阻/短肠/高流量肠瘘） |
| 途径 | 鼻胃管/鼻肠管/PEG/PEJ | PICC/中心静脉 |
| 并发症 | 腹泻/腹胀/误吸（最严重） | 感染(导管相关)/胆汁淤积/肝功能损害/代谢紊乱 |
| 优越性 | 维持肠屏障功能/防止细菌移位/并发症少/费用低 | — |

**营养评估指标**：
- 体重变化（3月内>10%→重度营养不良）
- BMI <18.5
- 血清白蛋白<35g/L / 前白蛋白<200mg/L
- 氮平衡
- 主观全面评定(SGA)

**💡 考试角度**

| 🟢 绿皮书 | EN适应证（胃肠有吸收功能）；TPN适应证；再喂养综合征（低磷/钾/镁→先纠正电解质）；营养支持应从低剂量开始 |

### 📝 例题印证

**【例1·绿皮书型】**
> 关于肠内营养（EN）与肠外营养（TPN）适应证的选择，正确的是：
> A. 胃肠道有吸收功能时应优先选择TPN　B. 短肠综合征早期应选择EN　C. **胃肠道有吸收功能但不能经口摄食时选择EN**✅　D. 高流量肠瘘应首选EN　E. 肠梗阻患者可经鼻胃管行EN

**解析**：营养支持基本原则——"If the gut works, use it"（胃肠道有功能首选EN）。C正确：EN适应证=胃肠有吸收功能但不能经口摄食。A错（应选EN非TPN）。B错（短肠早期需TPN）。D错（高流量肠瘘需TPN肠道休息）。E错（肠梗阻禁忌EN）。

**【例2·教材改编型】**
> 长期饥饿患者重新给予营养支持后，出现以低磷血症为特征的电解质紊乱，最可能的诊断是：
> A. 倾倒综合征　B. **再喂养综合征**✅　C. 短肠综合征　D. 肠衰竭　E. 吸收不良综合征

**解析**：再喂养综合征——长期营养不良者重新喂养→胰岛素大量分泌→磷/钾/镁向细胞内转移→低磷/低钾/低镁血症。关键预防：营养支持前先纠正电解质，从低热量开始缓慢增加。

## T2-2：烧伤补液公式 【Tier 2·⭐⭐】

### 📖 三源讲解

**🧬 两种主流公式对比**

| 项目 | 国内通用公式 | Parkland公式 |
|------|:----------:|:----------:|
| 晶体 | **1.0** ml × kg × %TBSA | **4** ml × kg × %TBSA（乳酸林格液） |
| 胶体 | **0.5** ml × kg × %TBSA | **0** |
| 水分(5%GS) | **2000ml** | **0** |
| 总液量 | 1.5ml×kg×%+2000ml | 4ml×kg×% |
| 前8h | 总量的 **1/2** | 总量的 **1/2** |
| 后16h | 总量的 **1/2** | 总量的 **1/2** |
| 胶晶比 | 0.5:1 | 无胶体 |

**🔍 补液监测**

| 指标 | 目标值 |
|------|--------|
| 成人尿量 | **30-50ml/h** |
| 儿童尿量 | 1ml/kg/h |
| CVP | 5-12cmH₂O |
| 心率 | <120次/分 |
| 神志 | 安静 |

**🔍 吸入性烧伤识别**（教师重点）
- 火灾现场/密闭空间烧伤
- 面部烧伤、鼻毛烧焦、声音嘶哑、碳沫痰
- **早期气管插管**→头面部严重烧伤→气道水肿→6-12h达高峰

**💡 考试角度**

| 🟢 绿皮书 | 烧伤输液方案（第1个24h/第2个24h公式）；补液速度调整依据=尿量；有休克征象→血容量不足→加快输液 |
| 🟡 贺银成 | 中国九分法+烧伤深度分度详细表格 |
| 🔵 昭昭 | — |

---

### 📝 例题印证

**【例1·计算题】**
> 男性，30岁，体重60kg，火焰烧伤后2小时入院。查体：双下肢（含双足、双小腿、双大腿、臀部）Ⅱ度烧伤，躯干后侧Ⅲ度烧伤。按国内通用公式，伤后第1个24小时的补液总量为：
> A. 3100ml　B. 4250ml　C. 5310ml　D. 6500ml　E. **7310ml**✅

**解析**：烧伤面积=双下肢46%（含臀）+躯干后13%=59%。补液总量=1.5ml×60kg×59%+2000ml(5%GS)=5310+2000=**7310ml**。前8h输入一半≈3655ml。⚠️ I度烧伤不计入补液面积。

**【例2·教材改编型】**
> 烧伤休克期床旁判断输液速度是否适当的**最可靠**指标是：
> A. 血压　B. 脉搏　C. 中心静脉压　D. 神志　E. **尿量**✅

**解析**：尿量反映肾灌注——最可靠的床边指标。成人维持30-50ml/h→补液适当。血压/脉搏/CVP可受多因素干扰。
