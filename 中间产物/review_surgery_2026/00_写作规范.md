# 外科学复习资料写作规范（MedReview v5.1 执行细则）

> 本文档是 8 个并行撰写子 Agent 的**共享规范**。每模块范围见 `01_模块范围与页码映射.md`。
> 素材提取用附带脚本 `extract_sources.py`。

---

## 0. 你的任务与交付

- 角色：**MedReview（主复习资料生成器）Agent 5**。产出不是"考点罗列"，而是"帮助建立临床直觉"的深度复习章节。
- 交付：`中间产物/review_surgery_2026/模块{NN}_{名称}.md`（每个子 Agent 只写自己那一个模块文件）。
- 最终将 8 个模块合并为《外科学》主复习资料，所以**不要**写科目导航/使用指南/疾病谱系总览(D3 科目级)/跨模块概念地图(D5)/最终附录一、二、三——这些由编排者整合。
- 面向对象：大三下临床医学学生，目标：**期末考试 + 考研西综打底**（贺银成讲义为补充）。

## 1. 五维深度体系（D1-D5）

| 维度 | 要求 | 强制程度 |
|------|------|:-------:|
| **D1 第一性原理** | 每个 🔴掌握级考点必须有「🧬 第一性原理」段 | 🔴 强制 |
| **D2 因果链** | 每个疾病组 ≥1 张 ASCII 因果链图（代码块内） | 🔴 强制 |
| **D3 谱系梯度** | 本模块疾病 ≥5 个时做 1 张 ASCII 梯度图（良→危，标转折点） | 🟡 建议 |
| **D4 鉴别决策树** | 症状对应 ≥3 种鉴别时生成 ASCII 决策树，每模块 ≥2 张 | 🟡 高频触发 |
| **D5 跨模块地图** | 不做（编排者负责） | — |

### D1 写法（每 🔴考点）
```
🔴 【掌握级】{考点名称}：{定义句}（教材P##）
💡 为什么重要：{≤1行，考试价值}

🧬 第一性原理：
  {从正常状态→异常状态的逻辑推导，2-5行}
  {≥1个"如果X不出问题，就不会有Y"的逻辑转折}
  {结尾一句话：本质上就是XX}

{机制/原理要点，2-3句}

<details open>
<summary>🔬 展开：{细分知识点}</summary>
{深入机制/鉴别/数据}
</details>

> [!WARNING] 易错陷阱
> {为什么容易错}
```
- D1 段**不允许以纯文本段落结束**——后面必须紧跟 callout 或 `<details open>`。
- 纯分类记忆型考点可标注「💡 本考点为分类记忆型，第一性原理不适用」并给出替代记忆策略。

### D2 写法（每疾病组 ≥1 张）
- 放 ``` 代码块内的 **ASCII** 图（节点 ≤15，箭头标注因果，★=关键临床转折点）。
- 图下方紧跟 `> [!INFO]` 解释图的临床含义（如"此图展示机制链路，具体数据对比见上方表格"）。

### D3 写法（模块级 1 张）
- ASCII 梯度图：最轻→危症，每层标注 `↓ ← 转折点N: {触发条件}`；图后列"关键转折点识别"。

### D4 写法（每模块 ≥2 张）
- ASCII 分支树 + "每一步的判断依据"（第一分支核心区分逻辑、第二分支次级区分逻辑）。

## 2. 模块模板（以「疾病组」为模板单元）

一个模块 = 1 个教学单元（含 2-4 个疾病组）。结构：

```
## 模块N：{模块名}

> [!INFO] 模块信息
> **重点等级**：🔴掌握 X 个 / 🟡熟悉 X 个 / 🟢了解 X 个
> **预计题型**：A1 / A2 / A3 / B1 / X
> **关联模块**：与模块X（前导）、模块Y（后续）
> **谱系位置**：本模块疾病在"外科疾病严重度谱系"中的位置
> **预计阅读**：约 X 分钟

### 🧩 前置知识检查
{2-4条：不掌握会卡住的解剖/生理/病理前提 + 快速答案}

### 🎯 高收益摘要
{本模块最高频的 3-6 个考点一句话点破}

### 📋 结构化笔记
{按疾病组逐组展开，见下}

### 🔄 主动回忆区
{5-10 个填空，答案用《》包裹；含 1-2 个第一性原理问题 + 1 个决策树路径问题}

### ⚠️ 常见陷阱
{≥3 条}

### 💡 记忆口诀
{≥3 条}

### 📌 本章小结

> [!INFO] 本章小结
> - take-home message 1（含因果链核心环节）
> - take-home message 2
> - take-home message 3
> **🧬 本章核心洞察**：{1 句话总结}
```

### 疾病组内部顺序（每组一个小节，如 `### 一、腹股沟疝`）
1. **组引言**（≤3 行：这组解决什么问题 + 本质）
2. **结构化笔记**：🔴🟡🟢 考点，按上面 D1 格式；🟡 熟悉级 4-6 行；🟢 了解级 2-3 行
3. **📊 对比速查**：每疾病组 ≥2 张标准 Markdown 表（诊断标准表/分期分级表/术式选择表/鉴别表四类中选），3-5 列，每格 ≤20 字
4. **🔗 因果链**（ASCII 图 + [!INFO]）
5. **🌳 鉴别决策树**（触发时）
6. **组内记忆点**（可并入口诀库）

> ⚠️ **v5.1 表格保护**：对比表和 D2 因果链是互补关系——表给数据、图给机制。**不可用图替代表**。

## 3. 机械约束（v5.1 · 不可违反）

- 全文 callout 总数 ≥ **4 × 本模块疾病组数**；`<details open>` 总数 ≥ **2 × 疾病组数**（疾病组数见 `01_模块范围与页码映射.md`）
- callout 类型 ≥ **4 种**（WARNING / TIP / INFO / SUCCESS / NOTE 中选 4 种）
- 严禁 `<details>`（不带 open）——必须默认展开
- 禁用 Mermaid（一律 ASCII 图置 ``` 代码块）；禁用其它 HTML 标签；禁用 YAML front matter；禁用任务列表 `- [ ]`
- 核心层单句 ≤60 字；每 3-5 行正文后必须有视觉断点（callout/表格/折叠区/hr）
- 标题层级：模块 = `##`，疾病组 = `###`，考点条目用 **粗体** 而非标题

## 4. 来源与页码纪律（HC-10 / HC-11）

- **教材**：`知识库素材/chunks_metadata/surgery_chunks.jsonl`——《外科学（第10版）》（陈孝平 等主编，人卫），3314 chunks，每 chunk 带 `chapter` / `page_number` / `text` 字段。
  - 页码**只能**取自 chunk 的 `page_number` 字段（真实教材页）；禁止编造、禁止引 TOC 行（chunk 的 chapter 字段以 `....` 结尾 = 目录页，页号不可用于正文）
- **贺银成讲义**（补充）：`chunks_metadata/heyincheng-jy{1,2,3}_chunks.jsonl`（上/中/下册，无页码）——引用时标注（贺银成讲义·X册），**不标页码**
- **习题集**（可选补充）：`chunks_metadata/surgery-exercise_chunks.jsonl`
- 文字可能含 OCR 错字（如"㘥部损伤"=胸部损伤、"脊倀"=脊髓）——以语义判断，不照抄错字
- 数值/诊断标准以教材为准；教材缺失或冲突时用贺银成补充并标注「素材冲突说明」于模块末尾
- 引用格式：正文考点处标（教材P##）；附录贡献块列页码

## 5. 禁止事项

- ❌ 不生成选择题/判断题（主动回忆区填空是复习资料固有形态，允许，答案用《》包裹）
- ❌ 不写流程残留（`📦 复习资料批次 X/Y`、`✅ 批次完成`、`⏭️ 下一批`、`V1-V13 自检报告` 等一律不写入文件）
- ❌ 不做科目导航/使用指南/科目级谱系总览/D5/最终附录
- ❌ 不编造药物剂量、各期数值——提炼自素材，拿不准就引用原文
