## 二、质检维度（新格式专用）

### D1：考点完整性（权重 30%）

逐一对照教师重点文档，确认每个考点是否在手册中有对应「讲解+例题」块。

**呼吸系统检查清单**：总论/COPD/哮喘/肺炎/肺结核/肺癌/肺心病/呼衰 + T2支扩/PTE/胸腔积液/气胸
**循环系统检查清单**：心衰/心律失常/冠心病/高血压/心肌病/瓣膜病/心包炎/心脏骤停+夹层 + T2感染性心内膜炎/继发性高血压/洋地黄专题
**血液系统检查清单**：总论/贫血概述/IDA/AA/MDS/淋巴瘤/白血病/过敏性紫癜/ITP/DIC + T2巨幼贫/溶血/MM/输血

**评分**：遗漏1个Tier1→扣10分；遗漏1个Tier2→扣5分

### D2：例题来源优先级（权重 20%）

验证绿皮书优先原则是否落实：
- 每个 Tier 1 考点至少 ≥1 道绿皮书例题
- 每个 Tier 1 考点至少 ≥1 道贺银成例题
- Tier 2 考点至少 ≥1 道例题（绿皮书或贺银成）

**抽查**：每批随机抽 5 个考点，验证例题来源标注的真实性（通过 RAG 反查确认该题确实存在于标注的页码/来源中）

### D3：数值准确性（权重 20%）

随机抽查 ≥10% 的数值型陈述（百分比/剂量/天数/正常值范围/阈值），与教材原文比对。

**RAG验证命令**：
```bash
python 知识库素材/search_kb.py "<数值所在原文句子>" --subject 内科学 --top 3 --hybrid
```

**不合格标准**：发现1处数值错误→警告；发现2处→该批次标记为BLOCKED

**重点抽查项**：
- FEV1/FVC<70%（COPD诊断）
- PaO2<60/PaCO2>50（呼衰标准）
- LVEF≤40%（HFrEF）
- 血压≥140/90（高血压）
- Hb男<120/女<110（贫血）
- 原始细胞≥20%（急性白血病WHO）

### D4：三源标注完整性（权重 15%）

检查每个「💡 考试角度」表格：
- 🟢 绿皮书栏是否有实质内容（非"暂无"或空）
- 🟡 贺银成栏是否有实质内容
- 🔵 昭昭栏是否至少 30% 考点有内容

**抽查**：每批随机查 5 个考点的三源表格

### D5：格式一致性（权重 10%）

检查结构一致性：
- 每个考点块是否包含「核心概念→机制理解→考试角度→易混淆→例题印证」
- 表格对齐是否正确
- 代码块（dot/mermaid）是否可解析
- 来源标注格式是否统一

### D6：昭昭记忆法覆盖率（权重 5%）

统计有昭昭口诀/题眼的考点占比，目标 ≥30%

## 四、评分与门禁规则

| 总分范围 | gate_decision | 处理方式 |
|----------|:-----------:|----------|
| ≥85% | PASS | 直接签收 |
| 70-84% | PASS_WITH_FIXES | Agent 4 修复 should_fix 项 |
| <70% 或任一D3发现≥2处数值错误 | BLOCKED | 告警用户，需 Agent 2 重新生成 |

## 五、质检执行指引

1. 读取三份 .md 文件全文
2. 逐维度执行检查，填写评分和问题列表
3. 对 D3 数值准确性，执行 ≥10% 的 RAG 交叉验证
4. 汇总评分，给出每个批次的 gate_decision
5. 将 JSON 报告写入 `质检报告/batch024_质检报告.json`
