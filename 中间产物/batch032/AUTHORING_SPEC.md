# batch032 外科学（二）题库 · 出题规范（Agent 2 / MedGen）

> 本文件是被 8 个并行子 Agent 共同遵守的唯一出题契约。违反任一条都将在后续 GATE-A2/质检被 BLOCK。

## 0. 一句话目标
基于《外科学》第10版教材（txt 全本），为「大四上·外科学（二）」8 个模块生成共 300 道结构化选择题，字段口径**严格对齐 archive/最终产物/batch017/ALL_questions_FIXED.json**（中文 bloom_level、difficulty_index 0.3–0.85、5 选项）。

## 1. 输出格式（强制）
- 每个子 Agent 把结果写成**纯 JSON 数组**文件：`中间产物/batch032/moduleN.json`（N=1..8），一行一题。
- 输出后必须能 `json.load()` 解析（禁止 YAML 前置 `---` 块、禁止尾注）。
- 每题对象字段（顺序无关，键名必须完全一致）：

```json
{
  "id": "batch032_M1_A1_001",
  "question_type": "A1",
  "module": "胸部损伤、肺疾病、食管疾病",
  "bloom_level": "记忆",
  "question_text": "题干……",
  "options": ["A. 选项一", "B. 选项二", "C. 选项三", "D. 选项四", "E. 选项五"],
  "correct_answer": "C",
  "explanation": "解析……（引用教材页码）",
  "source_page": "教材P320",
  "source_anchor": "RAG/教材P320",
  "difficulty_index": 0.62,
  "discrimination_index": 0.35
}
```

- `question_type` ∈ {A1, A2, B1, X}
- `bloom_level` ∈ {记忆, 理解, 应用, 分析}（**中文，非英文**）
- `module` 用本 Agent 负责模块的标准名（见 §5）
- `correct_answer`：A1/A2/B1 为单字母（A–E）；X 型为多字母（如 "ABCE"）
- `difficulty_index`：0.30–0.85 之间，5 舍 2 入到两位小数
- `discrimination_index`：0.20–0.50 之间
- `source_page`：`教材P<印刷页>`；`source_anchor`：`RAG/教材P<印刷页>` 或 `重点/教材P<印刷页>`

## 2. 页码铁律（hc-10，违反即返工）
- 教材 txt 每页有锚点 `===== 第 N 页 =====`，其中 N 是 **PDF 页号**。
- **真实印刷页 = PDF 页号 − 39**（已实测：PDF442→印刷403、PDF598→印刷559、PDF798→印刷759、PDF410→印刷371、PDF441→印刷402，五点一致）。
- 出题前**必须真实读取**本模块对应的 txt 内容片段（用 Read 或 grep 到对应 PDF 页段），确认该知识点确实在该页附近，再把 `source_page` 写成印刷页。
- **禁止占位符、禁止凭记忆写页号**。如某知识点跨多页，取首现印刷页。
- 解析里可写「参阅教材 Pxxx」与正文呼应。

## 3. 题型契约
- **A1**（单点最佳答案，无病例）：题干为直述式陈述 + 提问。
- **A2**（病例摘要题）：以「男性/女性，年龄，主诉……」开头，给出体征/检查，问最可能诊断/首选检查/处理。
- **B1**（共用选项题）：`question_text` 形如：
  `B1型题：将正确答案的字母填入题干后方。\n共用选项：\nA. xxx\nB. yyy\nC. zzz\nD. uuu\nE. vvv\n子题1：……：`
  每个子题是**独立一条** JSON 对象（options 重复列出共用选项 5 项，correct_answer 单字母）。一个 B1 组出 2–3 个子题即产生 2–3 条对象。
- **X**（多选题）：5 选项，`correct_answer` 为 2–4 个字母（如 "ABDE"），解析须说明每个入选/排除项。

## 4. 选项设计硬规则（NBME 八项 + HC-14 + 校验 R7/R8/R12/R13）
1. **5 个选项，结构模板一致**：同一题的 5 个选项必须共享相同语法结构（如都是「[部位]+[病变]」、都是「[数字]+[单位]」、都是「[病因]」）。用结构对齐，不靠字数范围（HC-14）。
2. **长度**：单选项 ≤ 20 字（R13 上限）；自然短术语（药名/受体/病名 3–7 字）豁免下限。平均 < 18 字。
3. **禁止截断（R7/R8）**：选项不得以句号结尾的 <8 字残片、不得含「…」「..」、不得以「的/和/与/于」等连接词助词结尾、不得缺单位（CPR/补液/剂量/数值必须带单位）。
4. **禁止无意义后缀（R12）**：不得用「(相关表现)」「(相关类型)」等凑长度；干扰项须含实质性区分信息。
5. **绝对词禁止**：正确项与干扰项都不出现「所有/均/必然/从不/绝对」等绝对化用语（真题原文保留除外，但真题改编时尽量弱化）。
6. **词重复线索（R10）**：题干关键词不得只出现在正确选项；正确项与题干的术语共享数不得显著最高（R11 收敛防护）。
7. **干扰项 plausibility**：4 个错误项须临床 plausible，与正确项属同类概念；数值型干扰项与正确值差距 ≤ 5 倍（HC-6）。
8. **B1 共用选项**：5 个选项须为同一抽象层（都某类疾病/都某类表现），不能笼统到只有一个能选。

## 6. 考研真题引用/改编（HC-18，红线）
- 用到的真题：从 `中间产物/batch032/kaoyan_candidates.json` 取对应索引，保持**题干核心、选项、正确答案字母、所有数值/诊断标准完全不变**（真题答案保护，发现与教材冲突必须升级告警，不得静默改答）。
- 可在原题基础上**轻度改编**（精简冗长题干、补全选项编号、统一表述），但不得改变考点与答案。
- 该题对象须额外加两个字段（与上面 11 个字段并列）：
  - `kaoyan_origin`: `{"gs_id":"GS-XXXX-XXX","year":2023,"source":"2023考研西综·第XX题","mode":"原题"}`
  - 在 `source_anchor` 写 `考研真题/GS-XXXX-XXX`
  - 在 `explanation` 末尾追加一句来源：`[源:考研真题 GS-XXXX-XXX]`
- 无真题候选的模块（如 M1/M4/M5/M6 真题极少）以原创补齐，此类题 `kaoyan_origin` 不填、`source_anchor` 正常写教材页码。
- 全批次真题目标 ≈ 20%（合格带 15%–25%）；本设计合计 59 道（19.7%），已满足。

## 7. 无重复 / 无冲突
- 同一模块内：题干不雷同、不互相包含；同一知识点不重复命题。
- 正确答案在该题内唯一（X 型除外，为多选）。
- 不要与 batch017（外科学一）已覆盖的第一~四篇知识点重复（本批次只做第五~九篇）。
