## 1. 字段 Schema（严格对照 batch027 范本）

每道题必须是如下 JSON 对象，纯 JSON 数组输出（无 YAML 前置块、无 markdown 代码围栏）：

```json
{
  "id": "batch033-M6-A1-001",
  "module": "M6",
  "module_name": "炎症性肠病（IBD）",
  "topic": "溃疡性结肠炎与克罗恩病的鉴别",
  "type": "A1",
  "polarity": "positive",
  "bloom": "记忆",
  "stem": "溃疡性结肠炎最典型的镜下特征是？",
  "options": [
    {"label": "A", "text": "节段性纵行溃疡"},
    {"label": "B", "text": "连续性弥漫性黏膜糜烂与隐窝脓肿"},
    {"label": "C", "text": "干酪样坏死"},
    {"label": "D", "text": "嗜酸性粒细胞浸润"},
    {"label": "E", "text": "肉芽肿形成"}
  ],
  "answer": "B",
  "explanation": "溃疡性结肠炎（UC）为直肠连续性、弥漫性黏膜炎症，特征为隐窝脓肿与浅溃疡；克罗恩病（CD）呈节段性、透壁性、纵行溃疡、非干酪性肉芽肿。教材P390。",

  "option_polarities": {"A": false, "B": true, "C": false, "D": false, "E": false}

```

**字段约束（任一不符 → FAIL）**：
- `id`：`batch033-{模块号}-{题型}-{3位序号}`，如 `batch033-M6-A1-001`（A3/A4 共用题干时子题序号连续）
- `module`：`M1`~`M10`（消化）/ `M1`~`M4`（泌尿）/ `M1`~`M3`（内分泌/风湿/理化）
- `module_name`：见 §4 模块清单原文（一字不差）
- `topic`：本模块内一个具体考点（≤ 20 字）
- `type`：`A1`/`A2`/`A3`/`A4`/`B1`/`X`（无判断题）
- `polarity`：`positive`（选正确项）/ `negative`（选错误/不正确/除外项，题干须含「不/错误/除外/不包括」）/ `multi`（X 型多选）
- `bloom`：`记忆`/`理解`/`应用`/`分析`
- `stem`：题干文本（A3/A4 为病例题干，B1 为共用问题）
- `options`：5 个 `{label, text}` 对象（B1 为 5 个共用选项；X 仍为 5 项，答案可为多字母）
- `answer`：A/B/C/D/E（X 型为 `"AB"`/`"ACE"` 等多字母串）
- `explanation`：含机制/鉴别要点 + **真实印刷页**（如 `教材P390`）
- `source_page`：`教材P{printed}` 单值
- `difficulty`：`基础`/`中等`/`较难`/`困难`（按梯度分布）
- `option_polarities`：`{A:bool,...}` 仅正确项为 `true`

## 2. 题型定义（与现有题库一致）

- **A1**：单句最佳单选题（标准/数值/定义/首选治疗/特征）。
- **A2**：简短病例单点诊断/处理。
- **A3/A4**：共用题干病例组（A3 3 问、A4 4 问，逐步推进：诊断→机制→检查→治疗/预后）。同组题干只写一次，子题 `id` 连续。
- **B1**：共用 5 选项，2~3 个独立小问，每问 `type:B1`，`stem` 为该小问。
- **X**：不定项多选（题干含「正确的有/包括/机制涉及」），`polarity:multi`/`answer` 多字母。

## 3. 选项设计 —— NBME 八项硬约束（HC-14、D17、R1-R13）

1. **禁绝对词**：正确项与干扰项都不用「所有/绝对/必然/一定/从不」等；允许「最常见/主要/典型」。
2. **结构模板（HC-14）**：同一题 5 个选项必须**共享语法结构**（如都是「[部位]+[疾病]」或都是「[数值]+[单位]」或都是「[药物类别]」），靠结构一致而非字数凑齐。
3. **长度比 ≤ 1.5×**：最长/最短选项字符数 ≤ 1.5。
4. **数值排序**：含数值时选项按升/降序排列，正确答案位置随机（禁恒在 C）。
5. **词重复防护（D18）**：题干关键词不应只出现在正确选项（否则泄漏答案）。
6. **收敛策略（D19）**：正确选项的术语不应在 4 个干扰项中显著高频重复。
7. **禁无意义后缀（R12）**：禁止「（相关表现）」「（相关类型）」等凑长度。
8. **视觉突出/语法一致**：选项语法时态一致、无一项明显装饰性加粗。
- **数值干扰项（HC-6）**：与正确值差距 ≤ 5×（如正确 7.0，干扰项 5.5/8.5/4.0/10.0 合理；勿用 100 之类）。
- **答案位置均衡**：各组题正确答案在 A-E 上尽量均匀，避免连续 5 题都选 C。
