## 科目导航：传染病学怎么学？

<b>一句话核心逻辑链</b>：传染病学的一切都可以用「<b>一条传播链 + 三类病原 + 一套防治框架</b>」串起来——<b>传播链</b>=传染源→传播途径→易感人群（三大环节）；<b>三类病原</b>=病毒（肝炎/麻疹/水痘/狂犬病/艾滋病）→细菌（伤寒/菌痢/霍乱）→寄生虫（疟疾/血吸虫）；<b>一套框架</b>=每种病都按<b>病因→流行病学→发病机制→临床表现→诊断→治疗预防</b>六要素展开。临床表现再压成几条<b>综合征主线</b>：发热出疹（麻疹/水痘）、发热+消化道（伤寒/菌痢/霍乱）、发热+肝损（病毒性肝炎）、发热+恐水/痉挛（狂犬病）、发热+免疫缺陷（艾滋病）、周期性寒战高热（疟疾）、疫水接触后发热肝脾大（血吸虫）。抓住「<b>流行病学史定病种 → 热型/体征定诊断 → 六要素定治疗预防</b>」这条链，全科即可打通。

- <b>命题规律</b>：两大量点 = <b>病毒性肝炎（M02）</b>与<b>肠道细菌病鉴别（M05/M06）</b>；其次艾滋病（M04，传播途径与四期）与疟疾（M07，生活史与周期热）。数值类必考：潜伏期、隔离期、传染病报告时限（甲类 2 小时 / 乙丙类 24 小时）、各型病毒性肝炎慢性化率、霍乱脱水分级。鉴别类必考：肝炎五型传播途径、肠道溃疡形态、腹泻性状（侵袭性 vs 分泌性）、热型。
- <b>题型结构</b>：A1（病原/传播/数值/首选处理）、A2/A3（病例：流行病学史+热型+体征 → 诊断，如"东南亚归来+间歇热+脾大 → 疟疾"）、B1（共用选项鉴别：肝炎病毒传播组、肠道溃疡形态组、腹泻粪便性状组、抗疟药组）、X（机制与分类多选：肉芽肿/化脓性炎/免疫缺陷/嗜酸性粒细胞）。
- <b>复习路径</b>：先 M01 搭「三环节 + 六要素 + 报告」框架 → M02 病毒性肝炎（最大考点，投入最多时间，五型对比 + 重型肝炎 + 抗病毒）→ M03 出疹病毒病 + M04 狂犬病/艾滋病（其余病毒组）→ M05/M06 伤寒·菌痢·霍乱（肠道细菌病，鉴别核心）→ M07 疟疾 + M08 日本血吸虫病（寄生虫，生活史驱动）。
- <b>避坑提示</b>：① 潜伏期 / 隔离期 / 报告时限必须逐字背（甲类 2h、乙丙类 24h；麻疹隔离至出疹后 5 天、合并肺炎延长）；② 病例题第一眼抓<b>流行病学史</b>（疫水接触=血吸虫；疫区蚊虫=疟疾；动物咬伤=狂犬病；不洁饮食/水源=伤寒·菌痢·霍乱；输血/注射/母婴=肝炎·艾滋病）；③ <b>热型是鉴别核心</b>（稽留热=伤寒，间歇热=疟疾，弛张热；中毒性菌痢可高热伴休克而肠道症状轻）；④ 病毒性肝炎五型的传播途径与病原学标志物组合必背（甲戊粪-口，乙丙丁血液体液，丁为缺陷病毒需 HBV 辅助）；⑤ <b>霍乱=分泌性腹泻</b>（无里急后重、无脓血、米泔水样便、重度脱水），<b>菌痢=侵袭性腹泻</b>（里急后重 + 黏液脓血便）；⑥ 伤寒禁用大量退热药与激素（防虚脱/肠穿孔），慎用灌肠。

> [!TIP] 本科目高分密码
> 每遇到一个病，都问四句话：<b>传染源与传播途径是什么？→ 潜伏期与隔离期多久？→ 典型热型与关键体征是什么？→ 首选诊断与首选治疗是什么？</b> 再加一句「<b>和它长得像的病怎么鉴别？</b>」——五句话答完，考点基本全覆盖。

## 使用指南

<b>分层阅读策略</b>：
- 🔴 <b>掌握级</b>（逐字精度）：病原与传播途径、潜伏期/隔离期、诊断标准、首选检查与首选治疗、急症与报告时限——考前必背，配合 D1 第一性原理理解。
- 🟡 <b>熟悉级</b>（能复述机制与鉴别）：发病机制、鉴别要点、并发症。
- 🟢 <b>了解级</b>（眼熟即可）：罕见类型、带过章节。

<b>主动回忆法</b>：每模块「🔄 主动回忆区」的填空（答案用《》包裹）先遮住自测再核对；「🌳 D4 决策树」要求自己从主诉口述完整路径。

## 📐 传染病学 疾病谱系总览（D3：从可自限到危及生命）

```
【病毒性疾病】
  麻疹 / 水痘·带状疱疹（多为自限，可疫苗预防，预后好）
    ↓ ← 转折点1: 并发症（麻疹肺炎/脑炎；水痘继发细菌感染）
  病毒性肝炎（急性多自愈；乙丙丁戊可慢性化）
    ↓ ← 转折点2: 慢性化 / 重型化
  慢性肝炎 → 肝硬化 → 肝癌（"三部曲"）；重型肝炎（肝衰竭，危及生命）
  狂犬病（一旦发病，近乎 100% 死亡——暴露后处置是与时间的赛跑）
  艾滋病（CD4 进行性下降 → 机会性感染与肿瘤，终末期致命）

【细菌性疾病】
  细菌性痢疾（急性多可治愈；中毒性菌痢可在肠道症状轻微时休克）
    ↓ ← 转折点1: 侵袭/毒力升级
  中毒性菌痢（休克/脑病，急危）；伤寒（肠出血/肠穿孔，第二三周危险）
    ↓ ← 转折点2: 失控
  霍乱（分泌性腹泻，重度脱水 → 循环衰竭，补液是与死亡赛跑）

【寄生虫病】
  疟疾（周期发作；恶性疟凶险发作脑型可致命；间日疟可复发）
  日本血吸虫病（急性发热；慢性→晚期肝硬化/巨脾腹水/上消化道出血）

【共性防线】控制传染源 → 切断传播途径 → 保护易感人群（疫苗/防护）
```

<b>关键转折点识别</b>：
- 转折点1（自限→复杂）：并发症出现（麻疹肺炎、水痘继发感染、伤寒肠出血、菌痢中毒型）。
- 转折点2（→危及生命/不可逆）：重型肝炎、狂犬病发病、艾滋病终末期、霍乱重度脱水、恶性疟凶险发作、晚期血吸虫肝硬化。
- <b>防治主轴</b>：所有传染病都回到「控制传染源（隔离/报告/治疗）→ 切断传播途径（消毒/灭媒/卫生）→ 保护易感人群（疫苗/免疫球蛋白/防护）」三环节——答题卡壳时，先答这三条。

## 🗺️ 传染病学 跨模块概念地图（D5）

```
                      传染病学 = 传播链 × 病原 × 六要素
                                  │
        ┌─────────────────────────┼─────────────────────────┐
        ↓                         ↓                         ↓
   【传播途径轴线】           【临床综合征轴线】          【防治轴线】
   粪-口(M05伤寒/M06菌痢霍乱)   发热+消化道(M05/M06)      控制传染源：报告+隔离
   血液体液(M02肝炎/M04艾滋病)  发热+肝损(M02)            切断途径：消毒+灭媒
   呼吸道(M03麻疹水痘)          发热+出疹(M03)            保护易感：疫苗+免疫球蛋白
   虫媒蚊(M07疟疾)              周期热+脾大(M07)                 │
   疫水接触(M08血吸虫)          疫水后发热肝脾大(M08)            ↓
   动物咬伤(M04狂犬病)          恐水/痉挛(M04)          ┌───────────────┐
        │                        免疫缺陷(M04)         ↓               ↓
        └──────────────┬──────────────────┘      M02肝炎疫苗     M03麻疹/水痘疫苗
                       ↓                              │               │
              鉴别主线：热型 + 腹泻性状 + 皮疹 + 溃疡形态
              热型：稽留热(M05伤寒)｜间歇热(M07疟疾)｜弛张热
              腹泻：侵袭性脓血便(M06菌痢) vs 分泌性米泔水样(M06霍乱)
              皮疹：麻疹(科氏斑/向心) vs 水痘(向心性"三代同堂")
        └──────────────┬──────────────────────────────┘
                       ↓
        共同教训：一切传染病 = 「传染源—途径—易感者」三环节 +「防-诊-治」闭环
```

<b>关键跨模块链路</b>：
- <b>M05↔M06：肠道细菌病鉴别轴线</b>——同以「发热 + 腹泻」起病：伤寒（稽留热、相对缓脉、玫瑰疹、肠出血/肠穿孔）→ 菌痢（里急后重、黏液脓血便、侵袭性）→ 霍乱（无发热或低热、无里急后重、米泔水样便、分泌性重度脱水）。三病一字排开即 D4 决策树主干。
- <b>M02↔M03↔M04：病毒病轴线</b>——传播途径与出疹/免疫表现分道：肝炎（血液体液+粪-口，肝损）→ 麻疹/水痘（呼吸道，出疹）→ 狂犬病（动物咬伤，神经）→ 艾滋病（性/血液/母婴，免疫缺陷）。同属「病毒 + 疫苗/抗病毒」框架。
- <b>M07↔M08：寄生虫病轴线</b>——均由「媒介/中间宿主」驱动：疟疾（按蚊传播、原虫、周期热）vs 血吸虫（钉螺中间宿主、尾蚴钻皮、疫水接触、肝脾与门脉）。防治共同点=切断媒介/中间宿主环节。
- <b>M01↔全部：报告与预防回环</b>——任何病的后续都回到 M01 的「传染病报告（甲 2h/乙丙 24h）+ 三环节预防 + 隔离期」。
