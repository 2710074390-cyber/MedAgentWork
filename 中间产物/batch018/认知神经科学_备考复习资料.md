## 二、结构化知识笔记

### M1 概论

**认知神经科学的定义**
认知神经科学是研究人类心灵脑机制的科学，揭示神经组织和脑结构怎样通过其生理过程，产生知觉、注意、记忆、语言、思维、情感和意识等精神活动的奥秘。

**三层映射关系**
```
神经组织/脑结构 → 生理过程 → 精神活动（知觉/注意/记忆/语言/思维/情感/意识）
```

---

### M2 神经系统解剖和发育

**脑区层次结构**
```
大脑皮层
├── 额叶：运动、工作记忆、情绪及冲动控制、高级思维及语言
│   ├── 背外侧前额叶
│   ├── 腹外侧前额叶
│   └── 眶额皮质：自我知觉
├── 顶叶：躯体感觉、空间注意与觉知
│   └── 体感小人（手+面部投射最大）
├── 枕叶：视觉信号处理
└── 颞叶：听觉、情绪、记忆、视觉加工、语言理解（左叶）

间脑
├── 丘脑：感觉中继站（嗅觉除外）
├── 下丘脑：内稳态、四驱力、体温、自主神经、生物节律
└── 脑垂体：释放激素、调节内分泌腺

脑干
├── 中脑：视听觉皮层下反射中枢、上下行纤维通路
├── 脑桥：睡眠调控
├── 延髓：呼吸/排泄/吞咽（生命中枢）
└── 网状系统：唤醒皮层、筛查传入信息

小脑：运动平衡、条件反射、技能记忆、知觉、高级认知

边缘系统：杏仁核（情绪评估）+ 海马（记忆）
```

**神经系统发育关键节点**
```
出生 → 3岁（突触数量达成人2倍）→ 14岁（40%被修剪）
```

**可塑性两类场景**
1. 生理损伤后：灵长类皮质重构、人类幻肢现象
2. 训练后：训练导致大脑结构变化

### M3 神经冲动的产生和传导

**动作电位产生过程**
```
刺激 → Na⁺通道开放 → Na⁺内流 → 去极化（达阈电位）
→ 动作电位"全或无"爆发 → K⁺通道开放 → K⁺外流 → 复极化
→ Na⁺-K⁺泵恢复离子梯度
```

**兴奋性 vs 抑制性突触后电位**

| 特征 | EPSP | IPSP |
|------|------|------|
| 离子机制 | Na⁺内流 | Cl⁻内流/K⁺外流 |
| 膜电位变化 | 去极化 | 超极化 |
| 对动作电位影响 | 易化 | 抑制 |
| 递质举例 | 谷氨酸 | GABA/甘氨酸 |

**跳跃式传导**
髓鞘包裹轴突（绝缘）→ 电位只在郎飞结处再生 → 跳跃式传导 → 显著提高传导速度

### M4 认知神经科学研究技术 ⭐

**五大技术对比**

| 维度 | ERP | MEG | fNIRS | fMRI | TMS |
|------|-----|-----|-------|------|-----|
| 时间分辨率 | ★★★ 高 | ★★★ 高 | ★★ 中 | ★ 低 | — |
| 空间分辨率 | ★ 低 | ★★★ 高(毫米) | ★★ 中 | ★★★ 高 | ★ 仅表层 |
| 因果推断 | × | × | × | ✓操纵行为观脑 | ✓直接因果 |

**经典ERP成分**

| 成分 | 含义 | 诱发条件 | 特性 |
|------|------|---------|------|
| MMN | 失匹配负波 | 重复刺激中出现不匹配 | 无需注意，偏差越大MMN越大 |

| N400 | 负波400ms | 语义不匹配/冲突 | 冲突越大N400越大 |

**ERP时程分类**
- 早成分：1~10ms
- 中成分：10~50ms
- 晚成分：>50ms → 反映认知加工

### M5 感知觉 ⭐

**视觉：两类感光细胞**

| 特征 | 视杆细胞 | 视锥细胞 |
|------|---------|---------|
| 光照 | 弱光 | 强光 |
| 视觉类型 | 暗视觉 | 明视觉 |
| 颜色 | 无色 | 有色 |
| 分布 | 周边为主 | 黄斑中心凹集中 |
| 损伤 | 夜盲 | 视敏度下降 |
| 视敏度 | 低 | 高（1.0视力靠锥细胞） |

**色盲类型与机制**
```
红绿色盲 ← 缺少中波+长波感光色素
黄蓝色盲 ← 缺少短波感光色素
全色盲 ← 中枢神经系统受损（非感光细胞缺失）
```

**视觉双通路模型**
```
视神经 ─→ 外侧膝状体 → 初级视皮层（90%，主通路）
    └──→ 枕核/上丘（10%，盲视保留通路）

初级视皮层损伤 → 盲视（主观看不见，行为能定位）

腹侧通路（what）：颞叶方向 → 物体识别
背侧通路（where）：顶叶方向 → 空间知觉
```

**听觉损伤两类**

| 类型 | 部位 | 机制 | 处理方案 |
|------|------|------|---------|
| 传导性失聪 | 中耳 | 声波不能传至耳蜗，耳蜗/听神经正常 | 助听器有效 |
| 神经性失聪 | 内耳 | 耳蜗/毛细胞/听神经受损 | 人工耳蜗 |

摇滚队员→长期过大音量→纤毛不稳定或死亡→神经性失聪

**嗅觉与记忆**
- 嗅皮层直接连接边缘系统
- 气味比视觉刺激更稳定激活边缘系统
- 海马损伤→气味识别严重受损

**五种味觉**：酸、甜、苦、咸、鲜

### M6 意识和注意

**注意分类**
```
随意注意：有目的 + 需意志努力（自上而下）
不随意注意：无目的 + 无需意志努力（自下而上）
```

**选择性注意之争**
```
早期选择（过滤器/衰减模型）← ERP N1(90ms) + MEG M20-50
晚期选择（反应选择模型）
→ 脑电/脑磁证据更支持早期选择
```

**空间线索化范式**
告知箭头方向=目标最可能位置 → 引导有意注意 → 两线差异=有意注意证据

**注意分离实验**
三类线索条件：中性线索 / 位置线索 / 方向线索 → 空间注意和特征注意可分离

### M7 学习与记忆 ⭐

**记忆系统分类**

| 记忆类型 | 保持时间 | 容量 | 注意需求 | 脑区 |
|---------|:--:|:--:|:--:|------|

### M9 情绪 ⭐

**詹姆士-兰格理论证据三角**

| 预测 | 检验方法 | 结果 |
|------|---------|------|
| 不能跑→不会怕 | 脊髓损伤患者 | 情绪体验=正常被试（*质疑理论*）|
| 面部表情→影响主观体验 | 表情操纵 | ✓ 支持 |
| 不能生理唤醒→不会怕 | 阻断唤醒 | ✓ 支持 |

## 四、临床/实验思维路径

### 路径一：视觉障碍定位诊断
```
主诉：视力异常/视野缺损/色觉异常
  ├─ 暗光下视物困难 → 视杆细胞 → 考虑夜盲/维生素A缺乏
  ├─ 强光/颜色辨别困难 → 视锥细胞 → 考虑黄斑病变
  ├─ 红绿色分辨困难 → 中/长波色素缺失 → 红绿色盲
  ├─ 一半视野看不见 → 初级视皮层损伤 → 偏盲
  ├─ 看不见但能定位 → 盲视 → V1损伤+上丘保留
  ├─ 能看见但认不出物体 → 腹侧通路损伤 → 视觉物体失认症
  └─ 能看见但认不出面孔 → 梭状回损伤 → 面孔失认症
```

### 路径二：听力损伤定位诊断
```
主诉：听力下降
  ├─ 助听器有效 + 耳蜗/听神经正常 → 传导性失聪（中耳）
  └─ 助听器无效 + 耳蜗/听神经受损 → 神经性失聪（内耳）
      ├─ 长期噪声暴露史 → 毛细胞损伤性
      └─ 年龄大/药物史 → 老年性/药物性
```

### 路径三：脑区损伤→功能缺损推理
```
额叶损伤 → 运动障碍/工作记忆差/情绪冲动失控/语言障碍
顶叶损伤 → 躯体感觉缺失/空间注意障碍（右顶→半边忽视）
枕叶损伤 → 视觉障碍（偏盲/盲视/皮盲）
颞叶损伤 → 听觉障碍/记忆障碍/面孔失认（右）/语言理解障碍（左）
海马损伤 → 顺行性遗忘（不能形成新记忆）
杏仁核损伤 → 恐惧识别障碍/情绪记忆优势消失
眶额皮质损伤 → 社交失范（行为粗俗/无尴尬感）
```

### 路径四：实验技术选择决策
```
研究目标
├─ 关注认知加工时间进程 → ERP（时间分辨率高）
├─ 关注脑区精确定位 → fMRI（空间分辨率高）

```
