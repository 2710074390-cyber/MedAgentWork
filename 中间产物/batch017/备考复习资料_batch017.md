## 二、结构化知识笔记

### 第一篇 外科学基础

#### 1. 外科感染临床思维链

```
病原菌入侵 → 突破皮肤黏膜屏障 → 局部炎症反应（红肿热痛）
  ├─ 非特异性感染：金葡菌→疖痈/链球菌→丹毒/大肠埃希菌→腹腔感染
  └─ 特异性感染：破伤风梭菌→痉挛毒素/气性坏疽→产气荚膜杆菌
        ├─ 破伤风：痉挛毒素→抑制突触释放抑制性递质→肌紧张痉挛
        │   → 治疗：中和毒素(TAT)+镇静解痉(地西泮)+清创+抗感染
        └─ 气性坏疽：产气荚膜杆菌→分解糖产气→捻发音+恶臭+X线积气
            → 早期诊断=局部表现+涂片G⁺粗大杆菌+X线软组织积气
            → 治疗：彻底清创+大剂量青霉素+高压氧
```

#### 2. 休克螺旋恶化链

```
有效循环血量↓ → 组织灌注不足 → 细胞缺氧 → 无氧代谢→乳酸堆积
  ├─ 微循环代偿期(缺血)：儿茶酚胺↑→微动脉收缩→cap前阻力↑→cap灌注↓
  ├─ 微循环淤血期：酸中毒→cap前括约肌松弛+cap后仍收缩→血液淤滞
  └─ 微循环衰竭期：DIC形成→组织坏死→MODS
       ├─ 肾：最早受损→少尿(<400ml/d)
       └─ 监测：一般(神志/皮温/BP/尿量)+特殊(CVP/PAWP/乳酸)
```

#### 3. 水电解质平衡速查

| 类型 | Na⁺ | 渗透压 | 主要病因 | 治疗原则 |
|------|-----|--------|----------|----------|
| 高渗性缺水 | >150 | >310 | 水摄入不足/丢失过多 | 补水为主(5%GS) |
| 低渗性缺水 | <135 | <280 | 胃肠液丢失后补水未补盐 | 补盐为主(3%NaCl) |
| 等渗性缺水 | 135-150 | 280-310 | 胃肠液急性丢失 | 平衡盐溶液 |

**补钾铁律**：尿量>40ml/h方可补钾（"见尿补钾"）

### 第二篇 麻醉与围手术期处理

#### 4. 麻醉方式选择决策树

```
手术部位与范围
  ├─ 下腹/盆腔/下肢 → 椎管内麻醉（腰麻/硬膜外）
  │     ├─ 禁忌：休克/感染/凝血障碍/颅内高压
  │     └─ 腰麻后：去枕平卧6h→防脑脊液漏→防头痛
  ├─ 全身手术 → 气管插管全麻
  │     ├─ 插管深度：♂22-24cm/♀20-22cm
  │     ├─ 禁忌：喉水肿/喉肿瘤/喉异物
  │     └─ 上呼吸道梗阻最常见原因：舌后坠
  └─ 浅表小手术 → 局麻
        ├─ 酯类：普鲁卡因/丁卡因
        └─ 酰胺类：利多卡因(极量400mg)/布比卡因(150mg)
```

#### 5. 心肺复苏关键数值

| 项目 | 成人标准 |
|------|----------|
| 按压:呼吸(双人) | 30:2 |
| 打开气道 | 仰头抬颏法 |
| 心室细颤→电击前 | 给肾上腺素（细颤→粗颤） |
| 心搏骤停判断 | 意识丧失+大动脉搏动消失+呼吸停止 |
| 脑复苏关键 | 脑灌注压+亚低温+脱水+激素 |

### 第三篇 神经外科疾病

#### 6. 颅内压增高→脑疝演变链

```
颅内占位/水肿/脑积水 → 颅内容积↑ → ICP>200mmH₂O
  ├─ 代偿期：脑脊液转移+脑血流调节
  ├─ 失代偿期：三大主症(头痛/呕吐/视乳头水肿)
  │     ├─ 急性ICP↑：Cushing反应(BP↑+HR↓+R慢)
  │     └─ 颅腔压力不均衡 → 脑疝形成
  └─ 脑疝：意识障碍+瞳孔不等大+对侧偏瘫
        → 紧急脱水(甘露醇)+手术减压
```

#### 7. 颅脑损伤影像鉴别

| 血肿类型 | CT特征 | 好发部位 | 跨越颅缝 |
|----------|--------|----------|:---:|
| 硬膜外血肿 | 梭形/双凸镜 | 颞部(脑膜中动脉) | 否 |
| 硬膜下血肿 | 新月形 | 广泛 | 是 |
| 脑内血肿 | 脑实质内高密度 | 额叶/颞叶 | — |

### 第四篇 颈部与乳腺外科疾病

#### 8. 甲状腺术后呼吸困难鉴别

```
术后呼吸困难→紧急床旁拆线探查
  ├─ 切口出血→颈部肿胀+引流血多→清创止血
  ├─ 喉头水肿→喘鸣+雾化/激素有效→激素+吸氧
  ├─ 气管塌陷→气管软化病史→气管插管/切开
  └─ 双侧喉返神经损伤→声带内收→紧急气管切开
```

#### 9. 乳腺癌体征机制串联

```
外上象限好发 → 无痛质硬肿块
  ├─ Cooper韧带受侵 → "酒窝征"
  ├─ 淋巴管堵塞 → "橘皮样"改变
  ├─ 淋巴转移 → 腋窝淋巴结(先)/锁骨上/内乳
  └─ 血运转移顺序：肺→骨→肝→脑
```

## 四、临床思维路径

### 路径1：外科感染患者评估

```
主诉：局部红肿热痛/发热
  ↓
【评估感染性质】
  ├─ 非特异性 → 明确致病菌→抗生素选择
  └─ 特异性 → 临床表现鉴别
       ├─ 破伤风：外伤史+肌痉挛→TAT+镇静+清创
       └─ 气性坏疽：伤口捻发音+恶臭→立即清创+青霉素+高压氧
  ↓
【判断病程】
  急性(<3周) / 亚急性(3周-2月) / 慢性(>2月)
  ↓
【制定治疗】
  清创引流 + 抗生素 + 全身支持
```

### 路径2：休克患者快速评估

```
意识改变+皮肤湿冷/花斑+尿量减少
  ↓
【ABC评估】气道→呼吸→循环
  ↓
【休克类型判断】
  ├─ 低血容量：出血/脱水→补液+止血
  ├─ 心源性：心衰/心梗→强心+利尿
  ├─ 分布性：感染/过敏→抗感染+血管活性药
  └─ 梗阻性：心包填塞/肺栓塞→解除梗阻
  ↓
【监测分层】
  一般监测(神志/皮温/BP/HR/尿量)
  → 特殊监测(CVP/PAWP/乳酸/SvO2)
  ↓
【治疗】病因治疗 + 容量复苏 + 血管活性药 + 器官保护
```

### 路径3：颅脑损伤急诊处理

```
外伤史+意识障碍/头痛呕吐
  ↓
【初次评估】GCS评分/瞳孔/生命体征
  ├─ GCS≤8 → 重型→立即气管插管
  └─ 颅底骨折征象(熊猫眼/Battle征/耳鼻漏)
  ↓
【CT检查—鉴别血肿类型】
  ├─ 梭形→硬膜外→脑膜中动脉→手术指征明确
  ├─ 新月形→硬膜下→桥静脉→手术/保守
  └─ 脑实质内→脑内血肿→迟发可能→复查CT
  ↓
【治疗】降颅压(甘露醇)+手术清除血肿+防治并发症
```

### 路径4：甲状腺结节诊疗决策

```
颈前肿块
  ↓
【病史+体检】质地/活动度/压迫症状/声音嘶哑
  ↓
【辅助检查】超声(首选)+ TSH + 穿刺(FNA)
  ↓
【决策分支】
  ├─ 良性+无症状 → 观察随访
  ├─ 良性+压迫症状/胸骨后/可疑恶变 → 手术
  ├─ 甲亢+内科治疗无效 → 手术
  └─ 恶性 → 甲状腺癌根治术+淋巴结清扫
  ↓
【术后注意】出血/喉返神经/甲状旁腺低钙
```
