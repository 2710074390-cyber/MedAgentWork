## M06 创伤急救与多发伤

> 权重 14% ｜ 题型 案例 + 多选 ｜ 卡片 7 张 ｜ 谱系位置：创伤→失血→休克→MODS 的起点
> 三个题眼：①ABCDE 的顺序 ②三种胸伤的处置差异 ③现场禁忌
> 阅读时长：22 分钟（卡片 14 分钟 + 图表 5 分钟 + 自测 3 分钟）

### 🧩 前置知识检查

1. 为什么创伤急救的第一个字母不是「呼吸」而是「气道+颈椎」？
2. 连枷胸为什么会出现「反常呼吸」？
3. 开放性气胸与张力性气胸，谁先封闭、谁先穿刺？
4. 骨盆骨折为什么容易大出血？


### 🎯 30 秒摘要

- 多发伤：一个因素，≥2 个部位，三个死亡高峰。
- ABCDE：气道颈椎、呼吸、循环止血、意识、暴露。
- 连枷胸：浮动胸壁+反常呼吸，先固定。
- 开放气胸：先封闭；张力气胸：先穿刺。
- 骨盆骨折：骨盆带+平托，防大出血。

### 📋 考点卡群

#### 🔴 K-M06-001｜多发伤的概念与死亡高峰（教师重点第39条｜P255）

📌 重点原文（第39条）：多发伤：同一致伤因素造成 2 个及以上解剖部位严重损伤；伤情重、变化快，有三个死亡高峰（伤后数分钟内、伤后 1 小时内、伤后数天）（P255）

<b>🎯 一句话题眼</b>：一个因素、两个部位、三个高峰——多发伤的三句话。

<b>🧬 为什么</b>：多发伤不是各部位损伤的简单相加，而是“加重效应”：出血、缺氧、炎症反应叠加，迅速导致生理功能失衡。三个死亡高峰分别对应即时死亡（大血管/脑干）、早期死亡（大出血/张力性气胸/心脏压塞）、后期死亡（感染/MODS）。急救窗口在第二个高峰，因此流程围绕“1 小时内找到并处理致命伤”。 临床上最典型的漏诊是「只盯一处明显伤」：颅脑伤病人可能同时有腹腔内出血，ABCDE 的意义就是全身扫一遍。

<b>🔗 机制链</b>：致伤 → 多部位损伤 → 出血/缺氧/炎症叠加 → 生理失衡 → 数分钟（当场）/1 小时（早期可救）/数天（感染、MODS）三个高峰。

<b>⚖️ 鉴别</b>：多发伤 vs 复合伤：多发伤是同一因素造成≥2 个解剖部位损伤；复合伤是两种以上致伤因素（如烧伤＋骨折、放射＋创伤）同时作用。

<b>💡 记忆钩子</b>：一因素、两部位、三高峰（数分钟/1 小时/数天）。

<b>🚨 红线</b>：第一小时是“黄金小时”，必须先处理致命伤；不要为追求完整诊断而延误转运。

<b>🩺 下一步</b>：按 ABCDE 初级评估→控制出血/减压/固定→快速转运至有手术条件的医院。

<b>🔄 自测</b>：①多发伤的定义？②三个死亡高峰的时间与原因？③多发伤与复合伤的区别？

#### 🔴 K-M06-002｜创伤初级评估 ABCDE（教师重点第40、41条｜P256-257、P307）

📌 重点原文（第40条）：创伤初级评估 ABCDE 顺序和处理原则：A 气道与颈椎保护、B 呼吸与通气、C 循环与止血、D 意识（GCS）、E 暴露与保温；先救命后治伤，致命性外出血优先控制（P256-257、P307）

📌 重点原文（第41条）：重点创伤疾病：连枷胸、开放性气胸、张力性气胸、骨盆骨折等可在短时间内危及生命，属优先处理的致命伤（P255-257）

<b>🎯 一句话题眼</b>：ABCDE＝气道颈椎、呼吸、循环止血、意识、暴露保温；大出血在 A 之前先压住。

<b>🧬 为什么</b>：创伤死亡按“气道—呼吸—循环—脑”的顺序发生，评估必须按同样顺序，否则会在处理次要伤时错过致命伤；颈椎保护贯穿 A，因为搬运或开放气道时的二次脊髓损伤可致终身残疾。E 暴露后保温，是防止低体温加重凝血障碍与酸中毒（致死三联征）。 最容易忽略的是「E 暴露后的保温」：低体温会加重凝血障碍与酸中毒，与休克、酸中毒构成致死三联征。

<b>🔗 机制链</b>：A 气道/颈椎 → B 呼吸/通气 → C 循环/止血 → D 意识（GCS）→ E 暴露/保温 → 次级评估（从头到脚＋影像）→ 转运。

<b>⚖️ 鉴别</b>：初级评估（ABCDE，找致命伤）vs 次级评估（系统查体＋影像）；不要在一次评估里做完整查体，否则会漏掉正在恶化的致命伤。

<b>💡 记忆钩子</b>：ABCDE：气道颈椎-呼吸-循环止血-意识-暴露保温。

<b>🚨 红线</b>：致命性外出血先控制再进 A；怀疑颈椎损伤用双手托颌、颈托；E 暴露后必须保温，防低体温加重凝血障碍。

<b>🩺 下一步</b>：A 开放气道/颈椎固定→B 通气/胸腔减压→C 止血/建立通道/限制性液体复苏→D GCS→E 暴露查体＋保温→转运。

<b>🔄 自测</b>：①ABCDE 各代表什么？②致命性外出血应在哪一步之前处理？③为什么 E 之后要保温？

#### 🔴 K-M06-003｜连枷胸（教师重点第42条｜P257）

📌 重点原文（第42条）：连枷胸：多根多处肋骨骨折致胸壁浮动、反常呼吸；处理包括固定浮动胸壁、镇痛、保持气道通畅，必要时机械通气（P257）

<b>🎯 一句话题眼</b>：多根多处肋骨骨折 + 反常呼吸 = 连枷胸，先固定+镇痛。

<b>🧬 为什么</b>：相邻多根多处肋骨骨折后，该段胸壁失去骨性支撑，吸气时胸腔负压反而使浮动胸壁内陷，呼气时外凸，形成反常呼吸，导致通气效率下降、肺挫伤加重。固定浮动胸壁、镇痛、保持气道通畅，是为了减少反常运动和呼吸功。 临床上最常见的错误是「用胶布环形固定整个胸廓」：这会限制通气，反而加重低氧。

<b>🔗 机制链</b>：多根多处肋骨骨折 → 胸壁失去支撑 → 吸气内陷/呼气外凸 → 反常呼吸 → 通气效率↓、肺挫伤 → 低氧。

<b>⚖️ 鉴别</b>：与单纯肋骨骨折鉴别：后者无浮动胸壁、无反常呼吸；与开放性气胸鉴别：后者有胸壁伤口、随呼吸进出气体。

<b>💡 记忆钩子</b>：连枷胸＝浮动胸壁＋反常呼吸，先固定镇痛。

<b>🚨 红线</b>：连枷胸伴呼吸窘迫应尽早气管插管＋机械通气（内固定）；不要用胶布环形固定整个胸廓（限制通气）；镇痛要充分。

<b>🩺 下一步</b>：固定浮动胸壁（敷料/胸带局部）→镇痛→氧疗/无创通气→必要时插管机械通气→处理合并血气胸。

<b>🔄 自测</b>：①连枷胸的病理基础与体征？②为什么会出现反常呼吸？③连枷胸的呼吸支持时机？

#### 🔴 K-M06-004｜开放性气胸（教师重点第43条｜P257、P282）

📌 重点原文（第43条）：开放性气胸：立即用 5～6 层凡士林油纱布封闭伤口，外用无菌敷料严密包扎，使开放性伤口变为闭合性，再行胸腔闭式引流（P257、P282）

<b>🎯 一句话题眼</b>：胸壁有伤口+随呼吸进出气 → 先封闭（凡士林纱布），再引流。

<b>🧬 为什么</b>：胸壁伤口使胸膜腔与大气相通，患侧肺塌陷，且吸气时空气经伤口进入、呼气时排出，形成吸吮性伤口；封闭后胸膜腔恢复负压，肺才能复张。必须先封闭再搬运/穿刺，否则每一次呼吸都在加重塌陷。 最危险的是「先做闭式引流、后封闭伤口」：伤口未闭，负压无法建立，肺也复张不了。

<b>🔗 机制链</b>：胸壁伤口 → 胸膜腔与大气相通 → 患侧肺塌陷 → 吸吮性伤口 → 通气/血流比例失调 → 低氧 → 封闭伤口 → 闭式引流。

<b>⚖️ 鉴别</b>：开放性气胸 vs 张力性气胸：前者有开放伤口、可闻吸吮声；后者无伤口或伤口已闭，表现为进行性呼吸困难、气管偏移、皮下气肿。

<b>💡 记忆钩子</b>：开放气胸先封闭（5～6 层凡士林），再引流。

<b>🚨 红线</b>：必须先封闭伤口再搬运/穿刺；封闭敷料要够大、固定牢；到达医院后尽快闭式引流，不要长期只贴敷料。

<b>🩺 下一步</b>：呼气末封闭伤口（凡士林纱布＋无菌敷料）→半卧位→胸腔闭式引流→抗休克/镇痛/抗生素。

<b>🔄 自测</b>：①开放性气胸的现场第一步？②用什么材料封闭？③封闭后下一步是什么？

#### 🔴 K-M06-005｜张力性气胸（教师重点第44条｜P257、P282）

📌 重点原文（第44条）：张力性气胸：立即用 9～16 号针头在锁骨中线第 2 肋间或腋中线第 4、5 肋间穿刺排气，并给予高流量吸氧（P257、P282）

<b>🎯 一句话题眼</b>：进行性呼吸困难+气管偏移+皮下气肿 → 张力性气胸，立即粗针穿刺。

<b>🧬 为什么</b>：胸膜腔破口形成单向活瓣，气体只进不出，胸膜腔内压持续升高，压迫患侧肺并推移纵隔，同时压迫腔静脉，回心血量骤降，可在数分钟内致循环衰竭。因此必须“先穿刺、后拍片”，任何影像检查都不能排在减压之前。 临床上最忌讳「等床旁胸片」：张力性气胸是临床诊断，穿刺减压不需要影像确认。

<b>🔗 机制链</b>：胸膜腔单向活瓣 → 气体只进不出 → 胸膜腔内压↑ → 患侧肺塌陷、纵隔移位 → 腔静脉回流受阻 → 心输出量↓ → 休克。

<b>⚖️ 鉴别</b>：与开放性气胸鉴别：后者有开放伤口；与心脏压塞鉴别：后者颈静脉怒张、心音遥远、血压下降（Beck 三联征），无气管偏移与皮下气肿。

<b>💡 记忆钩子</b>：张力性气胸：9～16 号粗针，锁骨中线第 2 肋间/腋中线 4、5 肋间。

<b>🚨 红线</b>：张力性气胸是“先穿刺、后拍片”的急症；穿刺后接单向活瓣/闭式引流；正压通气可加重，插管前先减压。

<b>🩺 下一步</b>：粗针穿刺（锁骨中线第 2 肋间/腋中线第 4、5 肋间）→高流量吸氧→胸腔闭式引流→抗休克→必要时手术。

<b>🔄 自测</b>：①张力性气胸的穿刺位置？②为什么不能等胸片？③与心脏压塞如何鉴别？

#### 🟡 K-M06-006｜骨盆骨折（教师重点第45条｜P255、P284）

📌 重点原文（第45条）：骨盆骨折：复杂性骨盆骨折或伴休克属危重；搬运取仰卧、双下肢髋膝关节半屈、膝下垫软物，用骨盆带固定，多人平托（P255、P284）

<b>🎯 一句话题眼</b>：骨盆骨折=隐性大出血，先固定骨盆、平托搬运。

<b>🧬 为什么</b>：骨盆环由松质骨与丰富静脉丛构成，骨折后可短时间内大量出血至腹膜后间隙，形成休克；不稳定的骨盆环在搬动时还会继续出血、加重疼痛。固定骨盆带、多人平托，是为了缩小骨盆容积、减少出血与二次损伤。 最容易忽略的是「骨盆挤压试验反复做」：每次挤压都可能让骨折端再出血，查一次就够。

<b>🔗 机制链</b>：骨盆骨折 → 腹膜后静脉丛/松质骨出血 → 有效循环血量↓ → 休克；搬动 → 骨折端活动 → 继续出血。

<b>⚖️ 鉴别</b>：与股骨骨折鉴别：后者有肢体畸形、肿胀、骨擦感，出血量较少；骨盆骨折常无明确畸形，仅表现为骨盆挤压痛、会阴瘀斑。

<b>💡 记忆钩子</b>：骨盆骨折＝隐性大出血；仰卧屈膝、骨盆带、多人平托。

<b>🚨 红线</b>：不要反复挤压骨盆做检查；不要随意翻动；先固定骨盆带再搬运；合并尿道损伤时禁止盲目导尿。

<b>🩺 下一步</b>：骨盆带固定→多人平托搬运→建立两条静脉通道、限制性液体复苏→输血/止血→血管造影栓塞或外固定。

<b>🔄 自测</b>：①为什么骨盆骨折容易休克？②搬运体位与固定方法？③合并尿道损伤的处理禁忌？

#### 🔴 K-M06-007｜现场禁忌操作（教师重点第46条｜P282、P284、P317）

📌 重点原文（第46条）：现场禁忌操作：外露骨折端不回纳、畸形肢体不复位；脊柱骨折严禁一人抬胸一人抬腿的拉车式搬运；严禁用电线、铁丝、绳索代替止血带；腹部内脏脱出不要还纳（P282、P284、P317）

<b>🎯 一句话题眼</b>：现场四不——不回纳、不复位、不拉车、不用电线。

<b>🧬 为什么</b>：外露骨折端与脱出内脏已被污染，回纳会把污染带入深部；现场复位缺乏影像与无菌条件，易加重血管神经损伤；拉车式搬运使脊柱屈曲扭转，可致截瘫；电线/铁丝无弹性、接触面小，易切割组织。四条禁忌的共同逻辑是“避免把可救的伤变成不可救”。 临床上最常见的错误是「现场复位畸形肢体」：没有影像与无菌条件，复位可能加重血管神经损伤。

<b>🔗 机制链</b>：现场 → 外露骨折端（覆盖固定）/内脏脱出（覆盖保护）/脊柱骨折（平托）/大出血（制式止血带）→ 转运。

<b>⚖️ 鉴别</b>：正确做法—骨折端用无菌敷料覆盖、畸形按原位固定；脊柱骨折三人/四人平托；止血带用制式旋压式；内脏脱出用湿无菌敷料覆盖。

<b>💡 记忆钩子</b>：现场四不：不回纳、不复位、不拉车、不用电线。

<b>🚨 红线</b>：这四条是考场高频“错误做法”选项，看到即选错；每一条都对应一个可致残或致死的后果。

<b>🩺 下一步</b>：覆盖伤口→固定→平托搬运→制式止血带→快速转运。

<b>🔄 自测</b>：①为什么外露骨折端不能回纳？②脊柱骨折的正确搬运方法？③腹部内脏脱出的现场处理？
