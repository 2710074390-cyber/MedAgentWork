### 🎯 30 秒摘要

- 上消化道大出血：>800ml（教师）/ >1000ml（教材）。
- 胰腺炎：Grey-Turner、Cullen 征，血钙<2.0。
- DKA：血糖≥11.1、pH<7.3、酮体阳性。
- HHS：血糖≥33.3、渗透压≥320、昏迷。
- 卒中溶栓：3～4.5 小时，血压<180/110。

### 📋 考点卡群

#### 🔴 K-M08-001｜上消化道大出血（教师重点第55条｜P116-122）

📌 重点原文（第55条）：上消化道大出血：出血量>800ml（教师口径）；教材口径为超过 1000ml 或血容量减少 20% 以上可危及生命；最常见病因是消化性溃疡、食管胃底静脉曲张、急性胃黏膜病变和胃癌；高危征象者应在 12 小时内急诊内镜（P116-122）

<b>🎯 一句话题眼</b>：呕血/黑便 + 休克 → 上消化道大出血；病因首位是消化性溃疡。

<b>🧬 为什么</b>：上消化道出血速度快、量较大时，胃内血液刺激引起呕血，部分血液经肠道分解形成黑便；当失血量超过血容量 20%，代偿失败出现休克。教师口径>800ml、教材>1000ml 或血容量减少 20%，两个口径都要记。高危者 12 小时内镜，是因为早期内镜可明确出血点并止血，降低再出血与死亡。 临床上最典型的误判是「黑便就当成下消化道出血」：黑便多为上消化道，暗红血便才更偏下消化道。

<b>🔗 机制链</b>：溃疡/静脉曲张/急性胃黏膜病变/胃癌 → 出血 → 呕血/黑便 → 失血 → 代偿（心率↑、血管收缩）→ 失代偿（血压↓、休克）。

<b>⚖️ 鉴别</b>：与咯血鉴别：咯血鲜红、泡沫状、碱性、伴痰、先有咳嗽；呕血暗红/咖啡色、酸性、伴食物残渣、先有恶心。与下消化道出血鉴别：便血为主、呕血少见。

<b>💡 记忆钩子</b>：上消化道大出血：教师 800ml、教材 1000ml；溃疡首位；12 小时内镜。

<b>🚨 红线</b>：血流动力学不稳定先复苏再内镜；肝硬化静脉曲张出血急性期用生长抑素/特利加压素＋抗生素；三腔二囊管仅作临时压迫。

<b>🩺 下一步</b>：两条静脉通道、输血（Hb<70g/L）→PPI/生长抑素→12～24 小时内急诊内镜→内镜止血失败介入/手术。

#### 🟡 K-M08-002｜急性胰腺炎（教师重点第56条｜P101）

📌 重点原文（第56条）：急性胰腺炎：胰腺消化酶被激活后对胰腺自身及周围脏器产生消化作用；重症出现腹膜炎体征、休克、腰部皮肤青紫（Grey-Turner 征）、脐部青紫（Cullen 征）；血钙<2.0mmol/L、血糖>11.1mmol/L 提示重症（P101）

<b>🎯 一句话题眼</b>：饱食/酗酒后剧烈上腹痛 + 淀粉酶↑ → 胰腺炎；Grey-Turner/Cullen 提示重症。

<b>🧬 为什么</b>：胰酶在腺体内被提前激活，自身消化胰腺及周围脂肪组织，产生炎症介质；重症时腹膜后出血沿筋膜间隙渗透至腰胁与脐周，形成 Grey-Turner 征与 Cullen 征。血钙<2.0mmol/L（脂肪皂化消耗钙）、血糖>11.1mmol/L 提示重症。 最容易忽略的是「胰腺炎早期血钙正常」：低钙出现在重症后期，不能凭一次正常血钙排除重症。

<b>🔗 机制链</b>：胆石/酒精/高脂 → 胰酶提前激活 → 自身消化 → 炎症介质 → 腹膜后渗出/坏死 → 低钙、高糖、休克。

<b>⚖️ 鉴别</b>：与消化性溃疡穿孔鉴别：后者突发刀割样痛、板状腹、肝浊音界消失、膈下游离气体；与急性胆囊炎鉴别：右上腹痛、墨菲征阳性、超声见胆囊壁增厚。

<b>💡 记忆钩子</b>：胰腺炎：饱食酗酒＋上腹痛放射＋淀粉酶↑；重症低钙<2.0、高糖>11.1。

<b>🚨 红线</b>：重症胰腺炎早期大量补液需监测，避免肺水肿；镇痛禁用吗啡（可致 Oddi 括约肌痉挛）；胆源性胰腺炎合并胆管炎需急诊 ERCP。

<b>🩺 下一步</b>：禁食、胃肠减压→补液、纠正电解质→抑制胰酶分泌（生长抑素）→镇痛→抗感染（选择性）→重症监护。

#### 🔴 K-M08-003｜糖尿病酮症酸中毒 DKA（教师重点第57条｜P36-38）

📌 重点原文（第57条）：糖尿病酮症酸中毒 DKA：胰岛素缺乏、升糖激素增多致高血糖、高血酮、酮尿、脱水、电解质紊乱、代谢性酸中毒；重度 DKA 血清 HCO3-<5mmol/L 或伴意识障碍；治疗为补液+小剂量胰岛素+纠正电解质（P36-38）

<b>🎯 一句话题眼</b>：高血糖 + 酮体 + 酸中毒 + 脱水 → DKA；治疗「先补液、再胰岛素、补钾」。

<b>🧬 为什么</b>：胰岛素绝对或相对不足，脂肪分解增强，游离脂肪酸氧化生成酮体，形成酮症酸中毒；高血糖致渗透性利尿，脱水后肾灌注下降、酸排泄障碍，形成恶性循环。治疗必须补液、小剂量胰岛素、纠正电解质三管齐下，血钾<3.5mmol/L 时补钾先于胰岛素。 临床上最常见的错误是「先推胰岛素、后补钾」：血钾<3.5mmol/L 时先补钾，否则可诱发致命性心律失常。

<b>🔗 机制链</b>：胰岛素不足 → 脂肪分解 → 酮体↑ → 酸中毒 → 渗透性利尿 → 脱水 → 肾灌注↓ → 酸排泄↓ → 恶性循环。

<b>⚖️ 鉴别</b>：与 HHS 鉴别：DKA 血糖≥11.1mmol/L、pH<7.3、HCO3-<18、尿酮阳性、渗透压不定；HHS 血糖≥33.3mmol/L、pH≥7.3、HCO3-≥18、尿酮阴性/弱阳性、渗透压≥320。

<b>💡 记忆钩子</b>：DKA：高糖＋酮体＋酸中毒＋脱水；补液→小剂量胰岛素→补钾。

<b>🚨 红线</b>：补钾先于胰岛素（血钾<3.5mmol/L 先补钾）；血糖下降速度每小时 3.9～6.1mmol/L；补碱仅在 pH<7.0 时考虑。

<b>🩺 下一步</b>：补液（生理盐水）→小剂量胰岛素静脉泵入→监测血钾/血糖/血气→找诱因（感染、停药）→防治脑水肿。

#### 🟡 K-M08-004｜高渗高血糖综合征 HHS（教师重点第58条｜P39-40）

📌 重点原文（第58条）：高渗高血糖综合征 HHS：血糖≥33.3mmol/L、有效血浆渗透压≥320mOsm/(kg·H2O)、尿酮阴性或弱阳性、神志木僵或昏迷；治疗以积极补液为主，HHS 所致癫痫禁用苯妥英钠（P39-40）

<b>🎯 一句话题眼</b>：老年 + 极度高血糖 + 高渗透压 + 昏迷 + 无明显酮症 → HHS。

<b>🧬 为什么</b>：相对胰岛素不足足以抑制酮体生成，却不能抑制高血糖；严重高血糖导致渗透性利尿与细胞内脱水，脑细胞脱水引起意识障碍与抽搐。HHS 所致癫痫禁用苯妥英钠（抑制内源性胰岛素释放），补液速度需考虑心功能。 最容易漏诊的是「HHS 病人抽搐按癫痫治」：苯妥英钠抑制胰岛素释放，会加重高血糖。

<b>🔗 机制链</b>：相对胰岛素不足 → 高血糖 → 渗透性利尿 → 细胞内脱水 → 脑细胞脱水 → 昏迷/抽搐。

<b>⚖️ 鉴别</b>：与 DKA 鉴别见上表；与低血糖昏迷鉴别：后者血糖低、出汗、心悸、补糖迅速清醒；与卒中鉴别：后者局灶体征、CT 有病灶。

<b>💡 记忆钩子</b>：HHS：老年、血糖≥33.3、渗透压≥320、无酮、昏迷；癫痫禁苯妥英钠。

<b>🚨 红线</b>：HHS 癫痫禁用苯妥英钠；补液速度需考虑心功能；渗透压下降过快可致脑水肿。

<b>🩺 下一步</b>：积极补液（生理盐水，按心功能调整）→小剂量胰岛素→补钾→查找诱因→抗凝预防血栓。

#### 🔴 K-M08-005｜低血糖（教师重点第59条｜P34-36）

📌 重点原文（第59条）：低血糖：非糖尿病者血糖<2.8mmol/L、糖尿病者<3.9mmol/L；具 Whipple 三联征；先有自主神经症状、继而中枢神经症状，严重者昏迷；昏迷者静脉补糖，血糖恢复后 30 分钟神志仍未清醒提示脑水肿（P34-36）

<b>🎯 一句话题眼</b>：出汗+心悸+意识改变 → 先测血糖；<2.8（糖尿病<3.9）即低血糖。

<b>🧬 为什么</b>：脑几乎完全依赖葡萄糖供能，血糖过低时先是交感-肾上腺髓质兴奋（心悸、出汗、震颤），随后大脑皮层与网状结构受抑（意识模糊、抽搐、昏迷）。非糖尿病<2.8mmol/L、糖尿病<3.9mmol/L 是诊断阈值；补糖后 30 分钟未清醒提示脑水肿。 临床上最危险的是「昏迷病人喂糖水」：误吸风险极高，昏迷一律静脉补糖。

<b>🔗 机制链</b>：血糖↓ → 交感兴奋 → 心悸出汗震颤 → 脑葡萄糖供应不足 → 意识模糊/抽搐/昏迷 → 补糖 → 清醒。

<b>⚖️ 鉴别</b>：与脑血管病鉴别：后者有局灶体征、血糖正常、CT/MRI 有病灶；与癫痫鉴别：后者脑电图异常、血糖正常；与酒精中毒鉴别：后者有饮酒史、血糖可低。

<b>💡 记忆钩子</b>：低血糖：2.8/3.9；Whipple 三联征；昏迷静推葡萄糖。

<b>🚨 红线</b>：昏迷者禁止口服补糖（误吸）；补糖后 30 分钟未清醒要考虑脑水肿，加甘露醇/地塞米松；磺脲类所致低血糖易复发，需持续输注葡萄糖并观察 24～48 小时。

<b>🩺 下一步</b>：清醒者口服 15～20g 葡萄糖→昏迷者 50% 葡萄糖 40～60ml 静推→复测血糖→持续葡萄糖输注→查病因。

#### 🔴 K-M08-006｜急性脑卒中（教师重点第60条｜P29-30）

📌 重点原文（第60条）：急性脑卒中：分缺血性与出血性；缺血性卒中静脉溶栓时间窗 3～4.5 小时（rt-PA 0.9mg/kg，最大 90mg）或 6 小时内尿激酶 100 万～150 万 IU；收缩压≥180mmHg 或舒张压≥110mmHg 为溶栓禁忌（P29-30）

<b>🎯 一句话题眼</b>：突发偏瘫/失语 → 先 CT 排出血；缺血性溶栓 3～4.5 小时、血压<180/110。

<b>🧬 为什么</b>：缺血半暗带在闭塞后仍可存活数小时，尽早再通可挽救；但溶栓会增加出血风险，故必须先排除出血、控制血压、评估禁忌。3～4.5 小时（rt-PA 0.9mg/kg，最大 90mg）或 6 小时内尿激酶 100 万～150 万 IU 是时间窗；血压≥180/110mmHg 为禁忌。 最常见的延误是「等 MRI 再溶栓」：CT 排除出血即可决策，MRI 不是溶栓前置条件。

<b>🔗 机制链</b>：血栓/栓塞 → 脑动脉闭塞 → 核心梗死＋半暗带 → 缺血 → 及时再通则半暗带存活，否则梗死扩大。

<b>⚖️ 鉴别</b>：缺血 vs 出血：前者多在安静/睡眠中起病、无头痛呕吐、CT 早期无高密度；后者多在活动中起病、头痛呕吐、意识障碍、CT 高密度。与低血糖鉴别：先测血糖。

<b>💡 记忆钩子</b>：卒中：先 CT 排出血；溶栓 3～4.5 小时、血压<180/110。

<b>🚨 红线</b>：溶栓前必须 CT 排除出血；血压≥180/110mmHg 为禁忌；溶栓 24 小时内不用抗血小板/抗凝；不要因等待 MRI 延误溶栓。

<b>🩺 下一步</b>：气道/血糖/血压→急诊 CT→评估溶栓窗→rt-PA/尿激酶→卒中单元监护→二级预防。

#### 🟡 K-M08-007｜蛛网膜下腔出血 SAH（教师重点第61条｜P27、P31-33）

📌 重点原文（第61条）：蛛网膜下腔出血：起病急骤，剧烈头痛、呕吐、一过性意识障碍；有明显脑膜刺激征、很少出现局限性神经系统体征；脑脊液呈血性；CT 可助诊，脑血管造影／DSA 明确病因（P27、P31-33）

<b>🎯 一句话题眼</b>：突发「一生最剧烈」头痛 + 脑膜刺激征 + 无局灶体征 → SAH。

<b>🧬 为什么</b>：颅内动脉瘤或动静脉畸形破裂，血液进入蛛网膜下腔，刺激脑膜与血管，引起剧烈头痛与脑膜刺激征；血液刺激还可致脑血管痉挛、再出血与脑积水。SAH 很少出现局限性体征，这是与脑出血鉴别的重要点。 最容易忽略的是「CT 阴性就排除 SAH」：起病数小时内 CT 可假阴性，仍需腰穿查血性脑脊液。

<b>🔗 机制链</b>：动脉瘤破裂 → 血液入蛛网膜下腔 → 脑膜刺激 → 剧烈头痛/呕吐/一过性意识障碍 → 血管痉挛/再出血/脑积水。

<b>⚖️ 鉴别</b>：与脑出血鉴别：后者多有偏瘫等局灶体征，先出现偏瘫后出现脑膜刺激征；SAH 先有脑膜刺激征、局灶体征少。与偏头痛鉴别：后者反复发作史、无脑膜刺激征、CT 正常。

<b>💡 记忆钩子</b>：SAH：一生最剧烈头痛＋脑膜刺激征＋无局灶体征；CT/DSA。

<b>🚨 红线</b>：怀疑 SAH 而 CT 阴性，仍需腰穿查血性脑脊液；确诊后绝对卧床、镇痛、控压，尽早处理动脉瘤；禁用抗凝/抗血小板。

<b>🩺 下一步</b>：CT→腰穿（CT 阴性）→DSA/CTA 找动脉瘤→尼莫地平防血管痉挛→介入栓塞/手术夹闭→防治脑积水。
