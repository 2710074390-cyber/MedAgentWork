## M04 急性中毒

> 权重 14% ｜ 题型 单选 + 案例 ｜ 卡片 5 张 ｜ 谱系位置：理化损伤与内科急症的交叉
> 三个题眼：①洗胃的时间窗与禁忌 ②解毒剂配对 ③有机磷的 M/N 样与中间综合征
> 阅读时长：20 分钟（卡片 12 分钟 + 图表 5 分钟 + 自测 3 分钟）

### 🧩 前置知识检查

1. 毒物进入人体后，哪些环节可以被干预？
2. 为什么有机磷中毒既要用阿托品又要用胆碱酯酶复活剂？
3. 中间综合征与「反跳」有什么区别？
4. 一氧化碳中毒为什么用高压氧？


### 🎯 30 秒摘要

- 中毒处理：稳定→清除→解毒→支持。
- 洗胃 4～6 小时内最好，腐蚀性禁洗。
- 有机磷：阿托品解 M 样，复活剂解 N 样。
- 中间综合征：中毒后 1～4 日，呼吸肌麻痹。
- CO 中毒：高压氧防迟发性脑病。

### 📋 考点卡群

#### 🔴 K-M04-001｜急性中毒总则与毒物清除（教师重点第22条｜P159-160）

📌 重点原文（第22条）：急性中毒总原则：优先稳定生命体征，清除毒物+支持治疗；口服中毒 4～6 小时内洗胃效果最好；吞服腐蚀性毒物不宜洗胃；昏迷、惊厥者洗胃须保护呼吸道、避免误吸（P159-160）

<b>🎯 一句话题眼</b>：中毒先保命，再洗胃；4～6 小时内最有效，腐蚀性毒物禁洗。

<b>🧬 为什么</b>：毒物在胃肠道吸收有时限，早期洗胃可减少进入体循环的量；但洗胃本身可致误吸、穿孔、迷走反射，因此对腐蚀性毒物、昏迷未保护气道者，风险大于收益。4～6 小时内效果最好，是因为此时胃内毒物尚未大量排入肠道；超过这个窗口，洗胃的收益迅速下降。 临床上最常见的延误是「等毒物鉴定再洗胃」；毒物未知不影响先稳定 ABC 与按时间窗洗胃。

<b>🔗 机制链</b>：脱离现场/脱污染 → 稳定 ABC → 判断毒物与时间 → 有指征则洗胃（左侧卧位、头低、每次 300～500ml、总量 2～5L）→ 活性炭/导泻 → 解毒剂 → 血液净化评估。

<b>⚖️ 鉴别</b>：洗胃 vs 催吐：催吐仅用于清醒配合者，昏迷、惊厥、腐蚀性毒物禁催吐；洗胃 vs 血液净化：后者针对已吸收、蛋白结合率/分布容积合适的毒物。

<b>💡 记忆钩子</b>：中毒先保命：4～6 小时洗胃，腐蚀禁洗，昏迷先护气道。

<b>🚨 红线</b>：腐蚀性毒物（强酸强碱）禁洗胃、禁催吐；昏迷/惊厥洗胃先插管保护气道；洗胃液总量 2～5L，必要时 6～8L，回收液清亮无味为止。

<b>🩺 下一步</b>：脱污染 → 稳定 ABC → 洗胃/活性炭/导泻 → 特效解毒剂 → 血液净化评估；每一步都要记录时间与总量。

<b>🔄 自测</b>：①洗胃的最佳时间窗？②哪类毒物禁洗胃？③昏迷者洗胃的关键保护措施？

#### 🔴 K-M04-002｜特异性解毒剂配对（教师重点第23条｜P161）

📌 重点原文（第23条）：特异性解毒剂：有机磷—阿托品、盐酸戊乙奎醚、碘解磷定；阿片类—纳洛酮 0.4～0.8mg 静脉注射；苯二氮䓬类—氟马西尼 0.2mg 静脉注射（总量可达 2mg）；亚硝酸盐／苯胺—亚甲蓝 1～2mg/kg；氰化物—亚硝酸盐-硫代硫酸钠疗法；铅—依地酸钙钠；砷汞—二巯丙醇（P161）

<b>🎯 一句话题眼</b>：解毒剂按「毒物—药名—剂量」三件套背，考场最爱配对题。

<b>🧬 为什么</b>：不同毒物的分子靶点不同：有机磷抑制胆碱酯酶、阿片激动 μ 受体、苯二氮䓬增强 GABA-A、亚硝酸盐氧化血红蛋白、氰化物抑制细胞色素氧化酶、重金属与巯基酶结合。解毒剂分别针对这些靶点，所以必须先识别中毒综合征再选药；所谓“万能解毒”并不存在，盲目用药只会延误真正的拮抗。 最容易出错的是「看到昏迷就给纳洛酮」：没有针尖瞳与呼吸抑制线索时，纳洛酮无效且可能诱发戒断。

<b>🔗 机制链</b>：识别中毒综合征（瞳孔、呼吸、皮肤、气味、病史）→ 推断毒物类别 → 选特异性解毒剂 → 同时清除毒物 → 监测并发症。

<b>⚖️ 鉴别</b>：纳洛酮 vs 氟马西尼：前者用于阿片类（呼吸抑制、针尖瞳），后者用于苯二氮䓬（昏迷、呼吸抑制但瞳孔不一定小）；亚甲蓝小剂量还原高铁血红蛋白，大剂量反而氧化。

<b>💡 记忆钩子</b>：解毒配对：有机磷-阿托品/碘解磷定；阿片-纳洛酮；苯二氮䓬-氟马西尼；亚硝酸盐-亚甲蓝；氰化物-亚硝酸盐＋硫代硫酸钠；铅-依地酸钙钠；砷汞-二巯丙醇。

<b>🚨 红线</b>：氟马西尼禁用于苯二氮䓬依赖者及三环类抗抑郁药中毒（可诱发癫痫）；纳洛酮在阿片依赖者可致戒断；亚甲蓝 1～2mg/kg，过量致溶血。

<b>🩺 下一步</b>：先识别中毒综合征 → 选解毒剂 → 同时清除毒物 → 监测并发症；剂量按锚定清单原样执行，不自行加量。

<b>🔄 自测</b>：①有机磷的三个解毒药？②纳洛酮、氟马西尼的剂量？③亚甲蓝用于哪些中毒，剂量？

#### 🔴 K-M04-003｜有机磷中毒与瞳孔变化（教师重点第24、26条｜P158、P162-163）

📌 重点原文（第24条）：有机磷中毒：抑制胆碱酯酶致乙酰胆碱蓄积；M 样症状（瞳孔针尖样缩小、大汗淋漓、流涎、支气管分泌物增多）、N 样症状（肌纤维颤动）、中枢神经系统症状；呼出气有蒜味；血胆碱酯酶活力轻度 50%～70%、中度 30%～50%、重度<30%（P162-163）

📌 重点原文（第26条）：瞳孔变化记忆：瞳孔缩小—有机磷、阿片类、镇静催眠药、氨基甲酸酯类；瞳孔扩大—阿托品、莨菪碱、甲醇、乙醇、大麻、苯、氰化物（P158）

<b>🎯 一句话题眼</b>：针尖瞳 + 大汗 + 蒜味 + 肌颤 → 有机磷；阿托品中毒则瞳孔散大。

<b>🧬 为什么</b>：有机磷与胆碱酯酶酯解部位结合形成磷酰化胆碱酯酶，乙酰胆碱不能被水解，在突触间隙蓄积，先兴奋后抑制 M、N 受体及中枢。支气管腺体分泌骤增是早期致死原因；N 样症状（肌颤）提示烟碱受体受累，阿托品对 M 受体有效、对 N 受体无效，所以必须加复活剂。 临床上最危险的是「阿托品化后停药太早」：M 样症状缓解不代表胆碱酯酶恢复，过早减量可反跳。

<b>🔗 机制链</b>：有机磷 → 胆碱酯酶磷酰化 → 乙酰胆碱蓄积 → M 样（瞳孔缩小、大汗、流涎、支气管分泌物增多）→ N 样（肌纤维颤动）→ 中枢症状 → 呼吸衰竭/中间综合征。

<b>⚖️ 鉴别</b>：与阿托品中毒鉴别：后者瞳孔散大、皮肤干燥潮红、心率快、谵妄；与氨基甲酸酯中毒鉴别：后者胆碱酯酶抑制可自行恢复（2～4 小时），病程短。

<b>💡 记忆钩子</b>：针尖瞳＋大汗＋蒜味＋肌颤＝有机磷；阿托品中毒瞳孔散大。

<b>🚨 红线</b>：阿托品只解 M 样症状，对 N 样症状和呼吸肌麻痹无效；达“阿托品化”后维持，避免阿托品中毒；敌百虫中毒禁用碳酸氢钠洗胃，对硫磷中毒禁用高锰酸钾洗胃。

<b>🩺 下一步</b>：脱污染、清水/2% 碳酸氢钠洗胃（敌百虫除外）→ 阿托品加胆碱酯酶复活剂（氯解磷定/碘解磷定）→ 呼吸支持 → 血液灌流。

<b>🔄 自测</b>：①M 样与 N 样症状各举两项？②胆碱酯酶活力三级界值？③哪些毒物瞳孔缩小、哪些扩大？④敌百虫为何禁用碳酸氢钠洗胃？

#### 🟡 K-M04-004｜中间综合征与迟发性脑病（教师重点第25、27条｜P163、P176）

📌 重点原文（第25条）：中间综合征：急性有机磷中毒后 1～4 日（个别第 7 日）发病，表现为颈屈肌、四肢近端肌肉及第Ⅲ～Ⅶ、Ⅸ～Ⅻ对脑神经支配肌肌力减退；累及呼吸肌可致呼吸肌麻痹、呼吸衰竭（P163）

📌 重点原文（第27条）：迟发性脑病：主要见于一氧化碳中毒；高压氧可减少迟发性脑病发生，血液碳氧血红蛋白降至 5% 可停止吸氧；严重一氧化碳中毒后 24～48 小时脑水肿达高峰（P160、P176）

<b>🎯 一句话题眼</b>：有机磷后 1～4 日出现抬头/吞咽无力 → 中间综合征；CO 中毒后 2～30 天出现痴呆/帕金森 → 迟发性脑病。

<b>🧬 为什么</b>：中间综合征是神经肌肉接头处乙酰胆碱蓄积致突触后膜烟碱受体失敏，冲动传递受阻，表现为近端肌与脑神经支配肌无力，呼吸肌受累最危险；它多发生在中毒后 1～4 日、M 样症状已缓解时，所以容易被误认为“好转”。迟发性脑病与 CO 导致的白质脱髓鞘、细胞色素氧化酶抑制及再灌注损伤有关，常在假愈期后 2～30 天出现。 最容易漏诊的是「中间综合征被当成好转」：病人从大汗流涎转为安静、但抬头困难，恰恰是呼吸肌麻痹前兆。

<b>🔗 机制链</b>：有机磷中毒 → 急性期缓解 → 1～4 日出现颈屈肌/四肢近端/脑神经支配肌无力 → 呼吸肌麻痹 → 呼吸衰竭。CO 中毒 → 急性期恢复 → 假愈期 → 2～30 天出现痴呆、帕金森样表现。

<b>⚖️ 鉴别</b>：中间综合征 vs 有机磷反跳：反跳在中毒后 2～7 天、原有 M/N 样症状加重、胆碱酯酶活性低；中间综合征以肌无力为主、M 样症状已缓解。迟发性脑病 vs 急性 CO 中毒脑水肿：前者在假愈期后，后者在急性期。

<b>💡 记忆钩子</b>：中间综合征 1～4 日、抬头吞咽无力；CO 迟发脑病 2～30 天。

<b>🚨 红线</b>：中间综合征出现呼吸肌麻痹需立即气管插管/机械通气；迟发性脑病高危者（老年、昏迷时间长、COHb 高）应尽早高压氧；COHb 降至 5% 才停氧。

<b>🩺 下一步</b>：中间综合征—监测呼吸肌力量/血气、机械通气、继续解毒；迟发性脑病—高压氧、神经保护、康复。

<b>🔄 自测</b>：①中间综合征的发病时间与典型肌群？②中间综合征最危险的并发症？③迟发性脑病主要见于哪种中毒，何时出现？

#### 🟡 K-M04-005｜中毒昏迷的气道管理（教师重点第28条｜P160、P176、P256）

📌 重点原文（第28条）：中毒昏迷气道管理：昏迷、窒息或呼吸停止者及时气管内插管、机械通气；洗胃时注意呼吸道保护、避免误吸；昏迷者头偏向一侧、放置口咽通气道（P160、P176、P256）

<b>🎯 一句话题眼</b>：中毒昏迷 → 先保气道（头侧位/口咽通气道/插管），再洗胃。

<b>🧬 为什么</b>：昏迷后舌根后坠、咽反射消失，洗胃液或胃内容物极易误吸，导致吸入性肺炎甚至窒息；部分毒物（有机磷、百草枯）本身增加分泌物或致肺损伤，气道风险更高。因此“先保气道、再洗胃”不是流程偏好，而是防止在解毒之前先制造一次新的肺损伤。 临床上最致命的操作是「昏迷病人直接插胃管洗胃」：一次误吸就足以造成不可逆低氧。

<b>🔗 机制链</b>：昏迷 → 舌后坠/咽反射消失 → 误吸风险↑ → 头侧位加吸引 → 口咽/鼻咽通气道 → 气管插管（昏迷、窒息、呼吸停止）→ 机械通气 → 再洗胃。

<b>⚖️ 鉴别</b>：口咽通气道适用于深昏迷无咳嗽反射者；清醒或半昏迷有咽反射者放置可致恶心、喉痉挛，应改用侧卧位/吸引。

<b>💡 记忆钩子</b>：中毒昏迷：头侧位/口咽通气道/插管，再洗胃。

<b>🚨 红线</b>：昏迷未保护气道时禁止盲目洗胃；插管前充分吸引；百草枯中毒避免高浓度氧（加重肺损伤），但严重低氧时仍需氧疗。

<b>🩺 下一步</b>：头偏向一侧加吸引 → 口咽/鼻咽通气道 → 气管插管 → 机械通气 → 再洗胃/血液净化。

<b>🔄 自测</b>：①中毒昏迷为什么先处理气道？②口咽通气道的适用与禁忌？③百草枯中毒氧疗有何特殊？

### 🔗 因果链

```text
毒物入体 → 胃肠道吸收/皮肤黏膜污染 → 靶酶抑制或受体占位 → 乙酰胆碱/COHb/高铁血红蛋白蓄积
  → 腺体分泌、肌颤、缺氧 → 呼吸循环衰竭 → 清除毒物+解毒剂+器官支持
```

```text
疑似急性中毒
```
