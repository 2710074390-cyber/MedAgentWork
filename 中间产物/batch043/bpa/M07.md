## M07 心血管与呼吸急症

> 权重 12% ｜ 题型 单选 + 案例 ｜ 卡片 8 张 ｜ 谱系位置：内科急症的前半段（心、肺）

### 🎯 30 秒摘要

- ACS：cTn + 心电图，STEMI 120 分钟内 PCI。
- 高血压急症：>180/120 + 靶器官损害。
- 左心衰：端坐呼吸、粉红泡沫痰、呋塞米。
- 哮喘重度：单字、RR>30、SaO2≤90%。
- ARDS：P/F≤300，小潮气量+ PEEP。

### 📋 考点卡群

#### 🔴 K-M07-001｜急性冠脉综合征 ACS（教师重点第47条｜P87-90）

📌 重点原文（第47条）：急性冠脉综合征 ACS：包括不稳定型心绞痛、非 ST 段抬高型心肌梗死、ST 段抬高型心肌梗死；心肌肌钙蛋白>99th ULN；STEMI 预计 120 分钟内可完成 PCI 首选直接 PCI，溶栓适用于无 PCI 条件且发病 12 小时内（P87-90）

<b>🎯 一句话题眼</b>：胸痛+出汗+cTn 升高 → ACS；STEMI 记「120 分钟 PCI、12 小时溶栓」。

<b>🧬 为什么</b>：冠脉斑块破裂后血小板聚集、血栓形成，堵塞程度决定 UA、NSTEMI 还是 STEMI；STEMI 是完全闭塞，心肌从心内膜向心外膜坏死，越早开通越多心肌得救。120 分钟内可完成 PCI 首选直接 PCI，溶栓仅用于无 PCI 条件且发病 12 小时内，是因为溶栓再通率低于 PCI，且出血风险更高。 临床上最典型的延误是「等肌钙蛋白结果」：STEMI 的再灌注决策看心电图，不必等生化。

<b>🔗 机制链</b>：斑块破裂 → 血栓形成 → 冠脉闭塞 → 心肌缺血 → 心内膜下到透壁坏死 → 泵衰/心律失常。

<b>⚖️ 鉴别</b>：与主动脉夹层鉴别：夹层为撕裂样痛、向背部放射、双上肢血压差、纵隔增宽；与肺栓塞鉴别：突发呼吸困难、低氧、D-二聚体高、右心负荷表现；与张力性气胸鉴别：患侧呼吸音消失、气管偏移。

<b>💡 记忆钩子</b>：ACS 三家：UA、NSTEMI、STEMI；STEMI 120 分钟 PCI、12 小时溶栓。

<b>🚨 红线</b>：STEMI 溶栓禁忌包括既往出血性卒中、近期缺血性卒中、活动性出血、未排除主动脉夹层、血压>180/110mmHg；确诊 ACS 不要反复等肌钙蛋白而延误再灌注。

<b>🩺 下一步</b>：10 分钟内 12 导联心电图→cTn→抗血小板/抗凝/他汀/硝酸酯（禁忌者除外）→STEMI 再灌注（PCI 优先）→监护防室颤。

<b>🔄 自测</b>：①ACS 的三个类型？②cTn 的诊断界值？③STEMI 直接 PCI 与溶栓的时间窗？④溶栓的主要禁忌？

#### 🔴 K-M07-002｜高血压急症（教师重点第48条｜P82-83）

📌 重点原文（第48条）：高血压急症：收缩压>180mmHg、舒张压>120mmHg 伴急性进行性靶器官损害，需立即降压但不宜立即降至正常；主动脉夹层目标收缩压 100～110mmHg；高血压合并脑出血维持收缩压 130～180mmHg（P82-83）

<b>🎯 一句话题眼</b>：>180/120 + 靶器官损害 = 高血压急症；降压要快但不能到正常。

<b>🧬 为什么</b>：血压骤升超过脑、肾、心自身调节上限，导致内皮损伤、脑水肿、微血管血栓；但长期高血压者脑血管自动调节曲线右移，降压过快会导致脑灌注不足。因此“要降、但要稳”，并按靶器官设定目标：夹层 100～110mmHg、脑出血 130～180mmHg。 最容易忽略的是「降压速度」：血压从 210 降到 120 只用了半小时，病人可能因此脑梗死。

<b>🔗 机制链</b>：诱因（停药、嗜铬细胞瘤）→ 外周血管痉挛 → 血压骤升 → 内皮损伤/脑水肿/微血栓 → 急性进行性靶器官损害。

<b>⚖️ 鉴别</b>：高血压急症 vs 亚急症：前者有急性进行性靶器官损害、需静脉降压；后者无急性靶器官损害、可口服药缓慢降压。

<b>💡 记忆钩子</b>：>180/120＋靶器官损害；要降不到正常；夹层 100～110、脑出血 130～180。

<b>🚨 红线</b>：不宜立即降至正常；主动脉夹层 SBP 目标 100～110mmHg；脑出血维持 130～180mmHg；子痫/先兆子痫需产科协同。

<b>🩺 下一步</b>：静脉降压（硝普钠/乌拉地尔/尼卡地平）→按靶器官选目标→镇痛（夹层）→监测。

<b>🔄 自测</b>：①高血压急症的血压界值？②为什么不能快速降至正常？③主动脉夹层与脑出血的降压目标？

#### 🔴 K-M07-003｜急性左心衰（教师重点第49条｜P55-57）

📌 重点原文（第49条）：急性左心衰：端坐呼吸、咳粉红色泡沫痰、双肺湿啰音或哮鸣音、心率 130～140 次/分、心尖区舒张期奔马律；首选呋塞米 20～40mg 静脉注射；硝酸甘油舌下含服 0.4～0.6mg（P55-57）

<b>🎯 一句话题眼</b>：端坐呼吸 + 粉红泡沫痰 + 双肺湿啰音 → 急性左心衰，呋塞米+硝酸甘油。

<b>🧬 为什么</b>：左心室收缩或舒张功能急性下降，左房压升高，肺静脉与肺毛细血管压随之升高，血浆渗入肺泡形成肺水肿；肺泡内液体与气体混合，就形成粉红色泡沫痰。端坐位、双腿下垂减少回心血量，呋塞米利尿、硝酸酯扩静脉，都是为了降低肺毛细血管压。 临床上最常见的误判是「喘就是哮喘」：老年、有心脏病史、端坐呼吸、粉红泡沫痰，先按左心衰处理。

<b>🔗 机制链</b>：左室功能↓ → 左房压↑ → 肺静脉压↑ → 肺毛细血管渗漏 → 肺水肿 → 气体交换障碍 → 低氧。

<b>⚖️ 鉴别</b>：与支气管哮喘鉴别：左心衰有心脏病史、端坐呼吸、粉红泡沫痰、双肺底湿啰音、BNP 升高；哮喘有过敏史、呼气性呼吸困难、哮鸣音、对支气管扩张剂反应好。

<b>💡 记忆钩子</b>：左心衰：端坐＋粉红泡沫痰＋湿啰音；呋塞米 20～40mg。

<b>🚨 红线</b>：急性心梗并发左心衰利尿要慎重（过快可致低血压）；严重低血压/休克时慎用血管扩张剂；吗啡在低血压、意识障碍时慎用。

<b>🩺 下一步</b>：端坐位＋双腿下垂→高流量吸氧（必要时无创通气）→呋塞米 20～40mg 静推→硝酸甘油舌下/静滴→必要时正性肌力药/机械辅助。

#### 🟡 K-M07-004｜心源性晕厥（教师重点第50条｜P15-17）

📌 重点原文（第50条）：心源性晕厥：心律失常（心室率<40 次/分或>130 次/分）或器质性心脏病致急性脑缺血；突发意识丧失、心音消失、抽搐、面色苍白或青紫；心电图或 24 小时动态心电图多能明确，治疗针对病因（P15-17）

<b>🎯 一句话题眼</b>：晕厥+心脏病史/心悸 → 先查心电图；心率<40 或>130 要警惕。

<b>🧬 为什么</b>：心输出量骤降导致全脑低灌注，意识丧失；心律失常性晕厥可在数秒内发生，器质性心脏病（主动脉瓣狭窄、肥厚型心肌病）在运动时更易发作。心率<40 或>130 次/分是危险界值，因为超出此范围心室充盈时间明显不足，心输出量无法维持。 最危险的是「晕厥醒后放回家」：心源性晕厥的再发可能直接是猝死，必须心电监护与病因评估。

<b>🔗 机制链</b>：心律失常/器质性心脏病 → 心输出量骤降 → 全脑低灌注 → 意识丧失 → 摔倒/外伤。

<b>⚖️ 鉴别</b>：与血管迷走性晕厥鉴别：后者有诱因（久站、恐惧）、先兆（恶心、出汗、视物模糊）、面色苍白、心动过缓，平卧后迅速恢复；心源性晕厥常无先兆、伴心悸/胸痛、可致猝死。

<b>💡 记忆钩子</b>：晕厥看心率：<40 或>130 要警惕心源性。

<b>🚨 红线</b>：晕厥伴胸痛、心悸、心脏病史、运动中发作、无先兆者按高危处理；不要仅凭“醒过来了”放回家。

<b>🩺 下一步</b>：平卧抬高下肢→心电监护→12 导联心电图/Holter/超声心动图→病因治疗（起搏器/消融/手术）。

#### 🔴 K-M07-005｜重症哮喘（教师重点第51条｜P50-52）

📌 重点原文（第51条）：重症哮喘：休息时气短、端坐呼吸、只能讲单个字、大汗淋漓、呼吸频率>30 次/分、脉率>120 次/分、血氧饱和度≤90%、呼气流量峰值<60%；治疗大流量吸氧使血氧饱和度在 92% 以上，短效β2受体激动剂+糖皮质激素，必要时机械通气（P50-52）

<b>🎯 一句话题眼</b>：只能讲单字 + RR>30 + HR>120 + SaO2≤90% → 重症哮喘。

<b>🧬 为什么</b>：气道炎症、平滑肌痉挛与黏液栓使呼气气流严重受限，肺过度充气，呼吸功骤增；当 PaCO2 由低转正常或升高时，提示呼吸肌疲劳，是插管信号。SaO2≤90%、PEF<60%、单字说话、RR>30、HR>120 是重症的量化界值。 临床上最容易被忽略的是「PaCO2 正常化」：哮喘病人 CO2 由低转正常，提示呼吸肌疲劳，是插管前兆。

<b>🔗 机制链</b>：气道炎症 → 痉挛＋黏液栓 → 呼气受限 → 肺过度充气 → 呼吸功↑ → 呼吸肌疲劳 → CO2 潴留 → 呼吸衰竭。

<b>⚖️ 鉴别</b>：与心源性哮喘鉴别（见 M07-003）；与 COPD 急性加重鉴别：后者年龄大、吸烟史、咳痰、肺气肿体征，支气管舒张试验阴性。

<b>💡 记忆钩子</b>：重症哮喘：单字、RR>30、HR>120、SaO2≤90%、PEF<60%。

<b>🚨 红线</b>：PaCO2 正常化或升高提示病情恶化，不是好转；镇静药仅在机械通气时使用；不宜给纯氧（可致 PaCO2 升高）。

<b>🩺 下一步</b>：大流量吸氧（SaO2>92%）→SABA 雾化（可联合 SAMA）→全身糖皮质激素→茶碱/硫酸镁（酌情）→无改善则无创/有创通气。

#### 🔴 K-M07-006｜ARDS（教师重点第52条｜P59-61）

📌 重点原文（第52条）：ARDS：急性起病、双肺浸润影、氧合指数 PaO2/FiO2≤300mmHg 且排除心源性肺水肿；机械通气潮气量 6～8ml/kg、气道平台压<30cmH2O、SpO2>90%；液体入量<2000ml/d（P59-61）

<b>🎯 一句话题眼</b>：急性双肺浸润 + P/F≤300 + 非心源性 → ARDS，小潮气量+PEEP。

<b>🧬 为什么</b>：肺泡-毛细血管膜损伤导致通透性肺水肿，肺泡塌陷后形成肺内分流，出现顽固低氧；小潮气量避免容积伤，PEEP 复张塌陷肺泡，限制液体减少肺水。P/F≤300 且排除心源性肺水肿，是 ARDS 诊断的核心。 最常见的错误是「为追求正常氧分压不断加高 FiO2」：高氧本身加重肺损伤，目标 SpO2>90% 即可。

<b>🔗 机制链</b>：诱因（感染、创伤、胰腺炎）→ 肺泡-毛细血管膜损伤 → 通透性肺水肿 → 肺泡塌陷 → 分流 → 低氧。

<b>⚖️ 鉴别</b>：与心源性肺水肿鉴别：后者有心脏病史、端坐呼吸、BNP 升高、利尿有效、PCWP>18mmHg；ARDS 常有诱因、P/F 低、对利尿反应差。

<b>💡 记忆钩子</b>：ARDS：P/F≤300、双肺浸润、非心源；潮气量 6～8、平台压<30。

<b>🚨 红线</b>：平台压>30cmH2O 易致气压伤；不宜追求完全正常 PaO2 而使用高 FiO2；液体负平衡需在灌注稳定前提下。

<b>🩺 下一步</b>：治疗原发病→肺保护通气（6～8ml/kg、PEEP、平台压<30）→限制液体→俯卧位（中重度）→必要时 ECMO。

#### 🟡 K-M07-007｜社区获得性肺炎 CAP（教师重点第53条｜P203-206）

📌 重点原文（第53条）：社区获得性肺炎：在医院外罹患的肺实质急性感染，包括入院后 48 小时内发病；重症标准满足 1 条主要标准或≥3 条次要标准；主要标准为需气管插管机械通气、感染性休克经液体复苏仍需血管活性药物（P203-206）

<b>🎯 一句话题眼</b>：院外肺实质感染 + 48 小时内发病 = CAP；重症看「1 主或 3 次」。

<b>🧬 为什么</b>：病原体经微量误吸进入下呼吸道，突破宿主防御后引起肺泡渗出与实变；重症时炎症累及多叶，导致低氧与脓毒症，故以“是否需要插管/升压药”作为主要标准。院外罹患、入院 48 小时内发病是 CAP 的时间定义，用以区分医院获得性肺炎。 临床上最容易被忽略的是「重症 CAP 的首剂抗生素时间」：1 小时内用药与病死率直接相关。

<b>🔗 机制链</b>：病原体吸入 → 肺泡渗出 → 实变 → 通气/血流比例失调 → 低氧 → 重症（多叶、脓毒症）。

<b>⚖️ 鉴别</b>：与肺结核鉴别：后者病程长、低热盗汗、上叶尖后段、抗感染无效；与肺栓塞鉴别：突发呼吸困难、D-二聚体高、CTPA 充盈缺损。

<b>💡 记忆钩子</b>：CAP：院外＋入院 48 小时内；重症 1 主或≥3 次。

<b>🚨 红线</b>：重症 CAP 首剂抗生素应在 1 小时内；不要因等痰培养而延迟用药；注意流感继发细菌感染。

<b>🩺 下一步</b>：评估重症标准→经验性抗感染（按社区病原谱）→氧疗/液体复苏→1 小时复评。

#### 🟡 K-M07-008｜肺栓塞的栓子来源与诊断（教师重点第54条｜P57-59）

📌 重点原文（第54条）：肺栓塞栓子：70%～90% 来自深静脉血栓，以下肢深静脉为主，盆腔静脉血栓是女性肺栓塞的重要来源；诊断首选 CT 肺动脉造影；高危患者尽早溶栓（P57-59）

<b>🎯 一句话题眼</b>：突发呼吸困难+低氧+ D-二聚体高 → 想肺栓塞；栓子多来自下肢深静脉。

<b>🧬 为什么</b>：深静脉血栓脱落后随静脉回流进入右心，卡在肺动脉分支，导致肺循环阻力骤升、右心负荷增加、通气/血流比例失调；大栓子可致右心衰与休克。70%～90% 的栓子来自深静脉血栓，以下肢为主，盆腔静脉是女性重要来源。 最容易漏诊的是「术后卧床病人的突发呼吸困难」：先想肺栓塞，不要只按肺炎或心衰处理。

<b>🔗 机制链</b>：深静脉血栓 → 脱落 → 右心 → 肺动脉分支 → 肺循环阻力↑ → 右心负荷↑ → 通气/血流比例失调 → 低氧/低血压。

<b>⚖️ 鉴别</b>：与 ACS 鉴别：后者胸痛伴心电图 ST-T 改变、cTn 升高；与气胸鉴别：后者患侧呼吸音消失、气管偏移；与肺炎鉴别：后者发热、实变影、抗感染有效。

<b>💡 记忆钩子</b>：肺栓塞：栓子来自下肢深静脉，确诊 CTPA，高危溶栓。

<b>🚨 红线</b>：高危肺栓塞（休克/低血压）尽早溶栓，不等 CTPA 完整报告；抗凝前评估出血风险；妊娠期首选低分子肝素。

<b>🩺 下一步</b>：评估血流动力学→D-二聚体/心电图/血气→CTPA（首选）→抗凝；高危溶栓，禁忌者介入取栓。
