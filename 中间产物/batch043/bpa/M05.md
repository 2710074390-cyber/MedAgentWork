### 🎯 30 秒摘要

- 中暑三级：先兆≤38℃、轻症>38℃、热射病>40.5℃。
- 热射病：快速降温，10～40 分钟到 39℃以下。

### 📋 考点卡群

#### 🔴 K-M05-001｜中暑的分级（教师重点第29、30、31条｜P178-179）

📌 重点原文（第29条）：中暑分级：先兆中暑、轻症中暑、重症中暑（热痉挛、热衰竭、热射病）；先兆中暑体温正常或略高、不超过 38℃；轻症中暑体温一般超过 38℃；热射病核心体温超过 40.5℃（P178-179）

📌 重点原文（第30条）：先兆中暑：口渴、乏力、多汗、头晕、目眩、耳鸣、头痛、恶心、胸闷、心悸、注意力不集中；体温正常或略高，不超过 38℃（P178）

📌 重点原文（第31条）：轻症中暑：面色潮红或苍白、烦躁不安或表情淡漠、恶心呕吐、大汗淋漓、皮肤湿冷、脉搏细数、血压偏低、心率加快；体温一般超过 38℃，及时处理可于数小时内恢复（P178-179）

<b>🎯 一句话题眼</b>：先兆「症状多、体温＜38」；轻症「循环紊乱、体温＞38」；重症「痉挛/衰竭/高热」。

<b>🧬 为什么</b>：高温高湿使散热受阻，水和电解质丢失，外周血管扩张，有效循环血量不足。先兆阶段只有缺水缺盐症状、体温不超过 38℃；轻症出现循环功能紊乱、体温一般超过 38℃；重症则中枢与循环同时失代偿，再按主要矛盾分为热痉挛（盐丢失）、热衰竭（容量不足）、热射病（体温调节中枢失效）。三级不是三种病，而是同一条病理链的不同深度。 临床上最容易被忽略的是「热痉挛病人体温正常」：正因体温不高，常被当成普通抽筋而延误补盐。

<b>🔗 机制链</b>：高温高湿 → 散热受阻 → 出汗丢失水盐 → 外周血管扩张 → 有效循环血量↓ → 先兆（口渴乏力、体温≤38℃）→ 轻症（循环紊乱、>38℃）→ 重症（痉挛/衰竭/高热）。

<b>⚖️ 鉴别</b>：热痉挛（意识清、体温正常、腓肠肌痉挛）vs 热衰竭（头晕、冷汗、血压↓、体温≤40℃）vs 热射病（高热、无汗、意识障碍、>40.5℃）。三者的分界是体温、意识与循环状态，不是出汗多少。

<b>💡 记忆钩子</b>：中暑三级：先兆≤38、轻症>38、热射病>40.5。

<b>🚨 红线</b>：热射病不是普通中暑，必须立即降温；不要给意识障碍者口服大量水；热衰竭补液用生理盐水/平衡液，不用纯水。

<b>🩺 下一步</b>：先兆/轻症—阴凉通风、口服淡盐水、监测；重症—快速降温、补液、器官支持。

<b>🔄 自测</b>：①中暑三级各自体温界值？②热痉挛、热衰竭、热射病的鉴别要点？③先兆中暑的典型症状？

#### 🔴 K-M05-002｜热射病与快速降温（教师重点第32条｜P179）

📌 重点原文（第32条）：热射病（重度中暑）：中暑最严重类型，也称中暑高热；高热、无汗、意识障碍，体温超过 40.5℃；降温目标为核心体温 10～40 分钟内降至 39℃以下、2 小时内降至 38.5℃以下（P179）

<b>🎯 一句话题眼</b>：高热 + 无汗 + 意识障碍 + >40.5℃ → 热射病，降温速度决定生死。

<b>🧬 为什么</b>：核心体温过高直接损伤细胞膜与线粒体，触发全身炎症反应、凝血障碍与 MODS；体温每升高 1℃，代谢率与耗氧量增加，形成恶性循环。降温延迟则病死率显著升高，因此“先降温、后转运”。10～40 分钟降至 39℃、2 小时降至 38.5℃，是为了在器官损伤不可逆之前打断链条。 最危险的是「等转运到院内再降温」：热射病的降温每延迟 10 分钟，病死率明显上升，现场就应开始。

<b>🔗 机制链</b>：高温暴露 → 体温调节中枢失效 → 核心体温>40.5℃ → 细胞膜/线粒体损伤 → 炎症反应、凝血障碍 → 脑、肝、肾、凝血序贯障碍。

<b>⚖️ 鉴别</b>：与脑卒中/脑膜炎/甲状腺危象/抗胆碱药中毒鉴别：后几者有相应病史与体征，且不一定有高温暴露史；热射病有高温高湿环境或剧烈运动史。

<b>💡 记忆钩子</b>：热射病降温：10～40 分钟到 39℃，2 小时到 38.5℃。

<b>🚨 红线</b>：降温目标 10～40 分钟降至 39℃以下、2 小时降至 38.5℃以下；降至正常即停止降温，防低体温；不用酒精擦浴（可致寒战/吸收）。

<b>🩺 下一步</b>：脱离热环境 → 冷水浸泡/喷洒加扇风/冰毯 → 补液、纠正电解质 → 器官支持（肝、肾、凝血）。

<b>🔄 自测</b>：①热射病的体温界值与三联表现？②降温的两个时间目标？③为什么不能过度降温？

#### 🔴 K-M05-003｜溺水与现场急救（教师重点第33、34条｜P177-178）

📌 重点原文（第33条）：溺水：淹没或沉浸在水或其他液性介质中引起呼吸系统损伤，导致窒息和缺氧；重度淹溺体温常低于 30℃；复温初始目标 34℃，经 24 小时温和的低体温治疗后再恢复到正常体温（P177-178）

📌 重点原文（第34条）：溺水现场：立即清除口鼻泥沙异物、开放气道、给予人工呼吸和胸外按压；不常规倒挂控水；注意保温（P177-178；控水条目教材未单列，标教师补充）

<b>🎯 一句话题眼</b>：溺水核心是缺氧，现场「清口鼻—开气道—通气/按压—保温」，不倒挂控水。

<b>🧬 为什么</b>：溺水者吸入液体导致肺泡通气/血流比例失调、肺水肿与窒息；缺氧是主要死因，尽快恢复通气和循环比排出胃内水更重要。低温有脑保护效应，复温过快可加重再灌注损伤，因此重度淹溺体温常低于 30℃，复温初始目标 34℃，经 24 小时温和低体温治疗后再恢复正常。 临床上最常见的错误是「先控水、后通气」：倒挂控水延误的每一分钟，都在加重脑缺氧。

<b>🔗 机制链</b>：淹没 → 水进入口鼻 → 喉痉挛/误吸 → 肺泡通气障碍 → 缺氧 → 意识丧失 → 呼吸停止/骤停 → 低温 → 复温。

<b>⚖️ 鉴别</b>：淡水淹溺 vs 海水淹溺：前者低渗液入血致稀释性低钠、溶血；后者高渗液致血液浓缩、高钠；但现场处理相同——通气和复苏优先。

<b>💡 记忆钩子</b>：溺水先通气后按压，不倒挂控水；重度<30℃，复温先 34℃。

<b>🚨 红线</b>：禁止倒挂控水（延误通气、增加误吸）；不要轻易放弃低温溺水者（“溺水者不复温不放弃”）；复温避免过快。

<b>🩺 下一步</b>：上岸→清理口鼻→开放气道→2 次人工呼吸→30:2 CPR→AED→保温→转运；院内复温、肺保护通气、防治 ARDS。

<b>🔄 自测</b>：①溺水的主要病理环节？②现场急救顺序？③为什么不主张倒挂控水？④重度淹溺体温与复温目标？

#### 🟡 K-M05-004｜电击伤与断电（教师重点第35条｜P189）

📌 重点原文（第35条）：电击伤断电：立即切断电源或用绝缘物挑开电线；电线落地时人与落地点保持室内 4m、室外 8m 以上安全距离，小于该距离应单脚跳跃或双脚并小步迅速离开（P189）

<b>🎯 一句话题眼</b>：电击第一步永远是断电，第二步才是碰病人。

<b>🧬 为什么</b>：电流通过心脏可致室颤，通过脑干可致呼吸中枢麻痹，通过肌肉可致强直收缩与灼伤；持续接触电源会让救援者一起触电。跨步电压沿地面分布，双脚分开时两脚间存在电位差，故要单脚跳或小步离开。断电是唯一能同时保护救护者与伤员的第一步。 最容易忽略的是「电击后看起来清醒」：电流对心肌与传导系统的损伤可能延迟出现，必须心电监护。

<b>🔗 机制链</b>：触电 → 电流入体 → 心脏（室颤）/脑干（呼吸麻痹）/肌肉（强直、灼伤）→ 断电 → 评估 → CPR/AED → 处理烧伤与肌红蛋白尿。

<b>⚖️ 鉴别</b>：与雷击鉴别：雷击常致心跳呼吸骤停、鼓膜破裂、树枝样皮肤花纹；处理同样先断电/脱离，再 CPR。

<b>💡 记忆钩子</b>：电击先断电；落地线室内 4m、室外 8m。

<b>🚨 红线</b>：未断电不得直接接触伤员；不能用湿手/金属物挑电线；高压电需专业断电并保持安全距离。

<b>🩺 下一步</b>：断电→判断意识/呼吸/脉搏→CPR/AED→处理烧伤、筋膜切开减压、碱化尿液防肌红蛋白肾损→监测心律失常。

<b>🔄 自测</b>：①电击伤现场第一步？②跨步电压的安全距离（室内/室外）？③电击伤最危险的全身并发症？

#### 🟡 K-M05-005｜烧烫伤急救与面积估算（教师重点第36条｜P186-187、P309）

📌 重点原文（第36条）：烧烫伤急救冲：脱离热源后立即用冷水连续冲洗或浸泡；Ⅰ～Ⅱ度中小面积烧烫伤适用，Ⅲ度及大面积烧伤不必冷疗；不刺破水疱、不涂油脂或药膏，用清洁敷料覆盖（P187、P309）

<b>🎯 一句话题眼</b>：烧伤现场「冲、脱、泡、盖、送」，冷水冲但不涂药。

<b>🧬 为什么</b>：冷水冲洗可带走残余热量、减轻热力向深层传导、缓解疼痛；但大面积/Ⅲ度烧伤冷疗可致低体温与休克，故不适用。水疱是天然敷料，刺破增加感染。烧伤面积与深度决定补液与转院，现场先“冲、脱、泡、盖、送”。 临床上最常见的错误是「用冰块直接敷创面」：局部冻伤会加深创面，冷水冲洗才是正确冷疗。

<b>🔗 机制链</b>：热源接触 → 蛋白质凝固 → 局部坏死/水疱 → 炎症介质释放 → 毛细血管渗漏 → 低血容量 → 休克。

<b>⚖️ 鉴别</b>：Ⅰ度（红斑、无水疱）vs 浅Ⅱ度（水疱、基底红润、痛觉敏感）vs 深Ⅱ度（水疱小、基底苍白/红白相间、痛觉迟钝）vs Ⅲ度（焦痂、蜡白/炭化、无痛觉）。

<b>💡 记忆钩子</b>：烧伤「冲脱泡盖送」；Ⅰ～Ⅱ度冷疗，Ⅲ度/大面积不冷。

<b>🚨 红线</b>：不涂牙膏、酱油、油脂；不刺破水疱；大面积烧伤不复温过度；环形焦痂影响血运时切开减压。

<b>🩺 下一步</b>：冲冷水 15～30 分钟→剪开衣物（不撕脱）→清洁敷料覆盖→补液抗休克（乳酸林格液）→镇痛、破伤风、抗感染。

#### 🟡 K-M05-006｜犬咬伤与狂犬病暴露后处置（教师重点第37条｜P192）

📌 重点原文（第37条）：犬咬伤：伤口处理+狂犬病疫苗；Ⅱ级暴露处理伤口+注射狂犬病疫苗；Ⅲ级暴露加用狂犬病被动免疫制剂；5 针法第 0、3、7、14、28 天各 1 剂，“2-1-1”程序第 0 天（2 剂）、第 7 天和第 21 天各 1 剂；潜伏期多数 20～90 天（P192）

<b>🎯 一句话题眼</b>：Ⅱ级「洗+疫苗」，Ⅲ级「洗+被动免疫+疫苗」；5 针 0-3-7-14-28。

<b>🧬 为什么</b>：狂犬病毒经唾液进入伤口，沿周围神经向中枢移行；伤口彻底冲洗可机械清除病毒，疫苗主动产生抗体需要时间，Ⅲ级暴露需被动免疫制剂在伤口周围中和病毒，形成“即时＋主动”双保险。潜伏期多数 20～90 天，因此暴露后越早处理越有效。 最容易被忽略的是「Ⅱ 级暴露只冲洗不打疫苗」：只要皮肤破损，就应按暴露级别完成疫苗程序。

<b>🔗 机制链</b>：咬伤 → 病毒入伤口 → 沿神经移行 → 中枢神经系统感染 → 发病几乎 100% 死亡。处置：冲洗→消毒→疫苗/免疫球蛋白→破伤风→抗生素。

<b>⚖️ 鉴别</b>：Ⅱ级 vs Ⅲ级：Ⅱ级为裸露皮肤轻咬无出血、轻微抓伤；Ⅲ级为贯穿皮肤咬伤/抓伤、破损皮肤被舔、黏膜被唾液污染、暴露于蝙蝠。

<b>💡 记忆钩子</b>：狂犬病：Ⅱ级疫苗、Ⅲ级加被动免疫；5 针 0-3-7-14-28。

<b>🚨 红线</b>：Ⅲ级暴露必须用被动免疫制剂，不能只打疫苗；伤口不宜一期缝合（除面部、大血管等特殊情况）；狂犬病一旦发病几乎 100% 死亡。

<b>🩺 下一步</b>：肥皂水/流动水冲洗至少 15 分钟→碘伏消毒→按级别接种疫苗/免疫球蛋白→破伤风评估→抗生素（深部咬伤）。

#### 🟡 K-M05-007｜止血带的使用（教师重点第38条｜P282）

📌 重点原文（第38条）：止血带使用：扎在出血伤口上方 5cm，上臂宜在上 1/3、大腿宜在上 2/3；须用三角巾、毛巾等垫衬，不能直接缠在皮肤上；以出血停止、远端动脉搏动不能扪及为度；最长不宜超过 4 小时，每小时缓慢放松 1 次、每次 1～2 分钟；严禁用电线、铁丝、绳索代替（P282）

<b>🎯 一句话题眼</b>：止血带「上 5cm、上臂 1/3、大腿 2/3、垫衬、4 小时、每小时松 1～2 分钟」。

<b>🧬 为什么</b>：止血带通过压迫动脉阻断远端血流；位置过高会扩大缺血范围，直接缠皮肤会压伤神经与皮肤；长时间阻断导致缺血性肌挛缩与神经损伤，故需定时放松。以出血停止、远端动脉搏动不能扪及为度：过松只压住静脉反而出血，过紧则神经缺血。 临床上最常见的错误是「止血带扎上就不管」：超过 4 小时不松解，可致缺血性肌挛缩与神经损伤。

<b>🔗 机制链</b>：大血管出血 → 加压包扎无效 → 止血带（伤口上方 5cm、上臂上 1/3、大腿上 2/3、垫衬）→ 出血停止、远端搏动消失 → 记录时间 → 每小时松 1～2 分钟 → 尽快手术止血。

<b>⚖️ 鉴别</b>：指压止血适用于头面/肢体小出血；加压包扎适用于大多数活动性出血；填塞适用于深大伤口；止血带仅用于大血管损伤、其他方法无效时。

<b>💡 记忆钩子</b>：止血带：上 5cm、上臂 1/3、大腿 2/3、垫衬、≤4 小时、每小时松 1～2 分钟。

<b>🚨 红线</b>：严禁电线、铁丝、绳索代替；不能直接缠皮肤；最长 4 小时；放松前先压迫伤口，防再次大出血。

<b>🩺 下一步</b>：记录上止血带时间→每 1 小时放松 1～2 分钟→尽快转运手术止血→监测远端血运与肌红蛋白尿。

### 📊 对比速查

| 中暑分级 | 体温 | 关键表现 | 处理 |
|---|---|---|---|
| 先兆 | ≤38℃ | 口渴、多汗、头晕 | 阴凉、口服淡盐水 |
| 轻症 | >38℃ | 面色潮红/苍白、脉细数、血压偏低 | 补液、降温、观察 |
| 热痉挛 | 一般正常 | 腓肠肌对称性痉挛、意识清 | 补盐、拉伸 |
| 热衰竭 | ≤40℃ | 冷汗、晕厥、血压下降 | 补液、降温 |
| 热射病 | >40.5℃ | 高热、无汗、意识障碍 | 快速降温、器官支持 |

| 烧伤深度 | 累及层次 | 外观 | 痛觉 |
|---|---|---|---|
| Ⅰ度 | 表皮浅层 | 红斑、无水疱 | 敏感 |
| 浅Ⅱ度 | 真皮乳头层 | 水疱大、基底红润 | 敏感 |
| 深Ⅱ度 | 真皮网状层 | 水疱小、基底红白相间 | 迟钝 |
| Ⅲ度 | 全层及以下 | 焦痂、蜡白/炭化 | 无 |

| 暴露级别 | 情形 | 处理 |
|---|---|---|
| Ⅰ级 | 接触/喂养、完整皮肤被舔 | 无需处置 |
| Ⅱ级 | 轻咬无出血、轻微抓伤 | 处理伤口+疫苗 |
| Ⅲ级 | 贯穿咬伤、黏膜污染、蝙蝠暴露 | 处理伤口+被动免疫+疫苗 |

```text

  → 休克、脑水肿、肌红蛋白尿 → 器官支持 → 康复或 MODS
```
