# 第一章 绪论——小儿年龄分期 🔥🔥

> 🅰️ **A1型题核心章**：各年龄期分界点必须一字不差，死亡率最高/生长发育最快的时期必考。

---

## 📌 一、小儿年龄分期及各期特点（必背·死记硬背）

| 分期 | 时间节点 | 核心特点关键词 |
|------|----------|----------------|
| **胎儿期** | 受精卵形成→出生，约40周（280天） | 完全依赖母体；最初12周（孕早期）最易致畸 |
| **围产期**（围生期） | 孕满28周→生后满1周 | 围产儿死亡率高 |
| **新生儿期** 🔥 | 脐带结扎→生后满28天 | **发病率及死亡率最高**，尤以早期新生儿（第1周）最高 |
| **婴儿期** 🔥 | 出生→满1周岁前 | **体格生长发育最快的时期**；营养需求大→消化紊乱多见；"免疫真空期"→感染多见 |
| **幼儿期** | 1周岁→满3周岁前 | 意外事故较多见；营养障碍、腹泻多见 |
| **学龄前期** 🔥 | 3周岁→6~7岁入小学前 | **智能发育最快**，性格形成关键期；意外事故多，其他疾病减少 |
| **学龄期** | 6~7岁→青春期前 | 除生殖器官外，各器官外形接近成人；免疫系统疾病增多 |
| **青春期** | 女11~12→17~18岁<br>男13~14→18~20岁 | **第二个体格生长高峰**；第二性征及生殖系统迅速发育 |

> 🧠 **学霸口诀**（景老师原创）：
> "胎儿期防致畸，围生期围死期；新生儿四周内，一周内危中危；
> 婴儿期1岁内，长太快缺营养；幼儿期不懂事，到处跑防意外；
> 学龄前期幼儿园，智力语言和习惯；学龄期上小学，心理龋齿和近视；
> 免疫系统大洗牌，风湿容易找上来；青春期性发育，身高体重再一窜。"

---

### 🔥 高频陷阱题目速记

| 题目 | 答案 | 解析 |
|------|------|------|
| 小儿死亡率最高的时期 | **新生儿期** | 尤以早期新生儿（第1周）最高 |
| **智力发展的关键期** | **学龄前期** | 不是婴儿期！婴儿期是体格发育最快 |
| 体格发育两个高峰期 | **婴儿期+青春期** | 注意是两个！ |
| 意外事故多+营养性疾病多 | **幼儿期** | |
| 意外事故多+其他疾病减少 | **学龄前期** | |

> ⚠️ **易错点**：新生儿期定义是"脐带结扎至生后28天"，注意婴儿期包含新生儿期在内。

---


> ⚡ **绪论·速记卡**
> 🔑 新生儿期=脐带结扎~28天 | 婴儿期=体格生长最快 | 学龄前期=智力发展关键
> ⚠️ 死亡率最高=新生儿期（非围产期！）
> 💡 婴儿期+青春期=两个生长高峰

# 第二章 生长发育 🔥🔥🔥

> 🅰️🅱️ **公式推算+年龄判断核心章**：给年龄问指标/给指标问年龄，必考！

---

## 📌 一、生长发育四大规律（必背·填空题常考）

1. **连续性、阶段性**：两个生长高峰（婴儿期+青春期）
2. **各系统器官发育不平衡**：神经系统→先快后慢；生殖系统→先慢后快；淋巴系统→儿童期快，青春期前达高峰
3. **一般规律**：由上到下、由近到远、由粗到细、由低级到高级、由简单到复杂
4. **个体差异性**

> 🧠 **口诀**："上→下，近→远，粗→细，简单→复杂"

---

## 📌 二、体格生长——公式与数值（必背！核心考点）

### 1. 体重（kg）⭐⭐⭐

| 年龄段 | 公式/数值 |
|--------|----------|
| 出生 | **3kg** |
| 3个月 | 约6kg（出生2倍） |
| 1岁 | 约9~10kg（出生3倍） |
| 2岁 | 约12kg（出生4倍） |
| **3~12个月** | **体重(kg) = （月龄+9）/ 2** |
| **1~6岁** | **体重(kg) = 年龄×2 + 8** |
| **7~12岁** | **体重(kg) = （年龄×7 - 5）/ 2** |

> 🧠 **巧记**：前3个月增长=后9个月增长，1岁时=3倍出生体重。

### 2. 身高/身长（cm）⭐⭐⭐

| 年龄段 | 数值/公式 |
|--------|----------|
| 出生 | **50cm** |
| 3个月 | 约61~63cm |
| 1岁 | **75cm**（增长25cm） |
| 2岁 | 约87cm（增长10~12cm） |
| **2~12岁** | **身高(cm) = 年龄×7 + 75** |

### 3. 头围（cm）

| 年龄 | 数值 |
|------|------|
| 出生 | **34cm** |
| 3个月 | 40cm |
| 1岁 | **46cm** |
| 2岁 | **48cm** |
| 5岁 | 50cm |

> ⚠️ **易错点**：1岁时头围=胸围（约46cm），此为"头胸交叉"！

### 4. 胸围

- 出生时：约32cm（比头围小1~2cm）
- **1岁时：胸围 = 头围（约46cm）**
- 1岁后：胸围 > 头围（约为头围+年龄-1cm）

---

## 📌 三、骨骼发育

### 1. 前囟闭合
- **正常闭合时间**：约1~1.5岁闭合，最迟不超过2岁
- 过早闭合→头小畸形
- 过迟闭合→佝偻病、甲减
- 饱满隆起→颅内压增高
- 凹陷→脱水

### 2. 骨龄——骨化中心公式 ⭐⭐⭐

$$
\text{腕部骨化中心数} \approx 年龄（岁） + 1（1~9岁）
$$
- 共10个，10岁出齐
- ⚠️ **注意**：婴儿早期应摄**膝部**X线片（非腕部）
- 💡 **补充**：新生儿腕部无骨化中心，3个月出现2个（头状骨、钩骨），"年龄+1"仅为粗略估算

## 📌 五、神经心理发育——隐藏考点扩展 🔥

（本部分对照《补充复习资料》详细展开）

### 1. 感知觉发育

| 感知类型 | 关键时间节点 |
|---------|------------|
| **视感知** | 新生儿只能看清15~20cm内事物；3~4月头眼协调好；8~9月出现视深度感觉；5岁区别各种颜色；6岁视深度充分发育 |
| **听感知** | 出生时鼓室无空气，听力差；3~7天听觉已良好；3~4月头转向声源；6月区分父母声音；4岁听觉发育完善 |
| **味觉** | 出生时味觉发育已很完善；**4~5个月为味觉发育关键期**，应适时添加辅食 |

### 2. 神经反射的年龄特点

| 反射 | 特点 |
|------|------|
| **握持反射** | 3个月时消失 |
| **腹壁反射和提睾反射** | 1岁时才稳定 |
| **Kernig征** | 3~4个月前婴儿可为阳性（生理性） |
| **Babinski征** | 2岁以下儿童阳性可为生理现象 |
| **腰椎穿刺位置** | 胎儿期脊髓下端在L2下缘，4岁时上移至L1，婴幼儿腰穿位置偏低 |

### 3. 记忆、思维、情绪发展速记表

| 项目 | 关键节点 |
|------|---------|
| 记忆 | 1岁内只有再认无重现；幼年以机械记忆为主；年龄增长→逻辑记忆发展 |
| 思维 | 1岁后产生思维；3岁前只有最初级形象思维；3岁后开始有初步抽象思维；6~11岁学会综合分析、分类比较 |
| 情绪 | 婴幼儿情绪特点：时间短暂、反应强烈、容易变化、外显而真实 |
| 注意力 | 婴儿期以无意注意为主；5~6岁后能较好控制注意力 |
| 想象力 | 新生儿无想象；1~2岁仅有萌芽；3~4岁迅速发展（自由联想为主） |

### 4. 神经心理发育评价试验 🔴（补充·必考）

| 类别 | 试验名称 | 适用年龄 | 用途 |
|------|---------|---------|------|
| **筛查性** | **丹佛发育筛查（DDST）** | 0~6岁 | 最常用筛查，四大能区：个人-社交、精细动作、语言、大运动 |
| | **图片词汇试验（PPVT）** | 4~9岁 | 筛查语言障碍（不需口头回答，听词指图） |
| | **绘人试验** | 5~9岁 | 筛查智力（画人→评分，反映智力成熟度） |
| **诊断性** | **Gesell发育量表** | 0~3岁 | 诊断性评估，四大能区 |
| | **Bayley婴儿发育量表** | 0~3岁 | 诊断性评估，心理/运动两个分量表 |
| | **Wechsler量表** | 各年龄段 | WPPSI（4~6.5岁）、WISC（6~16岁） |

> ⚠️ **常考**：区分筛查性 vs 诊断性的分类归属。DDST和PPVT是筛查性，Gesell/Bayley/Wechsler是诊断性。 |

# 第三章 儿童保健——预防接种 🔥🔥🔥

> 🅰️ **必背表格**：国家免疫规划疫苗免疫程序表。口诀+复种时间是易忽略考点。

---

## 📌 一、五苗防七病 + 接种口诀

> 🧠 **经典口诀**："出生乙肝卡介苗，2/3/4月脊髓苗，3/4/5月百白破，8月麻疹一独苗"

| 疫苗 | 初种年龄 | 备注 |
|------|---------|------|
| **乙肝疫苗** | 出生时、1月、6月 | 0-1-6方案 |
| **卡介苗**（BCG） | 出生时 | **皮内注射**（非皮下！）；出生未种者先做PPD试验，阴性可种 |
| **脊髓灰质炎** | 2、3、4月 | 口服减毒活疫苗，凉开水送服 |
| **百白破** | 3、4、5月 | 肌内注射 |
| **麻疹** | 8月 | 皮下注射 |

---

## 📌 二、复种时间（极易忽略！）

| 年龄 | 复种内容 |
|------|---------|
| 1.5~2岁 | 百白破复种、麻疹复种 |
| **4岁** | **脊髓灰质炎复种** |
| **6~7岁** | **白破二联类毒素复种**（不是百白破！）⚠️ |

> ⚠️ **易错点**：6~7岁复种的是**白破二联**，不是百白破！

| 接种年/月龄 | 疫苗 |
|------------|------|
| **出生时** | 卡介苗（BCG）、乙肝疫苗第1针 |
| **1月龄** | 乙肝疫苗第2针 |
| **2月龄** | 脊髓灰质炎疫苗第1剂 |

2. 出生未接种者 → 必须先做PPD试验 → **阴性才可接种**
3. 阳性不可接种（说明已感染过结核或接种过）

# 第四章 儿童液体平衡特点与液体疗法 🔥🔥

> 🅲️ **理解+计算**：补液总量≠累计损失量，极易混淆！脱水程度和性质的判断是核心。

---

## 📌 一、补液三部分

1. **生理需要量**
2. **累计损失量**（已丢失的）
3. **继续丢失量**（正在丢失的）

---

## 📌 二、脱水程度判断（必背！）

| 程度 | 失水量(占体重) | 累计损失量(ml/kg) | 皮肤弹性 | 眼窝/前囟 | 尿量 | 精神状态 |
|------|---------------|-------------------|----------|-----------|------|---------|
| **轻度** | <5% | 30~50 | 尚可 | 稍凹陷 | 稍减 | 尚可 |
| **中度** | 5%~10% | 50~100 | 差 | 明显凹陷 | 明显减少 | 萎靡 |
| **重度** | >10% | 100~120 | 极差 | 深凹 | 无尿 | 昏迷/休克 |

---

## 📌 三、补液总量 vs 累计损失量（易混淆！）

| 脱水程度 | **补液总量(ml/kg)** | **累计损失量(ml/kg)** |
|---------|---------------------|----------------------|
| 轻度 | **90~120** | 30~50 |
| 中度 | **120~150** | 50~100 |
| 重度 | **150~180** | 100~120 |
| 扩容 | 20ml/kg | — |

> ⚠️ **易错点**：补液总量≠累计损失量！总量包含三部分（生理+累计+继续），累计损失量只是其中一部分。

---

## 📌 四、脱水性质判断（根据血钠）

| 类型 | 血钠(mmol/L) | 补液张力 | 临床特点 |
|------|-------------|---------|---------|
| **等渗脱水** | 130~150 | **1/2张** | 最常见 |
| **低渗脱水** | <130 | **2/3张** | 缺钠>缺水，易休克 |
| **高渗脱水** | >150 | **1/3~1/5张** | 缺水>缺钠，烦渴 |

---

## 📌 五、常用液体张力速查

| 溶液 | 张力 | 用途 |
|------|------|------|
| 0.9%氯化钠（生理盐水） | 等张 | — |
| 5%葡萄糖 | 无张 | — |
| **2:1等张含钠液**（2盐:1碱） | 等张 | 扩容抗休克 |
| **3:2:1液**（3糖:2盐:1碱） | **1/2张** | 等渗脱水 |
| **4:3:2液**（4盐:3糖:2碱） | **2/3张** | 低渗脱水 |
| **1:2液**（1盐:2糖） | **1/3张** | 高渗脱水 |

> 🧠 **口诀**："先快后慢，先盐后糖，先浓后淡，见尿补钾，见惊补钙"

---


> ⚡ **液体疗法·速记卡**
> 🔑 轻度失水<% | 中度5%~10% | 重度>%
> ⚠️ 补液总量≠累计损失量！总量包含生理+累计+继续三部分
> 💡 等渗1/2张、低渗2/3张、高渗1/3~1/5张；见尿补钾

# 第五章 营养和营养障碍疾病 🔥🔥🔥

---

## 📌 一、婴儿喂养——母乳特点

### 1. 母乳 vs 牛乳对比速查表

| 项目 | 母乳 | 牛乳 |
|------|------|------|
| 蛋白质主成分 | **乳清蛋白为主（60%以上）** | 酪蛋白为主（80%） |
| 钙磷比 | **2:1** | 约1.2:1 |
| 脂肪 | 不饱和脂肪酸多，含DHA | 饱和脂肪酸多 |
| 糖类 | **乙型乳糖**，促双歧杆菌 | 甲型乳糖为主 |
| 免疫物质 | **SIgA、乳铁蛋白、溶菌酶丰富** | 极低 |
| 矿物质 | 适量 | 含量高，肾溶质负荷高 |

### 2. 各期母乳成分变化

| 时期 | 时间 | 特点 |
|------|------|------|
| **初乳** | 产后4~5天 | 量少，蛋白质（SIgA）丰富，脂肪和乳糖较少，呈黄色 |
| 过渡乳 | 产后5~14天 | 蛋白质渐减，脂肪和乳糖渐增 |
| 成熟乳 | 产后14天以后 | 各成分稳定 |
| 晚乳 | 10个月后 | 量和营养成分减少 |

## 📌 二、辅食添加原则

> 🧠 **口诀**："由少到多、由稀到稠、由细到粗、由一种到多种，在婴儿健康时添加"

| 月龄 | 添加内容 |
|------|---------|
| 4~6个月 | 米粉、菜泥、蛋黄（补铁） |
| 7~9个月 | 烂面、碎菜、肉末、鱼泥 |
| 10~12个月 | 软饭、碎肉、豆制品 |

## 📌 三、维生素D缺乏性佝偻病 🔥🔥🔥

### 1. 病因
- 日照不足（最主要）
- 维生素D摄入不足
- 生长过快
- 疾病因素（肝胆疾病、长期用抗惊厥药等）

### 2. 临床表现——表5-7掌握（核心考点）

| 分期 | 症状 | 血钙 | 血磷 | AKP | 25-(OH)D₃ | X线 |
|------|------|------|------|-----|-----------|-----|
| **初期** | 神经兴奋性增高（哭闹、多汗、枕秃） | 正常或稍低 | ↓ | 正常或稍↑ | ↓ | 正常或轻微 |
| **激期**（活动期） | 骨骼改变+运动功能发育迟缓 | 稍低或正常 | ↓↓ | ↑↑ | ↓↓ | 骨骺端钙化带模糊/消失、**杯口状** |
| **恢复期** | 症状减轻 | 正常 | 正常 | 逐渐正常 | 恢复 | 钙化带重新出现 |
| **后遗症期** | 仅遗留骨骼畸形 | 正常 | 正常 | 正常 | — | — |

### 3. 激期骨骼改变——各年龄段特征

| 部位 | 名称 | 好发年龄 |
|------|------|----------|
| 头部 | **颅骨软化**（乒乓感） | 3~6个月 |
| 头部 | **方颅** | 7~8个月以上 |
| 胸部 | 肋骨串珠、肋膈沟、鸡胸/漏斗胸 | 1岁左右 |
| 四肢 | **手镯、脚镯** | 6个月以上 |
| 四肢 | **O/X形腿** | 1岁以上 |
| 脊柱 | 后凸或侧弯 | 学坐后 |

> 🧠 **口诀**："3~6月乒乓球，7~8月方脑袋，6月手镯和脚镯，1岁以上胸和腿"

### 4. X线典型表现
- 骨骺端钙化带模糊/消失
- **杯口状、毛刷状**改变
- 骨骺软骨带增宽（>2mm）

### 5. 治疗
- 口服为主：维生素D 2000~4000IU/d，1个月后改预防量400~800IU/d
- 肌内注射：维生素D₃ 15万~30万IU一次（适用于不能口服者）
- 补充钙剂

### 6. 预防
- 生后2周开始补充维生素D 400IU/d，持续至青春期

## 📌 四、蛋白质-能量营养不良

### 1. 临床表现
- 体重不增→**最早出现的症状**
- 皮下脂肪消失顺序：**腹部→躯干→臀部→四肢→面颊部**（最后消失的是面颊部！）
- 身高低于正常→反映慢性营养不良

### 2. 分型分度（5岁以下）

| 指标 | 意义 |
|------|------|
| **体重低下** | 反映**慢性或急性**营养不良 |
| **生长迟缓** | 反映**慢性长期**营养不良 |
| **消瘦** | 反映**近期、急性**营养不良 |

### 3. 并发症
- 自发性低血糖（清晨突然面色苍白、神志不清→首先考虑！）
- 维生素A缺乏（毕脱斑、角膜干燥）
- 感染

## 📌 五、单纯性肥胖 🔴（补充·教师明确要求）

### 1. 病因
- 能量摄入＞消耗（最主要）
- 遗传因素（多基因）
- 环境因素（膳食结构、久坐不动、屏幕时间↑）

### 2. 临床表现
- 体重超过同性别同身高参照值20%以上
- 皮下脂肪丰满，分布均匀
- 常有家族史
- 可伴有：黑棘皮病（胰岛素抵抗）、性发育提前

### 3. 诊断标准
- **BMI≥同年龄同性别P₉₅** → **肥胖**
- BMI在P₈₅~P₉₅ → 超重
- 需除外内分泌疾病（甲减、库欣综合征等）

### 4. 实验室检查
- 血脂：TG↑、TC↑
- 血糖：空腹血糖↑、胰岛素↑（胰岛素抵抗）
- 肝脏B超：脂肪肝

> ⚠️ **考试常考**：儿童肥胖诊断标准为BMI≥P₉₅（非成人标准BMI≥28）

## 📌 六、碘缺乏与甲状腺功能

- 碘是合成甲状腺激素的必需元素
- **碘缺乏→甲状腺激素合成↓→TSH↑→甲状腺肿大**
- 儿童碘缺乏可致：智力低下、生长发育迟缓
- 预防：碘盐、定期监测尿碘

# 第六章 新生儿与新生儿疾病 🔥🔥🔥🔥🔥

## 📌 一、新生儿分类（非常重要！）

### 1. 按胎龄分类（周数↔天数换算必考！）

| 分类 | 胎龄（周） | 胎龄（天） |
|------|----------|----------|
| **足月儿** | 37周≤GA<42周 | **259~293天** |
| 早产儿 | GA<37周 | <259天 |
| 过期产儿 | GA≥42周 | ≥294天 |

> ⚠️ **易错点**：考题常给天数不给周数！259天=37周，259~293天=足月儿。

### 2. 按出生体重分类

| 类型 | 标准 |
|------|------|
| 正常出生体重儿 | 2500~3999g |
| 低出生体重儿 | <2500g |
| 极低出生体重儿 | <1500g |
| 超低出生体重儿 | <1000g |
| 巨大儿 | ≥4000g |

### 3. 按胎龄与体重关系

| 类型 | 标准 |
|------|------|
| 小于胎龄儿（SGA） | 出生体重<同胎龄第10百分位 |
| 适于胎龄儿（AGA） | 第10~90百分位之间 |
| 大于胎龄儿（LGA） | >第90百分位 |

## 📌 六、新生儿呼吸窘迫综合征（RDS）

- **病因**：肺泡表面活性物质（PS）缺乏
- **高危因素**：早产（最主要）、糖尿病母亲婴儿、剖宫产
- **临床表现**：生后**6~12小时**内出现进行性呼吸困难、呻吟、三凹征
- **X线特征**：①毛玻璃样改变→②支气管充气征→③**白肺**
- **治疗**：PS替代治疗（经气管插管给药）+ CPAP/机械通气

## 📌 八、新生儿溶血病——换血原则 🔥🔥🔥

### 1. ABO vs Rh溶血比较

| 特点 | ABO溶血 | Rh溶血 |
|------|---------|--------|
| **母血型** | 多为O型 | Rh(-) |
| **新生儿血型** | A或B型 | Rh(+) |
| **第几胎** | 第一胎即可发生 | 一般第二胎 |
| **黄疸程度** | 较轻 | 较重 |

### 2. 换血疗法原则

> 🧠 **核心口诀**："Rh→Rh同母亲、ABO同患儿；ABO溶血→O型红细胞+AB型血浆"

- **换血量**：新生儿血容量的2倍（约150~180ml/kg）
- **Rh溶血病选血**：**Rh系统与母亲同型、ABO系统与患儿同型**
- **ABO溶血病选血**：O型红细胞+AB型血浆混合血

## 📌 九、新生儿败血症

### 1. 病原菌
- 早发型（生后7天内）：大肠杆菌为主，经母体感染
- 晚发型（生后7天后）：葡萄球菌、机会致病菌为主
- 国内最常见：**葡萄球菌**（凝固酶阴性葡萄球菌已超金葡菌）

### 2. 临床表现——"五不一低下"
- 不吃、不哭、不动、体温不升、体重不增、反应低下
- 黄疸加重或退而复现（有时是唯一表现）

## 📌 十、新生儿坏死性小肠结肠炎（NEC）

- **好发**：早产儿，生后2~3周
- **三联征**：腹胀（最早）+ 呕吐（胆汁样）+ 便血
- **X线特征**：**肠壁积气**（特征性）、门静脉积气、气腹（穿孔）
- 治疗：禁食（首要）、胃肠减压、抗感染

# 第7章 免疫缺陷病 🔴（补充·整章缺失）

> 📌 **教师明确要求！**原发性/继发性免疫缺陷病特点为考试必考点。

---

## 📌 一、原发性免疫缺陷病（PID）

### 1. 分类（按免疫缺陷类型）

| 类型 | 主要代表 | 关键特点 |
|------|---------|---------|
| **抗体缺陷为主**（最多，占50%以上） | **X-连锁无丙种球蛋白血症（XLA）** | Bruton酪氨酸激酶（BTK）突变→B细胞缺如→各型Ig↓↓；男婴，生后6个月后反复细菌感染 |
| | **婴儿暂时性低丙种球蛋白血症** | B细胞数量正常，IgG↓、IgA/IgM可正常或↓，随年龄增长可自行恢复 |
| **联合免疫缺陷（T+B）** | **严重联合免疫缺陷病（SCID）** | T细胞↓+B细胞↓/正常；生后早期严重感染，未治多在1岁内死亡 |
| | **DiGeorge综合征** | 22q11.2缺失→胸腺发育不良+甲状旁腺功能↓+心脏畸形+特殊面容 |
| **吞噬细胞缺陷** | 慢性肉芽肿病（CGD） | NADPH氧化酶缺陷→不能杀灭过氧化氢酶阳性菌 |
| **补体缺陷** | 遗传性血管性水肿（HAE） | C1酯酶抑制剂缺乏→反复血管性水肿 |

### 2. PID预警信号
1. 一年内≥8次中耳炎 2. 一年内≥2次严重鼻窦炎 3. 一年内≥2次肺炎 4. 反复深部皮肤/器官脓肿 5. 需静脉抗生素 6. ≥2处深部感染 7. 反复不典型病原菌感染 8. 婴儿期持续鹅口疮 9. PID家族史 10. 生长发育迟缓

---

## 📌 二、继发性免疫缺陷

| 原因 | 机制 |
|------|------|
| **感染**（HIV/AIDS、麻疹） | 直接破坏免疫细胞 |
| **营养不良** | 蛋白质-能量不足→T细胞功能↓ |
| **免疫抑制剂** | 抑制免疫细胞功能 |
| **恶性肿瘤** | 正常造血受抑 |
| 脾切除 | 清除病原体能力↓ |
| 蛋白丢失（肾病综合征） | Ig大量丢失 |

> ⚠️ **与原发性鉴别**：继发性有明确病因，去除病因后可恢复。

---

## 📌 三、诊断与治疗

- **诊断**：淋巴细胞亚群 + 免疫球蛋白定量 + 疫苗抗体反应 + 基因检测
- **治疗**：IVIG替代（抗体缺陷）、HSCT（重症PID）、预防感染（TMP-SMZ、避免活疫苗）

# 第八章 风湿性疾病 🔥🔥

---

## 📌 一、风湿热

### 1. 病因
- **A组乙型溶血性链球菌**（咽峡部感染后）

### 2. 临床表现——Jones诊断标准（5项主要表现 + 4项次要表现）

**5项主要表现**：
| 主要表现 | 特点 |
|---------|------|
| **心脏炎** | 最严重，可致风湿性心瓣膜病（二尖瓣最常受累） |
| **多发性关节炎** | 游走性、大关节、不留畸形 |
| **舞蹈症** | 无目的不自主运动 |
| **环形红斑** | 躯干和四肢近端，一过性 |
| **皮下小结** | 关节伸面，无痛 |

**4项次要表现**：发热、关节痛、血沉↑/CRP↑、PR间期延长

**诊断标准**：
- **2项主要**表现 → 高度可能
- **1项主要 + 2项次要** + 链球菌感染证据 → 可诊断

**链球菌感染证据**：咽拭子培养A组链球菌(+) / 抗链球菌抗体滴度↑（ASO↑）

### 3. 治疗
- 清除链球菌：青霉素
- 抗风湿：阿司匹林（无心脏炎）或泼尼松（心脏炎）
- 预防复发：苄星青霉素（长效青霉素），至少5年

## 📌 二、川崎病 🔥🔥🔥

### 1. 诊断标准——发热+以下5项中≥4项

1. **双侧球结膜充血**（非化脓性）
2. **口腔黏膜改变**（草莓舌、口唇皲裂/充血）
3. **多形皮疹**
4. **四肢末端变化**：急性期手足硬肿、掌跖红斑；恢复期指（趾）端膜状脱皮（特征性！）
5. **颈部非化脓性淋巴结肿大**

### 2. 治疗——两种关键药物

| 药物 | 用法 | 目的 |
|------|------|------|
| **阿司匹林** | 大剂量（急性期30~50mg/kg/d）→小剂量（3~5mg/kg/d） | 抗炎+抗血小板聚集 |
| **IVIG**（丙种球蛋白） | 2g/kg，一次输注 | 预防冠脉瘤（核心！发病10天内用） |

### 3. 难治性川崎病与糖皮质激素 🟡

- **IVIG无反应型**（约10%~20%）：首次IVIG 36h后仍发热
- 此型可加用**糖皮质激素**：甲泼尼龙冲击（30mg/kg/d×1~3d）或泼尼松口服
- ⚠️ 现行指南：糖皮质激素并非川崎病禁忌，可用于IVIG无反应型或高危患者
- 其他二线：英夫利昔单抗（TNF-α拮抗剂）

### 4. 预后
- 自限性疾病，多数预后良好
- 冠脉瘤→猝死风险；未经治疗者冠脉损害率15%~25%

- **传播途径**：**飞沫传播**（呼吸道）

## 📌 二、腹泻病——整节重点，大题常考 🔥🔥🔥🔥🔥

### 1. 按病程分类

| 分类 | 病程 |
|------|------|
| 急性腹泻 | <2周 |
| 迁延性腹泻 | 2周~2个月 |
| 慢性腹泻 | >2个月 |

### 2. 按病因分型及机制

| 类型 | 机制 | 代表病原 | 大便特点 |
|------|------|---------|---------|
| **分泌性腹泻** | 肠黏膜分泌增加（cAMP↑→Cl⁻分泌↑） | 霍乱弧菌、**产毒性大肠杆菌（ETEC）** | **大量水样便、无脓血、禁食后不停止** |

| **渗透性腹泻** | 肠腔内渗透压升高 | **轮状病毒**（双糖酶活性↓→乳糖堆积） | 酸味、有泡沫、**禁食后减轻** |
| 吸收不良性腹泻 | 吸收面积减少 | 乳糜泻 | 脂肪泻、恶臭 |
| 动力性腹泻 | 肠道蠕动过快 | 肠易激综合征 | 水样便+腹痛 |

### 3. 轮状病毒肠炎——秋季腹泻

| 项目 | 内容 |
|------|------|
| 病原 | 轮状病毒（HRV） |
| 好发季节 | 秋冬寒冷季节 |
| 好发年龄 | **6个月~2岁** |
| 临床表现 | **先吐后泻**，蛋花汤样或水样便，无腥臭，常伴发热和上感症状 |
| 机制 | 破坏小肠绒毛上皮细胞→双糖酶活性↓→渗透性腹泻 |
| 并发症 | 脱水（等渗或低渗）、电解质紊乱 |
| 病程 | 自限性，3~8天 |

### 4. 几种腹泻大便特点速记

> 🧠 **鉴别口诀**：
> "水样泻+WBC不高=病毒性肠炎（轮状病毒）"
> "脓血便+WBC升高=细菌性肠炎（侵袭性）"

> "长期用抗生素+黄绿色便=金葡菌性肠炎"

## 📌 三、炎症性肠病（IBD）——克罗恩病 vs 溃疡性结肠炎 🔴（补充·表10-1）

| 鉴别点 | 克罗恩病（CD） | 溃疡性结肠炎（UC） |
|--------|--------------|-------------------|
| **病变部位** | 回肠末端+右半结肠为主 | 直肠开始，向近端蔓延 |

## 📌 七、婴儿胆汁淤积症 🟡（补充·教师要求）

### 1. 定义
- 生后3个月内出现黄疸，直接胆红素↑>20%总胆红素

### 2. 临床表现（三联征）
1. **黄疸**（结合胆红素↑为主）
2. **白陶土样大便**（胆道梗阻标志）
3. **肝大**（质地硬）

### 3. 关键检查
- 血清总胆汁酸↑↑（最敏感指标之一）
- GGT↑↑（≥300U/L强烈提示胆道闭锁）
- 肝胆B超：胆道闭锁→胆囊缺如或发育不良
- 十二指肠引流：无胆汁→胆道闭锁

### 4. 鉴别（最重要）
| 鉴别点 | 胆道闭锁 | 婴儿肝炎综合征 |
|--------|---------|--------------|
| 大便 | 出生即白陶土便，持续不退 | 黄疸波动，便色可变 |
| 肝大 | 进行性增大、硬化 | 轻中度增大 |
| GGT | 明显升高 | 轻中度升高 |
| 治疗 | 肝门空肠吻合术（Kasai术）<生后60天效果最好 | 对症支持 |

> ⚠️ **考试关键**：胆道闭锁需在生后60天内手术（Kasai术），否则进展为胆汁性肝硬化！

|------|---------|
| **Ⅰ度** | 活动后出现吸气性喉鸣和呼吸困难，肺部听诊呼吸音及心率无改变 |
| **Ⅱ度** | **安静时**亦出现喉鸣和吸气性呼吸困难，肺部可闻及喉传导音或管状呼吸音，心率加快 |
| **Ⅲ度** | 缺氧→**烦躁不安、口唇发绀、惊恐**、出汗，肺部呼吸音明显降低，心率快，心音低钝 |
| **Ⅳ度** | 渐显**衰竭、昏睡状态**，面色苍白发灰，三凹征反不明显，肺部呼吸音几乎消失，可有心律不齐，心音钝弱 |

> ⚠️ **治疗关键**：Ⅱ度以上喉梗阻→糖皮质激素（减轻喉头水肿）；Ⅲ度以上→气管插管。

## 📌 二、两种特殊类型上呼吸道感染 🔴（补充·必考）

| 类型 | 病原体 | 临床表现 |
|------|--------|---------|
| **疱疹性咽峡炎** | **柯萨奇A组病毒** | 高热、咽痛；咽峡部**灰白色疱疹**（2~4mm），周围有红晕，破溃后形成小溃疡；病程约1周 |
| **咽结合膜热** | **腺病毒3型/7型** | 发热+**咽炎**+**滤泡性结膜炎**（三联征）；一侧或双侧球结膜充血，但无分泌物；可伴耳后淋巴结肿大；病程1~2周 |

> 🧠 **口诀**："柯萨奇疱疹咽峡，腺病毒感染眼红加咽炎"  
> ⚠️ **常考**：疱疹性咽峡炎的疱疹位于咽峡部（与手足口病不同！），病原是柯萨奇A组病毒。

## 📌 三、毛细支气管炎 🔥🔥🔥

| 项目 | 内容 |
|------|------|
| 病原 | **呼吸道合胞病毒（RSV）** ← 最常见 |
| 好发年龄 | **2~6个月婴儿** |
| 临床特点 | **喘憋**、呼气性呼吸困难、双肺哮鸣音 |
| 胸部X线 | 肺气肿、肺纹理增粗 |
| 治疗 | 支持对症为主；不推荐常规使用糖皮质激素 |

> 🧠 **口诀**："小婴儿（2~6月）+ RSV + 喘憋→毛细支气管炎"

## 📌 三、肺炎——不同病原体胸部X线鉴别 🔥🔥🔥🔥🔥

> 🅲️ **大题核心**：不同病原体肺炎的X线表现鉴别表必须牢记！

| 病原体 | 好发年龄 | 热型 | 咳嗽特点 | **X线特征**（核心考点） |
|--------|---------|------|---------|----------------------|
| **呼吸道合胞病毒** | 婴幼儿 | 低中度热 | 喘憋明显 | 点片状、斑片状影；肺气肿 |
| **腺病毒** | 6月~2岁 | 稽留高热 | 阵发性干咳 | **片状融合影**、肺实变；病变吸收慢（数周至数月） |
| **肺炎链球菌** | 年长儿 | 稽留高热 | 铁锈色痰 | 大叶性肺炎（节段性实变） |
| **金黄色葡萄球菌** | 婴儿 | 弛张高热 | 黄脓痰 | **多发小脓肿、肺大疱、脓气胸**（易变、多变） |
| **肺炎支原体** | 学龄儿童 | 不规则热 | **刺激性干咳**（咳嗽剧烈但肺部体征轻微） | 肺门影增浓、**云雾状/淡薄浸润影**、游走性 |
| **沙眼衣原体** | 1~3月婴儿 | 无热或低热 | — | 间质性肺炎、过度充气 |

> 🧠 **超级口诀**：
> "合胞点片肺气肿，腺病毒片状融合难吸收；
> 金葡脓肿肺大疱，支原体云雾与体征不匹配"
> 
> **支原体肺炎特征**：**"体征轻、X线重、咳嗽剧烈"**（体征与胸片不一致！）

## 📌 四、支气管哮喘 🔥🔥🔥

### 1. 诊断标准（儿童哮喘）

1. 反复发作喘息、咳嗽、气促、胸闷，多与接触过敏原/冷空气/运动等有关
2. 发作时双肺可闻及弥漫性呼气相哮鸣音
3. 症状和体征可经治疗缓解或自行缓解
4. 除外其他疾病
5. **肺功能检查**：支气管舒张试验阳性（FEV₁增加≥12%）或PEF变异率≥13%

### 2. 咳嗽变异性哮喘（CVA）诊断标准

1. 咳嗽持续>4周，多为干咳，夜间/凌晨加重
2. 无感染征象，抗生素治疗无效
3. **抗哮喘治疗有效**
4. 除外其他慢性咳嗽

### 3. 哮喘急性发作治疗

| 药物 | 用法 |
|------|------|
| **SABA**（沙丁胺醇） | 首选，吸入 |
| **糖皮质激素** | 中重度发作时口服/静脉（泼尼松1~2mg/kg/d） |
| 抗胆碱能药物 | 中重度联合使用 |

> 🔑 疱疹性咽峡炎=柯萨奇A组 | 咽结合膜热=腺病毒3/7型 | 毛细支气管炎=RSV(2~6月)
> ⚠️ 支原体肺炎=体征轻X线重+顽固干咳+大环内酯类；喉梗阻Ⅲ度→气管插管
> 💡 金葡菌→脓肿肺大疱；腺病毒→融合影+BO后遗症；合胞→点片+肺气肿

# 第十一章 心血管系统疾病 🔥🔥🔥

> 🅰️🅱️🅲️ **先心病是整章重点**：四种常见先心病的杂音位置、X线特征、P₂变化是"必杀题"。

---

## 📌 一、心脏胚胎发育与出生后血循环变化 🟡（补充·教师要求）

### 胎儿血循环特点
- 气体交换在**胎盘**完成（非肺）
- 三大通道：
  1. **卵圆孔**——右房→左房（生后5~7个月解剖关闭）
  2. **动脉导管**——肺动脉→主动脉（生后10~15h功能关闭，3个月内解剖关闭）
  3. **静脉导管**——脐静脉→下腔静脉（生后7天关闭）
- 胎儿右心室承担约2/3心脏输出量

### 出生后血循环变化
- 脐带结扎→胎盘循环终止→体循环阻力↑
- 肺膨胀→肺血管阻力↓→肺血流↑
- 左房压力↑→卵圆孔功能关闭
- 动脉导管PO₂↑→导管平滑肌收缩→关闭

> ⚠️ **易考**：卵圆孔和动脉导管未及时关闭是新生儿期常见问题（早产儿PDA常见）。吲哚美辛/布洛芬促进PDA关闭。

---

## 📌 二、先天性心脏病分类

| 类型 | 血流特点 | 代表疾病 | 有无发绀 |
|------|---------|---------|---------|
| **左向右分流**（潜伏发绀型） | 左心→右心（体循环→肺循环） | **室缺（VSD）> 房缺（ASD）> 动脉导管未闭（PDA）** | 无（哭闹时可有） |
| **右向左分流**（发绀型） | 右心→左心（肺循环→体循环） | **法洛四联症（TOF）**、大动脉转位 | 有 |
| **无分流型** | 无异常通道 | 肺动脉瓣狭窄、主动脉缩窄 | 无 |

---

## 📌 二、四种常见先心病核心鉴别表 🔥🔥🔥🔥🔥

### 最全鉴别表（必背！）

| 鉴别点 | 房间隔缺损（ASD） | 室间隔缺损（VSD） | 动脉导管未闭（PDA） | 法洛四联症（TOF） |
|--------|------------------|------------------|--------------------|------------------|
| **发病率** | 5%~10% | **最多见（50%）** | 10% | 最常见的**发绀型** |
| **杂音位置** | L2（第2肋间） | **L3~4（第3、4肋间）** | **L2** | L2~4 |
| **杂音性质** | 收缩期喷射性 | **全收缩期粗糙杂音** | **连续性"机器样"杂音** | 收缩期喷射性 |
| **震颤** | 可有 | 可有 | 可有 | 可有 |
| **P₂（肺动脉第二心音）** | **亢进、固定分裂**（特征！） | 亢进 | 亢进 | **减弱** |
| **X线** | 肺血多，肺动脉段凸出，主动脉结小，"梨形心" | 肺血多，左右室大 | 肺血多，主动脉结增大 | **肺血少**，肺动脉段凹陷，**"靴形心"** |
| **房室增大** | 右房、右室大 | 左室、右室大（双室大） | 左房、左室大 | 右室大，心尖上翘 |
| **肺门舞蹈** | 有 | 有 | 有 | 无 |
| **特有体征** | P₂固定分裂 | — | **周围血管征**（脉压增大、水冲脉、枪击音）、**差异性发绀** | **青紫+杵状指+蹲踞** |

> 🧠 **杂音口诀**："房缺L2收缩喷射，室缺L3~4全收缩；PDA L2连续机器样，法洛四联L2~4收缩喷射但P₂减弱"

### 各病特征速记

| 疾病 | 核心记忆点 |
|------|----------|
| **ASD** | P₂固定分裂（唯一！不受呼吸影响） |
| **VSD** | 最多见先心病；L3~4全收缩期粗糙杂音 |
| **PDA** | 连续性机器样杂音；**差异性发绀**（下半身青紫）；早产儿可用**吲哚美辛**关闭 |
| **TOF** | 四种畸形：肺动脉狭窄+室缺+主动脉骑跨+右室肥厚；**蹲踞**（特征性体位）；缺氧发作→膝胸卧位+普萘洛尔 |

---

## 📌 三、法洛四联症缺氧发作的处理

> 🧠 **口诀**："膝胸卧位吸氧吗啡，普萘洛尔纠酸补液"

1. **膝胸卧位**
2. 吸氧
3. **吗啡**皮下注射（0.1~0.2mg/kg）
4. **普萘洛尔**（心得安）静脉注射
5. 5%碳酸氢钠纠正酸中毒

---


> ⚡ **心血管系统·速记卡**
> 🔑 VSD最多见+L3~4全收缩期 | ASD=L2+P₂固定分裂 | PDA=L2+连续性机器样 | TOF=发绀+靴形心+肺血少
> ⚠️ 卵圆孔5~7月解剖关闭；动脉导管10~15h功能关闭/3月内解剖关闭
> 💡 TOF缺氧发作=膝胸卧位+吗啡+普萘洛尔+纠酸

# 第十二章 泌尿系统疾病 🔥🔥🔥

---

## 📌 一、急性肾小球肾炎 🔥🔥🔥

### 1. 病因
- **A组β型溶血性链球菌**（"致肾炎菌株"）——咽部或皮肤感染后

### 2. 临床表现

| 表现 | 特点 |
|------|------|
| **水肿** | **非凹陷性**（水钠潴留），最早出现，眼睑/颜面→全身 |
| **血尿** | 肉眼血尿（30%~50%）→洗肉水色 |
| 蛋白尿 | 轻~中度（非肾病水平，<50mg/kg/d） |
| **高血压** | 轻~中度，可致高血压脑病 |
| 尿量减少 | 可致急性肾衰竭 |

### 3. 严重并发症（三大）

| 并发症 | 临床表现 |
|--------|---------|
| **严重循环充血** | 酷似心衰（水钠潴留→血容量↑） |
| **高血压脑病** | 血压突然升高→头痛、惊厥 |
| **急性肾功能不全** | 少尿/无尿、氮质血症 |

### 4. 实验室检查

| 检查 | 变化 |
|------|------|
| **补体C3** | **↓降低**，6~8周恢复正常（超过8周不恢复→考虑其他肾炎） |
| ASO | 升高（链球菌感染证据） |
| 尿常规 | 红细胞+，蛋白+~+++ |

---

## 📌 二、肾病综合征 🔥🔥🔥

### 1. 诊断标准——"三高一低"

| 项目 | 标准 |
|------|------|
| **大量蛋白尿** | 24小时尿蛋白≥50mg/kg（定性+++~++++） |
| **低白蛋白血症** | 血浆白蛋白<30g/L |
| **高脂血症** | 血浆胆固醇>5.7mmol/L |
| **水肿** | 凹陷性水肿 |

### 2. 急性肾小球肾炎 vs 肾病综合征鉴别（大题常考！）

| 鉴别点 | 急性肾小球肾炎 | 肾病综合征 |
|--------|--------------|-----------|
| **水肿** | **非凹陷性**（水钠潴留） | **凹陷性**（低蛋白血症） |
| **蛋白尿** | 轻~中度（<50mg/kg/d） | **大量**（≥50mg/kg/d） |
| **血尿** | **必有**（肉眼或镜下） | 可有镜下血尿 |
| **低蛋白血症** | 无 | **有** |
| 高脂血症 | 无 | **有** |
| **补体C3** | **降低** | 正常（微小病变型） |
| 高血压 | 常见 | 多正常 |
| **治疗** | 对症（限盐限水+利尿） | **糖皮质激素**（首选泼尼松） |

### 3. 肾病综合征并发症

| 并发症 | 要点 |
|--------|------|
| **感染** | 最常见并发症（上呼吸道感染最多） |
| 电解质紊乱 | 低钠、低钾、低钙 |
| **血栓形成** | 肾静脉血栓最常见（突发腰痛+血尿） |
| 急性肾损伤 | — |

### 4. 激素治疗
- **首选**：泼尼松（中长程疗法）
- 初治：2mg/(kg·d)，分次口服，4周内转阴后巩固2周
- 总疗程：中程6个月，长程9个月

> ⚡ **泌尿系统·速记卡**
> 🔑 NS诊断=大量蛋白尿(≥50mg/kg/d)+低白蛋白(<30g/L)；C3正常
> ⚠️ AGN水肿=非凹陷性(水钠潴留)；NS水肿=凹陷性(低蛋白血症)
> 💡 AGN补体C3↓→6~8周恢复；NS首选泼尼松中长程疗法

# 第十三章 血液系统疾病 🔥🔥🔥

---

## 📌 一、白细胞分类——两次交叉 🔥🔥🔥🔥

| 交叉 | 时间 | 变化 |
|------|------|------|
| **第一次交叉** | **生后4~6天** | 中性粒细胞↓ = 淋巴细胞↑ |
| **第二次交叉** | **4~6岁** | 中性粒细胞↑ = 淋巴细胞↓→成人水平 |

> 🧠 **口诀**："第一次在'天'，第二次在'岁'；两头大，中间小，4~6天和4~6岁"

**出生时**：中性粒细胞占优势（约65%）
**生后4~6天→第一次交叉**：淋巴细胞占优势（持续至4~6岁）
**4~6岁→第二次交叉**：中性粒细胞再次占优势

---

## 📌 二、生理性贫血
- **时间**：生后2~3个月
- **Hb最低点**：约100g/L
- 自限性，无需特殊处理

---

## 📌 三、缺铁性贫血（IDA）🔥🔥🔥🔥

### 1. 铁代谢检查——"四步记忆"

| 指标 | 变化 | 说明 |
|------|------|------|
| **血清铁蛋白（SF）** | **↓↓** | 最早和最敏感指标 |
| 血清铁（SI） | ↓ | — |
| **总铁结合力（TIBC）** | **↑** | 代偿性增加 |
| 转铁蛋白饱和度（TS） | ↓（<15%） | — |

> ⚠️ **易错点**：TIBC是**升高**的，不是降低！

### 2. 血象特点
- **小细胞低色素性贫血**：MCV↓、MCH↓、MCHC↓
- 血涂片：红细胞大小不等，中央淡染区扩大

### 3. 治疗

| 项目 | 内容 |
|------|------|
| 铁剂 | **口服二价铁**（硫酸亚铁等），元素铁4~6mg/(kg·d)，分2~3次 |
| 服用时间 | **两餐之间** |
| 配伍 | 加服**维生素C**促进吸收 |
| 禁忌同服 | 牛奶、茶、咖啡、抗酸药 |
| **疗效判断** | **网织红细胞**最早上升（2~3天↑，5~7天达高峰）|
| 停药时机 | 血红蛋白正常后**继续服6~8周**（补充储存铁） |

---

## 📌 四、地中海贫血 vs 缺铁性贫血 🔥🔥🔥🔥

| 鉴别点 | 缺铁性贫血 | 地中海贫血 |
|--------|----------|-----------|
| **SI（血清铁）** | ↓ | **正常或↑**（关键鉴别点！） |
| **TIBC** | ↑ | 正常 |
| **SF（铁蛋白）** | ↓ | 正常或↑ |
| **血红蛋白电泳** | 正常 | HbA₂↑和/或HbF↑ |
| **治疗** | **铁剂** | **禁铁剂！**（警惕含铁血黄素沉着症） |
| 输血 | 必要时 | 重型需**定期输血**+去铁治疗 |

> ⚠️ **易错点**：地中海贫血是**小细胞低色素性贫血但SI不低**！误补铁剂会加重铁负荷！

---

## 📌 五、营养性巨幼细胞性贫血

| 项目 | 内容 |
|------|------|
| 病因 | 维生素B₁₂和/或叶酸缺乏 |
| 血象 | **大细胞性贫血**（MCV↑>94fL、MCH↑） |
| 骨髓象 | **巨幼变**——红系/粒系/巨核系均可出现巨幼变；红系增生为主，原红+早幼红↑ |
| 特征性表现 | **神经精神症状**（维生素B₁₂缺乏→震颤、反应迟钝、智力倒退） |
| 血涂片 | 红细胞体积大、中性粒细胞**分叶过多**（≥5叶者有诊断意义） |
| 治疗 | 维生素B₁₂ + 叶酸；有神经系统症状者以B₁₂为主；**不宜单用叶酸**（会加重神经系统损害！） |

> ⚠️ **易错点**：不能单用叶酸治疗B₁₂缺乏！会消耗更多B₁₂→加重神经症状。

---

## 📌 六、免疫性血小板减少症（ITP）🔴（补充·教师明确要求）

### 1. 病因
- **免疫介导**——产生抗血小板抗体→血小板破坏↑
- 诱因：病毒感染（上感/疫苗接种后1~3周）
- 好发年龄：2~5岁

### 2. 临床表现
- **皮肤黏膜出血**为主：瘀点、瘀斑、鼻衄、牙龈出血
- 自发性出血风险：PLT<**50×10⁹/L**时活动性出血；PLT<**20×10⁹/L**时严重出血
- 肝脾淋巴结**不大**（与白血病鉴别的关键！）
- 病程：自限性，80%~90%在6个月内自行缓解

### 3. 实验室检查
| 检查 | 结果 |
|------|------|
| 血小板计数 | ↓↓ |
| 骨髓象 | **巨核细胞数正常或增多**（伴成熟障碍） |
| 血小板抗体 | 可检出PAIgG |
| 其他血象 | WBC、Hb正常（出血严重者可贫血） |

### 4. 治疗
| 情况 | 方案 |
|------|------|
| PLT≥20×10⁹/L且无活动性出血 | **观察随访**，不需治疗 |
| 一线 | **糖皮质激素**（泼尼松1.5~2mg/kg/d）或**IVIG**（0.4g/kg/d×5d或1g/kg/d×2d） |
| 二线/慢性 | 利妥昔单抗、促血小板生成素受体激动剂（TPO-RA）、脾切除 |

> ⚠️ **与过敏性紫癜鉴别关键**：ITP血小板↓，过敏性紫癜血小板正常/↑！

## 📌 七、急性白血病 🔴🔴🔴（补充·教师重点）

### 1. 分类分型
| 分类 | 亚型 | 占比 |
|------|------|:---:|
| **急性淋巴细胞白血病（ALL）** | B-ALL（80%~90%）、T-ALL | **约75%~80%** |
| **急性髓系白血病（AML）** | M0~M7（FAB分类） | 约15%~20% |

- ALL是儿童最常见的恶性肿瘤

### 2. 临床表现——"四联征"
| 表现 | 机制 |
|------|------|
| **发热** | 白血病细胞本身或继发感染（最常见就诊原因） |
| **贫血** | 骨髓红系受抑→面色苍白、乏力 |
| **出血** | 血小板↓→瘀斑、鼻衄、牙龈出血 |
| **浸润** | ①骨痛（白血病细胞浸润骨膜，下肢长骨+脊柱最常见）<br>②肝脾淋巴结肿大<br>③CNS白血病（头痛、呕吐、脑膜刺激征）<br>④睾丸白血病（无痛性肿大） |

### 3. 实验室检查
| 检查 | 结果 |
|------|------|
| 血象 | 正细胞正色素贫血+PLT↓+WBC可高/正常/低；可见**原始和幼稚细胞** |
| **骨髓象**（确诊！） | **原始+幼稚细胞≥20%**；涂片+组化染色+免疫分型+染色体 |
| MICM分型 | 形态学+免疫学+细胞遗传学+分子生物学（现代分型金标准） |

### 4. 治疗（ALL为例）
- 化疗：诱导缓解→巩固→维持（总疗程约2.5~3年）
- CNS白血病预防：鞘内注射MTX+Ara-C+头颅放疗（高危）
- 造血干细胞移植：高危/复发ALL

> ⚠️ **考试题眼**："发热+贫血+出血+肝脾淋巴结大+血涂片原始细胞"→急性白血病；确诊靠骨髓涂片。

---


> ⚡ **血液系统·速记卡**
> 🔑 WBC交叉=4~6天+4~6岁 | IDA=小细胞低色素+SF↓+TIBC↑ | 地贫=小细胞低色素但SI不低
> ⚠️ ITP=血小板↓+巨核细胞↑+激素/IVIG；ALL=发热+贫血+出血+浸润+骨髓原始≥20%
> 💡 铁剂有效最早=网织红细胞(2~3d↑)；Hb正常后继续服6~8周

# 第十四章 神经肌肉系统疾病 🔥🔥🔥

## 📌 一、急性细菌性脑膜炎（化脓性脑膜炎）

### 1. 常见病原菌（按年龄）

| 年龄 | 常见病原 |
|------|---------|
| 新生儿 | 大肠杆菌、B组链球菌（GBS）、李斯特菌 |
| 婴幼儿（2月~2岁） | **肺炎链球菌**、脑膜炎奈瑟菌（流脑）、流感嗜血杆菌b型 |
| 年长儿 | 脑膜炎奈瑟菌、肺炎链球菌 |

### 2. 临床表现（三联征）
- 发热
- **颅内压增高**：头痛、呕吐、前囟饱满
- **脑膜刺激征**（+）：颈项强直、Kernig征、Brudzinski征

### 3. 并发症
- **硬膜下积液/积脓**（最常见，1岁以内婴儿多见）
- 脑室管膜炎
- **脑积水**
- 脑脓肿

---

## 📌 二、三种脑膜炎脑脊液鉴别——表15-2 🔥🔥🔥🔥🔥

> 🅲️ **必考大题**：化脑、病脑、结脑的CSF鉴别表是"儿科经典题库"！

| 项目 | **化脓性脑膜炎** | **病毒性脑膜炎** | **结核性脑膜炎** |
|------|----------------|----------------|----------------|
| **外观** | **浑浊/脓性**（米汤样） | 清亮 | **毛玻璃样**，静置后有薄膜 |
| 压力 | ↑↑ | 正常或↑ | ↑ |
| **白细胞** | **显著↑↑**（数百~数千） | ↑（数十~数百） | ↑（数十~数百） |
| **白细胞分类** | **中性粒细胞为主** | **淋巴细胞为主** | **淋巴细胞为主** |
| **蛋白质** | **↑↑**（>1g/L） | 正常或↑ | **↑↑**（1~3g/L） |
| **糖** | **↓↓**（可为零） | **正常** | **↓↓** |
| **氯化物** | ↓ | **正常** | **↓↓**（最有特征） |
| 病原体检查 | 涂片/培养找到细菌 | 阴性 | 抗酸染色找到结核杆菌 |

> 🧠 **超级口诀**：
> "化脑：浑浊米汤样，糖低氯低蛋白高，中性为主
> 病脑：清亮透明，糖氯正常蛋白微增，淋巴为主
> 结脑：毛玻璃薄膜，**糖和氯化物同步降**，淋巴为主"

> ⚠️ **易错点**：病毒性脑膜炎**糖和氯化物正常**！这是与化脑/结脑最关键鉴别点。

---

### 硬膜下积液诊断（化脑最常见并发症）

"**好了好了又重了**"——体温退而复升+前囟持续隆起+惊厥反复
- **特征性检查**：硬膜下穿刺（确诊+治疗）
- 正常婴儿硬膜下积液量<2ml

---

## 📌 三、病毒性脑膜炎 🟡（补充·独立临床表现）

### 临床特征
- 起病较急，但较化脑轻
- 发热、头痛、呕吐、烦躁或嗜睡
- **脑膜刺激征（+）**：颈项强直、Kernig征(+)
- **意识障碍轻**（与化脑/结脑的重要区别）
- 病程较短，一般1~2周自愈，绝大多数预后良好

> ⚠️ CSF鉴别见上表——关键记忆：**病脑糖和氯化物正常**！

---

## 📌 四、热性惊厥

- **好发年龄**：**6个月~5岁**（高峰18个月）
- 与发热相关（体温>38℃），排除颅内感染

| 特点 | 单纯型 | 复杂型 |
|------|--------|--------|
| 发作形式 | **全面性** | 局灶性 |
| 持续时间 | <15分钟 | ≥15分钟 |
| 24h内发作 | 1次 | ≥2次 |

---


> ⚡ **神经肌肉系统·速记卡**
> 🔑 化脑CSF=浑浊+中性粒+糖↓↓ | 病脑=清亮+淋巴+糖正常 | 结脑=毛玻璃+淋巴+糖↓↓+氯化物↓↓
> ⚠️ 单纯型热性惊厥=6月~5岁+全面性+<
min+24h仅1次+不需长期用药
> 💡 化脑最常见并发症=硬膜下积液；"好了好了又重了"→穿刺确诊

# 第十五章 内分泌疾病 🔥🔥

## 📌 一、先天性甲状腺功能减退症（甲减/呆小病）🔥🔥🔥

### 1. 临床表现（特征性）

| 时期 | 表现 |
|------|------|
| **新生儿期** | **生理性黄疸延长**、腹胀便秘、少吃少哭、体温低（"三超三少五低"） |
| **6个月后典型表现** | **特殊面容**：头大、鼻梁低平、眼距宽、**舌大伸出口外**<br>**生长发育迟缓**（非匀称性矮小）<br>**智力低下**（不可逆！）<br>代谢低下：怕冷、少汗、便秘、心率慢 |

### 2. 筛查与诊断

| 方法 | 说明 |
|------|------|
| **新生儿筛查** | 足跟血TSH（生后2~3天），TSH↑→阳性 |
| 确诊 | 血清T₄↓、TSH↑ |

### 3. 治疗
- **终身服用L-甲状腺素钠**
- 起始剂量：8~10μg/(kg·d)
- **越早治疗预后越好**（生后3个月内开始治疗→智力可正常）
- 6个月后才治疗→智力受损不可逆

## 📌 二、生长激素缺乏症（GHD）

- 临床表现：**匀称性矮小**、身高低于P₃、生长速率<5cm/年、**智力正常**
- 诊断：需两种药物刺激试验GH峰值均<10μg/L
- 治疗：rhGH皮下注射，每晚睡前

|------|------|
| 定义 | **女孩<7.5岁、男孩<9岁**出现第二性征 |

## 📌 四、儿童糖尿病 🔴🔴（补充·教师明确要求）

### 1. 定义与分型
- 儿童糖尿病以**1型糖尿病（T1DM）**占绝大多数（>90%）
- T1DM：胰岛β细胞自身免疫破坏→胰岛素绝对缺乏
- 好发年龄：学龄前期和青春期（两个高峰）

### 2. 临床表现
- **"三多一少"**：多饮、多尿、多食、体重下降（消瘦）
- 夜尿增多或遗尿（有时是首发表现）
- 约20%~40%患儿以**DKA（糖尿病酮症酸中毒）**为首发表现

### 3. 实验室检查
| 检查 | 诊断标准 |
|------|---------|
| **空腹血糖** | ≥7.0mmol/L |
| **随机血糖** | ≥11.1mmol/L + 三多一少症状 |
| **OGTT 2h血糖** | ≥11.1mmol/L |
| HbA1c | ↑（>6.5%） |
| 尿糖 | + |
| 尿酮体 | +（DKA时） |
| **胰岛自身抗体** | ICA、GAD65、IA-2、IAA(IAA/IAA阳性支持T1DM) |

### 4. DKA的识别（急症！）
| 表现 | 特点 |
|------|------|
| 脱水 | 中~重度脱水体征 |
| 酸中毒 | Kussmaul呼吸（深大呼吸）、呼气有**烂苹果味**（丙酮） |
| 电解质紊乱 | 低钠、低钾（总体钾缺乏但血钾可正常） |
| 意识改变 | 嗜睡→昏迷 |

### 5. 治疗原则
| 治疗 | 内容 |
|------|------|
| **胰岛素** | 终身使用——基础量+餐前追加量（MDI方案）或胰岛素泵 |
| 饮食管理 | 控制总热量，碳水化合物50%~55%，脂肪<30%，蛋白质15%~20% |
| 运动 | 规律运动，注意防低血糖 |
| DKA治疗 | 补液（等张液）+胰岛素（0.1U/kg/h静脉）+纠正电解质+监测血糖/血气 |

> ⚠️ **考试要点**：儿童糖尿病多是1型，"三多一少"+消瘦；DKA是常见首发表现；终身需胰岛素治疗（不能用口服降糖药替代！）

---


> ⚡ **内分泌·速记卡**
> 🔑 甲减=TSH↑+T₄↓+终身LT₄ | 性早熟=女<.5岁(十版)/男<\9岁
> ⚠️ 甲减：生后3月内治疗→智力正常；3月后治疗→不可逆！
> 💡 儿童糖尿病=1型为主+"三多一少"+DKA首发+终身胰岛素

# 第十六章 遗传性疾病 🔥🔥🔥

---

## 📌 一、21-三体综合征（Down综合征/唐氏综合征）🔥🔥🔥

### 1. 临床表现——"唐氏面容"
- 眼距宽、眼裂小、外眼角上斜、鼻梁低平
- **舌大伸出口外**、耳小低位
- **通贯掌**（猿线）
- 智力低下（最主要问题）
- **先天性心脏病**（室缺、房室间隔缺损）
- 肌张力低下

### 2. 核型分类 🔥🔥🔥

| 类型 | 核型 | 占比 |
|------|------|------|
| **标准型** | 47,XX(XY),+21 | **约95%** |
| **易位型** | 46,XX(XY),der(14;21)(q10;q10),+21（多为罗伯逊易位） | 约3%~4% |
| **嵌合型** | 46/47,+21 | 约1%~2% |

> ⚠️ **易错点**：易位型中若为21/21易位或父母为平衡易位携带者，**再发风险高**。

### 3. 产前筛查
- 孕母血清学筛查：β-HCG↑、AFP↓、FE₃↓
- 无创产前检测（NIPT）
- 确诊：羊水染色体核型分析

---

## 📌 二、苯丙酮尿症（PKU）🔥🔥🔥🔥🔥

### 1. 遗传方式
- **常染色体隐性遗传**

### 2. 病因
- **苯丙氨酸羟化酶（PAH）缺乏**（经典型）→苯丙氨酸不能转化为酪氨酸
- 少数为BH₄（四氢生物蝶呤）缺乏

### 3. 临床表现
| 项目 | 内容 |
|------|------|
| 出生时 | 正常 |
| 3~6个月后 | 智力发育迟缓、行为异常 |
| **特殊气味** | **鼠尿味/霉臭味**（尿和汗液中苯乙酸↑） |
| 外貌 | 皮肤白、头发黄（酪氨酸↓→黑色素合成↓） |
| 其他 | 湿疹、呕吐 |

### 4. 诊断

| 方法 | 说明 |
|------|------|
| **新生儿筛查** | Guthrie试验（哺乳3天以上采血） |
| 确诊 | 血苯丙氨酸（Phe）浓度↑（>1200μmol/L） |
| 尿筛查 | 尿三氯化铁试验阳性（绿色） |

### 5. 治疗

| 项目 | 内容 |
|------|------|
| **核心治疗** | **低苯丙氨酸饮食**（特殊配方奶）→终身坚持 |
| 开始时间 | **越早越好**（生后2周内开始→智力可接近正常） |
| 监测 | 定期测血Phe浓度，控制在理想范围 |

> ⚠️ **女性PKU患者**：怀孕前必须严格控制血Phe，否则会导致**母源性PKU→胎儿畸形/智力障碍**。

---

> ⚡ **遗传性疾病·速记卡**
> 🔑 21-三体=标准型47,+21(95%) | PKU=AR遗传+PAH缺乏
> ⚠️ 21-三体易位型→父母平衡易位者再发风险高；PKU女性孕前必须控制血Phe
> 💡 PKU=低苯丙氨酸饮食终身治疗+鼠尿味+皮肤白头发黄；生后2周内开始治疗
