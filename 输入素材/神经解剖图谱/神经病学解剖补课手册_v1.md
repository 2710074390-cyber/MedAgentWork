## 模块A 🟦 脊髓解剖 — 脊髓平面定位诊断基础

### 🧠 临床关联


**临床意义**：脊髓解剖是神经病学定位诊断的第一步。掌握脊髓横断面结构（前角→运动、后角→感觉、侧角→自主神经）和节段-椎体对应关系，是理解以下临床综合征的解剖基础：
- **脊髓半切综合征 (Brown-Sequard)**：同侧锥体束+后索损害，对侧脊髓丘脑束损害
- **脊髓横贯性损害**：损害平面以下全部感觉运动丧失
- **前角病变**：下运动神经元瘫（如脊髓灰质炎、ALS）
- **后索病变**：深感觉障碍+感觉性共济失调（如脊髓痨、亚急性联合变性）
- **脊髓中央管综合征**：分离性感觉障碍（痛温觉丧失、触觉保留）

**必记对应关系**：C1-C4 ≈ 同序椎体；C5-T4 ≈ 椎体序数-1；T5-T8 ≈ 椎体序数-2；T9-T12 ≈ 椎体序数-3；L1-L5 ≈ T10-T12；S1-Co ≈ T12-L1

### ⚡ 模块A 必记要点


1. 脊髓横断面三层结构：白质（外）、灰质（中）、中央管（内）
2. 脊髓灰质 Rexed 分层：Ⅰ-Ⅵ层=后角（感觉）、Ⅶ层=中间带（含侧角T1-L3交感 + S2-S4副交感）、Ⅷ-Ⅸ层=前角（运动）
3. **脊髓节段-椎体对应关系是腰穿和脊柱MRI定位的基础**
4. 脊髓血供：1条脊髓前动脉 + 2条脊髓后动脉 + 根动脉（T4和L1为分水岭区，易缺血）

## 模块B 🟩 脑干解剖 — 脑干综合征定位基础

### 🧠 临床关联


**临床意义**：脑干是神经病学最复杂的定位区域。核心原则——**交叉性瘫痪**（同侧脑神经核损害+对侧锥体束损害），是区分脑干病变与大脑半球病变的关键。

| 病变平面 | 同侧脑神经 | 综合征 | 关键血管 |
|----------|-----------|--------|----------|
| 中脑（上丘平面） | 动眼神经(Ⅲ) | Weber综合征 | PCA穿支 |
| 中脑（下丘平面） | 滑车神经(Ⅳ) | Parinaud综合征 | PCA穿支 |
| 脑桥（面神经丘） | 展神经(Ⅵ)+面神经(Ⅶ) | Millard-Gubler综合征 | AICA/BA穿支 |
| 脑桥（三叉平面） | 三叉神经(Ⅴ) | 脑桥外侧综合征 | AICA |
| 延髓（锥体交叉） | 舌下神经(Ⅻ) | Jackson综合征 | ASA穿支 |
| 延髓（背外侧） | Ⅴ/Ⅸ/Ⅹ（非Ⅻ） | Wallenberg综合征 | PICA |

**必记断面**：延髓4个横切面（锥体交叉/丘系交叉/下橄榄核中部/蜗神经核）+ 脑桥2个（面神经丘/三叉运动核）+ 中脑2个（下丘/上丘）

### ⚡ 模块B 必记要点


1. **交叉性瘫痪 = 脑干病变的定位标志**（同侧脑神经+对侧肢体）
2. 脑干断面顺序：延髓（锥体交叉→丘系交叉→下橄榄核→蜗神经核）→ 脑桥（面神经丘→三叉运动核）→ 中脑（下丘→上丘）

5. 网状结构在脑干被盖部——维持意识（上行网状激活系统）

## 模块C 🟨 小脑与间脑 — 共济失调与意识障碍的解剖基础

### 🧠 临床关联


**临床意义**：
- **小脑**：古小脑（绒球小结叶→前庭联系→平衡）、旧小脑（前叶→脊髓→肌张力）、新小脑（后叶→大脑皮层→协调运动）。病变导致**同侧**共济失调（小脑传出纤维双重交叉）。
- **丘脑**：感觉中继站+意识闸门。丘脑病变可导致丘脑痛（对侧自发灼痛）、丘脑手、意识水平改变。
- **下丘脑**：体温/摄食/水盐/睡眠/内分泌中枢。病变导致中枢性高热、尿崩症、摄食异常。

**必记**：小脑齿状核→小脑上脚交叉→对侧红核→丘脑→皮层（小脑-红核-丘脑-皮层环路）

## 模块D 🟪 端脑功能定位 — 高级皮层功能障碍的解剖基础

### 🧠 临床关联


**临床意义**：大脑皮层功能定位是理解失语、失用、失认、偏盲等高级功能障碍的基础。

| 区域 | Brodmann分区 | 功能 | 病变表现 |
|------|-------------|------|----------|
| 额叶（中央前回） | BA4 | 初级运动皮层 | 对侧单瘫 |
| 额叶（额中回后部） | BA8 | 额叶眼动区 | 双眼向对侧凝视 |
| 额叶（额下回后部，优势半球） | BA44/45 | Broca区（运动性语言） | Broca失语（表达障碍） |
| 顶叶（中央后回） | BA3,1,2 | 初级感觉皮层 | 对侧感觉障碍 |
| 顶叶（角回，优势半球） | BA39 | 阅读/计算 | Gerstmann综合征 |
| 颞叶（颞上回后部，优势半球）| BA22 | Wernicke区（感觉性语言）| Wernicke失语（理解障碍） |
| 枕叶（距状裂） | BA17 | 初级视皮层 | 对侧同向偏盲 |
| 内囊（后肢） | — | 锥体束集中通过 | 对侧完全偏瘫（三偏征） |

**必记**：内囊后肢 = 皮质脊髓束 + 丘脑皮质束 + 视辐射（三偏征的解剖基础）

## 模块E 🟥 脑血管解剖 — 卒中定位的基础

### 🧠 临床关联


**临床意义**：脑血管解剖是缺血性脑卒中定位诊断的核心。掌握每条动脉的供血区域 = 掌握每种卒中综合征的责任血管。

| 动脉 | 主要供血区 | 闭塞后综合征 |
|------|-----------|-------------|
| **大脑前动脉(ACA)** | 额叶内侧面、旁中央小叶 | 对侧下肢瘫>上肢瘫、尿失禁 |
| **大脑中动脉(MCA)** | 大脑外侧面大部（额/顶/颞叶） | 对侧面舌上肢瘫>下肢瘫、偏身感觉障碍、优势半球→失语 |
| **大脑后动脉(PCA)** | 枕叶、颞叶内侧 | 对侧同向偏盲（黄斑回避）|
| **椎-基底动脉** | 脑干、小脑 | 交叉性瘫、眩晕、共济失调 |
| **Willis环** | 前-后循环侧支通路 | 动脉瘤好发部位 |
| **脊髓前动脉** | 脊髓前2/3 | 脊髓前动脉综合征（双侧痛温觉障碍+运动障碍）|
| **PICA（小脑后下动脉）** | 延髓背外侧 | Wallenberg综合征 |

**必记**：MCA = 大脑半球外侧面 + 内囊 + 基底节（临床上最常见的卒中血管）

## 模块F 🟧 脑膜系统与脑脊液循环

### 🧠 临床关联


**临床意义**：
- **硬脑膜窦**：上矢状窦、横窦、乙状窦→颈内静脉。了解窦汇关系对理解颅内静脉血栓形成（CVT）至关重要。
- **脑脊液循环**：侧脑室脉络丛→室间孔→第三脑室→中脑水管→第四脑室→外侧孔/正中孔→蛛网膜下腔→蛛网膜颗粒→上矢状窦。任何环节阻塞导致**脑积水**。
- **脊髓被膜**：硬膜外隙（麻醉）、硬膜下隙（血肿）、蛛网膜下隙（腰穿、SAH）。

**腰穿层次记忆**：皮肤→浅筋膜→棘上韧带→棘间韧带→黄韧带→硬膜外隙→硬脊膜→硬膜下隙→蛛网膜→蛛网膜下隙

### 🧠 临床关联

## 模块H 🟦 感觉与运动传导通路 — 定位诊断的核心

### 🧠 临床关联


**临床意义**：传导通路是神经病学定位诊断的理论核心。病变在通路的不同位置产生不同的症状分布。

**感觉传导路关键交叉点**：
- 浅感觉（痛温觉）：后角换元→经白质前连合交叉→对侧脊髓丘脑束上行（脊髓内已完成交叉！）
- 深感觉（本体感觉+精细触觉）：延髓薄束核/楔束核换元→丘系交叉→对侧内侧丘系上行
- 三叉神经感觉：三叉神经脊束核换元→交叉→对侧三叉丘系
- 视觉：鼻侧视网膜纤维在视交叉交叉→对侧视束（视交叉=鼻侧交叉）
- 听觉：双侧传导（蜗神经核→双侧外侧丘系→双侧下丘）——因此单侧听觉通路病变不导致单侧耳聋

**运动传导路关键交叉点**：
- 锥体束：延髓锥体交叉（85-90%纤维交叉→皮质脊髓侧束；10-15%不交叉→皮质脊髓前束）
- 皮质核束：在脑干各平面分别交叉至对侧脑神经运动核（面神经下半核、舌下神经核仅接受对侧纤维！）
- 锥体外系：纹状体-苍白球系、皮质-脑桥-小脑系（不经过锥体交叉）

**必记**：「感觉三级换元，运动两级换元」；「浅感觉脊髓交叉，深感延髓交叉，视觉视交叉」

### ⚡ 模块H 必记要点


1. **浅感觉传导路**：后角换元→白质前连合交叉→脊髓丘脑束（脊髓内已完成交叉！）
2. **深感觉传导路**：延髓薄束核/楔束核换元→丘系交叉→内侧丘系（延髓才交叉！）
3. **视觉传导路**：视交叉中仅鼻侧视网膜纤维交叉（颞侧不交叉）→ 垂体瘤压迫视交叉→双颞侧偏盲
4. **锥体束**：85-90%在延髓锥体交叉（皮质脊髓侧束），10-15%不交叉（皮质脊髓前束，在脊髓内交叉）
5. **皮质核束**：除面神经下半核+舌下神经核外，其余脑神经运动核均接受双侧皮质核束支配
6. 瞳孔对光反射通路：视网膜→视神经→视交叉→视束→顶盖前区→双侧EW核→动眼神经→睫状神经节→瞳孔括约肌

## 模块I 🟩 自主神经系统 — 内脏神经支配的解剖基础

### 🧠 临床关联


**临床意义**：
- **交感神经**：胸腰段(T1-L3)→椎旁/椎前神经节→节后纤维长→"战斗或逃跑"反应（心率↑、血压↑、瞳孔散大、支气管扩张）
- **副交感神经**：脑干(Ⅲ/Ⅶ/Ⅸ/Ⅹ)+骶段(S2-S4)→终末神经节→节后纤维短→"休息与消化"反应（心率↓、腺体分泌↑、瞳孔缩小）
- **Horner综合征**：交感通路中断→同侧瞳孔缩小+上睑下垂+无汗（三级神经元病变定位不同）
- **神经源性膀胱**：骶髓(S2-S4)排尿中枢受损→膀胱功能障碍（上运动神经元型：痉挛性膀胱；下运动神经元型：弛缓性膀胱）

**必记**：交感节前纤维短（胸腰段→椎旁节），副交感节前纤维长（脑干/骶段→终末节）；交感节后纤维长，副交感节后纤维短

### ⚡ 模块I 必记要点
