## 硬约束（Hard Constraints — 违反即为不合格产物）

### PG-01：题型极性必须显式标记
每一道选择题必须在题干前方标注题型标记：
- `[正选]`：选择"正确/最合适/最可能" → 正确答案陈述必须为 TRUE
- `[反选]`：选择"错误/不正确/除外" → 正确答案陈述必须为 FALSE
- `[多选]`：X型题，多个正确选项

**反向题不变式**：`[反选]`题中，正确答案选项的内容必须可被权威知识判定为假；其余四个干扰选项的内容必须可被权威知识判定为真。生成时逐选项验证。

### PG-02：所有输出必须包含 Schema 化元数据

> **P9 模式元数据（batch048 起必填）**：每题输出 `"p9_mode"`，取值 `teacher_keypoint`（有教师重点/锚定清单）、`course_schedule`（有课程安排）、`module`（常规模块版）。`gate_check --stage final` 会校验覆盖率 100%，缺失即 BLOCKED。
每道题附带 JSON 元数据块，包含：题目ID、题型标记、认知层级、考点溯源、答案键、每个选项的真值极性、教育测量指标（difficulty_index / discrimination_index / non_functioning_distractors）。

### HC-24：学习价值层强制（2026-10-23 新增 · schema v2）

从 batch044 起，新批次每道题使用 `"schema_version": "2.1"` 并包含 `"learning_value"`；2.1 包含本节 v2 学习价值要求与 HC-27 概念要求，不要降回 2.0。旧批次不追溯。

- `correct_rationale`：正确答案的机制/依据，≥60 字，不得只复述答案。
- `per_option`：覆盖全部选项，`truth` 表示选项陈述本身的真假，不等同于是否被选中；正确答案选项 `misconception_id=null`，每个干扰项 `why`≥20 字且 `misconception_id` 与 `misconception` 非空。正选题正确项为真、干扰项为假；多选题逐项按真实真假和答案判断。
- **反选题**：`polarity=negative` 时，`truth` 表示“陈述本身真假”；正确答案选项 `truth=false`，其余干扰项 `truth=true`；`misconception` 解释学生为何忽略“不包括/错误/除外”。
- `key_takeaway`：可迁移的鉴别规则/记忆钩子，≥30 字。
- **错误认知 ID 是类别，不是题号**：格式 `MC-{学科缩写}-{模块}-{NN}`；同一批次内同一 ID 必须对应同一段 `misconception` 释义，不得跨题复用为不同含义（R19）。
- `source_quote`：逐字来自教师重点/教材/RAG 原文；必须写入该题的 `teacher_anchor` 中。`source_quote_status=exact` 时，引文（省略号分段后）必须能在 `teacher_anchor` 中逐字找到；找不到就改标 `paraphrase` 或 `missing`，禁止自报 exact 或编造。
- `anchor_status`：`verified|partial|mismatch|missing`；`mismatch` 必须回退重做。
- **自检**：生成后运行 `python scripts/check_learning_value.py --file <你的JSON路径>`；`FAIL>0` 或 `ID 冲突>0` 不得交付。

### HC-27：概念标注强制（2026-10-27 新增 · schema v2.1）

从 batch044 起，每道题必须输出 `"schema_version"`（2.1）与 `"concepts"` 数组；**batch047 起改用 `"schema_version": "2.2"`，在 concepts 之外再带 HC-29 的结构字段**。**旧批次不追溯**，但新批次缺此项即不合格。

为什么要有这一条：错题归因靠"这题到底考了哪几个概念"。一题只挂一个概念时，A3 病例题答错无法区分是"概念不会"还是"没读懂题"；一个概念只出现在一处时，也没法统计它被考了几次。这件事**只能在出题时标**，事后拿解析文本去猜，准确率很低且不可复核。

- 每题 **恰好 1 条** `role="primary"`，其 `keypoint` 必须与本题 `keypoint_ref` 一致。
- **A2/A3/A4/X 至少 2 条**：1 条 primary + 至少 1 条 `differential`（干扰项对应的鉴别概念）。A1/B1/判断 可以只写 1 条。
- `title` 写概念名，尽量用教师重点原文里的词（便于回查 KC 卡片标题），≥2 字。
- `evidence` 写"为什么这题测到它"，要具体到题干或某个选项，≥8 字；写"相关"不算。
- 只写 `related` 不算数：`differential` 才是"干扰项在考什么"，这是错题归因的抓手。
- 同一题内 `title` 不得重复；`concepts` 最多 4 条。
- **自检**：`python scripts/check_source_concepts.py --file <你的JSON路径> --batch {batchID}`；`FAIL>0` 不得交付。

```json
"concepts": [
  {"role": "primary", "keypoint": "第2条", "title": "急诊五级分诊",
   "evidence": "题干直接问Ⅱ类病人的评估时限"},
  {"role": "differential", "keypoint": "第3条", "title": "灾难检伤分类与四色标签",
   "evidence": "C 项把Ⅲ类的 30 分钟时限套到Ⅱ类上"}
]
```

### HC-29：干扰项生成协议（2026-11-02 新增 · schema v2.2）

从 batch047 起，新批次使用 `"schema_version": "2.2"`。旧批次不追溯。

为什么要有这一条：干扰项是这题唯一真正"教人"的部分——做错的人是被某个**具体的错误推理**带偏的，不是被一个随机错答案带偏的。此前干扰项靠"看着不像"随手写，结果是：四个干扰项互不相干、错误认知每题一个私有标签、整批无法沉淀任何可复用的概念。HC-29 把"先列鉴别、再挑最强竞争者"变成强制流程。

**① 先做 top-3 鉴别，再动笔写选项**

在写选项之前，先在 `competing_dx` 里按可能性从高到低列出 3 个竞争诊断/竞争概念（题型允许时至少 1 个）：

```json
"competing_dx": ["急性心梗", "主动脉夹层", "肺栓塞"]
```

- 第 1 条 = **最强竞争者**，必须用作 **干扰项①**（通常落在 B 或 C 位置，不得放在正确项旁边制造"二选一"提示）。
- 第 2、3 条用于干扰项②③。
- 第 4 个干扰项从"同一机制下的常见误答"取，不必是独立疾病。
- 若一道题列不出 3 个真实竞争项，说明这题只考记忆、不构成鉴别——按 L1 处理，或重写题干补条件。

**② 每个干扰项必须带机制标签 `distractor_mechanism`**

作用于 `learning_value.per_option[].distractor_mechanism`（`truth=true` 的选项留 `null`）：

| 枚举值 | 含义 | 典型场景 |
|---|---|---|
| `similar_presentation` | 表现相似 | 同样发热+腹痛，一个是阑尾炎一个是憩室炎 |
| `adjacent_concept` | 邻近概念 | 解剖相邻（胃 vs 十二指肠）、分类相邻（Ⅰ型 vs Ⅱ型呼衰） |
| `direction_error` | 方向颠倒 | 该升的说降、该禁的说用、酸中毒说成碱中毒 |
| `timing_error` | 时机/顺序错误 | 溶栓窗、抗凝启动时机、复苏顺序 |
| `population_mismatch` | 人群不匹配 | 儿童/妊娠/老年/肝肾功能不全的剂量或禁忌 |
| `mechanism_confusion` | 机制混淆（含因果倒置） | 把"代偿结果"当成"病因"，把降压药当成升压药 |
| `overgeneralization` | 以偏概全 | 一条指南推荐套到全部人群 |
| `outdated_guideline` | 旧指南/旧观念 | 已被指南删除的体位、药物或阈值 |

标签写不出唯一值时，说明这个干扰项**没有明确的错误推理**，应重写而不是硬贴。

**③ 同一错误认知必须复用同一个 `misconception_id`**

- ID 走 `MC-<学科>-<三位序号>`（如 `MC-EM-007`），**释义与 ID 一一对应**：同一 ID 在整批内只能有一种释义（R19 会拦）。
- 一个错误认知若在多题出现（如"所有胸痛都先想到心梗"），**必须复用同一 ID**，不得每题新造。
- 目标：被复用的 ID 覆盖 ≥20% 的干扰项（X6）。每题四个全新 ID 等于把错误认知降级成题内私有注释，无法跨题追踪、无法沉淀概念卡。
- 不要为了凑复用率把不同的错误硬塞进同一个 ID——R19 的 ID 冲突检查会直接判 FAIL。

**④ 反选题（`polarity=negative`）有三条额外约束**

反选题问「哪个说法是错的」，比正选题更容易靠排除法蒙对，也更容易让整批题目退化成「背否定词」。整批占比上限 **15%**（X5 门禁）。

1. **整批 ≤ 15%**。超了就把多出来的改成正选——考同一个知识点、换个问法，不要为了多样性硬凑反选。历史实测：batch036 18.0%、batch037 17.9%、batch042 18.0% 三批超标，全库 6.7%。
2. **`polarity` 必须如实标注**。它是 R15 判定 `truth` 期望值的唯一依据：反选题的答案（错误说法）`truth=false`，另外四个（正确说法）`truth=true`；标成 `positive` 会让整题的 truth 校验整体反向。batch042 的 18 道反选全部标了 `positive`，事后只能靠题干正则兜底。
3. **4 个为真干扰项逐项写 `source_anchor`**。反选题的干扰项是**正确说法**，它们的价值在于「这句话出自教材哪一段」，不在于「错在哪」：
   - 必填 `per_option[].source_anchor`（题级 `answer_evidence` 可兜底）；
   - `misconception` 改为**可选**——写了就描述「学生为什么误选」（通常是忽略否定词），没写不算缺项；
   - **不要**给为真干扰项硬编 `misconception_id`：那会造出语义虚假的标签，污染 R19 的 ID 一致性统计。

**⑤ 同步补齐 v2.2 结构字段（缺一即覆盖率不达标）**

| 字段 | 写什么 | 判定口径 |
|---|---|---|
| `difficulty_tier` | `L1`/`L2`/`L3`/`L4` | L1 单点记忆；L2 理解辨析；L3 应用推理（1–2 步）；L4 综合决策（≥3 步或多因素权衡） |
| `step_count` | 整数 1–8 | 「取信息→套规则→得中间结论」记 1 步，直接回忆记 1 步 |
| `negative_cues` | 题干反选线索原文 | 反选题必须非空且能在 `stem` 中逐字命中；正选题留 `[]` |
| `conditionals` | 改变结论的条件从句原文 | 如「若合并肾功能不全」「发病 4.5 小时内」；无则 `[]` |
| `competing_dx` | 见 ① | 按可能性排序，第 1 条用于干扰项① |

`difficulty_index` 自 2.2 起**弃用**：它是主观估值、不可复核，而命题者自评难度与实际 p 值的一致性在文献里是显著不符的（见 `reports/research/命题认知难度与干扰项设计调研_20261102.md`）。不要再填。

### PG-03：知识溯源强制
每个知识点主张必须有来源锚点：`[源:教材名 章.节/页码]` 或 `[源:笔记 PX]`。**数值型答案必须标注具体页码**（如「P142」）。

**PG-03a：大纲来源也必须标注教材页码（2026-06-17 新增）**
- 当知识点来源于复习大纲/考试大纲/重点总结时，来源锚点**仍须标注对应教材页码**
- 格式：`大纲/教材P##`（如 `大纲/教材P29`），不可只写「大纲」或「复习大纲」
- 原因：大纲本身无页码可查，读者需要回溯到教材原文验证，必须提供教材页码
- 如确实无法确定教材页码，写`大纲/待查`，不可省略教材部分

### PG-04：选项互斥与唯一性
- 选项语义互斥，无实质重叠
- `[正选]`题：恰好 1 个正确选项，其余 4 个为有区分度的干扰项
- `[反选]`题：恰好 1 个错误选项
- `[多选]`题：明确标注正确选项数量

### 后续批次命题质量补充约定
- 对原创或允许改编的题，按题干所问统一候选的临床类别、决策层级、语法及适用情境；每个干扰项应有可辨认的混淆原因，结合题干具体条件说明为何不如答案，而非靠荒谬、长度或表面形式排除。数值必须有单位、合理范围和可追溯依据，比例阈值只作筛查，不得为了凑比例改变医学事实。
- 单选题按给定条件证明唯一正确或唯一最优；多选逐项判断，B1 按每个子题判断，反选区分陈述真值与应选性。存在多个合理答案、缺关键条件或无法排除竞争项时补充条件或重写一次；仍不能解决则将该题标为 `release.disposition=quarantined` 并写入复核队列，**继续生成其余题目，不得因此停止整批**（HC-28）。
- 对关键诊断、治疗、数值及排除竞争项的主张，记录可核验的来源名称、版本及章节/真实页码或可定位原文；教师重点定位范围不能代替医学事实依据。未取得原文或真实页码则如实标记 `evidence_grade=C`，不得编造或声称已核验；关键依据缺失、来源冲突或医学争议只影响该题的 `release.disposition`（高风险 C 级 → `quarantined`，其余 → `pending_human`），**不阻断整批**（HC-28）。
- 原题保真优先：不可为满足选项形式规则而擅改原题题干、选项或答案；发现缺陷、争议或来源不足时隔离并写入复核队列，不用配额迫使放行。上述检查和脚本不能自动保证医学正确；不能保证的部分用 `release` 对象显式标注，而不是停下来询问。

### HC-5：禁止幻觉编造
绝对禁止凭空编造：药物剂量/用法/频次、流行病学百分比、基因位点、临床试验数据。素材和 RAG 检索片段中未提供的数据用"参见教材"替代，不编造。

### HC-28：一次跑完与复核队列（2026-11-01 新增）
- 每题必须带 `release` 对象：`disposition`（`publishable|pending_human|quarantined`）、`evidence_grade`（`A|B|C`）、`risk_level`（`high|medium|low`）、`reason_code`、`agent_checks[]`、`human_check`、`suggested_action`。
- 证据等级：A=输入素材/教师重点/教材原文逐字可定位；B=教师重点覆盖或教材口径一致但无逐字引文；C=仅模型知识、无可定位来源。
- 高风险题（剂量/时间窗/复苏/禁忌/儿科/急救）C 级 → `quarantined`；低风险 C 级 → `pending_human`；**A/B 且确定性门禁通过 → `publishable`（默认，不需要逐题人工核验/签收）**。
- **2026-11-03 用户裁定**：取消逐题人工医学核验作为发布前置。不要因为「没有人工逐题看过」而把 A/B 级题批量写成 `pending_human`；`review_status` 默认写 `agent_verified`，`medical_verification` 写「agent 自检通过」而不是「待人工」。只有 C 级、明确冲突或高风险题才进队列。
- **禁止硬停**：单题歧义、来源不足、人类专属核验（原卷/版权/专家裁定）只写队列，不停止整批；连续生成直到目标题数完成。
- 最终报告必须给出 `generation_status`（`DONE|PARTIAL|FAILED`）、`release_status`（`READY|PENDING_HUMAN_REVIEW|BLOCKED`）、`review_queue` 路径与计数。编排器导出时会同时生成人可读的 `review_queue.md`。

### HC-7：选项设计硬约束（2026-06-16 新增·依据 NBME 第6版 + 北大命题规范）

1. **禁止项**：不使用"以上都是/以上都不是"及变体（如"以上C不是"）；不使用"总是/从不/所有/必须/完全/绝对"等绝对化用语（NBME规则：绝对词使选项易被排除）；选项末尾不得附加括号说明（如"（见上文）"）或注释性后缀

2. **选项同质性 — 结构模板铁律（HC-14 · 2026-06-24 重构）**：

   > **核心原则：同一题5个选项共享相同的语法结构，长度自然接近。不设字数范围——设结构模式。**

   **结构模板速查表**（出题时选择题干对应的结构模式，全题5个选项保持一致）：

   | 选项类别 | 结构模式 | 5选项示例 | 自然长度 |
   |---------|---------|----------|:-------:|
   | 疾病/综合征 | [病因/部位]+[疾病名] | 支气管哮喘 / 过敏性哮喘 / 心源性哮喘 / 职业性哮喘 / 咳嗽变异性哮喘 | 4-7字 |
   | 药物 | [药物名]（同题只用裸药名） | 阿司匹林 / 氯吡格雷 / 华法林 / 替格瑞洛 / 双嘧达莫 | 3-4字 |
   | 症状/体征 | [部位]+[症状/体征] | 胸部疼痛 / 腹部疼痛 / 背部疼痛 / 腰部疼痛 / 颈部疼痛 | 4字 |
   | 数值结果 | [数字]+[单位] | 140/90mmHg / 130/85mmHg / 120/80mmHg / 150/95mmHg / 110/70mmHg | 6-8字 |
   | 解剖结构 | [限定词]?+[结构名] | 延髓 / 脑桥 / 中脑 / 小脑 / 间脑 | 2字 |
   | 机制/病理 | [部位/因子]+[过程] | 冠状动脉粥样硬化 / 冠状动脉痉挛 / 冠状动脉栓塞 / 冠状动脉夹层 / 冠状动脉炎 | 6-7字 |
   | **机制/条件** | [条件从句]+[机制/结论] | 合并肾功能不全时减量 / 妊娠期禁用 / 发病4.5小时内溶栓 / 以免伤及气管后壁 | 10-24字 |
   | 中医证型 | [脏腑]?+[病理]+[证] | 肝阳上亢证 / 心脾两虚证 / 肝肾阴虚证 / 脾肾阳虚证 / 肺肾气虚证 | 4-5字 |
   | 中医方剂 | [方名]（裸名） | 六味地黄丸 / 逍遥散 / 白虎汤 / 四君子汤 / 血府逐瘀汤 | 3-6字 |
   | 中医中药 | [药名]（裸名） | 大黄 / 人参 / 黄芪 / 天麻 / 附子 | 2字 |
   | A2病例诊断 | [完整诊断名] | 急性心肌梗死 / 不稳定型心绞痛 / 主动脉夹层 / 急性肺栓塞 / 张力性气胸 | 4-7字 |

   **自检方法**：出题后问自己——"如果给这5个选项各自加上相同的修饰前缀，它们听起来像同一个列表吗？" 像 → ✅，不像 → ❌ 修改。

   **违规示例（绝对禁止）**：
   ```
   ❌ A. 支气管哮喘 (结构: [部位]+[疾病], 4字)
      B. 由过敏原引起的气道慢性炎症性疾病 (结构: [病因]+[机制]+[描述], 14字)
   → 结构不一致！应改写为: B. 过敏性哮喘
   ```

   **结构一致但内容多样**：同一结构内的选项使用不同的限定词/部位/病因，保证区分度。

   **条件从句可以长**（2026-11-02，P2-S5）：含「若/一旦/合并…/…时/…者/以免…」这类限定语的选项，删短就改变医学含义，因此**不受 20 字上限约束**（R13 已降级为提示并对这类选项豁免）。但豁免只认限定语，不认堆砌——把三个并列适应证塞进一个选项来凑长度，仍然算矫枉过正。真正的硬线仍是 R2：正确项不得显著长于最短干扰项。

   ⛔ **截断零容忍**（以下规则独立于结构模板，始终强制）：
   - 诊断/疾病名必须完整（禁止"急性前壁心肌"，必须"急性前壁心肌梗死"）
   - 数值必须有单位（禁止"LVEF<40"，必须"LVEF<40%" / 禁止"PaO2<60"，必须"PaO2<60mmHg"）
   - 禁止选项以虚词结尾（的/和/与/或/及/在/被/将/对/向/于）、逗号、顿号
   - 禁止以句号结尾的短残片（<8字+.结尾）
   - 选项末尾字自检：禁止以'哮/心/凝/亢/肌/进/平'等不完整语素结尾
   - 所有选项均为10字的均匀长度 → 极可能是系统截断，逐个修正
   - 自检：问自己「这个选项能否作为一句话独立朗读？」能 → 完整，不能 → 截断
   - 选项与题干**语法一致**：题干末尾字的数量/词性/时态须与每个选项首字兼容（NBME规则：语法不匹配的选项被直接排除）
   - 含**数值的选项必须按升序或降序排列**（NBME规则：乱序数值增加无关难度）
   - 五个选项**共有的词汇移至题干**，不在每个选项中重复（NBME规则：减少阅读量，消除重复词线索）

3. **词重复与收敛防护（NBME Testwiseness 核心规则）**：
   - **词重复检测**：检查题干与正确项是否存在可利用的重复线索；自然改写消除线索，不强制在干扰项重复关键词，更不能破坏医学事实。
   - **收敛策略检测**：出题后检查——计算每个选项与其他选项的术语重叠度。正确答案的"共同元素数"不应显著高于各干扰项（避免"正确答案恰好含最多共同元素"的收敛线索）
   - 判定方法：提取5个选项的关键术语 → 计算每个选项包含的术语在其他4个选项中出现的次数 → 正确选项的共享计数不得为最高

4. **干扰项科学设计**（有效干扰项>=3个）：
   - 错误选项须基于「常见错误认知」设计，不能是明显错误
   - 数值型干扰项应有合理临床范围和错误认知依据，不以与正确值的固定百分比替代医学判断。
   - 每个干扰项须有解释"为什么学生会选它"

5. **否定词标注**：所有否定题干中的"不/除外/错误"等词必须 `**加粗**`

6. **溯源格式**：每题标注 -> 【溯源】第X章第X节 知识点名称 + 教材页码

7. **模糊术语控制（NBME规则）**：避免使用"频繁""可能""通常""常见""有时"等模糊程度副词。如需使用，全题统一用同一个词，不混用"通常""常见""一般""多数"

8. **B1 型题（配伍题/共用选项题）专项规则**（2026-06-18 新增·batch005 ISSUE-007）：
   - B1 型题共用选项与整组考查的临床类别和决策层级一致；逐子题判断适用性及唯一答案，不强求每个选项对每个子题都具有干扰性。
   - 共用选项不得过于笼统/宽泛（如仅用"虚证/实证"概括一切、仅用"表证/寒证/热证"等大范畴概念）。每个共用选项应为具体诊断/机制/药物/结构名，长度建议 >= 4 字
   - 每个共用选项至少对组内 1 道子题构成有效干扰（plausibility ≥ 0.3——即至少有 1 道题的干扰项分析中可合理解释学生为何可能选它）
   - B1 组内子题的正确答案不得集中于同一选项位置（如不得 4 道题全选 A），分布应覆盖 ≥ 3 个不同选项字母
   - B1 组内子题应覆盖不同知识点维度（如考查不同脏腑/不同病机/不同方剂），不得仅通过换题干数值来制造子题

### HC-8：Bloom 层级标注强制（2026-06-16 新增）
每道题必须标注认知层级：`【层级】记忆/理解/应用/分析`
- 记忆：纯回忆事实（如"正常小儿前囟闭合时间"）
- 理解：解释机制（如"低渗脱水为何更易休克"）
- 应用：在病例中运用知识（如"根据血气分析判断酸碱失衡类型"）
- 分析：多知识点综合判断（如"鉴别三种脑膜炎的CSF特征"）

**配额执行**：

- 选取：按「教材章节 → 真题知识点」匹配，优先考查同一知识点的题目（病例题、数值题均可参与）
- 引用形式二选一：
  - **原题引用**：保留真题题干/选项/答案，仅适配本库格式（选项重排须同步答案字母；题型/选项数须与 GS 源一致）
  - **轻度改编**：换问法/换病例情境/调整干扰项（仍须满足 PG-01~HC-8 全部约束），但**知识点、答案、数值不得改动**

- **无真题覆盖章节**（如中医学方剂、医患沟通、部分皮肤性病学章节）：该章节配额清零，以原创补齐；批次统计中如实标注「该章节无考研真题覆盖」

### 阶段五：分批执行控制（防止调用失败·2026-06-27 新增）

> ⚠️ **强制规则**：任何宿主的单次调用都有输出上限（早期 Cherry Studio 实测会截断或调用失败，其它宿主同样存在上下文/输出预算）。以下规则不可跳过，且不依赖具体宿主名称。

**触发条件**：当预估总产出 ≥ 20 道题 或备考资料 ≥ 3000 字时，必须启用分批模式。

**分批流程**：

1. **首次响应**（意图确认回显之后）：
   ```
   📦 分批计划
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   预计总产出：备考资料约 X 字 + 题库约 X 题
   分批方案：
     第1批：备考资料（考点速记表+结构化笔记+对比表+路径图）
     第2批：A1/A2 型题（≤30题）
     第3批：B1/X 型题（≤10组/≤30题）
     第4批：简答/论述/案例题（≤5题）
     最后批：批量统计
   预计批次：X 批
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   直接开始第1批，无需用户确认；单批完成后自动继续下一批，直至最后批统计。
   ```

2. **每批格式**：
   - 开头标记：`---\n## 📦 批次 {X}/{Y}：{内容描述}\n---`
   - 结尾标记：
     ```
     ---
     ✅ 批次 {X}/{Y} 完成。本批产出：{简要统计}
     ⏭️ 下一批：{内容描述}（预计 {题数/字数}）
     ⏭️ 自动继续生成下一批（不等待用户输入）。
     ```

3. **续接规则**：
   - 用户说「继续」→ 直接输出下一批，**无需重复意图确认和分批计划**
   - 用户说「重做批次{X}」→ 重新输出指定批次
   - 用户说「跳到批次{X}」→ 跳过中间批次，直接输出指定批次
   - 用户说「全部整合」→ 将所有批次合并为完整输出（仅当总产出 ≤ 5000 字时可用）

4. **题量硬上限**：
   - 每批 ≤ 30 道选择题（A1/A2/B1/X）
   - 每批 ≤ 5 道简答/论述/案例题
   - 每批 ≤ 3000 字纯文本（备考资料）

5. **中断恢复**：如某批次输出被截断，用户说「批次{X}中断，从第{Y}题继续」→ 从指定位置继续该批次剩余内容
