## 教师重点原文（M3-M10）

```
神经系统疾病的常见症状：意识障碍的类型和表现，失语（运动性、感觉性、命名性、传导性），眩晕（引起眩晕的常见疾病及特点），躯体感觉障碍的种类，共济失调（小脑性、感觉性、前庭性）的概念及表现，步态异常的种类。

神经系统疾病的病史采集和体格检查：病史（尤其是现病史）采集过程中的重点，运动系统检查、感觉系统检查、反射检查、脑膜刺激征检查。

神经系统疾病的辅助检查：常用的辅助检查方法，脑脊液的产生与吸收，腰椎穿刺的适应症和禁忌症，导致脑脊液中细胞数和蛋白质增高的常见疾病，磁共振弥散加权成像（DWI）的临床价值。

脑血管疾病：短暂性脑缺血发作（定义、鉴别诊断、治疗），脑梗死的病因、发病机制、临床表现尤其是大动脉粥样硬化型脑梗死（一般特点、三偏征、闭锁综合征、基底动脉尖、延髓背外侧综合征）、辅助检查、治疗，脑出血的病因、发病机制、临床表现、辅助检查、治疗，脑梗死与脑出血的鉴别，蛛网膜下腔出血的病因、发病机制、临床表现（一般症状）、辅助检查（腰椎穿刺），脑血管疾病的危险因素及其预防。

运动障碍性疾病：帕金森病的病理基础、临床表现、治疗原则、早期治疗。

癫痫：影响发作的因素，癫痫临床表现的特点，癫痫部分性发作（部分运动性发作），癫痫大发作即全面强直-阵挛发作的临床表现，癫痫的诊断（辅助检查、鉴别诊断尤其是与晕厥的鉴别）癫痫持续状态的概念及治疗。

周围神经疾病：三叉神经痛（临床表现、药物治疗），特发性面神经麻痹（临床表现），多发性神经病的临床表现，吉兰-巴雷综合征（诱因、临床表现、诊断等）

神经-肌肉接头和肌肉疾病：重症肌无力（临床表现、诊断、药物治疗、危象的概念及处理），周期性瘫痪的概念、分类、低钾周期性瘫痪（临床表现、治疗）。
```

## RAG教材原文验证（M3-M10）

### M3 常见症状
- **教材P60**: 常见症状及体征包括意识障碍、认知障碍、运动障碍、感觉障碍和平衡障碍。
- **教材P61**: 脑死亡判定 — 持续至少12小时，须除外急性药物中毒、低温和内分泌代谢疾病。
- **教材P69**: 癫痫发作与晕厥鉴别 — 癫痫有神经系统定位体征+发作间期脑电图异常；晕厥心血管异常常见+脑电图正常。
- **教材P70**: 眩晕是对空间定位产生障碍的运动性或位置性错觉。
- **教材P78-79**: 小脑蚓部病变→共济失调步态；痉挛性偏瘫步态为单侧皮质脊髓束受损。

### M4 病史采集与体格检查
- **教材P92-112 (第四章)**: 病史采集重点、运动系统检查、感觉系统检查（自缺失→正常、远端→近端）、反射检查、脑膜刺激征、自主神经功能检查。

### M5 辅助检查
- **教材P114 (第五章)**: 腰穿禁忌证 — 严重高颅压、明显视乳头水肿、颅后窝占位。术后去枕平卧4-6小时。

### M6 脑血管疾病
- **教材P171**: TIA 50-70岁多发，男>女，突发性/短暂性/可逆性。
- **教材P173**: 鉴别 — 梅尼埃病（反复眩晕+耳鸣+耳内胀满感，持续数小时）。
- **教材P222**: 脑缺血事件包括TIA及急性脑梗死。

### M7 帕金森病
- **教材P284**: PD以静止性震颤、运动迟缓、肌强直、姿势平衡障碍为主要特征。
- **教材P288**: 抑郁症无肌强直和震颤。早期PD易误诊为脑血管病。
- **教材P290**: DBS微创、安全、可调控。靶点：GPi和STN。

### M8 癫痫
- **教材P307**: 全面性发作（GTCS/强直/阵挛/失神/失张力/肌阵挛）、部分性发作（单纯/复杂/继发全面性）。
- **教材P308**: GTCS以意识丧失+双侧强直后阵挛为特征。
- **教材P310**: 儿童良性癫痫 — 局灶性+夜间GTCS，2-3分钟，13岁前消失。

### M9 周围神经疾病
- **教材P334**: 三叉神经痛呈周期性发作，缓解期如常人，无阳性体征。药物治疗首选卡马西平。
- **教材P345-346**: GBS核心症状 — 肢体对称性弛缓性肌无力，远端→近端，数日至2周达高峰，可致呼吸肌麻痹。

### M10 神经肌肉接头与肌肉疾病
- **教材P347**: 低钾性周期性瘫痪 — 四肢弛缓性瘫痪，无感觉障碍，血清钾降低，补钾有效。
- **教材P359**: MG危象 — ①肌无力危象（新斯的明有效）②胆碱能危象（抗ChE过量+毒蕈碱反应）③反拗危象。
- **教材P361**: 危象病死率15.4%-50%。
- **教材P363**: 高钾型—10岁前发病，白天运动后发作，肌无力短+肌强直。
