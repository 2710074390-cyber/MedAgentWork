## 0. 一句话结论

**项目已经具备“批量生产合规、可溯源、可发布”的医学复习资料能力；尚未具备“证明并持续提升学习效果”的能力。**

- 生产侧：8 个学科、10 份主复习资料 MD、9 份 HTML、10 份人工 PDF；教师重点版 125/125 条覆盖、0 缺失；105 项自动化测试全绿。
- 学习侧：无学习者模型、无掌握度诊断、无间隔重复调度、无错题→知识卡回链、无学习结果数据。
- 结构侧：教师重点版与教学计划版是两套模板，各有优势也各有缺口，尚未统一到“单一知识底座 + 双视图”。

## 1. 系统定位

MedAgentWork 不是“脚本集合”，而是：

1. **临床医学考试复习资料生产系统**：教材/教师重点/真题 → 五阶段 Agent 管线 → 题库、复习资料、押题卷。
2. **静态发布站**：Cloudflare Pages（`med-review-site.pages.dev`），国内可直连。
3. **规则与门禁系统**：`SOUL.md` / `CONTEXT.md` / `.dsh/skills/` / `scripts/` 共同约束模型自由度，强调“错误出不来”，而不是“模型更准”。
4. **可复用的公开技能包**：`medagentwork-skill`（GitHub `2710074390-cyber`），v2.2 起移除插图功能，与主工作区不同步。

## 2. 架构与模块

### 2.1 五角色管线

| 角色 | 职责 | 关键输入 | 关键输出 |
|---|---|---|---|
| MedMaster | 编排、意图解析、阶段门禁 | 用户指令、批次状态 | 下游调用指令、HALT/放行 |
| MedGen | 出题 + 备考资料 | 教材、真题候选、蓝图 | `中间产物/{batchID}/ALL_questions.json` |
| MedQC | 质检、评分、维度判定 | 题库、GoldenSet、蓝图 | `质检报告/{batchID}/A3_质检报告.json` |
| MedFix | 修复、溯源、答案保护 | 质检报告、原题 | `最终产物/{batchID}/ALL_questions_FIXED.*` |
| MedReview | 主复习资料生成 | 教师重点、备考资料、修复后题库、RAG 教材 | `复习资料/{科目}教学计划版/{科目}_主复习资料.md` + 配图清单 |
| MedIllustrator（豆包） | 配图执行 | 配图清单、图谱索引 | `images_webp/*.webp`、标注图 |

主线状态机：

```text
启动(登记批次) → MedGen → GATE-A2 → MedQC → GATE-A3 → MedFix → GATE-A4
→ MD 导出 → MedReview → 终审门禁 → 用户签收(APPROVED) → 归档
```

状态写入唯一入口：`scripts/workflow_state.py`（原子写，HC-17）。禁止手改 `workflow_state.json`。

### 2.2 复习资料生成链路（MedReview）

**输入优先级（2026-10-18 修订）**：

1. 教师重点/复习大纲原文（权威范围，最高优先）
2. 已有备考复习资料（二手概括，只能增强）
3. RAG 教材原文
4. 修复后题库

**生成步骤**：

1. 读取教师重点，建立逐条覆盖矩阵（`中间产物/{batchID}/{科目}_教师重点覆盖矩阵.md`，过程产物，不进交付 MD）。
2. 按模块拆分；模块 ≥5 时强制分批（每批 ≤5 模块）。
3. 每模块按模板生成：前置知识检查、30 秒摘要、考点卡、对比速查、因果链、决策树、一页纸、主动回忆。
4. 每个 🔴 考点写 D1 第一性原理；每模块至少 1 张 D2 因果链；系统 ≥5 模块时做 D3 谱系；≥3 种鉴别时做 D4 决策树；科目末尾做 D5 概念地图。
5. 教师重点条目写 `📌 重点原文（第X条）：…` 落点行 + `（教师重点第X条）` 锚点。
6. 生成附录：教材页码索引、术语同义异名表、口诀、数字锚、主动回忆答案。
7. 自检 V1–V17：三色覆盖、callout 密度、展开区、表格保留、D1–D5、V14 导出兼容、V15 插图占位、V17 教师重点覆盖。
8. 门禁：`check_keypoint_coverage.py` → `verify_page_numbers.py` → `verify_produce_rules.py` → `gate_check.py --stage final`。

**关键规则**：

- HC-20：教师重点原文锚定；数值/时间窗/分级界值/剂量/百分比/并列与禁止结构必须原文字面保留；原文锚定 > 原创性。
- HC-9/HC-10/HC-11：术语附录、真实页码、来源锚点。
- HC-18：复习资料 = MD + HTML；PDF 一律人工上传；禁 Mermaid；禁 `**`/`*`、禁 `<details>`、仅允许 `<b>/<i>`。
- V15：插图占位符与配图清单一一对应；通道白名单（①复用/①教材/①示意/②卡通/③flow/③compare/③grid/跨科复用）；AI 卡通必须人工核解剖准确性。

## 7. 主要问题与根因

| # | 问题 | 证据 | 根因 |
|---|---|---|---|
| P1 | 两套模板分叉：教师版范围准但深度浅；教学版深度足但范围契约缺失 | 教师版 0 展开区/22 callout/0 图；教学版 12 类硬事实缺失/0 锚点 | 两条生产线独立演进，没有统一知识底座 |
| P2 | K-ID 是“展示编号”，不是“知识组件主键” | 复习资料 178 个 K-ID；题库 0 个匹配 | 缺少 KC 注册表与映射契约 |
| P3 | 有主动回忆，没有调度与反馈 | 82 题 + 附录五答案；无间隔重复、无掌握度、无错题回链 | 文档是静态产物，不是学习系统 |
| P4 | 蓝图权重与卡片数不完全配平 | M05 +26.1%、M06 −29.4%、M07 +56.9%（相对偏差） | 卡片按内容自然生长，未按测评蓝图校准 |
| P5 | 评价偏生产合规，不偏学习效果 | 门禁覆盖页码/格式/覆盖；无学习者结果数据 | 质量体系的目标函数是“可交付”，不是“学得会” |
| P6 | 临床推理层有“图”，缺“脚本” | 有决策树/谱系；无 illness script 卡、无对比病例组 | 模板以考点为中心，不以临床任务为中心 |
| P7 | 多模态支持不均 | 教师版 0 图；教学版有配图；AI 解剖图需人工核验 | 插图管线未接入教师版；解剖准确性风险高 |
| P8 | 证据时效性未分层 | 教材页码锚定强；指南版本/证据等级/复查日期缺失 | 考试范围以教材为准，但临床相关性需要指南时效 |
| P9 | 成本与版权约束 | RAG 付费 API（batch027 402 事件）；教材/真题版权 | 生产系统必须考虑成本与合规 |
| P10 | 文档级学习价值无门禁 | 12 题试点，文档无评分卡 | 度量工具尚未从题目扩展到文档 |
