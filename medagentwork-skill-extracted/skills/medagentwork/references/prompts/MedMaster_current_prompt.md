### HC-5：外来素材数值交叉验证（2026-06-15 新增·题填25事件）
合并外来素材（非 Agent 2 生产的现成题目/题库）时，必须对所有数值型答案执行 >=10% 随机抽查，对照教材原文验证。抽查结果写入工作流日志。

- 抽样规则：对所有含数字（百分比/剂量/天数/月龄/年龄/检验值）的答案，随机抽 >=10%

### HC-6：干扰项区分度审查（2026-06-15 新增·题245事件，2026-06-18 扩展至全量）
对「数值对比型」选项执行区分度检查，**所有批次均触发**：
- 如果错误值与正确值的差距一目了然（如错误值"3天" vs 正确值"10-14天"），选项区分度过低，应替换为更接近的混淆值
- 数值型干扰项与正确答案差值应 <= 正确答案的50%（如正确值14天，干扰项用5-7天而非1-3天）
- 判断标准：如果一个医学生不看教材也能立刻识别该选项为错误 -> 区分度不足
- **触发模式区分**：
  - 外来素材合并：全量检查（100% 题目）
  - Agent 2 自产题目：抽查 ≥10% 题目（随机抽样，优先覆盖含数值的题目）
- 校验脚本：`python validate_options.py --batch {batchID}`（机械化检测 R6 数值区分度）

### HC-9：术语同意异名附录（2026-06-17 新增·客户反馈）
每批次主复习资料末尾必须附加「术语同意异名对照表」。目的：同一概念在不同教材/教师/考试中可能使用不同名称，学生可能按自己熟悉的名称搜索却找不到对应内容，附录可消除术语歧义。

- 触发条件：**所有批次均触发**（无需特殊条件）
- 附录内容分类：
  - 脑神经/解剖结构同义异名（如 前庭蜗神经=位听神经）

- 放置位置：主复习资料末尾，作为最后一个附录
- 在 Agent 5 调用指令中明确列出「术语附录」作为必须产出项

### HC-10：附录页码真实性验证（2026-06-17 新增·P230占位符事件）

  - `MISSING_PAGE` → 同上，从正文提取
