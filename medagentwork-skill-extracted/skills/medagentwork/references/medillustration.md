# MedIllustration — 医学插图工作流（卡通 + 图谱双形态）

> 本文改编自原项目 medillustration skill（可选阶段）。`{SKILL}` = 本 skill 安装目录；命令须在用户工作区执行。插图四件套需 `pip install Pillow PyYAML`。

## 分工契约（硬约束）

- **文字内容**（复习资料 MD、题库、解析）由管线各角色生成，本手册不负责。
- **图片内容**（卡通底图、确定性图谱、标注、压缩、嵌入）由图片生成方负责（宿主 agent 的文生图能力，或人工 + 工具）。
- 两者通过文件系统交接：内容角色在 MD 中写 `![图注](images_webp/xxx.webp)` 占位，图片方按占位生成对应文件，互不越界。

## 输入输出契约（与 MedReview / MedMaster 衔接）

- **输入**：编排者打包的交接任务包 = ①`{科目}_配图清单.md`（每条含 **通道：图谱复用 / AI卡通 / 确定性图谱** + AI Prompt 四要素或图谱 YAML 要点）②本手册 ③可复用图路径（用户自备图谱素材）④科目目录规范。
- **输出**：回传 `复习资料/{科目}教学计划版/images_webp/*.webp`（1600px、q=82）供 MD 渲染；`raw/`、`diagram_configs/`、`annotate_configs/`、`annotated/` 同目录保留中间产物。
- **验收**：MD 中每个 `![图N：…](images_webp/…)` 占位符必须有对应文件；三种通道来源可溯源到清单行（`python {SKILL}/scripts/check_inline_images.py --md … --img-dir … --list …`）。

## 形态总原则：三通道路由（决策树）

> 实证结论：AI 写实解剖 >99% 含虚构结构，已废弃写实路线。改为 AI 擅长的**扁平卡通示意** + **确定性图谱**。

```
知识点需要插图？
├─ ① 解剖结构类（骨骼/肌肉/器官/神经/眼球等）
│   ├─ 图谱有覆盖 → 出版级解剖图谱复用 + 程序标注（准确第一，首选）
│   │   多面板拼接：YAML → python {SKILL}/scripts/compose_atlas.py compose_configs/xxx.yaml
│   └─ 图谱无覆盖 → AI 扁平卡通「示意」无字底图 + 程序标注
│                   ★ 图注必须带「（示意）」，不承担精确解剖定位
├─ ② 机制/病理/进展/形态类（如门脉侧支循环、ARDS、胎儿循环、突触机制）
│   └─ AI 扁平卡通无字底图（风格锁定）+ 程序标注
└─ ③ 流程/决策/对比/时序/分型类（步骤、鉴别、分期、分类）
    └─ 确定性图谱：内容 YAML → python {SKILL}/scripts/render_diagram.py diagram_configs/xxx.yaml
        ★ 不调用文生图；文字与结构 100% 来自教材，零幻觉、零乱码
```

**判定口诀：「长什么样」走卡通（①缺口/②），「什么关系、什么顺序」走图谱（③）。** 拿不准时优先③（确定性渲染不会出错），其次②。

## 通道①②：AI 扁平卡通无字底图

### 固定风格前缀 STYLE_PROMPT（每张必带，只替换主体部分）

> 扁平矢量风格医学科普卡通插画（flat vector medical illustration），柔和平涂色块，统一粗细的深色描边，造型极简概括，纯白色背景，居中单一主视图，构图简洁、四周留白充足；无渐变、无阴影、无照片质感、无纹理；画面中不出现任何文字、字母、数字、箭头、指示线、编号、图例、局部放大图或辅助小图。主体：{主体/视角/结构清单/状态配色}。

负面约束：写实、照片、3D 渲染、复杂纹理、光影质感、文字乱码、水印、多余结构、解剖变形。

### 风格锁定（系列一致性，必做）

1. 每个大类先出 **1 张金样**，人工确认风格后作为全系列参考。
2. 同科/同批后续底图以金样为参考图生成（image_edit / 图生图），prompt 只写主体差异，保证全系列风格统一。
3. 分辨率 ≥2048px（1:1 或 4:3）；仍然是**无字底图**，中文一律程序标注。

### 扁平色板（AI prompt 与 render_diagram.py 共用同一语义）

动脉/异常用柔和红、静脉/通路用蓝、神经用黄、正常/代偿用绿、病变/进展用橙、缺血/特殊用紫、中性结构用灰；**一图主色不超过 4 种**。渲染器色板键：blue / teal / green / orange / yellow / red / purple / gray。

## 通道③：确定性图谱渲染

- **适用**：流程/时序（`flow`）、对比鉴别（`compare`）、分型网格（`grid`）。
- **做法**：内容取自教材写成 YAML（`title/subtitle/note` + `steps` 或 `items`，每项 `title/color/lines`）；渲染器负责版式、自动折行、箭头、配色，输出 2048px PNG，并可用 `webp:` 字段同时产出 1600px q82 部署版。
- 配置放 `diagram_configs/`，路径解析相对科目目录。
- **不需要底图、不需要再标注**（文字已在图内且 100% 正确）；质检只需核对 YAML 内容与教材一致。

## 通道①图谱复用：多面板拼接

- **适用**：一张复习图需要图谱中 2-3 个相邻视图拼合，或要在出版图上程序叠加虚线轮廓/中文图例。
- **做法**：YAML 定义 `rows → panels`（`image/caption/marks`），自动裁白边、等比排版、中文小标题带；`marks` 支持千分比虚线 `ellipse/rect` 与白底 `note` 图例框；输出 2048 PNG。
- 源图按**画面真实内容**命名复制到 `raw/`；渲染后必须回读逐面板核对内容、图注与虚线位置。
- **⚠ 图谱索引与实际画面可能系统性错位（原项目实证：图号 meta220/333 等与画面不符），必须逐张目视核验，严禁只按索引 fig_num 提图。**

## 质检（硬需求，不可跳过）

- **通道①图谱复用**：图号对应正确知识点、标注术语与教材一致。
- **通道①②AI 卡通**：标准——
  1. **结构关系无原则错误**：结构数量、左右、连接、层次正确（卡通允许形态简化）；错误→重生成（在主体描述里强化结构清单与相对位置）。
  2. **风格达标**：扁平色块、白底、无渐变/阴影/照片质感；不达标→以金样为参考重做。
  3. **无杂项**：无文字乱码、无辅助小图、无指示线、无多余结构。
  4. **标注后无重叠遮挡**。
- **通道③确定性图谱**：只核对 YAML 内容与教材一致、无错别字；版式由脚本保证。

## 标注工具：annotate_image.py（仅通道①②需要）

YAML 驱动，box 用千分比相对坐标（0-1000，左上原点），与分辨率无关。

| 模式 | 适用场景 | 效果 |
|------|---------|------|
| `label`（**默认推荐**） | 干净卡通底图、图谱图 | 无背景块，深色文字 + 白色描边直接写在图上，不遮挡图片 |
| `overlay` | 仅用于盖住 AI 图内偶发乱码后重写中文 | 白底圆角覆盖块 + 文字 |

```bash
cd <工作区> && python {SKILL}/scripts/annotate_image.py annotate_configs/xxx.yaml
```

## 压缩与嵌入

1. **压缩**：PNG → WebP，1600px 宽，quality=82，method=6：`python {SKILL}/scripts/export_webp.py "复习资料/{科目}" [名称…]`
2. **嵌入**：MD 中用 `![图N：图注](images_webp/xxx.webp)`；`python {SKILL}/scripts/render_review.py "复习资料/XXX.md"` 支持 `![]()` 图片语法（含 `--embed-images` base64 自包含模式）。
3. **嵌入 MD 不破坏格式（硬规则）**：
   - 图片语法独占一行，路径用正斜杠相对路径，不用绝对路径或反斜杠。
   - **优先同名替换**：新图文件名与 MD 既有引用完全一致时只换文件、零改动 MD；确需新增图片行时，插在对应考点段落之后，前后各留一个空行。
   - 图号 `图N` 与图注沿用 MD 既有编号与措辞；一次嵌入只动图片相关行。
   - 嵌入后必须做引用解析校验：MD 中每个 `![]()` 引用都能在该科目 `images_webp/` 找到同名文件。

## 图注规范

- 通道①「图谱无覆盖的 AI 卡通解剖示意」**图注必须含「（示意）」**，如 `图3：女性盆腔矢状结构（示意）`。
- 通道②机制卡通建议加「（示意）」；通道③确定性图谱与图谱复用图不加。

## 科目目录规范

```
复习资料/{科目}教学计划版/
├── raw/                    # AI 卡通无字底图（或图谱提取）
├── diagram_configs/        # 通道③确定性图谱 YAML
├── compose_configs/        # 通道①图谱多面板拼接 YAML
├── annotate_configs/       # 通道①②标注 YAML
├── annotated/              # 标注版/渲染版 PNG（2048px）
├── images_webp/            # 压缩部署版（MD 引用此目录）
└── {科目}_主复习资料.md / .html
```

## 已知硬伤与规避

- **AI 写实解剖不可靠** → 已废弃写实路线：解剖优先图谱复用，缺口用扁平卡通示意并标注「（示意）」。
- **AI 中文标注乱码** → AI 只出无字底图，中文一律 annotate_image.py 程序叠加；通道③文字由渲染器输出，零乱码。
- **系列风格不统一** → 固定 STYLE_PROMPT 前缀 + 金样参考图锁定。
- **overlay 白底块遮挡** → 默认 label 模式，overlay 仅用于修复偶发乱码。
