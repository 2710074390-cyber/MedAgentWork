### 3.1 三科考情

**传染病学**（期末 10 章；执医有独立单元；考研 306 未单列，但内科系统章节病种重叠）
- 第10版结构：总论 → 新发感染病 → 病毒性疾病（肝炎体量最大）→ 立克次体 → 细菌 → 深部真菌 → 螺旋体 → 原虫 → 蠕虫 → 其他感染相关问题
- 高频考点共识（B 站带背/教学大纲资料交叉）：病毒性肝炎（分型、传播、重症乙肝、抗病毒治疗）、流行性脑脊髓膜炎、结核病、伤寒与副伤寒、霍乱、疟疾、血吸虫病、狂犬病暴露处置、艾滋病机会性感染、抗菌药物合理使用/耐药。
- 参考资源：[传染病学(第10版)教学大纲](https://m.book118.com/html/2025/1120/7146055021011013.shtm)、[《传染病学》病毒性肝炎学习指南（南医大）](https://aike.smu.edu.cn/mod/page/view.php?id=207984&lang=zh_cn)、[人卫第10版核心考点带背（B站）](https://www.bilibili.com/video/BV1PUJDzHEUa/)

**眼科学**（第10版：20 章，592 千字，期末 2-4 学分；执医「临床医学综合·其他」有小分值；306 不考）
- 高频考点共识：白内障（分类/手术指征/囊外+人工晶状体）、青光眼（急性闭角型发作三联征/眼压/前房角/降眼压药）、结膜炎与沙眼、角膜炎（细菌/病毒/真菌鉴别）、葡萄膜炎、视网膜脱离（裂孔性/牵拉性/渗出性）、糖尿病性视网膜病变（分期）、屈光不正与弱视斜视、眼外伤（异物/化学伤急救）、全身疾病眼部表现。
- 网络资源密度高：人卫第10版「1505 客观题常考点 + 543 主观题挖空」带背（[B站](https://www.bilibili.com/video/BV1aGGm6XEY9/)）、[眼科学考试题库（book118）](https://max.book118.com/html/2026/0307/8026011047010051.shtm)、[眼科学(第10版)购书页](https://www.pmphmall.com/gdsdetail/653330-331927)。
- ⚠️ 注意：眼科学第10版与《生理学》感觉器官章节（青光眼/折光系统）交叉，建议在「前导知识检查」写明回补路径。

**口腔科学**（非口腔专业临床医学院必修短课，通常 16-36 学时；执医笔试每单元仅少量题；306 不考）
- 第10版 20 章中，非口腔专业教学重点多在：牙体牙髓病（龋病/牙髓炎/根尖周炎）、牙周疾病、口腔黏膜常见病（复发性阿弗他溃疡/白斑/扁平苔藓）、口腔颌面部感染（智齿冠周炎/间隙感染）、颌面部损伤（骨折/软组织伤）、唾液腺疾病、口腔颌面部肿瘤（良恶性鉴别）、口腔修复与种植（了解级）。
- 网络样本考法（[口腔科学试题样例](https://wenku.suwen.cn/d-341688.html)、[口腔科学模拟测评卷](https://max.book118.com/html/2026/0330/5022022114013142.shtm)）：楔状缺损病因、猛性龋相关因素、「全身健康状况」关联题——提示**口腔疾病与系统性疾病的关系、预防保健**值得设了解级考点。
- ⚠️ 素材注意：本教材适用「供基础、临床、预防、口腔医学类专业用」，临床专业授课范围以本校教学大纲为准；若用户能提供本校口腔科学教学大纲（学时/章节），模块范围按大纲收敛，否则按本方案 §5 建议模块。

## 六、生成流程与质量门禁（每科固定 9 步，无题库批次）

```
S1  建工作目录：中间产物/{code}_review/（如 infectious_review/、stomatology_review/、ophthalmology_review/）
S2  写 00_编写规范与素材映射.md：
    - 页偏移测定：取教材目录印刷页 vs txt 中 ===== 第 N 页 ===== 对照（急诊先例 N−17；内科 N−31）
    - 教学内容块→模块分配（§5 表）+ txt 行号范围（用 grep 定位每章起始行）
    - 贺银成补充定位：grep 讲义中/下册 相关章节行号（传染病→中册·内科学感染/肺结核/脓毒症；
      眼科/口腔→中册·感觉器官/外科·口腔颌面、皮肤；无对应章节则如实声明跳过）
S3  并行子 agent（每块 1 个，prompt 含 medreview skill + 模块范围 + 行号范围 + 格式契约摘录）
S4  子 agent 产出 模块N_XXX.md → 主会话逐份核对（页码非占位、无试题形态、无流程残留）
S5  主会话写：科目导航（一句话核心逻辑链/命题规律/复习路径/避坑提示）+ 使用指南
    + D3 谱系总览 + 模块速览 + D5 跨模块概念地图 + 附录一页码索引/附录二术语表(HC-9)/附录三口诀
S6  合并 → {科目}_主复习资料.md（放入 复习资料/{科目}教学计划版/）
S7  机械约束自检脚本化（沿用既有 check_fences.py 思路）：
    callout ≥ 模块数×4 | 展开区 ≥ 模块数×2 | D2 图每模块≥1 | D4 树≥1 | 对比表≥5/模块
    V14：** 计数=0、<details> 计数=0、<b></b> 配对、0 Mermaid、0 批次/自检残留、0 试题形态
S8  python 知识库素材/render_review.py "{文件}" → 自包含 HTML（--dark 默认）
S9  人工：浏览器打印→PDF → 大四上/复习资料/；跑 verify_produce_rules.py（PDF 人工上传标记）
```

**每科基线引用**（对照已产 5 科）：正文规模 ≈ 模块数 × 9,000–13,000 汉字（v5.1 契约 #9）；总篇幅按 Prompt #16（≈150 页上限区间 + 分批执行规则），深度版单独加批。
