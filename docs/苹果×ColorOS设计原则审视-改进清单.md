# 苹果 × ColorOS 设计原则审视与改进清单

> 审视对象：`index.html`（v2.3 · 临床深蓝双主题 + 苹果取向液态玻璃 + 粒子动效）
> 审视日期：2026-10-17 ｜ 方法：设计原则梳理（Apple WWDC25 / HIG、ColorOS 水生·流体设计）→ 代码事实核对 → 明暗双主题渲染截图与像素审计 → 逐项定位

---

## 一、设计理念速记（本次审视的基准）

### 1.1 Apple（HIG 三原则 + Liquid Glass + 无障碍）

| 层面 | 原则 | 要点 |
|---|---|---|
| 视觉 | **层次 / 协调 / 一致**（WWDC25 SOTU 三大指导原则） | 玻璃控件作为悬浮层浮于内容之上；「同心性」——UI 曲度随设备外形与控件分组推导，营造视觉协调感 |
| 视觉 | **Liquid Glass 光学** | 内部透明、**沿边缘产生外部高光**、透镜折射；材质自适应明暗环境 |
| 视觉 | 排印 | 加大加粗、清晰层级、左对齐；可读性优先 |
| 交互 | **静止安静，交互以光激活** | 静息态视觉安静；交互时材质"瞬间绷紧并聚光"（instantly flex and energize with light）；元素可临时"浮起" |
| 交互 | 即时反馈与直接操纵 | 每次点按需立即回应；44pt 最小触控目标 |
| 体验 | **Deference（界面退后）** | 界面不与内容争抢注意力，让内容自己发声 |
| 体验 | 无障碍 | 响应"减弱动态效果 / 降低透明度"等系统偏好；**不以颜色作为唯一信息载体** |

### 1.2 ColorOS（水生设计 Aquamorphic → 流体设计 Fluid）

| 层面 | 原则 | 要点（官方表述） |
|---|---|---|
| 视觉 | **水生设计：以"水"为灵感** | 包容、流动、平静，"润物细无声"；轻、快、**无边界**，为用户繁杂的信息生活减负 |
| 视觉 | 自然色彩体系 | 取自海平面日出日落；以**单一蓝色锚定**（宁静、可靠），橘色为点缀 |
| 视觉 | **卡片式布局（Card-Styled Layout）** | 分类整合散落信息、**放大最重要信息**、减少过载；"重要，却不显重" |
| 视觉 | 圆润有机轮廓 | 图标、窗口、卡片、输入框采用更大圆角与柔和过渡 |
| 视觉 | **凝光视效** | 通透纯净；凝光**跟随手指自然流动**，以不同形态指引状态与进程 |
| 交互 | **柔性反馈** | 元素随点按与拖动**自然拉伸、受力挤压、灵动回弹**，呈现真实惯性 |
| 交互 | 量子动画引擎 / 流体动效 | 模拟物理轨迹；涟漪与光影流动；界面切换以高斯模糊过渡（"透过湖水看湖底"） |
| 交互 | 行为预测 | 操作意图即时响应，不迟滞、不等待 |
| 体验 | 人因研究 | 追求"舒适度最高、反应时长最短、准确率最高"的交互方式 |
| 体验 | 空状态插画 | 空白页**不再只显示"无内容"三个字**，用图形让信息生动 |
| 体验 | 包容性 | 针对色觉障碍提高辨识度、**避免蓝紫 / 红绿同时出现**；自适应布局保证跨设备一致 |

## 二、审视结果总览

对当前实现逐层核对后，共定位 **16 项可改进点**：3 项 P0（可用性/无障碍）、6 项 P1（设计语言一致性）、7 项 P2（体验打磨）。逐项如下。

---

## 三、P0 — 建议立即处理（可用性 / 无障碍）

| # | 界面 / 组件 | 存在的问题 | 改进方向 | 依据 |
|---|---|---|---|---|
| **1** | Hero 首屏：chip + 规格框 ×3 + CTA ×3 + 终端三步指南 + 统计条 | 同一组"刷题 / 题库 PDF / 复习手册"三个目的地在**一屏内出现 3 次**（规格框、CTA、终端步骤），数字信息（5,990/2,047）在 chip 与统计条重复；3 个 CTA 同级竞争，主操作不明确 | 收敛为「一主两次」：主 CTA 用实心按钮（网页刷题），其余降为文字链或整体并入终端三步；规格框与统计条择一保留；终端默认页可改为"命令演示"以降噪 | Apple 三原则之 **Deference**："界面退后，让内容发声"；ColorOS **卡片式布局**："分类整合信息、放大最重要的信息、避免信息过载" |
| **2** | 全站按钮/卡片/导航项/瓷砖（`.btn-*`、`.card`、`.deck-tile`、`.nav-*`、`.g-go`…） | 全站仅 1 处 `:active` 样式——**按下零反馈**，触屏设备尤甚（点完即跳转，没有"手感"） | 统一按压反馈：`:active { transform: scale(.97) }` + 玻璃截面高光瞬时加深/缩短；触屏统一 tap-highlight | Apple Liquid Glass："交互时**瞬间绷紧并以光激活**"；ColorOS **柔性反馈**："随点按与拖动自然拉伸、受力挤压、灵动回弹" |
| **3** | ≤400px 学期的 `.nav-term`（高 40px、字号 11.5px）、终端内 `.g-go`（约 28px）、`.term-copy`（约 30px） | 高频操作触控目标低于 44px 基线，小屏误触率高 | 440px 断点把学期切换收进汉堡菜单；终端内按钮高度 ≥40px 或扩大透明热区（padding 外扩） | Apple HIG：**44pt 最小点击目标**；ColorOS 人因研究："舒适度最高、反应时长最短、准确率最高的交互方式" |

## 四、P1 — 设计语言一致性（品牌感与整体协同）

| # | 界面 / 组件 | 存在的问题 | 改进方向 | 依据 |
|---|---|---|---|---|
| **4** | 全局圆角：icon-btn 10 / terminal·spec 12 / glyph 11 / deck·modal 22 / `--r` 20 / 胶囊 | 数值混杂且嵌套无推导关系（外层 20 的卡片里嵌 10/11 的小件），轮廓节奏不统一 | 立"同心圆角"规则：外件 20/22 → 内嵌件 = 外角 − 内边距（≈14/16）；小控件统一 12；terminal 12 → 16 | Apple："根据设备外形确定 UI 曲度并**提升同心性**，营造视觉协调感"；ColorOS："图标、窗口、卡片轮廓更圆润有机" |
| **5** | `.deep-sea` 网格氛围层（全站 fixed 贯穿） | 网格与光晕**从页首一直铺到页脚**，在内容密集区形成持续纹理噪音，抢内容注意力 | 网格在 Hero 区显露、向下渐隐为 0（沿 scroll 或 200vh 距离衰减）；内容区回归留白，氛围交给卡片自身质感 | ColorOS："轻、快、**无边界**，为信息生活减负"；Apple **Deference** |
| **6** | `.grid-empty`（搜索无结果）、`.modal-error`（加载失败） | 空状态只有一行灰字；错误态只有图标+文字，**没有恢复动作入口** | 空状态：轻量图形 + 「清空搜索」按钮；错误态：图形 + 「重试」按钮（复用加载函数） | ColorOS 官方："**Empty State Illustrations**——空白页不再只显示'无内容'三个字"；Apple：清晰传达状态与恢复路径 |
| **7** | Hash 路由视图切换（`.view` display 硬切） | 切换瞬间无任何过渡，空间关系断裂，层级感丢失 | 150–180ms 淡入 + 4px 上移；`prefers-reduced-motion` 下直切；返回时保持滚动位置锚定 | ColorOS："切换界面时以**高斯模糊过渡**（透过湖水看湖底）、无缝流转"；Apple：动效服务于**连续性与 Depth** |
| **8** | Markdown callout（tip / success / note / warning） | 状态语义主要靠颜色 + 标题词；tip 紫与 info 蓝**同屏出现**（色觉障碍敏感组合） | 每类 callout 加**区分性图标符号**；tip 紫色调收敛或替换为带图标的品牌中性色 | ColorOS 包容性："避开蓝紫、红绿同时出现，减轻色弱色盲负担"；Apple："**不以颜色作为唯一信息载体**" |
| **9** | 材质自适应（液态玻璃 / 磨砂） | 只响应了 `prefers-reduced-motion`；未响应 **`prefers-reduced-transparency`**（部分用户开启"降低透明度"后界面依然全玻璃，可读性受损） | 新增 `@media (prefers-reduced-transparency: reduce)`：玻璃 → 半实色、磨砂关闭、描边加深；与既有 `@supports` 回退合并为统一"降级阶梯" | Apple 材质 **Adaptivity**："材质需自动适应系统级偏好并提供实色回退" |

## 五、P2 — 体验打磨（感知品质）

| # | 界面 / 组件 | 存在的问题 | 改进方向 | 依据 |
|---|---|---|---|---|
| **10** | 鼠标光晕（`glass-glow`） | lerp 0.16 跟随偏迟滞、指针离开**瞬灭**，与"凝光"的流体气质不齐 | 跟随提速至 .22–.26；离开改为 300ms 渐隐（透明度过渡）；可保留"到位休眠"省电策略 | ColorOS **凝光视效**："凝光**跟随手指自然流动**"；行为预测："即时响应，不迟滞" |
| **11** | 搜索框 ×4 | 清空依赖浏览器原生 `type=search`（Firefox 无此按钮）；无键盘快捷键 | 自绘清空按钮（有值时浮现）；全局 `/` 聚焦当前视图首个搜索框 | Apple 直接操纵；ColorOS："控件分组、常用能力触手可及" |
| **12** | 长页（题库/手册/资源区） | 深度滚动后无回顶入口，桌面/移动均需手动长滑 | 滚动超过 1.5 屏浮现玻璃胶囊回顶按钮（对齐液态玻璃描边） | ColorOS："重要却不显重"（"being important, yet appearing weightless"） |
| **13** | 模态加载（PDF / Markdown） | 全屏 spinner，加载 1–2s 时出现"空窗闪烁" | Markdown 用文本行骨架屏；PDF 保留 spinner + 进度文案；骨架需与最终排版同构 | Apple：感知性能与**连续性**（减少状态跳变）；ColorOS 流体动效连贯性 |
| **14** | 全局字体栈 | 仅 PingFang / 雅黑 / Segoe；国产安卓设备回退到较粗糙的默认字形 | 栈中前置 `"MiSans","OPPO Sans","HarmonyOS Sans SC"`（有则用、无则退），提升安卓中文渲染一致性 | ColorOS：**OPPO Sans**（Red Dot 获奖）——笔画略宽更稳、清晰舒适 |
| **15** | 模态内 Markdown 表格 | 窄屏下宽表可能溢出容器 | 表格外包横向滚动容器 + 右缘渐变提示 | ColorOS **自适应布局**；Apple 自适应呈现 |
| **16** | 整站（进阶） | 无离线能力；医学复习常处弱网（地铁/图书馆） | 引入 Service Worker：静态壳 + 已访问手册缓存，离线可读 | ColorOS："跨设备、跨环境的一致体验"；Apple 连续性 |

## 六、建议实施批次

| 批次 | 范围 | 内容 | 交付判断标准 |
|---|---|---|---|
| **批次 1（P0）** | Hero 减法 + 全站按压反馈 + 触控目标 | #1 #2 #3 | 首屏目的地唯一化；按下有"回弹"手感；小屏全部目标 ≥44px |

> 说明：批次 1 不改变信息架构，可在一次提交内完成且风险低；批次 2 涉及全局视觉规则，建议先行截图基线（沿用本次 QA 流水线）再逐项合入。
