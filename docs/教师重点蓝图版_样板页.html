03 · 30 秒摘要

五条，每条 ≤30 字。摘要里的每个短句，都能在下面卡片里找到“原文 + 解释 + 自测”。

考前最后一眼
01

外耳集音、中耳传音、内耳感音；任何一环坏了，听力就掉。

02

传导性聋：Rinne 阴性、气骨导差；感音神经性：气骨导同降。

03

胆脂瘤：松弛部穿孔 + 恶臭豆渣样脓 + CT 骨质破坏。

04

突发性聋：一天内骤降，2 周内激素，2～6 周挽救。

05

眩晕先看时间：秒级 BPPV，小时级梅尼埃，天级前庭神经炎。

04 · 考点卡

一张卡 = 一个可背诵单元。六字段：锚点 / 题眼 / 为什么 / 鉴别 / 红线 / 下一步；每张卡自带 2–3 道自测。

🔴 掌握级
K-M02-015

🔴突发性聋

第 125 条 · 教材 P###
📌 重点原文（第125条）：突发性聋应尽早进行听力学检查和专科评估，可在发病 2 周内考虑糖皮质激素初始治疗；初始治疗后恢复不完全者，可在发病 2～6 周评估鼓室内糖皮质激素挽救治疗。
🎯 题眼
一天内听力骤降 → 越早激素越好；2 周内初始，2～6 周挽救。
🧬 为什么
内耳供血依赖终末动脉，栓塞/痉挛 → 毛细胞缺氧。越早恢复灌注，听力挽救概率越高；超过窗口，毛细胞不可逆丢失。
🔗 机制链
病毒感染 / 血管因素 ↓ 内耳供血障碍 → 毛细胞缺氧/损伤 ↓ ↓ 高频听力下降 耳鸣 / 眩晕 ↓ ↓ 言语识别下降 需排除后循环卒中
⚖️ 鉴别
vs 梅尼埃：突发性聋多为单次、数分钟–数小时达峰；梅尼埃反复发作、波动性、伴耳闷。
vs 听神经瘤：进行性单侧感音神经性聋，MRI 可查。
🚨 红线：伴眩晕/神经体征 → 先排后循环卒中；不能只按“耳科”处理。
🩺 下一步：① 纯音测听 + 声导抗；② MRI/增强排除桥小脑角病变；③ 2 周内激素，2～6 周挽救。
🔄 自测：突发性聋激素初始治疗的时间窗是？挽救治疗的时间窗是？为什么越早越好？（答案见附录五）
K-M02-021

🟡梅尼埃病 vs BPPV

第 26–28 条 · 教材 P###
📌 重点原文（第26、27、28条）：梅尼埃病病理基础为膜迷路积水，典型表现为反复发作旋转性眩晕，持续数小时，伴耳闷、低频耳鸣、波动性低-中频感音神经性聋；BPPV 由翻身/头位变动诱发，眩晕持续十余秒，静止后缓解，无耳鸣、耳闷和听力下降。
🎯 题眼
看时间轴：秒级 → BPPV；小时级 + 耳部症状 → 梅尼埃。
🧬 为什么
膜迷路积水 → 内淋巴压力波动 → 反复发作的眩晕与低频听力下降；耳石脱落进入半规管 → 头位变动时短暂眩晕。
⚖️ 鉴别
鉴别轴梅尼埃病BPPV
诱因自发性，反复发作翻身 / 头位变动
持续时间20 分钟–12 小时十余秒，通常 <1 分钟
听力波动性低-中频感音神经性聋正常
伴随耳闷、低频耳鸣无耳鸣、耳闷、听力下降
关键检查甘油试验、听力学Dix-Hallpike / 滚转试验
🚨 红线：首次发作、伴神经体征或进行性听力下降 → 先排中枢/桥小脑角病变，不要直接诊断梅尼埃。
🩺 下一步：梅尼埃急性期用前庭抑制剂/镇静剂控制眩晕；BPPV 首选手法复位（Epley 等）。
🔄 自测：一位患者翻身时出现旋转性眩晕 10 秒，无耳鸣耳闷，听力学正常。最可能的诊断与首选处理是？（答案见附录五）
⚠️ 易错陷阱
梅尼埃病的“数小时”不是“数天”；BPPV 的“十余秒”不是“数分钟”。看到“持续时间”先定位，再看听力，不要先背病名。

06 · 因果链与决策树

机制用因果链，鉴别用决策树。节点 5–9 个，箭头必须写“导致/抑制/代偿”，不画装饰流程。

🔗 因果链 · 咽鼓管功能障碍 → 分泌性中耳炎
上呼吸道感染 / 过敏 / 鼻咽部肿瘤 ↓ 咽鼓管咽口阻塞 ↓ 中耳负压 → 黏膜静脉扩张 → 渗出 ↓ 鼓室积液 → 传导性听力下降 ↓ 长期不愈 → 粘连性中耳炎 / 胆脂瘤

读图：为什么“单侧分泌性中耳炎”要查鼻咽？因为咽鼓管咽口被肿瘤压迫是常见诱因。

🌳 决策树 · 眩晕的时间轴
眩晕 ├─ 翻身/头位变动诱发、十余秒、无听力下降 │ → BPPV（Dix-Hallpike / 滚转试验） ├─ 反复发作、20 分钟–12 小时、波动性听力下降 │ → 梅尼埃病（甘油试验、听力学） ├─ 持续数天、近期上感、无听力下降 │ → 前庭神经炎 └─ 伴复视/构音障碍/共济失调/中枢眼震 → 先排后循环卒中（急诊影像）

读图：第一分支不是“病名”，而是“时间 + 诱因 + 听力”三个轴。

07 · 一页纸

考前最后一眼：3 个必考 + 2 个易混 + 1 个红线。每格只放一个“能直接说出口”的句子。

30 秒可复述
必考 01

传导性 vs 感音神经性聋

Rinne 阴性 + 气骨导差 → 传导性；气骨导同降 → 感音神经性。

必考 02

胆脂瘤三大征

松弛部穿孔、恶臭豆渣样脓、CT 骨质破坏伴硬化边缘。

必考 03

突发性聋时间窗

2 周内激素初始；2～6 周鼓室内挽救；越早越好。

易混 01

梅尼埃 vs BPPV

小时级 + 耳部症状 vs 秒级 + 无听力下降。

易混 02

中枢 vs 周围性眩晕

伴神经体征/中枢眼震 → 先排卒中，不做耳科对症。

红线

突发性聋伴神经体征

先排后循环卒中；不能只按“耳科”处理。

08 · 主动回忆

产出型，不是选择题。先闭卷想 30 秒，再点“显示答案”；答案放附录，正文只给问题。

每模块 ≥8 题
Q1

患者 45 岁，突发左耳听力下降 3 天，纯音测听示左耳中高频感音神经性聋，无眩晕。请说出：诊断、激素初始治疗时间窗、挽救治疗时间窗。

答案：突发性聋。初始治疗在发病 2 周内；恢复不完全者在 2～6 周评估鼓室内激素挽救。越早恢复内耳灌注，毛细胞不可逆损伤越少。
易错：把“2 周”写成“尽早”而不给具体窗；把“2～6 周”漏掉。
Q2

一位患者翻身时出现旋转性眩晕 10 秒，静止后缓解，无耳鸣、耳闷，听力学正常。最可能的诊断？首选检查与处理？

答案：良性阵发性位置性眩晕（BPPV）。首选 Dix-Hallpike 试验（后半规管）或 滚转试验（外半规管）；处理首选手法复位（如 Epley 法）。
易错：把“十余秒”记成“数分钟”；把梅尼埃的听力下降套到 BPPV。
Q3

为什么“单侧分泌性中耳炎”要特别关注鼻咽部？请用一条因果链说明。

答案：鼻咽部肿瘤（如鼻咽癌）压迫咽鼓管咽口 → 咽鼓管功能障碍 → 中耳负压 → 鼓室积液 → 传导性听力下降。因此成人单侧分泌性中耳炎应查鼻咽，排除鼻咽癌。
易错：只写“咽鼓管功能不良”，不写“肿瘤压迫”这一可考因果。

09 · 这页为什么这样排

每个版式决策都对应一条学习科学证据；不是“好看”，是“可读、可记、可查”。

红色锚点块 = 原文冻结教师重点的数值/时间窗/并列结构原样保留；锚点行单读可答，避免“主题名锚点”。
卡片左侧色条 = 重要性信号三色只标“掌握/鉴别/了解”，并与文字标签同时出现；黑白打印仍可辨。
绿色“下一步” = 临床行动每张 🔴 卡必须落到“首选检查/确诊/治疗”，把知识点变成可执行的决策。
对比表只放鉴别轴表给数据，树给路径；不用大段文字描述鉴别，降低认知负荷。
每 3–5 行一个断点callout、表格、代码块、分隔线交替出现，维持阅读节奏；长段落是记忆的敌人。
自测答案不在正文先产出再核对，利用测试效应；答案放附录，正文只留问题，避免“看一眼就会”的错觉。
