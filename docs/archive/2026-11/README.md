# docs 归档说明（2026-11）

本目录是 2026-11-02 P1-S6 文档收敛的产物。

## 为什么归档

工作指令 `AC-P1-09` 要求「活跃 docs ≤5」。收敛前 `docs/` 下有 23 篇 md，
其中大多数是一次性调研、历史版本快照或已被替代的方案。它们**不是垃圾**——
里面有插图选型、网站再设计的决策依据——但混在活跃文档里，新 Agent 分不清
哪份是当前有效的合同。

## 归档 ≠ 删除

- 文件内容一字未改（除路径引用）；
- 全部仍在 git 里，`git log --follow <path>` 可追完整历史；
- 被归档文档之间的互相引用已改为同目录相对路径（`./xxx.md`），仍可点开。
