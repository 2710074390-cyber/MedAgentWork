# 题目评审协议 v0.1（P3-S3 · 2026-11-02）

> 状态：**草案**。最终并入规则注册表（`rules/registry.yaml`）与质量规范。
> 适用：题目级抽检、批次验收、专家盲评、LLM 预评。
> 不含任何用户数据条款——本项目零用户数据。

---

## 0. 这份协议要解决什么

现状是：抽检靠"看一遍觉得行不行"。同一个人隔一天看同一道题，结论可能不同；两个人看同一道题，谁也说服不了谁。原因是**没有共同的刻度**。

本协议给 7 个维度各定 4 个锚点（0/1/2/3），并要求每条评分附**可复核证据**（题干原文、选项字母、规则编号、页码）。做不到"指出具体位置"的分数，一律视为无效评分。

---

## 1. 七个维度

| 维度 | 名称 | 评的是什么 | 关键 |
|---|---|---|:---:|
| D1 | 题干清晰度 | 读完能不能确定"在问什么、限定条件是什么" | |
| D2 | 答案唯一性 | 给定条件下是否只有一个最优解 | ★ |
| D3 | 干扰项质量 | 每个错项是否有**具体**的骗人机制 | ★ |
| D4 | 解析质量 | 解析是否解释了"为什么对"和"每个错项错在哪" | |
| D5 | 溯源可靠性 | 关键主张能否回溯到可核验的原文/页码 | ★ |
| D6 | 难度标注 | 难度是否按结构判定、可复核 | |
| D7 | 概念标注 | 这题测到哪些概念、证据是否具体 | |

★ = **关键维度**，任一 < 2 分 → 该题**否决**（不论总分多少）。

理由：D2/D3/D5 出问题，题目的**教学内容**就是错的或有毒的；D1/D4/D6/D7 出问题是"不好用"，可以修。

---

## 2. 锚点（0–3）

### D1 题干清晰度

| 分 | 锚点 | 判定话术 |
|:--:|---|---|
| 3 | 主诉/关键条件/提问方向齐全，读完无歧义 | "不用回读就能答" |
| 2 | 信息齐全但提问方式含糊（如"下列哪项正确"却没有限定范围） | "要猜他想问哪个层面" |
| 1 | 缺关键限定（年龄/病程/合并症），导致多个答案都成立 | "补一句话才能答" |
| 0 | 题干缺失、含占位词（待补/XXX/略）、或前后矛盾 | "读不懂在问什么" |

### D2 答案唯一性 ★

| 分 | 锚点 | 判定话术 |
|:--:|---|---|
| 3 | 给定条件下唯一最优，且能说出排除其他项的理由 | "只有一个站得住" |
| 2 | 唯一正确，但排除其他项需要额外临床假设 | "要补常识才排得掉" |
| 1 | 存在第二个"也说得通"的选项，或命中 R1（以上都是/绝对化）可被排除法猜出 | "两个都能选" |
| 0 | 答案不在选项内、答案字母与 `is_correct` 不一致、多选未标数量 | "答案本身是错的" |

### D3 干扰项质量 ★

| 分 | 锚点 | 判定话术 |
|:--:|---|---|
| 3 | 每个错项都能指出**具体机制**（表现相似/邻近概念/方向颠倒/时机/人群/机制混淆/以偏概全/旧指南），且四项机制不重复堆叠 | "错得有道理" |
| 2 | 机制大体成立，但有一项是"明显不对的凑数项" | "有一个是白送" |
| 1 | 靠长度/荒谬/结构不一致就能排除（命中 R2/R8/R13 等） | "不看医学也能排除" |
| 0 | 干扰项与正确项语义重复、或不足 3 个有效干扰项 | "没有干扰作用" |

### D4 解析质量

| 分 | 锚点 | 判定话术 |
|:--:|---|---|
| 3 | 说清机制 + 逐项说明错在哪 + 给出可迁移的判断线索 | "看完能解同类题" |
| 2 | 说清为什么对，错项只笼统带过 | "知道对，不知道为什么错" |
| 1 | 只有结论复述（"故选 C"）或未过 R17 信息量门槛 | "等于没解析" |
| 0 | 解析缺失，或解析与答案矛盾 | "解析在讲另一道题" |

### D5 溯源可靠性 ★

| 分 | 锚点 | 判定话术 |
|:--:|---|---|
| 3 | 关键主张可定位到教材/指南的具体章节或**真实印刷页码**，引文逐字可命中 | "能翻到那一页" |
| 2 | 有来源名称与章节，但未逐字核验（`source_quote_status=paraphrase`） | "来源对，原话没核" |
| 1 | 只有"教材/大纲"级别来源，无页码 | "知道出自哪本书，找不到哪页" |
| 0 | 无来源、页码编造、或 `anchor_status=missing/mismatch` | "来源是编的" |

> 注意：教师重点的条号（`keypoint_ref`）**不能替代**医学事实来源。前者回答"考不考"，后者回答"对不对"。

### D6 难度标注

| 分 | 锚点 |
|:--:|---|
| 3 | `difficulty_tier` 与 `step_count` 一致（L1→1 步、L2→2 步、L3→2–3 步、L4→≥3 步），且 tier 与题型相符 |
| 2 | 有 tier 但缺 step_count，或二者轻微不一致 |
| 1 | 只有自由文本 difficulty（如"中等"），不可校验 |
| 0 | 只有 `difficulty_index`（LLM 主观估值，已弃用）或完全没有 |

### D7 概念标注

| 分 | 锚点 |
|:--:|---|
| 3 | 恰好 1 条 primary 且与 `keypoint_ref` 一致；A2/A3/A4/X ≥2 条；每条 evidence 具体到题干/选项 |
| 2 | 结构合规，但 evidence 泛泛（"考查该知识点"） |
| 1 | 缺 concepts、primary 不唯一、或条数不足（check_source_concepts 报 FAIL） |
| 0 | concepts 与题目内容明显不符（挂错概念） |

## 3. 判定规则

1. **单题**：D2/D3/D5 任一 < 2 → `REJECT`；否则总分 ≥ 18/21 → `ACCEPT`；12–17 → `REVISE`；< 12 → `REJECT`。
2. **批次**：抽样 50 题，`REJECT` 率 > 10% → 整批退回；关键维度不达标 > 10% → 整批退回。
3. **否决不可被平均**：一道 D2=0 的题，不会因为其他维度满分而通过。

## 4. 评分者要求

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| 机器规则 | 给 D6/D7 与 D2/D3/D5 的**硬伤**判定（可复核、可复现） | 判断"临床上是否站得住" |
| LLM 预评 | 给 7 维初评，供专家参考 | 冒充专家评分；作为一致性统计的评分者之一 |
| 专家 | 7 维终评，是唯一有效评分 | —— |

**一致性统计只接受 ≥2 名独立评分者。** 单评分者（含 LLM 两轮）只能算 intra-rater 自身一致性，且必须在报告标题里写明，不得称为"专家一致性"。

## 5. 证据要求

每条评分必须能填出下面三项中的至少一项，否则该分数作废：

- 题干/选项**原文片段**（≥6 字）；
- 规则编号（R1–R20 / X1–X6 / S1–S3）；
- 文件路径 + 行号，或教材页码。
