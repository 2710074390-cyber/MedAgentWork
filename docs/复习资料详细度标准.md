# 复习资料详细度标准（HC-26）

> 版本：v1.0.0 · 生效：2026-10-27 · 主责：Agent 5（MedReview）
> 单一事实来源：`scripts/quality_policy.json` 的 `review_detail_*` 阈值
> 机械门禁：`scripts/check_review_detail.py` · 契约 Schema：`schemas/review_detail.schema.json`
> 适用范围：所有**新生成/重新生成**的教师重点版、教学计划版、课程安排版复习资料。
> 旧产物（含 batch040 教师版）只作基线证据，**不追溯、不回改**。

---

## 0. 一句话结论

**详细度不是字数，而是“读一遍后能否独立完成临床推理与应试判断”。**
一份合格的详细复习资料，必须让读者在不另开教材的情况下，对每个掌握级考点回答九个问题：
**是什么 → 为什么 → 怎么认 → 怎么查 → 怎么治 → 和谁鉴别 → 哪里易错 → 怎么记 → 能否回忆**；
掌握级还要能完成一次**病例迁移**（案例）。

## 1. 证据基础：为什么这样定

| 证据 | 结论 | 转成的契约 |
|---|---|---|
| 引导式笔记（guided notes）元分析：大学阶段效果量约 0.4–0.5；医学课程中提供结构化的教师笔记显著提高期末成绩 | “有结构、有空白、有检索点”的讲义优于纯听讲，也优于无结构全文 | 九槽位固定结构 + 每卡自测，而不是把教材段落搬过来 |
| 完整讲义 vs 骨架讲义研究：完整讲义会减少学生自己的笔记加工，部分内容保持下降；骨架/部分讲义反而更好 | 详细 ≠ 全文转录；要给结构、线索与检索任务 | 槽位完整 + 反注水 + 自测，而不是无限加字 |
| 检索练习 + 分散练习系统综述（健康职业教育）：多数研究支持提高考试成绩 | 每卡必须有可检索问题，答案可查 | `🔄 自测` + 附录五答案 100% 覆盖 |
| 认知负荷理论 / worked examples / self-explanation：工作记忆有限；范例+自我解释提示优于纯问题解决；新手需要更多指导，专家会出现“专长反转” | 掌握级需要完整推理链与案例；熟悉/了解级降低要求；超长要拆分 | 三级槽位表 + 字符上限 + `🔬 展开` 分段 |
| 疾病脚本（illness script）理论：临床推理依赖“诱因—病理机制—临床表现”网络 | 按疾病脚本组织，而不是按教材目录罗列 | `🧬 机制` + `👁 识别` + `⚖️ 鉴别` 固定顺序 |
| 细化追问（elaborative interrogation）：问“为什么”能提高深加工 | 每个掌握级考点必须解释“为什么”，不能只给结论 | `🧬 机制` 强制，且含“如果…就不会…”转折 |
| 可取性困难（desirable difficulties）：检索、间隔、交错会让当下感觉更难，但长期保持更好 | 自测要原子化、有间隔调度；不追求“读起来顺” | 自测一题一个事实/决策；配合 `spaced_schedule.py` |
| 国内教学大纲“掌握/熟悉/了解”三级要求：掌握=理解并能运用/分析综合；熟悉=能用自己的话叙述；了解=知道 | 详细度必须按大纲层级分层，不能一刀切 | 掌握 9 槽位+案例；熟悉 7 槽位；了解 4 槽位 |

> 说明：以上是设计依据，不是“字数科学”。字符下限是项目基线校准值，需在每 2 个批次后用实际学习结果复校。

## 2. 两种输入模式

### 2.1 教师重点模式（teacher_keypoint）

触发：提供 `输入素材/{科目}/{科目}_教师重点_*.md`，或 MD 中出现 `📌 重点原文（第X条）` / `（教师重点第X条）`。

- 教师重点仍是**范围契约（下限）**：逐条覆盖、原文锚定、数值零改写（HC-20 不变）。
- 详细度契约是在“覆盖”之上追加“展开”：每条重点不仅要有落点，还要在对应卡片里回答九问。
- 顺序：**先逐条覆盖 → 再按九槽位展开 → 最后自测**；不得用概括替代原文。

### 2.2 课程安排模式（course_schedule）

触发：提供 `输入素材/{科目}/{科目}_课程安排_*.md`，或 MD 中出现 ≥2 个 `## 第N周/第N讲/Week N/Lecture N` 标题。

- 以“周/讲/课时”为组织单位，而不是按疾病模块。
- 每一讲必须回答：**学什么（目标）→ 带着什么来（课前）→ 讲什么（重点）→ 为什么（机制）→ 怎么用（案例）→ 怎么考（映射）→ 会不会（自测）→ 花多久/接哪里（时间与衔接）**。
- 若同时有教师重点，每一讲还必须标注本讲覆盖的教师重点编号。

### 2.3 模块模式（module）

触发：既无教师重点锚点、也无周/讲结构，仅有 `## 模块N` 的常规教学计划版。

- 卡片按九槽位分级要求执行；模块按第 4 节的八块要求执行。
- 不强制教师重点锚点，但必须保留教材页码。

## 3. 卡片级契约：九问 + 案例

### 3.1 九个槽位

| # | 读者问题 | 槽位标签（强制） | 最低内容要求 |
|---|---|---|---|
| 1 | 是什么/在哪 | `<b>🎯 定位</b>` | 一句话题眼 + 定义/解剖位置/分类归属 |
| 2 | 为什么会这样 | `<b>🧬 机制</b>` | 正常→触发→病理→表现的因果链；至少 1 个“如果…就不会…”转折 |
| 3 | 怎么认出来 | `<b>👁 识别</b>` | 典型场景 + 核心症状 + 关键体征 + 关键阴性 |
| 4 | 怎么查/怎么确诊 | `<b>🔍 诊断</b>` | 首选检查 + 确诊金标准 + 分级/分期界值 + 何时做鉴别性检查 |
| 5 | 怎么治/怎么处理 | `<b>🩺 处置</b>` | 治疗原则 + 一线方案 + 禁忌/转诊/随访 |
| 6 | 和谁混/怎么分 | `<b>⚖️ 鉴别</b>` | ≥3 行对比表，≥2 个鉴别对象；每行给可判定差异 |
| 7 | 哪里最容易错 | `<b>🚨 易错</b>` | 1–2 个学生真实错误 + 为什么错 + 正确口径 |
| 8 | 怎么记住 | `<b>🧠 记忆钩子</b>` | 一句话/口诀/对比锚；不得是标题复述 |
| 9 | 能否回忆 | `<b>🔄 自测</b>` | 2–3 个原子问题；答案必须进附录五 |
| 10 | 能否迁移（仅掌握级） | `<b>🏥 案例</b>` | 3–5 行病例 → 关键发现 → 最可能诊断 → 下一步 |

> 旧版 `🎯 一句话题眼` 可保留，但必须并入 `🎯 定位` 一行；不得只写题眼而没有定位/定义。
> 旧版 `🩺 下一步` 视为 `🩺 处置` 的兼容写法；新生成统一用 `🩺 处置`。

### 3.2 分级要求与量化阈值

“正文”指去掉空白、`📌 重点原文` 锚点行与 HTML 标记后的字符数。
“信息单元”指可判定句子/条目 + 表格数据行 + 代码图块；用于防止用空话凑字数。

| 层级 | 必填槽位 | 正文字符下限（pilot / release） | 信息单元下限（pilot / release） | 字符上限 |
|---|---|---:|---:|---:|
| 🔴 掌握 | 九槽位全部 + 案例 | 700 / 900 | 9 / 12 | 3600 / 3200 |
| 🟡 熟悉 | 定位、机制、识别、诊断、处置、鉴别、自测 | 450 / 550 | 6 / 7 | 2600 / 2400 |
| 🟢 了解 | 定位、识别、鉴别、自测 | 220 / 250 | 3 / 4 | 1800 / 1600 |

> 阈值来自 batch040 基线校准：教师版 85 卡平均正文仅 **377 字符**，47 张掌握卡 **0 张** 槽位完整。
> 900 字符 ≈ 九个槽位各 100 字符 + 一张 3 行鉴别表 + 一个短案例，是最低可读单位，不是“越长越好”。

### 3.3 掌握级卡片模板（生成时必须逐行照此结构）

```markdown
#### 🔴 K-Mxx-xxx｜{考点名}（教师重点第X条｜P##）

📌 重点原文（第X条）：{照录原文关键句；数值/时间窗/并列/禁止结构一字不改}

<b>🎯 定位</b>：{一句话题眼}；{定义/解剖位置/分类归属}
<b>🧬 机制</b>：{正常状态→触发因素→病理环节→临床表现}；{如果…就不会…}
<b>👁 识别</b>：{典型场景}；{核心症状}；{关键体征}；{关键阴性}
<b>🔍 诊断</b>：{首选检查}；{确诊金标准}；{分级/分期界值}；{何时加做鉴别性检查}
<b>🩺 处置</b>：{治疗原则}；{一线方案}；{禁忌/转诊/随访}
<b>⚖️ 鉴别</b>：

| 鉴别轴 | 本病 | 鉴别病A | 鉴别病B |
|---|---|---|---|
| 起病/病程 | … | … | … |
| 关键体征 | … | … | … |
| 首选检查 | … | … | … |

<b>🚨 易错</b>：{错误1}；{为什么错}；{正确口径}
<b>🧠 记忆钩子</b>：{一句话/口诀/对比锚}
<b>🏥 案例</b>：{年龄/诱因/主诉/关键查体或检查} → {最可能诊断} → {下一步}
<b>🔄 自测</b>：{问题1}；{问题2}（答案见附录五）
```

熟悉级去掉 `🏥 案例`，其余七个槽位保留；了解级只保留定位、识别、鉴别、自测。

### 3.4 反注水规则（与下限同等重要）

1. 每句话必须提供**事实、机制、决策规则或鉴别点**之一；禁止同义反复、空泛评价、把标题改写成句子。
2. 禁止“详见教材/略/众所周知”替代；禁止只写“首选 X”而不写“为什么首选、何时不选”。
3. 一个槽位只讲一个主题；超过字符上限时，拆成 `#### 🔬 展开：…` 或独立卡片，不得堆成整页墙。
4. 表格优先于长段罗列；因果链优先于重复叙述；同一事实不得在多个槽位重复计入。
5. 自测必须**原子化**：一题一个事实/决策，答案可检索；禁止把整段正文塞进一张卡。
6. 详细度以“读者能否复述/判断”为准，不以“看起来很长”为准；能用 900 字说清，不写 1800 字。

## 4. 模块级契约：八块齐全

每个模块（或每个系统）必须具备：

| 块 | 判定 | 最低要求 |
|---|---|---|
| 前置知识 | `🧩 前置知识检查` | 3–5 个问题，指向本模块先修概念 |
| 模块摘要/目标 | `🎯 30 秒摘要` 或 `学习目标` | 5 条以内，覆盖本模块必考点 |
| 对比表 | 标准 Markdown 表 | ≥3 行数据；不能只用因果链替代 |
| 因果链 | `🔗 因果链` 或含箭头的代码块 | 5–15 节点，箭头标因果 |
| 案例推演 | `🏥 案例推演` | ≥1 例；含关键发现、最可能诊断、下一步、易错分支 |
| 主动回忆 | `🔄 自测` / `🔄 主动回忆` | ≥1 组；答案可检索 |
| 本章小结 | `📌 本章小结` / 一页纸 | 3–5 条 take-home message |
| 展开区 | `#### 🔬 展开：` | ≥2 个/模块；放机制细节、数据表、例外、前沿 |

另：每模块 callout ≥4；模块信息框含权重、题型、谱系位置、预计阅读时间。
案例推演建议格式：

```markdown
### 🏥 案例推演：{主诉}

{3–5 行：年龄/诱因/主诉/关键查体/关键检查}

| 步骤 | 判断 |
|---|---|
| 关键发现 | … |
| 最可能诊断 | … |
| 下一步 | … |
| 易错分支 | … |
```

## 5. 课程安排版契约：每讲八块

每一讲（周/课时）必须具备：

| 块 | 判定 | 最低要求 |
|---|---|---|
| 学习目标 | `🎯 学习目标` | 掌握/熟悉/了解三级，各 ≥1 条；用可测量动词 |
| 课前准备 | `🧩 课前准备` / `前置知识` | ≥2 条，指明先修与预习任务 |
| 课堂重点 | `📚 课堂重点` | ≥3 条，按课时分节；每条含机制或判断规则 |
| 机制解释 | `🧬 机制` / `原理` | 至少 1 条完整因果链 |
| 案例 | `🏥 案例` / `病例` | ≥1 例，含下一步 |
| 课后自测 | `🔄 自测` / `课后任务` | ≥2 问，答案可检索 |
| 时间预算 | `⏱ 时间预算` / `学时` | 写明学时或分钟分配 |
| 前后衔接 | `⏭️ 下周衔接` / `关联` | 说明本讲在课程中的位置 |

量化：每讲正文 ≥1000 字符（pilot）/ ≥1200（教师重点版）/ ≥1400（教学计划版）；信息单元 ≥10 / 12 / 14。
若同时有教师重点：每讲增加 `🔍 考点映射`，列出本讲覆盖的教师重点编号、题型、分值。

## 6. 判定与门禁

### 6.1 命令

```bash
# 教师重点版 / 常规模块版
python scripts/check_review_detail.py \
  --md "复习资料/{科目}教师重点版/{科目}教师重点版_主复习资料.md" \
  --mode auto --profile release_teacher_keypoint \
  --json-out reports/validate/review_detail_{科目}.json \
  --md-out reports/validate/review_detail_{科目}.md

# 教学计划版
python scripts/check_review_detail.py --md <教学计划版 MD> --mode module --profile release_teaching_plan

# 课程安排版
python scripts/check_review_detail.py --md <课程安排版 MD> --mode course_schedule --profile release_teaching_plan
```

### 6.2 通过条件（release）

| 指标 | 通过线 |
|---|---:|
| 掌握级槽位完整率 | 100% |
| 卡片达标率（槽位+字数+单元） | ≥90%（教师重点版）/ ≥95%（教学计划版） |
| 自测答案覆盖 | 100% |
| 模块八块完整率 | 100% |
| 模块案例覆盖 | 100% |
| 详细度总分 | ≥90%（教师重点版）/ ≥92%（教学计划版） |

`pilot` 档位放宽为：核心槽位 ≥85%、卡片达标 ≥75%、自测答案 ≥95%、模块块 ≥85%、案例模块 ≥85%、总分 ≥80%；
`advisory` 模式下 FAIL 只降级为 WARN，**不得用于正式发布**。
