# 复习资料详细度标准（HC-26）

> 适用：新生成或重新生成的教师重点版、教学计划版、课程安排版；旧产物保留原样，不追溯回改。
> 本规范描述内容要求；`scripts/check_review_detail.py` 默认仍为旧固定规则，另有 adaptive 人工审核预检，不替代正式发布门禁。见第 5 节过渡说明。

## 1. 目标与适配

详细度以读者能否完成该考点要求的理解、回忆或判断为准，而非字数、标签或固定块数。先识别来源及教学层级，再识别知识类型与实际学习任务，按重要性、复杂度和安全风险分配篇幅；掌握级应能理解并运用，熟悉级能准确解释，了解级能识别基本概念。层级不等于统一字数或统一疾病模板。

- 疾病/临床决策：按适用性讲清识别、检查、鉴别、处理及必要禁忌；重要判断说明依据、适用条件和例外。
- 机制/病理：讲清关键环节、因果关系及其与表现或干预的关联；证据不足时不强造因果链。
- 解剖/操作：讲清位置、结构关系或步骤，以及关键辨认、风险和禁忌；不强填诊断治疗。
- 分类/标准/数字：讲清分类依据、界值、适用条件及易混差别；不强造病例或机制。
- 有助于应用时使用案例、表格、图、记忆提示和自测；不为凑数量或固定顺序重复内容。自测答案应可检索。

教师重点决定覆盖范围与强调，不等于每条都是完整疾病；教材、大纲、课程安排或其他素材决定补充深度和组织方式。课表按周/讲组织并保留真实学时及衔接；没有来源支持的目标、分值、学时或临床细节不编造。无教师重点时不虚构教师锚点。

## 2. 来源、覆盖与医学安全

有教师重点时，逐条建立覆盖矩阵并在正文设置可追溯落点；条号以输入锚定清单自身连续编号为准。逐字保留教师原文关键句及该条数值、时间窗、剂量、分级、并列和禁止结构，不用概括替代；一条一行，保留 `📌 重点原文（第X条）：` 格式。多个条目可共用一个讲解位置，但每条仍须独立锚定、逐条核对。覆盖矩阵是过程产物，不写入交付正文。

教师只写主题时，原文锚点仅照录原文；另起明确标识的「教材补写」或「其他来源补充」解释，标注真实教材版本及可核实页码或其他具体来源，绝不将补写拼入原文或冒充教师表述。来源缺失、无法核实或冲突时明确标注待核实，记录交付说明，不编造页码、证据、金标准、剂量或唯一方案。教师原文与教材/指南不一致时，两种口径分别标注来源、适用场景及差异；教师口径可用于说明考试要求，但不以考试优先覆盖医学安全，也不擅自裁定过时或有害的做法可用于临床。

## 3. 一处讲透，按需关联

同一知识点确定一个主讲位置，完整解释该层级需要的事实、机制、判断条件及相关安全边界；其他卡片或章节只保留必要的情境提示与明确的主讲位置引用，不复制整段。原文锚点逐条保留不视为无意义重复；必要的禁忌、关键数字和自测为安全或学习目的可简短重申，但不得借此堆字。跨模块引用须指向真实存在的标题或卡片，确保读者可找到完整解释。

禁止空泛评价、同义反复、模板填空及用“详见教材”代替核心说明。长内容按主题自然拆分，短内容说清即止；可读性靠结构和信息密度，而不是硬性字符上下限。保留真实页码、可检索答案、单一合并交付文件及既有导出兼容约束；按适用内容选择图表与展开区，不强制每卡或每模块固定数量。

## 4. 自检

1. 核对输入范围、层级与教师条目：覆盖矩阵无遗漏，原文和硬事实保持原样；无教师重点则标记不适用。
2. 按知识类型核查相关要素和关键安全边界，检查来源、页码、冲突及待核实事项；不存在的知识不强行填写。
3. 检查每个知识点有明确主讲位置，引用可达，无不必要重复；自测答案可检索。
4. 对合并后的交付文件执行覆盖、导出兼容和现有详细度门禁，保存真实结果，不把分片结果当作交付结果。

## 5. 现有门禁过渡

`check_review_detail.py` 的旧版 release 仍要求九槽位、固定区块和字符/信息单元阈值，可能将合乎本规范的自适应资料判为 FAIL。仍应运行并记录 profile、报告与真实 PASS/FAIL；人工逐项区分真实内容缺失与仅因旧模板产生的误报，不为刷分制造不适用内容，也不把 FAIL、advisory 或人工复核说成 PASS。现有 R2/R3 或正式发布流程如仍 enforce 该门禁，FAIL 仍会阻断发布；须等待门禁、策略和 schema 同步，或由有权负责人按现行流程明确处理，不能自行绕过。教师重点覆盖和导出兼容门禁不因本过渡放宽。

## 6. 证据基础与历史测量

本规范延续引导式笔记、检索练习、认知负荷、疾病脚本、细化追问和分层学习的原有依据：结构化线索和可检索答案有助于学习；案例、因果和对比应服务知识类型及学习任务，不能从研究直接推出固定字符数、槽位或每卡病例。每两批可用学习结果复核实际详细度和可读性。

2026-10-27 的旧版 release 基线（按当时规则测量）：耳鼻喉教师版 85 卡、7 模块、平均正文 377 字符，掌握槽位完整 0/47、自测答案覆盖 88.2%、模块八块 75%，判 FAIL；教学计划版 87 卡、5 模块、平均 716 字符，掌握槽位完整 0/41、自测答案 0%、模块八块 75%，判 FAIL。报告为 `reports/validate/review_detail_ent_baseline_20261027.json|md` 和 `reports/validate/review_detail_ent_teaching_baseline_20261027.json|md`。这些是改进前证据而非对旧产物的重新签收。

batch043 急诊与灾难医学教师重点版 v6.0 旧规则下 48 卡、8 模块、平均正文 1515.3 字符，掌握槽位、卡片达标、自测答案、模块八块及总分均为 100%，旧版 release_teacher_keypoint 为 PASS；同时 HC-20 硬事实 105 类缺失 0、61 条重点落点齐全，V14 `**` 和 `<details>` 为 0，`<b>` 473/473 配对。该样本不构成统一字数或结构配额。

## 7. 交付与相关规则

分片生成时，`M01.md…Mnn.md` 留在 `中间产物/{batchID}/bpa_v6/`，合并为 `复习资料/{科目}教师重点版/{科目}教师重点版_主复习资料.md`，附录一至五随文写回。合并命令 `python scripts/merge_review_shards.py --shards 中间产物/{batchID}/bpa_v6 --appendix 中间产物/{batchID}/bpa/appendix.md --out <交付路径>`；合并器检查一级标题、模块数、卡片可解析及附录五唯一，失败如实报告。详细度门禁、V14/V17 仅以合并后的结果作为交付检查。

HC-20 覆盖锚定不因 D6 调整而放宽；HC-18 的导出兼容须单独检查；HC-24 约束题目层，HC-26 约束资料层；HC-25 现行 R2/R3 enforce 阻断按第 5 节处理。展开区和 callout 保留为按需工具，语法与导出兼容规则继续生效。
