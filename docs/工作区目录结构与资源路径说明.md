## 二、工作流五阶段产物目录

### 📁 输入素材/ — 原始教材入口
- **作用**：用户放入待处理的教材章节、课堂笔记、考试重点
- **写入者**：用户手动
- **命名规范**：`{科目}_{章节}_{类型}.{txt/md/pdf}`，如 `内科学_心衰_章节原文.txt`
- **生命周期**：批次完成后归档至 `archive/输入素材/`

### 📁 中间产物/ — Agent 2 产出
- **作用**：Agent 2 (MedGen) 根据教材生成的题库 JSON + 备考资料
- **写入者**：Agent 2（经 `save.py` 入库）
- **结构**：`中间产物/batch{NNN}/` 子目录，含分模块 JSON
- **散落文件**：调用指令、RAG 片段、热点文件等中间态文件
- **生命周期**：批次 APPROVED 后归档至 `archive/中间产物/batch{NNN}/`

### 📁 质检报告/ — Agent 3 产出
- **作用**：Agent 3 (MedQC) 输出的 JSON 质检报告 + CoT 自查记录
- **写入者**：Agent 3
- **命名规范**：`batch{NNN}_质检报告.json`、`batch{NNN}_CoT自查.md`
- **生命周期**：批次 APPROVED 后归档至 `archive/质检报告/batch{NNN}/`
- **⚠️ 注意**：分散的 `质检报告/archive/` 子目录已于 2026-08-09 合并至根级 `archive/质检报告/`

### 📁 最终产物/ — Agent 4 产出
- **作用**：Agent 4 (MedFix) 修复后的最终题库 + 追溯日志 + 押题卷 HTML
- **写入者**：Agent 4
- **结构**：`最终产物/batch{NNN}/` 子目录（含 `ALL_questions_FIXED.json` + `AGENT4_追溯日志.json`）
- **根级文件**：押题卷 HTML（`{科目}押题卷_2026.html`）+ `index.html` 索引页
- **生命周期**：用户签收后，题库合并入 GoldenSet，本目录归档

### 📁 复习资料/ — Agent 5 产出
- **作用**：Agent 5 (MedReview) 综合生成的主复习手册
- **写入者**：Agent 5
- **命名规范**：`{科目}_主复习资料_v{X}.{md/html}`
- **活跃版本**：各科目保留最新版本（v5/v5.1），旧版本归档
- **渲染**：`python 知识库素材/render_review.py "复习资料/XXX.md"` 生成自包含 HTML

### 📁 GoldenSet/ — 金标准题库（写保护）
- **作用**：用户手动签收的题库，作为回归测试基准
- **写入者**：⚠️ **仅用户手动签收，任何 Agent/脚本禁止写入**
- **结构**：
  ```
  GoldenSet/
  ├── Layer0_锚定层/      ← 核心金标准
  ├── Layer1_扩展层/      ← CMB_val_280（基础知识点）
  ├── Layer2_临床推理/    ← CMB_clin_74（复杂推理）
  ├── structured/         ← 结构化题库
  ├── regression_reports/ ← 回归测试报告
  ├── 真题上册.md / 真题下册.md
  ├── validate.py         ← GoldenSet 校验脚本
  └── regression.py       ← 回归测试脚本
  ```
- **保护机制**：`save.py` / `ingest.py` 内置 GoldenSet 写保护，任何脚本拒绝写入

## 三、知识库与脚本资源

### 📁 知识库素材/ — 个性化 RAG
- **作用**：医学教材向量索引 + 混合检索（向量语义 + 关键词精确匹配）
- **核心脚本**：
  | 脚本 | 用途 |
  |------|------|
  | `search_kb.py` | 两阶段检索（向量+重排序），`--hybrid` 启用混合 |
  | `embed_index.py` | PDF 教材嵌入索引 |
  | `embed_md.py` | 贺银成 Markdown 嵌入 |
  | `embed_zhaozhao.py` | 昭昭题眼嵌入 |
  | `validate_configs.py` | 配置完整性校验 |
  | `render_review.py` | 复习资料 MD → HTML 渲染 |
- **结构**：
  ```
  知识库素材/
  ├── subject_config.json     ← 全局注册表（15 学科入口）
  ├── configs/                ← 各学科独立配置（chunk/检索/语义保护）
  ```

- **检索示例**：`python 知识库素材/search_kb.py "心力衰竭诊断" --subject internal-med --top 10 --hybrid`

## 五、根目录白名单（铁律①）

根目录**仅允许**以下文件：

```
✅ 配置文件：SOUL.md  USER.md  CONTEXT.md  workflow_state.json  操作流程.txt  .gitignore
✅ 守门脚本：gate_check.py  healthcheck.py  validate_options.py  save.py  ingest.py  verify_page_numbers.py
```

**绝对禁止**出现在根目录：
```
❌ 任何 *_report_*.json（validate/healthcheck/maintenance/gate 产物）→ reports/{子目录}/
❌ __pycache__/  *.pyc → .gitignore + maintenance.py 自动清理
❌ 临时/备份/下载文件 → temp/ 或 archive/
❌ 散落脚本 → scripts/
❌ 技术文档 → docs/
```
