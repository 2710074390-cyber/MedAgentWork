# MedAgentWork 项目介绍 v4.0（2026-08-21 最新版）

> 一句话：**把 LLM 关进质量管线**——一个把临床医学教材 + 考研真题素材转成结构化题库
> 的多 Agent 生产系统：5 个 Agent 编排 + 机械化门禁 + 契约 Schema + 可追溯产物。

**本版（v4.0）核心变化：题库生成规则新增 HC-18「考研真题配额」——每个学科批次约 1/5 的题目为考研原题（引用或轻度改编自 1994–2025 考研西综真题素材），之后所有学科批次按此规则执行。**

---

## 1. 这是什么

MedAgentWork 向用户交付的不是"让 AI 出几道题"，而是一套**可复现的题库生产流水线**。运行于 DeepSeek Harness (DSH)：

```
用户 ─► MedMaster（编排者，主会话）
          ├─► MedGen（出题）    → 中间产物/        + 门禁 validate_options.py
          ├─► MedQC（质检）     → 质检报告/        + 门禁 gate_check.py
          ├─► MedFix（修复）    → 最终产物/        + 门禁 gate_check.py
          ├─► MedReview（复习资料）→ 复习资料/      + 终审门禁
          └─► 用户审查 → 签收 → GoldenSet 真题归档
```

每位 Agent 以 `.dsh/skills/` 技能形式存在，由主会话以后台子代理调用，产物直接写文件（无剪贴板中转）。

## 2. 设计命题

医学题库同时踩中四个最难约束：**事实零容错、格式强结构、规模化需求、可追溯性**。
幻觉是 LLM 的内生属性，不是 Prompt bug——本项目的回答是**用架构而非 Prompt 兜底**：

- **文件系统当管线**：Agent 按目录交接，失败点可追踪、可回滚、可人工介入
- **Pipeline as Code**：阶段、门禁、SLO 阈值集中声明（`pipeline/pipeline.yaml`）
- **声明式规则会失效，强制式才有效**：Agent 产出契约 Schema + 机械化校验脚本
- **代码、LLM、人三者分工**：LLM 生成，代码校验，人签收金标准

## 4. 最新版更新亮点

### 🎯 HC-18 考研真题配额（2026-08-21 新增 · 本版主打）

- 每批题库 **约 1/5（目标 20%，合格带 15%–25%）为考研原题**，其余按教材原创
- 真题素材：**1994–2025 考研西综真题**（GoldenSet 解析产物 9,616 条：上册试卷含题干/选项 + 下册贺银成精析含答案/解析，按 gs_id 配对）+ RAG 贺银成真题 / 昭昭题眼索引
- 引用方式：原题引用或轻度改编（换问法/换情境，**知识点、答案、数值零改动**）
- 标注：每题携带 `kaoyan_origin` 元数据（gs_id/年份/题号/模式）+ `[源:考研真题 GS-XXX]` 溯源 + 解析来源句
- 机械化：`scripts/kaoyan_picker.py`（pick 按章节检索真题候选并配对答案；check 终端校验占比）
- 红线：真题答案以官方公布为准——发现与教材冲突 → 升级告警，**禁止**静默改答案
- 无真题覆盖章节（如中医方剂、医患沟通等）：配额清零、以原创补齐并如实标注

### 📦 2026-08-20/21 批量升级（v3.0 → v4.0 之间的地基）

- **P1 修复**：门禁 fail-open 三连修复（终审 fail-closed）、状态覆写数据丢失窗口、契约双源收编、渲染链收敛、GoldenSet 解析器 v2.0（5,168 题 / 31 套卷 / gs_id 全局唯一）、R9 假阳性、多选答案截断
- **第三方交付集成**：CMExam 锚点难度体系（anchor_bank.py + 校准难度回写 registry）、考频蓝图（blueprint.py）、组卷公式（paper_builder.py + 统一押题卷模板 quiz_template.html）
- **统一题库数据层**：`qbank.py` 注册表（共 4,296 题注册，2026-08-21 去重）+ 最终交付 MD 导出（`ALL_questions_FIXED.md`）
- **DSH 主流程**：状态单一入口（workflow_state.py 原子写）、契约摄入校验、批次运行手册（medbatch skill）

## 6. 目录结构（本仓库）

```
├── Prompt版本/            # 5 个 Agent 的完整系统提示词（核心资产，当前版 *_current_*）
├── .dsh/skills/           # DSH 技能（medmaster/medgen/medqc/medfix/medreview/medbatch）
├── scripts/               # 门禁与工具（validate_options/gate_check/qbank/fact_check/kaoyan_picker/...）
├── schemas/               # Agent 输出契约 JSON Schema
├── GoldenSet/             # 考研真题素材与解析器（parse_goldenset.py v2.0）
├── 知识库素材/            # RAG 教材索引、检索脚本、学科配置
├── 中间产物/ 质检报告/ 最终产物/ 复习资料/
├── tests/                 # 回归测试套件
├── docs/                  # 本文档 + 使用指南 + 架构演进 + TODO
├── CONTEXT.md SOUL.md USER.md   # 共享规则（工具路径/硬约束/用户画像）
```

> 公开仓库（MedAgentWork-Public）为脱敏导出：`prompts/` `pipeline/` `tools/` `docs/` `tests/`，
> 不含真题数据与题库产物；GoldenSet 数据需自行准备。

## 7. 开始使用

1. 读 `docs/MedAgentWork_使用指南_v2.0.md`（唯一用户手册：DSH 主流程操作）
2. 把教材/笔记放入 `输入素材/{科目}/`，打开 DSH Web 新建会话，输入「开始新批次：科目+章节」
3. 回显确认后全自动走完 MedGen→MedQC→MedFix→MedReview→终审；你只需审查与签收
