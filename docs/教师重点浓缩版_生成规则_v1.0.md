## 0. 为什么换：舒适度不是审美，是结构

对三份真实产物做过量化（2026-11-16）：

| 产物 | 卡片数 | 卡片正文中位数 | 表格 | Callout | 模板复读行占比 |
|---|---:|---:|---:|---:|---:|
| 急诊 BPA v1.0（九槽位） | 48 | 1656 字 | 38 | 8 | 0% |
| 眼科·教材浓缩型 v5.2 | 106 | 1010 字 | 99 | 151 | 1.2% |
| 眼科教师重点版（旧模板） | 24 | — | 少 | 少 | **25.5%** |

BPA 的问题不是「错」，是「均匀」：每张卡都是 🎯🧬👁🔍🩺⚖️🚨🧠🏥🔄 十行等长标签，单卡中位 1656 字，全册只有 8 个 Callout（约 1 个/模块），读者进入纯文本长跑。眼科旧模板则更直接：`考试落点：本题组常以 A1 考定义…` 重复 30 次、`补充：本卡的复习顺序建议…` 重复 40 次，占全部长行的四分之一——模板复读是「看起来累」的第一元凶。

教材浓缩型之所以舒适，是四件事同时成立：

1. **阅读单位约 1000 字**，不是 1650 字的标签墙；
2. **每 3–5 行一个断点**（表 / Callout / 展开 / ASCII 图）；
3. **叙事顺序固定为「定义 → 为什么重要 → 第一性原理 → 临床细节 → 易错」**，不是十行等长填空；
4. **零模板复读**：每个考点的句子只为这个考点写。

TKC 保留 BPA 的全部覆盖契约（逐条原文、100% 落点、数值零改写），只换呈现方式。

## 1. 强制路由

| 输入 | 路径 |
|---|---|
| 有教师重点 / 复习大纲 / 锚定清单 | **TKC v1.0 强制**（本文件），不得回退教材目录平铺 |
| 无教师重点 | 教学计划版流程（教材浓缩型 D1–D5） |

**判定即承诺**：输入 N 条 = 交付 N 条落点。权重只决定篇幅与配题，不决定是否覆盖。
**覆盖是下限，不是上限**：落点只保证「这条被讲到」，不限制「这条能讲多深、能补多少」。教师条目模糊时，按 §3.1 自主补全，不把自己锁在原文直接提到的几个词里。

## 2. 三层结构

### 2.1 科目层（顺序固定，≤3 页）

1. 标题 + 来源/版本说明（教师重点来源、教材版本、ISBN）。
2. `## 科目导航：{科目}怎么学？`
   - 一句话核心逻辑链（把全科串成 2–4 个轴）
   - 命题规律（4–6 条，每条 ≤1 行）
   - 题型结构（A1/A2/A3/B1/X 各考什么）
   - 复习路径（模块顺序 + 理由）
   - 避坑提示（3–5 条，写成可执行动作）
3. `## 使用指南`：🔴🟡🟢 分层阅读策略、主动回忆法、三遍刷法。
4. `## 📐 {科目}疾病谱系总览`（ASCII，按「良性→危重→不可逆」或「功能→结构」排）。
5. `## 模块速览地图`（表：模块｜名称｜教学范围｜谱系位置｜与其他模块连接）。
6. `## 🗺️ {科目}跨模块概念地图`（ASCII，一张图说明模块间因果/解剖/诊疗连接）。

> 科目层不是装饰：它回答「这门课怎么学、先学哪、哪里最容易丢分」。缺这一层，读者进入模块就没有坐标系。

### 2.2 模块层（顺序固定）

```markdown
## 模块N：{模块名}（M{nn}）｜教师重点第 a–b 条｜约 X 分钟

### 🧩 前置知识检查
（3–5 个问题，只提问不给答案，指向本模块先修概念）

### 🎯 高收益摘要
（≤5 条，每条 ≤40 字，句尾带〔第X条〕）

### 📋 结构化笔记
（若干考点块，见 2.3）

### 🧠 因果链：{本模块主线}
（按需；ASCII 5–9 节点，箭头标因果；图下接 `> [!INFO]` 一句临床含义）

### 🌳 鉴别决策树：{入口主诉}
（按需；首分支=关键鉴别轴，每层 ≤3 分支）

### 🔄 主动回忆
（8–12 个填空，答案用《》包裹；先遮答案自测，再核对）
```

- **因果链 / 决策树按需**：机制型、鉴别密集型模块必须有；单纯分类模块可只保留其中一张。
- **不设「本章小结」八股**：模块末尾的主动回忆本身就是收口；确有 3 条以上 take-home 时才写 `### 📌 带走的五句话`。
- **不设模块封面表格**（权重/卡片数/阅读时长）：这些信息放进模块标题行与速览地图，不再重复。

### 2.3 考点块解剖（核心）

```markdown
#### 🔴 【掌握级】{考点名}（第X条｜P##）

📌 重点原文（第X条）：{逐字照录；数值/时间窗/并列/禁止结构一字不改}

{定义段：1–3 句，说清是什么/在哪/分类归属，句末标教材页码}

💡 <b>为什么重要</b>：{这个考点在考试或临床里决定什么；≤2 行，必须是判断，不是评价}

🧬 第一性原理：{正常→触发→病理→表现；必须含「如果…就不会…」或「本质上就是…」；≥150 字}

{临床细节段：识别 / 检查 / 处置 / 鉴别，按知识类型取 2–4 段；每段只讲一件事}

#### 🔬 展开：{更细的分型/数值/机制/术式}

（列表、表、或 1–2 段说明；默认可见）

> [!WARNING] 易错陷阱
> {1–2 个真实错误 + 为什么错 + 正确口径}

| 鉴别轴 | 本病 | 鉴别病 A | 鉴别病 B |
|---|---|---|---|
| … | … | … | … |
```

**固定顺序只有前四件**：标题 → 原文锚点 → 定义段 → 为什么重要 → 第一性原理。之后按知识类型自由组织，不要求每块都出现「识别/诊断/处置/鉴别」。

**分级要求**：

| 层级 | 必含 | 正文字数下限 | 建议上限 |
|---|---|---:|---:|
| 🔴 掌握 | 原文锚点、定义段、为什么重要、第一性原理、≥1 个视觉断点 | 600 | 2400 |
| 🟡 熟悉 | 原文锚点、定义段、为什么重要、机制或识别、≥1 个视觉断点 | 320 | 1800 |
| 🟢 了解 | 原文锚点、定义段、识别或鉴别 | 140 | 900 |

> 字数是**下限**，不是配额。能用 800 字说清就不写 1600 字；超过上限优先拆 `#### 🔬 展开`，不堆成整页墙。

### 2.4 知识类型适配（不套同一把尺）

| 知识类型 | 必须讲清 | 不要强填 |
|---|---|---|
| 疾病 / 临床决策 | 识别、首选检查、一线处理、禁忌与转诊、和谁鉴别 | 无关的流行病学、冗长病理 |
| 机制 / 病理生理 | 关键环节、因果关系、与表现/干预的连接 | 没有证据的「可能机制」 |
| 解剖 / 操作 | 位置、层次关系、步骤、关键辨认与风险 | 诊断治疗细节 |
| 分类 / 标准 / 数字 | 分类依据、界值、适用条件、易混差别 | 虚构病例、强行机制 |

## 3. 教师重点锚点与补写

1. 每条教师重点在**对应考点块开头**独立一行：`📌 重点原文（第X条）：{原文}`；不包 `<b>`，不写成「第26、27条」，一条一行。
2. 原文只给主题名时，锚点**照录主题名**，紧跟其后的定义段即教材补写，段末必须标真实教材页码；不得把教材内容拼进锚点行。若启用 `check_keypoint_coverage.py --adaptive` 逐条核验，则另起一行：`📚 教材补写（第X条）：{补写要点 + 教材页码}`。
3. 多条重点共用一个考点块时，锚点逐条排列（每条一行），考点标题写 `（第X、Y条｜P##）`。
4. 原文与教材冲突时，分别标注来源与适用场景；考试口径不覆盖医学安全。
5. 页码只写教材真实标注；全篇同一页码视为占位（HC-10）→ FAIL。

### 3.1 模糊重点的自主补全（2026-11-16 用户裁定）

**先判断「模糊」**（任一即算）：

- 只有主题名或章节名，没有可判定事实（如「视神经炎」）；
- 只有动作指令，没有对象细节（如「掌握××的鉴别」）；
- 并列项未展开（如「常见并发症」没列具体是哪几个）；
- 术语与教材章节标题不完全对应，需要先定位才能确认写哪一节；
- 条目含超出教材范围的表述，需要回源核实。

**处理顺序（不许跳步）**：

1. **先定位，再动笔**：用关键词 + 目录 + 页码在教材中定位对应章节，读**整节**，不是只搜与原文同词的句子。
2. **判断考试边界**：按层级（掌握/熟悉/了解）与本省题型，确定「为了回答这个考点，读者最少需要知道什么」。把定义、机制、识别、首选检查、首选处理、鉴别、易错中适用的部分写全。
3. **允许超出原文**：教师条目未直接提到、但属于该考点完整理解所必需的内容，必须补。典型包括：分类依据、相邻疾病鉴别、关键数值与界值、适用条件与禁忌、常见错误口径。
4. **不越界**：补写必须能回答「这个考点会怎么考、怎么用」；不把整章搬过来，不把相邻章节的独立考点塞进本条。内容确实重要且独立时，另立考点块或写 `🔬 展开`。
5. **标来源**：补写内容标真实教材页码；与教师原文冲突时分别标来源、适用场景。补写不得写成教师原话。
6. **补不出就标待核实**：教材无对应内容、来源冲突或无法核实时，写「待核实」并列入交付说明，不编造页码、剂量、金标准或唯一方案。

**示例（第39条只写「视神经炎」）**：至少补到——定义与分类（视神经乳头炎 / 球后视神经炎）、典型表现（视力骤降、眼球转动痛、RAPD）、首选检查（视野、VEP、MRI）、与缺血性视神经病变及视盘水肿的鉴别、治疗原则（激素冲击的时机与禁忌）。这些都不在「视神经炎」四个字里，但不写就答不了题。

> 边界：补全是「把这条讲透」，不是「把整科写完」。新增内容一旦需要独立成节（如另一个疾病、另一套分级），就另立考点块，不塞进本条。

## 4. 反模板复读（硬红线）

以下任一出现即返工：

| 反模式 | 判定 |
|---|---|
| 同一句 ≥40 字在全文出现 ≥8 次 | FAIL（机械） |
| 模板复读行占全部长行 >5% | FAIL（机械，`template_repeat_ratio`） |
| 每张卡以同一句套话开头/结尾 | 人工抽检，出现即返工 |
| `考试落点：本题组常以…`、`补充：本卡的复习顺序建议…`、`本卡在期末中常以 A1 考…` | 禁用句式，出现即返工 |
| 空泛评价（「非常重要」「必须掌握」「值得注意」）单独成句、无事实 | 人工抽检 |

**允许的重复**：原文锚点、必要禁忌、关键数字在不同考点的简短重申；这些不算模板复读。

## 5. 视觉与节奏

- 每 3–5 行正文出现一个断点（Callout / 表格 / 展开区 / ASCII 图 / 分隔线）；连续纯文本 ≤10 行。
- 每个**掌握级考点**至少 1 个视觉断点；每个模块 ≥2 张表、≥4 个 Callout（≥3 种类型）、≥2 个 `#### 🔬 展开`。
- 表格 ≤5 列，单元格 ≤20 字；首列是鉴别轴。
- Callout 只用 `WARNING / TIP / INFO / SUCCESS / NOTE` 五型；标题 ≤20 字。
- 禁止 `**` / `*` 行内强调、`<details>`、Mermaid、装饰性插图；粗体只用 `<b>`，斜体只用 `<i>`。
- 字号、配色、打印基线以 `references/review-visual-spec.md` 为准。
