> **适用范围**：所有带「教师重点 / 复习大纲 / 锚定清单」输入的复习资料批次
> **规则地位**：HC-20 的落地细则。与 `medagentwork-skill/skills/medagentwork/references/bpa-v1.md` 同源，二者冲突时以 skill 版为准（分发口径）。
> **设计依据**：`Obsidian产物/教师重点蓝图版/教师重点蓝图版复习资料设计方案_v1.0.md`（证据基础与评估标准）
> **样板**：`Obsidian产物/教师重点蓝图版/耳鼻咽喉头颈外科学_教师重点蓝图版_主复习资料.md`

## 1. 强制路由

| 输入 | 路径 |
|---|---|
| 有教师重点 / 复习大纲 / 锚定清单 | **BPA v1.0 强制**，不得按教材目录平铺 |
| 无教师重点 | medreview 教学计划版流程（D1–D5） |

**判定即承诺**：教师重点 N 条 = 交付 N 条落点。权重只决定篇幅与配题，不决定是否覆盖。

## 2. 结构骨架

### 2.1 科目层（≤2 页）

1. 使用指南 + 图例（🔴🟡🟢、`K-M{nn}-{nnn}` 卡片 ID）。
2. 科目蓝图：模块 × 权重 × 卡片数 × 题型分布（一张表）。
3. 三条阅读路径：30 秒（一页纸+数字锚）/ 3 分钟（对比表+决策树）/ 30 分钟（卡片+自测）。
4. 五个记忆主轴。
5. 十个高频陷阱（每条 ≤1 行）。
6. 疾病谱系总览 + 跨模块概念地图（各 1 张 ASCII）。

### 2.2 模块层（1+7，顺序固定）

```
封面（权重｜题型｜卡片数｜谱系位置｜三个题眼｜阅读时长）
→ 🧩 前置知识检查（3–5 问）
→ 🎯 30 秒摘要（5 条，每条 ≤30 字）
→ 📋 考点卡群
→ 📊 对比速查（2–4 张表）
→ 🔗 因果链（1 张，5–9 节点）
→ 🌳 决策树（1 棵，首分支=关键鉴别轴）
→ 📌 一页纸（6 格）+ 🔄 主动回忆（8–12 题）
```

### 2.3 卡片八行（顺序固定）

| 行 | 字段 | 要求 |
|---|---|---|
| 1 | `📌 重点原文（第X条）：` | 逐字照录，含全部硬事实；单读可答；**不包 `<b>`** |
| 2 | `<b>🎯 一句话题眼</b>` | ≤40 字，看到什么→想到什么 |
| 3 | `<b>🧬 为什么</b>` | 2–5 行，正常→异常 |
| 4 | `<b>🔗 机制链</b>` | 5–9 节点，🔴 卡建议写 |
| 5 | `<b>⚖️ 鉴别</b>` | 1–3 个易混病，给鉴别轴 |
| 6 | `<b>🚨 红线</b>` | 禁忌/急症；无则写"无" |
| 7 | `<b>🩺 下一步</b>` | 首选检查/金标准/首选治疗，1–3 条 |
| 8 | `<b>🔄 自测</b>` | 2–3 问，产出型，答案进附录五 |

## 3. 锚点自足五规则

1. 主体完整（疾病/结构/操作 + 部位/人群/分期等限定）。
2. 事实齐全（数值、时间窗、剂量、百分比、分级界值、并列与禁止结构同在一行）。
3. 不是主题名（`XX 的病因及治疗原则` 不合格）。
4. 可单读（遮住正文只看锚点能答题）。
5. 可回源（`（第X条｜教材P###）`，无页码不虚构）。

**主题名条目**：回源教师重点正文/教材补足，格式 `——①…②…③…`；补不出标 `ambiguous` 并在交付说明列出。

## 4. 事实与来源

- 优先级：教师重点原文 > 教学大纲/课表 > 教材 > 题库/讲义。
- 数值冲突：教材为准并显式标注；教师明确的考试口径保留教师值。
- 页码只用原文真实标注；全篇同页码视为占位（HC-10）→ FAIL。
- 删除/合并写 CHANGELOG，理由限 duplicate / out_of_scope / error / merge。

## 5. 门禁

```bash
# 覆盖门禁（必须 PASS）
python medagentwork-skill/skills/medagentwork/scripts/check_keypoint_coverage.py \
  --keypoints "输入素材/大四上/{科目}/{科目}_教师重点_锚定清单_{date}.md" \
  --md "Obsidian产物/教师重点蓝图版/{科目}_教师重点蓝图版_主复习资料.md"

# 结构自检（工作区脚本）
python 中间产物/bpa_v1/selfcheck.py
```

**通过线**：条目覆盖 100% + 带单位硬事实缺失 0 + 落点行内事实缺失 0 + 每模块 8 区块齐全 + 每模块 ≥8 题。

**抽检（3-10-30）**：每模块 3 张卡遮住正文只读锚点；每科 10 个数字回教材；30 秒盲读一页纸能复述 4/5 个必考点。

## 7. 改稿工作流

1. 源分片放 `中间产物/{batchID}/`（`head.md` + `M01.md…M07.md` + `appendix.md`）。
2. 改分片 → `cat` 合并 → 复制到交付路径。
3. **不要直接改交付大文件**，否则分片与交付物不一致。
4. 每次改完复跑门禁与自检，结果写进 `reports/gate/`。
