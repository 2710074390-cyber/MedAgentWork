# 教师重点蓝图版（BPA v1.0）· 复习资料生成规则

> **生效**：2026-10-22（耳鼻喉全科签收当日）
> **适用范围**：所有带「教师重点 / 复习大纲 / 锚定清单」输入的复习资料批次
> **规则地位**：HC-20 的落地细则；本工作区生成按 `docs/复习资料详细度标准.md` 的自适应规则执行。分发版 `medagentwork-skill/skills/medagentwork/references/bpa-v1.md` 尚未同步，见第 5 节过渡说明。
> **设计依据**：`Obsidian产物/教师重点蓝图版/教师重点蓝图版复习资料设计方案_v1.0.md`（证据基础与评估标准）
> **样板**：`Obsidian产物/教师重点蓝图版/耳鼻咽喉头颈外科学_教师重点蓝图版_主复习资料.md`

## 1. 强制路由

| 输入 | 路径 |
|---|---|
| 有教师重点 / 复习大纲 / 锚定清单 | **BPA v1.0 强制**，不得按教材目录平铺 |
| 无教师重点 | medreview 教学计划版流程（D1–D5） |

**判定即承诺**：教师重点 N 条 = 交付 N 条落点。权重只决定篇幅与配题，不决定是否覆盖。

## 2. 自适应结构

科目、模块与考点按素材、教学目标和知识类型组织；蓝图、摘要、对比表、因果链、决策树、案例和回忆题按实际学习价值选择，不规定每模块固定顺序、数量或卡片八行。疾病、机制、解剖操作和分类标准分别采用适合的解释方式，详见 `docs/复习资料详细度标准.md`。

教师重点逐条设置 `📌 重点原文（第X条）：` 落点，原文字面及硬事实保持完整；每个知识点只设一处主讲位置，其他位置以必要提示和可定位引用关联。题目答案可检索，真实安全红线和适用条件不得省略。

## 3. 原文与补写分离

逐条照录教师原文关键句，保留全部硬事实，不包 `<b>`；条号以输入锚定清单编号为准。原文仅有主题名时，锚点照录主题，不将教材事实拼接成教师原文。另起「教材补写」或「其他来源补充」并注明可核实来源和真实页码；无法核实则标记待核实，在交付说明列出，不得编造。主体、条件与事实的完整解释放在主讲位置。

## 4. 事实与来源

- 教师重点决定覆盖范围；教材等可核实来源支持补写，不能冒充教师原文。
- 数值或建议冲突时分别标明来源、适用场景与差异，未核实则标记；考试口径不覆盖医学安全。
- 页码只用原文真实标注；全篇同页码视为占位（HC-10）→ FAIL。
- 删除/合并写 CHANGELOG，理由限 duplicate / out_of_scope / error / merge。

## 5. 门禁

```bash
# 覆盖门禁（必须 PASS）
python medagentwork-skill/skills/medagentwork/scripts/check_keypoint_coverage.py \
  --keypoints "输入素材/大四上/{科目}/{科目}_教师重点_锚定清单_{date}.md" \
  --md "Obsidian产物/教师重点蓝图版/{科目}_教师重点蓝图版_主复习资料.md"

# 结构自检（工作区脚本）
python 中间产物/bpa_v1/selfcheck.py
```

**通过线**：条目覆盖 100% + 带单位硬事实缺失 0 + 落点行内事实缺失 0；按知识类型人工核查内容、来源与安全。旧结构自检及详细度门禁仍检查固定区块和数量，可能误报：须运行并如实记录，不把 FAIL 当 PASS；若现行发布流程阻断，等待同步或由有权负责人按现行流程处理，不自行绕过。子模块分发规则仍为旧口径，尚未同步。

**抽检**：逐条核对原文及关键数字，对主题名条目检查补写来源与可追溯性，并检查主讲位置及引用。

## 7. 改稿工作流

1. 源分片放 `中间产物/{batchID}/`（`head.md` + `M01.md…M07.md` + `appendix.md`）。
2. 改分片 → `cat` 合并 → 复制到交付路径。
3. **不要直接改交付大文件**，否则分片与交付物不一致。
4. 每次改完复跑门禁与自检，结果写进 `reports/gate/`。
