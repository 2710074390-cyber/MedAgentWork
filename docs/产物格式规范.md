# 产物格式规范（v1.1 · 2026-09-01 导出兼容修订）

> 本文件是 **MedAgentWork 线 → 线上站（med-review-site.pages.dev）** 之间唯一的产物形态契约。
> 所有 Agent / 脚本 / 人工流程必须遵守；与站端渲染器（`index.html` 的 `mdToHtml` v2）配套。
> 违反本规范的产物视为**不合规**，`scripts/verify_produce_rules.py` 会拦截。

---

## 1. 三张表的产物形态（强制）

| 产物 | 管线/脚本最终输出 | 网站呈现 | 允许扩展名 | PDF 由谁产出 |
|------|-----------------|---------|-----------|-------------|
| **押题卷** | 仅 **HTML**（统一模板 `quiz_template.html` 渲染，QUESTIONS 数组注入） | 在线交互答题 | `.html` | **一律人工**（用户手动上传；管线不产出押题卷 PDF） |
| **题库** | **MD + HTML**（MD：MedFix `ALL_questions_FIXED.md` 等；HTML：`render_qbank_html.py`） | 卡片下载/网页查看 | `.md` `.html` | **一律人工**（用户手动上传） |
| **复习资料** | **MD + HTML**（MD：MedReview 主文档；HTML：`render_review.py` 渲染） | 在线预览（mdToHtml）/ 网页版 | `.md` `.html` | **一律人工**（用户手动上传） |

其它说明：
- 押题卷组卷中间产物（`最终产物/押题卷_*_N题.json`）是**生产中间物**，不是交付物，不进入 `大三下/`。
- `大三下/` 目录（网站上架目录）内**禁止出现** `.pdf` 之外的文件类型（.docx/.txt/.json 等一律不允许）；PDF 由人工上传后保留。
- 任何脚本不得生成/写入 PDF 文件路径（`weasyprint`/`pdfkit` 输出到 `大三下/` 或 `最终产物/` 均违规）。

## 2. 押题卷 HTML 契约（quiz_template / QUESTIONS）

- 交付物 = 单文件 HTML（`大三下/押题卷/{科目}押题卷_{年}.html`），内联 CSS/JS，零外部依赖。
- 题目注入：`<script id="quiz-data">` 内 `const QUESTIONS = [...]`，字段契约：
  | 字段 | 必填 | 说明 |
  |---|---|---|
  | `qid` | ✅ | 作答记录主键 |
  | `type` | ✅ | A1/A2/A3/A4/B1/X/判断 |
  | `system` | 可选 | **可读系统名**（如"呼吸系统"），多个值时自动生成系统筛选标签；禁止填模块号（`M5`） |
  | `bloom` | 可选 | 认知层级 |
  | `stem` | ✅ | 题干，否定词用 `<b>不</b>` 加粗 |
  | `options` | ✅ | **纯文本字符串数组**（不带 "A." 前缀） |
  | `answer` | ✅ | 大写字母串；X 型如 "ABD"；B1 复合 "E/A" 保留 |
  | `explanation` | ✅ | 解析（打印时展示） |
  | `source` | 可选 | 来源标注 |
- `PAPER_META.sub` 必须为成品文案：`按考频组卷 · {N} 题 · {日期}`。
  **禁止**：`统一模板`、`v1.x`、`TEST`、内部代号等出现在标题/副标题/正文对可见区域。

## 3. 复习资料 MD 语法契约（与 mdToHtml v2 匹配）

MedReview 输出 MD 仅允许以下语法（站端渲染器 `mdToHtml` 支持的全部能力）：

- 标题 `#`~`######`（层次 ≤ 4 推荐）；空行分段
- **行内**：`<b>加粗</b>`、`<i>斜体</i>`、`` `代码` ``（v1.1 起禁用 `**加粗**`/`*斜体*`：Obsidian 实时预览与原生 PDF 导出按 CommonMark 解析不认中/日/韩文字符相邻的强调标记，裸 `**` 泄漏；站端 mdToHtml 与 render_review.py 同时**向下兼容**旧 `**`）
- **块**：标准 Markdown 表格（`| a | b |` 形式）、``` 代码块（ASCII 图放这里）、
  `---` 分隔线、普通引用 `> 文本`
- **Obsidian Callout**：`> [!WARNING|TIP|INFO|SUCCESS|NOTE] 标题`（连续 `>` 行组成卡片；
  站端渲染为 `.callout-{type}` 样式卡）
- **展开区**：`#### 🔬 展开：{名称}` 标题 + 普通 MD 内容（v1.1 起禁用 `<details>`/`<summary>`——Obsidian 阅读视图与原生 PDF 导出不渲染 HTML 块内部 Markdown；标题内容默认可见、全管线兼容；站端渲染器对旧 `<details>` 仍向下兼容）
- **列表**：`- ` 无序、`1. ` 有序（渲染为 `<ul>/<ol>`）

**禁止（站端不支持 / 会泄漏为文本）**：
- Mermaid 代码块（一律用 **ASCII 图**，放置于 ``` 代码块内）
- 行内强调 `**…**` / `*…*`、折叠区 `<details>` / `<summary>`（v1.1 起；旧产物保留兼容渲染，新产物禁止）
- `</?b>` / `</?i>` 之外的任意其它 HTML 标签（`<span>`/`<img>`/`<table>` 手写等）
- YAML front matter（`---` 文件头 + 元数据块）
- 流程标记：`📦 复习资料批次 X/Y`、`✅ 批次完成`、`⏭️ 下一批`、`本批产出/统计`、
  `V1-V14 视觉质量自检报告` 等（内部自检材料移动到 `质检报告/`，不进交付物；
  交付前用 `clean_produce_markup.py` 清理）

## 4. 统一渲染链（写入即适配）

| 环节 | 唯一入口 | 禁止并行入口 |
|------|---------|-------------|
| 押题卷渲染 | `quiz_template.html` + 注入脚本 | `render_interactive_html.py` / `build_html_final.py` / `render_predict_html.py`（历史遗留，勿再使用） |
| 复习资料 MD→HTML | `知识库素材/render_review.py` | 其它手写转换器 |
| 站端在线预览 | `index.html` 内 `mdToHtml`（无需联网） | 另起第三方渲染库（保持零依赖） |

## 5. 发布流程（新批次 / 新产物）

1. 产出原始文件（按上表形态）；
2. 运行 `python scripts/clean_produce_markup.py`（清除流程残留、成品化副标题）；
3. 需要网页版的复习资料运行 `render_review.py` 重渲 HTML；题库如需 HTML 运行 `render_qbank_html.py`；
4. 运行 `python scripts/verify_produce_rules.py`（FAIL==0 才算通过）；
5. 检查 `index.html` 卡片数组（EXAMS/BANKS/REVIEWS）的 meta（题数/大小/描述）与实际文件一致；
6. **PDF 一律等待用户手动上传**（押题卷/题库/复习资料均如此；脚本禁止生成）；
7. `git add` 对应文件 → push（GitHub Actions 自动部署 Cloudflare Pages）。

## 6. 站端渲染器能力速查（mdToHtml v2）

支持：h1-h6 / 表格 / 代码块 / 行内 code / 粗体（`<b>`，兼容旧 `**`）/ 斜体（`<i>`，兼容旧 `*`）/ 引用 / Callout 五型 / h4 展开区（兼容旧 details 折叠区）/
有序无序列表 / hr。不支持：Mermaid、脚注、任务列表（`- [ ]`）、数学公式。

## 7. 生命周期

- 新契约变更需同步更新：本文件 + `index.html` mdToHtml + `quiz_template.html` 注释 + `Agent5/MedGen` Prompt 输出约束。
- v1.1 同步记录（2026-09-01）：`index.html` mdToHtml 已加 `<b>`/`<i>` 白名单还原（步骤 2.2），保留旧 `**`/`<details>` 向下兼容；`verify_produce_rules.py` 已增复习资料 MD 标签白名单检查（details/summary 仅提示不判 FAIL，兼容旧产物）；`render_review.py` 无需改动（HTML 直通）。
- `verify_produce_rules.py` 与 `gate_check.py` 同为门禁：任何产物进入 `大三下/` 前必须通过。
