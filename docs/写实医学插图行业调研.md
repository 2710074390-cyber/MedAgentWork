## 一、国际医学教育平台插图实践

### 1. Osmosis

| 维度 | 内容 |
|------|------|
| **插图风格** | 白板动画风格（white-board animation），专业插画团队手绘风格的动态插图，偏卡通/叙事化，**非写实解剖**。将复杂生化通路、生理机制、发病机制转化为可视化叙事。 |
| **是否AI生成** | ❌ 否。专业插画团队制作，Elsevier旗下。 |
| **规模** | 2,000+ 动画视频，16,000+ 闪卡。 |
| **学习效果角色** | 基于学习科学（艾宾浩斯曲线、chunking分块），"visual learning"为核心卖点。将复杂概念拆解为可消化的视觉片段。 |
| **付费模式** | 订阅制（学生个人订阅 + 机构授权），Elsevier全球分销。 |
| **可学习的点** | ① 视觉叙事+分块学习的产品方法论；② 插图与视频/闪卡/测验的闭环整合；③ 但风格偏卡通，**不适合作为写实插图参考**。 |
| **来源** | ✅ https://www.osmosis.org/why-osmosis ；✅ https://www.osmosis.org/features/videos ；✅ https://www.aitooldiscovery.com/guides/ai-tools-for-medical-students |

### 2. AMBOSS

| 维度 | 内容 |
|------|------|
| **插图风格** | 现代数字插画 + **Image Overlay（图像叠加标注）** 为核心特色。在医学影像/解剖图上叠加交互式标注层，映射关键解剖结构、诊断和系统。配色清晰，彩色编码高亮（high-yield facts用特定颜色标记）。包含流程图、示意图、临床影像。 |
| **是否AI生成** | ❌ 否（公开信息未提及AI生成，专业团队制作）。 |
| **规模** | 1,400+ 交互式文章，含图像叠加、插图、流程图。 |
| **学习效果角色** | "Most medical images don't come with captions. Ours do." —— 叠加层引导学生发现关键影像征象，培养模式识别（pattern recognition）。 |
| **付费模式** | 订阅制（学生个人 + 校园机构授权），德国公司。 |
| **可学习的点** | ① **Image Overlay模式**：在底图上叠加标注层，比直接在图上画标注更灵活、可交互；② 彩色编码文本高亮与插图配合；③ 性别平衡意识（研究显示AMBOSS男女解剖图比例0.6，女性更多）。 |
| **来源** | ✅ https://www.amboss.com/us/features ；✅ https://www.amboss.com/us/students/md/preclinical ；✅ https://anatomypubs.onlinelibrary.wiley.com/doi/full/10.1002/ase.2211 |

### 3. Sketchy Medical

| 维度 | 内容 |
|------|------|
| **插图风格** | **视觉记忆宫殿（memory palace）风格**，刻意卡通化/符号化的插画"世界"。每个视觉符号编码一个知识点（如微生物特征、药物机制与副作用）。**故意非写实**——怪诞、有趣的场景更易记忆。 |
| **是否AI生成** | ❌ 否。2013年由四名医学生创立，专业插画团队。 |
| **规模** | 600+ 视频，覆盖微生物、药理、病理。 |
| **学习效果角色** | 基于method of loci（记忆宫殿法），空间视觉记忆强于文字记忆。召回画面即召回关联知识点。微生物和药理领域的行业标准。 |
| **付费模式** | 约$30/月或$400/年（Micro+Pharm+Path全捆绑）。 |
| **可学习的点** | ① 视觉符号编码体系的设计方法；② 但**风格与"写实插图"目标完全相反**，仅作为对比参考——证明在需要记忆的领域，非写实风格有其不可替代性；③  recurring "worlds"（ recurring场景/角色）提升系列一致性。 |
| **来源** | ✅ https://www.sketchy.com/explore/medical ；✅ https://testpreppal.com/usmle/study-tools/sketchy ；⚠️ https://www.sketchy.com/blog/sketchy-sticks-with-you-for-every-year-of-medical-school |

### 4. Kenhub

| 维度 | 内容 |
|------|------|
| **插图风格** | **高质量写实解剖插图**，详细且标注精良（detailed and well-labeled）。配合交互式测验。风格接近经典解剖图谱的数字版。 |
| **是否AI生成** | ❌ 否。德国公司（Kenhub GmbH, Leipzig）。 |
| **学习效果角色** | 插图 + 视频 + 交互式测验的组合。用户评价："详细且标注精良的插图使复杂主题更易理解。" |
| **可学习的点** | ① **写实解剖插图 + 交互式测验**的闭环；② 性别代表性研究显示Kenhub男女解剖图比例0.3（女性远多于男性），是纠正传统解剖教材性别偏差的正面案例；③ 标注质量是用户最常提及的优点。 |
| **来源** | ✅ https://anatomypubs.onlinelibrary.wiley.com/doi/full/10.1002/ase.2211 ；✅ https://www.kenhub.com/fr/success-stories |

### 5. Lecturio

| 维度 | 内容 |
|------|------|
| **插图风格** | 高质量插图 + 动画 + Concept Pages（概念页）。混合风格：解剖示意图、生理机制图、流程图。图片采用CC BY-NC-SA 4.0开源协议。 |
| **是否AI生成** | ❌ 否。由US-trained physicians创建和同行评审。 |
| **规模** | 涵盖基础医学全学科，Concept Pages含插图、视频、Qbank。 |
| **可学习的点** | ① **Concept Page模式**：每个知识点一页，整合插图+视频+测验+First Aid参考，适合结构化复习资料；② 开源协议（CC BY-NC-SA）使插图可被引用/改编；③ 医师同行评审确保准确性。 |
| **来源** | ✅ https://www.lecturio.com/medical/ ；✅ https://www.lecturio.com/medical/topics/physiology |

### 6. Physiopedia

| 维度 | 内容 |
|------|------|
| **插图风格** | 以**Primal Pictures 3D解剖模型**为核心（合作关系），交互式3D模型 + 演示性解剖视频 + 技术操作视频。非传统2D插图，而是3D可交互模型。 |
| **是否AI生成** | ❌ 否。 |
| **可学习的点** | ① 3D交互模型在肌肉骨骼解剖领域的优势；② 但3D模型制作成本极高，不适合规模化快速生产；③ 演示视频（demonstrative technique videos）配合操作类内容。 |
| **来源** | ✅ https://members.physio-pedia.com/ ；✅ https://members.physio-pedia.com/organisation-partnership/ |

### 7. Medscape

| 维度 | 内容 |
|------|------|
| **插图风格** | 以临床新闻、药物参考、CME课程为主。插图非核心产品，主要使用临床照片、医学影像、少量示意图。免费平台。 |
| **是否AI生成** | 未公开提及。 |
| **可学习的点** | 参考价值有限——Medscape的核心是资讯和药物数据库，插图不是差异化因素。 |
| **来源** | ✅ https://forum.facmedicine.com/threads/the-best-resources-for-medical-students-must-have-apps-books-and-websites.98503/ |

### 8. StatPearls（NCBI Bookshelf）

| 维度 | 内容 |
|------|------|
| **插图风格** | **众包混合风格**，质量参差不齐。来源包括：Wikimedia Commons公共领域图片、投稿者贡献的插图、临床照片。标注方式不统一。CC BY 4.0协议。 |
| **是否AI生成** | ⚠️ 部分文章开始使用AI生成图片。2024年发表于PubMed的论文（PMID: 39744279）明确讨论了使用Microsoft Image Creator（免费AI工具）为医学演示生成器官插图，并提供了prompt模板。但这是教育者个人行为，非平台官方策略。 |
| **规模** | 数千篇综述文章，NCBI免费开放获取。 |
| **可学习的点** | ① **众包+开放获取模式**的成本优势，但插图质量和风格一致性是硬伤；② AI生成图片已开始渗透，但准确性堪忧；③ CC BY 4.0协议使内容可自由复用。 |
| **来源** | ✅ https://www.ncbi.nlm.nih.gov/books/ ；✅ https://pubmed.ncbi.nlm.nih.gov/39744279/ ；✅ https://www.ncbi.nlm.nih.gov/books/NBK534793/figure/article-29693.image.f1/ |

## 二、经典医学插图标杆

### 1. Netter（奈特解剖）—— 写实医学插图的金标准

| 维度 | 内容 |
|------|------|
| **风格特征** | **自然主义写实（naturalistic realism）**。Frank H. Netter本人是医师+插画师双重身份，手绘丙烯/油画风格。 vibrant lifelike色彩，精确的解剖细节，临床视角构图。Netter自己的话："striven for a middle course of realism without the clutter of confusing minutiae"（在写实与简化之间取中道——写实但不被琐碎细节干扰）。 |
| **色彩规范** | 全图谱统一色彩编码：**黄色=神经，红色=动脉，蓝色=静脉**，不同肌肉类型用不同色调。这一色彩语言贯穿全书，读者无需反复看图例。 |
| **制作方式** | 传统手绘（Netter本人作品）。第9版新增Carlos A. G. Machado等艺术家的数字绘画，延续Netter传统（"working in the Netter tradition"）。 |
| **为什么是金标准** | ① 医师视角——强调临床相关的解剖关系（"relationships most important to the clinician"）；② 人文主义叙事——将疾病过程描绘为个体患者面临的生活挑战（如经典的中年男子寒夜走出餐厅 clutching chest的心绞痛图），通过视觉故事连接解剖与临床；③ 简化复杂结构的能力——break down intricate structures into understandable components；④ 由clinicians为clinicians创作。 |
| **可学习的点** | ① **"写实但不琐碎"的中道原则**——AI生成图容易过度细节化（超现实主义问题），Netter的选择性简化是关键；② 全系列统一色彩编码；③ 临床视角构图（外科医生打开体腔看到什么、放射科医生读片看到什么）；④ 中英文双语标注（人卫中文版已实现）。 |
| **来源** | ✅ https://netterreference.com/content/netter_atlas_9e/assets/pdf/FM9eForNetRef.pdf ；✅ https://pmc.ncbi.nlm.nih.gov/articles/PMC11563165/ ；✅ https://www.asia.elsevierhealth.com/netter-atlas-of-human-anatomy-classic-regional-approach-9780443118685.html ；✅ https://www.opinioneslibros.com/libros/netter-atlas-anatomia-humana/ |

### 2. Gray's Anatomy（格氏解剖学）

| 维度 | 内容 |
|------|------|
| **风格特征** | 1858年首版，Henry Carter绘制的**黑白线刻版画（line engravings）**。与前代解剖书的"proxy labeling"（读者需翻页查脚注编号）不同，Gray's采用**统一标注（unified nomenclature）**——结构名称直接标在图上，读者可同时吸收图像和标签。第40版（2008年）首次全彩。第43版融合：经典Gray's artwork + 高分辨率X线/CT/MRI + cinematic rendering（电影级渲染）。 |
| **制作方式** | 传统：木刻/铜版画 → 现代：数字绘画 + 医学影像 + 3D渲染。 |
| **风格混合** | 解剖标本照片（dissection photos）+ 插图 + 示意图 三合一。 |
| **可学习的点** | ① **统一标注（unified labeling）**是Gray's超越前代的关键创新——直接在图上标注结构名，而非编号+脚注；② 插图与真实标本照片、医学影像并置，互为参照；③ 持续更新（43版），在保留经典artwork的同时引入现代影像技术。 |
| **来源** | ✅ https://synapse.koreamed.org/articles/1140511 ；✅ https://www.rcseng.ac.uk/library-and-publications/library/blog/grays-anatomy-descriptive-and-applied/ ；✅ https://www.us.elsevierhealth.com/grays-anatomy-9780443124785.html |

### 3. Robbins Pathology（罗宾斯病理学）

| 维度 | 内容 |
|------|------|
| **风格特征** | **三重插图体系**：① "world-class illustrations"（世界级概念插图——最有价值的部分，conceptual artist drawings）；② 高质量显微照片（photomicrographs）；③ 大体标本照片（gross photos）+ 放射影像。第10版Pathologic Basis of Disease含1,600幅全彩插图。第11版Basic Pathology新增150+幅示意图。 |
| **概念插图特点** | 将发病机制（pathogenesis）、细胞通路、炎症级联等抽象过程可视化为示意图。与真实病理照片互补——照片展示"是什么"，概念图展示"为什么"。 |
| **制作方式** | 专业医学插画师 + 病理标本摄影。Elsevier出版。 |
| **可学习的点** | ① **写实病理主体（大体/镜下照片）+ 概念机制图的双轨制**——本项目已有"写实解剖/病理主体"插图，可借鉴Robbins的做法：每张写实图配一张机制示意图；② 1,600幅的规模证明专业插画团队可支撑大部头教材；③ Key Concepts boxes（要点框）与插图配合。 |
| **来源** | ✅ https://www.us.elsevierhealth.com/robbins-cotran-kumar-pathologic-basis-of-disease-9780443264528.html ；✅ https://www.us.elsevierhealth.com/robbins-basic-pathology-e-book-9780323394130.html ；✅ https://www.us.elsevierhealth.com/robbins-cotran-pathologic-basis-of-disease-e-book-9780323609937.html |

### 4. 人卫版教材（人民卫生出版社）

| 维度 | 内容 |
|------|------|
| **风格特征** | 多模式混合：① **精细手绘**（系统解剖学等经典教材）；② **实物标本彩色照片**（如《实用人体解剖彩色图谱》使用381件精心制作的实物标本 + 22幅手绘示意图 + 4张活体彩色照片）；③ **计算机3D绘制**（《人卫3D人体解剖图谱》500余幅，利用3D模型多角度/透明/镜像展示）；④ **镜下摄片**（病理、组织学）；⑤ **流程图**（临床路径）。 |
| **3D图谱创新** | 不同于经典图谱的前/后/侧位展示，人卫3D图谱采用左/右前侧位、镜像位、透明/隐藏方式，更好展示三维立体形态和空间关系。 |
| **人卫教学助手数字资源** | 解剖模型（虚拟与实体三维结合）+ 精美动画 + 优质图片（精细手绘/镜下摄片/模式流程）。 |
| **可学习的点** | ① **实物标本照片+手绘示意图的组合**是国内医学教材的成熟模式，写实度高且临床贴合；② 3D数字绘制是国内教材的新方向，但制作成本高；③ 中英文双语标注（部分图谱已实现）；④ 标注以全国自然科学名词审定委员会《人体解剖学名词》为标准。 |
| **来源** | ✅ http://edu.ipmph.com/edu/resourcelibrary.html ；✅ http://lib.smu.edu.cn/Article/Detail/1599 ；✅ https://medu.pmph.com/readdetail/todetail.action?id=23099 ；✅ http://www.ptu.edu.cn/jcyxb/info/1151/11943.htm |

## 三、AI + 医学插图先行者案例

### 1. Natomy —— AI医学插图专业工具

| 维度 | 内容 |
|------|------|
| **产品定位** | "The AI Medical Illustrator for Clinicians & Researchers"——面向临床医生和研究者的AI医学插图/动画生成工具。 |
| **风格选项** | ① **Academic Illustration**（经典Netter风格，适用于教材和学习材料）；② **Photorealistic Render**（照片级写实渲染，适用于演示和临床参考）；③ **Ultra-Realistic Animation**（超写实3D动画）。 |
| **工作流** | 上传任意医学图片 + 选择风格 → 生成出版级医学图像/视频，声称"minutes"即可完成。 |
| **效果评估** | ⚠️ 厂商宣传"publication-ready"，但独立准确性验证未见公开同行评审研究。其博客引用了2025年J Clin Med研究（Midjourney/DALL-E/Gemini/Stable Diffusion在颅面解剖任务上均有局限），暗示其产品在准确性上优于通用模型，但缺乏独立验证。 |
| **可学习的点** | ① **风格预设（Netter-style / Photorealistic / 3D Animation）**的产品设计——用户不需要从零写prompt，选择风格模板即可；② 上传参考图+风格迁移的工作流；③ 但"publication-ready"的声称需谨慎对待。 |
| **来源** | ⚠️ https://www.natomy.com/ ；⚠️ https://www.natomy.com/blog/ai-medical-illustration-generator |

### 2. SciDraw AI —— 临床插图生成器

| 维度 | 内容 |
|------|------|
| **产品定位** | 免费AI临床插图生成器，将临床描述/病例摘要/纯文字概念转化为可用于发表的医学插图草稿。 |
| **覆盖类型** | 解剖图、手术步骤图、患者教育图、医疗器械/植入物位置、作用机制图（药理/治疗）、临床诊疗路径图。 |
| **可学习的点** | ① **按插图类型细分的生成器**（不是一个通用入口，而是针对解剖/手术/机制/流程分别优化）；② 免费工具定位为"草稿生成"，明确需要人工修订；③ 中文界面。 |
| **来源** | ⚠️ https://sci-draw.com/zh/clinical-illustration-generator ；⚠️ https://sci-draw.com/blog/ai-textbook-illustrations-and-medical-infographics |

### 3. 国内AI医疗插图实践（Qwen-Image / Z-Image-Turbo / WuliArt）

| 维度 | 内容 |
|------|------|

### 4. AI医学插图的准确性问题——同行评审证据汇总

这是本调研中**证据最充分、结论最一致**的部分。多项独立同行评审研究证实：

| 研究 | 模型/工具 | 发现 |
|------|----------|------|
| **2023, PubMed 37694692** | 多个文生图模型 | 无一能生成全面准确的解剖细节。颏孔/眶上孔经常缺失，缝线不准确，心脏冠状动脉起源错误，主动脉/肺动脉分支错误，脑沟回/小脑与颞叶关系错误。 |
| **2025, Wiley Clinical Anatomy** | Bing, DeepAI, Freepik, Gemini | 四种AI文生图工具在解剖教育中的准确性比较评估，均存在不同程度解剖错误。 |
| **2025, J Clin Medicine** | Midjourney v6, DALL-E 3, Gemini Ultra 1.0, Stable Diffusion 2.0 | 颅面解剖插图任务，解剖学家5分制评估。所有模型均有局限，原因包括训练数据不足和对复杂解剖理解不完整。 |
| **2025, PMC12547223（手外科）** | AI文生图工具 | >99%的AI生成图片包含至少一定程度的**虚构解剖（fabricated anatomy）**。图像细节和清晰度优秀，但手部解剖和标注不准确。 |
| **2024, Cureus（眼科屈光手术）** | OpenAI DALL-E | 能生成可识别为眼睛的图像，但**缺乏教育价值**。LASIK/PRK/SMILE手术步骤描绘不准确。 |
| **2025, 足部骨骼识别** | ChatGPT (DALL-E) | 正确标注率分别为27%、57%、0%。标签错位、关键骨骼错误或缺失、整个结构缺失。 |
| **2025, 医学与哲学（中文）** | 文生图技术 | AI医学图片普遍存在**"超现实主义"（superrealism/超现实主义）**特征——生成内容看似高度真实但实际不符合解剖事实。需由具备专业知识的医学插图人员人工审核修订，才能勉强达到出版或教学使用的最低门槛。在肺叶划分等基础结构上均存在错误。 |
| **系统性综述（偏见）** | 多项研究 | 75%的研究报告显著的人口统计学偏差，生成的临床医生常为白人男性。47.2%的研究报告临床保真度局限（解剖幻觉、看似合理但错误的医疗设备描绘）。高视觉可信度常与高错误率并存。 |

**关键结论**：✅ AI生成医学插图在**视觉外观**上已达到高写实度，但在**解剖准确性**上严重不足。>99%的图片含虚构解剖。当前阶段，AI生成图必须经过医学专业人员审核修订才能用于教育。"看起来对"不等于"是对的"——这是AI医学插图最核心的风险。

## 四、医学教育插图风格分类学

综合 Maa Illustrations、Artery Studios、Kreafolk、metazoa.studio、SciDraw、NLM展览等来源，医学教育插图可分为以下主流风格谱系：

### 风格谱系总表

| 风格类型 | 描述 | 适用场景 | 制作难度 | AI可生成性 | 代表案例 |
|---------|------|---------|---------|-----------|---------|
| **1. 写实解剖插图** | 高细节、色彩渐变和阴影，精确复现解剖结构。参考尸体标本、组织学切片、医学影像。 | 解剖学、局部解剖、手术入路 | ★★★★★ | ★★☆（外观可，准确性差） | Netter, Kenhub, 人卫手绘 |
| **2. 写实病理插图** | 描绘病变/损伤的结构、器官、组织。包括大体标本写实和镜下组织学。 | 病理学、各学科疾病形态 | ★★★★☆ | ★★☆（显微图较难） | Robbins, 人卫镜下摄片 |
| **3. 概念/机制示意图** | 简化抽象的发病机制、细胞通路、生理过程。非写实，强调逻辑关系。 | 病理生理学、药理机制、生化通路 | ★★☆☆☆ | ★★★★★（AI最擅长） | Robbins概念图, Osmosis白板 |
| **4. 手术步骤图** | 分步描绘手术过程关键阶段，包括术后视图。 | 外科学、操作规范 | ★★★★☆ | ★★☆（步骤准确性差） | 手术图谱, SciDraw手术类型 |
| **5. 信息图/Infographic** | 数据+视觉组合，扁平设计，图标+统计+流程。 | 流行病学、临床数据、患者教育 | ★★☆☆☆ | ★★★★☆ | 健康科普, 医学资讯 |
| **6. 流程图/决策树** | 诊疗路径、鉴别诊断、算法。节点+箭头+分支。 | 诊断学、急诊、临床指南 | ★☆☆☆☆ | ★★★★★ | AMBOSS流程图, 临床路径 |
| **7. 线描/示意图** | 黑白极简线条，去除色彩和阴影，突出结构关系。 | 课堂笔记、考试速记、印刷 | ★★☆☆☆ | ★★★☆☆ | 传统解剖线图, Gray's早期 |
| **8. 显微/超微结构图** | 细胞、组织、细胞器水平。HE染色/电镜风格。 | 组织学、病理学、细胞生物学 | ★★★★☆ | ★★☆（染色特征难准确） | Robbins显微照片, 人卫镜下 |
| **9. 3D渲染/交互3D** | 高保真3D人体模型，可旋转/分层/透明。 | 解剖学、肌肉骨骼、患者教育 | ★★★★★（建模成本极高） | ★★☆（需专业3D工具） | Complete Anatomy, BioDigital, Primal Pictures |
| **10. 对比表/对比图** | 左右/上下并列对比正常vs异常、A疾病vs B疾病。 | 鉴别诊断、对比学习 | ★★☆☆☆ | ★★★☆☆ | 教材对比框, 复习资料 |

### 关键发现

1. **AI可生成性与制作难度呈负相关**：制作难度最低的流程图/决策树/概念示意图，AI生成性最高；制作难度最高的写实解剖/病理/手术步骤图，AI生成性最低。
2. **"写实"是AI最大的短板**：AI在外观写实度上已很强，但在解剖准确性上>99%含虚构结构。这意味着AI生成的写实图**不能直接使用**，必须经过医学审核。
3. **概念示意图是AI最适合的领域**：流程图、机制图、信息图不要求精确解剖，AI可高效生成且质量可接受。
4. **3D交互模型不适合规模化快速生产**：Complete Anatomy/BioDigital的3D模型需专业团队数年开发，成本极高，不适合"每科几十到上百张"的快速规模化目标。

## 五、优秀写实医学插图的可复用构成要素

综合 Netter、Robbins、Gray's、SciDraw指南、McMaster大学、WJG期刊规范等来源，提炼"一张好的写实医学插图"的构成要素：

### 1. 构图原则

| 要素 | 规范 | 来源 |
|------|------|------|
| **一图一概念** | 每张图只表达一个核心概念；超过两个概念应拆分为两张图 | SciDraw |
| **信息密度上限** | 图中独立元素控制在5-7个（人脑短期记忆7±2容量）；医学信息图4-6个 | 掘金/SciDraw |
| **临床视角构图** | 从临床使用者视角构图——外科医生打开体腔看到什么、放射科医生读片看到什么，而非纯艺术视角 | Netter |
| **选择性简化** | "写实但不琐碎"——保留临床关键结构，省略干扰性细节。AI生成图常犯"超现实主义"过度细节错误 | Netter / 医学与哲学 |
| **留白** | 至少30%空白区域用于标注和图注，避免画面拥挤 | SciDraw |

### 2. 标注方式

| 要素 | 规范 | 来源 |
|------|------|------|
| **统一标注（Unified Labeling）** | 结构名称直接标注在图上，不使用"编号+脚注"的proxy labeling方式 | Gray's Anatomy |
| **标签用名词，不用句子** | "左心房"而非"左心房是接收肺静脉血液的腔室"——描述性文字放图注 | SciDraw |
| **引导线，不用箭头** | 使用leader lines（引导线）连接标签和结构，箭头用于指示方向/流程 | SciDraw textbook guide |
| **标签在轮廓外** | 标注文字放在主体轮廓之外，保持解剖结构可读性 | SciDraw textbook guide |
| **中英文双语** | 核心结构同时标注中英文（本项目面向中文医学生但需对接国际术语） | 人卫图谱 / Netter中文版 |
| **字体规范** | 印刷10-12pt，网页12-14px；主要术语加粗，次要描述斜体；对比色确保可读性 | Madrid Atocha / 期刊规范 |

### 3. 色彩规范

| 要素 | 规范 | 来源 |
|------|------|------|
| **解剖色彩编码** | 全系列统一：红色=动脉，蓝色=静脉，黄色=神经。读者无需反复看图例 | Netter / Scientific Illustration指南 |
| **颜色数量上限** | 3种主色 + 1种强调色，不超过4种颜色。彩虹色看起来"忙"且损害记忆 | 掘金/SciDraw |
| **红色慎用** | 红色在医疗语境=血/危险/警告。大面积红色使读者紧张。红色仅用于最关键警示 | 掘金 |
| **安全配色** | 蓝色、青绿色、暖灰色是医学传播的安全配色 | 掘金 |
| **组织区分色** | 不同肌肉类型/组织类型用不同色调区分，但保持在同一色系内 | Netter |

### 4. 分辨率与格式

| 要素 | 规范 | 来源 |
|------|------|------|
| **彩色/半色调图** | 最低300 dpi | McMaster / WJG |
| **线描/扫描图** | 最低600 dpi | McMaster |
| **单色线稿** | 最低1200 dpi | medtigo期刊规范 |
| **高倍病理/电镜图** | 500-800 dpi | WJG |
| **比例尺** | 显微图像必须包含比例尺（scale bar），标注实际尺寸 | PMC9949169 / PMC8041175 |
| **矢量优先** | 线描图和图表使用矢量格式（EPS/SVG），可无损缩放 | McMaster |

### 5. 系列一致性（Style Sheet）

规模化生产（每科几十到上百张）最关键的是**跨图一致性**。必须在第一张图之前定义并写定：

| 要素 | 说明 |
|------|------|
| **调色板** | 全项目统一4-6种颜色（细胞类型、腔室、分子等） |
| **线条粗细** | 细胞轮廓线、箭头、引导线的统一线宽 |
| **标签样式** | 字体、字号、缩写vs全称、单词标注vs短语 |
| **图标体系** |  recurring符号（如细菌、病毒、药物分子的统一画法） |
| **风格Prompt模板** | AI生成时复用同一段style prompt，确保风格一致性。长期项目存为模板 |

## 六、对本项目最有参考价值的案例（Top 5）

### 🥇 第1名：Netter（奈特解剖）—— 写实风格定义者

**理由**：
1. **写实医学插图的金标准**，其"写实但不琐碎"的中道原则直接回应AI生成图的"超现实主义"过度细节问题。
2. **全系列统一色彩编码**（红=动脉/蓝=静脉/黄=神经）是规模化生产必须建立的视觉语言。
3. **临床视角构图**——从医生使用者角度组织画面，而非纯艺术视角，这与本项目"复习资料"定位高度契合。
4. 第9版已引入数字艺术家延续Netter传统，证明写实风格可从传统手绘迁移到数字生产（包括AI辅助）。
5. 人卫中文版已实现中英文双语标注，可直接参考其标注规范。

### 🥈 第2名：Robbins Pathology —— 写实+概念双轨制

**理由**：
1. **"世界级概念插图 + 高质量病理照片"的双轨制**是本项目最应借鉴的内容架构。本项目已有写实解剖/病理主体插图，Robbins证明每张写实图应配一张机制示意图——写实图展示"是什么"，概念图展示"为什么"。
2. **1,600幅全彩插图的规模**证明专业插画团队可支撑大部头教材的规模化生产。
3. **概念示意图是AI最擅长的领域**（AI可生成性★★★★★），而写实病理图需人工审核——Robbins的双轨制恰好对应"AI高效生产概念图 + 人工审核写实图"的混合工作流。
4. Key Concepts boxes（要点框）与插图配合的版式，适合Markdown复习资料的图文整合。

### 🥉 第3名：AMBOSS —— Image Overlay与交互式标注

**理由**：
1. **Image Overlay（图像叠加标注）模式**是对传统"直接在图上画标注"的升级——标注层与底图分离，可交互、可切换、可更新。在Markdown/HTML环境中可通过CSS/SVG实现类似效果。
2. **"Most medical images don't come with captions. Ours do."** —— AMBOSS将标注视为核心产品功能，而非附属。本项目的写实插图应将高质量标注作为一等公民。
3. **彩色编码文本高亮**与插图配合的方式，可在Markdown中通过自定义CSS实现。
4. 性别平衡意识（研究证实AMBOSS女性解剖图多于男性）是规模化生产时应注意的代表性问题。

### 第4名：Kenhub —— 写实解剖插图+交互式测验闭环

**理由**：
1. **高质量写实解剖插图 + 详细标注 + 交互式测验**的闭环，是"学习效果"验证最充分的模式之一。用户评价中最常提及的就是"详细且标注精良"。
2. 写实风格与本项目目标一致，是国际平台中少有的以**写实解剖插图**为核心的产品（Osmosis/Sketchy均偏卡通）。
3. 标注质量是用户最看重的因素——本项目规模化生产时，标注质量的一致性控制是关键挑战。
4. 性别代表性研究中Kenhub表现最佳（男女比例0.3），可作为内容多样性的参考基准。

### 第5名：Lecturio —— Concept Page结构化整合模式

**理由**：
1. **Concept Page模式**（每个知识点一页：插图+视频+测验+参考链接）与本项目"纯文本Markdown复习资料"的结构天然契合。每张写实插图嵌入一个Concept Page单元，而非随意散布在文本中。
2. **医师同行评审**确保准确性——这是AI生成插图必须补充的环节。Lecturio的US-trained physicians评审流程可作为本项目审核机制的参考。
3. **CC BY-NC-SA开源协议**使插图可被引用/改编——本项目可考虑类似的开放协议策略。
4. 与First Aid等权威参考的链接整合，提升了内容的可信度和实用性。

## 七、核心结论与行动建议

### 事实性结论

1. ✅ **国际主流医学教育平台中，以"写实解剖插图"为核心的只有Kenhub**。Osmosis（白板动画）、Sketchy（记忆宫殿卡通）、AMBOSS（现代数字+Overlay）均非纯写实路线。写实插图的标杆仍是经典教材（Netter/Gray's/Robbins/人卫）。

2. ✅ **AI生成医学插图的解剖准确性严重不足**，>99%的图片含虚构解剖（手外科研究），足部骨骼标注正确率0-57%，冠状动脉起源经常错误。"看起来对"≠"是对的"。

3. ✅ **AI在概念示意图/流程图/信息图领域表现良好**，这些类型不要求精确解剖，是AI最高效的应用场景。

4. ✅ **Netter的"写实但不琐碎"原则**是对抗AI"超现实主义"过度细节的关键指导。

5. ✅ **规模化生产的最大挑战不是单张图质量，而是跨图一致性**——色彩、标注、字体、线条粗细必须在项目开始前定义为Style Sheet。

### 对本项目的建议方向（仅供参考，不做工具选型）

- **写实插图**：AI生成 + 医学专业人员审核修订的混合工作流是当前唯一可行路径。审核重点：解剖结构准确性、标注位置、色彩编码一致性。
- **概念/机制图**：可更大程度依赖AI高效生产，审核重点为逻辑正确性而非解剖精确性。
- **Style Sheet先行**：在生产第一张图之前，定义调色板（红/蓝/黄解剖编码+3主色+1强调色）、标注规范（统一标注/引导线/中英文双语/字体字号）、分辨率标准（300dpi彩色/600dpi线描）、信息密度上限（5-7元素）。
- **双轨制内容架构**：借鉴Robbins——每个知识点配一张写实主体图（形态/解剖）+ 一张概念机制图（病理生理/药理），前者人工审核为主，后者AI高效生产。
