# 第40章 非化脓性关节炎

## 考纲要求

骨关节炎、强直性脊柱炎和类风湿关节炎的病因、病理、临床表现、临床检查、诊断、鉴别诊断和治疗。复习要点

## 一、骨关节炎

骨关节炎是一种以关节软骨退行性变和继发性骨质增生为特征的慢性关节疾病。

### 1.病因

(1)原发性骨关节炎 病因不明,其发生、发展是一个长期、慢性、渐进的过程。一般认为是多种致病因素包括机械性因素和生物性因素共同作用所致。年龄是明确的高危因素,主要为中老年人发病。其他因素包括性别、肥胖、遗传、炎症、代谢等,女性发病率高于男性。
(2) 继发性骨关节炎 可发生于青壮年, 多继发于创伤、感染、关节不稳定或先天性疾病等, 在局部原有病变基础上继发关节软骨退变。

【例 1】2014NO180X 引起继发性骨关节炎的常见原因有(10 版《外科学》改动大)

A. 后天性关节面不平整  
B. 先天性关节结构异常  
C. 关节不稳定  
D. 体重超重者下肢关节过于承重劳损  

### 2. 病理

最主要的病理变化包括关节软骨变性、磨损、缺失，软骨下骨硬化或囊性变，关节边缘骨赘形成，关节滑膜增生，关节囊和周围韧带增厚挛缩，关节周围肌肉萎缩，最终关节面完全破坏，出现关节畸形。

### 3. 临床表现

疼痛是最主要的症状,关节活动受限和关节畸形为常见表现。

| 关节疼痛 | 初期为轻、中度间歇性隐痛,休息时缓解,活动后加重;后期可出现持续性疼痛或夜间痛 |
|---|---|
| 关节压痛 | 关节局部有压痛,在伴有关节肿胀时尤为明显 |
| 关节僵硬 | 表现为晨僵,活动后缓解,晨僵时间一般不超过30分钟 |
| 关节活动障碍 | 关节疼痛、肌肉萎缩、软组织挛缩、关节交锁、关节不能完全伸直和屈曲 |
| 关节畸形 | 手部骨关节炎关节肿大变形明显,可出现Heberden结节和Bouchard结节膝关节可因关节积液和骨赘形成造成关节肿大,甚至出现内翻或外翻畸形 |
| 骨擦音(感) | 由于关节软骨破坏、关节面不平,关节活动时可出现骨擦音(感),多见于膝关节 |

### 4. 辅助检查

(1)实验室检查 血常规、蛋白电泳、免疫复合物、血清补体等正常。滑膜炎症期可出现C反应蛋白(CRP)轻度升高和血沉(ESR)轻度加快。
(2)X线检查 最常用,表现为非对称性关节间隙变窄,软骨下骨硬化和囊性变,关节边缘骨赘形成。

### 5. 诊断与鉴别诊断

根据病人的症状、体征和典型 X 线表现,诊断骨关节炎并不困难。须与类风湿关节炎、痛风性关节

炎、强直性脊柱炎、色素沉着绒毛结节性滑膜炎等相鉴别。

A. 肩关节骨关节炎  
B. 粘连性肩关节囊炎  
C. 类风湿关节炎  
D. 肩袖损伤  

6. 治疗

治疗目的主要是缓解疼痛、改善功能、延缓病程和纠正畸形。

(1)基础治疗 包括健康宣教、物理治疗、行动支持、支具辅助等。
(2)药物治疗 包括外用镇痛药、全身镇痛药、关节腔注射药物(透明质酸、糖皮质激素)。
(3)手术治疗 包括关节镜清理术、关节力线矫正术、人工关节置换术等。

## 二、强直性脊柱炎

强直性脊柱炎(AS)是一种慢性炎症性疾病,病变常从骶髂关节开始逐渐向上蔓延至脊柱,导致脊柱发生纤维性或骨性强直,并可累及下肢关节,最终发生畸形。

1.病因

本病属风湿病范畴,病因尚不清楚,一般认为人类白细胞抗原 HLA-B27 与本病相关。

2. 病理

基本病理改变为原发性、慢性、血管翳破坏性炎症，韧带骨化是继发的修复过程。病变一般自骶髂关节开始，缓慢沿着脊柱向上延伸，累及椎间小关节的滑膜和关节囊以及脊柱周围的软组织，晚期可使整个脊柱周围的软组织钙化、骨化，导致严重的驼背畸形。病变也可同时向下蔓延，累及双侧髋关节，少数也可累及膝关节和踝关节。

3. 临床表现

(1)好发人群 16\~30 岁青壮年,男性占 90%,有明显家族史。
(2)下腰痛伴晨僵 早期表现为下腰痛或骶髂部疼痛,活动后减轻,休息时加重,常伴晨僵。
(3)髋关节受累 表现为臀部和腹股沟酸痛不适,疼痛可向下肢放射。半数病人以下肢大关节如髋、膝、踝关节炎症为首发症状。髋关节受累时行走呈摇摆步态。
(4)脊柱强直 随着病变逐渐向上发展,整个脊柱自下向上强直,呈驼背畸形。由于颈椎和腰椎旋转活动受限,侧视时必须转动全身。
(5)胸椎后凸 胸椎后凸,骨性强直而头部前伸畸形。
(6)颈部活动受限 病变累及颈椎时,可有颈部活动受限,侧视时必须转动全身。

4. 辅助检查

(1)实验室检查 血小板升高、血红蛋白降低、血沉增快和C反应蛋白升高。类风湿因子一般为阴性,免疫球蛋白可轻度升高。HLA-B27阳性率达88%\~96%,对诊断本病起一定辅助作用。

(2)X线表现

①早期 骶髂关节骨质疏松,关节边缘呈虫蛀状改变,间隙不规则增宽,软骨下骨硬化。
②中期 关节面渐趋模糊,间隙逐渐变窄,直至双侧骶髂关节完全融合。
③晚期 竹节样脊柱(椎间小关节融合、椎间盘骨化、脊柱前后纵韧带骨化)、髋关节骨性强直。

5. 诊断与鉴别诊断

(1)诊断标准 ①腰背痛至少持续3个月,活动后疼痛可缓解。②受累脊柱节段各个方向的活动均受限。③胸廓扩展范围小于同年龄、同性别人群正常值。④双侧骶髂关节炎Ⅱ\~Ⅳ级,或单侧骶髂关节炎Ⅲ\~Ⅳ级。如具备第④条和①\~③条中的任何1条,可诊断为强直性脊柱炎。
(2)鉴别诊断 本病须与类风湿关节炎、髂骨致密性骨炎相鉴别。

### 6. 治疗

目的是解除疼痛、防止畸形和改善功能。

(1)非药物治疗 功能锻炼,保持恰当姿势,尽量延缓、减轻驼背畸形。戒烟有利于功能预后。

(2)药物治疗 非甾体抗炎药是控制症状的一线药物。

(3) 手术治疗 关节强直者可行人工关节置换术,有严重驼背畸形者可行脊柱截骨矫形手术。

B. 退行性脊柱骨关节病  
C. 强直性脊柱炎

## 三、类风湿关节炎

类风湿关节炎(RA)是一种以关节病变为主的慢性炎症,以对称性、多关节发病为主要特点。好发于手、腕、足等小关节,关节疼痛和肿胀反复发作且进行性加重,最终导致关节破坏、强直和畸形。

### 1.病因

(1) 自身免疫反应 人类白细胞相关抗原 HLA-DR4 与本病有不同程度的相关性。
(2) 感染 本病发展过程的一些特征与病毒感染相符, 目前认为甲型链球菌感染为本病的诱因。
(3)遗传因素 本病有明显的遗传特点,发病率在类风湿关节炎病人家族中明显增高。

### 2. 病理

类风湿关节炎的基本病理变化是关节滑膜的慢性炎症。

### 3. 临床表现

中青年女性多发。表现为反复发作的、对称性、多发性小关节炎。受累关节以近侧指间关节、掌指关节以及腕、肘、肩、膝和足趾关节多见，颈椎、颞下颌关节也可受累，并伴活动受限，髋关节受累少见。

| 关节肿痛 | 受累关节持续性肿胀、疼痛和压痛。手指近侧指间关节的梭形肿胀是类风湿病人的典型表现之一。关节疼痛的程度通常与其肿胀的程度相关联,关节肿胀愈明显,疼痛愈重 |
|---|---|
| 晨僵 | 95%的病人出现晨僵,晨僵时间超过1小时有诊断意义 |
| 关节活动受限 | 病变持续发展,关节活动受限逐渐加重 |
| 关节畸形 | 最常见的手部畸形有掌指关节尺偏畸形和手指鹅颈畸形、膝关节内翻或外翻畸形 |

### 4. 辅助检查

(1)常规检查 血红蛋白减少,白细胞正常或降低,淋巴细胞计数增加,血沉加快,CRP增高。
(2)类风湿因子 类风湿因子(RF)阳性率为70%\~80%。
(3)免疫球蛋白 IgG、IgA、IgM增高。
(4)关节液检查 混浊,黏稠度降低,黏蛋白凝固力差,糖含量降低,细菌培养阴性。
(5)X 线表现 ①早期:周围软组织肿胀,关节间隙增宽,关节周围骨质疏松;②中期:关节周围骨质疏松更明显,关节面边缘模糊不清,关节间隙逐渐变窄;③晚期:关节间隙消失,最终出现骨性强直。

### 5. 诊断

①晨起关节僵硬至少1小时(≥6周);②3个或3个以上关节肿胀(≥6周);③腕关节、掌指关节或近侧指间关节肿胀(≥6周);④对称性关节肿胀(≥6周);⑤皮下类风湿结节;⑥手、腕关节X线片有明确的骨质疏松或骨侵蚀;⑦类风湿因子阳性(滴度>1:32)。符合4条或4条以上标准即可诊断本病。

### 6. 治疗

类风湿关节炎目前尚无特效治疗方法。治疗目的在于控制炎症、减轻症状、延缓病情进展、保持关节功能和防止畸形。应根据不同病人、不同病情制订合适的综合治疗方案。

(1)非药物治疗 注意休息,禁烟,控制体重,合理饮食和适当运动,关节活动与肌力训练。
(2)药物治疗 类风湿关节炎一经确诊,应尽早使用传统合成改善病情抗风湿药物治疗。推荐首选甲氨蝶呤,如存在甲氨蝶呤禁忌,则选用来氟米特或柳氮磺吡啶。
(3) 手术治疗 ①早期可在关节镜下行关节清理、滑膜切除术,以减少关节液渗出,防止血管翳形成,保护软骨和软骨下骨组织,改善关节功能。②晚期关节功能严重受损时可考虑行人工关节置换术。
