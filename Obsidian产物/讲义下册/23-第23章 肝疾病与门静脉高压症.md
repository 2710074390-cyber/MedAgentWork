# 第23章 肝疾病与门静脉高压症

## 考纲要求

## 复习要点

## 一、肝的解剖生理概要

### 1. 肝的应用解剖

| 肝的韧带 | 肝的膈面和前面——左、右三角韧带、冠状韧带、镰状韧带、肝圆韧带 肝的脏面——肝胃韧带、肝十二指肠韧带(内有肝蒂) |
|---|---|
| 肝蒂 | 肝十二指肠韧带内,包含门静脉、肝动脉、淋巴管、淋巴结、神经,称为肝蒂 |
| 第一肝门 | 门静脉、肝动脉和肝总管在肝脏面的横沟处各自分出左、右干进入肝实质内,称第一肝门 |
| 第二肝门 | 肝静脉是肝血液的流出管道,肝左、中、右静脉在肝后上方的静脉窝进入下腔静脉,称第二肝门 |
| 第三肝门 | 小部分肝血液经数支肝短静脉汇入肝后方的下腔静脉,称第三肝门 |
| Glisson鞘 | 在肝实质内,门静脉、肝动脉和肝内胆管的走向基本一致,共同被包裹在Glisson鞘内 |
| 肝的血供 | 肝的血供25%~30%来自肝动脉,70%~75%来自门静脉,肝的总血流量可达1500ml/min 供氧量——门静脉(40%~60%)、肝动脉(40%~60%) |

### 2. 肝的主要功能

(1)分泌胆汁 每日分泌胆汁 $800 \sim 1000 \mathrm{ml}$ , 其中由肝细胞分泌的胆汁约占 $3 / 4$ , 由胆管细胞分泌的黏液约占 $1 / 4$ 。并不是我们想当然的胆汁全部由肝细胞分泌 (10 版《外科学》P462)。
(2)代谢功能 ①肝将肠道吸收的碳水化合物、蛋白质和脂肪转化为糖原,储存于肝内。②在蛋白质代谢过程中,肝主要起合成、脱氨和转氨作用。③肝在脂肪代谢中起重要作用,并维持体内各种脂质浓度和比例的稳定。④肝对雌激素、抗利尿激素具有灭活作用。
(3)凝血功能 肝能合成大多数凝血因子,参与凝血过程。
(4) 解毒作用 内源性或外源性毒物在肝经过生物转化变为无毒物质。
(5) 吞噬或免疫功能 肝通过 Kupffer 细胞的吞噬作用, 将细菌、抗原抗体复合物、色素从血液中清除。

注意:①10版《外科学》P443:胆汁分泌量为800\~1000ml/d,10版《外科学》P462此数据为800\~1200ml/d。

②伴肝硬化的病人,实施肝切除术时,常温下单次肝门阻断的时间不宜超过20分钟。

## 二、肝脓肿

### 1. 细菌性肝脓肿

(1) 感染途径 致病菌大多为肺炎克雷伯菌、大肠埃希菌、厌氧链球菌、葡萄球菌等。

| 胆道 | 胆道逆行感染是最主要感染途径,约占50%胆道良性或恶性病变并发化脓性胆管炎时,细菌沿胆管上行,引起细菌性肝脓肿 |
|---|---|
| 门静脉 | 如坏疽性阑尾炎、胃肠道憩室炎等,细菌可突破肠道屏障经门静脉入肝 |
| 肝动脉 | 体内任何部位的化脓性感染,如细菌性心内膜炎等,并发菌血症时,细菌可经肝动脉入肝 |
| 直接扩散 | 肝毗邻器官或组织存在感染病灶,细菌可循淋巴系统侵入或直接扩散感染至肝 |
| 开放性损伤 | 开放性肝损伤时,细菌可直接经伤口入肝引起感染,形成脓肿 |

#### (2)临床表现

| 炎症表现 | 寒战、高热、体温升高、周身乏力 |
|---|---|
| 消化道症状 | 恶心、呕吐、食欲缺乏 |
| 局部症状 | 肝区疼痛、肝大、肝区叩痛。肝区钝痛或胀痛多为持续性,可伴右肩牵涉痛 |
| 溃破症状 | 1向上溃破→右侧脓胸; 2向下溃破→腹膜刺激征; 3向左溃破→穿入心包;4向膈下溃破→膈下脓肿; 5向肝内溃破→侵犯肝内血管致大量出血 |

#### (3)辅助检查

| 血常规 | 白细胞计数和中性粒细胞比例增高 |
|---|---|
| 血清学检查 | 转氨酶、碱性磷酸酶增高、CRP增高、ESR增快 |
| B超 | 首选检查,阳性率96%。可在B超引导下行脓肿诊断性穿刺和治疗 |
| CT检查 | 阳性率为90%,更易显示多发小脓肿 |
| MRI检查 | 对存在可疑胆道疾病时帮助较大 |
| X线检查 | 右叶肝脓肿可使右侧膈肌升高,肝阴影增大或局限性隆起,右侧反应性胸膜炎或胸腔积液 |

(4)诊断与鉴别诊断 根据病史、临床表现、超声检查,即可诊断本病。必要时在 B 超引导下施行诊断性穿刺予以确诊。细菌性肝脓肿与阿米巴肝脓肿的鉴别如下。

|  | 细菌性肝脓肿 | 阿米巴性肝脓肿 |
|---|---|---|
| 一般情况 | 发病年龄&gt;50岁,男女比例1.5:1 | 发病年龄20~40岁,男女比例&gt;10:1 |
| 病史 | 继发于胆道感染或其他化脓性疾病,糖尿病病史 | 继发于阿米巴痢疾,少见糖尿病病史 |
| 症状 | 急骤严重,全身中毒症状明显,寒战、高热,黄疸 | 起病慢,可有高热,或不规则发热、盗汗 |
| 血液化验 | 白细胞计数和中性粒细胞比例增高 细菌培养可阳性,血清胆红素可升高 | 白细胞计数可增高。如无细菌感染,细菌培养阴性。血清阿米巴抗体检测阳性 |
| 粪便检查 | 无特殊发现 | 部分病人可找到阿米巴滋养体或包囊 |
| 脓液 | 多为黄白色脓液,涂片和培养可发现细菌 | 多为棕褐色脓液,无臭味,镜检可有阿米巴滋养体。如无感染,涂片和培养无细菌 |
| 试验治疗 | 抗阿米巴治疗无效 | 抗阿米巴治疗有效 |
| 脓肿 | 较小,常为多发性 | 较大,常为单发,多见于肝右叶 |

### 2. 阿米巴性肝脓肿

(1) 临床特点 阿米巴性肝脓肿是肠道阿米巴感染的并发症, 绝大多数单发。

(2) 治疗 采用非手术治疗, 大多数病人可获得良好疗效。

①非手术治疗 抗阿米巴治疗可以选用甲硝唑、氯喹、依米丁。必要时反复穿刺吸脓、行支持治疗。
②经皮肝穿刺置管引流术 适用于病情较重,脓腔较大,有穿破危险者;或经抗阿米巴治疗及多次穿刺吸脓,而脓腔未见缩小者。
③手术切开引流 适用于:A. 经抗阿米巴治疗及穿刺引流后仍高热不退者; B. 脓肿伴继发细菌感染, 经穿刺引流及药物治疗不能控制者; C. 脓肿已穿破入胸腹腔并发脓胸和腹膜炎者。

## 三、肝肿瘤

### 1. 原发性肝癌

(1)病因 肝细胞癌发病与肝硬化、病毒性肝炎、黄曲霉毒素以及某些化学致癌物质等因素有关。

(2) 病理 肝癌大体病理形态分为三型: 结节型、巨块型和弥漫型。

①传统上以肿瘤直径5cm为界，将肝细胞癌分为小肝癌(直径≤5cm)和大肝癌(直径>5cm)两类。
②中华医学会外科学分会肝脏外科学组的分类:微小肝癌(直径≤1cm),小肝癌(直径>1cm,≤5cm),大肝癌(直径>5cm,≤10cm)和巨大肝癌(直径>10cm)。

#### (3) 转移途径

①肝内转移 肝癌细胞极易经门静脉系统在肝内播散。
②血行转移 肝外转移最多见于肺,其次为骨、脑等。

③淋巴转移 相对少见,可转移至肝门淋巴结以及胰周、腹膜后、主动脉旁及锁骨上淋巴结。

④直接侵犯 肿瘤可直接侵犯邻近脏器，如膈肌、胃或横结肠，也可发生腹腔种植性转移。

(4)临床表现 病人年龄大多为40\~50岁,男性比女性多见。

①早期 肝癌早期缺乏典型临床表现，一旦出现症状和体征，疾病多已进入中、晚期。

②常见症状 肝区疼痛、肝大或右上腹肿块，乏力、消瘦、食欲缺乏、黄疸、腹胀等症状。

③转移症状 发生肺、骨、脑等脏器转移者，可引起相应症状。

④副肿瘤综合征 少数病人可有低血糖症、红细胞增多症、高血钙和高胆固醇血症等特殊表现。

(5)诊断 病人有乙型肝炎或丙型肝炎等肝病病史,甲胎蛋白(AFP)≥400ng/ml,超声、CT或MRI检查发现肝实质性肿块,且具有肝细胞癌典型影像学表现者,即可作出临床诊断。

(6) 治疗 早期诊断、早期采用以手术切除为主的综合治疗。

①肝切除 适应证如下。

A. 病人情况 一般情况较好,无明显心、肺、肾等重要脏器器质性病变;肝功能 Child-Pugh 分级属 A 级;肝储备功能良好,吲哚菁绿检测正常。  
B. 根治性肝切除 单发肿瘤,估计肝切除后残肝体积≥全肝50%;多发肿瘤,局限在同一肝段或半肝范围内;肝内无多发转移,无肝外转移。  
C. 非根治性肝切除 肝癌侵犯肝内重要管道或邻近器官,合并门静脉癌栓和/或腔静脉癌栓者,如病人一般情况允许,可考虑肝切除。  

②不可切除肝癌的外科治疗 可根据具体情况,术中作肝动脉栓塞化疗以及冷冻、射频或微波消融治疗等,有一定的疗效。

③肝移植 手术指征包括:肝功能属 C 级,或长期为 B 级,经护肝治疗不能改善;肿瘤直径 $\leqslant5cm$ ,数目少于 3 个;无血管侵犯和远处转移。

④消融治疗 常用的消融方法有射频、微波、冷冻和无水乙醇4种,通常是在超声引导下经皮穿刺施行,也可在手术中施行。消融治疗适用于瘤体较小而不宜手术切除者,特别是肝切除术后早期复发者。

⑤介入治疗 经皮穿刺股动脉插入导管,将导管插入肿瘤侧肝动脉,注入栓塞剂和化疗药物。此方法可使肿瘤部分坏死,使肿瘤缩小,延长病人生存时间。

⑥放射治疗 肿瘤较局限、无远处转移而又不适宜手术切除者,或手术切除后肝断面有残癌或手术切除后复发者,可采用放射治疗为主的综合治疗。

⑦肝癌破裂出血 小的破裂往往可以自行止血。如出血量大,应急诊行经肝动脉栓塞(TAE)或经肝动脉化疗栓塞(TACE),或行急诊肝切除术。病情危急、术中情况不允许者,立即行纱布填塞止血,尽快结束手术,待病人情况稳定后再作进一步处理。

### 3. 肝海绵状血管瘤

肝海绵状血管瘤常见于中年女性，多为单发，也可多发，左、右肝的发生率大致相等。

(1) 临床症状 肿瘤生长缓慢,病程长达数年以上。瘤体较小时无任何临床症状。增大后主要表现为肝大或压迫胃、十二指肠等邻近器官,引起上腹部不适、腹胀、嗳气、腹痛等症状。
(2)体征 腹部肿块与肝相连,表面光滑,质地柔软,有囊性感及不同程度的压缩感。
(3)诊断 根据临床表现、超声、CT、MRI、肝动脉造影等检查,不难诊断。
(4) 治疗 手术切除是治疗本病最有效的方法。

①无须治疗 对于小的、无症状的肝海绵状血管瘤不需治疗。
②手术切除 手术指征:临床症状明显且影响正常生活和工作者;肿瘤直径>10cm,特别是位于肝缘,有外伤性破裂危险者。
③肝动脉结扎术 病变广泛分布于左、右半肝而不能切除者，可行肝动脉结扎术。

(5)并发症 最危险的并发症是肝肿瘤破裂引起的大出血,但极少发生。

## 四、肝囊肿

肝囊肿是较常见的肝良性疾病,分为寄生虫性(如肝棘球蚴病)和非寄生虫性肝囊肿。后者又分为先天性、创伤性、炎症性、肿瘤性囊肿。临床上以先天性肝囊肿多见,它又分为单发性和多发性两种。

### 1. 病理

(1)单发性肝囊肿 以20\~50岁多见,男女发生率之比为1:4。囊肿多发生于肝右叶。囊肿直径小者仅数毫米,大者含液量>500ml,甚至可占据整个肝叶。
(2) 多发性肝囊肿 以 40\~60 岁女性多见,囊肿大小不等,多累及全肝,但也可局限于一段或一叶。
(3)囊液 囊液澄清透明,不含胆汁。

### 2. 临床表现

(1) 小的囊肿 常无任何症状, 多系影像学检查或术中发现。
(2)大的囊肿 可压迫邻近脏器而出现食后饱胀、恶心、呕吐、右上腹隐痛不适等。
(3)体征 可触及右上腹肿块和肝大,肿块与肝相连,表面光滑,带囊性感,无明显压痛。

### 3. 诊断

(1)超声检查 是诊断肝囊肿的首选方法。
(2) CT 或 MRI 检查 可明确囊肿大小、部位、形态、数目。
(3) X 线检查 大的肝囊肿 X 线检查可显示膈肌抬高、胃肠受压移位等征象。

### 4. 治疗

(1)不需治疗 无症状的肝囊肿,不需特殊处理。
(2)适当治疗 巨大而有症状的肝囊肿,应予以适当治疗。常用方法是腹腔镜下囊肿“开窗术”或“去顶术”。对于并发感染、囊内出血者,可在“开窗术”后放置引流。多发性肝囊肿一般仅限于处理其中可能引起症状的大囊肿,可行囊肿“开窗术”,以缓解症状。

## 五、门静脉高压症

门静脉高压症是指各种原因导致门静脉血流受阻和/或血流量增加所引起的门静脉系统压力增高，继而引起脾大和脾功能亢进,食管胃底静脉曲张、呕血、黑便、腹水等的临床综合征。门静脉正常压力为13\~24cmH₂O,平均值为18cmH₂O。门静脉压力>25cmH₂O时即定义为门静脉高压,多数病例门静脉压力可上升至30\~50cmH₂O。

### 1. 解剖概要

(1)门静脉位于两个毛细血管网之间 门静脉主干是由肠系膜上、下静脉和脾静脉汇合而成,肠系膜上、下静脉和脾静脉由来自胃、肠、脾、胰的毛细血管网逐渐汇合而成。门静脉主干在近肝门处分为左、右两支,分别进入左、右半肝后逐级分支,其小分支最终与肝动脉小分支的血流汇合于肝小叶内的肝窦(肝的毛细血管网),然后汇入肝小叶的中央静脉,再汇入小叶下静脉、肝静脉,最后汇入下腔静脉。可见门静脉位于两个毛细血管网之间:一端是胃、肠、脾、胰的毛细血管网,另一端是肝窦(肝的毛细血管网)。
(2)门静脉没有静脉瓣 由于门静脉系统没有静脉瓣,因此当门静脉压力升高时,首先出现脾脏淤血性肿大,久之可出现脾功能亢进。
(3)门静脉与肝动脉关系密切 门静脉和肝动脉的小分支血流除了汇合于肝小叶内的肝窦,还在肝小叶间门管区借着无数的动静脉间交通支相互沟通。
(4)门静脉系与腔静脉系之间有4个交通支 正常情况下,这些交通支都很细小、血流量都很少。

①胃底、食管下段交通支 门静脉血流经胃冠状静脉、胃短静脉，通过食管胃底静脉丛与奇静脉、半奇静脉的分支吻合，汇入上腔静脉。
②直肠下端、肛管交通支 门静脉血流经肠系膜下静脉、直肠上静脉与直肠下静脉、肛管静脉吻合，流入下腔静脉。
③前腹壁交通支 门静脉的血流经脐旁静脉与腹上深静脉、腹下深静脉吻合，汇入上、下腔静脉。
④腹膜后交通支 许多肠系膜上、下静脉分支与下腔静脉分支在腹膜后相互吻合,形成的交通支称为 Retzius 静脉丛。

### 3. 病理生理

(1)脾大和脾亢 门静脉压力升高后,脾静脉血回流受阻,脾窦扩张,脾脏肿大。血流在脾内的驻留时间延长,遭到脾脏吞噬细胞吞噬的概率增大,导致外周血白细胞、血小板、红细胞减少,称为脾功能亢进。
(2) 交通支扩张 由于正常的肝内门静脉通路受阻, 如下四个交通支大量开放, 并扩张、扭曲形成静脉曲张。其中最有临床意义的是在食管下段、胃底形成的曲张静脉, 它离门静脉主干和腔静脉最近, 压力差最大, 因而受门静脉高压影响也最早、最显著。

| 门腔静脉交通支 | 门脉高压症时交通支扩张的后果 |
|---|---|
| 食管下段、胃底交通支 | 最重要的交通支,曲张静脉破裂可导致上消化道大出血 |
| 直肠下端、肛管交通支 | 直肠上、下静脉丛扩张可引起继发性痔 |
| 前腹壁交通支 | 脐旁静脉与腹上、下深静脉交通支扩张,引起前腹壁静脉曲张,呈“海蛇头”体征 |
| 腹膜后交通支 | 腹膜后交通支的临床意义相对较小,曲张静脉破裂可引起腹膜后血肿 |

(3)腹水 腹水产生的机制如下。①门静脉压力升高,使门静脉系统毛细血管床的滤过压增高。②肝硬化引起的低蛋白血症,造成血浆胶体渗透压降低及淋巴液生成增加。③淋巴液自肝表面、肠浆膜面漏入腹腔形成腹水。④门静脉高压症时,门静脉内血流量增加,有效循环血量减少,继发性醛固酮分泌增多。⑤慢性肝病时,醛固酮、抗利尿激素等在肝内的灭活减少,导致水钠潴留。
(4)门静脉高压性胃病 门静脉高压症时,胃壁淤血、水肿,胃黏膜下层的动-静脉交通支广泛开放,胃黏膜微循环发生障碍,导致胃黏膜防御屏障破坏,形成门静脉高压性胃病。发生率约20%。
(5)肝性脑病是指门脉高压症时,由于门体血流短路或手术分流,造成大量门静脉血流绕过肝细胞或因肝细胞功能严重受损,致使有毒物质进入体循环,从而对脑产生毒性作用并出现精神神经综合征。

### 7. 治疗

(1) 治疗目的 主要针对食管胃底曲张静脉破裂出血、脾大脾亢、顽固性腹水、原发肝病进行治疗。
(2)食管胃底曲张静脉破裂出血 应根据病人的具体情况及肝功能分级选择适宜治疗措施。

①非手术治疗 适用于一般情况不良,肝功能较差(Child C级),难以耐受手术的病人;手术前准备。

| 补液输血 | 发生急性出血时,应尽快建立有效的静脉通道进行补液,监测病人生命体征 |
|---|---|
| 药物治疗 | 止血——首选血管收缩剂,如加压素、生长抑素、奥曲肽;β受体阻滞剂如普萘洛尔可预防出血预防感染——使用头孢类广谱抗生素其他——质子泵抑制剂、利尿、预防肝性脑病、护肝治疗 |
| 内镜治疗 | 内镜下硬化剂治疗、内镜下食管曲张静脉套扎术,后者是控制急性出血的首选方法 |
| 三腔管压迫止血 | 适用于无内镜治疗条件或内镜治疗失败者,可使80%病人出血得到控制,压迫不宜超过24小时。原理是利用充气的气囊分别压迫胃底和食管下段的曲张静脉,以达到止血目的。是紧急情况下暂时控制出血的有效方法 |
| TIPS | 经颈静脉肝内门体分流术(TIPS)可明显降低门静脉压力,用于治疗急性出血和预防再出血适用于药物和内镜治疗无效、外科手术后再出血、等待肝移植的病人TIPS后易发生肝性脑病(20%~40%)、肝衰竭(5%~10%)、支撑管血栓形成而进行性狭窄 |

②生长抑素、奥曲肽是治疗食管胃底静脉曲张出血最常用的药物(10版《内科学》P424)。

③内镜治疗(EVL)是控制食管静脉曲张急性出血的首选方法(10版《外科学》P455)。

④TIPS 主要用于药物治疗、内镜治疗无效者,但易并发肝性脑病,发生率为 20%\~40%。

②手术治疗 肝功能较好(Child A 级或 B 级)者,可手术治疗。

A. 手术适应证 曾经或现在发生消化道出血,或静脉曲张明显和“红色征”、出血风险较大,以及一般情况尚可、肝功能 Child A 级或 B 级,估计能耐受手术者。  
B. 手术禁忌证 肝功能 Child C 级病人一般不主张手术, 尽量采取非手术治疗。  
C. 手术时机的选择 手术时机可分为急诊手术、择期手术、预防性手术。  

|  | 手术适应证 | 临床评价 |
|---|---|---|
| 急诊手术 | 出血凶猛,出血量大;经严格内科治疗48小时仍不能控制出血;止血后24小时内再出血 | 此时病情往往严重,多合并休克急诊手术死亡率较高 |
| 择期手术 | 有过出血史者应在充分术前准备下择期手术 | 可防止再出血,减少肝性脑病的发生 |
| 预防性手术 | 对于没有发生过出血者进行预防性手术伴明显脾大、脾亢者在消除脾亢时可进行手术 | 食管胃底静脉曲张不明显不宜做预防性手术重度曲张,特别是镜下见“红色征”者,可手术 |

D. 手术方式 包括分流术、断流术、联合手术、肝移植四大类。  

a. 门体分流术 是通过在门静脉与腔静脉系统间建立分流通道、降低门静脉压力、达到止血的手术。

| 优点 | 降压效果好,再出血率低 |
|---|---|
| 缺点 | 术后肝脏门静脉血供减少,对肝功不利,不适合肝功能较差的病人,术后肝性脑病发生率较高 |
| 适应证 | 有食管胃底曲张静脉破裂出血(史)伴明显门静脉高压性胃病出血、断流术后再次出血者 |
| 分类 | 分流术可分为非选择性门体分流术、选择性门体分流术(包括限制性分流术)两类 |

选择性门体分流术旨在保存门静脉的入肝血流，同时降低食管胃底曲张静脉的压力，代表术式是远端脾-肾静脉分流术。限制性门体分流术的目的是充分降低门静脉压力，制止食管胃底曲张静脉出血，同时保证部分入肝血流，代表术式为限制性门-腔静脉分流术、门-腔静脉“桥式”（H形）分流术。

b. 断流术 是指通过阻断门-奇静脉间的反常血流,达到止血目的。

| 优点 | 手术操作相对简单,创伤小,对肝脏门静脉供血影响较小手术适应证宽,甚至肝功能Child C级的病人也能耐受手术死亡率及并发症发生率低,术后生存质量高,易于在基层医院推广,在国内的应用最广泛 |
|---|---|
| 缺点 | 术后门静脉高压仍较明显,再出血率高 |
| 适应证 | 门静脉循环中没有可供与体静脉吻合的通畅静脉既往分流手术和其他非手术疗法失败而又不适合分流手术,及需要行预防性手术的病人 |
| 术式 | 贲门周围血管离断术、胃周血管缝扎术、食管下端横断术、胃底横断术、食管下端胃底切除术 |

手术方式较多，但以脾切除+贲门周围血管离断术最为有效，最为常用。贲周血管分为以下4组。

| 冠状静脉 | 包括胃支、食管支及高位食管支,有时还可出现异位高位食管支 |
|---|---|
| 胃短静脉 | 一般为3~4支,伴行胃短动脉,分布于胃底的前后壁,注入脾静脉 |
| 胃后静脉 | 起始于胃底后壁,伴同名动脉下行,注入脾静脉 |
| 左膈下静脉 | 可单支或分支进入胃底或食管下段左侧肌层 |

贲周血管离断术时应彻底切断上述静脉，包括高位食管支或同时存在的异位高位食管支，同时结扎、切断与静脉伴行的同名动脉，才能彻底阻断门奇静脉间的反常血流。高位食管支的离断是手术成败的关键。

F. 手术方式选择 急诊手术首选贲周血管离断术,能达到即刻止血目的,手术死亡率低。

(3) 脾大、脾功能亢进 脾切除是治疗脾功能亢进最有效的方法, 既能降低门静脉压力, 又能延缓肝病进展。几乎全部断流术及部分分流术均包含有脾切除术。

(4)顽固性腹水 可采用腹腔穿刺外引流、TIPS、腹腔-上腔静脉转流术、腹水皮下转流术等治疗。

(5)原发肝病 我国绝大多数门静脉高压症是病毒性肝炎肝硬化所致,肝功能损害多较严重。行肝移植,既替换了病肝,又使门静脉系统血流动力学恢复到正常,目前认为是最根本的治疗方法。
