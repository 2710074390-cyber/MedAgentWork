## 8. 要注意归纳总结及鉴别比较

选择题不同于问答题或简答题,解题时要求的就是准确。如平时不注意归纳总结,希望考试时临时去推导、组合,结果多是错误的!常常听同学们抱怨说:“书我都看了两三遍,不知为什么就是做不对试题。”我只能遗憾地告诉你:“你目前的水平,只能做做问答题或简答题,还没有达到做选择题所要求的水平。”因为你还没有领会教科书内容的精髓,还没有对所有相关的知识点进行归纳总结。

这也不能怪同学们,因为考研就这么几个月,要复习的东西实在太多,哪有那么多时间去归纳总结?再看看有些复习资料,大多数是教科书内容的摘要,通过作者自己归纳总结后成文的东西几乎很少。看了这些复习资料后,还是不能解题。为此,本书将考点、难点进行归纳总结,比较鉴别,以使同学们复习事半功倍。例如有关“慢性胃炎”的内容,无论内科学还是病理学都是常考点,如果你平时复习时就能总结成下面这张表格,记忆起来就非常方便、快捷,且不易记混,解题时也会得心应手。

|  | 自身免疫性胃炎(A型胃炎、慢性胃体炎) | 多灶萎缩性胃炎(B型胃炎、慢性胃窦炎) |
|---|---|---|
| 累及部位 | 胃体、胃底 | 胃窦 |
| 基本病理变化 | 黏膜变薄、腺体减少 | 黏膜变薄、腺体减少 |
| 发病 | 少见 | 很常见 |
| 病因 | 多由自身免疫反应引起 | 多由幽门螺杆菌感染所致(占90%) |
| 贫血 | 常伴有,甚至恶性贫血 | 无 |
| 血清维生素 $B_{12}$ | 明显降低(恶性贫血) | 正常 |
| 抗内因子抗体(IFA) | 阳性(占75%) | 阴性 |
| 抗壁细胞抗体(PCA) | 多为阳性(阳性率90%) | 多为阴性(阳性率30%) |
| 胃酸 | 明显降低 | 正常或偏低 |
| 血清胃泌素 | 明显升高(恶性贫血时更高) | 正常或偏低 |

同学们也许会问：“这么大一张表，怎么记得住？”其实，在本书中，笔者也讲述了许多非常实用的记忆方法，只要方法得当，记忆起来也非常简单。比如要记住这张鉴别表，可采取如下步骤：

①首先记住“别称”项，即A型胃炎也称“慢性胃体炎”，B型胃炎也称“慢性胃窦炎”。

②根据“别称”项推导出其他内容：胃体、胃底含有大量壁细胞，而壁细胞是分泌胃酸的，故A型胃炎因胃体病变，胃酸分泌减少、抗壁细胞抗体 $(+)$ 。由于胃酸减少，通过负反馈机制，血清胃泌素分泌增多。

壁细胞除分泌胃酸外,还能分泌内因子。内因子和维生素 $B_{12}$ 结合促进后者的吸收。因此,慢性胃体炎由于壁细胞数量减少、功能减退,可导致内因子分泌减少、血清维生素 $B_{12}$ 浓度下降。维生素 $B_{12}$ 长期缺乏,将导致巨幼细胞贫血,严重时恶性贫血,故A型胃炎常伴贫血。

③记住剩余的内容:如慢性胃炎以萎缩性胃炎多见,“萎缩”就是指“黏膜萎缩、腺体减少”,因此两型胃炎共有的病理特点就是黏膜变薄、腺体减少。

## 9. 熟练掌握病例题的解答

从 2007 年开始,每年内、外科学都有大量病例题,约占内、外科分值的 50%。其中,常考点是疾病的诊断、鉴别诊断、首选确诊方法和首选治疗。因此,同学们复习时,应重点掌握这方面的知识点。

【例 65】2025NO50A 女性,42 岁。反复反酸、烧心 10 余年,平卧位时明显,近 2 个月来加重并影响睡眠,最适宜的治疗药物是——C

A. 促胃肠动力剂  
B. 抗酸剂  
C. 质子泵抑制剂  
D. 组胺 $\mathrm{H}_{2}$ 受体拮抗剂  

(85\~87题共用题干)男性,60岁。乏力、腰痛1个月。既往体健。血常规:Hb80g/L,WBC6.8× $10^{9}$ /L,Plt176× $10^{9}$ /L;血清总蛋白105g/L,白蛋白30g/L,血清蛋白电泳可见一染色浓而密集、单峰突起的M蛋白,血Cr134μmol/L。初步诊断为多发性骨髓瘤。

【例 66】2024NO85A 根据目前的临床资料,该患者最可能的类型是——A

A. IgG 型  
B. IgE 型  
C. IgD 型  
D. 轻链型
