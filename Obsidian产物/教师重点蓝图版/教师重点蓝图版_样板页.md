## 模块2：耳科学（含耳源性眩晕）

> [!INFO] 模块信息
> <b>权重</b>：28%｜<b>预计题型</b>：A1 / A2 / A3/A4 / 判断 / 多选 / 案例
> <b>谱系位置</b>：外耳 → 中耳 → 内耳 → 耳源性眩晕；从“传导障碍”到“感音/平衡障碍”，再到“颅内外并发症”
> <b>三个题眼</b>：① 传导性 vs 感音神经性聋；② 胆脂瘤三大征；③ 眩晕三病的时间轴
> <b>预计阅读</b>：约 25 分钟（标准版）

### 🧩 前置知识检查

- 外耳、中耳、内耳各含哪些结构？声音入内耳有哪两条途径？
- 鼓膜的正常标志有哪些？光锥在什么位置？
- 咽鼓管连通哪里？它的主要功能是什么？
- 面神经在腮腺内分为哪五支？周围性面瘫与中枢性面瘫怎么分？

> [!TIP] 复习入口
> 本模块是全科“地基”：先记“结构—功能—检查”三件套，再进入各论疾病。耳的解剖分区与听力检查是选择题的直接考点。

### 🎯 30 秒摘要

1. 外耳集音、中耳传音、内耳感音；任何一环坏了，听力就掉。
2. 传导性聋：Rinne 阴性、有气骨导差；感音神经性：气骨导同降、无差距。
3. 胆脂瘤：松弛部穿孔 + 恶臭豆渣样脓 + CT 骨质破坏伴硬化边缘。
4. 突发性聋：一天内骤降，2 周内激素，2～6 周挽救。
5. 眩晕先看时间：秒级 BPPV，小时级梅尼埃，天级前庭神经炎。

### 📋 考点卡

#### 🔴 K-M02-015｜突发性聋（教师重点第125条｜教材P###）

📌 重点原文（第125条）：突发性聋应尽早进行听力学检查和专科评估，可在发病2周内考虑糖皮质激素初始治疗；初始治疗后恢复不完全者，可在发病2～6周评估鼓室内糖皮质激素挽救治疗。

<b>🎯 一句话题眼</b>：一天内听力骤降 → 越早激素越好；2 周内初始，2～6 周挽救。

<b>🧬 为什么</b>：内耳供血依赖终末动脉，栓塞/痉挛 → 毛细胞缺氧。越早恢复灌注，听力挽救概率越高；超过窗口，毛细胞不可逆丢失。

<b>🔗 机制链</b>：

```text
病毒感染 / 血管因素
        ↓
内耳供血障碍 → 毛细胞缺氧/损伤
        ↓                ↓
高频听力下降      耳鸣 / 眩晕
        ↓                ↓
言语识别下降      需排除后循环卒中
```

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 突发性聋 | 梅尼埃病 | 听神经瘤 |
|---|---|---|---|
| 起病 | 数分钟–数小时达峰 | 反复发作 | 进行性 |
| 听力 | 单侧感音神经性聋 | 波动性低-中频感音神经性聋 | 单侧进行性感音神经性聋 |
| 伴随 | 耳鸣、可伴眩晕 | 耳闷、低频耳鸣、眩晕 | 耳鸣、不平衡感 |
| 关键检查 | 纯音测听、声导抗 | 甘油试验、听力学 | MRI / 增强 MRI |

<b>🚨 红线</b>：伴眩晕/神经体征 → 先排后循环卒中；不能只按“耳科”处理。

<b>🩺 下一步</b>：① 纯音测听 + 声导抗；② MRI/增强排除桥小脑角病变；③ 2 周内激素，2～6 周挽救。

<b>🔄 自测</b>：突发性聋激素初始治疗的时间窗是《　》；挽救治疗的时间窗是《　》；为什么越早越好？（答案见附录五）

> [!WARNING] 易错陷阱
> 把“2 周内”写成“尽早”而不给具体窗；把“2～6 周”漏掉。时间窗是本题的硬事实，不能用“早期”概括。

#### 🔴 K-M02-021｜梅尼埃病 vs BPPV（教师重点第26、27、28条｜教材P###）

📌 重点原文（第26条）：梅尼埃病的病理基础为膜迷路积水。

📌 重点原文（第27条）：典型表现为反复发作旋转性眩晕，持续数小时；伴耳闷、低频耳鸣；听力呈波动性低-中频感音神经性聋，反复发作后听力逐步下降。

📌 重点原文（第28条）：BPPV 由翻身、头位变动诱发，眩晕持续十余秒，静止后缓解；无耳鸣、耳闷和听力下降。

<b>🎯 一句话题眼</b>：看时间轴——秒级 → BPPV；小时级 + 耳部症状 → 梅尼埃。

<b>🧬 为什么</b>：膜迷路积水 → 内淋巴压力波动 → 反复发作的眩晕与低频听力下降；耳石脱落进入半规管 → 头位变动时短暂眩晕。

<b>⚖️ 鉴别</b>：

| 鉴别轴 | 梅尼埃病 | BPPV |
|---|---|---|
| 诱因 | 自发性，反复发作 | 翻身 / 头位变动 |
| 持续时间 | 20 分钟–12 小时 | 十余秒，通常不足 1 分钟 |
| 听力 | 波动性低-中频感音神经性聋 | 正常 |
| 伴随 | 耳闷、低频耳鸣 | 无耳鸣、耳闷、听力下降 |
| 关键检查 | 甘油试验、听力学 | Dix-Hallpike / 滚转试验 |

<b>🚨 红线</b>：首次发作、伴神经体征或进行性听力下降 → 先排中枢/桥小脑角病变，不要直接诊断梅尼埃。

<b>🩺 下一步</b>：梅尼埃急性期用前庭抑制剂/镇静剂控制眩晕；BPPV 首选手法复位（Epley 等）。

<b>🔄 自测</b>：一位患者翻身时出现旋转性眩晕 10 秒，无耳鸣耳闷，听力学正常。最可能的诊断是《　》，首选检查是《　》，首选处理是《　》。

> [!WARNING] 易错陷阱
> 梅尼埃病的“数小时”不是“数天”；BPPV 的“十余秒”不是“数分钟”。看到“持续时间”先定位，再看听力，不要先背病名。

#### 🟡 K-M02-006｜传导性聋 vs 感音神经性聋（教师重点第112条 + 教材分型补充）

📌 重点原文（第112条）：气导大于骨导为林纳试验阳性；林纳试验阴性典型提示传导性聋；韦伯试验中传导性聋偏患耳、单侧感音神经性聋偏健耳。

<b>🎯 一句话题眼</b>：有气骨导差 → 路的问题；气骨导一起掉 → 耳/神经的问题。

<b>⚖️ 对比速查</b>：

| 鉴别轴 | 传导性聋 | 感音神经性聋 | 混合性聋 |
|---|---|---|---|
| Rinne 试验 | 阴性（骨导＞气导） | 阳性（气导＞骨导） | 可阴性 / 阳性 |
| 气导 | 下降 | 下降 | 下降 |
| 骨导 | 基本正常 | 下降 | 下降 |
| 气骨导差 | 有 | 无 | 有 |
| 病变部位 | 外耳 / 中耳 | 内耳 / 听神经 | 两者兼有 |

> [!NOTE] 来源说明
> 第112条只覆盖音叉试验的判断；三型听力损失的完整定义（气导/骨导/气骨导差）来自教材“听力损失分型”节，属于理解性补充，不单列为教师重点条号。

<b>🩺 下一步</b>：音叉试验初筛 → 纯音测听 + 声导抗；传导性进一步查外耳/中耳，感音神经性进一步查内耳/听神经。

> [!TIP] 记忆钩子
> “传导差的是‘路’，感音差的是‘耳’；有气骨导差 → 路的问题；气骨导一起掉 → 耳/神经的问题。”

#### 🔬 展开：为什么“单侧分泌性中耳炎”要查鼻咽？

鼻咽部肿瘤（如鼻咽癌）压迫咽鼓管咽口 → 咽鼓管功能障碍 → 中耳负压 → 鼓室积液 → 传导性听力下降。因此成人单侧分泌性中耳炎应查鼻咽，排除鼻咽癌。

> [!INFO] 临床含义
> 这是“局部体征 → 远处病因”的典型链路。考试常把“单侧”作为题眼，而不是“中耳炎”本身。

### 📊 对比速查：眩晕三病

| 鉴别轴 | BPPV | 梅尼埃病 | 前庭神经炎 |
|---|---|---|---|
| 诱因 | 翻身 / 头位变动 | 自发性 | 常有上感史 |
| 持续时间 | 十余秒 | 20 分钟–12 小时 | 数天 |
| 听力 | 正常 | 波动性低-中频感音神经性聋 | 正常 |
| 伴随 | 无耳鸣耳闷 | 耳闷、低频耳鸣 | 恶心、呕吐、不平衡 |
| 关键检查 | Dix-Hallpike / 滚转试验 | 甘油试验、听力学 | 前庭功能、MRI 排中枢 |
| 处理 | 手法复位 | 前庭抑制剂/镇静剂 | 对症、前庭康复 |

### 🔗 因果链：咽鼓管功能障碍 → 分泌性中耳炎

```text
上呼吸道感染 / 过敏 / 鼻咽部肿瘤
                ↓
        咽鼓管咽口阻塞
                ↓
        中耳负压 → 黏膜静脉扩张 → 渗出
                ↓
        鼓室积液 → 传导性听力下降
                ↓
        长期不愈 → 粘连性中耳炎 / 胆脂瘤
```

> [!INFO] 读图
> 为什么“单侧分泌性中耳炎”要查鼻咽？因为咽鼓管咽口被肿瘤压迫是常见诱因。

### 🌳 决策树：眩晕的时间轴

```text
眩晕
├─ 翻身/头位变动诱发、十余秒、无听力下降
│    → BPPV（Dix-Hallpike / 滚转试验）
├─ 反复发作、20 分钟–12 小时、波动性听力下降
│    → 梅尼埃病（甘油试验、听力学）
├─ 持续数天、近期上感、无听力下降
│    → 前庭神经炎
└─ 伴复视/构音障碍/共济失调/中枢眼震
     → 先排后循环卒中（急诊影像）
```

> [!INFO] 读图
> 第一分支不是“病名”，而是“时间 + 诱因 + 听力”三个轴。
